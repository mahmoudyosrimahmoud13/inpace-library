# Structs: your own data types

Real data comes in groups: a student has a name, an age and a grade. A **struct** bundles related values into one type.

## Defining and using a struct

```c
#include <stdio.h>

struct Student {
    char name[30];
    int age;
    double grade;
};

int main(void) {
    struct Student s = {"Nour", 20, 88.5};
    printf("%s (%d): %.1f\n", s.name, s.age, s.grade);

    s.grade = 91.0;   // change one field with the dot
    printf("New grade: %.1f\n", s.grade);
    return 0;
}
```

```output
Nour (20): 88.5
New grade: 91.0
```

## typedef: a shorter name

`typedef` lets you write `Student` instead of `struct Student`:

```c
typedef struct {
    char name[30];
    int age;
    double grade;
} Student;
```

## Arrays of structs

```c
#include <stdio.h>

typedef struct {
    char name[30];
    double grade;
} Student;

int main(void) {
    Student cls[] = {{"Nour", 88.5}, {"Ali", 92.0}, {"Mona", 79.5}};
    int n = sizeof(cls) / sizeof(cls[0]);

    int best = 0;
    for (int i = 1; i < n; i++) {
        if (cls[i].grade > cls[best].grade) best = i;
    }
    printf("Top student: %s with %.1f\n", cls[best].name, cls[best].grade);
    return 0;
}
```

```output
Top student: Ali with 92.0
```

## Pointers to structs and ->

Structs are copied when you pass them to functions, which can be slow for big ones and doesn't let you change the original. Pass a **pointer** instead. With a pointer, use **`->`** to reach a field: `p->grade` means `(*p).grade`.

<!-- diagram -->
```mermaid
flowchart LR
  P["Account *acc"] --> S["Account a<br/>name: Karim<br/>balance: 100.0"]
  P -. "acc->balance is (*acc).balance" .-> S
```

```c
#include <stdio.h>

typedef struct {
    char name[30];
    double balance;
} Account;

void deposit(Account *acc, double amount) {
    acc->balance += amount;
}

void show(const Account *acc) {
    printf("%s: %.2f\n", acc->name, acc->balance);
}

int main(void) {
    Account a = {"Karim", 100.0};
    deposit(&a, 50.25);
    show(&a);
    return 0;
}
```

```output
Karim: 150.25
```

## Structs on the heap

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char title[40];
    int year;
} Book;

int main(void) {
    int n = 2;
    Book *shelf = malloc(n * sizeof(Book));
    if (!shelf) return 1;
    strcpy(shelf[0].title, "Cairo Trilogy");
    shelf[0].year = 1956;
    strcpy(shelf[1].title, "Season of Migration");
    shelf[1].year = 1966;
    for (int i = 0; i < n; i++) printf("%d %s\n", shelf[i].year, shelf[i].title);
    free(shelf);
    return 0;
}
```

```output
1956 Cairo Trilogy
1966 Season of Migration
```

## Enums

An `enum` gives names to a set of numbers, making code much easier to read:

```c
typedef enum { PENDING, PAID, SHIPPED } OrderStatus;
OrderStatus status = PAID;
if (status == PAID) { /* ... */ }
```

## Try it

Make a struct `Point` with `double x, y`, and a function `double distance(Point a, Point b)` that returns the distance between two points. Test it with (0,0) and (3,4). (You'll need `sqrt` from `<math.h>`, and on Linux add `-lm` when compiling.)

**Answer:**

```c
#include <stdio.h>
#include <math.h>

typedef struct {
    double x, y;
} Point;

double distance(Point a, Point b) {
    double dx = a.x - b.x, dy = a.y - b.y;
    return sqrt(dx * dx + dy * dy);
}

int main(void) {
    Point p = {0, 0}, q = {3, 4};
    printf("%.1f\n", distance(p, q));
    return 0;
}
```

```output
5.0
```
