# فيديو: تهجئة نهايات الكلمات s و ing و ed

حين تضيف **s** أو **ing** أو **ed** لفعل، تتغير الكتابة أحيانًا. شاهد الفيديو (من Cambly: ثلاث قواعد أساسية)،
ثم راجع الجدول، فهو يجمع القواعد التي تحتاجها في A1.

| الإضافة | القاعدة | أمثلة |
|---|---|---|
| **s** (he/she/it) | ss, sh, ch, x, o ← **es** | watch → watch**es**, go → go**es** |
| | ساكن + y ← **ies** | study → stud**ies** (لكن play → plays) |
| **ing** | ينتهي بـ e: احذفها | make → mak**ing** |
| | ساكن-علة-ساكن قصير: كرر الأخير | stop → sto**pp**ing, run → ru**nn**ing |
| **ed** | ينتهي بـ e: أضف d فقط | like → like**d** |
| | ساكن + y ← **ied** | study → stud**ied** (لكن play → played) |
| | ساكن-علة-ساكن قصير: كرر الأخير | stop → sto**pp**ed, plan → pla**nn**ed |

**لا تكرر** مع w و x و y: *snow → snowing, fix → fixed, play → playing*.

## تمرين

اكتب الفعل بالشكل المطلوب: 1. she ___ (watch) 2. I'm ___ (write) 3. we ___ (stop, ماضي) 4. he ___ (cry, ماضي)
5. they're ___ (swim) 6. it ___ (fix, ماضي)

## الإجابات

1. watches 2. writing 3. stopped 4. cried 5. swimming 6. fixed
