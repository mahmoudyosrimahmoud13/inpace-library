# جمع الأسماء

| القاعدة | مثال |
|---|---|
| أضف s | book → books, car → cars |
| ss, sh, ch, x, o → es | bus → buses, watch → watches, potato → potatoes |
| ساكن + y → ies | city → cities, baby → babies |
| f/fe → ves | knife → knives, wife → wives |

## جمع شاذ (احفظه)

```text
man → men      woman → women      child → children      person → people
foot → feet    tooth → teeth      mouse → mice
```
