# الآن: Present continuous

لشيء يحدث **الآن** أو هذه الأيام: **am/is/are + فعل-ing**

```text
I'm reading a book now.      She's cooking dinner.      They're playing football.
Are you working today?       What are you doing?        I'm not watching TV.
```

## إضافة ing

| القاعدة | مثال |
|---|---|
| أضف ing | read → reading, play → playing |
| ينتهي بـ e: احذفها | write → writing, come → coming |
| ساكن-علة-ساكن قصير: كرر الأخير | sit → sitting, run → running, swim → swimming |

## الآن أم دائمًا؟

| Present simple | Present continuous |
|---|---|
| I **work** in a bank. (دائمًا) | I'm **working** from home this week. (الآن/مؤقت) |
| She **drinks** tea every day. | She's **drinking** coffee now. |

أفعال لا تأتي مع ing عادة: like, love, want, know, understand, need. قل I'm wanting ❌ ← **I want** ✅
