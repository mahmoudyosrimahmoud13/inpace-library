# Writing journal entries

Transactions are first recorded in the **journal** (also called the *book of original entry*), in date order. Each record is a **journal entry**.

## The format

| Date | Account | Debit | Credit |
|---|---|---|---|
| Jun 2 | Equipment | 8,000 | |
| | &nbsp;&nbsp;&nbsp;&nbsp;Cash | | 8,000 |
| | *Bought an oven, receipt #104* | | |

The rules of the format:

- **Debits first**, at the left. **Credits after**, indented.
- A short **description** under each entry, ideally with the document number (invoice, receipt).
- Debits must equal credits in every entry.

## Compound entries

Some transactions touch three or more accounts. That's a **compound entry**, and the rule stays: total debits = total credits.

Example: Nour buys a mixer for $1,200, paying $400 now and the rest next month.

| Date | Account | Debit | Credit |
|---|---|---|---|
| Jul 3 | Equipment | 1,200 | |
| | &nbsp;&nbsp;&nbsp;&nbsp;Cash | | 400 |
| | &nbsp;&nbsp;&nbsp;&nbsp;Accounts payable | | 800 |

Another: she repays $1,000 of a bank loan plus $50 interest.

| Date | Account | Debit | Credit |
|---|---|---|---|
| | Loans payable | 1,000 | |
| | Interest expense | 50 | |
| | &nbsp;&nbsp;&nbsp;&nbsp;Cash | | 1,050 |

## Why a journal at all?

Because it keeps each transaction **whole**, in one place, in time order. If something looks wrong later, you can find the exact entry and its document. The ledger, next lesson, sorts the same numbers by account instead.

## Try it

Journalize:
1. Jul 5: Nour receives a $600 order paid in advance for a wedding cake to be delivered Jul 20.
2. Jul 20: she delivers the wedding cake.
3. Jul 22: she pays $150 for repairs to the oven.

**Answers:**
1. Debit Cash 600 / Credit Unearned revenue 600
2. Debit Unearned revenue 600 / Credit Sales revenue 600
3. Debit Repairs expense 150 / Credit Cash 150
