# Adjusting entries

At the end of the period, before preparing reports, you go through the timing gaps and fix them with **adjusting entries**. They're dated the last day of the period, and every one of them touches **one balance sheet account and one income statement account**. They never touch Cash.

## The five kinds

### 1. Prepaid expenses (paid before used)

Nour paid $3,000 for June to August. By June 30 she has used one month.

| Jun 30 | Debit | Credit |
|---|---|---|
| Rent expense | 1,000 | |
| &nbsp;&nbsp;&nbsp;&nbsp;Prepaid rent | | 1,000 |

Prepaid rent is now 2,000 (two months left).

**Supplies** work the same way. She bought 1,500 of supplies and a count on June 30 shows 600 left, so 900 were used:

| Jun 30 | Debit | Credit |
|---|---|---|
| Supplies expense | 900 | |
| &nbsp;&nbsp;&nbsp;&nbsp;Supplies | | 900 |

### 2. Depreciation (the cost of long-lived assets, spread out)

The oven cost 8,000, should last 5 years (60 months), and might sell for 800 at the end (*salvage value*). With the **straight-line** method:

> Depreciation per month = (Cost − Salvage) ÷ Months of life = (8,000 − 800) ÷ 60 = **120**

| Jun 30 | Debit | Credit |
|---|---|---|
| Depreciation expense | 120 | |
| &nbsp;&nbsp;&nbsp;&nbsp;Accumulated depreciation, equipment | | 120 |

We don't credit Equipment directly. **Accumulated depreciation** is a contra account: the balance sheet shows Equipment 8,000 − Accumulated depreciation 120 = **book value 7,880**, and you can still see the original cost.

### 3. Accrued expenses (used before paid)

The assistant worked the last days of June, earning 150, to be paid on July 5.

| Jun 30 | Debit | Credit |
|---|---|---|
| Wages expense | 150 | |
| &nbsp;&nbsp;&nbsp;&nbsp;Wages payable | | 150 |

Interest on a loan, utilities used but not billed yet, and taxes work the same way.

### 4. Unearned revenue (paid before delivered)

When a customer pays in advance, the money goes to Unearned revenue (a liability). When part of the work is done, move that part to revenue. Example: a café paid $600 in advance for six weekly deliveries and two were made by June 30:

| Jun 30 | Debit | Credit |
|---|---|---|
| Unearned revenue | 200 | |
| &nbsp;&nbsp;&nbsp;&nbsp;Sales revenue | | 200 |

(Nour didn't have this in June. It's here so you know the pattern.)

### 5. Accrued revenue (delivered before billed)

On June 30 Nour delivered cupcakes worth 200 to an office that she'll invoice in July.

| Jun 30 | Debit | Credit |
|---|---|---|
| Accounts receivable | 200 | |
| &nbsp;&nbsp;&nbsp;&nbsp;Sales revenue | | 200 |

## Nour's adjusted trial balance, June 30

After the five adjustments she made (rent, supplies, depreciation, wages, accrued revenue):

| Account | Debit | Credit |
|---|---|---|
| Cash | 9,400 | |
| Accounts receivable | 700 | |
| Supplies | 600 | |
| Prepaid rent | 2,000 | |
| Equipment | 8,000 | |
| Accumulated depreciation | | 120 |
| Accounts payable | | 500 |
| Wages payable | | 150 |
| Nour, capital | | 20,000 |
| Nour, drawings | 500 | |
| Sales revenue | | 3,800 |
| Wages expense | 1,050 | |
| Utilities expense | 300 | |
| Rent expense | 1,000 | |
| Supplies expense | 900 | |
| Depreciation expense | 120 | |
| **Totals** | **24,570** | **24,570** |

Profit is now 3,800 − 3,370 = **430**, not the 2,400 we had before adjusting. The difference is the true cost of the month: rent, supplies and oven wear Nour used, and wages she owes.

## A checklist for every month-end

- Prepaid items: how much was used?
- Supplies and inventory: count them.
- Long-lived assets: depreciation.
- Unpaid wages, interest, utilities: accrue them.
- Advance payments from customers: how much was earned?
- Work done not yet billed: accrue it.
