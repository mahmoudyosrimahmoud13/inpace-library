# Project part 2: train a digit recognizer

## 1. The data

scikit-learn's handwritten digits: 1,797 grey-scale images of 8 × 8 pixels, each a digit from 0 to 9. Flatten each
image into 64 numbers, scale them to [0, 1], and split 60 / 20 / 20.

```python
import numpy as np
from sklearn.datasets import load_digits
from minigrad import Tensor, MLP, Adam, cross_entropy

digits = load_digits()
X = digits.data / 16.0                     # pixel values were 0..16
y = digits.target
rng = np.random.default_rng(0)
idx = rng.permutation(len(y))
tr, va, te = idx[:1078], idx[1078:1437], idx[1437:]
print(X.shape, "train / validation / test:", len(tr), len(va), len(te))
print("one image, as numbers:\n", (digits.images[idx[0]]).astype(int))
print("its label:", y[idx[0]])
```

## 2. A training loop with mini-batches and early stopping

Everything from chapters 7 and 9 in one function: shuffled mini-batches (7.2.4), Adam (7.3.3), and early stopping on
the validation set (9.3.1), keeping a copy of the best weights.

```python
def accuracy(model, rows):
    return np.mean(model(Tensor(X[rows])).data.argmax(axis=1) == y[rows])

def train(model, epochs=60, batch=64, lr=3e-3, weight_decay=0.0, seed=1):
    order_rng = np.random.default_rng(seed)
    opt = Adam(model.parameters(), lr=lr, weight_decay=weight_decay)
    best_acc, best_weights, best_epoch = -1.0, None, 0
    for epoch in range(1, epochs + 1):
        shuffled = order_rng.permutation(tr)
        for start in range(0, len(shuffled), batch):
            rows = shuffled[start:start + batch]
            loss = cross_entropy(model(Tensor(X[rows])), y[rows])
            opt.zero_grad()
            loss.backward()
            opt.step()
        val = accuracy(model, va)
        if val > best_acc:
            best_acc, best_epoch = val, epoch
            best_weights = [p.data.copy() for p in model.parameters()]
    for p, w in zip(model.parameters(), best_weights):    # early stopping: restore the best weights
        p.data = w
    return best_epoch, best_acc
```

## 3. One layer versus two

First a single-layer network (softmax regression, the multi-class logistic regression of section 5.4.4), then a network
with one hidden layer of 128 ReLU units.

```python
for sizes in ([64, 10], [64, 128, 10]):
    model = MLP(sizes, np.random.default_rng(0))
    epoch, val = train(model)
    print(f"layers {sizes}: best validation accuracy {val:.3f} at epoch {epoch}, "
          f"test accuracy {accuracy(model, te):.3f}")
```

```output
layers [64, 10]: best validation accuracy 0.944 at epoch 60, test accuracy 0.956
layers [64, 128, 10]: best validation accuracy 0.986 at epoch 23, test accuracy 0.983
```

The hidden layer earns its place: learned features beat a linear model on raw pixels. And it all trains in about a
second, on your own automatic differentiation.

## 4. Where does it go wrong?

A **confusion matrix**: row = true digit, column = predicted digit. The diagonal holds the correct answers.

```python
pred = model(Tensor(X[te])).data.argmax(axis=1)
conf = np.zeros((10, 10), dtype=int)
for true, guess in zip(y[te], pred):
    conf[true, guess] += 1
print("     " + " ".join(f"{d:3d}" for d in range(10)))
for d in range(10):
    print(f"{d:3d}  " + " ".join(f"{n:3d}" for n in conf[d]))
print("mistakes:", int(np.sum(pred != y[te])), "of", len(te))
```

## 5. How sure is it when it's wrong?

The softmax output is a probability (section 6.4.3). A well-behaved classifier should be **less** confident on its
mistakes.

```python
from minigrad import softmax

probs = softmax(model(Tensor(X[te]))).data
confidence = probs.max(axis=1)
right = pred == y[te]
print(f"average confidence when right: {confidence[right].mean():.3f}")
print(f"average confidence when wrong: {confidence[~right].mean():.3f}")
for i in np.where(~right)[0][:5]:
    top2 = np.argsort(-probs[i])[:2]
    print(f"  true {y[te][i]}, predicted {top2[0]} ({probs[i, top2[0]]:.2f}), second choice {top2[1]} ({probs[i, top2[1]]:.2f})")
```

```output
average confidence when right: 0.962
average confidence when wrong: 0.627
  true 9, predicted 5 (0.57), second choice 1 (0.25)
  true 4, predicted 7 (0.64), second choice 4 (0.34)
  true 9, predicted 8 (0.60), second choice 9 (0.37)
  true 1, predicted 8 (0.65), second choice 1 (0.27)
  true 6, predicted 8 (0.67), second choice 0 (0.12)
```

Confidence is lower on the mistakes, and often the right answer is the second choice. That's useful: like the reject
option in part 1, you could send the low-confidence cases to a person.
