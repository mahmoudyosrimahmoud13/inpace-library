# Read: inductive bias, weight decay and learning curves (9.1–9.3)

Read the opening of chapter 9 and sections 9.1 to 9.3 (pages 253 to 270).

## Inductive bias (9.1)

Any finite data set can be explained by infinitely many functions. Learning only works because the model **prefers**
some functions over others: its **inductive bias**.

- **Inverse problems** (9.1.1): many inputs fit the data equally well, so you need extra preferences to choose.
- **No free lunch** (9.1.2): averaged over all possible problems, no learning algorithm beats any other. A method is good
  only because its biases match the problems we actually meet: smooth functions, objects that don't change when they
  move, and so on.
- **Symmetry and invariance** (9.1.3): a cat is still a cat when shifted, rotated or brightened. The book lists four
  ways to build that in, and you'll meet all of them: **augment** the training data with transformed copies, add a
  **regularizer** that penalizes sensitivity to the transformations, compute **invariant features** first, or build the
  invariance into the **architecture** (the route chapter 10's convolutional networks take).
- **Equivariance** (9.1.4): sometimes you want the output to transform *with* the input (shift an image, and its
  segmentation map should shift the same way). Convolutions are equivariant to shifts.

## Weight decay (9.2)

- The `(λ/2)‖w‖²` penalty from part 1, now for networks. It limits how far the weights
  travel in directions where the error is flat, and leaves well-determined directions alone.
- **Consistent regularizers** (9.2.1): if you rescale your inputs or outputs, an equivalent network exists with rescaled
  weights. Plain weight decay penalizes the two networks differently, which is inconsistent. The fix is to use separate
  λ's for different groups of weights, and **not to penalize the biases**.
- **Generalized weight decay** (9.2.2): penalties `|w|^q`. With q = 1 (the **lasso**), many weights become exactly zero,
  which gives sparse models.

## Learning curves (9.3)

- **Early stopping** (9.3.1): as training goes on, the training error keeps falling, while the validation error often
  falls, then rises. Stop at the validation minimum. The book shows why this works much like weight decay: stopping
  early keeps the weights from travelling far from their small starting values.
- **Double descent** (9.3.2): the surprise of modern deep learning. As the model gets bigger, the test error first follows
  the classic U-shape from part 1, peaks when the model can just barely fit the training data exactly, and then
  **falls again** as the model grows far beyond that point. The same can happen with training time. Very large networks
  generalize better than the simple bias–variance picture predicts. Read the book's careful discussion; this is still an
  active research topic.
