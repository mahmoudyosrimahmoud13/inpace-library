# Read: error functions and mixture density networks (6.4–6.5)

Read sections 6.4 and 6.5 to the end of the chapter (pages 194 to 208).

## Error functions (6.4)

Section 6.4 collects part 1's results into a rule you'll use for every network you build: **pick the output activation
and the error function together, from the type of target.**

| Target | Output activation | Error function |
|---|---|---|
| A real number (regression) | none (identity) | sum of squares |
| Yes / no (binary) | logistic sigmoid | binary cross-entropy |
| One of K classes | softmax | multiclass cross-entropy |
| K independent yes / no labels | K sigmoids | sum of K binary cross-entropies |

Each pairing comes from maximum likelihood with the matching distribution (Gaussian, Bernoulli, categorical), and each
gives the simple "prediction minus target" gradient at the output. Section 6.4.1 also shows how to estimate the noise
variance after training, so a regression network can report its uncertainty.

## Mixture density networks (6.5)

This is a lovely idea, and a warning about assumptions.

**The problem** (6.5.1). A robot arm: given the joint angles, the hand's position is easy to compute (forward
kinematics). But given a desired position, there are often **two** sets of angles that reach it (elbow up or elbow down).
The inverse problem has several right answers.

**Why squared error fails.** A network trained with squared error learns the **conditional mean** of the target. When
there are two right answers, their average can be a terrible answer: for the robot, a position halfway between "elbow
up" and "elbow down" might not reach the point at all. The book's toy problem shows this: data from `t = x + 0.3 sin(2πx)`
plus noise is easy to fit, but with x and t swapped, some inputs have three possible outputs, and the least-squares
network draws a curve through the gaps.

**The fix** (6.5.2–6.5.4). Let the network output the parameters of a **mixture of Gaussians** for each input: K mixing
coefficients (through a softmax, so they're positive and add to 1), K means and K widths (through an exponential, so
they're positive). Train by maximizing the likelihood of the targets under that mixture. Now the network can say "there
are three likely answers here", and you can pick the most probable branch instead of a useless average.

The lesson goes beyond robots: whenever the same input can lead to quite different outputs, **don't let the error
function assume a single bell curve**. Diffusion models and language models (parts 3 and 5) are, in a sense, extremely
sophisticated answers to this same problem.
