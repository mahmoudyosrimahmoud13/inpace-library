# Start here

This is part 2 of 5 of the course series on **Deep Learning: Foundations and Concepts** by Christopher M. Bishop and
Hugh Bishop (Springer, 2024). Part 2 covers chapters 6 to 9: deep neural networks, gradient descent,
backpropagation and regularization. This is where single-layer models become deep learning.

**Every module ends with a real project you build yourself**, in PyTorch, and publish on GitHub for your CV: a
width-vs-depth study, a robot arm that learns inverse kinematics, an optimizer benchmark, a neural network library with
hand-written backpropagation, an automatic differentiation engine, and a regularization study on scarce data. Each
project lesson comes with a notebook (attached to the lesson; on the website it opens in Google Colab) and the finished
code under `projects/` in the course files. Every dataset the projects use is also in one separate download, [bishop-datasets.zip](https://github.com/mahmoudyosrimahmoud13/inpace-library/releases/download/bishop-datasets-v1/bishop-datasets.zip) (239 MB, with a README saying which files go with which project), for working offline.

## Get the book

The book is **not inside this course**: each **Read** lesson opens the right pages of *your own copy*. Use the PDF
eBook from [Springer](https://link.springer.com/book/10.1007/978-3-031-45468-4), or read free online at
[bishopbook.com](https://www.bishopbook.com) (every lesson title gives the section numbers). On this course's page, in
the box **"This course reads a book you get yourself"**, press **Find it for me** and inPace finds your PDF. The course
expects a 656-page PDF; with another copy the pages may be a little off, so trust the section numbers.

## Before you start

You should have finished **part 1** (chapters 1 to 5), or know its ideas: likelihood, cross-entropy, regularization as
a prior, and logistic regression trained by gradient descent. You need NumPy, and the chain rule from calculus. For
the projects: `pip install torch pandas pyarrow pillow matplotlib`, a free GitHub account, and `git`.

## The big project: your own deep learning library

Real frameworks like PyTorch hide the most important idea in deep learning: **automatic differentiation**. In this
course you'll build it yourself. Piece by piece, you'll write **minigrad**, a small library in plain NumPy:

- Day 4: backpropagation by hand for a two-layer network.
- Day 5: a `Tensor` class that records every operation and computes all gradients automatically (section 8.2).
- Day 7: layers, a cross-entropy loss and the Adam optimizer, then a network that reads handwritten digits with about
  97% accuracy, trained in a couple of seconds on a laptop.

Parts 3, 4 and 5 keep using minigrad for convolutional networks, transformers, VAEs and diffusion models, so the
library grows with you. The finished file is in this course's files as `minigrad.py`, for checking your own version.

## How each module works

**Read** lessons open the book with notes underneath; **Watch** lessons are optional videos; **Build** lessons are code
you run, with the real output printed under every block; the **module project** turns the day's ideas into a project
of your own. Each module ends with a quiz (pass with 70%; questions can
have **more than one right answer**), plus an optional task (publishing your project) and a short explanation in your own words.
