# Project part 3: a mixture density network

On day 2, least squares failed on the inverse problem: for t ≈ 0.35 the right answers were either around 0.14 or around
0.65, and the network predicted 0.455, where there was no data at all. Now fix it with the **mixture density network**
from section 6.5, trained with your own library.

## 1. The data again

```python
import numpy as np
from minigrad import Tensor, Module, Linear, Adam, log_softmax

rng = np.random.default_rng(0)
x = rng.random(1000)
t = x + 0.3 * np.sin(2 * np.pi * x) + rng.uniform(-0.1, 0.1, 1000)
inputs, targets = t.reshape(-1, 1), x.reshape(-1, 1)     # the inverse problem: predict x from t
```

## 2. The network

For every input, the network outputs 3K numbers for a mixture of K = 3 Gaussians: K **mixing logits** (a softmax makes
them positive and add to 1), K **means**, and K **log-widths** (taking the exponential makes the widths positive).

```python
K = 3

class MDN(Module):
    def __init__(self, rng, hidden=20):
        self.l1 = Linear(1, hidden, rng)
        self.l2 = Linear(hidden, 3 * K, rng)

    def forward(self, X):
        out = self.l2(self.l1(X).tanh())
        return out[:, :K], out[:, K:2 * K], out[:, 2 * K:]     # mixing logits, means, log-widths
```

## 3. The error function

The negative log-likelihood of each target under its mixture (section 6.5.3):

```text
−ln Σₖ πₖ(t) · N(x | μₖ(t), σₖ(t)²)
```

Computing a log of a sum of exponentials directly can overflow, so we use the **log-sum-exp** trick: subtract the
largest term first, the same idea as in `log_softmax`.

```python
def mdn_loss(model, X, Y):
    logits, mu, log_sigma = model(Tensor(X))
    log_pi = log_softmax(logits)
    z = (Tensor(Y) - mu) * (log_sigma * -1).exp()              # (x − μ) / σ
    log_normal = z ** 2 * -0.5 - log_sigma - 0.5 * np.log(2 * np.pi)
    a = log_pi + log_normal                                  # log of each term of the sum
    biggest = Tensor(a.data.max(axis=1, keepdims=True))       # a constant, for numerical safety
    return -((a - biggest).exp().sum(axis=1, keepdims=True).log() + biggest).mean()
```

## 4. Train

```python
model = MDN(np.random.default_rng(1))
opt = Adam(model.parameters(), lr=0.01)
for step in range(3001):
    loss = mdn_loss(model, inputs, targets)
    opt.zero_grad()
    loss.backward()
    opt.step()
    if step % 1000 == 0:
        print(f"step {step}: negative log-likelihood {float(loss.data):.3f}")
```

```output
step 0: negative log-likelihood 1.215
step 1000: negative log-likelihood -0.967
step 2000: negative log-likelihood -1.000
step 3000: negative log-likelihood -1.005
```

## 5. Ask it about t = 0.35

```python
logits, mu, log_sigma = model(Tensor(np.array([[0.35]])))
pi = np.exp(log_softmax(logits).data[0])
for k in np.argsort(-pi):
    print(f"component {k}: weight {pi[k]:.2f}, mean {mu.data[0, k]:.2f}, width {np.exp(log_sigma.data[0, k]):.3f}")
```

```output
component 0: weight 0.45, mean 0.13, width 0.027
component 2: weight 0.41, mean 0.64, width 0.054
component 1: weight 0.14, mean 0.69, width 0.053
```

The network has found the two groups of answers. One component sits on the small branch near 0.13, and the others share
the large branch around 0.64 to 0.69 (two components can split one branch between them; their weights add up). Instead
of one useless average, the model now says: "x is probably about 0.13, or about 0.65". To make a single prediction,
take the mean of the heaviest component.
