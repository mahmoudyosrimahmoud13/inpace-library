# Build: when the average answer is wrong

Recreate the toy inverse problem of section 6.5 and see exactly how squared error fails. You'll fix it with a mixture
density network in this course's big project, once you have minigrad.

## 1. The forward problem is easy

```python
import numpy as np

rng = np.random.default_rng(0)
x = rng.random(1000)
t = x + 0.3 * np.sin(2 * np.pi * x) + rng.uniform(-0.1, 0.1, 1000)

def poly_fit(a, b, M=9):
    A = np.vstack([a ** j for j in range(M + 1)]).T
    return np.linalg.lstsq(A, b, rcond=None)[0]

def poly_eval(w, a):
    return np.vstack([a ** j for j in range(len(w))]).T @ w

w_fwd = poly_fit(x, t)
print("forward problem, RMS error:", round(np.sqrt(np.mean((poly_eval(w_fwd, x) - t) ** 2)), 4))
```

```output
forward problem, RMS error: 0.059
```

The error is about the size of the noise (uniform noise of width 0.2 has an RMS of about 0.058): a near-perfect fit.

## 2. The inverse problem is not

Swap the roles: now predict x from t. For some values of t there are several values of x.

```python
w_inv = poly_fit(t, x)
print("inverse problem, RMS error:", round(np.sqrt(np.mean((poly_eval(w_inv, t) - x) ** 2)), 4))

near = np.abs(t - 0.35) < 0.02             # every training point whose t is about 0.35
vals = np.sort(x[near])
groups = np.split(vals, np.where(np.diff(vals) > 0.1)[0] + 1)
for g in groups:
    print(f"  a group of answers: x from {g.min():.2f} to {g.max():.2f}  ({len(g)} points)")
print("least-squares prediction at t = 0.35:", round(poly_eval(w_inv, np.array([0.35]))[0], 3))
```

```output
inverse problem, RMS error: 0.2033
  a group of answers: x from 0.09 to 0.18  (24 points)
  a group of answers: x from 0.55 to 0.77  (38 points)
least-squares prediction at t = 0.35: 0.455
```

When t ≈ 0.35, the data says x is either small (around 0.1 to 0.2) or large (around 0.55 to 0.77). The least-squares
curve predicts a value **between** the two groups, where no training point lies at all. Count them:

```python
pred = poly_eval(w_inv, np.array([0.35]))[0]
print("training points within 0.05 of the prediction:", int(np.sum(np.abs(vals - pred) < 0.05)))
```

```output
training points within 0.05 of the prediction: 0
```

For a robot arm, the "average" of elbow-up and elbow-down is not a pose that reaches the target. The model isn't too
small: its **error function** assumes one Gaussian answer per input, and that assumption is wrong here (section 6.5).

## 3. A glimpse of the fix

A mixture density network outputs a few candidate answers with probabilities. Even without training one, you can see
why it fits: each group of answers becomes one component of the mixture.

```python
for g in groups:
    print(f"component: mean {g.mean():.2f}, width {g.std():.3f}, weight {len(g) / len(vals):.2f}")
```

```output
component: mean 0.14, width 0.024, weight 0.39
component: mean 0.65, width 0.067, weight 0.61
```

In the big project you'll train a network to produce these means, widths and weights for **every** t, by maximizing the
likelihood with your own automatic differentiation.
