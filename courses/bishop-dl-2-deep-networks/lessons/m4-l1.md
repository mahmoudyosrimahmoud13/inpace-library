# Read: evaluating gradients with backpropagation (8.1)

Read the opening of chapter 8 and section 8.1 (pages 233 to 244). Go slowly and redo the derivation in 8.1.2 on paper.
It's the single most important derivation in deep learning.

## The idea

Gradient descent needs the derivative of the error with respect to **every** weight. A network can have millions. Working
each one out separately would be hopeless. **Backpropagation** gets all of them for about the cost of two forward passes,
by reusing work with the chain rule.

## Single layer first (8.1.1)

For a linear output and squared error, the derivative for weight wⱼᵢ is `(yⱼ − tⱼ) · xᵢ`: an **error at the output end**
times an **activation at the input end** of the weight. Hold on to that shape: it survives into deep networks.

## General feed-forward networks (8.1.2)

Each unit j computes a weighted sum `aⱼ = Σᵢ wⱼᵢ zᵢ` and then `zⱼ = h(aⱼ)`. Define the unit's error signal

```text
δⱼ = ∂Eₙ / ∂aⱼ
```

Then two simple rules give everything:

```text
∂Eₙ / ∂wⱼᵢ = δⱼ · zᵢ                       (error at the output end × activation at the input end)
δⱼ = h′(aⱼ) · Σₖ wₖⱼ δₖ                   (hidden δ's come from the δ's of the next layer, sent backwards)
```

At the output units, with a matching error function (canonical link), δₖ = yₖ − tₖ. So the algorithm is:

1. **Forward**: compute every a and z for the input.
2. **Output δ's**: yₖ − tₖ.
3. **Backward**: propagate δ's back through the layers with the second rule.
4. **Gradients**: multiply each δ by the activation feeding the weight.

## A simple example (8.1.3)

The book works it out for a two-layer network with tanh hidden units, linear outputs and squared error. Here
`h′(a) = 1 − z²`, which is cheap because z is already known. You'll code exactly this network in the Build lesson.

## Checking your gradients (8.1.4)

Backpropagation code is easy to get subtly wrong. Compare it with **numerical differentiation**: nudge one weight by
±ε and measure the change in error. The **central difference** `(E(w + ε) − E(w − ε)) / 2ε` is much more accurate than a
one-sided one. It's far too slow for training (one forward pass per weight), but perfect for testing.

## The Jacobian and the Hessian (8.1.5–8.1.6)

The same backward trick gives the **Jacobian** (how each output moves with each input: useful for sensitivity and for
combining modules) and, with more work, the **Hessian**. Read 8.1.5; skim 8.1.6 the first time.
