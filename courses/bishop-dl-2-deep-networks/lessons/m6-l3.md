You'll make a network over-fit on purpose, watch it happen in the learning curves, and try three cures from chapter 9.
This uses the `Tensor` you wrote on day 5, saved as `minigrad.py` next to your notebook.

## 1. A network far too big for its data

15 noisy points from `sin(2πx)`, and a network with two hidden layers of 60 tanh units: about 3,800 weights for 15
numbers. A big validation set measures what we really care about.

```python
import numpy as np
from minigrad import Tensor

rng = np.random.default_rng(1)

def make(n):
    x = rng.random((n, 1))
    return x, np.sin(2 * np.pi * x) + rng.normal(0, 0.2, (n, 1))

Xtr, Ttr = make(15)
Xva, Tva = make(300)

def init(H=60, seed=0):
    r = np.random.default_rng(seed)
    return {"W1": Tensor(r.normal(0, 3, (1, H)), True), "b1": Tensor(r.normal(0, 3, H), True),
            "W2": Tensor(r.normal(0, 1 / np.sqrt(H), (H, H)), True), "b2": Tensor(np.zeros(H), True),
            "W3": Tensor(r.normal(0, 1 / np.sqrt(H), (H, 1)), True), "b3": Tensor(np.zeros(1), True)}

def predict(p, X, drop=0.0, r=None):
    h = (Tensor(X) @ p["W1"] + p["b1"]).tanh()
    if drop:                                   # inverted dropout: zero some units, scale the rest up
        h = h * Tensor((r.random(h.shape) > drop) / (1 - drop))
    h = (h @ p["W2"] + p["b2"]).tanh()
    if drop:
        h = h * Tensor((r.random(h.shape) > drop) / (1 - drop))
    return h @ p["W3"] + p["b3"]

def mse(p, X, T):
    return float(((predict(p, X).data - T) ** 2).mean())

print("weights:", sum(v.data.size for v in init().values()))
```

```output
weights: 3841
```

## 2. A training loop with Adam

Adam from section 7.3.3, with optional weight decay and dropout, and a record of the training and validation error
every 500 steps: the **learning curves**.

```python
def train(steps=10000, lr=0.01, weight_decay=0.0, drop=0.0):
    p = init()
    r = np.random.default_rng(5)
    m = {k: 0.0 for k in p}
    v = {k: 0.0 for k in p}
    curve = []
    for s in range(1, steps + 1):
        for q in p.values():
            q.grad = None
        loss = ((predict(p, Xtr, drop, r) - Ttr) ** 2).sum() * (1 / len(Xtr))
        loss.backward()
        for k, q in p.items():
            g = q.grad + weight_decay * q.data
            m[k] = 0.9 * m[k] + 0.1 * g
            v[k] = 0.999 * v[k] + 0.001 * g * g
            q.data -= lr * (m[k] / (1 - 0.9 ** s)) / (np.sqrt(v[k] / (1 - 0.999 ** s)) + 1e-8)
        if s % 500 == 0:
            curve.append((s, mse(p, Xtr, Ttr), mse(p, Xva, Tva)))
    return curve

plain = train()
print(" step   train    validation")
for s, tr_err, va_err in plain[::2]:
    print(f"{s:5d}   {tr_err:.4f}   {va_err:.4f}")
```

This is the picture from section 9.3. The training error drops to almost zero: the network memorizes the 15 points. The
validation error is best early on and then climbs as the network bends itself through the noise. The noise variance is
0.04 (0.2²), so no model can get the validation error much below that.

## 3. Cure 1: early stopping

Keep the weights from the step where the validation error was lowest.

```python
best = min(plain, key=lambda row: row[2])
print(f"best validation error {best[2]:.4f} at step {best[0]}, versus {plain[-1][2]:.4f} at the end")
```

```output
best validation error 0.0797 at step 1000, versus 0.2351 at the end
```

## 4. Cure 2: weight decay

```python
decay = train(weight_decay=1e-3)
print(f"weight decay: validation error at the end {decay[-1][2]:.4f}, "
      f"best {min(r[2] for r in decay):.4f}, training error {decay[-1][1]:.4f}")
```

```output
weight decay: validation error at the end 0.0761, best 0.0702, training error 0.0120
```

With weight decay, the training error stays well above zero: the network is no longer allowed to memorize. And the
validation error stays low for the whole run, so you don't have to stop at exactly the right moment.

## 5. Cure 3: dropout

```python
dropped = train(drop=0.2)
print(f"dropout: validation error at the end {dropped[-1][2]:.4f}, "
      f"best {min(r[2] for r in dropped):.4f}")
```

```output
dropout: validation error at the end 0.1170, best 0.0842
```

Dropout also stops the run-away over-fitting, though on such a tiny data set its curve is noisy: every step trains a
different thinned network. Dropout shines on bigger networks and data sets, like the digits in tomorrow's project.

## What you've seen

| Method | How it stops over-fitting |
|---|---|
| Early stopping | Weights don't get time to travel far from their small starting values |
| Weight decay | A penalty keeps them small (a Gaussian prior, from part 1) |
| Dropout | Units can't co-adapt, and the result acts like an average of many networks |

All three need a **validation set** to tune: when to stop, how large λ is, which dropout rate to use.
