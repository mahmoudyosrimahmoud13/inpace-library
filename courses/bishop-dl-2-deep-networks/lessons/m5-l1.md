## Four ways to get derivatives

The book compares them at the start of 8.2. Make sure you can say what's wrong with the first three:

1. **By hand**: what you did yesterday. Error-prone, and you redo it every time the architecture changes.
2. **Numerically** (finite differences): easy, but one or two forward passes **per weight**, and limited accuracy.
3. **Symbolically** (like a computer algebra system): exact, but the expressions can grow enormously ("expression
   swell") and repeat the same work many times.
4. **Automatic differentiation**: exact derivatives, computed by following the program's own operations. This is what
   every deep learning framework does.

## The evaluation trace

Any program that computes a function is a sequence of **primitive operations** (add, multiply, exp, tanh …), each with a
derivative we know. Write them down in order, naming every intermediate result: that's the **evaluation trace**, a
graph from inputs to output. The book's running example is a small function of two variables; draw its graph yourself.

## Forward mode (8.2.1)

Carry along, next to every value, its derivative with respect to **one chosen input**. Each primitive updates both, using
the chain rule. One forward sweep gives the derivatives of **all outputs** with respect to that **one input**. Great for
few inputs and many outputs. Hopeless for a network with millions of weights (inputs) and one error (output): you'd need
a million sweeps.

## Reverse mode (8.2.2)

First run the program forward and **keep** every intermediate value. Then sweep **backwards** from the output, carrying
the **adjoint** of each intermediate, `v̄ = ∂f / ∂v`: how much the output changes when v changes. Each node adds its
contribution to the adjoints of its inputs:

```text
if  v = a · b,   then  ā += v̄ · b   and   b̄ += v̄ · a
if  v = a + b,   then  ā += v̄       and   b̄ += v̄
if  v = tanh(a), then  ā += v̄ · (1 − v²)
```

One backward sweep gives the derivative of **one output** with respect to **all inputs**. That's exactly our situation:
one error, millions of weights. **Backpropagation is reverse-mode automatic differentiation**, applied to neural
networks. The price is memory: every intermediate value from the forward pass must be stored until the backward pass
uses it.

Two details that matter when you write your own (tomorrow's job):

- Adjoints are **added up** (`+=`), because one value can feed several later operations, and each use contributes.
- The backward sweep must visit nodes in **reverse topological order**: a node's adjoint is complete only after every
  node that uses it has been processed.
