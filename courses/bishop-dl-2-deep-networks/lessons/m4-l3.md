# Build: backpropagation by hand

This is the network of section 8.1.3: inputs, one hidden layer of tanh units, linear outputs, squared error. You'll
write the forward pass, the backward pass, check every gradient numerically, and then train it.

## 1. The network

```python
import numpy as np

rng = np.random.default_rng(0)
D, M, K = 1, 8, 1                                  # inputs, hidden units, outputs
params = {
    "W1": rng.normal(0, 1.0, (M, D)), "b1": np.zeros(M),
    "W2": rng.normal(0, 1 / np.sqrt(M), (K, M)), "b2": np.zeros(K),
}

def forward(p, X):
    a1 = X @ p["W1"].T + p["b1"]                   # hidden pre-activations
    z1 = np.tanh(a1)                               # hidden activations
    y = z1 @ p["W2"].T + p["b2"]                   # linear outputs
    return z1, y

def error(p, X, T):
    return 0.5 * np.sum((forward(p, X)[1] - T) ** 2)
```

## 2. The backward pass

Follow the four steps of section 8.1.2, for a whole batch at once.

```python
def backward(p, X, T):
    z1, y = forward(p, X)                          # 1. forward
    d2 = y - T                                     # 2. output δ's: prediction minus target
    d1 = (1 - z1 ** 2) * (d2 @ p["W2"])            # 3. hidden δ's: h'(a) times the δ's sent back
    return {                                       # 4. gradient = δ at the output end × activation at the input end
        "W2": d2.T @ z1, "b2": d2.sum(0),
        "W1": d1.T @ X,  "b1": d1.sum(0),
    }
```

## 3. Check it against numerical differentiation

Section 8.1.4: central differences for every single parameter.

```python
X = rng.random((20, D))
T = np.sin(2 * np.pi * X)

grads = backward(params, X, T)
eps = 1e-6
worst = 0.0
for name, value in params.items():
    for idx in np.ndindex(value.shape):
        old = value[idx]
        value[idx] = old + eps; e_plus = error(params, X, T)
        value[idx] = old - eps; e_minus = error(params, X, T)
        value[idx] = old
        numeric = (e_plus - e_minus) / (2 * eps)
        worst = max(worst, abs(numeric - grads[name][idx]))
print("largest difference between backprop and numerical gradients:", f"{worst:.2e}")
```

```output
largest difference between backprop and numerical gradients: 5.15e-10
```

A difference around 10⁻⁹ means the code is right. A bug typically shows up as a difference of 10⁻² or more.

## 4. Train it

Fit `sin(2πx)` from 50 noisy points with plain gradient descent on these gradients.

```python
X = rng.random((50, 1))
T = np.sin(2 * np.pi * X) + rng.normal(0, 0.1, (50, 1))
lr = 0.005
for step in range(40001):
    g = backward(params, X, T)
    for name in params:
        params[name] -= lr * g[name]
    if step % 10000 == 0:
        print(f"step {step:5d}: error {error(params, X, T):.3f}")

grid = np.linspace(0, 1, 5).reshape(-1, 1)
print("predictions:", np.round(forward(params, grid)[1].ravel(), 2))
print("true values:", np.round(np.sin(2 * np.pi * grid).ravel(), 2))
```

```output
step     0: error 10.074
step 10000: error 0.364
step 20000: error 0.279
step 30000: error 0.239
step 40000: error 0.225
predictions: [ 0.06  0.98 -0.04 -1.01 -0.04]
true values: [ 0.  1.  0. -1. -0.]
```

Eight tanh units learned their own basis functions and fit the curve. The final error is about what the noise alone
would give: 50 points × noise variance 0.01 / 2 = 0.25. Going lower would mean fitting the noise. Compare with part 1, where you had to choose 24
Gaussian bumps by hand.

## 5. Count the cost

How much work does backpropagation save? For each method, count how many times the network is run to get all the
gradients.

```python
W = sum(v.size for v in params.values())
print(f"parameters: {W}")
print(f"numerical differentiation: {2 * W} forward passes")
print("backpropagation: 1 forward pass + 1 backward pass (about the cost of 2 forward passes)")
```

```output
parameters: 25
numerical differentiation: 50 forward passes
backpropagation: 1 forward pass + 1 backward pass (about the cost of 2 forward passes)
```

For this toy network, 50 passes versus 2. For a network with a hundred million weights, two hundred million versus 2.
That's why deep learning is possible at all.
