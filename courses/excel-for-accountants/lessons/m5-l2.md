# Budgets and what-if analysis

Spreadsheets shine at "what if?": what if prices rise 10%, what if we sell 20% less?

## A driver-based budget

Put the **drivers** in inputs, never the results:

| Input | Value |
|---|---|
| Cakes per month (January) | 450 |
| Monthly growth | 5% |
| Price | 120 |
| Variable cost per cake | 50 |
| Fixed costs per month | 21,000 |

Then months across columns:

| | Jan | Feb | Mar |
|---|---|---|---|
| Cakes | `=Jan_cakes` | `=B2*(1+Growth)` | `=C2*(1+Growth)` |
| Sales | `=B2*Price` | ... | |
| Variable costs | `=B2*VarCost` | ... | |
| Contribution | `=B3-B4` | ... | |
| Fixed costs | `=Fixed` | ... | |
| Profit | `=B5-B6` | ... | |

Change one input and the whole year updates.

## Goal Seek: work backward

"How many cakes for a 7,000 profit?" Data → What-If Analysis → Goal Seek:
- Set cell: the profit cell
- To value: 7000
- By changing: the cakes input

Answer: 400. (The same break-even logic as *Cost and management accounting*, done by the spreadsheet.)

## Data tables: many answers at once

A **one-variable data table**: profit for prices from 100 to 140.

1. List prices down a column (100, 105, ..., 140).
2. In the cell above and to the right of the list, put `=Profit`.
3. Select the range → Data → What-If Analysis → Data Table → Column input cell: the Price input.

A **two-variable** table shows profit for every combination of price (down) and volume (across): a quick map of where the business makes money.

## Scenarios

Make three columns of inputs: **Pessimistic**, **Base**, **Optimistic** (volume, price, costs), and a selector cell with a dropdown. The active inputs use:

`=CHOOSE(Scenario, Pess_volume, Base_volume, Opt_volume)`

or `=XLOOKUP(Scenario_name, ScenarioNames, VolumeRow)`. One switch flips the whole model. Present all three to management, never just the optimistic one.

## Sensitivity: which input matters most?

Change each input by 10% one at a time and note the change in profit. The biggest effect is where to focus your forecasting effort (for Nour: price, because of operating leverage).

## Try it

Build a 12-month driver budget for a small business with growth, a price rise in July and a new hire in September. Use Goal Seek for the break-even volume, a two-variable data table for price × volume, and three scenarios with a selector.
