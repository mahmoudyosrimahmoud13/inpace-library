# Clean data, controls and Power Query

Exports from systems and banks are messy: extra spaces, numbers as text, dates in odd formats, totals mixed with data. Cleaning by hand every month is slow and error-prone.

## Quick fixes with formulas

| Problem | Fix |
|---|---|
| Extra spaces | `=TRIM(A2)` (and `CLEAN` for invisible characters) |
| Numbers stored as text | `=VALUE(A2)` or `=A2*1`, or Data → Text to Columns → Finish |
| "1.234,50" European numbers | `=NUMBERVALUE(A2, ",", ".")` |
| Dates as text "31/03/2026" | `=DATE(RIGHT(A2,4), MID(A2,4,2), LEFT(A2,2))` |
| Code and name in one cell "1010 - Cash" | `=TEXTBEFORE(A2, " - ")`, `=TEXTAFTER(A2, " - ")` |
| Duplicates | Data → Remove Duplicates (on a copy), or `=UNIQUE()` |
| Blank rows | Filter blanks and delete, or `=FILTER(range, colA<>"")` |

## Power Query: clean once, refresh forever

Data → Get Data → From File (CSV, Excel, folder). The Power Query editor records every cleaning step:

1. Remove top rows (the bank's logo and headers)
2. Use first row as headers
3. Change types (Date, Decimal number)
4. Trim text, replace values, split columns
5. Filter out total rows
6. Close & Load to a Table

Next month: put the new file in the same place → Data → Refresh All. Every step runs again. **From Folder** even combines all monthly files into one Table.

Google Sheets has no Power Query, but `IMPORTDATA`, `QUERY` and the same formulas cover simple cases.

## Controls: make errors visible

- **Check cells** everywhere (debits = credits, BS balances, pivot total = source total), collected on one `Checks` sheet with a single "ALL OK" cell: `=IF(AND(check1=0, check2=0), "ALL OK", "CHECK")`.
- **Data validation**: dropdowns for codes and categories, date limits, whole numbers only.
- **Protect** formula cells (Format Cells → Protection, then Review → Protect Sheet), leaving inputs unlocked.
- **Version and notes**: a `Readme` sheet saying what the file does, its sources, who updated it and when.
- **Avoid hard-coded numbers** inside formulas. Search for them: Ctrl + ` shows formulas, and Go To Special → Constants finds typed numbers among formulas.

## Common spreadsheet errors to hunt

- A formula range that misses the last rows (use Tables)
- A total that includes a subtotal (double counting)
- A sign error (credits added as positive)
- A copied formula pointing to the wrong row
- A linked file that moved (Data → Edit Links)

## Try it

Download a CSV statement from your bank (or make a messy one with spaces, text numbers and a total row). Clean it with Power Query, load it as a Table, and refresh it after adding rows to the CSV. Add a Checks sheet with at least three checks.
