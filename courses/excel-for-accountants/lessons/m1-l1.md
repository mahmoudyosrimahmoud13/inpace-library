# Start here: a spreadsheet you can trust

Accountants live in spreadsheets. A good one is fast to update, easy to check, and hard to break. A bad one hides a typed-over number that nobody finds for a year. This course teaches the habits and the functions accountants use every day, in **Excel** (365 or 2021+) with **Google Sheets** notes where they differ.

## Five habits from day one

1. **Inputs, calculations and outputs apart.** Put assumptions (tax rate, prices) in one clearly marked place, usually a sheet called `Inputs`, and refer to them. Never type a number inside a formula like `=B5*0.14`: write `=B5*VAT_rate`.
2. **One formula per row or column.** The same formula copied down. If one cell is different, it's a trap.
3. **Color the inputs.** A common convention: inputs in blue text (or a light yellow fill), formulas in black. Anyone can see what may be changed.
4. **Checks.** Add cells that must be zero: `=SUM(Debits)-SUM(Credits)`, `=TotalAssets-TotalLiabilitiesEquity`. Make them turn red if not zero.
5. **No merged cells in data.** Use *Center Across Selection* for titles instead. Merged cells break sorting, filtering and formulas.

## References: relative, absolute, mixed

- `A1` relative: changes when copied.
- `$A$1` absolute: never changes. Press **F4** while editing to toggle.
- `$A1` or `A$1` mixed: column or row fixed.

Example: prices in B2:B10 and a VAT rate in `E1`. In C2: `=B2*$E$1`, copied down. Without the `$`, the copy in C3 would point to E2 (empty).

## Tables (Ctrl + T)

Turn every list of data into a **Table**: select it and press **Ctrl + T**. Benefits:
- New rows are included automatically in formulas, pivots and charts.
- Formulas use names: `=[@Amount]*VAT_rate` instead of `=D2*$E$1`.
- Filters and banded rows come for free.

Name the table (Table Design → Table Name), for example `Journal`.

## Named cells

Select E1, type `VAT_rate` in the Name Box (left of the formula bar) and press Enter. Now any formula can use `VAT_rate`. Formulas become readable: `=Subtotal*VAT_rate`.

## Number formats accountants use

- Thousands separator, no decimals for reports: `#,##0`
- Negatives in brackets: `#,##0;(#,##0);-` (positive; negative; zero shown as a dash)
- Never round by formatting alone when the rounded number feeds other calculations: use `ROUND` (next lesson).

## Shortcuts worth learning now

| Keys | Does |
|---|---|
| Ctrl + Arrow | Jump to the end of the data |
| Ctrl + Shift + Arrow | Select to the end |
| Ctrl + D | Copy the cell above down |
| Alt + = | AutoSum |
| F2 | Edit the cell |
| F4 | Toggle $ in a reference |
| Ctrl + ` | Show all formulas |

## Try it

Make an `Inputs` sheet with a named VAT rate of 14%. On another sheet, make a Table of 5 invoices (date, customer, net amount) and add columns for VAT and gross using the named rate. Add one check cell: total gross − (total net + total VAT) must be 0.
