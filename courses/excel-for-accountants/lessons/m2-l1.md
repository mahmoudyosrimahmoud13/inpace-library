# Lookups: XLOOKUP, VLOOKUP and INDEX/MATCH

Accounting work is full of matching: account codes to names, customers to their terms, products to prices.

## XLOOKUP (Excel 365/2021, Google Sheets)

`=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode])`

Chart of accounts in a Table `COA` (Code, Name, Type, Statement):

| Need | Formula |
|---|---|
| Name for code in A2 | `=XLOOKUP(A2, COA[Code], COA[Name], "Not found")` |
| Statement line for code | `=XLOOKUP(A2, COA[Code], COA[Statement])` |

It can look left, gives a clean "not found" message, and doesn't break when columns are inserted.

### Approximate match: tax bands and commissions

A band table sorted ascending: 0 → 0%, 40,000 → 10%, 55,000 → 15%, 70,000 → 20%.

`=XLOOKUP(B2, Bands[From], Bands[Rate], , -1)` finds the largest "From" not above B2 (match mode −1).

## VLOOKUP (older files)

`=VLOOKUP(A2, COA_range, 2, FALSE)`

- Always use `FALSE` (exact match) for codes. Without it, VLOOKUP assumes sorted data and can return a **wrong** row without any error.
- It can only look to the right, and the column number (2) breaks if someone inserts a column.

## INDEX and MATCH (works everywhere)

`=INDEX(COA[Name], MATCH(A2, COA[Code], 0))`

`MATCH` finds the position, `INDEX` returns the value at that position. Flexible and robust. Two-way lookup (a budget grid by account and month):

`=INDEX(Budget, MATCH($A2, AccountList, 0), MATCH(B$1, MonthList, 0))`

## Why lookups fail, and fixes

| Symptom | Cause | Fix |
|---|---|---|
| `#N/A` though the code is visible | Extra spaces | `TRIM` both sides |
| `#N/A` for numbers | Number stored as text in one list | `VALUE` or Text to Columns |
| Wrong answer, no error | VLOOKUP without FALSE | Add FALSE, or use XLOOKUP |
| Breaks after inserting a column | VLOOKUP column number | XLOOKUP or INDEX/MATCH |

## Reconciling two lists

Which invoices in the sales system are missing from the ledger?

In the sales list: `=IF(COUNTIFS(Ledger[Invoice], A2)=0, "Missing", "OK")`, then filter "Missing". `COUNTIFS` is often the simplest matching tool: 0 means not there, 2 means duplicated.
