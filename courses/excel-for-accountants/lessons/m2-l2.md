# From journal to trial balance in a spreadsheet

Let's build the core of an accounting system in one workbook: a journal, a ledger and a trial balance that update themselves.

## Sheet 1: COA (chart of accounts)

Table `COA`: Code | Name | Type (Asset, Liability, Equity, Revenue, Expense) | Normal (Dr or Cr) | Statement (BS or IS)

## Sheet 2: Journal

Table `Journal`, one row per line of each entry:

| Date | Entry | Code | Account | Debit | Credit | Memo |
|---|---|---|---|---|---|---|
| 01/06/2026 | 1 | 1010 | *(formula)* | 20,000 | | Owner's investment |
| 01/06/2026 | 1 | 3010 | *(formula)* | | 20,000 | |

- Account: `=XLOOKUP([@Code], COA[Code], COA[Name], "Bad code")`
- A check per entry, in a summary: `=SUMIFS(Journal[Debit], Journal[Entry], A2)-SUMIFS(Journal[Credit], Journal[Entry], A2)` must be 0 for every entry. Conditional formatting turns non-zero red.

Data validation keeps it clean: Data → Data Validation → List → `=INDIRECT("COA[Code]")` (or a named range) so only real codes can be chosen.

## Sheet 3: Trial balance

List every code (`=COA[Code]` or `=SORT(COA[Code])`), then:

| Column | Formula |
|---|---|
| Name | `=XLOOKUP(A2, COA[Code], COA[Name])` |
| Total debits | `=SUMIFS(Journal[Debit], Journal[Code], A2)` |
| Total credits | `=SUMIFS(Journal[Credit], Journal[Code], A2)` |
| Debit balance | `=MAX(C2-D2, 0)` |
| Credit balance | `=MAX(D2-C2, 0)` |

Totals at the bottom, and a check: `=SUM(E:E)-SUM(F:F)` must be 0.

For a period: add a date condition to each SUMIFS, with start and end dates in input cells:
`=SUMIFS(Journal[Debit], Journal[Code], A2, Journal[Date], ">="&Start, Journal[Date], "<="&End)`

## Sheet 4: A ledger for any account

Pick an account in a cell (`B1`), then:

`=FILTER(Journal[[Date]:[Memo]], Journal[Code]=B1)`

and a running balance next to it: debit minus credit, accumulated. That's a full ledger page for any account, in one formula.

## Why build this if software exists?

Because you'll constantly export from accounting software (Odoo, QuickBooks, SAP, local systems) and rebuild exactly these views to check, adjust and explain numbers. Knowing the structure makes every export easy to work with.

## Try it

Build the four sheets and enter Nour's 11 June transactions from *Accounting from zero*. Your trial balance must total 24,100, every entry check must be 0, and the ledger sheet must show Cash ending at 9,400.
