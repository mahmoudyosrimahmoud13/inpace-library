# Pivot tables for accountants

A **pivot table** summarizes thousands of rows in seconds: sales by month, expenses by category, balances by account. No formulas, and it updates when the data changes.

## Making one

1. Click inside your data Table (it must have one header row and no blank rows).
2. Insert → PivotTable → New worksheet.
3. Drag fields:
   - **Rows:** what to list (Account, Customer, Region)
   - **Columns:** what to spread across (Month)
   - **Values:** what to add up (Amount, as Sum)
   - **Filters:** what to limit to (Year, Branch)

## Five pivots accountants build all the time

| Pivot | Rows | Columns | Values |
|---|---|---|---|
| Sales by month and region | Region | Date (grouped by month) | Sum of Amount |
| Expenses by category | Category | | Sum of Amount, % of total |
| Trial balance from a journal | Code, Account | | Sum of Debit, Sum of Credit |
| Top customers | Customer (sorted, Top 10 filter) | | Sum of Amount |
| Aging summary | Customer | Age bucket | Sum of Balance |

## Useful settings

- **Group dates:** right-click a date → Group → Months and Years.
- **Show values as:** right-click a value → Show Values As → % of Grand Total, % of Column Total, Difference From (last month).
- **Number format:** Value Field Settings → Number Format → `#,##0`.
- **Refresh:** data changed? Right-click → Refresh (or Data → Refresh All). Because the source is a Table, new rows are included.
- **Tabular layout:** Design → Report Layout → Show in Tabular Form, Repeat All Item Labels: easier to copy or use in other formulas.

## Pulling one number out: GETPIVOTDATA

Typing `=` and clicking a pivot cell creates `=GETPIVOTDATA("Amount", $A$3, "Region", "Cairo")`. It keeps working when the pivot's layout changes. (Turn it off in PivotTable Options if you prefer plain references.)

## Pivots and checks

A pivot's grand total must match the source: `=SUM(Sales[Amount])`. Put that check next to every pivot you send to anyone.

## Slicers

Insert → Slicer → choose Branch. Clickable buttons filter the pivot (and its charts). Great for simple dashboards for managers who won't touch a filter menu.

## In Google Sheets

Insert → Pivot table. Same idea: Rows, Columns, Values, Filters. Date grouping is under "Create pivot date group".

## Try it

From a sales Table of at least 50 rows (date, region, product, customer, amount), build: sales by month (rows) and region (columns); each product's share of total sales; the top 5 customers. Add a check cell matching each pivot total to the source.
