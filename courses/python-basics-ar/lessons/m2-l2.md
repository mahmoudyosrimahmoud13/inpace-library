# القوائم

**القائمة** تحمل قيمًا كثيرة بالترتيب، داخل أقواس مربعة.

```python
groceries = ["bread", "eggs", "milk"]
print(groceries)
print(len(groceries))   # 3
```

## الحصول على عنصر واحد

العد يبدأ من **0** وليس من 1:

```python
print(groceries[0])   # bread
print(groceries[2])   # milk
```

## إضافة عنصر

```python
groceries.append("tea")
print(groceries)   # ['bread', 'eggs', 'milk', 'tea']
```

`len()` تخبرك بعدد عناصر القائمة. ستستخدمها كثيرًا.
