# الطباعة والحساب البسيط

`print()` تعرض شيئًا على الشاشة. أي شيء تضعه بين القوسين يظهر.

```python
print("Hello!")
print(2 + 3)
```

النتيجة:

```
Hello!
5
```

## النص والأرقام

- النص يوضع بين علامتي تنصيص: `"Hello"`. بايثون تسمّي النص **string**.
- الأرقام لا تحتاج علامات تنصيص: `42`.

## عمليات حسابية تستخدمها

| الرمز | المعنى | مثال | الناتج |
|---|---|---|---|
| `+` | جمع | `4 + 2` | `6` |
| `-` | طرح | `4 - 2` | `2` |
| `*` | ضرب | `4 * 2` | `8` |
| `/` | قسمة | `4 / 2` | `2.0` |

جرّب طباعة بعض العمليات بنفسك قبل أن تكمل.
