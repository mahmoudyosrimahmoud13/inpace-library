# المتغيرات

**المتغير** اسم يحمل قيمة، مثل صندوق عليه ملصق.

```python
name = "Sara"
age = 27
print(name)
print(age + 1)
```

علامة `=` تعني "ضع هذه القيمة في الصندوق"، وليس "يساوي".

## تغيير المتغير

يمكنك وضع قيمة جديدة في نفس الصندوق في أي وقت:

```python
score = 10
score = score + 5
print(score)   # 15
```

## أسماء جيدة

- استخدم أسماء واضحة: `price` و`total_hours` و`city`.
- بدون مسافات: استخدم `_` بدلًا منها (`first_name`).
- لا يمكن أن يبدأ الاسم برقم.
