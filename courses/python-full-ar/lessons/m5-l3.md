# وحداتك الخاصة

أي ملف `.py` هو وحدة. ضع دوالًا في `money.py` واستوردها من ملف آخر في المجلد نفسه:

```python
# money.py
def egp(amount):
    return f"{amount:,.2f} EGP"


def main():
    print(egp(1500))


if __name__ == "__main__":     # only when you run money.py itself
    main()
```

```python
# receipt.py
from money import egp
print("Total:", egp(249.5))
```

دون سطر `if __name__ == "__main__":` سيؤدي استيراد `money` إلى تشغيل `main()` أيضًا وطباعة `1,500.00 EGP`. ومعه يعمل الملف برنامجًا ووحدةً معًا. وستستخدم هذا في كل مشروع فيه اختبارات.
