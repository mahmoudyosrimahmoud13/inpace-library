# الأنماط مع re.search

**التعبير النمطي** (regex) نمط يمكن أن يطابقه النص. ويجيب عن أسئلة مثل «هل هذا بريد صالح؟» أو «ابحث عن كل تاريخ في هذا النص».

> **فيديو اختياري في الأعلى.** محاضرة هارفارد الكاملة لهذا الأسبوع (ساعتان و5 دقيقة)، يقدّمها ديفيد مالان، وتغطي هذه الوحدة. وملاحظات هارفارد المكتوبة (بالإنجليزية): [ملاحظات CS50P، الأسبوع 7](https://cs50.harvard.edu/python/notes/7/). كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```python
import re

code = input("Student code: ").strip()     # like CS-2026-0042
if re.fullmatch(r"[A-Z]{2}-\d{4}-\d{4}", code, re.IGNORECASE):
    print("Valid")
else:
    print("Invalid")
```

## القطع

| النمط | يطابق |
|---|---|
| `.` | أي حرف عدا السطر الجديد |
| `*` | صفر أو أكثر مما قبله |
| `+` | واحد أو أكثر |
| `?` | صفر أو واحد (اختياري) |
| `{3}` و`{2,4}` | 3 بالضبط، ومن 2 إلى 4 |
| `\d` و`\w` و`\s` | رقم، وحرف من كلمة، ومسافة |
| `[abc]` و`[^abc]` | واحد من هذه، ولا شيء من هذه |
| `^` و`$` | البداية والنهاية |
| `(a\|b)` | a أو b |
| `\.` | نقطة حقيقية |

تبحث `re.search` عن النمط في أي مكان من النص، أما `re.fullmatch` (أو `^...$`) فتشترط أن يطابق النص كله. واكتب الأنماط دائمًا نصوصًا خامًا: `r"..."`.
