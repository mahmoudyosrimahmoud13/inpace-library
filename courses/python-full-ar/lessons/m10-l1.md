# المجموعات وتلميحات الأنواع والتوثيق

**المجموعة** (set) تحفظ كل قيمة مرة واحدة، بلا ترتيب. وهي أسرع طريقة لحذف التكرار أو فحص وجود شيء في مجموعة كبيرة:

> **فيديو اختياري في الأعلى.** محاضرة هارفارد الكاملة لهذا الأسبوع (ساعتان و29 دقيقة)، يقدّمها ديفيد مالان، وتغطي هذه الوحدة. وملاحظات هارفارد المكتوبة (بالإنجليزية): [ملاحظات CS50P، الأسبوع 9](https://cs50.harvard.edu/python/notes/9/). كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```python
cities = set()
for f in [{"city": "Cairo"}, {"city": "Aswan"}, {"city": "Cairo"}]:
    cities.add(f["city"])
print(sorted(cities))          # ['Aswan', 'Cairo']
```

## تلميحات الأنواع

تقول التلميحات ما النوع الذي يتوقعه المتغير أو الدالة. لا تفرضها بايثون، لكن أدوات مثل `mypy` وVS Code تستعملها لكشف الأخطاء قبل تشغيل الكود:

```python
def repeat(word: str, n: int) -> str:
    """
    Repeat a word n times, one per line.

    :param word: the word to repeat
    :param n: how many times
    :return: the word n times, one per line
    """
    return (word + "\n") * n
```

## الثوابت وglobal

الأسماء بالحروف الكبيرة (`MAX_TRIES = 3`) ثوابت بالاصطلاح: قيم لا تغيّرها. وتجنّب `global`: فالدالة التي تغيّر متغيرات خارجها صعبة التتبع. مرّر القيم وأرجعها بدلًا من ذلك، أو استخدم صنفًا.
