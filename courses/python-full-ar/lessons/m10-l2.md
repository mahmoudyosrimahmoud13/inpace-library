# التعابير المختصرة وlambda والمولّدات

يبني **التعبير المختصر** (comprehension) قائمة (أو قاموسًا) من حلقة، في سطر واحد:

```python
words = ["learn", "at", "your", "pace"]
upper = [w.upper() for w in words]                 # ['LEARN', 'AT', 'YOUR', 'PACE']
long = [w for w in words if len(w) > 2]            # with a condition
lengths = {w: len(w) for w in words}               # a dict comprehension

friends = [{"name": "Mona", "city": "Cairo"}, {"name": "Omar", "city": "Alexandria"}]
in_cairo = sorted(f["name"] for f in friends if f["city"] == "Cairo")
```

## lambda وmap وfilter

`lambda` دالة صغيرة بلا اسم، وأكثر ما تُستعمل في `key=` للترتيب. وتؤدي `map` و`filter` ما تؤديه التعابير المختصرة، ففضّل التعبير المختصر حين يكون أوضح:

```python
by_city = sorted(friends, key=lambda f: f["city"])
numbers = list(map(int, "1 2 3".split()))         # [1, 2, 3]
```

## المولّدات

الدالة التي فيها `yield` تعطي القيم واحدة بعد واحدة بدل بناء قائمة ضخمة في الذاكرة. وهذا مهم حين تكون العناصر بالملايين:

![الذاكرة القصوى المقيسة: القائمة تكبر مع n والمولّد يبقى ثابتًا](list_vs_generator-ar.png)

قيست بـ `tracemalloc` أثناء كتابة هذا الدرس: جمع مليون مربع عبر قائمة بلغ ذروة نحو 40 ميجابايت، وعبر مولّد أقل من 1 كيلوبايت.

```python
def squares(n):
    for i in range(n):
        yield i * i


for s in squares(1_000_000):
    print(s)          # starts printing at once, uses almost no memory
```
