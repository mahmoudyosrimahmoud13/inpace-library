# الحلقات المتداخلة والدوال الصغيرة

الحلقة داخل الحلقة تمر على الصفوف والأعمدة. وتقسيم العمل إلى دوال صغيرة يجعل كل جزء سهل القراءة:

```python
def main():
    print_table(3)


def print_table(n):
    for row in range(1, n + 1):          # each row
        print_row(row, n)


def print_row(row, n):
    for col in range(1, n + 1):          # each column
        print(row * col, end="\t")
    print()


main()        # a small times table
```

كل دالة تؤدي شيئًا واحدًا، واسمها يقول ما هو. وحين يتعطل شيء تعرف أين تبحث. وهذه العادة أهم من أي حيلة منفردة في هذه الدورة.
