# الأرقام: int وfloat والتقريب

في بايثون أعداد صحيحة (`int`) وأعداد عشرية (`float`). ولأن `input()` تُرجع نصًا دائمًا، حوّله أولًا:

```python
x = int(input("x: "))
y = int(input("y: "))
print(x + y)        # without int(), "1" + "2" would be "12"
```

## العمليات

| العملية | معناها | مثال |
|---|---|---|
| `+ - *` | جمع وطرح وضرب | `7 * 6` تساوي `42` |
| `/` | قسمة (والناتج عشري دائمًا) | `7 / 2` تساوي `3.5` |
| `//` | قسمة مع حذف الكسر | `7 // 2` تساوي `3` |
| `%` | باقي القسمة | `7 % 2` تساوي `1` (إذن 7 فردي) |
| `**` | الأس | `2 ** 10` تساوي `1024` |

## التقريب والتنسيق

تقرّب `round(x, 2)` إلى منزلتين. وداخل f-string يتحكم التنسيق بعد النقطتين في شكل الرقم دون أن يغيّره:

```python
z = 1000 / 3
print(round(z, 2))      # 333.33
print(f"{z:.2f}")       # 333.33
print(f"{1234567:,}")   # 1,234,567
```

## الأعداد العشرية ليست دقيقة تمامًا

ناتج `0.1 + 0.2` هو `0.30000000000000004`، لأن الحاسوب يخزّن الكسور بالنظام الثنائي. هذا طبيعي. قرّب عند عرض النتيجة، وفي الأموال استخدم وحدات صحيحة (القروش أو السنتات) أو وحدة `decimal`.
