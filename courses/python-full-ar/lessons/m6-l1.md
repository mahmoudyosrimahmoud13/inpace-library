# assert وpytest

**الاختبار** كود يفحص كودك. تتوقف `assert` بخطأ إذا كان شرطها خاطئًا. ويشغّل [pytest](https://docs.pytest.org/) كل دالة يبدأ اسمها بـ `test_` ويخبرك أيها فشل:

> **فيديو اختياري في الأعلى.** محاضرة هارفارد الكاملة لهذا الأسبوع (51 دقيقة)، يقدّمها ديفيد مالان، وتغطي هذه الوحدة. وملاحظات هارفارد المكتوبة (بالإنجليزية): [ملاحظات CS50P، الأسبوع 5](https://cs50.harvard.edu/python/notes/5/). كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```python
# shop.py
def discount(price, percent):
    return round(price * (1 - percent / 100), 2)
```

```python
# test_shop.py
from shop import discount


def test_normal():
    assert discount(200, 10) == 180
    assert discount(80, 25) == 60


def test_no_discount():
    assert discount(200, 0) == 200


def test_free():
    assert discount(200, 100) == 0
```
