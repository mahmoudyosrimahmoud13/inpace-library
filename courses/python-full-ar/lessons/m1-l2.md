تسأل `input()` المستخدم سؤالًا وتُرجع ما كتبه، وهو دائمًا **نص** (من النوع `str`). وتعرض `print()` القيم على الشاشة.

> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```python
name = input("What's your name? ")
print("hello,", name)        # print puts a space between arguments
print("hello, " + name)       # + joins two strings
print(f"hello, {name}")       # an f-string: the cleanest way
```

## تنظيف ما يكتبه الناس

يكتب الناس مسافات زائدة وحروفًا كبيرة في غير موضعها. و**توابع** النصوص (methods) تصلح ذلك. والتابع دالة تخص قيمة ما، وتُستدعى بنقطة:

```python
name = input("Name: ").strip().title()   # "  mona ali " -> "Mona Ali"
first, last = name.split(" ")            # split at the space into two variables
print(f"Hi {first}! Your name has {len(name)} characters.")
```

## توابع نصية مفيدة

| التابع | ماذا يفعل |
|---|---|
| `.strip()` | يحذف المسافات من الطرفين |
| `.lower()` و`.upper()` | كل الحروف صغيرة أو كبيرة |
| `.title()` | يجعل أول حرف من كل كلمة كبيرًا |
| `.replace(a, b)` | يستبدل كل `a` بـ `b` |
| `.split(sep)` | يقطع النص إلى قائمة |
| `.startswith(x)` | يُرجع `True` إذا بدأ النص بـ `x` |

## خيارات print نفسها

تضيف `print` سطرًا جديدًا في النهاية ومسافة بين المُدخلات. ويمكنك تغييرهما بـ `end` و`sep`:

```python
print("a", "b", "c", sep="-")    # a-b-c
print("no new line", end="")
print(" ...same line")
```

## التعليقات
