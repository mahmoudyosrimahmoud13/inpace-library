# ماذا تختبر

الاختبارات الجيدة تجرّب الحالات **العادية**، و**الأطراف** (الصفر، والنص الفارغ، وأكبر قيمة مسموحة)، والمدخلات **الخاطئة**. وتأكد أن المدخلات الخاطئة تطلق الخطأ الصحيح:

```python
import pytest
from grade import grade


def test_edges():
    assert grade(90) == "A"
    assert grade(89) == "B"
    assert grade(0) == "F"


def test_invalid():
    with pytest.raises(ValueError):
        grade(101)
```

## اجعل كودك قابلًا للاختبار

لا تفحص الاختبارات إلا ما **تُرجعه** الدالة. لذلك أبقِ `input()` و`print()` في `main()`، وضع المنطق في دوال صغيرة تأخذ قيمًا وتُرجع قيمًا. ولهذا يطلب كل تمرين عملي في هذه الدورة دالة.

## الاختبارات في مجلد

يمكن أن تجمع ملفات اختبار كثيرة في مجلد `tests/`، ويجدها `pytest` كلها إن شغّلته دون اسم ملف.
