# كتابة الشروط بإتقان

الشرط مجرد قيمة `True` أو `False` (من النوع `bool`). لذلك يمكن للدالة أن تُرجع الجواب مباشرة:

```python
def is_even(n):
    return n % 2 == 0      # instead of: if ...: return True / else: return False

if is_even(10):
    print("even")
```

## match: قيمة واحدة وحالات كثيرة

إذا قارنت متغيرًا واحدًا بقيم ثابتة كثيرة، فإن `match` (في بايثون 3.10 وما بعدها) أوضح من سلسلة `elif` طويلة. وتلتقط `_` كل ما عدا ذلك، وتعني `|` «أو»:

```python
match command:
    case "start" | "go":
        print("Starting")
    case "stop":
        print("Stopping")
    case _:
        print("Unknown command")
```

## القيم التي تُعدّ صحيحة أو خاطئة

الأشياء الفارغة تُحسب `False`: `""` و`0` و`[]` و`{}` و`None`. لذلك تعني `if name:` «إذا كتب المستخدم شيئًا». وهي مختصرة، لكن استخدمها فقط إن كان هذا ما تقصده فعلًا.
