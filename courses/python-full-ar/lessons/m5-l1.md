# الوحدات والمكتبة القياسية

**الوحدة** (module) ملف كود بايثون تعيد استعماله. وتأتي بايثون بمئات منها، وهي **المكتبة القياسية**، فنادرًا ما تبدأ من الصفر.

> **فيديو اختياري في الأعلى.** محاضرة هارفارد الكاملة لهذا الأسبوع (ساعة و18 دقيقة)، يقدّمها ديفيد مالان، وتغطي هذه الوحدة. وملاحظات هارفارد المكتوبة (بالإنجليزية): [ملاحظات CS50P، الأسبوع 4](https://cs50.harvard.edu/python/notes/4/). كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```python
import random
import statistics
from datetime import date

color = random.choice(["red", "green", "blue"])
roll = random.randint(1, 6)          # 1 to 6, both included
queue = ["Mona", "Omar", "Laila"]
random.shuffle(queue)
print(statistics.median([30, 45, 60]))  # 45
print(date.today().year)
```

## مُدخلات من الطرفية

`sys.argv` قائمة بما كُتب في الطرفية: اسم البرنامج ثم كل كلمة بعده. افحص طولها قبل استعمالها، واخرج بـ `sys.exit()` إن نقص شيء:

```python
import sys

if len(sys.argv) < 2:
    sys.exit("Usage: python greet.py NAME ...")
for arg in sys.argv[1:]:          # [1:] skips the program's own name
    print("Welcome,", arg)
```

جرّبه: `python greet.py Mona Ali` يطبع سطرين. والتقطيع بـ `[1:]` يعني «من الموضع 1 إلى النهاية».
