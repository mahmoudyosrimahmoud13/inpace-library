# الأصناف والكائنات

**الصنف** (class) نوع تصنعه بنفسك: مخطط. و**الكائن** (object) شيء واحد صُنع منه. ويجمع الصنف البيانات (الخصائص) مع الدوال التي تعمل عليها (التوابع):

> **فيديو اختياري في الأعلى.** محاضرة هارفارد الكاملة لهذا الأسبوع (ساعتان و51 دقيقة)، يقدّمها ديفيد مالان، وتغطي هذه الوحدة. وملاحظات هارفارد المكتوبة (بالإنجليزية): [ملاحظات CS50P، الأسبوع 8](https://cs50.harvard.edu/python/notes/8/). كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```python
class Course:
    def __init__(self, title, hours):
        if not title:
            raise ValueError("Missing title")
        self.title = title
        self.hours = hours

    def __str__(self):
        return f"{self.title} ({self.hours} h)"


python = Course("Python", 40)
print(python)            # Python (40 h)
print(python.hours)
```

## ما كل جزء

- تُنفَّذ `__init__` حين تنشئ كائنًا، وتجهّز الخصائص.
- `self` هو الكائن نفسه، ويأتي أولًا في كل تابع.
- تحدد `__str__` شكل الكائن عند طباعته.
- إطلاق خطأ في `__init__` يعني أن الكائن غير الصالح لا يمكن أن يوجد أبدًا.

لقد استخدمت الكائنات طوال الوقت: `"hi".upper()` تستدعي تابعًا لكائن من نوع `str`، و`[].append()` تابعًا لكائن من نوع `list`.
