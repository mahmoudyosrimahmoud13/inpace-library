# دوالك الخاصة

**الدالة** قطعة كود لها اسم، تشغّلها مرة بعد مرة. وقد تأخذ **معاملات** (مُدخلاتها) وتُرجع قيمة بـ `return` (مُخرجها).

```python
def main():
    x = int(input("What's x? "))
    print("x squared is", square(x))


def square(n):
    return n * n


main()
```

## لماذا `main()` في الأسفل؟

تقرأ بايثون الملف من أعلى إلى أسفل. فإذا وضعت البرنامج في `main()` واستدعيتها في آخر سطر، تكون كل الدوال معرّفة عند بدء البرنامج، فلا يهم ترتيبها.

## print أم return؟

`print` تعرض شيئًا لإنسان. أما `return` فتسلّم قيمة للكود الذي استدعى الدالة ليستعملها: يخزّنها أو يقارنها أو يطبعها لاحقًا. والدالة التي تطبع فقط لا يمكن استعمالها داخل حساب أكبر، ويصعب اختبارها.

## القيم الافتراضية والنطاق

يمكن أن يكون للمعامل قيمة افتراضية. والمتغيرات التي تُنشأ داخل دالة لا توجد إلا داخلها (وهذا **نطاقها**):

```python
def hello(to="world"):
    message = f"hello, {to}"
    return message

print(hello())        # hello, world
print(hello("Mona"))  # hello, Mona
# print(message)      # NameError: message only lives inside hello()
```
