# *args و**kwargs وargparse

تفكّ `*` قائمةً إلى مُدخلات منفصلة، وتفكّ `**` قاموسًا إلى مُدخلات مسماة. وفي تعريف الدالة تجمعان أي عدد من المُدخلات:

```python
def total(price, delivery, tip):
    return price + delivery + tip


order = [120, 25, 10]
print(total(*order))
print(total(**{"price": 120, "delivery": 25, "tip": 10}))


def f(*args, **kwargs):
    print("Positional:", args)      # a tuple
    print("Named:", kwargs)         # a dict
```

## argparse

للبرامج التي لها خيارات (`python hello.py -n 3`)، تقرأ `argparse` القائمة `sys.argv` نيابة عنك، وتفحص الأنواع، وتكتب نص المساعدة `--help`:

```python
import argparse

parser = argparse.ArgumentParser(description="Say hello")
parser.add_argument("-n", default=1, type=int, help="number of times to say hello")
args = parser.parse_args()
for _ in range(args.n):
    print("hello")
```
