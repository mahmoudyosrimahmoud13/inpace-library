# JSON والمسارات

CSV للجداول. أما البيانات المتداخلة (قوائم داخل قواميس) فاحفظها بصيغة **JSON** عبر وحدة `json`، وهي الصيغة التي تستخدمها واجهات الويب أيضًا:

```python
import json
from pathlib import Path

settings = {"name": "Mona", "goals": ["python", "sql"], "minutes": 60}
path = Path("settings.json")
path.write_text(json.dumps(settings, indent=2, ensure_ascii=False), encoding="utf-8")

loaded = json.loads(path.read_text(encoding="utf-8"))
print(loaded["goals"][0])     # python
print(path.exists(), path.suffix, Path.home())
```

`pathlib.Path` هي الطريقة الحديثة للتعامل مع مسارات الملفات: تربط المجلدات بـ `/`، وتعمل على ويندوز وماك ولينكس، وتقرأ ملفًا صغيرًا كاملًا أو تكتبه في سطر واحد.
