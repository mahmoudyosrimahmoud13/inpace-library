# الخصائص المحمية وتوابع الصنف

يستطيع أي أحد تغيير الخاصية: `course.level = "expert"`. أما **property** فتشغّل كودك كلما قُرئت الخاصية أو تغيّرت، فتتحقق من القيمة:

```python
class Course:
    LEVELS = ["beginner", "intermediate", "advanced"]

    def __init__(self, title, level):
        self.title = title
        self.level = level          # goes through the setter below

    @property
    def level(self):
        return self._level

    @level.setter
    def level(self, level):
        if level not in self.LEVELS:
            raise ValueError("Invalid level")
        self._level = level

    @classmethod
    def ask(cls):
        return cls(input("Title: "), input("Level: "))


course = Course.ask()
```

- `self._level` مع الشرطة السفلية هو المخزن الحقيقي، والشرطة تقول «لا تلمس هذا مباشرة».
- `@classmethod` تخص الصنف لا كائنًا واحدًا: `Course.ask()`. وهي مفيدة لطرق أخرى في إنشاء الكائنات.
- `LEVELS` **متغير صنف** تشترك فيه كل الدورات.
