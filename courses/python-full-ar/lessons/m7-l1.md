# قراءة الملفات وكتابتها

تختفي المتغيرات حين ينتهي البرنامج، أما الملفات فتبقى. تعطيك `open()` ملفًا، وتغلقه `with` نيابة عنك، حتى لو وقع خطأ:

> **فيديو اختياري في الأعلى.** محاضرة هارفارد الكاملة لهذا الأسبوع (ساعة و32 دقيقة)، يقدّمها ديفيد مالان، وتغطي هذه الوحدة. وملاحظات هارفارد المكتوبة (بالإنجليزية): [ملاحظات CS50P، الأسبوع 6](https://cs50.harvard.edu/python/notes/6/). كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```python
guest = input("Guest: ")
with open("guests.txt", "a", encoding="utf-8") as file:   # "a" adds to the end
    file.write(f"{guest}\n")

with open("guests.txt", encoding="utf-8") as file:
    for line in sorted(file):
        print("Invited:", line.rstrip())  # rstrip removes the \n at the end
```

## أوضاع الفتح

| الوضع | معناه |
|---|---|
| `"r"` | قراءة (الافتراضي) |
| `"w"` | كتابة: **يفرغ الملف أولًا** |
| `"a"` | إضافة في النهاية |

مرّر دائمًا `encoding="utf-8"` لتعمل العربية وغيرها من اللغات بالطريقة نفسها على كل جهاز.
