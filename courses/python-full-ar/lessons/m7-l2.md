# ملفات CSV

CSV (قيم مفصولة بفواصل) أبسط صيغة للجداول: صف في كل سطر، والأعمدة تفصلها فواصل. ويفتحها Excel وجداول Google. استخدم وحدة `csv` لا `split(",")`، لأن القيمة قد تحتوي فاصلة داخل علامتي اقتباس:

```python
import csv

# shops.csv:
# name,address
# Nile Books,"12 Tahrir St, Cairo"
# Sea Cafe,Corniche

shops = []
with open("shops.csv", encoding="utf-8") as file:
    for row in csv.DictReader(file):        # each row is a dict, keyed by the header
        shops.append(row)

for shop in sorted(shops, key=lambda s: s["name"]):
    print(f"{shop['name']}: {shop['address']}")
```

```python
with open("shops.csv", "a", encoding="utf-8", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "address"])
    writer.writerow({"name": "Green Grocer", "address": "5 Nasr Rd, Giza"})
```

يخبر `key=` الدالة `sorted` بما ترتّب عليه. و`lambda s: s["name"]` دالة صغيرة تُكتب في سطر واحد، وستلتقي بـ `lambda` مرة أخرى في الوحدة 10.
