# Classes, sub-dependencies and where to attach them

## Dependencies can depend on dependencies

```python
def get_token(authorization: Annotated[str | None, Header()] = None) -> str:
    if not authorization or not authorization.startswith("Bearer "):
        raise HTTPException(401, "Missing token")
    return authorization.removeprefix("Bearer ")


def get_current_user(token: Annotated[str, Depends(get_token)]) -> User:
    user = users_by_token.get(token)
    if not user:
        raise HTTPException(401, "Bad token")
    return user


def require_admin(user: Annotated[User, Depends(get_current_user)]) -> User:
    if not user.is_admin:
        raise HTTPException(403, "Admins only")
    return user
```

FastAPI builds the whole tree for you. If several dependencies need `get_current_user` in one request, it's called
**once** and the result is reused (you can turn this off with `Depends(fn, use_cache=False)`).

## Classes as dependencies

Any callable works, including a class. Its `__init__` parameters become request parameters:

```python
class BookFilter:
    def __init__(self, author: str | None = None, year: int | None = None):
        self.author = author
        self.year = year

@app.get("/books")
def books(f: Annotated[BookFilter, Depends()]):    # Depends() with no argument uses the type
    ...
```

## Dependencies that return nothing useful

Sometimes you only want the check, not the value. Attach it to the decorator, a router, or the whole app:

```python
@app.delete("/books/{id}", dependencies=[Depends(require_admin)])
def delete_book(id: int): ...

admin = APIRouter(prefix="/admin", dependencies=[Depends(require_admin)])

app = FastAPI(dependencies=[Depends(check_api_key)])      # every endpoint
