# Request bodies with Pydantic models

When a client sends JSON in the body (usually with POST, PUT or PATCH), describe its shape with a **Pydantic model**:

```python
from datetime import date
from pydantic import BaseModel, Field, EmailStr

class Address(BaseModel):
    city: str
    country: str = "EG"

class UserCreate(BaseModel):
    name: str = Field(min_length=2, max_length=60)
    email: EmailStr                      # needs: pip install "pydantic[email]"
    birthday: date | None = None
    tags: list[str] = []
    address: Address | None = None       # models can nest


@app.post("/users", status_code=201)
def create_user(user: UserCreate):
    data = user.model_dump()             # a plain dict
    return {"saved": data}
```

FastAPI sees that `user` is a Pydantic model, so it reads it from the **body**. It:

1. Parses the JSON.
2. Converts types (`"2001-05-03"` becomes a `date`).
3. Checks every rule and returns `422` with all problems at once if anything is wrong.
4. Gives your function a real `UserCreate` object with editor autocomplete.

## Body, path and query together

```python
@app.put("/users/{user_id}")
def update(user_id: int, user: UserCreate, notify: bool = False): ...
```

- In the path → path parameter.
- A Pydantic model → body.
- A simple type not in the path → query parameter.

## Partial updates with PATCH

Make a model where every field is optional, then only apply what was sent:

```python
class UserUpdate(BaseModel):
    name: str | None = None
    email: EmailStr | None = None

@app.patch("/users/{user_id}")
def patch_user(user_id: int, changes: UserUpdate):
    stored = db[user_id]
    updated = stored.model_copy(update=changes.model_dump(exclude_unset=True))
    db[user_id] = updated
    return updated
```

`exclude_unset=True` leaves out fields the client didn't send, so they don't get overwritten with `None`.

## Custom checks

```python
from pydantic import field_validator

class Signup(BaseModel):
    username: str

    @field_validator("username")
    @classmethod
    def no_spaces(cls, v: str) -> str:
        if " " in v:
            raise ValueError("must not contain spaces")
        return v.lower()
```
