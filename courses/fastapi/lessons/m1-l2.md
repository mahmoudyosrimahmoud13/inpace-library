# Install and run your first app

## 1. Make a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install "fastapi[standard]"
```

`fastapi[standard]` installs FastAPI plus Uvicorn, the `fastapi` command, and a few useful extras.

## 2. Write `main.py`

```python
from fastapi import FastAPI

app = FastAPI(title="My first API")


@app.get("/")
def home():
    return {"message": "Hello, FastAPI"}
```

## 3. Run it

```bash
fastapi dev main.py
```

`fastapi dev` restarts the server every time you save a file. Open:

- `http://127.0.0.1:8000/` to see the JSON
- `http://127.0.0.1:8000/docs` to see the interactive docs

You can also run Uvicorn yourself: `uvicorn main:app --reload`. `main` is the file, `app` is the variable.

## What just happened

- `FastAPI()` makes the application object.
- `@app.get("/")` says: when a **GET** request comes to `/`, call this function.
- The function returns a `dict`. FastAPI turns it into JSON and sends it with status `200`.

> Use `fastapi dev` only while developing. In production you'll use `fastapi run` (module 11).
