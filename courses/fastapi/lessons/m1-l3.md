# Path operations and HTTP methods

In FastAPI, a **path operation** is a path (like `/items`) plus an HTTP method (like `GET`). Each one is a
decorated function.

| Method | Usual meaning | Decorator |
|---|---|---|
| GET | Read something | `@app.get` |
| POST | Create something | `@app.post` |
| PUT | Replace something | `@app.put` |
| PATCH | Change part of something | `@app.patch` |
| DELETE | Remove something | `@app.delete` |

```python
from fastapi import FastAPI

app = FastAPI()
books = {1: {"title": "Dune"}, 2: {"title": "Emma"}}


@app.get("/books")
def list_books():
    return books


@app.get("/books/{book_id}")
def get_book(book_id: int):
    return books[book_id]


@app.delete("/books/{book_id}", status_code=204)
def delete_book(book_id: int):
    books.pop(book_id, None)
```

## Order matters

FastAPI checks paths **in the order you wrote them**. Put fixed paths before paths with variables:

```python
@app.get("/books/latest")      # must come first
def latest(): ...

@app.get("/books/{book_id}")
def get_book(book_id: int): ...
```

If `/books/{book_id}` came first, a request to `/books/latest` would try to turn `"latest"` into an `int` and fail.

## `def` or `async def`?

Both work. Use `async def` when the function `await`s something (an async database driver, `httpx`). Use plain
`def` when it calls normal blocking code. Module 7 explains exactly why.
