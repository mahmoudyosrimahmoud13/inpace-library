# Pagination, caching and idempotency

## Pagination

**Offset** pagination is simple: `?offset=40&limit=20`. But on big tables `OFFSET 100000` is slow, and rows can be
skipped or repeated if data changes between pages.

**Cursor** (keyset) pagination fixes both. Return the last id you sent, and continue after it:

```python
@app.get("/books")
def books(db: DB, after: int | None = None, limit: Annotated[int, Query(le=100)] = 20):
    stmt = select(Book).order_by(Book.id).limit(limit + 1)
    if after is not None:
        stmt = stmt.where(Book.id > after)
    rows = db.scalars(stmt).all()
    has_more = len(rows) > limit
    items = rows[:limit]
    return {"items": items, "next": items[-1].id if has_more else None}
```

## Caching

Tell clients and proxies what they may cache:

```python
@app.get("/countries")
def countries(response: Response):
    response.headers["Cache-Control"] = "public, max-age=3600"
    return COUNTRIES
```

**ETags** let clients ask "has it changed?" and get a tiny `304 Not Modified` if not:

```python
import hashlib, json

@app.get("/books/{book_id}")
def book(book_id: int, request: Request, db: DB):
    data = BookOut.model_validate(get_book(db, book_id)).model_dump(mode="json")
    etag = '"' + hashlib.sha256(json.dumps(data, sort_keys=True).encode()).hexdigest()[:16] + '"'
    if request.headers.get("if-none-match") == etag:
        return Response(status_code=304)
    return JSONResponse(data, headers={"ETag": etag})
```

For expensive computed data, cache it on the server too (Redis, with a short expiry).

## Idempotency keys

Networks fail. If a client retries `POST /payments`, you must not charge twice. Let clients send an
`Idempotency-Key` header, store the first result under that key, and return the same result on retries:

```python
@app.post("/payments", status_code=201)
def pay(data: PaymentIn, db: DB, idempotency_key: Annotated[str, Header()]):
    saved = db.scalar(select(Idem).where(Idem.key == idempotency_key))
    if saved:
        return saved.response
    result = charge(data)
    db.add(Idem(key=idempotency_key, response=result)); db.commit()
    return result
```

(Make `key` unique in the database so two parallel retries can't both succeed.)
