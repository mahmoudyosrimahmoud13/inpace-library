# Async tests

When your test itself needs `await` (for example to call an async database or another async helper), use an async
client:

```bash
pip install pytest-asyncio
```

```python
import pytest
from httpx import ASGITransport, AsyncClient
from app.main import app


@pytest.mark.asyncio
async def test_root():
    transport = ASGITransport(app=app)
    async with AsyncClient(transport=transport, base_url="http://test") as ac:
        r = await ac.get("/")
    assert r.status_code == 200
```

(`anyio`'s pytest plugin works too, with `@pytest.mark.anyio`.)

Note: `ASGITransport` doesn't run your **lifespan**. If your app needs startup code in tests, run it yourself, for
example with the `asgi-lifespan` package's `LifespanManager`, or use the sync `TestClient` as a context manager.

## Testing WebSockets

```python
def test_echo():
    with TestClient(app) as client:
        with client.websocket_connect("/ws") as ws:
            ws.send_text("hi")
            assert ws.receive_text() == "echo: hi"
```

## Make tests part of your routine

- Run them on every push with GitHub Actions.
- Measure coverage with `pytest --cov=app` (package `pytest-cov`).
- When you fix a bug, first write a test that fails because of it.
