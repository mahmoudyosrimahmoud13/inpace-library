# Status codes and HTTPException

## Pick the right status code

```python
from fastapi import status

@app.post("/items", status_code=status.HTTP_201_CREATED)
def create(): ...

@app.delete("/items/{id}", status_code=status.HTTP_204_NO_CONTENT)
def delete(id: int): ...
```

| Code | Meaning |
|---|---|
| 200 | OK |
| 201 | Created |
| 204 | Done, nothing to return |
| 400 | The request makes no sense |
| 401 | Not logged in |
| 403 | Logged in, but not allowed |
| 404 | Not found |
| 409 | Conflict (for example, email already used) |
| 422 | Validation failed (FastAPI sends this for you) |
| 429 | Too many requests |
| 500 | A bug on the server |

## Stop with an error

`raise` an `HTTPException` anywhere, even deep inside a helper or a dependency:

```python
from fastapi import HTTPException

def get_book_or_404(book_id: int):
    book = db.get(book_id)
    if book is None:
        raise HTTPException(status_code=404, detail="Book not found")
    return book
```

The client gets `{"detail": "Book not found"}` with status 404. `detail` can also be a dict or a list.

## Extra headers

```python
raise HTTPException(
    status_code=401,
    detail="Not logged in",
    headers={"WWW-Authenticate": "Bearer"},
)
```

> Use `raise`, not `return`. Returning an `HTTPException` object would send it as a normal 200 response.
