# Logging, metrics and tracing

When something breaks at night, these are your eyes.

## Logs

Log in **structured** form (JSON), with a request id on every line, so you can search and follow one request:

```python
import logging, json, sys

class JsonFormatter(logging.Formatter):
    def format(self, record):
        data = {"level": record.levelname, "msg": record.getMessage(), "logger": record.name}
        data.update(getattr(record, "extra_fields", {}))
        return json.dumps(data)

handler = logging.StreamHandler(sys.stdout)
handler.setFormatter(JsonFormatter())
logging.basicConfig(level=logging.INFO, handlers=[handler])
log = logging.getLogger("api")
```

Libraries like **structlog** or **loguru** make this nicer. Log to stdout; your platform collects it.

Never log passwords, tokens or full card numbers.

## Errors

Send exceptions to an error tracker (for example **Sentry**, which has a FastAPI integration). You get the stack
trace, the request, and how many users were hit.

## Metrics

Count requests, errors and latency per endpoint. With Prometheus:

```bash
pip install prometheus-fastapi-instrumentator
```

```python
from prometheus_fastapi_instrumentator import Instrumentator
Instrumentator().instrument(app).expose(app)      # adds /metrics
```

Watch the **four golden signals**: traffic, errors, latency (look at p95/p99, not only the average), saturation
(CPU, memory, DB pool).

## Tracing

**OpenTelemetry** follows one request through your API, the database and other services, and shows where the time
went:

```python
from opentelemetry.instrumentation.fastapi import FastAPIInstrumentor
FastAPIInstrumentor.instrument_app(app)
```

## Your launch checklist

- [ ] Secrets from the environment, `.env` not in git or the image
- [ ] Migrations run on deploy
- [ ] `/health` and `/ready`
- [ ] Logs with request ids, errors tracked, basic metrics
- [ ] Rate limits on login and expensive endpoints
- [ ] CORS set to your real front-end origins
- [ ] Tests run in CI on every push
- [ ] A way to roll back (keep the previous image)
