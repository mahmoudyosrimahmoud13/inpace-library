# Depends: share logic between endpoints

A **dependency** is a function FastAPI calls *before* your endpoint. Its return value is passed in as a parameter.

```python
from typing import Annotated
from fastapi import Depends, FastAPI

app = FastAPI()


def pagination(skip: int = 0, limit: int = 20) -> dict:
    return {"skip": skip, "limit": min(limit, 100)}


@app.get("/books")
def books(page: Annotated[dict, Depends(pagination)]):
    return {"page": page}


@app.get("/authors")
def authors(page: Annotated[dict, Depends(pagination)]):
    return {"page": page}
```

Notice:

- `pagination` has its own parameters (`skip`, `limit`). FastAPI reads them from the request **exactly like an
  endpoint's parameters**, validates them, and shows them in the docs of both endpoints.
- You don't call `pagination()` yourself. You declare that you need it.

## Make it shorter with a type alias

```python
Page = Annotated[dict, Depends(pagination)]

@app.get("/books")
def books(page: Page): ...
```

## What dependencies are good for

- Reading and checking common parameters (pagination, filters)
- Getting the current user from a token (module 6)
- Opening a database session (module 5)
- Checking permissions, feature flags, API keys
- Loading settings (module 9)

Each piece of logic lives in one place, and every endpoint that needs it just asks for it.
