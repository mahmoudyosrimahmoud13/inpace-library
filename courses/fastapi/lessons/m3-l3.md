# Custom error handlers and other responses

## Your own exceptions

Raise errors that mean something in your app, and turn them into HTTP responses in one place:

```python
from fastapi import Request
from fastapi.responses import JSONResponse

class OutOfStock(Exception):
    def __init__(self, sku: str):
        self.sku = sku

@app.exception_handler(OutOfStock)
async def out_of_stock_handler(request: Request, exc: OutOfStock):
    return JSONResponse(status_code=409, content={"error": "out_of_stock", "sku": exc.sku})
```

Your business code now just does `raise OutOfStock("A-12")`.

## Change how validation errors look

```python
from fastapi.exceptions import RequestValidationError

@app.exception_handler(RequestValidationError)
async def validation_handler(request: Request, exc: RequestValidationError):
    return JSONResponse(status_code=422, content={"error": "invalid_input", "fields": exc.errors()})
```

Keep a **consistent error shape** across your whole API. Front-end developers will thank you.

## Other kinds of responses

```python
from fastapi.responses import FileResponse, RedirectResponse, StreamingResponse, HTMLResponse

@app.get("/report.pdf")
def report():
    return FileResponse("files/report.pdf", filename="report.pdf")

@app.get("/old-page")
def old():
    return RedirectResponse("/new-page", status_code=308)

@app.get("/numbers")
def numbers():
    def gen():
        for i in range(1000):
            yield f"{i}\n"
    return StreamingResponse(gen(), media_type="text/plain")
```

## Setting headers and cookies on a normal response

```python
from fastapi import Response

@app.get("/hello")
def hello(response: Response):
    response.headers["X-Hello"] = "world"
    response.set_cookie("seen", "yes", httponly=True, samesite="lax")
    return {"ok": True}
```
