# Settings and configuration

Never hard-code passwords, URLs or secrets. Read them from environment variables with **pydantic-settings**:

```bash
pip install pydantic-settings
```

```python
# app/config.py
from functools import lru_cache
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env")

    app_name: str = "Library API"
    database_url: str
    secret_key: str
    access_token_minutes: int = 30
    cors_origins: list[str] = []
    debug: bool = False


@lru_cache
def get_settings() -> Settings:
    return Settings()
```

```bash
# .env  (add to .gitignore!)
DATABASE_URL=postgresql+asyncpg://app:secret@localhost/library
SECRET_KEY=change-me
CORS_ORIGINS=["http://localhost:5173"]
```

- Names match case-insensitively: `DATABASE_URL` fills `database_url`.
- Types are validated: `ACCESS_TOKEN_MINUTES=abc` fails at startup, not at 3 a.m.
- Required fields without defaults (`database_url`, `secret_key`) make the app refuse to start if they're missing.

## Use it as a dependency

```python
from typing import Annotated
from fastapi import Depends

SettingsDep = Annotated[Settings, Depends(get_settings)]

@app.get("/info")
def info(settings: SettingsDep):
    return {"app": settings.app_name}
```

`@lru_cache` means the `.env` file is read once. And in tests you can override it:

```python
app.dependency_overrides[get_settings] = lambda: Settings(database_url="sqlite://", secret_key="test")
```

Commit a `.env.example` with fake values so others know what to set.
