# Headers, cookies, forms and files

## Headers and cookies

```python
from typing import Annotated
from fastapi import Header, Cookie

@app.get("/whoami")
def whoami(
    user_agent: Annotated[str | None, Header()] = None,     # reads the User-Agent header
    session_id: Annotated[str | None, Cookie()] = None,
):
    return {"agent": user_agent, "session": session_id}
```

Header names use `-` but Python names use `_`. FastAPI converts `user_agent` to `User-Agent` for you.

## Forms

HTML forms send `application/x-www-form-urlencoded`, not JSON. Install `python-multipart` (included in
`fastapi[standard]`) and use `Form`:

```python
from fastapi import Form

@app.post("/login")
def login(username: Annotated[str, Form()], password: Annotated[str, Form()]):
    ...
```

## File uploads

```python
from fastapi import File, UploadFile

@app.post("/avatar")
async def upload_avatar(file: UploadFile):
    if file.content_type not in ("image/png", "image/jpeg"):
        raise HTTPException(400, "Send a PNG or JPEG")
    data = await file.read()
    return {"name": file.filename, "size": len(data)}
```

`UploadFile` keeps big files on disk instead of in memory and gives you `filename`, `content_type`, and async
`read()`, `seek()` and `close()`.

> Never trust `file.filename` as a path on your server. Make your own safe name (for example a UUID) before saving.

## You can't mix JSON and form in one request

A request has one body. If you need a file **and** structured data, send the data as form fields (or a JSON string
in a form field) next to the file.
