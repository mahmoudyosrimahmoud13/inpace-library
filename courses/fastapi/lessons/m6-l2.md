# JWT tokens and the current user

A **JWT** (JSON Web Token) is a signed piece of JSON. The server can check the signature, so it trusts the content
without looking anything up.

```python
from datetime import datetime, timedelta, timezone
import jwt

SECRET_KEY = settings.secret_key        # a long random string, kept out of git
ALGORITHM = "HS256"


def create_access_token(user_id: int, minutes: int = 30) -> str:
    now = datetime.now(timezone.utc)
    payload = {"sub": str(user_id), "iat": now, "exp": now + timedelta(minutes=minutes)}
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)


def get_current_user(token: Annotated[str, Depends(oauth2_scheme)], db: DB) -> User:
    unauthorized = HTTPException(401, "Could not validate token", headers={"WWW-Authenticate": "Bearer"})
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
    except jwt.InvalidTokenError:          # bad signature, expired, malformed...
        raise unauthorized
    user = db.get(User, int(payload["sub"]))
    if user is None or not user.is_active:
        raise unauthorized
    return user


CurrentUser = Annotated[User, Depends(get_current_user)]


@app.get("/me", response_model=UserOut)
def me(user: CurrentUser):
    return user
```

## Things to get right

- **Always pass `algorithms=[...]` to `decode`.** Never let the token choose its own algorithm.
- **Keep access tokens short-lived** (minutes). For longer sessions, use a **refresh token** stored safely and
  checked against the database, so you can revoke it.
- A JWT is **signed, not encrypted**. Anyone can read its content. Don't put secrets in it.
- Logging out with plain JWTs means the client forgets the token. If you need instant revocation, keep a deny list
  or use short tokens plus refresh tokens.
- Generate the secret with `python -c "import secrets; print(secrets.token_urlsafe(64))"`.
