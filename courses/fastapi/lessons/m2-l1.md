# Path and query parameters

## Path parameters

Parts of the path in `{braces}` become function parameters:

```python
@app.get("/users/{user_id}/posts/{post_id}")
def get_post(user_id: int, post_id: int):
    return {"user": user_id, "post": post_id}
```

`/users/7/posts/3` works. `/users/seven/posts/3` gets a `422` error with a message saying `user_id` must be an integer.

## Query parameters

Any function parameter that **isn't** in the path is read from the query string (`?key=value`):

```python
@app.get("/books")
def search(q: str | None = None, skip: int = 0, limit: int = 10):
    return {"q": q, "skip": skip, "limit": limit}
```

- `/books?q=dune&limit=5` sets `q` and `limit`.
- A parameter with a default is optional. One without a default is required.
- `str | None = None` means "optional, may be missing".

## Fixed choices with Enum

```python
from enum import Enum

class Sort(str, Enum):
    newest = "newest"
    title = "title"

@app.get("/books")
def list_books(sort: Sort = Sort.newest):
    return {"sort": sort}
```

The docs now show a dropdown, and any other value is rejected.

## Lists in the query

```python
from typing import Annotated
from fastapi import Query

@app.get("/books")
def by_tags(tag: Annotated[list[str], Query()] = []):
    return tag            # /books?tag=sci-fi&tag=classic -> ["sci-fi", "classic"]
```
