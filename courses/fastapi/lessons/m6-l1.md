# Passwords and the OAuth2 password flow

## Never store passwords

Store a **hash** made with a slow, salted algorithm (Argon2 or bcrypt). Use a library, never write your own:

```bash
pip install "pwdlib[argon2]"
```

```python
from pwdlib import PasswordHash

hasher = PasswordHash.recommended()        # Argon2

hash_ = hasher.hash("correct horse")
hasher.verify("correct horse", hash_)      # True
```

(`passlib` with bcrypt is another common choice.)

## The login endpoint

FastAPI has helpers for the standard OAuth2 "password" flow: the client sends `username` and `password` as a form
and gets a token back.

```python
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")


@app.post("/token")
def login(form: Annotated[OAuth2PasswordRequestForm, Depends()], db: DB):
    user = db.scalar(select(User).where(User.email == form.username))
    if not user or not hasher.verify(form.password, user.password_hash):
        raise HTTPException(401, "Wrong email or password", headers={"WWW-Authenticate": "Bearer"})
    return {"access_token": create_access_token(user.id), "token_type": "bearer"}
```

`OAuth2PasswordBearer(tokenUrl="token")`:

- reads the `Authorization: Bearer <token>` header,
- returns `401` if it's missing,
- adds an **Authorize** button to `/docs`, so you can log in and try protected endpoints.

> Give the same error for "no such user" and "wrong password". Different messages let attackers find out which
> emails have accounts.
