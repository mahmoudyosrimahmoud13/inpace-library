# Dependencies with yield, and overriding them

## Setup and cleanup

Use `yield` when something must be opened **before** the endpoint and closed **after** it:

```python
def get_db():
    db = SessionLocal()
    try:
        yield db          # the endpoint runs here
    finally:
        db.close()        # always runs, even after an error


@app.get("/books")
def books(db: Annotated[Session, Depends(get_db)]):
    return db.scalars(select(Book)).all()
```

You can also commit or roll back depending on what happened:

```python
def get_db():
    db = SessionLocal()
    try:
        yield db
        db.commit()
    except Exception:
        db.rollback()
        raise
    finally:
        db.close()
```

Async works the same way with `async def` and `yield`.

> If you catch an exception in a `yield` dependency, **re-raise it** (as above). Swallowing it hides the error and
> FastAPI can't send the right response.

## Swap dependencies in tests

`app.dependency_overrides` replaces a dependency with another function, for the whole app:

```python
def fake_user():
    return User(id=1, name="Test", is_admin=True)

app.dependency_overrides[get_current_user] = fake_user
# ... run tests ...
app.dependency_overrides.clear()
```

This is how you test endpoints without a real login or a real database (module 8). It's one of the biggest
practical wins of dependency injection.
