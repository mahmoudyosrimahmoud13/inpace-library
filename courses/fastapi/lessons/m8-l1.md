# Testing with TestClient and pytest

```bash
pip install pytest httpx
```

`TestClient` lets you call your app like a real client, without starting a server:

```python
# test_books.py
from fastapi.testclient import TestClient
from app.main import app

client = TestClient(app)


def test_create_and_get_book():
    r = client.post("/books", json={"title": "Dune", "author_id": 1})
    assert r.status_code == 201
    book_id = r.json()["id"]

    r = client.get(f"/books/{book_id}")
    assert r.status_code == 200
    assert r.json()["title"] == "Dune"


def test_validation_error():
    r = client.post("/books", json={"title": ""})
    assert r.status_code == 422
```

Run with `pytest`. The test functions are normal `def`, even if your endpoints are `async def`.

## Lifespan in tests

Startup and shutdown code only runs when you use the client as a context manager:

```python
def test_with_startup():
    with TestClient(app) as client:
        r = client.get("/health")
        assert r.status_code == 200
```

## What to test

- Happy paths for each endpoint.
- Every error you raise on purpose (404, 403, 409...).
- Validation edges: empty strings, too long, negative numbers.
- Permissions: user A can't touch user B's data.
