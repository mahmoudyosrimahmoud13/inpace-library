# الكلام عن عائلتك

لوسيا وعمر يتقابلان مرة أخرى على قهوة. عمر يريها بعض الصور على هاتفه.

## استمع أولًا: المحادثة

**صور على الهاتف**

| الإسبانية | المعنى |
|---|---|
| **Lucía:** ¿Quién es ella? | من هذه؟ |
| **Omar:** Es mi hermana, Nour. Tiene veinte años. | هذه أختي نور. عمرها عشرون سنة. |
| **Lucía:** ¡Qué guapa! ¿Y él? | ما أجملها! وهذا؟ |
| **Omar:** Es mi padre. Es médico y es muy simpático. | هذا أبي. هو طبيب ولطيف جدًا. |
| **Lucía:** ¿Tienes más hermanos? | عندك إخوة آخرون؟ |
| **Omar:** Sí, tengo dos hermanos. Son altos, como mi padre. ¿Y tú? | نعم، عندي أخوان. هما طويلان مثل أبي. وأنتِ؟ |
| **Lucía:** Yo no tengo hermanos, soy hija única. Pero tengo un perro. | ليس عندي إخوة، أنا البنت الوحيدة. لكن عندي كلب. |
| **Omar:** ¿Cómo se llama? | ما اسمه؟ |
| **Lucía:** Se llama Toby. Es pequeño y un poco loco. | اسمه توبي. صغير ومجنون قليلًا. |

## قلّد الكلام (Shadowing)

اقرأ المحادثة بصوت عالٍ **ثلاث مرات**: أولًا ببطء، ثم بسرعة عادية، ثم دون أن تنظر إلى عمود المعنى. ولو عندك الصوت من الروابط بالأسفل، أوقفه بعد كل جملة وقلّد إيقاع المتكلم ولحن صوته، لا الكلمات فقط. هذا اسمه **التقليد (Shadowing)**، وهو يدرّب أذنك ولسانك معًا.

## كلمات وعبارات احفظها

| العبارة | المعنى |
|---|---|
| mi padre / mi madre | أبي / أمي |
| mis padres | والداي |
| mi hermano / mi hermana | أخي / أختي |
| mi hijo / mi hija | ابني / ابنتي |
| mi marido / mi mujer | زوجي / زوجتي |
| ¿Tienes hermanos? | عندك إخوة؟ |
| Tengo dos hermanos. | عندي أخوان (أو إخوة). |
| ¿Cuántos años tienes? | كم عمرك؟ |
| Tengo treinta años. | عمري ثلاثون سنة. |
| Es alto / baja / simpático | هو طويل / هي قصيرة / هو لطيف |
| hijo único / hija única | الابن الوحيد / البنت الوحيدة |
| ¿Quién es? | من هذا؟ |

## انطقها صح

في الإسبانية صوتان لحرف **r**، والفرق بينهما يغيّر المعنى: *pero* (لكن) و*perro* (كلب).

- حرف **r** واحد بين حرفي علة هو ضربة لسان خفيفة سريعة، مثل الراء العربية الخفيفة: *pero* و*Lara* و*caro*.
- و**rr**، وحرف **r** في أول الكلمة، راء مكررة قوية مثل الراء العربية المشددة: *perro* و*Roma* و*rojo*.

هذا الصوت سهل على المتحدث العربي! فقط انتبه أن تفرّق: *pero* راء واحدة خفيفة، و*perro* راء مشددة.
