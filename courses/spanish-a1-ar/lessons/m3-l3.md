# كلمات السؤال و por / para / porque

> **فيديو اختياري في الأعلى:** جزء من كورس A1 الكامل على قناة freeCodeCamp.org (بالإنجليزية والإسبانية، تقدّمه معلمة من Master Spanish Academy). هذا الجزء: por و para و porque. الشرح كامل في النص أدناه، فشاهده إن كان يفيدك، وكرّر الجمل بصوت عالٍ بعد المتكلمين.
>
> الترجمة: اضغط **CC** لترجمة إسبانية أو إنجليزية، أو **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

## كلمات السؤال (كلها عليها علامة ´)

| بالإسباني | المعنى | مثال |
|---|---|---|
| **¿Qué?** | ماذا؟ ما؟ | ¿Qué haces? |
| **¿Quién? / ¿Quiénes?** | من؟ | ¿Quién es? |
| **¿Dónde?** | أين؟ | ¿Dónde vives? |
| **¿Adónde?** | إلى أين؟ | ¿Adónde vas? |
| **¿Cuándo?** | متى؟ | ¿Cuándo llegas? |
| **¿Cómo?** | كيف؟ | ¿Cómo te llamas? |
| **¿Cuánto/a/os/as?** | كم؟ | ¿Cuántos años tienes? |
| **¿Cuál? / ¿Cuáles?** | أي؟ ما؟ | ¿Cuál es tu número? |
| **¿Por qué?** | لماذا؟ | ¿Por qué estudias español? |

## لماذا؟ لأن...

- **¿Por qué?** (كلمتان، مع علامة) = لماذا؟
- **porque** (كلمة واحدة، بدون علامة) = لأن: *Estudio español porque quiero trabajar en España.*

## por و para (البداية فقط)

| para | por |
|---|---|
| الهدف: *Estudio para aprender.* (لكي) | السبب: *Gracias por todo.* (على / بسبب) |
| لمن: *Es para ti.* (لك) | عبر / في أنحاء: *Paseo por el parque.* |
| الوجهة: *Salgo para Madrid.* | الوقت من اليوم: *por la mañana* (صباحًا) |
| الموعد: *para el lunes* | الثمن: *por diez euros* |

## تمرين

أكمل: ¿___ vives?، En Alejandría. / Estudio ___ trabajar en Chile. / No como carne ___ soy vegetariano.

**الإجابات:** Dónde، para، porque.
