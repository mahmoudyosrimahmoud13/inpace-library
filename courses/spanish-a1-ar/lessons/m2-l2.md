## tener = عنده / يملك

| tengo | tienes | tiene | tenemos | tenéis | tienen |
|---|---|---|---|---|---|

```text
Tengo dos hermanos.     عندي أخوان.
¿Tienes coche?          عندك سيارة؟
Tengo hambre / sed.     أنا جائع / عطشان (حرفيًا: عندي جوع).
```

## أدوات التعريف والتنكير

| | مذكر | مؤنث |
|---|---|---|
| التعريف (الـ) مفرد | **el** libro | **la** casa |
| التعريف جمع | **los** libros | **las** casas |
| التنكير مفرد | **un** libro | **una** casa |
| التنكير جمع (بعض) | **unos** libros | **unas** casas |

## كيف تعرف المذكر والمؤنث؟

- غالبًا ما ينتهي بـ **-o** مذكر، وما ينتهي بـ **-a** مؤنث: *el chico، la chica*.
- ما ينتهي بـ **-ción، -dad** مؤنث: *la estación، la ciudad*.
- استثناءات مشهورة: **el día**، **el problema**، **el mapa**، **la mano**، **la foto**.
- الجنس لا يتبع العربي دائمًا: *el sol* (الشمس مذكر)، *la luna*، *la leche* (اللبن مؤنث).

## الجمع

- ينتهي بحرف متحرك: أضف **-s**: *libro → libros*.
- ينتهي بحرف ساكن: أضف **-es**: *ciudad → ciudades*، *profesor → profesores*.
