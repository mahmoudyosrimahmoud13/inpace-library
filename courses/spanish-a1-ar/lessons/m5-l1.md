# العائلة والملكية

> **فيديو اختياري في الأعلى:** جزء من كورس A1 الكامل على قناة freeCodeCamp.org (بالإنجليزية والإسبانية، تقدّمه معلمة من Master Spanish Academy). هذا الجزء: العائلة والملكية. الشرح كامل في النص أدناه، فشاهده إن كان يفيدك، وكرّر الجمل بصوت عالٍ بعد المتكلمين.
>
> الترجمة: اضغط **CC** لترجمة إسبانية أو إنجليزية، أو **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

## العائلة

| | | |
|---|---|---|
| el padre / la madre الأب / الأم | los padres الوالدان | el hermano / la hermana |
| el hijo / la hija ابن / ابنة | el abuelo / la abuela جد / جدة | el tío / la tía عم أو خال / عمة أو خالة |
| el primo / la prima ابن العم أو الخال | el marido / la mujer (esposo/a) زوج / زوجة | el sobrino / la sobrina ابن الأخ أو الأخت |

**los hermanos** = الإخوة (حتى لو بنات وأولاد)، و **los padres** = الأب والأم.

## الملكية

| | مفرد | جمع |
|---|---|---|
| لي | **mi** hermano | **mis** hermanos |
| لك | **tu** casa | **tus** casas |
| له / لها / لكم (usted) | **su** coche | **sus** coches |
| لنا | **nuestro** padre / **nuestra** madre | nuestros / nuestras |
| لكم (vosotros) | vuestro / vuestra | vuestros / vuestras |
| لهم | **su** | **sus** |

**su** قد تعني «له» أو «لها» أو «لهم» أو «لحضرتك». للتوضيح: *el coche de Ana* (سيارة آنا).

## ملكية الأسماء: de

لا يوجد 's: **el hermano de Omar** = أخو عمر. *La casa de mis padres* = بيت والديّ.

## تمرين

قدّم عائلتك في 5 جمل: *Mi padre se llama... Tengo dos hermanas. Mis abuelos viven en...*
