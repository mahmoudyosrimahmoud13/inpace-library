# في المقهى

عمر يطلب الإفطار في مقهى. النُدُل في إسبانيا يستخدمون usted مع الزبائن غالبًا، والزبائن يقولون quería (أريد / أودّ) للتأدب.

## استمع أولًا: المحادثة

**طلب الإفطار**

| الإسبانية | المعنى |
|---|---|
| **Camarero:** Buenos días. ¿Qué le pongo? | صباح الخير. ماذا أحضر لك؟ |
| **Omar:** Quería un café con leche y una tostada con tomate, por favor. | أريد قهوة بالحليب وتوست بالطماطم من فضلك. |
| **Camarero:** Muy bien. ¿Algo más? | تمام. شيء آخر؟ |
| **Omar:** Sí, un zumo de naranja. ¿Cuánto es todo? | نعم، عصير برتقال. كم الحساب كله؟ |
| **Camarero:** Son seis euros con cincuenta. | ستة يورو وخمسون. |
| **Omar:** Aquí tiene. | تفضّل. |
| **Camarero:** Gracias. ¿Le gusta el café de aquí? | شكرًا. هل يعجبك القهوة هنا؟ |
| **Omar:** Sí, me gusta mucho. ¡Y me encantan las tostadas! | نعم، تعجبني كثيرًا. وأحب التوست جدًا! |

## قلّد الكلام (Shadowing)

اقرأ المحادثة بصوت عالٍ **ثلاث مرات**: أولًا ببطء، ثم بسرعة عادية، ثم دون أن تنظر إلى عمود المعنى. ولو عندك الصوت من الروابط بالأسفل، أوقفه بعد كل جملة وقلّد إيقاع المتكلم ولحن صوته، لا الكلمات فقط. هذا اسمه **التقليد (Shadowing)**، وهو يدرّب أذنك ولسانك معًا.

## كلمات وعبارات احفظها

| العبارة | المعنى |
|---|---|
| ¿Qué le pongo? / ¿Qué desea? | ماذا أحضر لك؟ |
| Quería... / Quiero... | أودّ... / أريد... |
| ¿Algo más? | شيء آخر؟ |
| Nada más, gracias. | لا شيء آخر، شكرًا. |
| ¿Cuánto es? / ¿Cuánto cuesta? | كم الحساب؟ / كم سعره؟ |
| Aquí tiene. | تفضّل. |
| La cuenta, por favor. | الحساب من فضلك. |
| un zumo (Spain) / un jugo (Latin America) | عصير |
| Me gusta el café. | أحب القهوة. |
| No me gusta el pescado. | لا أحب السمك. |
| Me encantan las frutas. | أحب الفواكه جدًا. |
| ¿Tiene...? / ¿Hay...? | عندكم...؟ / هل يوجد...؟ |

## انطقها صح

**b وv** لهما **نفس الصوت** في الإسبانية: مثل الباء العربية. في أول الجملة أو بعد *m/n* باء واضحة: *vino* = "بينو"، و*bien* و*un vaso*. وبين حرفي علة أخف، والشفتان تكادان تتلامسان: *uva* و*Cuba* و*la verdad*. لا تنطق *v* فاءً أبدًا: *vino* ليست "فينو".

**d** بين حرفي علة خفيفة مثل الذال العربية: *nada* = "ناذا" تقريبًا، و*todo* و*helado*.

قل: *vino, bebida, uva, nada, todo, helado, ¿Cuánto vale?*
