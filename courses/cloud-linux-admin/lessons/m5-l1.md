# CloudWatch agent: metrics and logs from inside Linux

AWS sees CPU, network and disk I/O from outside. For **memory, disk space, and your log files**, install the CloudWatch agent.

```bash
sudo dnf -y install amazon-cloudwatch-agent      # Amazon Linux; Ubuntu: download the .deb
```

```json
{
  "agent": {"metrics_collection_interval": 60},
  "metrics": {
    "append_dimensions": {"InstanceId": "${aws:InstanceId}", "AutoScalingGroupName": "${aws:AutoScalingGroupName}"},
    "metrics_collected": {
      "mem": {"measurement": ["mem_used_percent"]},
      "disk": {"measurement": ["used_percent"], "resources": ["/", "/data"]}
    }
  },
  "logs": {"logs_collected": {"files": {"collect_list": [
    {"file_path": "/var/log/nginx/access.log", "log_group_name": "/shop/nginx/access", "log_stream_name": "{instance_id}"},
    {"file_path": "/var/log/nginx/error.log",  "log_group_name": "/shop/nginx/error",  "log_stream_name": "{instance_id}"}
  ]}}}
}
```

Store the config in Parameter Store and load it on every instance:

```bash
sudo /opt/aws/amazon-cloudwatch-agent/bin/amazon-cloudwatch-agent-ctl -a fetch-config -m ec2 -c ssm:/shop/cw-agent -s
```

The role needs `CloudWatchAgentServerPolicy`. Instances in an ASG come and go; logs in CloudWatch stay.

## Querying logs

**Logs Insights**:

```text
fields @timestamp, @message
| filter @message like / 5\d\d /
| stats count() by bin(5m)
```

## Alarms worth having on every server fleet

- Disk used > 85% on any mount.
- Memory > 90% for 10 minutes.
- ALB 5xx rate and target response time.
- Status check failed -> recover the instance automatically (an EC2 alarm action).

Set **retention** on every log group (default is forever, and you pay for it).
