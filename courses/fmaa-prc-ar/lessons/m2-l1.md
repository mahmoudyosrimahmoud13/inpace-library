# الميزانية وقائمة الدخل

## الميزانية (Balance Sheet)

الميزانية، وتُسمى أيضًا قائمة المركز المالي (Statement of Financial Position)، تعرض ما تملكه الشركة وما عليها **في تاريخ محدد**. هي صورة لحظية.

| القسم | أمثلة |
|---|---|
| الأصول المتداولة (Current assets) | النقدية، الذمم المدينة، المخزون، المصروفات المدفوعة مقدمًا |
| الأصول غير المتداولة (Non-current assets) | الأراضي والمباني والآلات، الأصول غير الملموسة |
| الالتزامات المتداولة (Current liabilities) | الذمم الدائنة، الأجور المستحقة، الجزء المتداول من القروض |
| الالتزامات غير المتداولة (Non-current liabilities) | السندات، القروض طويلة الأجل |
| حقوق الملكية (Equity) | رأس المال، الأرباح المحتجزة (Retained earnings) |

- **المتداول** = يتحول إلى نقدية أو يُسدَّد خلال سنة واحدة.
- يجب أن تتوازن دائمًا: الأصول = الالتزامات + حقوق الملكية.

## قائمة الدخل (Income Statement)

تعرض أداء الشركة **خلال فترة** (شهر، ربع، سنة).

| البند | الحساب |
|---|---|
| الإيرادات (Revenue) | |
| − تكلفة البضاعة المباعة (COGS) | |
| = مجمل الربح (Gross profit) | الإيرادات − تكلفة البضاعة المباعة |
| − المصروفات التشغيلية | البيع، الإدارة، الإهلاك |
| = الربح التشغيلي (Operating income / EBIT) | |
| − الفوائد والضرائب | |
| = صافي الربح (Net income) | |

**مثال:** إيرادات $500,000، تكلفة البضاعة $300,000، مصروفات تشغيلية $120,000، فوائد وضرائب $30,000.
مجمل الربح = $200,000. الربح التشغيلي = $80,000. صافي الربح = $50,000.

> **نصيحة للامتحان:** الميزانية = في تاريخ معين. قائمة الدخل = عن فترة. ومجمل الربح يطرح تكلفة البضاعة فقط، لا كل المصروفات.
