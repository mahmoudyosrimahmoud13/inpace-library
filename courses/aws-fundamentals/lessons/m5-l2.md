# Keeping S3 private

Public S3 buckets have leaked more data than almost anything else in the cloud. Defaults are now safe; keep them that way.

| Control | Does | Recommended |
|---|---|---|
| **Block Public Access** (account and bucket) | Overrides anything that would make data public | On, at the account level |
| **Object Ownership: bucket owner enforced** | Disables ACLs; only policies control access | On (the default) |
| **Bucket policy** | Resource policy: who may do what to this bucket | Use it, plus IAM |
| **Default encryption** | Every object encrypted at rest (SSE-S3 or SSE-KMS) | On (always on since 2023) |
| **Require TLS** | Deny requests not using HTTPS | Add a Deny with `aws:SecureTransport = false` |

## A bucket only one role may read

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {"Sid": "OnlyTheAppRole", "Effect": "Deny", "Principal": "*", "Action": "s3:GetObject",
     "Resource": "arn:aws:s3:::acme-uploads/*",
     "Condition": {"StringNotEquals": {"aws:PrincipalArn": "arn:aws:iam::123456789012:role/app-role"}}},
    {"Sid": "TLSOnly", "Effect": "Deny", "Principal": "*", "Action": "s3:*",
     "Resource": ["arn:aws:s3:::acme-uploads", "arn:aws:s3:::acme-uploads/*"],
     "Condition": {"Bool": {"aws:SecureTransport": "false"}}}
  ]
}
```

## Serving files to the public, safely

Don't make the bucket public. Put **CloudFront** in front with Origin Access Control: the bucket stays private, only CloudFront can read it, and users get a fast, cached, HTTPS site. For one-off downloads, use **presigned URLs** that expire.
