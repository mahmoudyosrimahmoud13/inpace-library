# EC2: virtual servers

An EC2 **instance** is a Linux (or Windows) virtual machine.

| Choice | Means | Tip |
|---|---|---|
| **AMI** | The disk image to boot (Amazon Linux 2023, Ubuntu 24.04...) | Use official AMIs from the vendor |
| **Instance type** | CPU, memory, network: `t3.micro`, `m7g.large`, `c7i.xlarge` | Family letter: t burstable, m general, c compute, r memory, g/p GPU; trailing g = ARM (Graviton, cheaper) |
| **Key pair** | The SSH key installed for the default user | Or skip SSH entirely and use Session Manager |
| **Subnet and security group** | Where it lives and what may reach it | Day 4 |
| **IAM role** | What the instance may do in AWS | Day 2: never put keys on the box |
| **User data** | A script run on first boot (cloud-init) | Install packages, configure the app |
| **Storage** | The root EBS volume and any others | Day 3 lesson 2 |

```bash
aws ec2 run-instances --image-id ami-0abc... --instance-type t3.micro \
  --key-name sara --subnet-id subnet-0123 --security-group-ids sg-0456 \
  --iam-instance-profile Name=web-role --user-data file://init.sh \
  --metadata-options HttpTokens=required \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=web01}]'
aws ec2 describe-instances --filters Name=tag:Name,Values=web01 --query 'Reservations[].Instances[].{id:InstanceId,state:State.Name,ip:PublicIpAddress}'
```

## States and billing

`pending -> running -> stopping -> stopped -> terminated`. You pay compute while **running**; stopped instances still pay for their EBS disks; **terminated** is gone forever (with its root volume by default).

## The instance metadata service

From inside the instance, `http://169.254.169.254` tells it about itself and serves the role's temporary credentials. Require **IMDSv2** (`HttpTokens=required`): it blocks a classic attack where a bug in a web app is tricked into fetching those credentials.

```bash
TOKEN=$(curl -s -X PUT http://169.254.169.254/latest/api/token -H "X-aws-ec2-metadata-token-ttl-seconds: 60")
curl -s -H "X-aws-ec2-metadata-token: $TOKEN" http://169.254.169.254/latest/meta-data/instance-id
```
