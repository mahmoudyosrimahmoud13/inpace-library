# ~/.ssh/config: stop typing long commands

```text
# ~/.ssh/config
Host web01
    HostName 203.0.113.10
    User sara
    Port 2222
    IdentityFile ~/.ssh/id_ed25519_work
    IdentitiesOnly yes

Host db-*
    User admin
    IdentityFile ~/.ssh/id_ed25519_work

Host github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_github
    IdentitiesOnly yes

Host *
    ServerAliveInterval 30
    ServerAliveCountMax 3
    AddKeysToAgent yes
```

Now `ssh web01`, `scp file web01:`, `rsync ... web01:` and `git push` all use the right user, port and key.

| Setting | Does |
|---|---|
| `HostName` | The real address behind the alias |
| `User`, `Port` | Defaults for that host |
| `IdentityFile` | Which key to offer |
| `IdentitiesOnly yes` | Offer **only** that key (prevents "Too many authentication failures" when the agent has many keys) |
| `ServerAliveInterval` | Send a keep-alive so idle sessions aren't dropped by NAT or firewalls |
| `Host *` | Defaults for everything; put it **last** (the first value found for each setting wins) |

```bash
ssh -G web01 | less      # the final settings ssh will really use for that host
```

## Faster repeat connections: multiplexing

```text
Host *
    ControlMaster auto
    ControlPath ~/.ssh/cm-%r@%h:%p
    ControlPersist 10m
```

The first connection does the handshake; the next `ssh`, `scp` or Ansible run reuses it instantly.

## Two GitHub accounts

```text
Host github-work
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_work
    IdentitiesOnly yes
```

Clone with `git clone git@github-work:company/repo.git`, and that repo always uses the work key.
