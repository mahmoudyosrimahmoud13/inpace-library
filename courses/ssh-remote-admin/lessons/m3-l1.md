# Copying files: scp, sftp and rsync

```bash
scp report.pdf web01:/tmp/                    # to the server
scp web01:/var/log/nginx/access.log .         # from the server
scp -r site/ web01:/srv/www/                  # a directory
scp -3 web01:/data/file db01:/data/           # between two servers, through you
```

Modern OpenSSH runs `scp` over the SFTP protocol underneath; the command line stays the same.

## sftp: an interactive session

```text
sftp web01
sftp> ls
sftp> cd /srv/www
sftp> put index.html
sftp> get -r logs
sftp> bye
```

## rsync: the one to use for anything big or repeated

```bash
rsync -avz --progress site/ web01:/srv/www/          # copies only what changed
rsync -avz --delete site/ web01:/srv/www/            # also delete files removed locally
rsync -avzn --delete site/ web01:/srv/www/           # -n: dry run, see what WOULD happen
rsync -avz -e "ssh -p 2222" data/ web01:/backup/     # custom ssh options
rsync -avP big.iso web01:/tmp/                       # -P: resume a broken transfer
```

| Need | Use |
|---|---|
| One quick file | `scp` |
| Browse and pick | `sftp` (or a GUI like FileZilla / WinSCP, which use SFTP) |
| Folders, repeated syncs, big files, resuming | `rsync` |

Trailing slash rule again: `site/` copies the contents, `site` copies the folder.

## Mounting a remote folder

```bash
sudo apt install sshfs
mkdir ~/web01 && sshfs web01:/srv/www ~/web01    # work on remote files with local tools
fusermount -u ~/web01                            # unmount
```
