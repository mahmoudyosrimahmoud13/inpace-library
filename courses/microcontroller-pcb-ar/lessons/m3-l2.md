# أول برامجك

## الرفع بـ Arduino IDE

1. ثبّت **Arduino IDE** ‏(arduino.cc).
2. الـ Board: ‏**Arduino Uno** ‏(الـ board الخاص بك هو Uno كهربائيًا: ‏ATmega328P، و16 MHz، وbootloader الـ Uno).
3. الـ Port: الذي يظهر عندما توصل الـ board ‏(أو الـ adapter). وعلى Windows قد يحتاج الـ CH340 إلى الـ driver الخاص به.
4. افتح الـ sketch أدناه واضغط **Upload**.

```cpp
// Blink: the "hello world" of microcontrollers
const int LED_PIN = 13;              // PB5, pin 19 on the chip

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(500);                        // milliseconds
  digitalWrite(LED_PIN, LOW);
  delay(500);
}
```

‏`setup()` تعمل مرة واحدة عند التشغيل؛ و`loop()` تعمل مرة بعد مرة للأبد. لو كان الـ LED يومض مرة كل ثانية، **فالـ board الخاص بك يعمل**: الكهرباء، والـ clock، والـ reset، والبرمجة، والـ LED كلها سليمة. ولو كان يومض أبطأ 16 مرة، فـ fuses الـ clock خطأ (الوحدة 3، الدرس 1).

## قراءة زر والطباعة على الكمبيوتر

```cpp
const int BUTTON_PIN = 2;            // PD2: button to ground, internal pull-up
const int LED_PIN = 13;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP); // pressed = LOW
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("board ready");
}

void loop() {
  bool pressed = digitalRead(BUTTON_PIN) == LOW;
  digitalWrite(LED_PIN, pressed ? HIGH : LOW);
  int light = analogRead(A0);        // 0 to 1023 from an LDR divider on A0
  Serial.print("light: ");
  Serial.println(light);
  delay(200);
}
```

افتح **Tools → Serial Monitor** على 9600 baud لترى القراءات. وطباعة القيم هي أداة الـ debugging الرئيسية على الـ microcontroller.

## نفس الوميض بدون Arduino: الـ registers

دوال Arduino أغلفة مريحة. وتحتها، كل pin يُتحكم فيه بـ bits في **registers**: أماكن خاصة في الذاكرة. للـ port B:

| الـ Register | كل bit معناه |
|---|---|
| `DDRB` | الاتجاه: ‏1 = output، و0 = input |
| `PORTB` | قيمة المخرج (أو تشغيل الـ pull-up للمدخلات) |
| `PINB` | مستوى الدخل الحالي للـ pin |

<!-- skip -->
```c
// blink.c: plain C for the ATmega328P (compile with avr-gcc)
#define F_CPU 16000000UL
#include <avr/io.h>
#include <util/delay.h>

int main(void) {
    DDRB |= (1 << PB5);              // PB5 (D13) as output
    while (1) {
        PORTB ^= (1 << PB5);         // flip the LED
        _delay_ms(500);
    }
}
```

ابنِه وارفعه بأدوات AVR ‏(تُثبت مع Arduino IDE، أو `sudo apt install gcc-avr avr-libc avrdude`):

```bash
avr-gcc -mmcu=atmega328p -Os blink.c -o blink.elf
avr-objcopy -O ihex blink.elf blink.hex
avrdude -c arduino -p m328p -P /dev/ttyUSB0 -b 115200 -U flash:w:blink.hex
```

نسخة الـ registers أصغر بعدة مرات من نسخة Arduino. وستستخدم دوال Arduino أغلب الوقت، لكن معرفة الـ registers تشرح ما يحدث فعلًا، وهي طريقتك لاعتصار السرعة أو الحجم عندما تحتاج. (ومهارات C والـ pointers من كورس C تنطبق هنا مباشرة.)

## الخلاصة

- اختر "Arduino Uno" والـ port الخاص بالـ board؛ ووميض بمعدل 1 Hz يثبت أن الـ board كله يعمل.
- `INPUT_PULLUP` و`digitalRead` و`analogRead` و`Serial.println` تغطي أغلب المشاريع الأولى.
- تحت الغطاء، registers ‏`DDRx` و`PORTx` و`PINx` تتحكم في الـ pins؛ وavr-gcc وavrdude يبنيان ويرفعان C عادية.
