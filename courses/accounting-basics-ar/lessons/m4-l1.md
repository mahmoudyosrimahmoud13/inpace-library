# كتابة قيود اليومية

العمليات تُسجَّل أولًا في **دفتر اليومية (Journal)**، بترتيب التاريخ. وكل تسجيل اسمه **قيد يومية**.

## الشكل

| التاريخ | البيان | مدين | دائن |
|---|---|---|---|
| 2 يونيو | من حـ/ المعدات | 8,000 | |
| | &nbsp;&nbsp;&nbsp;&nbsp;إلى حـ/ النقدية | | 8,000 |
| | *شراء فرن، إيصال رقم 104* | | |

قواعد الشكل:

- **المدين أولًا**. **الدائن بعده**، بإزاحة للداخل.
- **شرح** قصير تحت كل قيد، ويُفضَّل معه رقم المستند (فاتورة، إيصال).
- المدين يساوي الدائن في كل قيد.

## القيود المركّبة

بعض العمليات تمسّ ثلاثة حسابات أو أكثر. هذا **قيد مركّب**، والقاعدة ثابتة: إجمالي المدين = إجمالي الدائن.

مثال: نور تشتري عجّانة بـ 1,200، تدفع 400 الآن والباقي الشهر القادم.

| التاريخ | البيان | مدين | دائن |
|---|---|---|---|
| 3 يوليو | من حـ/ المعدات | 1,200 | |
| | &nbsp;&nbsp;&nbsp;&nbsp;إلى مذكورين: حـ/ النقدية | | 400 |
| | &nbsp;&nbsp;&nbsp;&nbsp;حـ/ الموردين | | 800 |

ومثال آخر: تسدّد 1,000 من قرض بنكي ومعها 50 فائدة.

| | البيان | مدين | دائن |
|---|---|---|---|
| | من مذكورين: حـ/ القرض | 1,000 | |
| | حـ/ مصروف الفوائد | 50 | |
| | &nbsp;&nbsp;&nbsp;&nbsp;إلى حـ/ النقدية | | 1,050 |

("من مذكورين" و"إلى مذكورين" تعني أن الطرف فيه أكثر من حساب.)

## لماذا دفتر يومية أصلًا؟

لأنه يحفظ كل عملية **كاملة** في مكان واحد وبترتيب الزمن. لو بدا شيء غلطًا لاحقًا، تجد القيد بالضبط ومستنده. دفتر الأستاذ، الدرس القادم، يرتّب نفس الأرقام حسب الحساب بدل التاريخ.
