# Arrays

An array is an ordered list. Positions start at **0**.

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 0:40:44 to 0:51:41. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
const tasks = ["Read", "Code", "Review"];
console.log(tasks[0], tasks.length);   // "Read" 3
tasks[1] = "Code more";                 // change an item
tasks.push("Rest");                     // add at the end
const last = tasks.pop();               // remove from the end: "Rest"
tasks.unshift("Plan");                  // add at the start
tasks.shift();                          // remove from the start
console.log(tasks.includes("Read"));    // true
console.log(tasks.indexOf("Review"));   // 2
const grid = [[1, 2], [3, 4]];          // an array of arrays
console.log(grid[1][0]);                // 3
```

A `const` array can still change inside (`push` works); `const` only stops you from pointing the name at another array.
