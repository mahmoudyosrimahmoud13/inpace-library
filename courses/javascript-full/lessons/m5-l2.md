# Arrow functions, rest and spread

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 2:47:17 to 2:57:18. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
const double = (n) => n * 2;           // one expression: the value is returned
const add = (a, b) => {                 // with braces you need return
  const sum = a + b;
  return sum;
};

const total = (...nums) => nums.reduce((s, n) => s + n, 0);   // rest: any number of arguments
console.log(total(1, 2, 3, 4));         // 10

const a = [1, 2];
const b = [...a, 3];                    // spread: copy and extend -> [1, 2, 3]
console.log(Math.max(...b));            // 3
console.log(double(5), add(2, 3));      // 10 5
```

Functions are values: you can store them in variables and pass them to other functions. That's what you did with `map((t) => t.title)`: a **callback**.
