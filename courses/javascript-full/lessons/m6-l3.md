# JSON

JSON is text that looks like JavaScript objects. It's how apps send data over the internet and save it.

```javascript
const tasks = [{ title: "Read", minutes: 25 }];
const text = JSON.stringify(tasks);        // object -> text
console.log(text);                          // [{"title":"Read","minutes":25}]
const back = JSON.parse(text);              // text -> object
console.log(back[0].minutes);               // 25
```

In JSON, keys and strings use **double quotes**, and there are no functions, `undefined` or comments. `JSON.parse` throws an error on bad text: module 10 shows how to catch it.
