# Start here

JavaScript is the language of the web: every website runs it in the browser, and with Node.js it also runs servers, tools and apps. This course takes you from your first line to a real web app you build step by step and publish online.

| Module | What you learn |
|---|---|
| 1 | Running JavaScript, variables, types |
| 2 | Numbers, strings, template literals |
| 3 | Conditions and logic |
| 4 | Arrays and loops, map, filter, reduce |
| 5 | Functions, scope, arrow functions |
| 6 | Objects, destructuring, JSON |
| 7 | let and const, classes, modules |
| 8 | The DOM and events: project step 1 |
| 9 | Async: promises, fetch, localStorage: project step 2 |
| 10 | Errors, tests, tools, publishing: project step 3 |

**Plan:** about 10 weeks at 4 to 5 hours a week. **The written lessons are the course.** Some lessons have a part of freeCodeCamp's full JavaScript course on top as an optional video.

## What you need

- A browser (Chrome, Edge or Firefox).
- [Node.js](https://nodejs.org) LTS, to run files from the terminal.
- [VS Code](https://code.visualstudio.com), a free editor.

The project you build: **Study Tasks**, a small app to plan what you study, with a list you can tick, a total of minutes, saving in the browser, a quote loaded from the internet, tests, and a public link to put in your CV.
