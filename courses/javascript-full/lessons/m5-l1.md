# Functions, parameters and return

A function is a named, reusable block of code.

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 0:51:41 to 1:08:41. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
function minutesToHours(minutes) {   // minutes is a parameter
  return minutes / 60;               // return sends a value back and stops the function
}
const h = minutesToHours(90);         // 90 is the argument
console.log(h);                       // 1.5

function greet(name = "friend") {     // a default value
  console.log(`Hi, ${name}!`);        // no return: the result is undefined
}
greet();          // Hi, friend!
greet("Mona");    // Hi, Mona!
```

## Scope

A variable made with `let` or `const` inside `{ }` exists only inside those braces. Variables outside a function can be read inside it, but avoid changing them from inside: pass values in and return results out.

```javascript
const tax = 0.14;
function withTax(price) {
  const result = price * (1 + tax);   // result lives only here
  return Math.round(result);
}
console.log(withTax(100));   // 114
// console.log(result);      // ReferenceError: result is not defined
```
