# Variables and types

A variable is a named box for a value. Use **`const`** by default, and **`let`** when the value will change. (Old code uses `var`; module 7 explains why to avoid it.)

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 0:05:56 to 0:14:05. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
const name = "Mona";       // string (text)
let age = 24;               // number
const isStudent = true;     // boolean: true or false
let city;                   // undefined: no value yet
const nothing = null;       // null: "empty on purpose"

age = age + 1;              // let can change
console.log(name, age);     // Mona 25
console.log(typeof age);    // "number"
```

| Type | Example |
|---|---|
| string | `"hello"`, `'hi'` |
| number | `42`, `3.14` (one type for both) |
| boolean | `true`, `false` |
| undefined | a variable with no value |
| null | no value, on purpose |
| object, array | module 4 and 6 |

**Names:** start with a letter, use camelCase (`totalMinutes`), and remember JavaScript is **case sensitive**: `age` and `Age` are different. Assigning to a `const` again is an error: `TypeError: Assignment to constant variable.`
