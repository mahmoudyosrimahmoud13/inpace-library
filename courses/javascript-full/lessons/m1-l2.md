# Three ways to run JavaScript

1. **The browser console:** press **F12** (or right click → Inspect), open **Console**, and type `2 + 3`. Good for quick tries.
2. **Node.js in the terminal:** save a file `hello.js` and run `node hello.js`.
3. **A web page:** a `<script>` tag in an HTML file.

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 0:01:24 to 0:05:56. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
// hello.js
console.log("Hello, world!");   // prints a line
console.log(2 + 3);              // 5
// a comment: JavaScript ignores it
/* a comment
   on several lines */
```

```html
<!-- index.html -->
<!doctype html>
<html>
  <body>
    <h1>My page</h1>
    <script src="hello.js"></script>
  </body>
</html>
```

`console.log` is your best friend: print values to see what your code is doing.
