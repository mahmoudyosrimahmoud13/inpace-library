# Classes

A class is a blueprint for objects that share structure and behaviour.

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 3:12:56 to 3:20:25. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
class Timer {
  #seconds = 0;                 // private field: only the class can see it

  constructor(label) {
    this.label = label;
  }

  tick(n = 1) {
    this.#seconds += n;
    return this;                // lets you chain: t.tick().tick()
  }

  get minutes() {               // a getter: used like a property
    return Math.floor(this.#seconds / 60);
  }

  toString() {
    return `${this.label}: ${this.minutes} min`;
  }
}

class PomodoroTimer extends Timer {   // inheritance
  constructor() {
    super("Pomodoro");
  }
  get finished() {
    return this.minutes >= 25;
  }
}

const p = new PomodoroTimer();
p.tick(1500);
console.log(String(p), p.finished);   // Pomodoro: 25 min true
```

Use classes when you have many objects with the same behaviour. For simple data, plain objects and functions are enough (that's what the project does).
