# Project step 3: tests and publishing

Because the logic lives in `tasks.js` with no DOM, Node can test it with its built-in test runner. Add `package.json` and `tasks.test.js`:

```json
{ "type": "module", "scripts": { "test": "node --test" } }
```

```javascript
// tasks.test.js
import { test } from "node:test";
import assert from "node:assert/strict";
import { createTask, toggleTask, removeTask, summary } from "./tasks.js";

test("createTask trims the title and keeps the minutes", () => {
  const t = createTask("  Read chapter 3 ", "30");
  assert.equal(t.title, "Read chapter 3");
  assert.equal(t.minutes, 30);
  assert.equal(t.done, false);
});

test("createTask refuses an empty title", () => {
  assert.throws(() => createTask("   "), /needs a title/);
});

test("toggle, remove and summary", () => {
  let tasks = [createTask("A", 20), createTask("B", 40)];
  tasks = toggleTask(tasks, tasks[0].id);
  assert.equal(tasks[0].done, true);
  assert.deepEqual(summary(tasks), { total: 2, left: 1, minutes: 40 });
  tasks = removeTask(tasks, tasks[1].id);
  assert.equal(tasks.length, 1);
});
```

Run `npm test`: all 3 tests should pass. Change `summary` on purpose to break it, watch a test fail, then fix it.

## Publish with GitHub Pages

1. Create a GitHub repository `study-tasks` and push the folder.
2. **Settings → Pages → Branch: main → Save**.
3. After a minute your app is live at `https://<you>.github.io/study-tasks/`.

Add a README with a screenshot, what it does, how to run the tests, and the live link. Now it's a project you can show.
