# switch, ternary, ?? and ?.

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 1:32:15 to 1:43:38. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
const day = "Fri";
switch (day) {
  case "Fri":
  case "Sat":
    console.log("Weekend");
    break;               // without break, it falls into the next case
  default:
    console.log("Work day");
}

const age = 20;
const label = age >= 18 ? "adult" : "minor";   // condition ? if true : if false

const nickname = null;
console.log(nickname ?? "no nickname");        // ?? : a default only for null/undefined

const user = { profile: null };
console.log(user.profile?.city);               // ?. : undefined instead of a crash
```

`||` gives the right side for **any** falsy value (so `0 || 10` is 10), while `??` only for `null` and `undefined` (so `0 ?? 10` is 0). Use `??` for defaults.
