# Modules: import and export

Split code into files. Each file exports what others may use.

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 3:20:25 to 3:26:00. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
// math.js
export function add(a, b) { return a + b; }
export const PI = 3.14159;
export default function square(n) { return n * n; }

// main.js
import square, { add, PI } from "./math.js";
console.log(add(2, 3), PI, square(4));
```

- **In the browser:** `<script type="module" src="main.js">`, and open the page through a small server (VS Code's Live Server extension), not by double-clicking the file.
- **In Node:** add `"type": "module"` to `package.json`.
- **npm packages:** `npm install date-fns`, then `import { format } from "date-fns";`.
