# Errors and debugging

```javascript
function parseTasks(text) {
  try {
    return JSON.parse(text);
  } catch (error) {
    console.error("Bad data:", error.message);
    return [];
  } finally {
    console.log("parseTasks finished");   // runs either way
  }
}

function createTask(title) {
  if (!title.trim()) throw new Error("A task needs a title.");   // your own error
  return { title };
}
```

**Read the error message:** its type (`TypeError`, `ReferenceError`), its message, and the file and line. Then use the browser's **Sources** panel: click a line number to set a **breakpoint**, reload, and step through the code while watching the variables. `debugger;` in your code does the same.
