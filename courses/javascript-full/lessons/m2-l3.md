# Template literals

Use backticks `` ` `` and `${...}` to put values inside text. It's cleaner than `+`, and it can span lines.

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 3:06:39 to 3:10:43. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
const task = "Read chapter 3";
const minutes = 30;
console.log(`${task}: ${minutes} min, ${minutes / 60} h`);
// Read chapter 3: 30 min, 0.5 h

const card = `
  Name: ${task}
  Done: ${minutes > 20 ? "later" : "now"}
`;
```
