# Objects

An object groups related values under names (keys).

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 1:49:11 to 2:10:15. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
const task = {
  title: "Read chapter 3",
  minutes: 30,
  done: false,
  tags: ["reading", "math"],
};

console.log(task.title);           // dot notation
console.log(task["minutes"]);      // bracket notation (when the key is in a variable)
task.done = true;                  // update
task.priority = "high";            // add a new key
delete task.tags;                  // remove a key
console.log("priority" in task);   // true
console.log(Object.keys(task));    // ["title", "minutes", "done", "priority"]

for (const [key, value] of Object.entries(task)) {
  console.log(`${key}: ${value}`);
}
```

**Objects for lookups** replace long if/else chains:

```javascript
const dayNames = { 0: "Sunday", 1: "Monday", 5: "Friday" };
console.log(dayNames[5] ?? "Another day");   // "Friday"
```

**Objects are passed by reference:** `const b = a` doesn't copy; both names point to the same object. Copy with `{ ...a }` (a shallow copy) or `structuredClone(a)` (a deep copy).
