# Where to go next

An optional lesson. Pick one path:

- **Front end:** learn React or Vue, then TypeScript. [react.dev](https://react.dev) has an excellent free tutorial.
- **Back end:** Node.js with Express or Fastify, a database, and REST APIs.
- **Practice:** [javascript.info](https://javascript.info) (the best free reference, in depth), [MDN Web Docs](https://developer.mozilla.org) (the official reference), and freeCodeCamp's JavaScript certification projects.

Keep building small things: a weather page with an API, a quiz game, a budget tracker. Each one is a line in your CV.
