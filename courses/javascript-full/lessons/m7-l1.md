# var, let and const

| | var | let | const |
|---|---|---|---|
| scope | the whole function | the block `{ }` | the block `{ }` |
| reassign | yes | yes | no |
| use it? | no, old code only | when the value changes | by default |

`var` leaks out of blocks and can be used before its line (as `undefined`), which hides bugs. Modern code uses `const` and `let`.

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 2:36:57 to 2:47:17. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
for (var i = 0; i < 3; i++) {}
console.log(i);   // 3: var leaked out of the loop
for (let j = 0; j < 3; j++) {}
// console.log(j); // ReferenceError: j stays inside the loop
```
