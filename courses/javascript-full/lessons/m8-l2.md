# Events

The page tells you when something happens: a click, a key, a form being sent.

```javascript
const button = document.querySelector("button");
button.addEventListener("click", (event) => {
  console.log("Clicked!", event.target);
});

const form = document.querySelector("form");
form.addEventListener("submit", (event) => {
  event.preventDefault();        // stop the page from reloading
  const text = form.querySelector("input").value;
  console.log("New task:", text);
});
```

**Event delegation:** instead of a listener on every item, put one on the list and check `event.target`. It also works for items added later. You'll use it in the project.
