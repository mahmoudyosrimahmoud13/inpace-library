# Writing good functions

- **One job per function**, and a name that says it: `totalMinutes`, `isValidEmail`.
- **Pure when you can:** same input, same output, no changes outside. Pure functions are easy to test.
- **Return early** for bad input instead of deep nesting.

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 1:41:11 to 1:43:38. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
function discount(price, percent) {
  if (price < 0 || percent < 0 || percent > 100) return null;   // return early
  return price - (price * percent) / 100;
}
console.log(discount(200, 25));   // 150
console.log(discount(200, 120));  // null
```
