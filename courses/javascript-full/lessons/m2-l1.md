# Math with numbers

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 0:14:05 to 0:21:19. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
console.log(7 + 2, 7 - 2, 7 * 2, 7 / 2);  // 9 5 14 3.5
console.log(7 % 2);       // 1: the remainder (is 7 odd? yes)
console.log(2 ** 10);     // 1024: power

let count = 0;
count += 5;               // count = count + 5
count++;                  // add 1
console.log(count);       // 6

console.log(0.1 + 0.2);                 // 0.30000000000000004
console.log((0.1 + 0.2).toFixed(2));    // "0.30"
console.log(Math.round(2.6), Math.floor(2.6), Math.max(3, 9, 4));  // 3 2 9
console.log(Math.floor(Math.random() * 6) + 1);  // a dice: 1 to 6
```

**Decimals are not exact** (0.1 + 0.2): for money, count in cents (whole numbers) or round when you show the value.

**From text to number:** `Number("42")` gives 42, `parseInt("42px")` gives 42, and `Number("abc")` gives `NaN` (not a number). Check with `Number.isNaN(x)`.
