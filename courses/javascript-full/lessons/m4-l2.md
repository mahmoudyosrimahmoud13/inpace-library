# Loops: for, while, for...of

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 2:10:15 to 2:24:12. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
for (let i = 1; i <= 5; i++) {   // start; condition; step
  console.log(i);                  // 1 2 3 4 5
}

const minutes = [25, 40, 15];
let total = 0;
for (const m of minutes) {       // each value: the easiest loop for arrays
  total += m;
}
console.log(total);              // 80

let n = 3;
while (n > 0) {                  // repeat while the condition is true
  console.log(n);
  n--;
}
```

Use `break` to leave a loop early and `continue` to skip to the next round. A loop whose condition never becomes false runs forever: check that something changes every round.
