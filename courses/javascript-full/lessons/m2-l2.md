# Strings

> **Optional video above.** Part of freeCodeCamp's *Learn JavaScript, Full Course for Beginners* (Beau Carnes), from 0:21:19 to 0:36:28. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```javascript
const first = "Omar";
const last = 'Hassan';
const full = first + " " + last;         // joining with +
console.log(full.length);                 // 11
console.log(full[0], full.at(-1));        // "O" "n"
console.log(full.toUpperCase());          // "OMAR HASSAN"
console.log(full.includes("Has"));        // true
console.log("  hi  ".trim());             // "hi"
console.log("a,b,c".split(","));          // ["a", "b", "c"]
console.log("ha".repeat(3));              // "hahaha"
console.log(full.slice(0, 4));            // "Omar"
console.log(full.replace("Omar", "Ali")); // "Ali Hassan"
```

**Strings are immutable:** methods return a new string; `full[0] = "A"` does nothing. Escape a quote inside a string with `\"`, and a new line is `\n`.
