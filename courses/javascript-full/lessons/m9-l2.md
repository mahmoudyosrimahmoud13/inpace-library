# async, await and fetch

```javascript
async function getUser(id) {
  const res = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);   // fetch doesn't throw on 404 or 500
  return res.json();                                      // also a promise
}

try {
  const user = await getUser(1);       // await works at the top level of a module
  console.log(user.name);

  // Several requests at once:
  const [a, b] = await Promise.all([getUser(2), getUser(3)]);
  console.log(a.name, b.name);
} catch (error) {
  console.log("Could not load:", error.message);
}
```

Check `res.ok`: fetch only rejects when the network fails, not on a 404 or 500. And always handle the error: show the user a friendly message.
