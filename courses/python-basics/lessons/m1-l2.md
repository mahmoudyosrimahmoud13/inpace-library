# Printing and simple math

`print()` shows something on the screen. Whatever you put between the brackets gets displayed.

```python
print("Hello!")
print(2 + 3)
```

This shows:

```
Hello!
5
```

## Text vs numbers

- Text goes inside quotes: `"Hello"`. Python calls text a **string**.
- Numbers don't need quotes: `42`.

## Math you can use

| Symbol | Meaning | Example | Result |
|---|---|---|---|
| `+` | add | `4 + 2` | `6` |
| `-` | subtract | `4 - 2` | `2` |
| `*` | multiply | `4 * 2` | `8` |
| `/` | divide | `4 / 2` | `2.0` |

Try printing a few calculations of your own before moving on.
