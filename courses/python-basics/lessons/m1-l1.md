# What is Python?

Python is a programming language: a way to give a computer clear, step-by-step instructions.

People like Python because it reads almost like English. It's used for websites, data analysis, automation, games, and artificial intelligence.

## How a program runs

1. You write instructions in a text file that ends in `.py`.
2. The Python program reads your file from top to bottom.
3. It does each instruction in order.

## Trying it without installing anything

You can practice in your browser at sites like **python.org/shell**, or install Python from **python.org** and use the editor it comes with (IDLE).
