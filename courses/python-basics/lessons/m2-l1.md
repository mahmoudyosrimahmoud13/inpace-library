# Variables

A **variable** is a name that holds a value, like a labeled box.

```python
name = "Sara"
age = 27
print(name)
print(age + 1)
```

The `=` sign means "put this value in the box", not "is equal to".

## Changing a variable

You can put a new value in the same box at any time:

```python
score = 10
score = score + 5
print(score)   # 15
```

## Good names

- Use clear names: `price`, `total_hours`, `city`.
- No spaces: use `_` instead (`first_name`).
- Names can't start with a number.
