# Lists

A **list** holds many values in order, inside square brackets.

```python
groceries = ["bread", "eggs", "milk"]
print(groceries)
print(len(groceries))   # 3
```

## Getting one item

Items are counted from **0**, not 1:

```python
print(groceries[0])   # bread
print(groceries[2])   # milk
```

## Adding an item

```python
groceries.append("tea")
print(groceries)   # ['bread', 'eggs', 'milk', 'tea']
```

`len()` tells you how many items a list has. You'll use it a lot.
