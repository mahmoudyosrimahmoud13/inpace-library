# Read: change of variables and inverse transform (6.7–6.8)

If you know the distribution of X and set Y = g(X), what is the distribution of Y?

**Distribution function technique (6.7.1)**: compute F_Y(y) = P(g(X) ≤ y) using X's distribution, then differentiate.
Example: X uniform on (0, 1), Y = X² → F_Y(y) = √y → f_Y(y) = 1/(2√y).

**Probability integral transform**: if X has CDF F, then F(X) is uniform on (0, 1). Run it backwards and you can sample
from any distribution with an invertible CDF: draw u uniform, return F⁻¹(u) (**inverse transform sampling**).

**Change of variables (6.7.2)**: for an invertible, differentiable g,
f_Y(y) = f_X(g⁻¹(y)) · |det J_{g⁻¹}(y)|. The **Jacobian determinant** from course 2 measures how much the map squashes
or stretches volume, and the density must change in the opposite way so total probability stays 1. Normalizing flows
(a family of generative models) are built on exactly this formula.
