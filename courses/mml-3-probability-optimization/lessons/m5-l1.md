# Read: conjugacy and the exponential family (6.6)

**Some distributions you should know (6.6.1)**: Bernoulli (one coin flip), Binomial (number of heads), Beta (a
distribution over probabilities μ ∈ [0, 1]).

**Conjugacy (6.6.2)**: a prior is **conjugate** to a likelihood if the posterior has the same form as the prior.
Then Bayesian updating is just updating a few numbers.

![Beta prior + coin flips = Beta posterior, sharpening around the true value](beta_update.png)

- Beta(α, β) prior + h heads and t tails (Bernoulli/Binomial likelihood) → **Beta(α + h, β + t)**. α and β behave like
  "imaginary earlier flips".
- The book's table lists other pairs: Gaussian–Gaussian (for the mean), Gamma–Poisson, Dirichlet–Categorical, …

**Sufficient statistics (6.6.3)**: a summary of the data that contains everything the likelihood needs (here: the
number of heads and the number of flips).

**Exponential family (6.6.4)**: p(x | θ) = h(x) exp(⟨θ, φ(x)⟩ − A(θ)). Bernoulli, Binomial, Gaussian, Beta, Poisson
all fit. Benefits: finite sufficient statistics φ(x), conjugate priors always exist, and the maximum likelihood
problem is concave. Read for the idea; don't memorize the forms.
