# Read: construction of a probability space (6.1)

Section 6.1 sets the vocabulary. Read it once for the ideas; you don't need measure theory to follow the rest.

- A **probability space** has a **sample space** Ω (all outcomes), an **event space** (the sets of outcomes we can
  ask about) and a **probability** P that gives each event a number in [0, 1], with P(Ω) = 1.
- A **random variable** X is a function from outcomes to numbers (or vectors). We usually forget Ω and work with
  the distribution of X directly.
- **Two interpretations (6.1.1)**: *frequentist* (probability = long-run frequency) and *Bayesian* (probability =
  degree of belief, updated with data). The book uses both; machine learning needs both.
- **Statistics vs probability**: probability goes from a model to data ("what data would this model produce?"),
  statistics goes from data to a model ("which model explains these data?"). Learning is the second.

The two-coin example (drawing coins from a bag and counting euros) is worth working through: it shows how a random
variable's distribution comes from the underlying probability space.
