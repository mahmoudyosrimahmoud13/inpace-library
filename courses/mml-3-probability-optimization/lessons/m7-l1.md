# Read: optimization using gradient descent (7.1)

Training a model means minimizing a loss. Chapter 7 is about how.

![Gradient descent with three step sizes: too small crawls, too big bounces](step_sizes.png)

- **Gradient descent**: x_{i+1} = x_i − γ_i (∇f(x_i))ᵀ. Each step goes downhill along the steepest direction. It finds a
  **local** minimum; for convex functions (day 9), local = global.
- **Step size (7.1.1)**: too small → slow; too large → oscillation or divergence. The book's heuristics adapt it: if f
  went up, undo the step and shrink γ; if it went down, try a bigger γ.
- **Condition number**: on a long, narrow valley (one direction much more curved than another) gradient descent
  zig-zags. Preconditioning rescales the problem to fix it.
- **Momentum (7.1.2)**: add a fraction α of the previous step. Oscillations cancel out; consistent directions speed up.
- **Stochastic gradient descent (7.1.3)**: when the loss is a sum over N examples, estimate the gradient from a
  **mini-batch**. Noisy, but each step is far cheaper, and the noise can even help escape bad regions. Every deep
  learning model trains this way (Adam and friends are SGD with adaptive step sizes and momentum).
