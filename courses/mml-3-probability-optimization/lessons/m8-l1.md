# Read: constrained optimization (7.2)

Many problems have constraints: probabilities must sum to 1, a budget must hold, a vector must have length 1 (PCA!).

![Maximize x + y on a circle: at the best point the gradients line up](lagrange.png)

- **Idea**: at the best point on a constraint g(x) = 0, you can't improve f by moving along the constraint, so ∇f must
  be **parallel** to ∇g: ∇f = λ∇g. λ is the **Lagrange multiplier**.
- **Lagrangian**: 𝔏(x, λ) = f(x) + Σᵢ λᵢgᵢ(x). Set all its partial derivatives to 0 to find candidates.
- **Inequality constraints** gᵢ(x) ≤ 0 need λᵢ ≥ 0 (and the KKT conditions).
- **Duality**: minimize 𝔏 over x for fixed λ to get the **dual function** D(λ). It's always a lower bound on the
  primal optimum (weak duality), and maximizing it is often easier. The SVM in course 4 is solved through its dual.

**Do on paper:** the example in the book, then: maximize x + y on the unit circle (answer √2 at x = y = 1/√2).
