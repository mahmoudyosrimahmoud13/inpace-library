# تعلم Git + GitHub درس 04# - طريقة عمل Add و Reset و Commit وشرح جميل المراحل

## ماذا تراقب في الفيديو
ركّز على المناطق الثلاث التي يمر بها الملف، وعلى الفرق بين `add` و`commit`. هذا أهم درس في الوحدة.

## الأفكار الأساسية
يمر كل ملف في Git بثلاث مناطق:

1. **Working Directory (منطقة العمل):** الملفات التي تعدّل عليها الآن على جهازك.
2. **Staging Area (منطقة التجهيز):** منطقة وسيطة تجهّز فيها ما تريد حفظه.
3. **Local Repository (المستودع المحلي):** مكان حفظ النسخ النهائية، أي الـ Commits.

```mermaid
flowchart LR
  A["Working Directory"] -- "git add" --> B["Staging Area"]
  B -- "git commit" --> C["Local Repository"]
  B -- "git reset" --> A
```

الأوامر:

```bash
git status                     # ما حالة ملفاتي الآن؟
git add index.html             # انقل ملفاً إلى منطقة التجهيز
git add .                      # انقل كل التعديلات
git reset index.html           # أرجع الملف من التجهيز إن أضفته بالخطأ
git commit -m "Add homepage"   # ثبّت التعديلات مع رسالة واضحة
```

لماذا نحتاج منطقة التجهيز؟ لأنك قد تعدّل خمسة ملفات وتريد حفظ اثنين منها فقط في commit مستقل.

نصيحة: اجعل رسالة الـ commit تصف ما أنجزته، فسترجع إليها لاحقاً.

## ملخص
`add` ينقل التعديلات إلى التجهيز، و`reset` يعيدها عند الخطأ، و`commit` يثبّتها في المستودع المحلي مع رسالة تصف العمل.
