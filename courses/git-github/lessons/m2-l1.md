# تعلم Git + GitHub درس 05# - إرسال التعديلات من Local إلى Remote بواسطة Push

## ماذا تراقب في الفيديو
انتبه لكيفية ربط المستودع المحلي بـ GitHub، ولما يطلبه GitHub منك من توثيق عند الرفع.

## الأفكار الأساسية
الـ commit يحفظ التعديل على جهازك فقط. حتى يراه غيرك يجب أن ترسله إلى GitHub.

**الخطوة 1: ربط المستودع المحلي بالسحابي:**

```bash
git remote add origin https://github.com/اسمك/اسم-المستودع.git
```

هذا الأمر يعطي المستودع البعيد اسماً هو `origin` ويربطه برابطه.

**الخطوة 2: الرفع:**

```bash
git push
```

هذا يرسل الـ commits التي سجلتها إلى GitHub.

```mermaid
flowchart LR
  A["commit على جهازك"] -- "git push" --> B["GitHub"]
  B --> C["الآخرون يرون عملك"]
```

**التوثيق (Authentication):** يطلب GitHub إثبات أنك صاحب الحساب عند الرفع. يشرح الدرس طريقة التوثيق بـ **Personal Access Token**، وهي رمز سري تنشئه من إعدادات حسابك يعمل بدل كلمة المرور. لا تشارك هذا الرمز مع أحد.

## ملخص
`remote add origin` يربط، و`push` يرسل، ويحتاج الرفع إلى توثيق حسابك مثل الـ Token.
