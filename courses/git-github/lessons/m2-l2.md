# تعلم Git + GitHub درس 06# - جلب التعديلات من Remote إلى Local بواسطة Pull

## ماذا تراقب في الفيديو
الدرس يحاكي عملاً جماعياً. راقب ماذا يحدث لمشروعك على جهازك بعد أن يرفع زميل تعديلاته.

## الأفكار الأساسية
تخيل أن زميلك عدّل الكود ورفعه إلى GitHub. نسختك على جهازك لا تعرف بذلك تلقائياً، وتحتاج أن تحدّثها:

```bash
git pull
```

هذا الأمر يجلب أحدث التعديلات من المستودع السحابي ويدمجها مع مشروعك المحلي.

```mermaid
flowchart LR
  A["زميلك يرفع تعديلاً"] --> B["GitHub"]
  B -- "git pull" --> C["نسختك محدّثة"]
```

عادة جيدة: نفّذ `git pull` قبل أن تبدأ العمل كل مرة، حتى تعمل على آخر نسخة وتتجنب التعارضات.

## ملخص
`push` يرسل عملك، و`pull` يجلب عمل الآخرين ويدمجه في نسختك. نفّذ `pull` قبل أن تبدأ العمل.
