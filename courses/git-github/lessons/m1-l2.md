# تعلم Git + GitHub درس 02# - ما هو ال Git + Github ولماذا يجب أن أتعلمهم الجزء الثاني

## ماذا تراقب في الفيديو
هذا الدرس يشرح مصطلحات ستسمعها في كل حلقات الدورة. انتبه للفرق بين Local وRemote، ولمعنى الفرع (Branch).

## الأفكار الأساسية
**المستودع (Repository):** هو المجلد الأساسي الذي يحوي ملفات مشروعك مع تاريخه بالكامل.

**الفرع (Branch):** مسار تطوير مستقل تجرب فيه ميزة جديدة دون أن تخرّب الكود الأصلي (الفرع الرئيسي `main`).

**Local مقابل Remote:**
- **Local:** المستودع الذي على جهازك.
- **Remote:** المستودع المخزن على خوادم الإنترنت مثل GitHub.

**أوامر أساسية** سنتعلمها بالتفصيل لاحقاً: `clone` ينسخ مستودعاً من الإنترنت إلى جهازك، و`push` يرسل تعديلاتك إلى الإنترنت، و`pull` يجلب التعديلات الجديدة منه.

```mermaid
flowchart LR
  R["Remote على GitHub"] -- "clone" --> L["Local على جهازك"]
  L -- "push" --> R
  R -- "pull" --> L
```

والفرق بين الاسمين: **Git** هو البرنامج الذي يتتبع تغييراتك، و**GitHub** موقع يستضيف مستودعاتك على الإنترنت.

## ملخص
المستودع هو المشروع مع تاريخه، والفرع مسار مستقل للتجربة، وLocal على جهازك وRemote على الإنترنت، وتنتقل التعديلات بينهما بـ clone وpush وpull.
