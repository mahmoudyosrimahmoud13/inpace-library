# تعلم Git + GitHub درس 13# - تعلم كل شيء عن ال Stash وتخزين الملفات الجزء الأول

## ماذا تراقب في الفيديو
انتبه للموقف الذي يحتاج إلى الـ stash، وللحال التي يصير عليها مجلدك بعد تنفيذه.

## الأفكار الأساسية
تخيل أنك تعدّل ملفات ولم تنهِ العمل، ثم تضطر للانتقال لفرع آخر لإصلاح مشكلة طارئة. تعديلاتك غير مثبتة (Uncommitted)، ولا تريد عمل commit لشيء غير جاهز ولا تريد خسارة عملك.

الحل **`git stash`**: يضع تعديلاتك في صندوق حفظ مؤقت، ويصير مجلد العمل نظيفاً لتبدأ مهمة أخرى:

```bash
git stash              # خزّن التعديلات مؤقتاً
git switch other-branch
# ... أصلح المشكلة الطارئة ...
git switch my-branch
git stash pop          # أرجع تعديلاتك
```

  A["تعديلات غير مكتملة"] -- "git stash" --> B["صندوق حفظ مؤقت"]

## ملخص
الـ Stash يحفظ تعديلاتك غير المثبتة مؤقتاً ويفرّغ مجلد العمل، لتنتقل إلى مهمة أخرى ثم تسترجع تعديلاتك.
