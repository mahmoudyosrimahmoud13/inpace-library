# تعلم Git + GitHub درس 08# - كيفية إنشاء Github Public Key وتجربة الإتصال بالموقع

## ماذا تراقب في الفيديو
راقب أي مفتاح تنسخه إلى GitHub، وكيف يختبر الدرس نجاح الاتصال.

## الأفكار الأساسية
يمكنك تأمين الاتصال بين جهازك وGitHub ببروتوكول **SSH** بدل كلمة المرور أو الـ Token. تعتمد الطريقة على زوج مفاتيح:

- **المفتاح الخاص (Private):** يبقى على جهازك ولا يُشارك مع أحد أبداً.
- **المفتاح العام (Public):** تنسخه وتضعه في إعدادات حسابك على GitHub.

**الخطوات:**

```bash
ssh-keygen -t ed25519 -C "ahmed@example.com"   # ولّد المفتاحين
cat ~/.ssh/id_ed25519.pub                       # اعرض المفتاح العام لتنسخه
```

ثم في GitHub: **Settings ثم SSH and GPG keys ثم New SSH key** والصق المفتاح العام. وأخيراً اختبر الاتصال:

```bash
ssh -T git@github.com
```

إن ظهرت رسالة ترحيب باسم حسابك فقد نجح الاتصال.

ملاحظة: قد يستخدم الفيديو نوعاً أقدم من المفاتيح هو RSA، والفكرة واحدة.

```mermaid
flowchart LR
  A["ssh-keygen"] --> B["مفتاح خاص + مفتاح عام"]
  B --> C["المفتاح العام في GitHub"]
  C --> D["ssh -T git@github.com"]
  D --> E["اتصال ناجح"]
```

## ملخص
تولّد المفتاحين بـ `ssh-keygen`، وتضع العام في حسابك على GitHub وتحتفظ بالخاص سراً، ثم تختبر الاتصال بـ `ssh -T git@github.com`.
