# تعلم Git + GitHub درس 09# - كيفية عمل Repo من مشروع موجود مسبقا

## ماذا تراقب في الفيديو
الدرس يعكس ما تعلمته في الدرس 03. انتبه لترتيب الخطوات من أول `git init` حتى أول `push`.

## الأفكار الأساسية
في الدرس 03 بدأت من مستودع على GitHub ونسخته. لكن قد يكون عندك مشروع جاهز على جهازك وتريد رفعه لأول مرة. الخطوات:

```bash
cd my-project
git init                                    # حوّل المجلد إلى مستودع Git
git remote add origin https://github.com/اسمك/my-project.git
git add .
git commit -m "First commit"
git push -u origin main                     # أول رفع
```

- `git init` يهيّئ المجلد ليصير مستودع Git.
- `git remote add` يربطه بمستودع أنشأته على GitHub.
- الخيار `-u` يجعل Git يتذكر الربط، فتكتفي لاحقاً بـ `git push`.

```mermaid
flowchart LR
  A["مشروع عادي"] -- "git init" --> B["مستودع محلي"]
  B -- "remote add" --> C["ربط بـ GitHub"]
  C -- "add + commit + push" --> D["المشروع على GitHub"]
```

ملاحظة: إن كان اسم فرعك `master` بدل `main`، فاستخدم الاسم الذي يظهر عندك بأمر `git branch`.

## ملخص
`init` ثم ربط بالـ remote ثم `add` و`commit` ثم `push -u`، وبهذا يصير أي مشروع جاهز مستودعاً على GitHub.
