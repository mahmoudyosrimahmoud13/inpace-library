# تعلم Git + GitHub درس 01# - ما هو ال Git + Github ولماذا يجب أن أتعلمهم الجزء الأول

## ماذا تراقب في الفيديو
انتبه إلى المشاكل التي يواجهها المبرمج بدون أداة لإدارة النسخ، وإلى معنى كلمة "موزع" في وصف Git.

## الأفكار الأساسية
تخيل أنك تحفظ مشروعك بأسماء مثل `Project_v1` ثم `Project_v2` ثم `Project_final`. بعد فترة سيحدث واحد من هذه الأمور:
- تضيع بعض الأكواد.
- تعدّل ملفاً بالخطأ ولا تعرف كيف ترجع عنه.
- لا تعرف ما الذي تغيّر بين نسختين.

**نظام إدارة النسخ (Version Control)** يحل هذه المشاكل. هو يسجل كل تغيير في ملفاتك، ويتيح لك الرجوع لأي نقطة قديمة.

**Git** هو نظام من هذا النوع، وهو **نظام موزع (Distributed)**. معنى ذلك أن كل مطور يحتفظ على جهازه بنسخة كاملة من المشروع ومن تاريخه. ويصلح Git لمن يعمل منفرداً ولفريق كبير.

```mermaid
flowchart LR
  A["بدون Git: نسخ كثيرة ومربكة"] --> B["مع Git: تاريخ واحد منظم"]
  B --> C["رجوع لأي نقطة سابقة"]
  B --> D["عمل جماعي دون فوضى"]
```

## ملخص
Git نظام موزع يتتبع تغييرات مشروعك ويحفظ تاريخه، فتتجنب ضياع الأكواد والتعديل الخاطئ وفوضى النسخ المتعددة.
