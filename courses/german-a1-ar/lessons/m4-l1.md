# السؤال عن الطريق

سمير يبحث عن صيدلية ويسأل رجلًا في الشارع، مستخدمًا Sie. استمع لـ es gibt وeinen.

## استمع أولًا: المحادثة

**هل توجد صيدلية هنا؟**

| الألمانية | المعنى |
|---|---|
| **Samir:** Entschuldigung, gibt es hier eine Apotheke? | لو سمحت، هل توجد صيدلية هنا؟ |
| **Mann:** Ja, in der Bahnhofstraße gibt es eine. | نعم، توجد واحدة في شارع بانهوف. |
| **Samir:** Ist das weit? | هل هي بعيدة؟ |
| **Mann:** Nein, nur fünf Minuten zu Fuß. Gehen Sie hier geradeaus und dann an der Ampel links. | لا، خمس دقائق فقط مشيًا. امشِ هنا على طول ثم يسارًا عند الإشارة. |
| **Samir:** Geradeaus und an der Ampel links... | على طول ثم يسارًا عند الإشارة... |
| **Mann:** Genau. Die Apotheke ist neben der Bank, gegenüber vom Supermarkt. | بالضبط. الصيدلية بجوار البنك، أمام السوبرماركت. |
| **Samir:** Und gibt es dort auch einen Geldautomaten? | وهل يوجد هناك صراف آلي أيضًا؟ |
| **Mann:** Ja, die Bank hat einen. Kein Problem. | نعم، البنك عنده واحد. لا مشكلة. |
| **Samir:** Vielen Dank! Schönen Tag noch! | شكرًا جزيلًا! أتمنى لك يومًا سعيدًا! |

## قلّد الكلام (Shadowing)

اقرأ المحادثة بصوت عالٍ **ثلاث مرات**: أولًا ببطء، ثم بسرعة عادية، ثم دون أن تنظر إلى عمود المعنى. ولو عندك الصوت من الروابط بالأسفل، أوقفه بعد كل جملة وقلّد إيقاع المتكلم ولحن صوته، لا الكلمات فقط. هذا اسمه **التقليد (Shadowing)**، وهو يدرّب أذنك ولسانك معًا.

## كلمات وعبارات احفظها

| العبارة | المعنى |
|---|---|
| Entschuldigung, ... | لو سمحت، ... |
| Gibt es hier einen / eine / ein...? | هل يوجد هنا...؟ |
| Wo ist der Bahnhof? | أين المحطة؟ |
| Ist das weit? / Das ist in der Nähe. | هل هو بعيد؟ / إنه قريب. |
| geradeaus | على طول |
| links / rechts | يسار / يمين |
| an der Ampel / an der Ecke | عند الإشارة / عند الناصية |
| neben / gegenüber von | بجوار / أمام |
| fünf Minuten zu Fuß | خمس دقائق مشيًا |
| mit dem Bus / mit der U-Bahn | بالأوتوبيس / بالمترو |
| Vielen Dank! | شكرًا جزيلًا! |
| Schönen Tag noch! | أتمنى لك يومًا سعيدًا! |

## انطقها صح

**حرف r الألماني.** في أول المقطع، **r** تُنطق من آخر الحلق، مثل الغين العربية الخفيفة: *rechts* و*Restaurant* و*Straße*. هذا الصوت سهل عليك: قل غينًا خفيفة جدًا. وفي آخر الكلمة وفي **-er**، تكاد تختفي وتصبح صوت "آ" قصيرًا: *Lehrer* ("ليرا")، و*der* و*hier* و*Uhr*.

قل: *rechts, Ampel, Straße, Lehrer, Supermarkt, hier*.
