# المضارع: النهايات

> **فيديو اختياري في الأعلى:** فيلم «Nicos Weg» (مستوى A1) من Deutsche Welle، الجزء 3 من 6: تابع قصة نيكو الذي وصل إلى ألمانيا لا يعرف كلمة، واسمع الألمانية الحقيقية بالمستوى نفسه. الفيلم عليه ترجمات بلغات كثيرة. الشرح كامل في النص أدناه، فشاهده إن كان يفيدك، وكرّر الجمل بصوت عالٍ بعد المتكلمين.
>
> الترجمة: اضغط **CC** لترجمة ألمانية، أو **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

احذف **-en** من المصدر وأضف النهاية:

| | wohnen (يسكن) | arbeiten (يعمل) |
|---|---|---|
| ich | wohn**e** | arbeit**e** |
| du | wohn**st** | arbeit**est** |
| er / sie / es | wohn**t** | arbeit**et** |
| wir | wohn**en** | arbeit**en** |
| ihr | wohn**t** | arbeit**et** |
| sie / Sie | wohn**en** | arbeit**en** |

إذا انتهى الجذر بـ -t أو -d نضيف e للنطق: *du arbeitest، er findet*.

## أفعال يتغير حرفها مع du و er/sie/es فقط

| e → i / ie | a → ä |
|---|---|
| sprechen: du spr**i**chst، er spr**i**cht | fahren: du f**ä**hrst، er f**ä**hrt |
| essen: du **isst**، er **isst** | schlafen: du schl**ä**fst |
| lesen: du l**ie**st، er l**ie**st | laufen (au→äu): er l**äu**ft |
| nehmen: du n**imm**st، er n**imm**t | |
| sehen: du s**ie**hst | |

## الألماني ليس فيه «أنا أعمل الآن» منفصلة

*Ich arbeite* = أعمل / أنا أعمل الآن. وللتأكيد: *Ich arbeite gerade.*

## تمرين

(du) fahren، (er) sprechen، (ich) lernen، (sie) lesen، (wir) essen، (du) arbeiten.

**الإجابات:** fährst، spricht، lerne، liest، essen، arbeitest.
