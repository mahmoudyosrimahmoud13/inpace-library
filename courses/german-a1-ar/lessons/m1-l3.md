# النطق: ä ö ü ß ch

> **فيديو اختياري في الأعلى:** فيلم «Nicos Weg» (مستوى A1) من Deutsche Welle، الجزء 1 من 6: تابع قصة نيكو الذي وصل إلى ألمانيا لا يعرف كلمة، واسمع الألمانية الحقيقية بالمستوى نفسه. الفيلم عليه ترجمات بلغات كثيرة. الشرح كامل في النص أدناه، فشاهده إن كان يفيدك، وكرّر الجمل بصوت عالٍ بعد المتكلمين.
>
> الترجمة: اضغط **CC** لترجمة ألمانية، أو **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

## حروف تختلف عن الإنجليزي

| الحرف | يُنطق | مثال |
|---|---|---|
| **w** | ڤ (v) | *Wasser* "ڤاسر" |
| **v** | ف غالبًا | *Vater* "فاتر" |
| **z** | تس | *Zeit* "تسايت" |
| **s** قبل حرف متحرك | ز | *Sonne* "زونه" |
| **ß** | سين قوية | *Straße* "شتراسه" |
| **sch** | ش | *Schule* "شوله" |
| **st / sp** في أول الكلمة | شت / شب | *Stadt* "شتات"، *spielen* "شبيلن" |
| **j** | ي | *ja* "يا" |
| **ch** بعد a, o, u | خاء | *Buch* "بوخ" |
| **ch** بعد e, i, ä, ö, ü | حاء خفيفة جدًا (مثل الهمس) | *ich* "إِح" |
| **r** | غالبًا غين خفيفة من الحلق، وفي آخر الكلمة تكاد تختفي | *rot*، *Vater* |

## الحروف المتحركة

| | يُنطق | مثال |
|---|---|---|
| **ei** | آي | *drei* "دراي" |
| **ie** | إي طويلة | *Liebe* "ليبه" |
| **eu / äu** | أوي | *neu* "نوي"، *Häuser* |
| **ä** | إيه مفتوحة | *Käse* |
| **ö** | قل «إي» وشفتاك مستديرتان كأنك تقول «أو» | *schön* |
| **ü** | قل «إي» وشفتاك مستديرتان جدًا | *müde*، *Tür* |

**تمرين للعرب:** ü و ö غير موجودين في العربي. قل «إيييي» ثم دوّر شفتيك تدريجيًا وأنت تستمر: هذا هو ü.

## تمرين

اقرأ بصوت عالٍ: *Wein, wie, Zug, Straße, schön, Brötchen, ich, acht, sprechen, Tschüss, Mädchen, vier.*
