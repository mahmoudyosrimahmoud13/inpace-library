# الكلام عن عائلتك

في الاستراحة، آنا تري سمير صورة عائلتها. استمع لـ der وdie وdas ولـ mein وmeine.

## استمع أولًا: المحادثة

**صورة العائلة**

| الألمانية | المعنى |
|---|---|
| **Samir:** Ist das deine Familie? | هل هذه عائلتك؟ |
| **Anna:** Ja. Das ist mein Vater, und das ist meine Mutter. Sie wohnen in Krakau. | نعم. هذا أبي، وهذه أمي. يعيشان في كراكوف. |
| **Samir:** Und wer ist das? | ومن هذا؟ |
| **Anna:** Das ist mein Bruder Piotr. Er ist dreißig Jahre alt und hat zwei Kinder. | هذا أخي بيوتر. عمره ثلاثون سنة وعنده طفلان. |
| **Anna:** Hast du auch Geschwister? | وهل عندك إخوة أيضًا؟ |
| **Samir:** Ja, ich habe eine Schwester und zwei Brüder. Meine Schwester ist Lehrerin. | نعم، عندي أخت وأخوان. أختي معلمة. |
| **Anna:** Bist du verheiratet? | هل أنت متزوج؟ |
| **Samir:** Nein, ich bin ledig. Aber ich habe eine Katze. Sie heißt Mimi. | لا، أنا أعزب. لكن عندي قطة. اسمها ميمي. |

## قلّد الكلام (Shadowing)

اقرأ المحادثة بصوت عالٍ **ثلاث مرات**: أولًا ببطء، ثم بسرعة عادية، ثم دون أن تنظر إلى عمود المعنى. ولو عندك الصوت من الروابط بالأسفل، أوقفه بعد كل جملة وقلّد إيقاع المتكلم ولحن صوته، لا الكلمات فقط. هذا اسمه **التقليد (Shadowing)**، وهو يدرّب أذنك ولسانك معًا.

## كلمات وعبارات احفظها

| العبارة | المعنى |
|---|---|
| mein Vater / meine Mutter | أبي / أمي |
| meine Eltern | والداي |
| mein Bruder / meine Schwester | أخي / أختي |
| die Geschwister | الإخوة |
| mein Sohn / meine Tochter | ابني / ابنتي |
| mein Mann / meine Frau | زوجي / زوجتي |
| Hast du Geschwister? | عندك إخوة؟ |
| Wie alt bist du? | كم عمرك؟ |
| Ich bin dreißig (Jahre alt). | عمري ثلاثون سنة. |
| Ich bin verheiratet / ledig. | أنا متزوج / أعزب. |
| Wer ist das? | من هذا؟ |
| Das ist... | هذا / هذه... |

## انطقها صح

**تقسية الحرف الأخير.** في آخر الكلمة أو المقطع، **b وd وg** تُنطق **p وt وk**: *und* ("أونت")، و*Tag* ("تاك")، و*halb* ("هالب")، و*Kind* ("كِنت"). و**-ig** في الآخر تُنطق مثل *ich*: *ledig* و*zwanzig*.

**sch** = شين: *Schwester* = "شفيستر". وفي أول الكلمة، **st** و**sp** تُنطقان "شت" و"شب": *Stadt* = "شتات"، و*sprechen* و*Straße*.

قل: *und, Kind, Tag, ledig, Schwester, Sport, Stadt*.
