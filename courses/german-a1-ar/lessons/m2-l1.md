# sein و haben

> **فيديو اختياري في الأعلى:** فيلم «Nicos Weg» (مستوى A1) من Deutsche Welle، الجزء 2 من 6: تابع قصة نيكو الذي وصل إلى ألمانيا لا يعرف كلمة، واسمع الألمانية الحقيقية بالمستوى نفسه. الفيلم عليه ترجمات بلغات كثيرة. الشرح كامل في النص أدناه، فشاهده إن كان يفيدك، وكرّر الجمل بصوت عالٍ بعد المتكلمين.
>
> الترجمة: اضغط **CC** لترجمة ألمانية، أو **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

| | sein (يكون) | haben (يملك) |
|---|---|---|
| ich (أنا) | **bin** | **habe** |
| du (أنت) | **bist** | **hast** |
| er / sie / es (هو / هي / لغير العاقل) | **ist** | **hat** |
| wir (نحن) | **sind** | **haben** |
| ihr (أنتم) | **seid** | **habt** |
| sie / Sie (هم / حضرتك) | **sind** | **haben** |

```text
Ich bin müde.            أنا تعبان.
Sie ist Ärztin.          هي طبيبة.
Wir haben zwei Kinder.   عندنا طفلان.
Hast du Zeit?            عندك وقت؟
Ich habe Hunger / Durst. أنا جائع / عطشان (حرفيًا: عندي جوع).
```

## الضمير لازم

بعكس العربي والإسبانية، الضمير **لا يُحذف**: *Ich bin müde* وليس *Bin müde* (إلا في الكلام السريع).

## المهن بدون أداة

*Ich bin Lehrer.* (أنا مدرس) و للمؤنث أضف **-in**: *Lehrerin*، *Ärztin*، *Ingenieurin*.

## تمرين

صرّف: ich ___ (sein) Student. ___ du Geschwister? (haben) Er ___ aus Syrien. (sein) Wir ___ ein Auto. (haben)

**الإجابات:** bin، Hast، ist، haben.
