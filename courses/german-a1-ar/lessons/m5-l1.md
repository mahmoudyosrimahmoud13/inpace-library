# العائلة و mein / dein

> **فيديو اختياري في الأعلى:** فيلم «Nicos Weg» (مستوى A1) من Deutsche Welle، الجزء 5 من 6: تابع قصة نيكو الذي وصل إلى ألمانيا لا يعرف كلمة، واسمع الألمانية الحقيقية بالمستوى نفسه. الفيلم عليه ترجمات بلغات كثيرة. الشرح كامل في النص أدناه، فشاهده إن كان يفيدك، وكرّر الجمل بصوت عالٍ بعد المتكلمين.
>
> الترجمة: اضغط **CC** لترجمة ألمانية، أو **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

## العائلة

*der Vater / die Mutter* (die Eltern = الوالدان)، *der Bruder / die Schwester* (die Geschwister = الإخوة)،
*der Sohn / die Tochter*، *der Opa / die Oma*، *der Onkel / die Tante*، *der Cousin / die Cousine*، *der Mann / die Frau* (الزوج / الزوجة).

## أدوات الملكية (نهايات مثل ein)

| | مذكر ومحايد | مؤنث وجمع |
|---|---|---|
| لي | **mein** Bruder | **meine** Schwester |
| لك | **dein** Vater | **deine** Eltern |
| له | **sein** Sohn | **seine** Tochter |
| لها | **ihr** Mann | **ihre** Kinder |
| لنا | **unser** Opa | **unsere** Oma |
| لكم | **euer** Haus | **eure** Familie |
| لهم / لحضرتك | **ihr / Ihr** Auto | **ihre / Ihre** Wohnung |

**sein** = له، و **ihr** = لها: *Ali und sein Bruder*، *Lisa und ihr Bruder*.

## ملكية الأسماء

*Das ist Annas Auto.* (بدون فاصلة علوية) أو *das Auto von Anna*.

## تمرين

قدّم عائلتك في 6 جمل: *Mein Vater heißt... Meine Mutter ist... Ich habe zwei Brüder...*
