# التكاليف الملائمة: اتخاذ القرارات

في أي قرار، تهم فقط **التكاليف والإيرادات الملائمة**: مبالغ مستقبلية **تختلف** بين البدائل. تجاهل **التكاليف الغارقة** (صُرفت بالفعل) والتكاليف التي تبقى كما هي في كل الأحوال.

## 1. طلبية خاصة

فندق يريد **100 كيكة بـ 70 للواحدة** لحفل الشهر القادم. السعر العادي 120. نور لديها وقت فرن فائض. الفندق يستلم بنفسه، فلا توصيل (التكلفة المتغيّرة 40 بدل 50).

| | |
|---|---|
| إيراد إضافي (100 × 70) | 7,000 |
| تكلفة متغيّرة إضافية (100 × 40) | (4,000) |
| **ربح إضافي** | **3,000** |

التكاليف الثابتة لا تتغيّر، فهي غير ملائمة. **اقبل**، بشرط: وجود طاقة فائضة (وإلا احسب ربح الكيك العادي الضائع)، وألا يطالب الزبائن المعتادون بنفس السعر المنخفض.

## 2. التصنيع أم الشراء

نور تصنع زينة سكر لـ 200 كيكة شهريًا: تكلفة متغيّرة 8 للقطعة، ومزيّنة بدوام جزئي تكلّف 500 شهريًا وستترك لو توقفت. مورّد يعرضها بـ **9** للقطعة.

| | تصنيع | شراء |
|---|---|---|
| متغيّر (200 × 8) | 1,600 | |
| ثابت يمكن تجنّبه (المزيّنة) | 500 | |
| الشراء (200 × 9) | | 1,800 |
| **الإجمالي** | **2,100** | **1,800** |

**اشترِ**: توفّر 300 شهريًا. التكاليف المشتركة (الإيجار، الفرن) التي تبقى في كل الأحوال غير ملائمة. وازن أيضًا الجودة والانتظام.

## 3. إلغاء خط إنتاج؟

تقرير خط الكوكيز: مبيعات 6,000؛ تكاليف متغيّرة 4,000؛ تكاليف ثابتة موزّعة 3,000. "خسارة" 1,000. هل تلغيه؟

من الـ 3,000 الثابتة، فقط **1,000** يمكن تجنّبها (عامل تعبئة بدوام جزئي)؛ و2,000 نصيب من الإيجار والمرتبات تبقى.

| لو أُلغي | |
|---|---|
| هامش مساهمة ضائع | (2,000) |
| تكاليف ثابتة موفّرة | 1,000 |
| **التغيّر في الربح** | **−1,000** |

**أبقِه**: إلغاء الكوكيز يجعل المخبز *أسوأ* بـ 1,000. التكاليف الموزّعة التي لا تختفي قد تجعل منتجًا جيدًا يبدو خاسرًا.

## 4. مورد نادر

وقت الفرن محدود بـ 200 ساعة شهريًا. الكيكة (مساهمة 70) تحتاج 0.5 ساعة فرن؛ وفطيرة الفاكهة (مساهمة 40) تحتاج 0.2 ساعة.

| | الكيكة | الفطيرة |
|---|---|---|
| المساهمة للوحدة | 70 | 40 |
| ساعات الفرن للوحدة | 0.5 | 0.2 |
| **المساهمة لكل ساعة فرن** | **140** | **200** |

عندما يكون وقت الفرن هو القيد، اصنع الفطائر أولًا (حتى حدود الطلب)، ثم الكيك. **رتّب حسب المساهمة لكل وحدة من المورد النادر**، وليس حسب المساهمة للوحدة.

## قائمة مراجعة لأي قرار

1. اكتب البدائل.
2. أبقِ فقط التكاليف والإيرادات المستقبلية التي تختلف.
3. أضف تكاليف الفرصة البديلة.
4. قارن، ثم وازن ما لا تقيسه الأرقام (الجودة، الزبائن، العاملين، المخاطر).

## جرّب بنفسك

ماكينة اشتُريت العام الماضي بـ 50,000 (غارقة) يمكن تطويرها بـ 12,000 لتوفّر 5,000 سنويًا لمدة 3 سنوات. بتجاهل الفائدة، هل تطوّرها؟ وما دور الـ 50,000؟

**الإجابة:** التوفير 15,000 > 12,000، إذن **طوّرها** (مكسب 3,000). الـ 50,000 غارقة: لا دور لها.
