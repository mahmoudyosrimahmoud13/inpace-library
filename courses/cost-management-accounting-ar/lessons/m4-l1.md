# التكاليف الكلية والتكاليف المتغيّرة

طريقتان لتحديد تكلفة المخزون، وقد تعطيان **أرباحًا مختلفة** لنفس الشهر.

- **التكاليف الكلية (الاستيعابية)** (مطلوبة في القوائم المنشورة والضرائب): تكلفة المنتج تشمل **أعباء التصنيع الثابتة**. جزء من التكلفة الثابتة يبقى في المخزون حتى تُباع البضاعة.
- **التكاليف المتغيّرة** (للقرارات الداخلية): تكلفة المنتج تشمل **التكاليف الصناعية المتغيّرة فقط**. كل التكاليف الثابتة تُحمَّل على الشهر.

## شهر نور

- أنتجت **500** كيكة، وباعت **450** (50 في الفريزر لطلبات الشهر القادم)
- السعر 120؛ التكلفة الصناعية المتغيّرة 45 للكيكة (مكونات 35، علبة 5، أجر الخبّاز بالقطعة 5)؛ بيع متغيّر (توصيل) 5 للكيكة
- أعباء تصنيع ثابتة 10,000 (إيجار المطبخ، الفرن، رئيس الخبّازين)؛ بيع وإدارة ثابتة 11,000

بالتكاليف الكلية، نصيب الكيكة من الأعباء الثابتة = 10,000 ÷ 500 منتجة = **20**، فتكلفة المنتج = 45 + 20 = **65**.

**التكاليف المتغيّرة**

| | |
|---|---|
| المبيعات (450 × 120) | 54,000 |
| تكلفة المبيعات المتغيّرة (450 × 45) | (20,250) |
| بيع متغيّر (450 × 5) | (2,250) |
| **هامش المساهمة** | **31,500** |
| أعباء تصنيع ثابتة | (10,000) |
| بيع وإدارة ثابتة | (11,000) |
| **ربح التشغيل** | **10,500** |

**التكاليف الكلية**

| | |
|---|---|
| المبيعات | 54,000 |
| تكلفة المبيعات (450 × 65) | (29,250) |
| **مجمل الربح** | **24,750** |
| بيع وإدارة (2,250 + 11,000) | (13,250) |
| **ربح التشغيل** | **11,500** |

## لماذا 1,000 زيادة؟

بالتكاليف الكلية، الـ 50 كيكة غير المباعة تحمل معها 50 × 20 = **1,000** من الأعباء الثابتة في المخزون. هذه التكلفة ستظهر الشهر القادم عند بيعها. وبالتكاليف المتغيّرة، الـ 10,000 كلها حُمِّلت الآن.

| لو... | فإن |
|---|---|
| الإنتاج > المبيعات (المخزون يزيد) | ربح التكاليف الكلية **أعلى** |
| الإنتاج < المبيعات (المخزون يقل) | ربح التكاليف الكلية **أقل** |
| الإنتاج = المبيعات | نفس الربح |

> **الفرق = التغيّر في المخزون بالوحدات × نصيب الوحدة من الأعباء الثابتة** = 50 × 20 = 1,000

## لماذا يهتم المديرون؟

التكاليف الكلية تسمح للمدير بأن **يرفع الربح بمجرد إنتاج أكثر** مما يمكن بيعه: الأعباء الثابتة تختبئ في المخزن. لهذا تستخدم التقارير الداخلية غالبًا التكاليف المتغيّرة، فيتحرّك الربح مع **المبيعات** فقط، ويناسب تحليل التعادل والقرارات.

## جرّب بنفسك

أعباء ثابتة 24,000؛ أُنتجت 8,000 وحدة؛ بيعت 7,000. ربح التكاليف المتغيّرة 40,000. كم ربح التكاليف الكلية؟

**الإجابة:** نصيب الوحدة 3؛ المخزون زاد 1,000 وحدة؛ ربح التكاليف الكلية = 40,000 + 3,000 = **43,000**.
