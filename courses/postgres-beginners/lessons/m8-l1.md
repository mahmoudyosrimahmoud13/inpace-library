# IDs, UUIDs, sequences, import and export

## Identity columns and sequences

An identity column uses a **sequence** behind the scenes: a counter that hands out numbers.

- Numbers are never reused, and **gaps are normal** (a rolled-back insert still used its number). Never rely on IDs having no gaps.
- After loading data with explicit IDs, reset the counter: `SELECT setval(pg_get_serial_sequence('customers', 'id'), (SELECT max(id) FROM customers));`

## UUIDs

A UUID is a random 128-bit ID like `0b8f6a3e-...`. Use one when IDs are created in many places (apps, devices), are shown in URLs (so people can't guess the next one), or merged across databases.

```sql
CREATE TABLE api_keys (
    id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),     -- built in since Postgres 13
    owner_id   bigint NOT NULL REFERENCES customers (id),
    created_at timestamptz NOT NULL DEFAULT now()
);
```

Newer Postgres (18) adds `uuidv7()`: time-ordered UUIDs that index much better than random ones.

## Extensions

```sql
SELECT name, comment FROM pg_available_extensions ORDER BY name LIMIT 20;
CREATE EXTENSION IF NOT EXISTS pg_trgm;        -- fuzzy text search
CREATE EXTENSION IF NOT EXISTS pg_stat_statements;   -- query statistics (advanced course)
```

## CSV in and out

```text
-- from psql (works with files on YOUR computer):
\copy customers (first_name, last_name, email, country_code) FROM 'customers.csv' WITH (FORMAT csv, HEADER true)
\copy (SELECT * FROM orders WHERE status = 'paid') TO 'paid_orders.csv' WITH (FORMAT csv, HEADER true)
```

`\copy` (psql) reads and writes files on the client; plain `COPY` (SQL) reads files on the **database server** and needs special rights.

## Backups

```bash
pg_dump -Fc shop > shop.dump          # the whole database, compressed
pg_restore -d shop_copy shop.dump     # into an empty database
```
