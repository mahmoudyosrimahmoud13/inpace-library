# Calculations, aliases, COALESCE and NULLIF

```sql
SELECT id,
       total,
       total * 0.14              AS vat,
       round(total * 1.14, 2)    AS total_with_vat,
       total - 10                AS after_coupon
FROM orders
LIMIT 5;
```

- Operators: `+ - * /`, `%` (remainder), `^` (power).
- **Integer division truncates**: `7 / 2` is `3`. Write `7 / 2.0` or cast `7::numeric / 2` to get `3.5`.
- `round(x, 2)`, `ceil`, `floor`, `abs`.

## Aliases

`AS` names an output column (or a table in a query). Aliases with spaces or capitals need double quotes: `AS "Total with VAT"`.

## COALESCE: a default for NULL

```sql
SELECT first_name, COALESCE(country_code, 'unknown') AS country FROM customers;
```

`COALESCE(a, b, c)` returns the first value that isn't NULL.

## NULLIF: avoid dividing by zero

```sql
SELECT status, sum(total) / NULLIF(count(*), 0) AS avg_total FROM orders GROUP BY status;
```

`NULLIF(a, b)` returns NULL when a equals b. Dividing by NULL gives NULL instead of an error.

## CASE: if/else inside SQL

```sql
SELECT id, total,
       CASE WHEN total >= 300 THEN 'large'
            WHEN total >= 100 THEN 'medium'
            ELSE 'small' END AS size
FROM orders;

-- counting by condition in one pass
SELECT count(*) FILTER (WHERE status = 'paid')      AS paid,
       count(*) FILTER (WHERE status = 'cancelled') AS cancelled
FROM orders;
```
