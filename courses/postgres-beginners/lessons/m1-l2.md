# Install Postgres and meet psql

## Install (pick one)

| Where | How |
|---|---|
| Ubuntu / Debian | `sudo apt install postgresql` then `sudo -u postgres psql` |
| macOS | Postgres.app (easiest) or `brew install postgresql@17` |
| Windows | The EDB installer from postgresql.org (includes pgAdmin) |
| Anywhere with Docker | `docker run --name pg -e POSTGRES_PASSWORD=secret -p 5432:5432 -d postgres:17` then `docker exec -it pg psql -U postgres` |
| No install | A free cloud database (Neon, Supabase) or an online playground |

## Make yourself a user and a database

```sql
-- inside psql as the postgres superuser:
CREATE ROLE sara WITH LOGIN PASSWORD 'change-me' CREATEDB;
CREATE DATABASE shop OWNER sara;
```

```bash
psql -h localhost -U sara -d shop      # connect
```

## psql commands (backslash commands are psql's own, not SQL)

| Command | Does |
|---|---|
| `\l` | List databases |
| `\c shop` | Connect to another database |
| `\dt` | List tables |
| `\d customers` | Describe a table: columns, types, keys, indexes |
| `\dn`, `\du` | Schemas, roles |
| `\x` | Toggle expanded display (great for wide rows) |
| `\timing` | Show how long each query took |
| `\i file.sql` | Run a SQL file |
| `\?` / `\h SELECT` | Help for psql / for an SQL command |
| `\q` | Quit |

SQL statements end with a **semicolon**. If psql shows `shop-#` instead of `shop=#`, it's waiting for you to finish the statement.

## Graphical clients

pgAdmin, DBeaver and DataGrip show tables and results in a grid. Use them freely, but learn psql too: it's on every server.

## The dangerous command

```sql
DROP DATABASE shop;      -- gone, no undo, no recycle bin
```

Only run `DROP` and `DELETE` on things you've double-checked, and keep backups (`pg_dump`) of anything that matters.
