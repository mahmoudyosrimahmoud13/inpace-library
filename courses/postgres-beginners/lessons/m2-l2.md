# Inserting data, and NULL

```sql
INSERT INTO customers (first_name, last_name, email, country_code, birth_date)
VALUES ('Sara', 'Ali', 'sara@example.com', 'EG', '1998-04-12');

-- several rows at once
INSERT INTO customers (first_name, last_name, email, country_code)
VALUES ('Omar', 'Hassan', 'omar@example.com', 'EG'),
       ('Lena', 'Berg',   'lena@example.com', 'DE'),
       ('Tom',  'Reed',   'tom@example.com',  NULL);

-- see what was created, including generated id and created_at
INSERT INTO customers (first_name, last_name, email)
VALUES ('Ana', 'Lima', 'ana@example.com')
RETURNING id, created_at;
```

- List the columns you're filling. Skipped columns get their `DEFAULT` (or NULL).
- Strings use **single quotes**. Double quotes are for column and table names.
- A constraint violation (a duplicate email, a missing NOT NULL value) rejects the whole statement with a clear error.

## NULL means "unknown"

`NULL` is not zero and not an empty string. It means "no value / unknown", and it behaves differently:

```sql
SELECT NULL = NULL;          -- NULL (not true!): unknown compared with unknown is unknown
SELECT * FROM customers WHERE country_code IS NULL;     -- the right way
SELECT * FROM customers WHERE country_code IS NOT NULL;
```

## Lots of practice data

Mockaroo (mockaroo.com) generates realistic fake rows as a `.sql` file: pick columns like first name, email, country, date. Then load it:

```text
\i /path/to/customers.sql
```

Or generate rows inside Postgres:

```sql
INSERT INTO customers (first_name, last_name, email, country_code)
SELECT 'User', 'N' || g, 'user' || g || '@example.com', (ARRAY['EG','DE','US','FR'])[1 + g % 4]
FROM generate_series(1, 1000) AS g;
```
