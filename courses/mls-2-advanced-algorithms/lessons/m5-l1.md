# Softmax and its stable implementation

For `N` classes, the output layer has `N` units and **softmax**:

```text
z_j = w_j·x + b_j
a_j = e^(z_j) / Σₖ e^(z_k)        (all a_j add up to 1)
loss = −log a_y                   (the probability given to the true class)
```

With `N = 2`, softmax reduces to logistic regression.

## Numerical stability: the version you should use

Computing `a` first and then `log a` loses precision. Let the loss do both from the raw `z` (**logits**):

```python
model = Sequential([Dense(25, activation="relu"), Dense(15, activation="relu"),
                    Dense(10, activation="linear")])            # logits
model.compile(loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True))
probs = tf.nn.softmax(model(X))                                  # when you need probabilities
```

Also, `softmax(z) = softmax(z − max(z))`: subtracting the max avoids overflow in `e^z`. Writing a stable softmax is
a classic interview question.

**Multi-label** (several labels can be true at once, like "car", "bus", "person" in one photo) is different: use
`N` **sigmoid** outputs with binary cross-entropy, not softmax.
