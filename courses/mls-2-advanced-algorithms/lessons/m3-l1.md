# Matrix multiplication for whole layers

A whole layer for a whole batch is one matrix multiply:

```python
def dense(A_in, W, b, g):          # A_in: (m, n_in), W: (n_in, units), b: (units,)
    return g(A_in @ W + b)          # (m, units)
```

Rules: `(m, n) @ (n, k) → (m, k)`; the inner sizes must match. `A @ W` is `np.matmul`. GPUs are, at heart, machines
for doing this fast, which is why deep learning took off when they did.

Revise: the dot product `a·w = Σ aᵢwᵢ`, the transpose `Aᵀ` (rows become columns), and that each entry of `A @ W` is a
row of `A` dotted with a column of `W`.
