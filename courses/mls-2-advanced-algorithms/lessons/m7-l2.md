# The full cycle, and ethics

**Full cycle:** scope the project → collect data → train (with error analysis) → deploy → **monitor** → loop back.

Deployment (MLOps): an inference server with an API, logging inputs and predictions, watching for **data drift** (the
world changes), retraining, scaling. It's often more work than the model.

**Fairness and ethics:** biased hiring tools and face recognition, deepfakes, harmful content. Practical steps:
diverse teams brainstorm what could go wrong, look up industry guidelines, **audit** systems for bias across groups
before release, have a plan to roll back, and monitor for harm after.
