# Project 2: backpropagation by hand

You'll compute every gradient of a small network yourself with the chain rule, then check them two independent ways.

The code is above this text. Save it as `p2_backprop.py`.

## Read the code

- The task is "is this digit a zero?" on 200 training digits; the network is 64 → 16 (ReLU) → 1 (sigmoid).
- **`backprop()`** goes backwards: the output's gradient is simply `p - y` (sigmoid with log loss), then through `W2`,
  then through the ReLU (which passes gradient only where its input was positive), then to `W1`.
- **The gradient check** nudges one weight up and down by `1e-6` and measures how the loss changes: the numerical
  derivative. It should match backprop to many decimals.
- **`tf.GradientTape`** computes the same gradients automatically.

## Run it

```bash
python p2_backprop.py
```

The real output:

```text
1. Loss of the untrained network: 0.6934
2. d loss / d W1[3, 2]: backprop -0.03116190   numerical -0.03116190
2. d loss / d W1[40, 7]: backprop  0.00000000   numerical  0.00000000
2. d loss / d b1[0]: backprop  0.04830443   numerical  0.04830443
2. d loss / d W2[0, 0]: backprop  0.25144886   numerical  0.25144886
2. d loss / d b2[0]: backprop  0.38401517   numerical  0.38401517
   largest difference: 3.3e-11  (gradient check passed: True)
3. TensorFlow's automatic gradients equal yours: True
```

What it shows:

- **Backprop and the numerical gradients agree** to about 10 decimal places.
- One gradient is exactly 0: that hidden unit's ReLU was off for every example, so its weights get no signal.
  (A "dead ReLU".)
- **TensorFlow's automatic gradients are yours.** Automatic differentiation is backprop done by the framework.

## What to take away

- Backprop is the chain rule applied layer by layer, from the loss backwards.
- A gradient check catches wrong gradients; always run one on code you wrote yourself.
