# Forward propagation and inference in code

**Forward propagation** computes the layers left to right to get a prediction. In TensorFlow (Keras):

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense

model = Sequential([
    Dense(25, activation="relu"),
    Dense(15, activation="relu"),
    Dense(1, activation="sigmoid"),
])
x = np.array([[200.0, 17.0]])          # shape (1, 2): ONE example, as a row
p = model.predict(x)                   # shape (1, 1)
yhat = (p >= 0.5).astype(int)
```

## Data shapes (the slides spend time here for a reason)

TensorFlow wants **2-D** inputs: `(examples, features)`. `np.array([200, 17])` has shape `(2,)` and confuses it;
`[[200, 17]]` is `(1, 2)`. Tensors are TensorFlow's arrays; `.numpy()` converts back.
