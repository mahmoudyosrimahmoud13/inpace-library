# Train, cross-validation and test sets

When a model does badly, you could get more data, add or remove features, add polynomial terms, or change `λ`. Picking
well needs **evaluation**.

| Set | Typical share | Used for |
|---|---|---|
| Training | 60% | fitting `w, b` |
| Cross-validation (dev) | 20% | choosing the model: degree, `λ`, architecture |
| Test | 20% | one final, honest estimate |

Choose the model by **CV error**, then report **test error** once. If you pick using the test set, its error becomes
optimistic, because you've fitted a choice to it.

Going further: with small data, **k-fold cross-validation** rotates the validation part; for time series, always split
by time (never shuffle the future into training).
