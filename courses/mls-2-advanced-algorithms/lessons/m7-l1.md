# Error analysis, more data, transfer learning

The loop: **choose architecture → train → diagnose (bias/variance, error analysis) → repeat**.

## Error analysis

Look at ~100 misclassified CV examples and count categories (pharma spam: 21, deliberate misspellings: 3, phishing:
18...). Spend effort where the count is big. Simple, and it beats guessing.

## Getting more data, wisely

- More data of the **types the analysis says** you need.
- **Data augmentation:** distort existing examples in realistic ways (rotations, crops, noise in audio). Unrealistic
  noise doesn't help.
- **Data synthesis:** make new examples from scratch (rendered text for OCR).
- **Data-centric AI:** improve the data, not only the model.

## Transfer learning

Train (or download) a network on a huge dataset (ImageNet), then **reuse its early layers** for your task:

1. Replace the output layer.
2. Either train only the new output layer (small data) or **fine-tune** all layers (more data).

Early layers learn general features (edges, shapes) useful for many tasks. Inputs must be the same kind (images for
an image model). This is how large pre-trained language models are used today.
