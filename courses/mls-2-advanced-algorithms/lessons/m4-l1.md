# The three training steps

Same three steps as logistic regression, at any scale:

| Step | Logistic regression | Keras |
|---|---|---|
| 1. Model | `f = g(w·x + b)` | `model = Sequential([...])` |
| 2. Loss and cost | log loss | `model.compile(loss=BinaryCrossentropy())` |
| 3. Minimize | gradient descent | `model.fit(X, y, epochs=100)` |

```python
from tensorflow.keras.losses import BinaryCrossentropy, MeanSquaredError
model.compile(loss=BinaryCrossentropy())          # MeanSquaredError() for regression
model.fit(X, y, epochs=100)
```

An **epoch** is one pass over the training data. `fit` uses mini-batches (32 by default) and backprop.
