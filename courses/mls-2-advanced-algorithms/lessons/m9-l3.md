# Project 8: trees against the network

You'll compute a split's information gain by hand, then compare one tree, a random forest and gradient boosting with
the Digit reader's network.

The code is above this text. Save it as `p8_trees.py`.

## Read the code

- **`entropy()`** of the labels, in bits. The script tries every pixel with three thresholds and keeps the split with
  the largest **information gain**: the entropy before, minus the weighted entropy of the two sides.
- scikit-learn's `DecisionTreeClassifier` does the same search over every threshold.
- Then four models on the test set, with their training times.

## Run it

```bash
python p8_trees.py
```

The real output:

```text
1. Entropy of the labels: 3.32 bits (ten even classes would be 3.32)
   best first split by information gain: pixel 42 (row 5, column 2) > 0.25, gain 0.45 bits
   scikit-learn tries every threshold, not only three, and picks pixel 33 > 0.094, gain 0.47 bits

2. On the test digits:
   one decision tree           85.0%   (0.0 s)
   random forest, 300 trees    97.5%   (0.7 s)
   gradient boosting           98.1%   (1.6 s)
   neural network (project 5)  96.9%   (13.9 s)

   One tree overfits; many trees vote it away. On 64 clean pixels, ensembles of trees match or beat a small
   network, and train in seconds. Networks pull ahead on bigger images, sound and text.
```

What it shows:

- **Ten balanced classes have log2(10) = 3.32 bits of entropy**: the labels start maximally mixed.
- Your best split gains 0.45 bits; scikit-learn, trying every threshold, finds a slightly better one (0.47). Same
  method, finer search.
- **One tree reaches 85%; a forest of 300 trees 97.5%; boosting 98.1%.** Averaging many different trees cancels each
  tree's overfitting.
- **The ensembles match or beat the small network here, and train in seconds.** On images bigger than 8 × 8, sound
  and text, networks pull ahead; on tables of mixed features, boosted trees are usually the ones to beat.

## What to take away

- Trees split on the feature with the largest information gain.
- Ensembles beat single trees; on tabular data they're often the best model.
