# Adam and other layer types

**Adam** (adaptive moment estimation) keeps a separate, adapting step size per parameter: it speeds up when a
parameter keeps moving the same way and slows down when it oscillates.

```python
model.compile(optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3), loss=...)
```

It's the default choice in practice. Going further: Adam combines **momentum** (a running mean of gradients) with
**RMSProp** (a running mean of squared gradients); **AdamW** decouples weight decay and is standard for transformers.

## Layer types

- **Dense**: every unit sees all of the previous layer.
- **Convolutional**: each unit sees only a **window** (for images, a patch; for an ECG signal, a time window). Fewer
  parameters, faster, less overfitting, and it builds in the idea that nearby values belong together.
- Beyond the course: recurrent layers (sequences), attention (transformers), normalization, dropout.
