# Project 3: train it, and choose the activation

You'll train the Digit reader on all ten digits with TensorFlow, three times, changing only the hidden activation.

The code is above this text. Save it as `p3_train_activations.py`.

## Read the code

- **`model(hidden)`**: 64 → 25 → 15 → 10, with the chosen activation in the hidden layers and no activation at the
  output (raw scores, "logits"; tomorrow explains why).
- `compile` sets the optimizer (Adam), the loss and the metric; `fit` trains for 30 epochs and reports validation
  accuracy after each.

## Run it

```bash
python p3_train_activations.py
```

The real output (a point or two of difference from run to run is normal):

```text
Same network, same data, 30 epochs with Adam; only the hidden activation changes.

   linear   validation accuracy after 5 epochs 83.0%, after 30 96.1%
   sigmoid  validation accuracy after 5 epochs 49.6%, after 30 77.4%
   relu     validation accuracy after 5 epochs 78.8%, after 30 95.5%

   Linear hidden layers collapse into one linear layer: the network is just logistic regression, which is
   already strong on these clean 8x8 digits. Sigmoid learns slowly here; ReLU matches the linear model and,
   unlike it, keeps improving as the network and the data grow.
```

What it shows:

- **Linear hidden layers reach about 96%.** That's not the network being clever: stacked linear layers collapse into
  one, so this is logistic regression, which is already strong on clean 8 × 8 digits.
- **Sigmoid learns slowly**: its gradients shrink when units saturate.
- **ReLU matches the linear model** here and, unlike it, can learn curved boundaries when the problem needs them.

## Make it yours

1. Train for 100 epochs. Does ReLU pull ahead of linear?
2. Make the task harder: add random noise (`X + 0.3 * np.random.randn(...)`, clipped) to all images and compare the
   three again.

## What to take away

- Without a non-linear activation, a deep network is a linear model.
- ReLU is the default for hidden layers; sigmoid for a binary output.
