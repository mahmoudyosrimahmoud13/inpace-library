# Diagnosing bias and variance

| Training error | CV error | Diagnosis |
|---|---|---|
| high | high (similar) | **high bias** (underfit) |
| low | much higher | **high variance** (overfit) |
| high | much higher still | both |

"High" is relative to a **baseline**: human-level performance, a competing system, or a guess from experience. For
speech recognition with 10.6% human error, 10.8% training error is fine; the gap to CV matters more.

**λ:** too small → variance; too large → bias. Plot training and CV error against `λ` and pick the CV minimum.

## What to try

| Fixes high variance | Fixes high bias |
|---|---|
| More training examples | More or better features |
| Fewer features | Polynomial features |
| Larger `λ` | Smaller `λ` |
| | A bigger model |

## Neural networks change the game

A large network with good regularization almost never does worse than a small one. Recipe: does it fit the
training set well? If not, make it bigger. Does it do well on CV? If not, get more data (or regularize). Repeat.
The limits are compute and data.
