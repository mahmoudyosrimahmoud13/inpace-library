# Forward propagation from scratch, and AGI

```python
def dense(a_in, W, b, g):          # a_in: (n_in,), W: (n_in, units), b: (units,)
    units = W.shape[1]
    a_out = np.zeros(units)
    for j in range(units):
        a_out[j] = g(np.dot(W[:, j], a_in) + b[j])
    return a_out

def sequential(x, params):
    a = x
    for W, b, g in params:
        a = dense(a, W, b, g)
    return a
```

Writing this once is how you **really** understand what `Dense` does, and it's a common interview exercise.

## AGI: the slides' honest view

Narrow AI (ANI: a spam filter, a self-driving stack) has made huge progress; **AGI**, doing anything a person can, is
a different question. The "one learning algorithm" hypothesis (brain tissue rewired to process new senses) is a
reason for hope, not proof. In interviews, keep claims measured and specific.
