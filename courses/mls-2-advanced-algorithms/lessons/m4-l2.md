# Activation functions

| Activation | Formula | Use |
|---|---|---|
| Sigmoid | `1/(1+e^−z)` | output for yes/no |
| Linear | `z` | output for any real number (regression) |
| **ReLU** | `max(0, z)` | **default for hidden layers** |
| Softmax | (Day 5) | output for many classes |

**Output layer:** choose by the target: sigmoid for 0/1, linear for any number, ReLU for non-negative numbers.

**Hidden layers: why ReLU?** Faster to compute, and it's flat only on one side, so gradient descent doesn't stall as
much as with sigmoid's two flat tails.

**Why any non-linearity at all?** Without it, a stack of linear layers is just **one** linear function
(`W₂(W₁x + b₁) + b₂ = W'x + b'`). Depth would add nothing.

## Going further

- **Dying ReLU:** units stuck at `z < 0` output 0 forever. Leaky ReLU (`max(0.01z, z)`), GELU or SiLU/Swish fix or
  soften it; GELU is standard in transformers.
- Tanh is a zero-centred sigmoid, still used in RNNs.
