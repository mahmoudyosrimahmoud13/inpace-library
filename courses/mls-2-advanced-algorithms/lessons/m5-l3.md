# Project 4: softmax done safely, and Adam

You'll see why softmax needs care with numbers, and compare plain gradient descent with Adam on the Digit reader.

The code is above this text. Save it as `p4_softmax_adam.py`.

## Read the code

- **`softmax()`** subtracts each row's largest score before `exp`. Mathematically nothing changes; numerically it
  prevents overflow.
- Three trainings of the same network: SGD with learning rate 0.01, SGD with 0.1, and Adam with 0.001. The loss uses
  `from_logits=True`, so Keras applies softmax inside the loss, safely.

## Run it

```bash
python p4_softmax_adam.py
```

The real output:

```text
1. Naive softmax of [1000, 999, 998]: [nan nan nan]  <- overflow
   Safe softmax:                     [0.665 0.245 0.09 ] (same as for [2, 1, 0]: [0.665 0.245 0.09 ])
   That's why Keras wants from_logits=True: it combines softmax and the loss safely.

2. Ten digits, 64 -> 25 -> 15 -> 10, ReLU, validation accuracy by epoch:
   gradient descent (SGD, lr 0.01)  epoch 1   7.8%  epoch 5  15.9%  epoch 20  51.0%
   SGD, lr 0.1                      epoch 1  56.8%  epoch 5  88.0%  epoch 20  94.4%
   Adam, lr 0.001                   epoch 1  18.7%  epoch 5  77.4%  epoch 20  93.6%

3. The Adam model on one validation digit (a 2): 2: 0.98, 3: 0.02, 8: 0.00
```

What it shows:

- **Naive softmax of large scores is `nan`**: `exp(1000)` overflows. Subtracting the maximum gives the right answer,
  the same as for `[2, 1, 0]`.
- **SGD at 0.01 is barely learning** after 20 epochs. At 0.1 it does well, but you had to find that number.
- **Adam at its default rate** gets there without tuning, because it adapts the step size for every weight.
- The trained model is 98% sure a validation 2 is a 2.

## Make it yours

1. Try Adam with learning rates 0.0001 and 0.01. How sensitive is it, compared with SGD?
2. Remove `from_logits=True` and add `activation="softmax"` to the last layer instead. Same accuracy?

## What to take away

- Subtract the max before softmax; let the loss handle softmax with `from_logits=True`.
- Adam is a good default because it needs little tuning.
