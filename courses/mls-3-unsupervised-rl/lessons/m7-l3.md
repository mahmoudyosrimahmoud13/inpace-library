# Project 6: deep Q-learning on a continuous rover

Now the rover's position is any number from 0 to 6, and each move goes about 1 unit, with noise. No table can hold Q
for infinitely many positions, so a small neural network learns it: deep Q-learning (DQN).

The code is above this text. Save it as `p6_dqn.py`. It needs TensorFlow and takes 2 to 3 minutes.

## Read the code

- **`step(x, a)`** moves left or right by about 1 (random, spread 0.3). The episode ends at the left edge (100) or
  the right edge (40); here the reward comes on arriving.
- **`net()`**: one input (the position, scaled to 0..1), two hidden layers of 32, two outputs: Q for left and right.
- **The DQN ingredients**, as in the lesson:
  - **Experience replay**: every step goes into a buffer; training uses random batches of 64 from it, so
    consecutive, similar steps don't dominate.
  - **A target network**: the training targets `r + gamma x max Q(x')` come from a copy updated every 100 steps, so
    the goal doesn't move with every update.
  - **Epsilon-greedy**: start fully random, decay to 5% random.
- Rewards are divided by 100 for the network (targets near 0..1 train better) and multiplied back when printed.

## Run it

```bash
python p6_dqn.py
```

The real output (training is random, so your numbers will differ a little):

```text
episode 100  epsilon 0.37  policy at x = 1, 1.5, ... 5: <<<<<>>>>
episode 200  epsilon 0.13  policy at x = 1, 1.5, ... 5: <<<<<<>>>
episode 300  epsilon 0.05  policy at x = 1, 1.5, ... 5: <<<<<<>>>
episode 400  epsilon 0.05  policy at x = 1, 1.5, ... 5: <<<<<<>>>

Learned Q at x = 1, 2, 3, 4, 5 (in reward units). Here the reward comes on arriving, so from x = 1 going
left is worth about 100, from x = 2 about 50, and so on, halving with each step (gamma 0.5):
   Q(x, left)  [95.2 51.7 26.8 17.8 11.5]
   Q(x, right) [28.  11.4 13.  22.2 35.1]
```

What it shows:

- After 100 episodes the policy is already sensible: left near the 100, right near the 40.
- **The learned Q halves with each step from the left edge** (about 100, 50, 25), as gamma 0.5 says it should,
  learned from experience at positions it never saw exactly.
- Values far from the goal (17, 11) are rougher: the network sees those positions less often.

## Make it yours

1. Remove the target network (use `q` itself for the targets). Is training less stable? Run it three times.
2. Shrink the replay buffer to 64 steps. What happens?

## What to take away

- DQN replaces the Q-table with a network that generalizes across states.
- Replay, a target network and decaying exploration make it trainable.
