# PCA in 15 minutes

**Principal component analysis** finds new axes (directions) that keep as much **variance** as possible, so you can
describe data with fewer numbers.

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
Z = StandardScaler().fit_transform(X)        # scale first
pca = PCA(n_components=2).fit(Z)
X2 = pca.transform(Z)
print(pca.explained_variance_ratio_)          # how much each component keeps
```

- Mostly used today for **visualization** (squeeze 50 features to 2 or 3).
- Used less for speeding up training or compression than in the past.
- It's linear; t-SNE and UMAP make better pictures of non-linear structure (but distances in them can mislead).
- PCA ≠ linear regression: regression predicts `y` with vertical errors; PCA has no `y` and uses perpendicular
  projection.
