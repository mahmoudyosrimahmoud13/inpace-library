# Project 5: the Mars rover, solved

The lessons' Mars rover: six states, 100 at the left end, 40 at the right. You'll solve the Bellman equation exactly,
make the rover slippery, and then let it learn Q from experience alone.

The code is above this text. Save it as `p5_bellman.py`.

## Read the code

- **`q_values(gamma, misstep)`** starts with Q = 0 and applies the Bellman equation again and again:
  `Q(s, a) = R(s) + gamma x E[max over a' of Q(s', a')]`, where `s'` is where action `a` leads (the wrong way with
  probability `misstep`). The end states just keep their reward.
- **`show()`** prints both rows and the policy: in each middle state, the action with the larger Q.
- **`q_learning()`** knows nothing about the rules: it starts the rover somewhere, picks actions (random 30% of the
  time: exploration), sees what happens, and moves `Q(s, a)` a little (`alpha = 0.1`) toward
  `reward + gamma x best Q of where it landed`.

## Run it

```bash
python p5_bellman.py
```

What it shows:

- **With gamma 0.5 you get the lessons' exact numbers** (50, 25, 12.5 going left; 20 going right from state 5) and the
  policy "left, left, left, right".
- **A patient rover (0.9) always goes for the 100; an impatient one (0.3)** takes the 40 from the middle.
- **Slipping lowers every value** but doesn't change the policy here.
- **Q-learning recovers the slippery Q-table within about 2 points**, and the same policy, only from trying.

## What to take away

- The Bellman equation defines Q; iterating it solves small problems exactly.
- Q-learning estimates the same Q from experience, without knowing the rules.
