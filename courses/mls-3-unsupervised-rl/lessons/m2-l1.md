# Density estimation with Gaussians

Learn what **normal** looks like, then flag points with very low probability.

```text
μ_j = (1/m) Σᵢ x_j⁽ⁱ⁾          σ_j² = (1/m) Σᵢ (x_j⁽ⁱ⁾ − μ_j)²
p(x) = Πⱼ p(x_j; μ_j, σ_j²)     (features treated as independent)
anomaly if p(x) < ε
```

## Choosing ε and evaluating

Even though training is unsupervised, use **a few labelled anomalies**:

- Train on normal examples (say 6,000 good engines).
- CV and test sets with some known anomalies (say 10 each).
- Pick `ε` by **F1** (or precision/recall) on CV: the data is very skewed.

## Anomaly detection vs supervised learning

| Anomaly detection | Supervised |
|---|---|
| Very few positives (0-20) | Enough positives to learn from |
| **New kinds** of anomalies appear (new fraud, new failure) | Future positives look like past ones (spam) |

## Features

- Make features roughly Gaussian (`log(x + c)`, `√x`).
- **Error analysis**: look at missed anomalies and invent features that separate them (CPU load / network traffic).
