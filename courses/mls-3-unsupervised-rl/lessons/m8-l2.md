# 25 questions, short answers

1. **K-means steps?** Assign to nearest centroid, move centroids to means.
2. **Why multiple k-means starts?** Local minima.
3. **How to choose K?** By purpose; silhouette when no purpose metric.
4. **K-means limits?** Round clusters, scaling, outliers.
5. **Anomaly detection idea?** Model normal density; flag low `p(x)`.
6. **Choose ε how?** F1 on a small labelled CV set.
7. **Anomaly detection vs classification?** Few, new-looking positives vs many, repeating ones.
8. **Collaborative filtering?** Learn user and item vectors from ratings only.
9. **Cold start?** New users or items lack data; mean normalization, content features, popular items.
10. **Content-based filtering?** Networks map user and item features to vectors; dot product.
11. **Retrieval and ranking?** Fast candidate generation, then precise scoring.
12. **Implicit vs explicit feedback?** Clicks vs ratings; missing isn't negative.
13. **How would you evaluate a recommender?** Offline: precision@k, recall@k, NDCG; online: A/B tests on engagement and
    satisfaction.
14. **What's an embedding?** A learned vector where similarity means something.
15. **RL vs supervised?** Rewards vs right answers.
16. **Return and γ?** Discounted sum of rewards.
17. **Policy?** A mapping from states to actions.
18. **Q(s, a)?** Return from taking `a` in `s` then acting optimally.
19. **Bellman equation?** `Q = R + γ max Q(next)`.
20. **DQN tricks?** Replay buffer, target network (soft updates), ε-greedy.
21. **Exploration vs exploitation?** Try new actions vs use the best known.
22. **On vs off-policy?** Learn about the policy you follow vs a different (greedy) one.
23. **PCA?** Linear projection keeping maximum variance.
24. **Why scale before PCA or k-means?** Large-range features would dominate.
25. **What is RLHF?** RL on a reward model learned from human preferences.

## Design question

> "Design recommendations for an online course library (like inPace's)."

Clarify the goal (finishing courses, not just clicks). Data: enrolments, completions, ratings, course text and tags.
Retrieval: similar courses by embeddings, same tags, popular in language. Ranking: a two-tower or gradient-boosted model
predicting completion. Cold start: content features for new courses; onboarding questions for new learners. Evaluate
offline with recall@k, then A/B test completion rate. Watch fairness for small authors and filter bubbles.
