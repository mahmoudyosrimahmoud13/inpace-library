# Project 3: collaborative filtering from scratch

You'll learn a vector for every movie and every person from the ratings alone, predict ratings nobody gave, and see
what the vectors discovered.

The code is above this text. Save it as `p3_collaborative.py`. Training takes about 20 seconds.

## Read the code

- **`fit()`** builds the 1,682 × 943 rating matrix `Y` and the mask `R` (1 where a rating exists), subtracts each
  movie's mean (**mean normalization**), and minimizes the lesson's cost: squared error on known ratings only, plus
  `lambda` times the size of every vector.
- The steps use **Adam**, as the course's TensorFlow version does. Popular movies have hundreds of ratings, so their
  plain gradients are huge; Adam gives every number its own step size. (Plain gradient descent diverged on this data.)
- **`predict()`** is `x_movie . w_person + b_person + movie mean`, clipped to 1..5.
- 10% of ratings are held out and predicted.

## Run it

```bash
python p3_collaborative.py
```

The real output:

```text
1. 90,000 ratings to learn from, 10,000 held out. The matrix is 6.3% filled.

2. Predicting the held-out ratings (RMSE, in stars):
   everyone's average (3.53)      1.129
   each movie's average                1.036
   collaborative filtering k=20, lambda=0.0  1.218
   collaborative filtering k=20, lambda=5.0  0.983
   collaborative filtering k=50, lambda=5.0  0.998

3. Movies whose learned vectors are closest to Star Wars (1977), among movies with 100+ ratings:
   Empire Strikes Back, The (1980); Return of the Jedi (1983); Raiders of the Lost Ark (1981); Indiana Jones and the Last Crusade (1989); Terminator, The (1984)
   Nobody told the model about genres or sequels: it found them in who rated what.
```

What it shows:

- Each movie's own average already beats everyone's average. **Collaborative filtering with regularization beats
  both** (0.983 stars).
- **Without regularization it's the worst of all** (1.218): 20 numbers per movie and person, from a matrix only 6.3%
  filled, memorize the training ratings. 50 numbers instead of 20 is slightly worse too.
- **The nearest movies to Star Wars are its sequels and similar adventures**, though the model never saw a genre or
  a title: only who rated what.

## What to take away

- Collaborative filtering learns item and user vectors from ratings alone.
- Regularize, mean-normalize, and measure on held-out ratings.
