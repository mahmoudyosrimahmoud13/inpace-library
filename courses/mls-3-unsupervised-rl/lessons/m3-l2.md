# Mean normalization and TensorFlow

A new user with no ratings gets `w = 0`, `b = 0` from regularization, so every prediction is 0. **Mean
normalization** fixes this: subtract each movie's mean rating before training, add it back at prediction time. New
users then get the average, a sensible start.

Custom training loop with automatic gradients:

```python
optimizer = tf.keras.optimizers.Adam(learning_rate=1e-1)
for it in range(200):
    with tf.GradientTape() as tape:
        cost = cofi_cost(X, W, b, Ynorm, R, lam)     # you write this, vectorized
    grads = tape.gradient(cost, [X, W, b])
    optimizer.apply_gradients(zip(grads, [X, W, b]))
```

## Limits of collaborative filtering
