# Project 2: catch the rating bots

You'll plant 15 fake accounts that rate like bots, then catch them with a Gaussian model of normal accounts.

The code is above this text. Save it as `p2_anomaly.py`.

## Read the code

- **`user_features()`** describes each account with five numbers: how many ratings (log), their mean, their spread,
  the share of 5-star ratings, and ratings per active day (log).
- **`bots()`** creates 15 accounts that rate 80 to 200 random movies within one hour, almost all 5 stars.
- **`fit()` and `density()`**: a Gaussian per feature, fitted on 600 **normal** accounts only; `p(x)` is their
  product. Low `p(x)` means unusual.
- The threshold `epsilon` is chosen on a small validation set with 7 labelled bots (best F1), then tested on new
  accounts and the other 8 bots.

## Run it

```bash
python p2_anomaly.py
```

The real output:

```text

real       4.27  3.59  1.02     0.23         3.08

2. Threshold chosen on validation (F1 1.00): p(x) < 3.7e-11
   test set: 8 of 8 bots caught, 0 of 173 real accounts flagged
```

What it shows:

- The bots stand out on every feature: almost all 5 stars, tiny spread, extreme speed.
- **All 8 test bots are caught and no real account is flagged.** These bots are crude on purpose; real fraud is
  subtler, which is why you engineer features that capture "what would a bad actor do?"
- **Anomaly detection learned only from normal accounts.** You need a few labelled examples just to set the threshold:
  the right tool when bad cases are rare and keep changing.
