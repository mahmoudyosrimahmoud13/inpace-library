# Project 1: Movie night starts with k-means

Through this course you build **Movie night**: a recommender for MovieLens 100K, 100,000 ratings of 1,682 movies by
943 people. Clusters today; then anomaly detection, collaborative and content-based filtering, reinforcement
learning on the lessons' Mars rover, and PCA.

The project folder is above this text. Install `pip install numpy pandas scikit-learn` (and `tensorflow` for
day 8). The data comes from GroupLens, whose licence doesn't allow passing it on, so `movies.py` downloads it (5 MB)
on the first run.

## Read the code

- **`kmeans(X, k)`** is the lesson's algorithm: start from k random movies; assign every movie to its nearest
  centroid; move each centroid to the mean of its movies; repeat until nothing moves. It returns the **distortion**
  (average squared distance to the centroid).
- Each movie is 21 numbers: its 19 genre flags, its average rating, and how many ratings it has (log, scaled).
- It tries k from 2 to 12, five random starts each, keeps the best, then describes k = 8.

## Run it

```bash
python p1_kmeans.py
```

What it shows:

- **Distortion always falls as k grows**, with no clear elbow: choose k for the use (how many shelves does the app
  show?), not from the curve alone.
- The clusters are readable: well-liked dramas, poorly rated dramas, good comedies, action and adventure. The rating
  features split genres into "good" and "bad" groups.
- **Your k-means equals scikit-learn's**, to three decimals.

## What to take away

- k-means alternates two steps: assign, then move the centroids.
- Run several starts; choose k for the purpose.
