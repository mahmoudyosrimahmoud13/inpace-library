# Project 7: PCA on what the recommender learned

You'll compress the 20 numbers collaborative filtering learned for each movie into 2, measure what survives, and read
what the main directions mean.

The code is above this text. Save it as `p7_pca.py`.

## Read the code

- It retrains project 3's model, keeps the 203 movies with at least 150 ratings (their vectors are reliable), and
  centres the vectors.
- **PCA by hand**: the SVD of the centred data. The rows of `Vt` are the principal components; the squared singular
  values say how much variance each one carries. scikit-learn's `PCA` is checked against it.
- It prints the four movies at each end of the first two components.

## Run it

```bash
python p7_pca.py
```

The real output:

```text
1. 203 movies with 150+ ratings, 20 learned numbers each
   share of variance on each principal component: 10%, 8%, 8%, 6%, 6%, 5% ...
   the first 2 keep 18%; it takes 17 to keep 90%
   scikit-learn's PCA agrees: True

2. Component 1, one end:   Trainspotting (1996); Boogie Nights (1997); Clockwork Orange, A (1971); Pulp Fiction (1994)
                other end: Top Gun (1986); Saint, The (1997); Conspiracy Theory (1997); Independence Day (ID4) (1996)
2. Component 2, one end:   English Patient, The (1996); Everyone Says I Love You (1996); Grease (1978); Sound of Music, The (1965)
                other end: Star Wars (1977); Alien (1979); Fifth Element, The (1997); Terminator, The (1984)

   Read the ends and name the axis yourself: PCA finds directions, people give them meaning.
```

What it shows:

- **The variance is spread out**: 2 components keep only 18%, and 17 of 20 are needed for 90%. Taste is many-sided;
  a 2D map of these movies would hide most of it.
- **Yet the first two directions are easy to read.** Component 1 runs from edgy 1990s films (*Trainspotting*, *Pulp
  Fiction*) to mainstream blockbusters (*Top Gun*, *Independence Day*). Component 2 from romance and musicals to
  science fiction. The model learned these from ratings alone.
