# Continuous states and learning Q with a network

Real states are vectors of numbers: a truck `(x, y, θ, ẋ, ẏ, θ̇)`; the **Lunar Lander** `(x, y, ẋ, ẏ, θ, θ̇, l, r)` with
leg-contact flags `l, r`. Actions: nothing, left, main, right engine. Rewards: landing +100-140, crash −100, leg
contact +10, firing engines small penalties.

**Deep Q-Network (DQN)**: a network takes `s` and outputs `Q(s, a)` for **all** actions at once.

Training data comes from the **Bellman equation**:

```text
collect experiences (s, a, R(s), s') by acting in the environment
keep the latest 10,000 in a replay buffer
train the network on:
    x = s (and a)
    y = R(s) + γ · max_a' Q(s', a')       # using the current network for Q(s', ·)
repeat
```

The targets come from the model itself, so learning can be unstable. Day 8 fixes that.
