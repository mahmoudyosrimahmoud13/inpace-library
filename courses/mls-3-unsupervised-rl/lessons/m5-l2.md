# The state-action value function Q

```text
Q(s, a) = return if you start in s, take action a once, then act optimally after that
```

- The best possible return from `s` is `max_a Q(s, a)`.
- The best action in `s` is `π(s) = argmax_a Q(s, a)`.

So if we can learn `Q`, we have the policy. In the rover example with `γ = 0.5`, compute `Q(2, left) = 0 + 0.5·100 =
50` and `Q(2, right) = 0 + 0.5·0 + 0.25·0 + 0.125·100 = 12.5`, so go left. Work through the other states yourself
with the slides.
