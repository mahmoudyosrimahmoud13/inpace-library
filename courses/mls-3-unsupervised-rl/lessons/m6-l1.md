# Bellman, and randomness

```text
Q(s, a) = R(s) + γ · max_a' Q(s', a')
```

The return is the **reward now** plus the **discounted best return from the next state** `s'`. This recursive
equation is the basis of most RL algorithms.

**Stochastic environments:** the rover sometimes slips the wrong way. The goal becomes the **expected** return:

```text
Q(s, a) = R(s) + γ · E[ max_a' Q(s', a') ]
```

More randomness lowers the values and can change the best policy (avoid risky edges).
