# Learning user and item vectors together

Ratings matrix: `n_u` users × `n_m` movies, most cells missing. `r(i, j) = 1` if user `j` rated movie `i`.

**With item features `x⁽ⁱ⁾`**, each user gets their own linear regression: `predict = w⁽ʲ⁾·x⁽ⁱ⁾ + b⁽ʲ⁾`.

**Collaborative filtering** learns the features too. The cost over all rated pairs:

```text
J(w, b, x) = ½ Σ_(i,j): r(i,j)=1 ( w⁽ʲ⁾·x⁽ⁱ⁾ + b⁽ʲ⁾ − y⁽ⁱ'ʲ⁾ )²
             + (λ/2) Σⱼ ‖w⁽ʲ⁾‖² + (λ/2) Σᵢ ‖x⁽ⁱ⁾‖²
```

Minimize over `w`, `b` **and** `x` with gradient descent. Many users rating the same movie is what lets the algorithm
guess that movie's features: users **collaborate**.

## Binary labels

For likes, clicks or "watched to the end": use a sigmoid and log loss, `P(y = 1) = g(w·x + b)`.

## Going further

This is **matrix factorization**: `Y ≈ X Wᵀ` (+ biases). The learned item vectors are **embeddings**; similar
vectors mean similar items. Implicit feedback (clicks) needs care: a missing click isn't a dislike.
