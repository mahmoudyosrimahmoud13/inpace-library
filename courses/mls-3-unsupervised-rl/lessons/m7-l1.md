# ε-greedy, mini-batches and soft updates

## Exploration: ε-greedy

While learning, with probability `ε` take a **random** action (explore), otherwise the best known one (exploit). Start
with `ε = 1` and lower it gradually to about 0.01. Without exploration, the agent may never discover a better action.

## Mini-batches

Train each step on a random mini-batch (e.g. 64) from the replay buffer: faster, and random sampling breaks the
correlation between consecutive experiences.

## Soft updates (a target network)

Use a separate **target network** `Q_target` for the targets `y = R + γ max Q_target(s', a')`, and move it slowly:

```text
W_target = 0.01 · W + 0.99 · W_target
```

Targets then change slowly, which stabilizes training. Without it, the network chases its own moving targets.

## The state of RL

Much more finicky than supervised learning: sensitive to hyperparameters, sample-hungry, and many results are from
simulations, which are easier than the real world. Still exciting, and the basis of RLHF in language models.
