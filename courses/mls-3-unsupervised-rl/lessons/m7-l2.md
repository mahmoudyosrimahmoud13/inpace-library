# Going further: what interviewers may ask

- **On-policy vs off-policy:** SARSA learns about the policy it follows; Q-learning learns about the greedy policy
  while exploring (off-policy, so a replay buffer works).
- **Value-based vs policy-based:** DQN learns Q; policy-gradient methods (REINFORCE, PPO) learn `π` directly and handle
  continuous actions; **actor-critic** combines both.
- **Double DQN** reduces Q over-estimation by choosing the action with one network and evaluating it with the other.
- **RLHF:** a reward model trained on human preferences, then the language model optimized with RL (often PPO).
