# States, actions, rewards and returns

RL learns from **rewards**, not right answers: tell the helicopter what's good (reward) and bad (penalty), and let it
figure out how.

Mars rover: states 1-6, rewards 100 at state 1, 40 at state 6, 0 between; actions left/right.

```text
Return = R₁ + γR₂ + γ²R₃ + …        discount factor γ (e.g. 0.9 or 0.99)
```

`γ < 1` makes the agent **impatient**: rewards sooner are worth more (and penalties are pushed later).

A **policy** `π(s)` says which action to take in state `s`. **Goal: find a policy that maximizes the return.**

The whole setup is a **Markov decision process** (MDP): the future depends only on the current state, not the history.
