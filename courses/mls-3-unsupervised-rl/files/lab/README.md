# Movie night

The running project of the inPace course "Machine Learning refresh 3": a recommender for MovieLens 100K (downloaded from GroupLens on first run), plus the lessons' Mars rover for reinforcement learning.

```bash
pip install numpy pandas scikit-learn tensorflow
python p1_kmeans.py
```

| File | What it adds |
|---|---|
| `movies.py` | Downloads and loads MovieLens 100K |
| `p1_kmeans.py` | k-means from scratch |
| `p2_anomaly.py` | Catching rating bots with a Gaussian model |
| `p3_collaborative.py` | Collaborative filtering from scratch |
| `p4_content.py` | Content-based filtering, retrieve then rank |
| `p5_bellman.py` | The Bellman equation and Q-learning |
| `p6_dqn.py` | Deep Q-learning on a continuous rover |
| `p7_pca.py` | PCA on the learned movie vectors |
