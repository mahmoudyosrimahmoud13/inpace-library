# Releases, the API and aliases

## Releases

A **release** is a tag with notes and files people can download.

```bash
git tag -a v1.0.0 -m "First release" && git push origin v1.0.0
gh release create v1.0.0 --generate-notes            # notes written from the merged pull requests
gh release create v1.0.1 dist/app.zip --generate-notes   # with a file attached
gh release list
gh release download v1.0.0
```

## Actions from the terminal

```bash
gh run list                    # the latest workflow runs
gh run watch                   # follow one live
gh run view --log-failed       # only the logs of the steps that failed
gh run rerun --failed          # run again only what failed
gh workflow run hello.yml      # start a workflow that has workflow_dispatch
```

## The API, and your own commands

`gh api` calls any of GitHub's API with your login. `{owner}` and `{repo}` are filled from the current folder, and `--jq` picks fields:

```bash
gh api repos/{owner}/{repo} --jq .stargazers_count
gh api repos/{owner}/{repo}/issues --paginate --jq '.[].title'

gh alias set bugs 'issue list --label bug'
gh bugs
gh extension install dlvhdr/gh-dash   # a dashboard of your PRs and issues
```
