# Your own action, and reusing workflows

When several repositories repeat the same steps, write them once.

## A composite action

Steps in an `action.yml`, used like any action:

```yaml
# .github/actions/node-test/action.yml
name: Node tests
description: Set up Node and run the tests
inputs:
  node-version:
    default: "22"
runs:
  using: composite
  steps:
    - uses: actions/setup-node@v7
      with:
        node-version: ${{ inputs.node-version }}
    - run: npm test
      shell: bash
```

```yaml
- uses: actions/checkout@v7
- uses: ./.github/actions/node-test     # from this repository
  with:
    node-version: "24"
```

## A reusable workflow

A whole workflow that other workflows call, with `on: workflow_call`. Teams keep one in a shared repository (`uses: my-org/ci/.github/workflows/node.yml@v1`) so every project tests the same way.

```yaml
# .github/workflows/node.yml in the shared repository
on:
  workflow_call:
    inputs:
      node-version:
        type: string
        default: "22"
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-node@v7
        with:
          node-version: ${{ inputs.node-version }}
      - run: npm test
```
