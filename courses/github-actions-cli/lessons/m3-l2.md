# Repositories, issues and pull requests from the terminal

## Repositories

```bash
gh repo create study-tasks --public --source=. --push   # make a GitHub repo from this folder and push it
gh repo clone mona/notes                                # clone (uses ssh after the login above)
gh repo fork owner/project --clone                       # fork and clone in one step, with upstream set for you
```

## Issues

```bash
gh issue list --label bug
gh issue list --assignee "@me"
gh issue create --title "Total is wrong when the list is empty" --label bug
gh issue view 12 --comments
gh issue develop 12 --checkout     # a branch linked to issue 12, and switch to it
gh issue close 12
```

## Pull requests: the whole loop

```bash
git switch -c fix/empty-total
# ... commit ...
git push -u origin fix/empty-total
gh pr create --fill                 # title and body from your commits (or answer the questions)
gh pr create --draft --reviewer ali
gh pr status                        # your pull requests, and the ones waiting for your review
gh pr checks --watch                # watch the tests until they finish
gh pr merge --squash --delete-branch

# reviewing someone else's:
gh pr list
gh pr checkout 34                   # get their branch locally, to run it
gh pr diff 34
gh pr review 34 --approve
gh pr review 34 --request-changes --body "Please add a test for an empty list."
```

`gh pr merge --auto --squash` merges by itself the moment the checks pass and the approvals arrive.
