# Install gh and sign in

`gh` brings GitHub to your terminal: pull requests, issues, releases and Actions, without leaving the keyboard. It works next to Git: Git handles commits, `gh` handles everything on GitHub around them.

- **Windows:** `winget install --id GitHub.cli`
- **Mac:** `brew install gh`
- **Linux:** follow [the official steps](https://github.com/cli/cli/blob/trunk/docs/install_linux.md) (Ubuntu's own package is often old).

```bash
gh --version
gh auth login --git-protocol ssh   # choose GitHub.com, then log in with a browser; ssh fits the keys you made
gh auth status                      # who you are, and the token's scopes
gh repo view --web                  # open this folder's repository in the browser
```

`gh` keeps its own token (in your system's keychain). If it ever says a scope is missing, for example to manage workflows, run `gh auth refresh -s workflow`.
