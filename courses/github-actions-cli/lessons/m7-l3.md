# Where to go next

An optional lesson.

- **Official docs:** [GitHub Docs: Actions](https://docs.github.com/actions) and the [gh manual](https://cli.github.com/manual) are clear and complete.
- **Certification:** GitHub offers a *GitHub Actions* certification; freeCodeCamp has a free full prep course on YouTube.
- **Containers:** take *Docker and Kubernetes* in this library, then build and push images from Actions.
- **Contribute:** find a project you use, read its workflows in `.github/workflows/`, and fix a small issue. Reading other people's pipelines teaches a lot.
