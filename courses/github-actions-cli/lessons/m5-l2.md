# Faster and smarter runs: cache, artifacts, filters

## Cache

Downloading the same packages on every run is slow. `setup-node` and `setup-python` can cache them (they need a lock file, like `package-lock.json`):

```yaml
- uses: actions/setup-node@v7
  with:
    node-version: 22
    cache: npm
- run: npm ci        # install exactly what package-lock.json says
```

For anything else, `actions/cache@v6` saves a folder under a key, usually a hash of the lock file: `key: deps-${{ hashFiles('**/requirements.txt') }}`.

## Artifacts: keep files from a run

A runner is deleted when the job ends. To keep a test report, a build or a screenshot, upload it as an **artifact** (downloadable from the run's page for 90 days by default):

```yaml
- if: failure()                 # only when something broke
  uses: actions/upload-artifact@v7
  with:
    name: screenshots
    path: test-results/
```

To pass files from one job to the next in the same run, upload in the first and use `actions/download-artifact` in the second.

## Only run what's needed

- `paths:` / `paths-ignore:` under `push` and `pull_request` skip runs for changes that can't matter (docs, images).
- `if:` on a job or a step: `if: github.event_name == 'push'`.
- `timeout-minutes: 15` on a job stops one that hangs (the default is 6 hours).
