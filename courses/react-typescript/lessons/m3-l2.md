# Forms the React way

## Controlled inputs

A **controlled** input gets its value from state and tells you every change:

```tsx
function AddTask({ onAdd }: { onAdd: (title: string) => void }) {
  const [title, setTitle] = useState("");

  function submit(e: React.FormEvent<HTMLFormElement>) {
    e.preventDefault();
    const clean = title.trim();
    if (!clean) return;
    onAdd(clean);
    setTitle("");
  }

  return (
    <form onSubmit={submit}>
      <label htmlFor="new-task">New task</label>
      <input id="new-task" value={title} onChange={(e) => setTitle(e.target.value)} />
      <button disabled={!title.trim()}>Add</button>
    </form>
  );
}
```

Because the value lives in state, you can clear it, check it, or disable the button as the user types.

Use `onSubmit` on the `<form>`, not `onClick` on the button: then pressing Enter works too.

## Several fields: one object

```tsx
type Draft = { title: string; minutes: number; level: "easy" | "hard" };

const [draft, setDraft] = useState<Draft>({ title: "", minutes: 25, level: "easy" });

<input
  value={draft.title}
  onChange={(e) => setDraft({ ...draft, title: e.target.value })}
/>
<input
  type="number"
  value={draft.minutes}
  onChange={(e) => setDraft({ ...draft, minutes: Number(e.target.value) })}
/>
<select
  value={draft.level}
  onChange={(e) => setDraft({ ...draft, level: e.target.value as Draft["level"] })}
>
  <option value="easy">Easy</option>
  <option value="hard">Hard</option>
</select>
```

Note `Number(...)`: inputs always give you **strings**, even `type="number"`.

Checkboxes use `checked`, not `value`:

```tsx
<input type="checkbox" checked={draft.done} onChange={(e) => setDraft({ ...draft, done: e.target.checked })} />
```

## Validation people can use

```tsx
const errors: Partial<Record<keyof Draft, string>> = {};
if (!draft.title.trim()) errors.title = "Give the task a name.";
if (draft.minutes < 5 || draft.minutes > 240) errors.minutes = "Between 5 and 240 minutes.";

<input
  aria-invalid={!!errors.title}
  aria-describedby="title-error"
  ...
/>
{errors.title && <p id="title-error" className="error">{errors.title}</p>}
```

Good form manners:
- Say **what's wrong and how to fix it**, next to the field.
- Don't shout errors before the user has typed anything (track a `touched` flag, or check on submit).
- Keep the browser's own checks too (`required`, `min`, `max`, `type="email"`): they're free.
- Always validate again on the server. Browser checks are for comfort, not security.

## Uncontrolled inputs (sometimes fine)

For a simple form you only read on submit, you can let the browser hold the values and read them with `FormData`:

```tsx
function submit(e: React.FormEvent<HTMLFormElement>) {
  e.preventDefault();
  const data = new FormData(e.currentTarget);
  onAdd(String(data.get("title") ?? ""));
  e.currentTarget.reset();
}
```

Controlled is better when the UI reacts while typing (live checks, disabling buttons, previews). For big forms, libraries like React Hook Form handle the bookkeeping.

## Accessibility check

Every input needs a **label** a screen reader can find (`<label htmlFor>` with a matching `id`, or the input inside the label). Placeholder text is not a label: it disappears when you type.
