# Pages with React Router

A **single-page app** has one HTML page; JavaScript swaps what's shown as the address changes. React Router connects addresses to components and keeps the browser's Back button working.

```bash
npm install react-router
```

## Routes

```tsx
// main.tsx
import { createRoot } from "react-dom/client";
import { BrowserRouter, Routes, Route } from "react-router";
import App from "./App";
import Home from "./pages/Home";
import TaskPage from "./pages/TaskPage";
import NotFound from "./pages/NotFound";

createRoot(document.getElementById("root")!).render(
  <BrowserRouter>
    <Routes>
      <Route element={<App />}>
        <Route index element={<Home />} />
        <Route path="tasks/:id" element={<TaskPage />} />
        <Route path="*" element={<NotFound />} />
      </Route>
    </Routes>
  </BrowserRouter>
);
```

`App` is a **layout**: the parts every page shares (header, menu), with an `<Outlet />` where the current page goes:

```tsx
import { Link, NavLink, Outlet } from "react-router";

export default function App() {
  return (
    <>
      <header>
        <NavLink to="/" end>Tasks</NavLink>
        <NavLink to="/stats">Stats</NavLink>
      </header>
      <main><Outlet /></main>
    </>
  );
}
```

- `<Link to="...">` changes page without reloading. Never use `<a href>` for your own pages (it reloads everything and loses state).
- `<NavLink>` adds an `active` class to the current page's link, for styling the menu.

## Reading the address

```tsx
import { useParams, useNavigate, useSearchParams } from "react-router";

function TaskPage() {
  const { id } = useParams();               // from "tasks/:id", always a string (or undefined)
  const navigate = useNavigate();
  const task = tasks.find((t) => t.id === Number(id));
  if (!task) return <p>No task {id}. <Link to="/">Back to tasks</Link></p>;
  return (
    <article>
      <h1>{task.title}</h1>
      <button onClick={() => navigate("/")}>Done</button>
    </article>
  );
}
```

Put **filters and searches in the address** with `useSearchParams` (`/?filter=done`). Then a refresh, a shared link or the Back button keeps the same view:

```tsx
const [params, setParams] = useSearchParams();
const filter = (params.get("filter") ?? "all") as Filter;
<button onClick={() => setParams({ filter: "done" })}>Done</button>
```

## Organizing files

A layout that scales without getting clever:

```
src/
  pages/        one component per route (Home.tsx, TaskPage.tsx)
  components/   reusable pieces (TaskRow.tsx, ProgressBar.tsx)
  hooks/        useLocalStorage.ts, useFetch.ts
  types.ts      Task, Filter, shared types
  App.tsx       layout
  main.tsx      router and start-up
```

## GitHub Pages and routing

GitHub Pages doesn't know your routes: refreshing `/tasks/3` returns 404. Two easy fixes:
- Use `HashRouter` instead of `BrowserRouter` (addresses look like `/#/tasks/3`, and always work), or
- Copy `index.html` to `404.html` when you build, so every unknown address loads your app.
