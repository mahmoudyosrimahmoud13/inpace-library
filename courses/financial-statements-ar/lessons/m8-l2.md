# المشروع الختامي: اقرأ تقريرًا سنويًا حقيقيًا

حان وقت استخدام كل شيء على شركة حقيقية. استخدم التقرير السنوي الذي وجدته في اليوم الأول (أو اختر واحدًا الآن: بنك أو شركة اتصالات أو أغذية أو تجزئة أو صناعة مقيدة في بلدك، أو شركة عالمية معروفة).

اشتغل على شيت إكسل. خذ وقتك: المحلل الخبير يقضي ساعات في هذا، وليس دقائق.

## الخطوة 1: قبل الأرقام (15 دقيقة)

- ماذا تبيع الشركة، ولمن، وأين؟
- بأي عملة ووحدة القوائم؟ مجمّعة أم للشركة وحدها؟
- ماذا يقول **تقرير مراقب الحسابات**؟ هل الرأي نظيف ("تعبّر بعدالة ووضوح، في جميع جوانبها الهامة")؟ هل هناك فقرة لفت انتباه أو أمور مراجعة رئيسية؟
- اقرأ كلمة رئيس المجلس: اكتب ثلاثة أشياء تقول الإدارة إنها سارت جيدًا وأي مشكلات تذكرها.

## الخطوة 2: انقل الأرقام الرئيسية (30 دقيقة)

لآخر سنتين (ثلاث إلى خمس لو استطعت)، انقل:

| قائمة الدخل | الميزانية | التدفقات النقدية |
|---|---|---|
| الإيرادات | النقدية | النقدية من التشغيل |
| مجمل الربح (لو ظاهر) | العملاء | الإنفاق الرأسمالي |
| ربح التشغيل | المخزون | التوزيعات المدفوعة |
| مصروف الفوائد | إجمالي الأصول المتداولة | قروض جديدة / مسدّدة |
| صافي الربح | إجمالي الأصول | |
| | إجمالي الخصوم المتداولة | |
| | إجمالي الديون (قروض، سندات، إيجارات) | |
| | إجمالي حقوق الملكية | |

## الخطوة 3: احسب (30 دقيقة)

على الأقل هذه، لكل سنة:

- نمو الإيرادات
- هوامش مجمل الربح والتشغيل وصافي الربح
- ROE وROA
- نسبة التداول والنسبة السريعة
- الديون إلى حقوق الملكية، وتغطية الفوائد
- فترة التحصيل وأيام المخزون (لو تنطبق)
- نقدية التشغيل ÷ صافي الربح، والتدفق النقدي الحر

## الخطوة 4: اقرأ إيضاحات أكبر الأرقام (30 دقيقة)

اختر أكبر ثلاثة بنود في الميزانية واعثر على إيضاحاتها. ابحث عن:

- السياسات المحاسبية (الاعتراف بالإيراد، طريقة المخزون، أعمار الإهلاك)
- مواعيد سداد الديون، وبأي فائدة
- المخصصات والالتزامات المحتملة (قضايا، ضمانات)
- الأحداث بعد تاريخ الميزانية

## الخطوة 5: احكِ القصة (30 دقيقة)

اكتب **صفحة واحدة** تجيب فيها:

1. هل الشركة **مربحة**، وهل تتحسّن أم تسوء؟ لماذا؟
2. هل هي **آمنة**: تقدر على فواتيرها القصيرة وديونها؟
3. هل ربحها يتحوّل إلى **نقدية**؟
4. ما **أكبر خطرين** وجدتهما؟
5. لو كنت بنكًا، هل تُقرضها؟ ولو كنت مستثمرًا، ماذا تسأل الإدارة؟

## قائمة علامات الخطر

- العملاء أو المخزون ينمون أسرع بكثير من المبيعات
- التدفق التشغيلي أقل بكثير من صافي الربح لعدة سنوات
- الديون تزيد والربح يقل
- تغطية الفوائد أقل من 2 إلى 3
- مكاسب استثنائية كبيرة تسند الربح
- رأي مراقب متحفظ، أو تحذير بشأن الاستمرارية
- تغييرات متكررة في السياسات أو التقديرات المحاسبية

## إلى أين بعد ذلك

أنت الآن تقدر تقرأ القوائم المالية وتبنيها وتحلّلها. الكورسات التالية في مسار المحاسبة:

- **محاسبة التكاليف والمحاسبة الإدارية:** تكلفة المنتجات، نقطة التعادل، الموازنات، والقرارات داخل المشروع.
- **الإكسل للمحاسبين:** عمل كل هذا بسرعة ودقة في الشيتات.

ولشهادة معترف بها لاحقًا، انظر في CMA (المكتبة فيها كورس CMA الجزء الأول للمبتدئين) أو امتحانات نقابة المحاسبين في بلدك.
