# The Python you need for data

You don't need all of Python for data work. This lesson covers the parts you'll use every day. If you already know Python, skim it.

## Numbers, text and true/false

```python
temp = 31.5            # float: a number with a decimal point
orders = 120           # int: a whole number
branch = "Zamalek"     # str: text
is_weekend = True      # bool: True or False

print(type(temp).__name__, type(orders).__name__, type(branch).__name__, type(is_weekend).__name__)
print(orders / 7, orders // 7, orders % 7)
print(branch.upper(), len(branch), branch.startswith("Zam"))
```

```output
float int str bool
17.142857142857142 17 1
ZAMALEK 7 True
```

`/` divides normally, `//` gives the whole part, `%` the remainder.

## Lists: several values in order

```python
prices = [45, 65, 70, 30, 55]
print(prices[0], prices[-1])        # first and last
print(prices[1:3])                  # a slice: items 1 and 2
prices.append(90)
print(len(prices), sum(prices), max(prices))
print(sorted(prices, reverse=True))
```

```output
45 55
[65, 70]
6 355 90
[90, 70, 65, 55, 45, 30]
```

Positions start at 0, and `-1` means the last item.

## Dictionaries: look things up by name

```python
menu = {"tea": 30, "latte": 70, "brownie": 55}
print(menu["latte"])
menu["croissant"] = 50
for item, price in menu.items():
    print(f"{item:10} {price:>4}")
print("cake" in menu)
```

```output
70
tea          30
latte        70
brownie      55
croissant    50
False
```

`{item:10}` pads to 10 characters; `{price:>4}` right-aligns in 4.

## Loops and conditions

```python
temps = [18.5, 24.0, 31.2, 35.8, 27.3]
for t in temps:
    if t >= 30:
        label = "hot"
    elif t >= 22:
        label = "warm"
    else:
        label = "cool"
    print(t, label)
```

```output
18.5 cool
24.0 warm
31.2 hot
35.8 hot
27.3 warm
```

Python uses **indentation** (4 spaces) to show what's inside the loop or the `if`. No braces.

## List comprehensions

A one-line way to build a list from another:

```python
hot_days = [t for t in temps if t >= 30]
in_fahrenheit = [round(t * 9 / 5 + 32) for t in temps]
print(hot_days)
print(in_fahrenheit)
```

```output
[31.2, 35.8]
[65, 75, 88, 96, 81]
```

You'll see these everywhere. Read them as "**the value** for each item **in** the list **if** the condition holds".

## Functions

```python
def with_tax(price, rate=0.14):
    """Price including tax. rate is 14% unless you give another."""
    return round(price * (1 + rate), 2)

print(with_tax(100))
print(with_tax(100, rate=0.05))
print([with_tax(p) for p in [30, 65]])
```

```output
114.0
105.0
[34.2, 74.1]
```

`rate=0.14` is a **default**: used when you don't pass a rate.

## Why not just use lists for data?

You could store a year of orders as a list of dictionaries and loop over it. It works, but it's slow to write and slow to run. pandas gives you a **table** where one line does what a loop would take ten lines to do:

```python
orders = [
    {"item": "latte", "qty": 2, "price": 70},
    {"item": "tea", "qty": 1, "price": 30},
    {"item": "latte", "qty": 1, "price": 70},
]
total = 0
for o in orders:
    total += o["qty"] * o["price"]
print("with a loop:", total)

import pandas as pd
df = pd.DataFrame(orders)
print("with pandas:", (df["qty"] * df["price"]).sum())
```

```output
with a loop: 240
with pandas: 240
```

## Summary

- int, float, str, bool; lists for ordered values, dictionaries for lookups.
- Loops and `if` use indentation; list comprehensions build lists in one line.
- Functions with `def`, defaults like `rate=0.14`; for tables of data, use pandas.
