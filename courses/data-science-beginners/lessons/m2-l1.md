## Loading a CSV

A **CSV** is a text file of rows, with values separated by commas. `read_csv` turns it into a **DataFrame**: a table with named columns.

```python
import pandas as pd

df = pd.read_csv("cafe_sales.csv")
print(df.shape)
print(df.head(3).to_string())
```

```output
(1464, 13)
   order_id        date   time   branch           item category    size  quantity  unit_price payment customer_type  rating  temp_c
0     10001  2025-01-01  12:47  Zamalek            tea    drink  medium         2          34    cash     returning     4.0    10.5
1     10002  2025-01-01  15:26    Maadi  hot chocolate    drink   large         2          72    cash           new     3.0    10.5
2     10003  2025-01-01  16:00    Maadi  hot chocolate    drink  medium         2          60    cash           new     NaN    10.5
```

- `shape` is (rows, columns).
- `head(3)` gives the first 3 rows. `tail()` gives the last ones. `.to_string()` prints all columns; in a notebook, just writing `df.head()` as the last line shows a nicer table.

## Selecting rows and columns

```python
small = df[["date", "branch", "item", "unit_price"]]          # some columns
lattes = df[df["item"] == "latte"]                            # rows matching a condition
big_orders = df[(df["quantity"] >= 3) & (df["category"] == "food")]
print(len(lattes), "latte orders")
print(len(big_orders), "food orders of 3 or more")
print(small.iloc[0].to_dict())                                # the first row, by position
```

```output
98 latte orders
50 food orders of 3 or more
{'date': '2025-01-01', 'branch': 'Zamalek', 'item': 'tea', 'unit_price': 34}
```

- `df[["a", "b"]]` (a list inside) picks columns.
- `df[condition]` keeps the rows where the condition is True. Combine conditions with `&` (and), `|` (or), each in brackets.
- `iloc[i]` selects by position; `loc[label]` selects by row label.

## Adding a column

```python
df["revenue"] = df["quantity"] * df["unit_price"]
print(df[["item", "quantity", "unit_price", "revenue"]].head(3).to_string())
print("Total revenue:", df["revenue"].sum())
```

```output
            item  quantity  unit_price  revenue
0            tea         2          34       68
1  hot chocolate         2          72      144
2  hot chocolate         2          60      120
Total revenue: 176827
```

Calculations on whole columns run on every row at once. This is called **vectorized** code: no loop, and much faster than one.

## Sorting

```python
top = df.sort_values("revenue", ascending=False).head(5)
print(top[["date", "branch", "item", "quantity", "unit_price", "revenue"]].to_string(index=False))
```

```output
      date     branch         item  quantity  unit_price  revenue
2025-09-08      Maadi     espresso         3        4500    13500
2025-01-30 Heliopolis falafel wrap         1        5400     5400
2025-01-30 Heliopolis    croissant         1        4500     4500
2025-05-29    Zamalek   iced latte         3         104      312
2025-08-22    Zamalek   iced latte         3         104      312
```

The top orders are the typo prices again. Exploring first, before calculating anything important, is how you catch problems like this.

## Summary

- `pd.read_csv` loads a table; `shape`, `head`, `columns`, `value_counts` and `describe` show what's inside.
- Select columns with `df[["a", "b"]]`, rows with `df[condition]`; combine conditions with `&` and `|`.
- New columns come from whole-column maths; sort with `sort_values`. Explore before you trust any number.
