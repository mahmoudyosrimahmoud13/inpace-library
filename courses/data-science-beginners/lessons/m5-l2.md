# Machine learning 2: predicting a category

**Classification** predicts a label instead of a number: spam or not, will the customer return or not, which product they'll pick.

## The question

*Will this order be an iced drink?* If the chain could tell from the weather, hour and branch, it could prepare ice and cups ahead.

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split

df = pd.read_csv("cafe_clean.csv", parse_dates=["date"])
df["iced"] = df["item"].isin(["iced latte", "mint lemonade"]).astype(int)
df["weekend"] = df["date"].dt.dayofweek.isin([4, 5]).astype(int)

X = pd.get_dummies(df[["temp_c", "hour", "weekend", "branch"]], columns=["branch"], dtype=int)
y = df["iced"]
print(list(X.columns))
print(f"{y.mean():.1%} of orders are iced drinks")

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
```

```output
['temp_c', 'hour', 'weekend', 'branch_Heliopolis', 'branch_Maadi', 'branch_Zamalek']
18.0% of orders are iced drinks
```

- `pd.get_dummies` turns a text column into 0/1 columns (one per branch), because models need numbers. This is called **one-hot encoding**.
- `stratify=y` keeps the same share of iced orders in the training and test sets.

## Logistic regression

Despite the name, it's a classifier. It predicts the **probability** of the label:

```python
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

clf = LogisticRegression(max_iter=1000)
clf.fit(X_train, y_train)
pred = clf.predict(X_test)
print("accuracy:", round(accuracy_score(y_test, pred), 3))
print("always say 'not iced':", round(accuracy_score(y_test, np.zeros(len(y_test))), 3))
```

```output
accuracy: 0.818
always say 'not iced': 0.821
```

Look at that: a "model" that always says "not iced" scores almost the same accuracy, because most orders aren't iced. **Accuracy is misleading when one class is rare.** We need better measures.

## The confusion matrix

```python
from sklearn.metrics import confusion_matrix, precision_score, recall_score
print(confusion_matrix(y_test, pred))
print("precision:", round(precision_score(y_test, pred, zero_division=0), 2))
print("recall:", round(recall_score(y_test, pred), 2))
```

```output
[[297   1]
 [ 65   0]]
precision: 0.0
recall: 0.0
```

```text
                 predicted: not iced   predicted: iced
actual: not iced   true negatives        false positives
actual: iced       false negatives       true positives
```

- **Precision**: of the orders we called "iced", how many really were?
- **Recall**: of the real iced orders, how many did we catch?

## Choosing the threshold

By default the model says "iced" when the probability is above 50%. For preparing ice, missing iced orders is worse than preparing a few extra cups, so lower the threshold to catch more:

```python
proba = clf.predict_proba(X_test)[:, 1]          # probability of "iced"
for t in [0.5, 0.3, 0.2]:
    p = (proba >= t).astype(int)
    print(f"threshold {t}: precision {precision_score(y_test, p, zero_division=0):.2f}, recall {recall_score(y_test, p):.2f}")
```

```output
threshold 0.5: precision 0.00, recall 0.00
threshold 0.3: precision 0.37, recall 0.38
threshold 0.2: precision 0.32, recall 0.65
```

Lower threshold, higher recall, lower precision. There's no universally right threshold: it depends on what each kind of mistake **costs** in your situation.

## What the model learned

```python
coefs = pd.Series(clf.coef_[0], index=X.columns).round(2).sort_values()
print(coefs.to_string())
```

```output
branch_Heliopolis   -0.12
weekend             -0.12
hour                 0.03
branch_Maadi         0.06
branch_Zamalek       0.06
temp_c               0.14
```

Temperature has the clearest positive effect: hotter means more likely iced. That matches what the charts showed, which is a good sign the model learned something real.

## A decision tree for comparison

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import roc_auc_score

tree = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X_train, y_train)
print("tree AUC:", round(roc_auc_score(y_test, tree.predict_proba(X_test)[:, 1]), 3))
print("logistic AUC:", round(roc_auc_score(y_test, proba), 3))
```

```output
tree AUC: 0.704
logistic AUC: 0.738
```

**AUC** (area under the ROC curve) measures how well the probabilities **rank** iced orders above non-iced ones, across all thresholds: 0.5 is guessing, 1.0 is perfect. It's a good single number for comparing classifiers on rare classes.

## Summary

- Classifiers predict labels and probabilities; one-hot encode text features.
- Accuracy misleads with rare classes; use the confusion matrix, precision, recall and AUC.
- Pick the threshold by the cost of each kind of mistake.
