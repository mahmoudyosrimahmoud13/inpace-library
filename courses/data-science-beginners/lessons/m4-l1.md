# Statistics 1: centre, spread and distributions

Statistics is the language for describing data honestly: what's typical, how much things vary, and how sure we can be.

```python
import pandas as pd
import numpy as np
df = pd.read_csv("cafe_clean.csv", parse_dates=["date"])
print(len(df), "orders")
```

```output
1452 orders
```

## The centre: mean vs median

```python
spend = df["revenue"]
print("mean:", round(spend.mean(), 1))
print("median:", spend.median())
print("mode:", spend.mode()[0])
```

```output
mean: 104.8
median: 89.0
mode: 50
```

- **mean**: the sum divided by the count. Sensitive to extreme values.
- **median**: the middle value when sorted. Half the orders are below it, half above.
- **mode**: the most common value.

The mean is above the median because a few big orders pull it up. When data has a long tail (incomes, house prices, order sizes), report the **median** as "typical", or both.

A quick demonstration of how one extreme value moves the mean but not the median:

```python
salaries = [7000, 8000, 8500, 9000, 9500]
print(np.mean(salaries), np.median(salaries))
salaries.append(250000)              # the owner joins the table
print(round(np.mean(salaries)), np.median(salaries))
```

```output
8400.0 8500.0
48667 8750.0
```

## Spread: how much values vary

```python
print("range:", spend.min(), "to", spend.max())
print("std:", round(spend.std(), 1))
q1, q3 = spend.quantile([0.25, 0.75])
print(f"middle half between {q1} and {q3} (IQR {q3 - q1})")
```

```output
range: 23 to 312
std: 59.0
middle half between 59.0 and 138.0 (IQR 79.0)
```

- **standard deviation (std)**: roughly the typical distance from the mean. Small std = values close together.
- **quartiles**: 25% of values are below Q1, 75% below Q3. The **IQR** (Q3 minus Q1) is the spread of the middle half, and isn't moved by extremes.

## Distributions

The **distribution** is the shape of all the values: where they bunch up and how far they stretch. A histogram shows it (you drew one last module). Two shapes matter most:

- **Normal** ("bell curve"): symmetric around the mean. Heights, measurement errors, temperatures in one season.
- **Skewed**: a long tail on one side. Order values, incomes, waiting times.

```python
rng = np.random.default_rng(1)
heights = rng.normal(loc=170, scale=8, size=10_000)       # simulated heights in cm
within_1 = np.mean(np.abs(heights - 170) <= 8) * 100
within_2 = np.mean(np.abs(heights - 170) <= 16) * 100
print(f"within 1 std: {within_1:.0f}%   within 2 std: {within_2:.0f}%")
```

```output
within 1 std: 69%   within 2 std: 96%
```

For a normal distribution, about **68%** of values fall within 1 standard deviation of the mean and about **95%** within 2. That's why "more than 2 std away" is a common rule for spotting unusual values.

## z-scores: how unusual is this value?

```python
daily = df.groupby("date")["revenue"].sum()
z = (daily - daily.mean()) / daily.std()
print("days more than 2.5 std above average:")
print(daily[z > 2.5].astype(int).to_string())
```

```output
days more than 2.5 std above average:
date
2025-05-29    1274
2025-06-18    1351
2025-07-26    1267
2025-08-15    1173
2025-08-22    1279
2025-09-13    1124
2025-12-13    1284
```

A **z-score** says how many standard deviations a value is from the mean. It lets you compare things on different scales and flag unusual days worth a closer look.

## Percentages and rates

Raw counts can mislead when groups differ in size. Compare **rates**:

```python
by_branch = df.groupby("branch").agg(orders=("order_id", "count"),
                                     wallet=("payment", lambda s: (s == "wallet").sum()))
by_branch["wallet_share_%"] = (by_branch["wallet"] / by_branch["orders"] * 100).round(1)
print(by_branch.to_string())
```

```output
            orders  wallet  wallet_share_%
branch                                    
Heliopolis     404      80            19.8
Maadi          479      98            20.5
Zamalek        569      97            17.0
```

Maadi and Zamalek have almost the same **count** of wallet payments, but Zamalek has many more orders, so its **share** is the lowest of the three. Looking only at counts would hide that.

## Summary

- Centre: mean (affected by extremes), median (robust), mode.
- Spread: standard deviation, quartiles and IQR; 68% and 95% within 1 and 2 std for normal data.
- z-scores flag unusual values; compare rates, not raw counts, across groups of different size.
