2. **When should I have more staff?**

Your deliverable: one clean notebook with short text cells, a few charts, and a final "Recommendations" section a busy owner can read in two minutes.

## Step 1: load and clean (reuse your work)

Put the cleaning steps from module 2 into one function, so the whole analysis starts from the raw file:

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

def load_clean(path):
    df = pd.read_csv(path).drop_duplicates()
    df["branch"] = df["branch"].str.strip().str.title()
    df["item"] = df["item"].str.strip()
    df.loc[df["unit_price"] > 500, "unit_price"] = df["unit_price"] // 100
    df["payment"] = df["payment"].fillna("unknown")
    df["date"] = pd.to_datetime(df["date"])
    df["month"] = df["date"].dt.month
    df["weekday"] = df["date"].dt.day_name()
    df["hour"] = df["time"].str[:2].astype(int)
    df["revenue"] = df["quantity"] * df["unit_price"]
    return df

df = load_clean("cafe_sales.csv")
assert df["order_id"].is_unique and df["unit_price"].max() < 500
print(len(df), "orders,", df["revenue"].sum(), "EGP")
```

```output
1452 orders, 152130 EGP
```

The `assert` line is a cheap safety check: if a future file breaks your assumptions, the notebook stops loudly instead of producing wrong numbers.

## Step 2: what sells, by season

```python
season = {12: "winter", 1: "winter", 2: "winter", 3: "spring", 4: "spring", 5: "spring",
          6: "summer", 7: "summer", 8: "summer", 9: "autumn", 10: "autumn", 11: "autumn"}
df["season"] = df["month"].map(season)
units = df.pivot_table(index="item", columns="season", values="quantity", aggfunc="sum", fill_value=0)
units = units[["winter", "spring", "summer", "autumn"]]
share = (units / units.sum() * 100).round(1)
print(share.loc[["iced latte", "mint lemonade", "hot chocolate", "tea", "cappuccino"]].to_string())
```

## Step 4: a simple forecast

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error

daily = df.groupby("date").agg(orders=("order_id", "count"), temp=("temp_c", "first")).reset_index()
daily["weekend"] = daily["date"].dt.dayofweek.isin([4, 5]).astype(int)
train = daily[daily["date"] < "2025-10-01"]          # learn from January to September
test = daily[daily["date"] >= "2025-10-01"]          # test on the last quarter: the future
features = ["temp", "weekend"]
model = LinearRegression().fit(train[features], train["orders"])
pred = model.predict(test[features])
print("baseline MAE:", round(mean_absolute_error(test["orders"], np.full(len(test), train["orders"].mean())), 2))
print("model MAE:   ", round(mean_absolute_error(test["orders"], pred), 2))
print(f"rule: orders = {model.intercept_:.1f} + {model.coef_[0]:.2f} x temp + {model.coef_[1]:.1f} x weekend")
```

```output
baseline MAE: 1.59
model MAE:    1.47
rule: orders = 1.2 + 0.10 x temp + 1.9 x weekend
```

Notice the split by **date**: train on the past, test on later months, exactly how a forecast is used. Whether the model beats the simple average here is itself a finding worth reporting honestly.

## Step 5: recommendations

End with plain sentences, numbers rounded, no jargon. A sample, based on the results above:

> **Recommendations for the owner**
>
> 1. **Prepare for iced drinks in summer.** Iced latte and mint lemonade make up a far larger share of sales in summer than in winter. Order more ice, milk and cold cups from May.
> 2. **Staff up on weekend afternoons.** Friday and Saturday from about 11 am to 4 pm are the busiest times all year; early mornings and evenings after 7 pm are quiet every day.
> 3. **Use the simple forecast as a rough guide only.** Daily orders are noisy; plan staff with a margin, and keep tracking real numbers to improve the forecast.
> 4. **Fix data entry.** We found duplicated orders, branch names typed in different ways, and prices entered 100 times too high. A drop-down list in the till would prevent most of these.
