# Cleaning data

Real data is messy. Cleaning is where data scientists spend most of their time, and where most mistakes in final results come from. The rule: **find each problem, decide on a fix, apply it, check it**.

```python
import pandas as pd
df = pd.read_csv("cafe_sales.csv")
print(len(df), "rows to start")
```

```output
1464 rows to start
```

## 1. Duplicate rows

```python
print("exact duplicates:", df.duplicated().sum())
df = df.drop_duplicates()
print("order_id repeated:", df["order_id"].duplicated().sum())
print(len(df), "rows now")
```

```output
exact duplicates: 12
order_id repeated: 0
1452 rows now
```

The same order recorded twice would double-count sales. After removing exact copies, check that the ID column really is unique.

## 2. Inconsistent text

```python
df["branch"] = df["branch"].str.strip().str.title()     # "MAADI" -> "Maadi"
df["item"] = df["item"].str.strip()                     # "basbousa " -> "basbousa"
print(df["branch"].value_counts().to_dict())
print(df["item"].nunique(), "different items")
```

```output
{'Zamalek': 569, 'Maadi': 479, 'Heliopolis': 404}
13 different items
```

`.str` gives text methods for a whole column: `strip` (remove spaces at the ends), `lower`, `upper`, `title`, `replace`, `contains`.

## 3. Impossible values

```python
print(df["unit_price"].describe().round(0).to_dict())
suspect = df[df["unit_price"] > 500]
print(suspect[["order_id", "item", "unit_price"]].to_string(index=False))
```

```output
{'count': 1452.0, 'mean': 72.0, 'std': 217.0, 'min': 23.0, '25%': 50.0, '50%': 60.0, '75%': 76.0, 'max': 5400.0}
 order_id         item  unit_price
    10087 falafel wrap        5400
    10085    croissant        4500
    10994     espresso        4500
```

An espresso or a croissant doesn't cost thousands of pounds. These look like prices typed with two extra zeros. Options: delete the rows, or fix them. Here the mistake is clear, so we fix them, and **write down** what we did:

```python
df.loc[df["unit_price"] > 500, "unit_price"] = df["unit_price"] // 100
print("max price now:", df["unit_price"].max())
```

```output
max price now: 104
```

`df.loc[rows, column] = value` changes only the selected cells.

## 4. Missing values

```python
print(df.isna().sum()[lambda s: s > 0].to_dict())
```

```output
{'payment': 15, 'rating': 116}
```

Different columns need different decisions:

- **payment** is missing for a few orders. We can't guess it, but the order still happened. Fill with the label "unknown" so those orders still count in sales.
- **rating** is missing because some customers didn't rate. Filling with the average would invent opinions. Leave it missing: pandas skips missing values in `mean()` and similar functions.

```python
df["payment"] = df["payment"].fillna("unknown")
print(df["payment"].value_counts().to_dict())
print("average rating (missing skipped):", round(df["rating"].mean(), 2))
```

```output
{'cash': 644, 'card': 518, 'wallet': 275, 'unknown': 15}
average rating (missing skipped): 3.93
```

Other tools: `dropna()` removes rows with missing values; `fillna(value)` fills them; `fillna(df[col].median())` fills with a typical value, which is fine for some measurements but never for opinions or IDs.

## 5. Correct types

Dates arrive as text. Convert them so you can sort, filter and group by month or weekday:

```python
df["date"] = pd.to_datetime(df["date"])
df["month"] = df["date"].dt.month
df["weekday"] = df["date"].dt.day_name()
df["hour"] = df["time"].str[:2].astype(int)
df["revenue"] = df["quantity"] * df["unit_price"]
print(df[["date", "month", "weekday", "hour", "revenue"]].head(3).to_string(index=False))
```

```output
      date  month   weekday  hour  revenue
2025-01-01      1 Wednesday    12       68
2025-01-01      1 Wednesday    15      144
2025-01-01      1 Wednesday    16      120
```

## Save the clean version

```python
df.to_csv("cafe_clean.csv", index=False)
print(len(df), "clean rows saved")
```

```output
1452 clean rows saved
```

Keep the original file untouched and save cleaning as code. Then anyone (including you, in three months) can see and rerun every step.

## A cleaning checklist

1. Duplicates: `duplicated()`, `drop_duplicates()`, check IDs are unique.
2. Text: `str.strip()`, consistent capitals, `value_counts()` to spot variants.
3. Impossible values: `describe()`, filters like `df[df.col > limit]`.
4. Missing values: `isna().sum()`, then decide per column: fill, drop, or keep missing.
5. Types: `to_datetime`, `astype`.
6. Write down every decision.

## Summary

- Find, decide, fix, check: for duplicates, text variants, impossible values, missing values and types.
- `.str` methods clean text columns; `df.loc[rows, col] = ...` fixes specific cells.
- Missing values need a decision per column; never invent data people didn't give.
