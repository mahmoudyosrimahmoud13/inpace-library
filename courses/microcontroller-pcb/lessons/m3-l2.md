# Your first programs

## Uploading with the Arduino IDE

1. Install the **Arduino IDE** (arduino.cc).
2. Board: **Arduino Uno** (your board is electrically an Uno: ATmega328P, 16 MHz, Uno bootloader).
3. Port: the one that appears when you plug your board (or adapter) in. On Windows the CH340 may need its driver.
4. Open the sketch below and press **Upload**.

```cpp
// Blink: the "hello world" of microcontrollers
const int LED_PIN = 13;              // PB5, pin 19 on the chip

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(500);                        // milliseconds
  digitalWrite(LED_PIN, LOW);
  delay(500);
}
```

`setup()` runs once at power-on; `loop()` runs again and again forever. If the LED blinks once per second, **your board works**: power, clock, reset, programming and the LED are all right. If it blinks 16 times too slowly, the clock fuses are wrong (module 3, lesson 1).

## Reading a button and printing to the computer

```cpp
const int BUTTON_PIN = 2;            // PD2: button to ground, internal pull-up
const int LED_PIN = 13;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP); // pressed = LOW
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("board ready");
}

void loop() {
  bool pressed = digitalRead(BUTTON_PIN) == LOW;
  digitalWrite(LED_PIN, pressed ? HIGH : LOW);
  int light = analogRead(A0);        // 0 to 1023 from an LDR divider on A0
  Serial.print("light: ");
  Serial.println(light);
  delay(200);
}
```

Open **Tools → Serial Monitor** at 9600 baud to see the readings. Printing values is your main debugging tool on a microcontroller.

## The same blink without Arduino: registers

Arduino functions are convenient wrappers. Underneath, every pin is controlled by bits in **registers**: special memory locations. For port B:

| Register | Each bit means |
|---|---|
| `DDRB` | direction: 1 = output, 0 = input |
| `PORTB` | output value (or pull-up on for inputs) |
| `PINB` | the pin's current input level |

<!-- skip -->
```c
// blink.c: plain C for the ATmega328P (compile with avr-gcc)
#define F_CPU 16000000UL
#include <avr/io.h>
#include <util/delay.h>

int main(void) {
    DDRB |= (1 << PB5);              // PB5 (D13) as output
    while (1) {
        PORTB ^= (1 << PB5);         // flip the LED
        _delay_ms(500);
    }
}
```

Build and upload with the AVR toolchain (installed with the Arduino IDE, or `sudo apt install gcc-avr avr-libc avrdude`):

```bash
avr-gcc -mmcu=atmega328p -Os blink.c -o blink.elf
avr-objcopy -O ihex blink.elf blink.hex
avrdude -c arduino -p m328p -P /dev/ttyUSB0 -b 115200 -U flash:w:blink.hex
```

The register version is several times smaller than the Arduino one. You'll use Arduino functions most of the time, but knowing the registers explains what's really happening, and it's how you squeeze out speed or size when you need to. (The C and pointer skills from the C course apply directly here.)

## Summary

- Select "Arduino Uno" and your board's port; Blink at 1 Hz proves the whole board works.
- `INPUT_PULLUP`, `digitalRead`, `analogRead` and `Serial.println` cover most first projects.
- Under the hood, `DDRx`, `PORTx` and `PINx` registers control the pins; avr-gcc and avrdude build and upload plain C.
