# Machine Learning 2: التنبؤ بفئة

**الـ classification** يتنبأ بتسمية بدل رقم: رسالة مزعجة أم لا، هل سيعود العميل أم لا، أي منتج سيختار.

## السؤال

*هل سيكون هذا الطلب مشروبًا مثلجًا؟* لو استطاعت السلسلة معرفة ذلك من الطقس والساعة والفرع، لجهّزت الثلج والأكواب مسبقًا.

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split

df = pd.read_csv("cafe_clean.csv", parse_dates=["date"])
df["iced"] = df["item"].isin(["iced latte", "mint lemonade"]).astype(int)
df["weekend"] = df["date"].dt.dayofweek.isin([4, 5]).astype(int)

X = pd.get_dummies(df[["temp_c", "hour", "weekend", "branch"]], columns=["branch"], dtype=int)
y = df["iced"]
print(list(X.columns))
print(f"{y.mean():.1%} of orders are iced drinks")

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=0, stratify=y)
```

```output
['temp_c', 'hour', 'weekend', 'branch_Heliopolis', 'branch_Maadi', 'branch_Zamalek']
18.0% of orders are iced drinks
```

- `pd.get_dummies` تحوّل عمود نص إلى أعمدة 0/1 (عمود لكل فرع)، لأن الـ models تحتاج أرقامًا. وهذا اسمه **الـ one-hot encoding**.
- `stratify=y` تحافظ على نفس نسبة الطلبات المثلجة في training and test sets.

## الـ logistic regression

رغم اسمه، إنه classifier. يتنبأ **باحتمال** التسمية:

```python
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

clf = LogisticRegression(max_iter=1000)
clf.fit(X_train, y_train)
pred = clf.predict(X_test)
print("accuracy:", round(accuracy_score(y_test, pred), 3))
print("always say 'not iced':", round(accuracy_score(y_test, np.zeros(len(y_test))), 3))
```

```output
accuracy: 0.818
always say 'not iced': 0.821
```

انظر: "model" يقول دائمًا "ليس مثلجًا" يحصل تقريبًا على نفس الدقة، لأن أغلب الطلبات ليست مثلجة. **الدقة (accuracy) مضللة عندما تكون إحدى الفئات نادرة.** نحتاج مقاييس أفضل.

## confusion matrix

```python
from sklearn.metrics import confusion_matrix, precision_score, recall_score
print(confusion_matrix(y_test, pred))
print("precision:", round(precision_score(y_test, pred, zero_division=0), 2))
print("recall:", round(recall_score(y_test, pred), 2))
```

```output
[[297   1]
 [ 65   0]]
precision: 0.0
recall: 0.0
```

```text
                        المتوقع: ليس مثلجًا   المتوقع: مثلج
الحقيقي: ليس مثلجًا    سلبي صحيح             إيجابي خاطئ
الحقيقي: مثلج          سلبي خاطئ             إيجابي صحيح
```

- **الـ precision**: من الطلبات التي قلنا إنها "مثلجة"، كم منها كان كذلك فعلًا؟
- **الـ recall**: من الطلبات المثلجة الحقيقية، كم منها التقطنا؟

## اختيار الـ threshold

افتراضيًا يقول الـ model "مثلج" عندما يكون الاحتمال أعلى من 50%. ولتجهيز الثلج، تفويت الطلبات المثلجة أسوأ من تجهيز أكواب زائدة قليلة، فاخفض الـ threshold لتلتقط أكثر:

```python
proba = clf.predict_proba(X_test)[:, 1]          # probability of "iced"
for t in [0.5, 0.3, 0.2]:
    p = (proba >= t).astype(int)
    print(f"threshold {t}: precision {precision_score(y_test, p, zero_division=0):.2f}, recall {recall_score(y_test, p):.2f}")
```

```output
threshold 0.5: precision 0.00, recall 0.00
threshold 0.3: precision 0.37, recall 0.38
threshold 0.2: precision 0.32, recall 0.65
```

threshold أقل، recall أعلى، ودقة نوعية أقل. ولا توجد threshold صحيحة دائمًا: الأمر يعتمد على **تكلفة** كل نوع من الأخطاء في موقفك.

## ماذا تعلّم الـ model

```python
coefs = pd.Series(clf.coef_[0], index=X.columns).round(2).sort_values()
print(coefs.to_string())
```

```output
branch_Heliopolis   -0.12
weekend             -0.12
hour                 0.03
branch_Maadi         0.06
branch_Zamalek       0.06
temp_c               0.14
```

الحرارة لها أوضح أثر موجب: أحر يعني احتمالًا أكبر أن يكون مثلجًا. وهذا يطابق ما أظهرته الرسوم، وهي علامة جيدة على أن الـ model تعلّم شيئًا حقيقيًا.

## decision tree للمقارنة

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import roc_auc_score

tree = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X_train, y_train)
print("tree AUC:", round(roc_auc_score(y_test, tree.predict_proba(X_test)[:, 1]), 3))
print("logistic AUC:", round(roc_auc_score(y_test, proba), 3))
```

```output
tree AUC: 0.704
logistic AUC: 0.738
```

‏**AUC** (المساحة تحت منحنى ROC) يقيس مدى جودة الاحتمالات في **ترتيب** الطلبات المثلجة فوق غير المثلجة، عبر كل العتبات: 0.5 تخمين، و1.0 مثالي. وهو رقم واحد جيد لمقارنة الـ classifiers مع الفئات النادرة.

## الخلاصة

- الـ classifiers تتنبأ بتسميات واحتمالات؛ ورمّز الـ features النصية ترميزًا أحاديًا.
- الدقة مضللة مع الفئات النادرة؛ استخدم confusion matrix والـ precision والـ recall وAUC.
- اختر الـ threshold حسب تكلفة كل نوع من الأخطاء.
