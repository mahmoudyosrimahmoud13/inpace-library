# تنظيف البيانات

البيانات الحقيقية فوضوية. والتنظيف هو المكان الذي يقضي فيه علماء البيانات أغلب وقتهم، ومنه تأتي أغلب الأخطاء في النتائج النهائية. والقاعدة: **اكتشف كل مشكلة، وقرر الإصلاح، وطبّقه، وتحقق منه**.

```python
import pandas as pd
df = pd.read_csv("cafe_sales.csv")
print(len(df), "rows to start")
```

```output
1464 rows to start
```

## ‏1. الصفوف المكررة

```python
print("exact duplicates:", df.duplicated().sum())
df = df.drop_duplicates()
print("order_id repeated:", df["order_id"].duplicated().sum())
print(len(df), "rows now")
```

```output
exact duplicates: 12
order_id repeated: 0
1452 rows now
```

نفس الطلب مسجلًا مرتين سيضاعف المبيعات. وبعد حذف النسخ المتطابقة، تحقق من أن عمود رقم الطلب فريد فعلًا.

## ‏2. نصوص غير متسقة

```python
df["branch"] = df["branch"].str.strip().str.title()     # "MAADI" -> "Maadi"
df["item"] = df["item"].str.strip()                     # "basbousa " -> "basbousa"
print(df["branch"].value_counts().to_dict())
print(df["item"].nunique(), "different items")
```

```output
{'Zamalek': 569, 'Maadi': 479, 'Heliopolis': 404}
13 different items
```

‏`.str` تعطي functions النصوص لعمود كامل: `strip` (حذف المسافات من الطرفين)، و`lower` و`upper` و`title` و`replace` و`contains`.

## ‏3. قيم مستحيلة

```python
print(df["unit_price"].describe().round(0).to_dict())
suspect = df[df["unit_price"] > 500]
print(suspect[["order_id", "item", "unit_price"]].to_string(index=False))
```

```output
{'count': 1452.0, 'mean': 72.0, 'std': 217.0, 'min': 23.0, '25%': 50.0, '50%': 60.0, '75%': 76.0, 'max': 5400.0}
 order_id         item  unit_price
    10087 falafel wrap        5400
    10085    croissant        4500
    10994     espresso        4500
```

الإسبريسو أو الكرواسون لا يكلف آلاف الجنيهات. هذه تبدو أسعارًا كُتبت بصفرين زائدين. والخيارات: حذف الصفوف، أو إصلاحها. وهنا الخطأ واضح، فنصلحها، و**نكتب** ما فعلناه:

```python
df.loc[df["unit_price"] > 500, "unit_price"] = df["unit_price"] // 100
print("max price now:", df["unit_price"].max())
```

```output
max price now: 104
```

‏`df.loc[rows, column] = value` تغيّر الـ cells المختارة فقط.

## ‏4. القيم الناقصة

```python
print(df.isna().sum()[lambda s: s > 0].to_dict())
```

```output
{'payment': 15, 'rating': 116}
```

أعمدة مختلفة تحتاج قرارات مختلفة:

- **payment** ناقص في طلبات قليلة. لا نستطيع تخمينه، لكن الطلب حدث فعلًا. املأه بالكلمة "unknown" لكي تظل هذه الطلبات محسوبة في المبيعات.
- **rating** ناقص لأن بعض العملاء لم يقيّموا. وملؤه بالمتوسط سيخترع آراء. اتركه ناقصًا: pandas تتخطى القيم الناقصة في `mean()` والـ functions المشابهة.

```python
df["payment"] = df["payment"].fillna("unknown")
print(df["payment"].value_counts().to_dict())
print("average rating (missing skipped):", round(df["rating"].mean(), 2))
```

```output
{'cash': 644, 'card': 518, 'wallet': 275, 'unknown': 15}
average rating (missing skipped): 3.93
```

أدوات أخرى: `dropna()` تحذف الصفوف التي فيها قيم ناقصة؛ و`fillna(value)` تملؤها؛ و`fillna(df[col].median())` تملؤها بقيمة نموذجية، وهذا مقبول لبعض القياسات لكن أبدًا للآراء أو الأرقام التعريفية.

## ‏5. الأنواع الصحيحة

التواريخ تصل كنص. حوّلها لكي تستطيع الترتيب والتصفية والتجميع بالشهر أو يوم الأسبوع:

```python
df["date"] = pd.to_datetime(df["date"])
df["month"] = df["date"].dt.month
df["weekday"] = df["date"].dt.day_name()
df["hour"] = df["time"].str[:2].astype(int)
df["revenue"] = df["quantity"] * df["unit_price"]
print(df[["date", "month", "weekday", "hour", "revenue"]].head(3).to_string(index=False))
```

```output
      date  month   weekday  hour  revenue
2025-01-01      1 Wednesday    12       68
2025-01-01      1 Wednesday    15      144
2025-01-01      1 Wednesday    16      120
```

## احفظ النسخة النظيفة

```python
df.to_csv("cafe_clean.csv", index=False)
print(len(df), "clean rows saved")
```

```output
1452 clean rows saved
```

اترك الملف الأصلي كما هو، واحفظ التنظيف ككود. وحينها يستطيع أي شخص (ومنهم أنت بعد ثلاثة أشهر) رؤية كل خطوة وإعادة تشغيلها.

## قائمة تحقق للتنظيف

1. المكرر: `duplicated()` و`drop_duplicates()`، وتأكد أن الأرقام التعريفية فريدة.
2. النصوص: `str.strip()`، وحروف كبيرة متسقة، و`value_counts()` لاكتشاف الأشكال المختلفة.
3. القيم المستحيلة: `describe()`، وتصفيات مثل `df[df.col > limit]`.
4. القيم الناقصة: `isna().sum()`، ثم قرر لكل عمود: املأ، أو احذف، أو اتركه ناقصًا.
5. الأنواع: `to_datetime` و`astype`.
6. اكتب كل قرار.

## الخلاصة

- اكتشف، وقرر، وأصلح، وتحقق: للمكرر، وأشكال النصوص المختلفة، والقيم المستحيلة، والقيم الناقصة، والأنواع.
- functions `.str` تنظّف أعمدة النصوص؛ و`df.loc[rows, col] = ...` تصلح cells محددة.
- القيم الناقصة تحتاج قرارًا لكل عمود؛ ولا تخترع أبدًا بيانات لم يعطها الناس.
