# الإحصاء 1: المركز والانتشار والـ distributions

الإحصاء هو لغة وصف البيانات بصدق: ما هو النموذجي، وكم تختلف الأشياء، وإلى أي حد يمكن أن نكون متأكدين.

```python
import pandas as pd
import numpy as np
df = pd.read_csv("cafe_clean.csv", parse_dates=["date"])
print(len(df), "orders")
```

```output
1452 orders
```

## المركز: المتوسط مقابل الوسيط

```python
spend = df["revenue"]
print("mean:", round(spend.mean(), 1))
print("median:", spend.median())
print("mode:", spend.mode()[0])
```

```output
mean: 104.8
median: 89.0
mode: 50
```

- **المتوسط (mean)**: المجموع مقسومًا على العدد. يتأثر بالقيم المتطرفة.
- **الوسيط (median)**: القيمة الوسطى بعد الترتيب. نصف الطلبات أقل منه ونصفها أكبر.
- **المنوال (mode)**: القيمة الأكثر تكرارًا.

المتوسط أعلى من الوسيط لأن طلبات كبيرة قليلة تسحبه لأعلى. وعندما يكون للبيانات ذيل طويل (الدخول، وأسعار البيوت، وأحجام الطلبات)، اذكر **الوسيط** كقيمة "نموذجية"، أو اذكر الاثنين.

مثال سريع يبيّن كيف تحرّك قيمة متطرفة واحدة المتوسط لا الوسيط:

```python
salaries = [7000, 8000, 8500, 9000, 9500]
print(np.mean(salaries), np.median(salaries))
salaries.append(250000)              # the owner joins the table
print(round(np.mean(salaries)), np.median(salaries))
```

```output
8400.0 8500.0
48667 8750.0
```

## الانتشار: كم تختلف القيم

```python
print("range:", spend.min(), "to", spend.max())
print("std:", round(spend.std(), 1))
q1, q3 = spend.quantile([0.25, 0.75])
print(f"middle half between {q1} and {q3} (IQR {q3 - q1})")
```

```output
range: 23 to 312
std: 59.0
middle half between 59.0 and 138.0 (IQR 79.0)
```

- **الـ standard deviation (std)**: تقريبًا المسافة النموذجية عن المتوسط. انحراف صغير = قيم قريبة من بعضها.
- **الـ quartiles**: ‏25% من القيم أقل من Q1، و75% أقل من Q3. و**الـ IQR** ‏(Q3 ناقص Q1) هو انتشار النصف الأوسط، ولا تحرّكه القيم المتطرفة.

## الـ distributions

**الـ distribution** هو شكل كل القيم: أين تتجمع وإلى أين تمتد. والـ histogram يبيّنه (رسمت واحدًا في الوحدة السابقة). وشكلان هما الأهم:

- **الطبيعي** ("منحنى الجرس"): متماثل حول المتوسط. الأطوال، وأخطاء القياس، ودرجات الحرارة في موسم واحد.
- **الملتوي**: ذيل طويل على جانب واحد. قيم الطلبات، والدخول، وأوقات الانتظار.

```python
rng = np.random.default_rng(1)
heights = rng.normal(loc=170, scale=8, size=10_000)       # simulated heights in cm
within_1 = np.mean(np.abs(heights - 170) <= 8) * 100
within_2 = np.mean(np.abs(heights - 170) <= 16) * 100
print(f"within 1 std: {within_1:.0f}%   within 2 std: {within_2:.0f}%")
```

```output
within 1 std: 69%   within 2 std: 96%
```

في الـ normal distribution، حوالي **68%** من القيم تقع في حدود standard deviation واحد من المتوسط، وحوالي **95%** في حدود انحرافين. ولهذا "أبعد من 2 standard deviations" قاعدة شائعة لاكتشاف القيم غير العادية.

## z-scores: ما مدى غرابة هذه القيمة؟

```python
daily = df.groupby("date")["revenue"].sum()
z = (daily - daily.mean()) / daily.std()
print("days more than 2.5 std above average:")
print(daily[z > 2.5].astype(int).to_string())
```

```output
days more than 2.5 std above average:
date
2025-05-29    1274
2025-06-18    1351
2025-07-26    1267
2025-08-15    1173
2025-08-22    1279
2025-09-13    1124
2025-12-13    1284
```

**z-score** تقول كم انحرافًا معياريًا تبعد القيمة عن المتوسط. وتسمح لك بمقارنة أشياء بمقاييس مختلفة، وتمييز الأيام غير العادية التي تستحق نظرة أقرب.

## النسب والمعدلات

الأعداد الخام قد تضلل عندما تختلف أحجام المجموعات. قارن **المعدلات**:

```python
by_branch = df.groupby("branch").agg(orders=("order_id", "count"),
                                     wallet=("payment", lambda s: (s == "wallet").sum()))
by_branch["wallet_share_%"] = (by_branch["wallet"] / by_branch["orders"] * 100).round(1)
print(by_branch.to_string())
```

```output
            orders  wallet  wallet_share_%
branch                                    
Heliopolis     404      80            19.8
Maadi          479      98            20.5
Zamalek        569      97            17.0
```

المعادي والزمالك لهما تقريبًا نفس **عدد** مدفوعات المحفظة، لكن الزمالك فيه طلبات أكثر بكثير، فتكون **نسبته** الأقل بين الثلاثة. والنظر إلى الأعداد فقط كان سيخفي ذلك.

## الخلاصة

- المركز: المتوسط (يتأثر بالمتطرف)، والوسيط (ثابت)، والمنوال.
- الانتشار: الـ standard deviation، والـ quartiles والـ IQR؛ و68% و95% في حدود انحراف وانحرافين للبيانات الطبيعية.
- z-scores تميّز القيم غير العادية؛ وقارن المعدلات لا الأعداد الخام بين مجموعات مختلفة الحجم.
