# بايثون التي تحتاجها للبيانات

لا تحتاج كل بايثون للعمل مع البيانات. وهذا الدرس يغطي الأجزاء التي ستستخدمها كل يوم. ولو كنت تعرف بايثون بالفعل، فمُرّ عليه سريعًا.

## الأرقام والنصوص والصح والخطأ

```python
temp = 31.5            # float: a number with a decimal point
orders = 120           # int: a whole number
branch = "Zamalek"     # str: text
is_weekend = True      # bool: True or False

print(type(temp).__name__, type(orders).__name__, type(branch).__name__, type(is_weekend).__name__)
print(orders / 7, orders // 7, orders % 7)
print(branch.upper(), len(branch), branch.startswith("Zam"))
```

```output
float int str bool
17.142857142857142 17 1
ZAMALEK 7 True
```

‏`/` تقسم قسمة عادية، و`//` تعطي الجزء الصحيح، و`%` الباقي.

## القوائم: عدة قيم بترتيب

```python
prices = [45, 65, 70, 30, 55]
print(prices[0], prices[-1])        # first and last
print(prices[1:3])                  # a slice: items 1 and 2
prices.append(90)
print(len(prices), sum(prices), max(prices))
print(sorted(prices, reverse=True))
```

```output
45 55
[65, 70]
6 355 90
[90, 70, 65, 55, 45, 30]
```

المواضع تبدأ من 0، و`-1` معناها العنصر الأخير.

## القواميس: ابحث عن الأشياء بالاسم

```python
menu = {"tea": 30, "latte": 70, "brownie": 55}
print(menu["latte"])
menu["croissant"] = 50
for item, price in menu.items():
    print(f"{item:10} {price:>4}")
print("cake" in menu)
```

```output
70
tea          30
latte        70
brownie      55
croissant    50
False
```

‏`{item:10}` تملأ حتى 10 حروف؛ و`{price:>4}` تحاذي لليمين في 4 خانات.

## الـ loops والشروط

```python
temps = [18.5, 24.0, 31.2, 35.8, 27.3]
for t in temps:
    if t >= 30:
        label = "hot"
    elif t >= 22:
        label = "warm"
    else:
        label = "cool"
    print(t, label)
```

```output
18.5 cool
24.0 warm
31.2 hot
35.8 hot
27.3 warm
```

بايثون تستخدم **الإزاحة** (4 مسافات) لتبيّن ما بداخل الـ loop أو داخل `if`. بدون أقواس معقوصة.

## بناء القوائم في سطر (List comprehensions)

طريقة في سطر واحد لبناء قائمة من قائمة أخرى:

```python
hot_days = [t for t in temps if t >= 30]
in_fahrenheit = [round(t * 9 / 5 + 32) for t in temps]
print(hot_days)
print(in_fahrenheit)
```

```output
[31.2, 35.8]
[65, 75, 88, 96, 81]
```

ستراها في كل مكان. اقرأها هكذا: "**القيمة** لكل عنصر **في** القائمة **لو** تحقق الشرط".

## الـ functions

```python
def with_tax(price, rate=0.14):
    """Price including tax. rate is 14% unless you give another."""
    return round(price * (1 + rate), 2)

print(with_tax(100))
print(with_tax(100, rate=0.05))
print([with_tax(p) for p in [30, 65]])
```

```output
114.0
105.0
[34.2, 74.1]
```

‏`rate=0.14` **قيمة افتراضية**: تُستخدم عندما لا تمرر نسبة.

## لماذا لا نستخدم القوائم للبيانات فقط؟

تستطيع تخزين سنة من الطلبات كقائمة من القواميس والمرور عليها بloop. هذا يعمل، لكنه بطيء في الكتابة وبطيء في التشغيل. أما pandas فتعطيك **جدولًا** يفعل فيه سطر واحد ما تحتاج loop لعشرة أسطر لفعله:

```python
orders = [
    {"item": "latte", "qty": 2, "price": 70},
    {"item": "tea", "qty": 1, "price": 30},
    {"item": "latte", "qty": 1, "price": 70},
]
total = 0
for o in orders:
    total += o["qty"] * o["price"]
print("with a loop:", total)

import pandas as pd
df = pd.DataFrame(orders)
print("with pandas:", (df["qty"] * df["price"]).sum())
```

```output
with a loop: 240
with pandas: 240
```

الوحدة القادمة: pandas كما يجب.

## الخلاصة

- int وfloat وstr وbool؛ والقوائم للقيم المرتبة، والقواميس للبحث.
- الـ loops و`if` تستخدم الإزاحة؛ وبناء القوائم في سطر يصنع القوائم في سطر واحد.
- الـ functions بـ `def` والقيم الافتراضية مثل `rate=0.14`؛ ولجداول البيانات استخدم pandas.
