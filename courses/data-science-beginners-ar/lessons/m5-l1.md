# Machine Learning 1: التنبؤ برقم

**machine learning** معناه أن تترك الكمبيوتر يجد قاعدة من الأمثلة بدل أن تكتب القاعدة بنفسك. تعطيه مدخلات (**features features**) والإجابات الصحيحة (**الهدف target**)، فيتعلم **model**، والـ model يتنبأ بإجابات لمدخلات جديدة.

```mermaid
flowchart LR
  D[بيانات سابقة: خصائص + إجابات] --> S{قسّم}
  S --> TR[مجموعة التدريب 80%]
  S --> TE[مجموعة الاختبار 20%]
  TR --> F[model.fit]
  F --> M[نموذج مدرّب]
  TE --> P[model.predict]
  M --> P
  P --> E[قارن بالإجابات الحقيقية]
```

الفكرة الأساسية: احكم على الـ model فقط ببيانات **لم** يتعلم منها. وإلا فأنت تمتحن طالبًا بنفس الأسئلة التي حفظها.

## السؤال

*كم طلبًا ستحصل عليه السلسلة غدًا؟* العاملون والمخزون يعتمدون على ذلك. لنبنِ صفًا لكل يوم:

```python
import pandas as pd
import numpy as np
df = pd.read_csv("cafe_clean.csv", parse_dates=["date"])

daily = df.groupby("date").agg(orders=("order_id", "count"), temp=("temp_c", "first")).reset_index()
daily["weekend"] = daily["date"].dt.dayofweek.isin([4, 5]).astype(int)    # Friday, Saturday
daily["month"] = daily["date"].dt.month
daily["summer"] = daily["month"].between(6, 9).astype(int)
print(daily.head(3).to_string(index=False))
print(len(daily), "days with orders")
```

```output
      date  orders  temp  weekend  month  summer
2025-01-01       4  10.5        0      1       0
2025-01-02       2  11.0        0      1       0
2025-01-03       3  12.0        1      1       0
352 days with orders
```

## التدريب والاختبار

```python
from sklearn.model_selection import train_test_split

X = daily[["temp", "weekend", "summer"]]          # features (capital X by custom)
y = daily["orders"]                                # target
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
print(len(X_train), "days to learn from,", len(X_test), "days to test on")
```

```output
281 days to learn from, 71 days to test on
```

‏`random_state=0` تجعل التقسيم العشوائي نفسه في كل تشغيل، فتكون نتائجك قابلة للتكرار.

## baseline أولًا

قبل أي model، اسأل: كم ستكون نتيجة تخمين بسيط؟ هنا "تنبأ دائمًا بالمتوسط":

```python
from sklearn.metrics import mean_absolute_error
baseline = np.full(len(y_test), y_train.mean())
print("baseline error:", round(mean_absolute_error(y_test, baseline), 2), "orders per day")
```

```output
baseline error: 1.87 orders per day
```

**متوسط الخطأ المطلق (MAE)**: في المتوسط، كم تبعد التنبؤات، بوحدات الهدف. والـ model لا يفيد إلا لو تفوّق على baseline.

## الـ linear regression

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X_train, y_train)
pred = model.predict(X_test)
print("model error:", round(mean_absolute_error(y_test, pred), 2), "orders per day")
for name, coef in zip(X.columns, model.coef_):
    print(f"  {name:8} {coef:+.2f}")
print(f"  start    {model.intercept_:+.2f}")
```

```output
model error: 1.74 orders per day
  temp     +0.10
  weekend  +1.55
  summer   -0.14
  start    +1.39
```

الـ linear regression يتعلم: **الطلبات = البداية + a × الحرارة + b × عطلة نهاية الأسبوع + c × الصيف**. والمعاملات مقروءة: يوم عطلة نهاية الأسبوع يضيف حوالي 1.5 طلب، وكل درجة حرارة إضافية تضيف حوالي 0.1. وهذه القابلية للقراءة هي سبب أن الـ models الخطية اختيار أول ممتاز.

لماذا `summer` سالب قليلًا، مع أن الصيف هو الموسم المزدحم؟ لأن أيام الصيف أيام حارة أيضًا، و`temp` تحمل بالفعل أغلب هذا الأثر. وعندما تتداخل الـ features هكذا، قد تبدو المعاملات المفردة غريبة، فاقرأها معًا لا واحدًا واحدًا.

إنه يتفوق على baseline، لكن الطلبات اليومية فيها ضوضاء (عدد كل يوم عشوائي حول مستواه النموذجي)، فلا يوجد model دقيق تمامًا. والصدق في ذلك جزء من العمل.

## ‏R²: كم يُفسَّر

```python
from sklearn.metrics import r2_score
print("R2 on test days:", round(r2_score(y_test, pred), 2))
```

```output
R2 on test days: 0.15
```

‏**R²** هي نسبة التباين التي يفسرها الـ model: 1 مثالي، و0 ليس أفضل من المتوسط. وR² متواضع أمر عادي للأعداد الواقعية التي فيها ضوضاء. والمهم: هل التنبؤات جيدة بما يكفي للقرار (هنا، تخطيط تقريبي للعاملين).

## regression models أخرى

‏`LinearRegression` ترسم علاقات خطوط مستقيمة. وللأنماط المنحنية والمتفاعلة، جرّب `DecisionTreeRegressor` أو `RandomForestRegressor` من scikit-learn: نفس استدعاءات `fit` و`predict`. وقارن دائمًا بbaseline وبالنموذج البسيط على مجموعة **الاختبار**.

## الخلاصة

- machine learning يتعلم قاعدة من الأمثلة: الـ features X، والهدف y، ثم `fit` ثم `predict`.
- قسّم إلى تدريب واختبار؛ وقيّم على بيانات الاختبار فقط؛ وقارن بbaseline.
- الـ linear regression مقروء (المعاملات)؛ وMAE وR² يقيسان جودته.
