# ما هو الـ Data Science، وأول notebook لك

data science هو تحويل البيانات إلى إجابات وقرارات. صاحب مقهى يسأل "أي فرع يبيع مشروبات مثلجة أكثر في الصيف؟"، ومستشفى يسأل "أي المرضى غالبًا سيعودون؟"، وبنك يسأل "هل هذه العملية احتيال؟". وعالم البيانات يحصل على البيانات، وينظفها، ويستكشفها، ويقيس الأشياء، ويبني models تتنبأ، ويشرح النتائج للناس.

هذا الكورس يأخذك من الصفر إلى مشروع صغير كامل. ستستخدم **بايثون**، أشهر لغة للعمل مع البيانات، وستعمل طوال الكورس على مجموعة بيانات واقعية واحدة: سنة من الطلبات في سلسلة مقاهٍ خيالية في القاهرة.

## خطوات العمل في data science

```mermaid
flowchart LR
  Q[اسأل سؤالًا واضحًا] --> G[احصل على البيانات]
  G --> C[نظّفها]
  C --> E[استكشف: جداول ورسوم]
  E --> M[قِس وابنِ نموذجًا]
  M --> T[احكِ القصة]
  T -. أسئلة جديدة .-> Q
```

أغلب الوقت يذهب في المنتصف: الحصول على البيانات وتنظيفها واستكشافها. والـ models جزء صغير، ولا تنجح إلا عندما تكون الخطوات السابقة متقنة.

## أداتك: Google Colab

**Colab** ‏(colab.research.google.com) يشغّل بايثون في متصفحك مجانًا، وكل مكتبات البيانات مثبتة فيه بالفعل. لا شيء لتثبيته، ويعمل على أي كمبيوتر.

1. ادخل على colab.research.google.com وسجّل الدخول بحساب Google.
2. اضغط **New notebook**.
3. اكتب في الـ cell الأولى واضغط **Shift+Enter** لتشغيلها.

**الـ notebook** صفحة من الـ cells. cells الكود تشغّل بايثون وتعرض النتيجة تحتها مباشرة. وcells النص فيها ملاحظات. تستطيع تشغيل الـ cells بأي ترتيب، لكن الـ notebooks أسهل في الفهم عندما تشغّلها من أعلى لأسفل.

(تفضّل كمبيوترك؟ ثبّت Anaconda، أو بايثون ثم `pip install pandas matplotlib scikit-learn jupyter`، ثم شغّل `jupyter notebook`. كل ما في الكورس يعمل بنفس الطريقة.)

## أول الـ cells

```python
print("Hello, data!")
2 + 3 * 4
```

```output
Hello, data!
```

في الـ notebook، آخر سطر في الـ cell يُعرض تلقائيًا، فسترى أيضًا `14` تحت الـ cell. وفي هذا الكورس نستخدم `print()` لكي ترى بالضبط ما تعرضه كل cell.

```python
price = 65
cups = 3
total = price * cups
print("Total:", total, "EGP")
print(f"Average per cup: {total / cups:.1f}")
```

```output
Total: 195 EGP
Average per cup: 65.0
```

- **الـ variable** يخزّن قيمة تحت اسم: `price = 65`.
- `f"...{expression}..."` هي **f-string**: بايثون تضع القيمة داخل النص. و`:.1f` معناها منزلة عشرية واحدة.

## المكتبات التي ستستخدمها

| المكتبة | لـ |
|---|---|
| **pandas** | جداول البيانات: التحميل والتنظيف والتصفية والتجميع والدمج |
| **NumPy** | حسابات سريعة على arrays الأرقام (pandas مبنية عليها) |
| **matplotlib** | الرسوم البيانية |
| **scikit-learn** | models machine learning |

```python
import pandas as pd
import numpy as np
import matplotlib
import sklearn
print("pandas is ready:", pd.__name__)
print("numpy works:", np.mean([2, 4, 6]))
```

```output
pandas is ready: pandas
numpy works: 4.0
```

‏`import pandas as pd` عادة عالمية: الجميع يكتب `pd.` لـ pandas و`np.` لـ NumPy.

## عادات جيدة من اليوم الأول

- أعطِ الـ variables أسماء واضحة: `monthly_sales` لا `x2`.
- اكتب cell نص فوق كل خطوة تقول **أي سؤال تجيب عنه**.
- أعد التشغيل وشغّل كل شيء من الأعلى (Runtime ← Restart and run all) قبل مشاركة الـ notebook. لو لم يعمل من أعلى لأسفل، فهو مكسور.
- اترك البيانات الأصلية كما هي؛ ونظّف في variable جديد.

## الخلاصة

- data science: سؤال ← بيانات ← تنظيف ← استكشاف ← قياس وmodel ← قصة.
- ‏Colab يشغّل notebooks بايثون في المتصفح وكل شيء مثبت؛ وShift+Enter تشغّل الـ cell.
- ‏pandas للجداول، وNumPy للحسابات، وmatplotlib للرسوم، وscikit-learn للـ models.
