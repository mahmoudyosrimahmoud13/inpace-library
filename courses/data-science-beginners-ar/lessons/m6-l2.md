## الخطوة 1: التحميل والتنظيف (أعد استخدام شغلك)

ضع خطوات التنظيف من الوحدة 2 في function واحدة، لكي يبدأ التحليل كله من الملف الخام:

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

def load_clean(path):
    df = pd.read_csv(path).drop_duplicates()
    df["branch"] = df["branch"].str.strip().str.title()
    df["item"] = df["item"].str.strip()
    df.loc[df["unit_price"] > 500, "unit_price"] = df["unit_price"] // 100
    df["payment"] = df["payment"].fillna("unknown")
    df["date"] = pd.to_datetime(df["date"])
    df["month"] = df["date"].dt.month
    df["weekday"] = df["date"].dt.day_name()
    df["hour"] = df["time"].str[:2].astype(int)
    df["revenue"] = df["quantity"] * df["unit_price"]
    return df

df = load_clean("cafe_sales.csv")
assert df["order_id"].is_unique and df["unit_price"].max() < 500
print(len(df), "orders,", df["revenue"].sum(), "EGP")
```

```output
1452 orders, 152130 EGP
```

سطر `assert` تحقق أمان رخيص: لو كسر ملف مستقبلي افتراضاتك، يتوقف الـ notebook بوضوح بدل أن ينتج أرقامًا خطأ.

## الخطوة 2: ما الذي يُباع، حسب الموسم

```python
season = {12: "winter", 1: "winter", 2: "winter", 3: "spring", 4: "spring", 5: "spring",
          6: "summer", 7: "summer", 8: "summer", 9: "autumn", 10: "autumn", 11: "autumn"}
df["season"] = df["month"].map(season)
units = df.pivot_table(index="item", columns="season", values="quantity", aggfunc="sum", fill_value=0)
```

## الخطوة 4: تنبؤ بسيط

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error

daily = df.groupby("date").agg(orders=("order_id", "count"), temp=("temp_c", "first")).reset_index()
daily["weekend"] = daily["date"].dt.dayofweek.isin([4, 5]).astype(int)
train = daily[daily["date"] < "2025-10-01"]          # learn from January to September
test = daily[daily["date"] >= "2025-10-01"]          # test on the last quarter: the future
features = ["temp", "weekend"]
model = LinearRegression().fit(train[features], train["orders"])
pred = model.predict(test[features])
print("baseline MAE:", round(mean_absolute_error(test["orders"], np.full(len(test), train["orders"].mean())), 2))
print("model MAE:   ", round(mean_absolute_error(test["orders"], pred), 2))
print(f"rule: orders = {model.intercept_:.1f} + {model.coef_[0]:.2f} x temp + {model.coef_[1]:.1f} x weekend")
```

```output
baseline MAE: 1.59
model MAE:    1.47
rule: orders = 1.2 + 0.10 x temp + 1.9 x weekend
```

لاحظ أن التقسيم **بالتاريخ**: تدرّب على الماضي وتختبر على شهور لاحقة، تمامًا كما يُستخدم التنبؤ. وهل يتفوق الـ model على المتوسط البسيط هنا أم لا؟ هذه نفسها نتيجة تستحق أن تُذكر بصدق.

## الخطوة 5: التوصيات

اختم بجمل بسيطة، وأرقام مقرّبة، وبدون مصطلحات صعبة. مثال مبني على النتائج أعلاه:

> **توصيات لصاحب السلسلة**
>
> 1. **استعد للمشروبات المثلجة في الصيف.** الآيس لاتيه والليمون بالنعناع نسبتهما من المبيعات في الصيف أكبر بكثير منها في الشتاء. اطلب ثلجًا وحليبًا وأكوابًا باردة أكثر من مايو.
> 2. **زد العاملين بعد ظهر عطلة نهاية الأسبوع.** الجمعة والسبت من حوالي 11 صباحًا حتى 4 عصرًا هما أكثر الأوقات ازدحامًا طوال السنة؛ والصباح الباكر والمساء بعد 7 هادئان كل يوم.
> 3. **استخدم التنبؤ البسيط كدليل تقريبي فقط.** الطلبات اليومية فيها ضوضاء؛ فخطط للعاملين مع هامش، واستمر في تتبع الأرقام الحقيقية لتحسين التنبؤ.
> 4. **أصلح إدخال البيانات.** وجدنا طلبات مكررة، وأسماء فروع مكتوبة بطرق مختلفة، وأسعارًا مُدخلة أكبر بمئة مرة. وقائمة اختيار في نظام الكاشير ستمنع أغلب ذلك.
