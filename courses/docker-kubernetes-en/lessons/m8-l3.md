# Logical architecture: Pods, Deployments, Services

| Resource | What it is |
|---|---|
| Pod | the smallest unit: one or more containers sharing network and storage |
| ReplicaSet | keeps a number of Pod copies |
| Deployment | manages ReplicaSets: updates and rollbacks |
| Service | a stable address in front of changing Pods (ClusterIP, NodePort, LoadBalancer) |
| ConfigMap / Secret | settings and secrets |
| Namespace | divides the cluster |
| Ingress | routes HTTP from outside by host and path |
