# Containerizing an application

1. The code. 2. A **Dockerfile** describing the environment. 3. `docker build`. 4. `docker run`, then `docker push`.

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["python", "app.py"]
```

```bash
docker build -t myapp:1.0 .
docker run -d -p 8000:8000 myapp:1.0
```

Copying requirements.txt **before** the rest of the code means libraries are reinstalled only when they change.
