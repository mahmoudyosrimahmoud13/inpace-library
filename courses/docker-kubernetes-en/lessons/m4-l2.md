# Networking (part 1 of 2)

| Driver | Use |
|---|---|
| bridge | default: a private network on one machine |
| host | the container uses the machine's network directly |
| none | no network |
| overlay | a network across several machines (Swarm) |
| macvlan | the container appears as a device on the real network |

```bash
docker network ls
docker network create mynet
docker run -d --name db --network mynet -e POSTGRES_PASSWORD=x postgres:16
```
