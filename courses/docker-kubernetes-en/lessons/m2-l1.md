# Introduction to Docker

## Docker: the company, the technology and the standard

- **Docker, Inc.**: the company.
- **Docker** the technology: tools to build images, run containers and ship them.
- **OCI (Open Container Initiative)**: an open standard for images and how to run them, so you're not locked in.

| Word | Meaning |
|---|---|
| Image | a read-only template: the program and everything it needs |
| Container | a running instance of an image |
| Registry | a store of images, like Docker Hub |

The classic comparison: an image is like a **class**, a container like an **object**.
