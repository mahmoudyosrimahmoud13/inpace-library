# Container architecture (part 2 of 2)

## Don't forget

- A container is **not** a small VM: it's an isolated process on the host.
- Linux containers need a Linux kernel. On Windows and Mac, Docker Desktop runs a small Linux VM in the background.
- A container lives as long as its main process (PID 1) runs. The process ends? The container stops.

## Try it after watching

```bash
ps aux | head                     # processes on your machine
docker run --rm alpine ps aux     # inside a container: almost just one
```
