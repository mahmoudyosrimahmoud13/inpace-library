# Containers in depth

```bash
docker run -d --name web -p 8080:80 nginx     # -d in the background, -p host:container port
docker logs -f web
docker stop web        # gentle: SIGTERM, then SIGKILL after 10 seconds
docker start web
docker rm -f web
docker run -d --restart unless-stopped nginx
docker inspect web
docker container prune
```

| Restart policy | Behaviour |
|---|---|
| no | never comes back |
| on-failure | comes back if it exits with an error |
| always | always comes back |
| unless-stopped | comes back unless you stopped it |
