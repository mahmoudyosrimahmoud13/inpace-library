# Dockerfile in depth (part 3 of 3)

## Multi-stage builds: a small production image

```dockerfile
FROM golang:1.22 AS build
WORKDIR /src
COPY . .
RUN go build -o /app

FROM gcr.io/distroless/base-debian12
COPY --from=build /app /app
USER nonroot
ENTRYPOINT ["/app"]
```

## Good habits

- `.dockerignore` (.git, node_modules...).
- `apt-get install --no-install-recommends` and clean the cache in the same RUN.
- Don't run as root: `USER`.
- Never put secrets in an image (they stay in its layers even if deleted later).
