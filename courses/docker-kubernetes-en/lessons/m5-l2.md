# Dockerfile in depth (part 1 of 3)

| Instruction | Does |
|---|---|
| FROM | the base image |
| WORKDIR | working folder |
| COPY / ADD | copy files (ADD also unpacks archives and fetches URLs: use COPY unless you need that) |
| RUN | a build-time command; makes a layer |
| ENV / ARG | runtime / build-time variables |
| EXPOSE | documents the port (doesn't open it) |
| USER | the user that runs the program |
| CMD / ENTRYPOINT | what runs when the container starts |
