# Networking (part 2 of 2)

On a bridge network **you created**, containers reach each other **by name** (built-in DNS):

```bash
docker run -d --name api --network mynet myapi
docker exec -it api ping db
```

That doesn't work on the default bridge, so create a network per app.

- `-p 8080:80` opens a port from the **host** to the container. Containers on the same network don't need -p to talk.
- `docker network inspect mynet` shows the containers and their addresses.
