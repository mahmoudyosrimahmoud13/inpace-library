# A container is an application

## The Ops view and the Dev view

```bash
docker image ls
docker pull ubuntu:latest
docker run -it --name test ubuntu bash
# Ctrl+P then Ctrl+Q: leave the container without stopping it
docker ps
docker exec -it test bash
docker stop test && docker rm test
```

You don't "install" the program on your machine: you **run** it from a ready image, then remove it without a trace.
