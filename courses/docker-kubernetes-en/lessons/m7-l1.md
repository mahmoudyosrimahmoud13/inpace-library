# Docker Swarm (part 1 of 2)

- **Manager**: runs the cluster and stores its state (Raft). Use 3 or 5 managers for fault tolerance.
- **Worker**: runs containers.
- **Service**: what you want (image, replicas, ports); Swarm keeps that desired state.

```bash
docker swarm init
docker swarm join-token worker
docker service create --name web --replicas 3 -p 8080:80 nginx
docker service ls
docker service ps web
```
