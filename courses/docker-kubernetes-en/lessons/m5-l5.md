# Image registries

```bash
docker login
docker tag myapp:1.0 USERNAME/myapp:1.0
docker push USERNAME/myapp:1.0
```

- Public: Docker Hub, GitHub Container Registry (ghcr.io).
- For companies: AWS ECR, Azure ACR, Google Artifact Registry, or Harbor on your own server.
- Scan images for vulnerabilities (`docker scout cves`, Trivy) before production.
