# Container architecture (part 1 of 2)

## What makes a container possible?

Two Linux kernel features:

- **Namespaces**: each container sees its own "world": processes (pid), network (net), file system (mnt),
  host name (uts), users (user) and ipc.
- **Control groups (cgroups)**: limit how much CPU, memory and disk a container may use.

```text
VM:         app → libraries → full guest OS → hypervisor → hardware
Container:  app → libraries → (shared host kernel) → hardware
```
