# Deploying on Kubernetes (part 1 of 2)

```yaml
apiVersion: apps/v1
kind: Deployment
metadata: {name: web}
spec:
  replicas: 3
  selector: {matchLabels: {app: web}}
  template:
    metadata: {labels: {app: web}}
    spec:
      containers:
        - name: web
          image: nginx:1.27
          ports: [{containerPort: 80}]
          resources:
            requests: {cpu: 100m, memory: 64Mi}
            limits: {memory: 128Mi}
```

```bash
kubectl apply -f deployment.yaml
kubectl get pods -o wide
kubectl describe pod POD
kubectl logs POD
```
