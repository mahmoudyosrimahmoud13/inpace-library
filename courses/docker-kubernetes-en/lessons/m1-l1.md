# Start here

## Your plan: 3 weeks, 5 days a week

| Days | Module | Video time |
|---|---|---|
| 1 | Containers from zero | about 50 min |
| 2 | Docker: what it is, installing it, your first app | about 53 min |
| 3-4 | The Docker Engine and images in depth | about 65 min |
| 5-6 | Containers, networks and storage | about 95 min |
| 7-9 | Building images: Dockerfile and registries | about 115 min |
| 10 | Docker Compose | about 49 min |
| 11-12 | Docker Swarm, Stack and Portainer | about 92 min |
| 13-14 | Kubernetes | about 90 min |
| 15 | Review and interview questions | no video |

About 1 to 1.5 hours a day: half watching, half doing it yourself on your own computer. Each lesson plays **only its
piece** of the video and continues from where you stopped.

## About the video's language

The video is taught in **Egyptian Arabic**, with the commands, slides and technical terms in English. If you don't
speak Arabic:

- Turn on YouTube's captions (**CC**), then **Settings → Subtitles → Auto-translate → English**.
- Follow the commands on screen: they're the same in any language.
- Every lesson here has English notes with the commands that matter, so you never depend on the audio alone.

## Before you start

- A computer with at least 8 GB of RAM (16 GB is better for the Kubernetes part).
- Docker Desktop on Windows or Mac, or Docker Engine on Linux.
- VS Code with the Docker extension.
