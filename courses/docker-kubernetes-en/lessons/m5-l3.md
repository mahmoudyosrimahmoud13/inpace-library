# Dockerfile in depth (part 2 of 3)

## CMD or ENTRYPOINT?

- **ENTRYPOINT**: the fixed program.
- **CMD**: default arguments, replaced by whatever you type after the image name.

```dockerfile
ENTRYPOINT ["curl"]
CMD ["--help"]
# docker run mycurl https://example.com  → curl https://example.com
```

Use the JSON (exec) form so SIGTERM reaches your program and it stops gracefully.

## The cache

Each instruction is a layer. Change one, and everything after it is rebuilt. Put what rarely changes **first**.
