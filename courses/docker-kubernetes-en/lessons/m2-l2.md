# Installing Docker

- **Windows / Mac**: Docker Desktop (on Windows it uses WSL 2).
- **Linux**: Docker Engine from Docker's official repositories.

```bash
docker version        # shows Client and Server: if both appear, the engine is running
docker info
docker run hello-world
```

On Linux, to run docker without sudo:

```bash
sudo usermod -aG docker $USER   # then log out and back in
```
