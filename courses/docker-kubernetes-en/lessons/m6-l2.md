# Docker Compose (part 2 of 2)

```bash
docker compose up -d
docker compose ps
docker compose logs -f web
docker compose exec db psql -U app
docker compose down
docker compose down -v        # also removes volumes (careful!)
```

- `depends_on` orders startup but doesn't wait until the database is **ready**: use a `healthcheck` with
  `condition: service_healthy`.
- Secrets: a `.env` file kept out of git, or `secrets`.
