# Docker Swarm (part 2 of 2)

```bash
docker service scale web=5
docker service update --image nginx:1.27 --update-parallelism 1 --update-delay 10s web   # rolling update
docker service rollback web
docker node ls
docker node update --availability drain NODE   # empty a node for maintenance
```

- **Routing mesh**: any node accepts the request on the published port and sends it to a running replica.
- **Overlay network**: one network spanning all nodes.
