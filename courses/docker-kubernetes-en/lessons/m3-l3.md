# Images in depth (part 2 of 2)

## Layers

An image is a stack of read-only layers, each with a hash. Different images **share** common layers, so they're not
downloaded or stored twice.

```bash
docker image inspect nginx:alpine
docker history nginx:alpine
docker pull nginx@sha256:...          # by digest: exactly the same bytes, always
docker image rm nginx:alpine
docker image prune -a
```

- A **digest** pins the content; a tag can be moved to point at another image.
- **Multi-arch**: the same name gives you an amd64 or arm64 build to match your machine.
