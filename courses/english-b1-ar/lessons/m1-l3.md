# used to و would و be used to

## used to + فعل: عادة أو حالة في الماضي انتهت

```text
I used to play football every day.       (لا أفعل الآن)
She used to live in Mansoura.
Did you use to have long hair?           (بدون d بعد did)
We didn't use to have a car.
```

## would: عادة متكررة في الماضي فقط (ليست حالة)

*When I was a child, my grandfather would tell us stories every night.* ✅
*I would live in Tanta* ❌ (حالة ← used to)

## be/get used to + ing: معتاد على (الآن)

```text
I'm used to waking up early.             (معتاد)
I'm getting used to the cold weather.    (أتعود تدريجيًا)
```

**used to do** (كنت أفعل) غير **be used to doing** (معتاد على).
