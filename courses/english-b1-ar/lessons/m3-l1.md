# الشرط الحقيقي وغير الحقيقي

على العشاء، الأصدقاء يلعبون لعبة: ماذا كنت ستفعل لو ربحت اليانصيب؟ استمع لـ If I won..., I'd... ولـ If it rains, we'll...

## استمع أولًا: المحادثة

**لو ربحت اليانصيب...**

| الإنجليزية | المعنى |
|---|---|
| **Layla:** Let's play a game: what would you do if you won the lottery? | هيا نلعب لعبة: ماذا كنت ستفعل لو ربحت اليانصيب؟ |
| **James:** I'd quit my job and travel around the world for a year. | كنت سأترك عملي وأسافر حول العالم لمدة سنة. |
| **Peter:** I wouldn't stop working. I'd buy a house with a garden and help my family. | أنا لن أتوقف عن العمل. كنت سأشتري بيتًا بحديقة وأساعد عائلتي. |
| **Layla:** How sensible! If I had a lot of money, I'd open a small restaurant with food from Jordan. | يا لك من عاقل! لو كان عندي مال كثير، كنت سأفتح مطعمًا صغيرًا بأكل أردني. |
| **James:** I'd eat there every day! But back to reality: if it doesn't rain tomorrow, shall we go to the park? | كنت سآكل هناك كل يوم! لكن لنرجع للواقع: إذا لم تمطر غدًا، هل نذهب إلى الحديقة؟ |
| **Peter:** Good idea. If it rains, we'll go to the cinema instead. | فكرة جيدة. إذا أمطرت، سنذهب إلى السينما بدلًا من ذلك. |
| **Layla:** Perfect. And if I were you, James, I'd bring an umbrella anyway. It's London! | ممتاز. ولو كنت مكانك يا جيمس، لأحضرت مظلة على أي حال. هذه لندن! |

## قلّد الكلام (Shadowing)

اقرأ المحادثة بصوت عالٍ **ثلاث مرات**: أولًا ببطء، ثم بسرعة عادية، ثم دون أن تنظر إلى عمود المعنى. ولو عندك الصوت من الروابط بالأسفل، أوقفه بعد كل جملة وقلّد إيقاع المتكلم ولحن صوته، لا الكلمات فقط. هذا اسمه **التقليد (Shadowing)**، وهو يدرّب أذنك ولسانك معًا.

## كلمات وعبارات احفظها

| العبارة | المعنى |
|---|---|
| What would you do if...? | ماذا كنت ستفعل لو...؟ |
| If I won the lottery, I'd... | لو ربحت اليانصيب، لـ... |
| If I had more time, I'd... | لو كان عندي وقت أكثر، لـ... |
| If I were you, I'd... | لو كنت مكانك، لـ... |
| I'd love to... | أود جدًا أن... |
| If it rains, we'll... | إذا أمطرت، سـ... |
| instead | بدلًا من ذلك |
| anyway | على أي حال |
| back to reality | لنرجع للواقع |
| How sensible! | يا لك من عاقل! |
| Shall we...? | هل نـ...؟ |
| unless | إلا إذا |

## انطقها صح

**'d و'll.** في الكلام، *would* تُختصر إلى *'d* و*will* إلى *'ll*، وهي سريعة جدًا: *I'd* = "آيد"، *we'll* = "ويل"، *it'll* = "إتل". وقد يصعب سماعها، لكنها تغيّر المعنى: *I like it* (أحبه) مقابل *I'd like it* (سيعجبني). و*'d* قد تعني *would* أو *had*: *I'd go* (would) و*I'd gone* (had).

قل: *If I won, I'd travel. If it rains, we'll stay in. I'd love to!*
