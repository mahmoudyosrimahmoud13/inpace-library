# فيديو: 5 قواعد تهجئة واستثناءاتها

في الكتابة (الإيميل، الامتحان، الـ CV) أخطاء التهجئة تُلاحظ فورًا. شاهد **English with Lucy**: خمس قواعد مع
استثناءاتها (منها i قبل e، تكرار الحرف الأخير، وحذف e) واختبار قصير في آخره.

## قاعدة التكرار في الكلمات الطويلة

في الكلمات ذات المقطعين أو أكثر نكرر الحرف الأخير **فقط إذا كان الضغط على المقطع الأخير**:

| الضغط في الآخر: كرر | الضغط في الأول: لا تكرر |
|---|---|
| be**gin** → begi**nn**ing | **o**pen → opening |
| pre**fer** → prefe**rr**ed | **vi**sit → visited |
| ad**mit** → admi**tt**ed | **hap**pen → happened |

**ملاحظة:** البريطاني يكرر l دائمًا (travel → travelled)، والأمريكي لا (traveled).

## بريطاني أم أمريكي؟

| بريطاني | أمريكي |
|---|---|
| colour, favourite | color, favorite |
| centre, theatre | center, theater |
| organise, realise | organize, realize |
| travelled, cancelled | traveled, canceled |

الاثنان صحيحان. **المهم أن تلتزم بنوع واحد** في النص كله.

## كلمات تختلط لأنها تُنطق متشابهة

| الكلمات | الفرق |
|---|---|
| **their / there / they're** | لهم / هناك / they are |
| **your / you're** | لك / you are |
| **its / it's** | له (لغير العاقل) / it is |
| **then / than** | بعد ذلك / من (في المقارنة) |
| **lose / loose** | يخسر / واسع |
| **affect / effect** | يؤثر (فعل) / تأثير (اسم) |
| **quite / quiet** | إلى حد ما / هادئ |

## تمرين

اختر: 1. (Their / They're) going to (their / there) house. 2. The dog wagged (its / it's) tail.
3. She is taller (then / than) me. 4. Don't (lose / loose) your keys. 5. He (preferred / prefered) tea.

## الإجابات

1. They're, their 2. its 3. than 4. lose 5. preferred
