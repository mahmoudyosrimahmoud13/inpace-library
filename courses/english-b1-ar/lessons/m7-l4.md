# فيديو: الحروف الصامتة (silent letters)

كثير من الكلمات فيها حروف **تُكتب ولا تُنطق**، فتخطئ في النطق إن قرأتها كما تُكتب، وتخطئ في الكتابة إن كتبتها
كما تُنطق. شاهد درس **JForrest English**: كل حرف صامت مع أمثلته.

| الحرف الصامت | أمثلة |
|---|---|
| **k** قبل n | **k**now, **k**nife, **k**nee |
| **w** قبل r | **w**rite, **w**rong, ans**w**er |
| **b** بعد m | clim**b**, thum**b**, com**b**, dou**b**t |
| **l** | ta**l**k, wa**l**k, cou**l**d, ha**l**f |
| **h** | **h**our, **h**onest, w**h**at |
| **t** | lis**t**en, cas**t**le, of**t**en (تُسمع أحيانًا) |
| **g** قبل n | si**g**n, forei**g**n, desi**g**n |
| **p** | **p**sychology, recei**p**t |

**انتبه:** *an hour* و *an honest man* (لأن h صامتة فالكلمة تبدأ بصوت علة).

## تمرين

اقرأ بصوت عالٍ ثم اكتبها من الذاكرة: knowledge, wrist, climbing, should, island, Wednesday, receipt, autumn.
(صامت: k، w، b، l، s، d في Wed، p، n في الآخر).
