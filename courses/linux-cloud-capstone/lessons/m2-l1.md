# Infrastructure: network, compute and data

Build everything with Terraform in an `infra` repo, using the module layout from the IaC course.

## Checklist

**Bootstrap**
- [ ] State bucket with versioning, encryption, locking; created by a tiny `bootstrap/` folder.
- [ ] GitHub OIDC provider and two roles: `tf-plan` (read-only) and `tf-apply` (limited to this project).

**Network module**
- [ ] VPC with public, app and database subnets in 2 AZs.
- [ ] NAT gateway (one, for cost) or VPC endpoints for SSM, Secrets Manager, CloudWatch, ECR and an S3 gateway endpoint.
- [ ] Flow logs to CloudWatch with 14-day retention.

**Service module**
- [ ] ALB with HTTP to HTTPS redirect, ACM certificate, `/health` target group check.
- [ ] Launch template: golden AMI by data source, IMDSv2 required, encrypted gp3, instance role with SSM core + only the secrets and S3 paths it needs.
- [ ] Auto Scaling group 2-4 instances, ELB health checks, target tracking, instance refresh.
- [ ] Security groups: ALB from internet on 443; app only from ALB; database only from app. No port 22 anywhere.

**Data module**
- [ ] RDS PostgreSQL in database subnets, `manage_master_user_password`, encryption, backups 7+ days, `deletion_protection` and `prevent_destroy` in prod.
- [ ] S3 bucket: Block Public Access, versioning, TLS-only policy, lifecycle rule.

**Environments**
- [ ] `envs/staging` and `envs/prod`, same modules, different sizes and settings.

## Done means

`terraform plan` on a clean checkout shows no changes, and a teammate could read the README and recreate staging.
