# العمليات والرياضيات

| العملية | معناها |
|---|---|
| `+ - * /` | العمليات الأربع |
| `%` | الباقي: `7 % 2` تساوي `1` |

| `+=` و`-=` و`*=` | تغيير المتغير في مكانه |

| `&& \|\| !` | و، أو، ليس |

## الفخ: القسمة الصحيحة

إذا كان الطرفان `int`، تعطي `/` عددًا صحيحًا وتحذف الكسر:

```csharp
Console.WriteLine(7 / 2);        // 3
Console.WriteLine(7 / 2.0);      // 3.5
Console.WriteLine(7.0 / 2);      // 3.5
int total = 7, people = 2;
double share = (double)total / people;   // 3.5
```

## الصنف Math

تعطي `Math.Round(2.567, 2)` القيمة `2.57`، وتعطي `Math.Pow(2, 10)` القيمة `1024`، وتختار `Math.Max(a, b)` و`Math.Min(a, b)` إحدى القيمتين، و`Math.Sqrt(16)` تساوي `4`. والأقواس كما في المدرسة: `(a + b) * c`.
