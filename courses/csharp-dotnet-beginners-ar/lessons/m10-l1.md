# async وawait

قراءة صفحة ويب أو قاعدة بيانات تستغرق وقتًا. وتتيح `async`/`await` لبرنامجك أن ينتظر دون أن يتجمد: فيخدم خادم الويب طلبات أخرى في أثناء ذلك.

```csharp
using System.Net.Http.Json;

using var http = new HttpClient();
http.DefaultRequestHeaders.UserAgent.ParseAdd("inpace-course");   // GitHub requires one
var repo = await http.GetFromJsonAsync<Repo>("https://api.github.com/repos/dotnet/runtime");
Console.WriteLine($"{repo?.Name}: {repo?.stargazers_count} stars");

record Repo(string Name, int stargazers_count);
```

## القواعد

- الدالة التي تستخدم await تُعلَّم بـ `async` وتُرجع `Task` (أو `Task<T>` إن كان لها قيمة).
- استخدم `await` مع كل مهمة، ولا تستخدم `.Result` أو `.Wait()` لأنهما تجمّدان التطبيق.
- تنتشر async إلى الأعلى: إن استدعيت دالة async تصير دالتك غالبًا async أيضًا. وهذا طبيعي.
- بعض الواجهات (ومنها GitHub) تشترط ترويسة `User-Agent`: `http.DefaultRequestHeaders.UserAgent.ParseAdd("my-app");`

اقرأ المزيد (بالإنجليزية): [Asynchronous programming](https://learn.microsoft.com/dotnet/csharp/asynchronous-programming/).
