# اختبارات الوحدة بـ xUnit

ضع منطقك في مكتبة أصناف، ثم اختبره من مشروع xUnit:

```bash
dotnet new xunit -o Shop.Tests
dotnet sln add Shop.Tests
dotnet add Shop.Tests reference Shop.Core
dotnet test
```

```csharp
// Shop.Core/Pricing.cs
namespace Shop.Core;

public static class Pricing
{
    public static decimal Discount(decimal price, int percent)
    {
        ArgumentOutOfRangeException.ThrowIfNegative(percent);
        ArgumentOutOfRangeException.ThrowIfGreaterThan(percent, 100);
        return Math.Round(price * (100 - percent) / 100, 2);
    }
}
```

```csharp
// Shop.Tests/PricingTests.cs
using Shop.Core;

public class PricingTests
{
    [Fact]
    public void TenPercentOff200Is180() => Assert.Equal(180m, Pricing.Discount(200m, 10));

    [Theory]
    [InlineData(100, 0, 100)]
    [InlineData(100, 100, 0)]
    [InlineData(250, 20, 200)]
    public void Edges(int price, int percent, int expected) =>
        Assert.Equal(expected, Pricing.Discount(price, percent));

    [Fact]
    public void RoundsToEven() => Assert.Equal(50.00m, Pricing.Discount(99.99m, 50));   // 49.995 -> 50.00

    [Fact]
    public void RejectsMoreThan100() =>
        Assert.Throws<ArgumentOutOfRangeException>(() => Pricing.Discount(10m, 101));
}
```

`[Fact]` اختبار واحد، و`[Theory]` مع `[InlineData]` يشغّل الاختبار نفسه بمدخلات كثيرة. اختبر الحالات العادية والأطراف والمدخلات السيئة. ولاحظ أن `Math.Round` يستخدم افتراضيًا «تقريب المصرفيين» (إلى العدد الزوجي): والاختبارات تكشف مفاجآت كهذه.

اقرأ المزيد (بالإنجليزية): [Unit testing C# with xUnit](https://learn.microsoft.com/dotnet/core/testing/unit-testing-csharp-with-xunit).
