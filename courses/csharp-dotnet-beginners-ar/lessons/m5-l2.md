# القواميس وLINQ

**`Dictionary<TKey, TValue>`** يربط المفاتيح بالقيم. واستخدم `TryGetValue` لقراءة مفتاح قد لا يكون موجودًا:

> **فيديو اختياري في الأعلى.** جزء من دورة freeCodeCamp «Learn C#: Full Course with Mini-Projects» (من 3:55:00 إلى 4:30:00، نحو 35 دقيقة)، يبرمج الأفكار نفسها في Visual Studio. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```csharp
var stock = new Dictionary<string, int>
{
    ["apples"] = 12,
    ["bread"] = 3,
};
stock["milk"] = 6;                         // add or change

if (stock.TryGetValue("bread", out int count))
    Console.WriteLine($"bread: {count}");

foreach (var (item, qty) in stock)
    Console.WriteLine($"{item}: {qty}");
```

## LINQ: أسئلة عن المجموعات

تتيح **LINQ** تصفية أي مجموعة وترتيبها وجمعها في سطر واحد مقروء. وكل خطوة تأخذ دالة صغيرة تُكتب بـ `=>` (وتُسمى **lambda**):

```csharp
int[] scores = [90, 45, 75, 88, 60];

var passed = scores.Where(s => s >= 60).OrderByDescending(s => s).ToList();
Console.WriteLine(string.Join(", ", passed));    // 90, 88, 75, 60
Console.WriteLine(scores.Average());             // 71.6
Console.WriteLine(scores.Count(s => s < 60));    // 1
var labels = scores.Select(s => s >= 60 ? "pass" : "fail");
```
