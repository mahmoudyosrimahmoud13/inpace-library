# المصفوفات وList<T>

**المصفوفة** حجمها ثابت. أما **`List<T>`** فتكبر وتصغر، و`T` نوع عناصرها. وكلتاهما تعدّ من 0:

> **فيديو اختياري في الأعلى.** جزء من دورة freeCodeCamp «Learn C#: Full Course with Mini-Projects» (من 3:11:02 إلى 3:55:00، نحو 44 دقيقة)، يبرمج الأفكار نفسها في Visual Studio. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```csharp
int[] scores = { 90, 75, 88 };
Console.WriteLine(scores[0]);          // 90
Console.WriteLine(scores.Length);      // 3
Array.Sort(scores);                    // 75, 88, 90

List<string> names = ["Mona", "Omar"]; // a collection expression (C# 12)
names.Add("Laila");
names.Remove("Omar");
Console.WriteLine(names.Count);        // 2
Console.WriteLine(names.Contains("Mona"));

foreach (string n in names)
    Console.WriteLine(n);
```

القراءة بعد النهاية (`scores[3]` أعلاه) تطلق `IndexOutOfRangeException` (وفي القائمة `ArgumentOutOfRangeException`). وفي الحلقات استخدم `.Length` للمصفوفات و`.Count` للقوائم.
