# المشروع الختامي وإلى أين بعد ذلك

ابنِ واجهة برمجية صغيرة خاصة بك، منطقها في مكتبة أصناف ولها اختبارات. أفكار: متتبع عادات، أو صندوق وصفات، أو قائمة قراءة، أو قائمة أسعار متجر بالخصومات.

## إلى أين تأخذك .NET

| المسار | تعلّم بعد ذلك |
|---|---|
| خلفية الويب | ASP.NET Core وEntity Framework Core والمصادقة |
| واجهة الويب | Blazor |
| الهاتف والحاسوب | .NET MAUI |
| الألعاب | Unity |
| السحابة | Azure وDocker (دورة Docker وKubernetes في المكتبة) |

مجاني ورسمي: [مسارات C# على Microsoft Learn](https://learn.microsoft.com/training/browse/?terms=c%23)، وشهادة [Foundational C# with Microsoft](https://www.freecodecamp.org/learn/foundational-c-sharp-with-microsoft/) على freeCodeCamp.
