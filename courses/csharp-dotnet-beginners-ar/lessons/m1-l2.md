# كيف يُبنى برنامج C#

تستخدم المشاريع الجديدة **الجمل العليا** (top-level statements): يحتوي `Program.cs` على الكود الذي يُنفَّذ دون صنف حوله. وقد يعرض الكود الأقدم (والفيديو) الشكل الكامل، وكلاهما البرنامج نفسه:

> **فيديو اختياري في الأعلى.** جزء من دورة freeCodeCamp «Learn C#: Full Course with Mini-Projects» (من 0:00:00 إلى 0:10:56، نحو 11 دقيقة)، يبرمج الأفكار نفسها في Visual Studio. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```csharp
// Program.cs, top-level statements (.NET 6 and newer)
Console.WriteLine("Hello, World!");
```

```csharp
// The same program, written the classic way
namespace Hello;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("Hello, World!");
    }
}
```

## قواعد يتعثر فيها المبتدئون

- تنتهي كل جملة بـ `;`.
- توضع الكتل بين `{ }`، والإزاحة للقراءة فقط.
- اللغة **حساسة لحالة الأحرف**: `Console` تعمل و`console` لا تعمل.
- يبدأ التعليق بـ `//`، و`/* ... */` يمتد على أسطر.

## ما في المجلد

| الملف | ما هو |
|---|---|
| `Program.cs` | كودك |
| `Hello.csproj` | المشروع: إصدار .NET المستهدف والحزم |
| `bin/` و`obj/` | ناتج البناء، لا تعدّله ولا ترفعه إلى git |

لغة C# **مُترجَمة**: يحوّل `dotnet build` كودك إلى برنامج، ويكتشف المترجم أخطاء كثيرة قبل أن يعمل البرنامج أصلًا. ويبني `dotnet run` ويشغّل في خطوة واحدة.
