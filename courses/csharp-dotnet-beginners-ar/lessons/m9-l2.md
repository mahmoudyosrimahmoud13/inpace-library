# حزم NuGet

[NuGet](https://www.nuget.org) متجر حزم .NET. إضافة حزمة تكتبها في `.csproj`، ويُنزّلها `dotnet build`:

```bash
dotnet add package Humanizer
```

```csharp
using Humanizer;

Console.WriteLine(TimeSpan.FromMinutes(90).Humanize());   // 1 hour
Console.WriteLine("some_variable_name".Humanize());       // Some variable name
```

قبل إضافة حزمة افحصها على nuget.org: عدد التنزيلات، وآخر تحديث، والناشر، والترخيص. فكل حزمة كود صرت تعتمد عليه. وكثير مما تحتاجه موجود في .NET أصلًا: JSON (`System.Text.Json`)، وHTTP (`HttpClient`)، والملفات، والتواريخ، وLINQ.
