# قراءة المدخلات بأمان

تُرجع `Console.ReadLine()` ما كتبه المستخدم نصًا من النوع `string` (وقد تكون `null` إذا انتهت المدخلات). لا تفترض أبدًا أنه رقم: استخدم `TryParse` التي تُرجع `true` أو `false` وتضع الرقم في متغير `out`:

> **فيديو اختياري في الأعلى.** جزء من دورة freeCodeCamp «Learn C#: Full Course with Mini-Projects» (من 1:36:16 إلى 2:08:24، نحو 32 دقيقة)، يبرمج الأفكار نفسها في Visual Studio. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```csharp
int age;
Console.Write("Age: ");
while (!int.TryParse(Console.ReadLine(), out age) || age < 0)
{
    Console.Write("Please type a whole number: ");
}
Console.WriteLine($"Next year you'll be {age + 1}.");
```

## تنسيق الأرقام

| التنسيق | تظهر `1234.5` هكذا |
|---|---|
| `{x:N2}` | `1,234.50` |
| `{x:F1}` | `1234.5` |
| `{x:C}` | مبلغ بعملة الجهاز |
| `{x:P0}` (للقيمة `0.25`) | `25%` |
