# الأصناف والخصائص والمُنشئات

**الصنف** نوع تصنعه بنفسك. تحفظ **خصائصه** البيانات، ويجهّز **مُنشئه** (constructor) الكائن، وتؤدي **توابعه** الأعمال:

> **فيديو اختياري في الأعلى.** جزء من دورة freeCodeCamp «Learn C#: Full Course with Mini-Projects» (من 7:15:56 إلى 8:17:11، نحو 61 دقيقة)، يبرمج الأفكار نفسها في Visual Studio. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```csharp
var account = new BankAccount("Mona", 500);
account.Deposit(250);
Console.WriteLine(account);        // Mona: 750.00 EGP

public class BankAccount
{
    public string Owner { get; }               // read-only after construction
    public decimal Balance { get; private set; } // only the class can change it

    public BankAccount(string owner, decimal opening = 0)
    {
        ArgumentException.ThrowIfNullOrWhiteSpace(owner);
        Owner = owner;
        Balance = opening;
    }

    public void Deposit(decimal amount)
    {
        ArgumentOutOfRangeException.ThrowIfNegativeOrZero(amount);
        Balance += amount;
    }

    public override string ToString() => $"{Owner}: {Balance:N2} EGP";
}
```

## القطع

- يُستخدم `public` من أي مكان، و`private` من داخل الصنف فقط. أبقِ البيانات خاصة ودع التوابع تحرسها.
- `{ get; private set; }` **خاصية تلقائية**: تكتب C# الحقل المخفي نيابة عنك.
- الأعضاء `static` تخص الصنف نفسه لا كائنًا واحدًا (مثل `Math.Round`).
- وضع كل صنف في ملفه (`BankAccount.cs`) يُبقي المشاريع مرتبة.
