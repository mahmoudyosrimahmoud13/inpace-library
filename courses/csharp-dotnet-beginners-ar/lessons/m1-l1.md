# ابدأ من هنا

**C#** (تُنطق «سي شارب») لغة حديثة ذات أنواع صارمة صنعتها مايكروسوفت. و**.NET** هي المنصة المجانية مفتوحة المصدر التي تعمل عليها، على ويندوز وماك ولينكس. ومعًا تبنيان واجهات الويب والمواقع، وتطبيقات الحاسوب والهاتف، وخدمات السحابة، والألعاب (Unity تستخدم C#).

## كيف تسير هذه الدورة

- **الدروس المكتوبة** هي الأساس، وتتبع توثيق C# الرسمي من مايكروسوفت، وهو أدق المصادر وأحدثها.
- **الفيديوهات اختيارية.** فوق أغلب الدروس المكتوبة جزء من دورة freeCodeCamp «Learn C#: Full Course with Mini-Projects» يعرض الأفكار نفسها وهي تُبرمج. شاهده إن أفاد، فالنص وحده يكفي.
- تنتهي كل وحدة ببرنامج تكتبه وسؤال واختبار.
- والوحدتان الأخيرتان تتجاوزان الفيديو: مشاريع .NET حقيقية، والحزم، والاختبارات، وأول واجهة ويب لك.

## ثبّت الأدوات

1. ثبّت **.NET SDK** (أحدث إصدار LTS) من [dotnet.microsoft.com/download](https://dotnet.microsoft.com/download).
2. اختر محررًا: [VS Code](https://code.visualstudio.com/) مع إضافة **C# Dev Kit** (على أي نظام)، أو **Visual Studio Community** (مجاني، على ويندوز، وهو المستخدم في الفيديو).
3. تأكد أنه يعمل، ثم أنشئ أول برنامج وشغّله:

```bash
dotnet --version
dotnet new console -o Hello
cd Hello
dotnet run
```

يجب أن ترى `Hello, World!`. وتريد التجربة دون تثبيت؟ [درس Hello world التفاعلي](https://learn.microsoft.com/dotnet/csharp/tour-of-csharp/tutorials/hello-world) من مايكروسوفت يعمل في المتصفح (بالإنجليزية، ويمكنك ترجمة الصفحة من المتصفح).
