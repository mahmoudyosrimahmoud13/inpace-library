# if وswitch والحلقات

توضع الشروط بين أقواس، والكتل بين معقوفات:

> **فيديو اختياري في الأعلى.** جزء من دورة freeCodeCamp «Learn C#: Full Course with Mini-Projects» (من 0:46:59 إلى 1:36:16، نحو 49 دقيقة)، يبرمج الأفكار نفسها في Visual Studio. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```csharp
int score = 85;
if (score >= 90)
    Console.WriteLine("A");
else if (score >= 80)
    Console.WriteLine("B");
else
    Console.WriteLine("Keep going");

// A switch expression (C# 8 and newer): one value in, one value out
string day = DateTime.Now.DayOfWeek switch
{
    DayOfWeek.Friday or DayOfWeek.Saturday => "Weekend",
    _ => "Workday",
};
```

```csharp
for (int i = 1; i <= 5; i++)      // start; keep going while; step
    Console.WriteLine(i);

int tries = 0;
while (tries < 3) { tries++; }

do { Console.Write("Again? (y/n) "); }     // runs at least once
while (Console.ReadLine() == "y");

foreach (char c in "hello") Console.Write(c);
```

تخرج `break` من الحلقة، وتقفز `continue` إلى الدورة التالية. ويختار **المعامل الشرطي** بين قيمتين: `string label = age >= 18 ? "adult" : "minor";`

اقرأ المزيد (بالإنجليزية): [Branches and loops](https://learn.microsoft.com/dotnet/csharp/tour-of-csharp/tutorials/branches-and-loops).
