# الأنواع والمتغيرات والتحويل

في C# لكل متغير **نوع** يُحدَّد عند تعريفه. ويرفض المترجم وضع نص في متغير رقمي، فتُكتشف الأخطاء مبكرًا.

> **فيديو اختياري في الأعلى.** جزء من دورة freeCodeCamp «Learn C#: Full Course with Mini-Projects» (من 0:10:56 إلى 0:25:36، نحو 15 دقيقة)، يبرمج الأفكار نفسها في Visual Studio. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```csharp
int age = 25;
double height = 1.75;
decimal price = 199.99m;     // m: a decimal literal
bool isStudent = true;
char grade = 'A';            // one character, single quotes
string name = "Mona";        // text, double quotes

var city = "Cairo";          // var: the compiler sees it's a string
const int MaxTries = 3;      // can never change
```

## أي نوع رقمي؟

| النوع | استخدمه لـ |
|---|---|
| `int` | العدّ والأعداد الصحيحة (حتى نحو ملياري) |
| `long` | الأعداد الصحيحة الأكبر |
| `double` | القياسات والعلوم حيث يُقبل تقريب ضئيل |
| `decimal` | **الأموال**: دقيق في النظام العشري |

## التحويل

ما يكتبه المستخدم نص من النوع `string`. حوّله بـ `int.Parse` (تطلق استثناءً مع النص غير الصالح) أو، وهو الأفضل، `int.TryParse` (الوحدة 3). وبين أنواع الأرقام يتحول النوع الأصغر إلى الأكبر وحده، أما العكس فيحتاج **تحويلًا صريحًا** (cast) وقد يضيع جزء من البيانات:

```csharp
int n = int.Parse("42");
double d = n;                // int to double: automatic
int back = (int)3.99;        // cast: 3, the fraction is dropped
string s = n.ToString();
```
