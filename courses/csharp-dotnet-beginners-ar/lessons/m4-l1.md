# العمل مع النصوص

الإدراج (`$"..."`) أوضح طريقة لبناء النصوص. ضع أي تعبير بين معقوفين، مع تنسيق اختياري بعد النقطتين:

> **فيديو اختياري في الأعلى.** جزء من دورة freeCodeCamp «Learn C#: Full Course with Mini-Projects» (من 2:08:24 إلى 3:11:02، نحو 63 دقيقة)، يبرمج الأفكار نفسها في Visual Studio. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```csharp
string name = "Mona";
decimal total = 1499.5m;
Console.WriteLine($"Hi {name}, you owe {total:N2} EGP");

string path = @"C:\Users\Mona\Docs";     // verbatim: backslashes stay as they are
string json = """
    { "name": "Mona", "city": "Cairo" }
    """;                                     // raw string (C# 11): quotes inside, no escaping
```

## توابع ستستخدمها كل يوم

| الكود | الناتج |
|---|---|
| `"  hi ".Trim()` | `"hi"` |
| `"Cairo".ToUpper()` | `"CAIRO"` |
| `"a,b,c".Split(',')` | مصفوفة من 3 نصوص |
| `"hello".Contains("ell")` | `true` |
| `"hello".Replace("l", "L")` | `"heLLo"` |
| `"hello".Substring(1, 3)` | `"ell"` |
| `"hello".Length` | `5` |
| `string.Join(", ", names)` | يربط بفواصل |

## المقارنة والفحص

للمقارنة مع تجاهل حالة الأحرف قل ذلك صراحة: `string.Equals(a, b, StringComparison.OrdinalIgnoreCase)`. ولفحص المدخلات فضّل `string.IsNullOrWhiteSpace(s)`: فهي `true` للقيم `null` و`""` و`"   "`.

## النصوص لا تتغير

النص **غير قابل للتغيير**: تُرجع `ToUpper()` نصًا جديدًا وتترك القديم كما هو، فاكتب `name = name.ToUpper();`. وحين تبني نصًا طويلًا داخل حلقة، استخدم `StringBuilder` الذي لا ينشئ نصًا جديدًا في كل مرة.
