# الدوال والمعاملات

**الدالة** (method) كتلة كود لها اسم. ويقول توقيعها ماذا تُرجع وماذا تأخذ. وفي برنامج الجمل العليا يمكنك كتابة الدوال تحت كودك:

> **فيديو اختياري في الأعلى.** جزء من دورة freeCodeCamp «Learn C#: Full Course with Mini-Projects» (من 4:30:00 إلى 6:01:09، نحو 91 دقيقة)، يبرمج الأفكار نفسها في Visual Studio. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```csharp
Console.WriteLine(Area(3, 4));          // 6
Greet("Mona");
Greet("Omar", greeting: "Welcome");

double Area(double width, double height) => width * height / 2;   // returns a value

void Greet(string name, string greeting = "Hello")                 // returns nothing
{
    Console.WriteLine($"{greeting}, {name}!");
}
```

## إرجاع أكثر من قيمة

- `out`: **يجب** على الدالة أن تضبطها، ويستلمها المستدعي (وهكذا تعمل `TryParse`).
- `ref`: تستطيع الدالة قراءة متغير المستدعي وتغييره.
- و**الـ tuple** غالبًا أوضح منهما:

```csharp
(int min, int max) Range(int[] numbers) => (numbers.Min(), numbers.Max());

var (low, high) = Range([4, 9, 1]);
Console.WriteLine($"{low} to {high}");    // 1 to 9

void DoubleIt(ref int x) => x *= 2;
int n = 5;
DoubleIt(ref n);                             // n is now 10
```
