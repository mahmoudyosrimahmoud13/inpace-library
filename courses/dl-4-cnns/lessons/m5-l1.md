# Localization and landmarks

**Classification with localization:** the output adds a box: `y = [p_c, b_x, b_y, b_h, b_w, c_1, c_2, c_3]`, where
`p_c` says whether there's an object. If `p_c = 0`, the other values don't matter in the loss.

**Landmark detection:** output the coordinates of key points (eye corners, joints of a body pose). The order of the
points must be the same in every label.
