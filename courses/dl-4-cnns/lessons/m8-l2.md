# 1D and 3D convolutions

The same idea in other dimensions: **1D** convolutions slide along time (ECG, audio, sensor data); **3D** convolutions
slide through volumes (CT scans) or video (height × width × time).

```python
nn.Conv1d(in_channels=1, out_channels=16, kernel_size=5)    # keras.layers.Conv1D
nn.Conv3d(1, 16, kernel_size=3)                             # keras.layers.Conv3D
```
