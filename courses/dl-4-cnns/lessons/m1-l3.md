# Padding, strides and output size

For an `n×n` image, an `f×f` filter, padding `p` and stride `s`:

```text
output size = ⌊(n + 2p − f) / s⌋ + 1
```

- **Valid** convolution: `p = 0`, the image shrinks.
- **Same** convolution: `p = (f − 1) / 2` (with `s = 1`), the output keeps the input size. That's why filters are odd:
  3×3, 5×5, 7×7, and they have a centre.

```python
nn.Conv2d(3, 16, kernel_size=3, stride=1, padding=1)    # "same" for stride 1 ("same" also works as a string)
keras.layers.Conv2D(16, 3, strides=1, padding="same")
```

**Technical note:** deep learning's "convolution" doesn't flip the filter (maths calls that cross-correlation). It
doesn't matter, because the filter is learned. The notebook checks the formula against PyTorch for five settings.
