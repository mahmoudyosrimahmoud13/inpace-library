# Semantic segmentation with U-Net

**Segmentation** labels every pixel (road, car, person; tumour or not). The network must shrink the image to understand
it, then grow it back to full size.

- **Transpose convolution** grows the image: each input value "paints" a filter-sized patch onto the output.
- **U-Net:** a contracting path (convolutions and pooling) then an expanding path (transpose convolutions), with
  **skip connections** that copy high-resolution features across, so fine details survive.

```python
nn.ConvTranspose2d(64, 32, kernel_size=2, stride=2)   # doubles height and width
keras.layers.Conv2DTranspose(32, 2, strides=2)
```

**Since then:** U-Nets became the backbone of image-generating **diffusion models**; and **promptable segmentation**
models (Segment Anything) cut out any object you click on, with no training at all.
