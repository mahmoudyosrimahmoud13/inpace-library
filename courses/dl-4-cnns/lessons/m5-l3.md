# IoU, non-max suppression and anchor boxes

**IoU** (intersection over union) measures how well two boxes overlap; ≥ 0.5 is the usual "correct" threshold.

**Non-max suppression** keeps one box per object: take the highest-scoring box, drop others that overlap it with IoU
above a threshold, repeat.

![Non-max suppression](nms.png)

```python
from torchvision.ops import box_iou, nms
keep = nms(boxes, scores, iou_threshold=0.5)        # boxes as (x1, y1, x2, y2)
tf.image.non_max_suppression(boxes, scores, 10, 0.5)  # TensorFlow uses (y1, x1, y2, x2)
```

**Anchor boxes** let one cell predict several objects of different shapes (a tall pedestrian and a wide car).

## Detection in 2026

YOLO kept evolving (newer versions add better backbones and drop anchors). **DETR**-style transformer detectors
predict a set of boxes directly and need no NMS. **Open-vocabulary** detectors find objects from a text prompt.
The ideas in these slides (boxes, IoU, NMS, anchors) are still how you read and debug any of them.
