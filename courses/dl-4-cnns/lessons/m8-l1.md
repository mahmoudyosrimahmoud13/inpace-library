# What deep networks learn, and style transfer

Visualizing units: early layers respond to edges and colours, deeper layers to textures, then object parts, then whole
objects.

**Neural style transfer** makes a generated image G with the **content** of C and the **style** of S, by gradient
descent on the **pixels of G** (the network's weights stay fixed):

- **Content cost:** compare activations of a middle layer for C and G.
- **Style cost:** compare **Gram matrices**, `G_kk' = Σ a_ijk · a_ijk'`: which channels fire together, regardless of where.

```python
def gram(features):                 # (channels, height, width)
    f = features.flatten(1)
    return f @ f.T / f.shape[1]
```

Today, diffusion models and image editing tools do style transfer from a text prompt, but this is still the clearest
way to see what CNN features capture.
