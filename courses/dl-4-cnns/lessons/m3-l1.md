# LeNet-5, AlexNet and VGG-16

- **LeNet-5** (1998): about 60 thousand parameters, digits. The CONV-POOL-CONV-POOL-FC pattern.
- **AlexNet** (2012): about 60 million parameters, ReLU, GPUs. The moment deep learning won ImageNet.
- **VGG-16** (2014): about 138 million parameters, only 3×3 convolutions and 2×2 pooling, very regular.

Reading these papers is still a good way to learn how architectures are put together.
