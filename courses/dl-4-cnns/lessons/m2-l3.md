# Why convolutions work

1. **Parameter sharing:** a feature detector useful in one part of the image is useful everywhere.
2. **Sparse connections:** each output depends only on a small patch.
3. Together they give **translation equivariance**: shift the cat, the features shift with it.

In the notebook, a small CNN reaches 97.8% on digits with **6,090** parameters; a plain network gets 97.6% with
**9,610**. On real-size images the gap is enormous.
