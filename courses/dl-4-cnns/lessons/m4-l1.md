# MobileNet: depthwise separable convolutions

Split a normal convolution in two:
1. **Depthwise:** one `f×f` filter per input channel (no channel mixing).
2. **Pointwise:** a 1×1 convolution to mix channels and set the output channels.

![MobileNet cost](mobilenet_cost.png)

The slide's example costs 2,160 multiplications normally and 672 separable: about **31%**, and the saving grows with
more channels (8× fewer weights in the notebook's 64→128-channel example). **MobileNet v2** adds an expand → depthwise
→ project "bottleneck" with a residual connection.

```python
nn.Sequential(nn.Conv2d(64, 64, 3, padding=1, groups=64), nn.Conv2d(64, 128, 1))   # PyTorch: groups = channels
keras.layers.SeparableConv2D(128, 3, padding="same")                                # Keras: one layer
```
