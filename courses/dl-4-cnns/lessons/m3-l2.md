# Residual networks

A **residual block** adds the input back after two layers: `a[l+2] = g(z[l+2] + a[l])`. If the extra layers aren't
useful, the block can learn `z[l+2] ≈ 0` and simply pass `a[l]` through, so adding blocks never makes the network much
worse. That's why ResNets train with 50, 152 or 1,000 layers where plain networks get worse as they grow.

```python
class ResidualBlock(nn.Module):
    def __init__(self, c):
        super().__init__()
        self.body = nn.Sequential(nn.Conv2d(c, c, 3, padding=1, bias=False), nn.BatchNorm2d(c), nn.ReLU(),
                                  nn.Conv2d(c, c, 3, padding=1, bias=False), nn.BatchNorm2d(c))
    def forward(self, x):
        return torch.relu(self.body(x) + x)
```

Skip connections are everywhere now: every transformer layer adds its input back the same way.
