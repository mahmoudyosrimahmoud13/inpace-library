# A simple CNN, and pooling

A typical small CNN: CONV → POOL → CONV → POOL → FC → FC → softmax. Height and width shrink, channels grow.

**Max pooling** keeps the largest value in each window (usually 2×2, stride 2, halving height and width). It has **no
parameters** and works on each channel separately. Average pooling is used too, especially **global average pooling**
at the end of modern networks (one number per channel instead of a big flatten).

```python
nn.MaxPool2d(2)                  # keras.layers.MaxPooling2D()
nn.AdaptiveAvgPool2d(1)          # keras.layers.GlobalAveragePooling2D()
```
