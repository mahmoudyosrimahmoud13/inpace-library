# Sliding windows and YOLO

Sliding windows (classify every crop) is far too slow. The **convolutional implementation** turns FC layers into
convolutions, so one pass of the network classifies all windows at once.

**YOLO** ("you only look once") goes further: divide the image into a grid (say 19×19); each cell predicts boxes, with
the object assigned to the cell containing its centre. Box coordinates are relative to the cell, so the network
predicts precise boxes in one pass.
