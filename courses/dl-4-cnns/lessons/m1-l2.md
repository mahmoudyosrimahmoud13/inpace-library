# Computer vision and edge detection

A 1000×1000 colour image has 3 million inputs; a fully connected first layer with 1,000 units would need **3 billion**
weights. Convolutions fix that by sliding a small filter over the image.

![Edge detection](edge_detection.png)

A 3×3 vertical-edge filter is bright where the image changes from light to dark, left to right. Swap the sign and you
find dark-to-light edges; turn it 90° for horizontal ones. In a CNN you **don't** hand-pick these numbers: the 9
values are parameters, learned by backprop, and the network finds filters better than any hand-made ones.
