# الشبكات (الجزء 2 من 2)

## الأسماء بدل العناوين

على شبكة bridge **أنشأتها أنت**، تتكلم الحاويات بأسمائها (DNS مدمج):

```bash
docker run -d --name api --network mynet myapi
docker exec -it api ping db      # يعمل: الاسم db يتحول لعنوان الحاوية
```

على الـ bridge الافتراضية لا يعمل هذا، لذلك أنشئ شبكة لكل تطبيق.

- `-p 8080:80` تفتح منفذًا من **الجهاز** للحاوية. الحاويات على نفس الشبكة لا تحتاج -p لتتكلم.
- `docker network inspect mynet` يعرض الحاويات وعناوينها.
