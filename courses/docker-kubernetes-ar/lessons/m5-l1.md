# تحويل تطبيق إلى حاوية

## الخطوات

1. الكود.
2. **Dockerfile** يصف البيئة.
3. `docker build` يبني الـ image.
4. `docker run` يشغلها، و`docker push` يرفعها.

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["python", "app.py"]
```

```bash
docker build -t myapp:1.0 .
docker run -d -p 8000:8000 myapp:1.0
```

ملاحظة: نسخ requirements.txt **قبل** باقي الكود يجعل تثبيت المكتبات يُعاد فقط عندما تتغير المكتبات.
