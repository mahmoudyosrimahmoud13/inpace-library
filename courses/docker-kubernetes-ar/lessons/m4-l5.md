# التخزين (الجزء 2 من 2)

```bash
docker volume create pgdata
docker run -d --name db -v pgdata:/var/lib/postgresql/data -e POSTGRES_PASSWORD=x postgres:16
docker rm -f db
docker run -d --name db2 -v pgdata:/var/lib/postgresql/data -e POSTGRES_PASSWORD=x postgres:16
# البيانات ما زالت موجودة

docker run --rm -v "$(pwd)":/app -w /app python:3.12 python script.py   # bind mount
docker volume ls
docker volume prune
```

الصيغة الأوضح: `--mount type=volume,source=pgdata,target=/var/lib/postgresql/data`.
