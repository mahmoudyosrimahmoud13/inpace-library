# مقدمة عن Docker

## Docker: الشركة والتقنية والمعيار

- **Docker, Inc.**: الشركة.
- **Docker** التقنية: أدوات لبناء الـ images وتشغيل الحاويات ونقلها.
- **OCI (Open Container Initiative)**: معيار مفتوح لشكل الـ image وطريقة تشغيلها، فلا تكون محبوسًا مع شركة واحدة.

## ثلاث كلمات ستسمعها كثيرًا

| الكلمة | المعنى |
|---|---|
| Image | قالب للقراءة فقط: البرنامج وكل ما يحتاجه |
| Container | نسخة تعمل من الـ image |
| Registry | مخزن للـ images، مثل Docker Hub |

المقارنة الشهيرة: الـ image مثل **الكلاس**، والحاوية مثل **الأوبجكت**.
