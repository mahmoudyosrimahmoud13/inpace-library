# ابدأ من هنا

## خطتك: 3 أسابيع، 5 أيام في الأسبوع

| الأيام | الوحدة | مدة الفيديو |
|---|---|---|
| 1 | الحاويات من الصفر | حوالي 50 دقيقة |
| 2 | Docker: التعريف والتثبيت وأول حاوية | حوالي 53 دقيقة |
| 3-4 | Docker Engine والـ Images بالتفصيل | حوالي 65 دقيقة |
| 5-6 | الحاويات والشبكات والتخزين | حوالي 95 دقيقة |
| 7-9 | بناء الـ Images: Dockerfile والـ Registries | حوالي 115 دقيقة |
| 10 | Docker Compose | حوالي 49 دقيقة |
| 11-12 | Docker Swarm وStack وPortainer | حوالي 92 دقيقة |
| 13-14 | Kubernetes | حوالي 90 دقيقة |
| 15 | مراجعة وأسئلة المقابلات | بدون فيديو |

حوالي ساعة إلى ساعة ونصف في اليوم: نصفها فيديو، والنصف الثاني تطبيق بيدك على جهازك.
كل درس يشغّل **الجزء الخاص به فقط** من الفيديو، ويكمل من حيث توقفت.

## قبل أن تبدأ

- جهاز عليه 8 جيجا رام على الأقل (يفضل 16 لجزء Kubernetes).
- Docker Desktop على Windows أو Mac، أو Docker Engine على Linux.
- VS Code مع إضافة Docker.
