# تثبيت Docker

## حسب نظامك

- **Windows / Mac**: Docker Desktop (على Windows يحتاج WSL 2).
- **Linux**: Docker Engine من مستودعات Docker الرسمية.

## تأكد أن كل شيء يعمل

```bash
docker version        # يظهر الـ Client والـ Server: لو ظهر الاثنان فالمحرك يعمل
docker info           # معلومات عن عدد الحاويات والـ images والتخزين
docker run hello-world
```

على Linux، لتشغيل docker بدون sudo:

```bash
sudo usermod -aG docker $USER   # ثم سجّل خروج ودخول
```
