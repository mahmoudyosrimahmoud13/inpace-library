# Docker Compose (الجزء 1 من 2)

## تطبيق كامل في ملف واحد

```yaml
# compose.yaml
services:
  web:
    build: .
    ports: ["8000:8000"]
    environment:
      DATABASE_URL: postgres://app:secret@db:5432/app
    depends_on: [db]
  db:
    image: postgres:16
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: secret
    volumes: ["pgdata:/var/lib/postgresql/data"]
volumes:
  pgdata:
```

Compose ينشئ شبكة للتطبيق، فـ web يصل لـ db بالاسم `db`.
