# الحاوية = تطبيق

## نظرة الـ Ops ونظرة الـ Dev

```bash
docker image ls                        # الـ images الموجودة
docker pull ubuntu:latest              # نزّل image
docker run -it --name test ubuntu bash # شغّل حاوية وادخل عليها
# Ctrl+P ثم Ctrl+Q: اخرج من الحاوية بدون إيقافها
docker ps                              # الحاويات التي تعمل
docker exec -it test bash              # ادخل مرة ثانية
docker stop test && docker rm test
```

الفكرة: أنت لا "تثبّت" البرنامج على جهازك، أنت **تشغّله** من image جاهزة، ثم تمسحه بدون أثر.
