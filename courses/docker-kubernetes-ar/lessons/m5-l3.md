# Dockerfile بالتفصيل (الجزء 2 من 3)

## CMD أم ENTRYPOINT؟

- **ENTRYPOINT**: البرنامج الثابت.
- **CMD**: الوسائط الافتراضية، تُستبدل بما تكتبه بعد اسم الـ image.

```dockerfile
ENTRYPOINT ["curl"]
CMD ["--help"]
# docker run mycurl https://example.com  → curl https://example.com
```

استخدم صيغة JSON (exec form) حتى يصل SIGTERM للبرنامج مباشرة ويتوقف بلطف.

## الكاش

كل تعليمة طبقة. تغيرت تعليمة؟ كل ما بعدها يُعاد بناؤه. لذلك: الأشياء التي نادرًا ما تتغير **أولًا**.
