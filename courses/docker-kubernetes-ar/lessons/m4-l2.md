# الشبكات (الجزء 1 من 2)

## أنواع الشبكات

| النوع | الاستخدام |
|---|---|
| bridge | الافتراضي: شبكة خاصة على جهاز واحد |
| host | الحاوية تستخدم شبكة الجهاز مباشرة |
| none | بدون شبكة |
| overlay | شبكة بين أكثر من جهاز (Swarm) |
| macvlan | الحاوية تظهر كجهاز على الشبكة الحقيقية |

```bash
docker network ls
docker network create mynet
docker run -d --name db --network mynet postgres:16 -e POSTGRES_PASSWORD=x
```
