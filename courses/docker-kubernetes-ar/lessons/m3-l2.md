# الـ Images بالتفصيل (الجزء 1 من 2)

## الأسماء والـ tags

```text
registry/repository:tag
docker.io/library/nginx:1.27-alpine
```

- بدون tag: Docker يفترض `latest` (وهي مجرد اسم، ليست بالضرورة الأحدث).
- الـ images الرسمية (official) تحت `library/`.

```bash
docker pull nginx:alpine
docker image ls
docker search nginx --filter is-official=true
```
