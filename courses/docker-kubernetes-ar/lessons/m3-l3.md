# الـ Images بالتفصيل (الجزء 2 من 2)

## الطبقات (layers)

كل image مكوّنة من طبقات للقراءة فقط، وكل طبقة لها hash. الـ images المختلفة **تتشارك** الطبقات المشتركة،
فلا تنزل مرتين ولا تأخذ مساحة مرتين.

```bash
docker image inspect nginx:alpine     # الطبقات والإعدادات
docker history nginx:alpine           # كيف بنيت
docker pull nginx@sha256:...          # بالـ digest: نفس البايتات بالضبط دائمًا
docker image rm nginx:alpine
docker image prune -a                 # احذف كل ما لا يستخدم
```

- **Digest** يثبت المحتوى؛ الـ tag يمكن أن يتغير ليشير إلى image أخرى.
- **Multi-arch**: نفس الاسم يعطيك نسخة amd64 أو arm64 حسب جهازك.
