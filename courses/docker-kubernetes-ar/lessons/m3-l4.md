# Docker في VS Code

## إضافة Docker في VS Code

- ترى الـ images والحاويات والشبكات والـ volumes في شريط جانبي.
- كليك يمين: تشغيل، إيقاف، فتح طرفية داخل الحاوية، قراءة الـ logs.
- تكتب Dockerfile وcompose مع إكمال تلقائي وتنبيهات.
- **Dev Containers**: تفتح المشروع كله داخل حاوية، فتكون بيئة التطوير نفسها عند كل أعضاء الفريق.
