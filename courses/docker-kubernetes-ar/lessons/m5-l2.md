# Dockerfile بالتفصيل (الجزء 1 من 3)

## التعليمات الأساسية

| التعليمة | تعمل |
|---|---|
| FROM | الـ image الأساس |
| WORKDIR | مجلد العمل |
| COPY / ADD | نسخ ملفات (ADD يفك الضغط ويقبل روابط: استخدم COPY إلا لو احتجت ذلك) |
| RUN | أمر وقت البناء، يصنع طبقة |
| ENV / ARG | متغيرات وقت التشغيل / وقت البناء |
| EXPOSE | توثيق المنفذ (لا يفتحه) |
| USER | المستخدم الذي يشغل البرنامج |
| CMD / ENTRYPOINT | ما يعمل عند تشغيل الحاوية |
