# الحاويات بالتفصيل

## دورة حياة الحاوية

```bash
docker run -d --name web -p 8080:80 nginx   # -d في الخلفية، -p منفذ الجهاز:منفذ الحاوية
docker logs -f web
docker stop web        # إيقاف لطيف: SIGTERM ثم SIGKILL بعد 10 ثوان
docker start web
docker rm -f web
docker run -d --restart unless-stopped nginx   # تعود وحدها بعد إعادة التشغيل
docker inspect web
docker container prune
```

| سياسة الإعادة | السلوك |
|---|---|
| no | لا تعود |
| on-failure | تعود إذا خرجت بخطأ |
| always | تعود دائمًا |
| unless-stopped | تعود إلا إذا أوقفتها أنت |
