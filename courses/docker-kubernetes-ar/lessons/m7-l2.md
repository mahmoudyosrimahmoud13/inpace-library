# Docker Swarm (الجزء 2 من 2)

```bash
docker service scale web=5
docker service update --image nginx:1.27 --update-parallelism 1 --update-delay 10s web   # rolling update
docker service rollback web
docker node ls
docker node update --availability drain NODE   # فرّغ جهازًا للصيانة
```

- **Routing mesh**: أي جهاز في الـ cluster يستقبل الطلب على المنفذ ويوصله لنسخة تعمل.
- **Overlay network**: شبكة تمتد على كل الأجهزة.
