# معمارية الحاويات (الجزء 2 من 2)

## نقاط لا تنساها

- الحاوية **ليست** آلة افتراضية صغيرة: هي عملية (process) معزولة على النظام المضيف.
- حاويات Linux تحتاج نواة Linux. على Windows وMac يشغّل Docker Desktop آلة Linux خفيفة في الخلفية.
- الحاوية تعيش طالما عمليتها الرئيسية (PID 1) تعمل. تنتهي العملية؟ تتوقف الحاوية.

## جرّب بعد المشاهدة (لو عندك Linux)

```bash
ps aux | head            # العمليات على جهازك
docker run --rm alpine ps aux   # داخل حاوية: عملية واحدة تقريبًا
```
