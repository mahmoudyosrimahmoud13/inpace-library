# مخازن الـ Images (Registries)

```bash
docker login
docker tag myapp:1.0 USERNAME/myapp:1.0
docker push USERNAME/myapp:1.0
```

- عامة: Docker Hub، GitHub Container Registry (ghcr.io).
- للشركات: AWS ECR، Azure ACR، Google Artifact Registry، أو Harbor على سيرفرك.
- افحص الـ images من الثغرات (`docker scout cves`، Trivy) قبل الإنتاج.
