# Docker Compose (الجزء 2 من 2)

```bash
docker compose up -d          # بناء وتشغيل الكل
docker compose ps
docker compose logs -f web
docker compose exec db psql -U app
docker compose down           # إيقاف وحذف الحاويات والشبكة
docker compose down -v        # ومعها الـ volumes (احذر!)
```

- `depends_on` يرتب الإقلاع لكنه لا ينتظر أن تكون قاعدة البيانات **جاهزة**؛ استخدم `healthcheck` مع
  `condition: service_healthy`.
- الأسرار: ملف `.env` (لا ترفعه على git) أو `secrets`.
