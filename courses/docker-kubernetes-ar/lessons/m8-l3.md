# المعمارية المنطقية: Pods وDeployments وServices

| المورد | ما هو |
|---|---|
| Pod | أصغر وحدة: حاوية أو أكثر تتشارك الشبكة والتخزين |
| ReplicaSet | يحافظ على عدد نسخ الـ Pod |
| Deployment | يدير الـ ReplicaSets: تحديثات ورجوع |
| Service | عنوان ثابت أمام Pods متغيرة (ClusterIP، NodePort، LoadBalancer) |
| ConfigMap / Secret | الإعدادات والأسرار |
| Namespace | تقسيم الـ cluster |
| Ingress | توجيه HTTP من الخارج حسب الاسم والمسار |
