# Dockerfile بالتفصيل (الجزء 3 من 3)

## Multi-stage builds: image صغيرة للإنتاج

```dockerfile
FROM golang:1.22 AS build
WORKDIR /src
COPY . .
RUN go build -o /app

FROM gcr.io/distroless/base-debian12
COPY --from=build /app /app
USER nonroot
ENTRYPOINT ["/app"]
```

أدوات البناء تبقى في المرحلة الأولى، والـ image النهائية فيها البرنامج فقط.

## عادات جيدة

- `.dockerignore` (مثل .git وnode_modules).
- `apt-get install --no-install-recommends` وامسح الكاش في نفس الـ RUN.
- لا تشغّل كـ root: `USER`.
- لا تضع أسرارًا في الـ image (تبقى في الطبقات حتى لو حذفتها لاحقًا).
