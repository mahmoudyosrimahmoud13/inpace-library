# معمارية الحاويات (الجزء 1 من 2)

## ما الذي يجعل الحاوية ممكنة؟

ميزتان في نواة Linux:

- **Namespaces**: كل حاوية ترى "عالمها" الخاص: العمليات (pid)، الشبكة (net)، نظام الملفات (mnt)، اسم الجهاز (uts)،
  المستخدمين (user)، والـ ipc.
- **Control groups (cgroups)**: تحدد كم تستهلك الحاوية من المعالج والذاكرة والقرص.

```text
VM:         التطبيق → المكتبات → نظام تشغيل ضيف كامل → Hypervisor → الجهاز
Container:  التطبيق → المكتبات → (نواة النظام المضيف مشتركة) → الجهاز
```
