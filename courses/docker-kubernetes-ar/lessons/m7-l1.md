# Docker Swarm (الجزء 1 من 2)

## من جهاز واحد إلى Cluster

- **Manager**: يدير الـ cluster ويحفظ حالته (Raft). استخدم 3 أو 5 managers للتحمل.
- **Worker**: يشغل الحاويات.
- **Service**: تصف ما تريده: image وعدد نسخ ومنافذ؛ Swarm يحافظ على الحالة المطلوبة.

```bash
docker swarm init
docker swarm join-token worker
docker service create --name web --replicas 3 -p 8080:80 nginx
docker service ls
docker service ps web
```
