# فعل + ing أم فعل + to؟

| بعده **ing** | بعده **to** |
|---|---|
| enjoy, like, love, hate | want, need, would like |
| finish, stop, mind | decide, plan, hope |
| avoid, practise, suggest | promise, agree, refuse |
| بعد حروف الجر: interested **in** learning | learn, try (بمعنى يحاول) |

```text
I enjoy cooking.            I want to learn Spanish.
She finished writing.       We decided to stay.
I'm good at drawing.        I'm looking forward to seeing you.   (to هنا حرف جر)
```

## تمرين

1. If you ___ (not / hurry), you'll miss the bus. 2. I'll text you when I ___ (get) home. 3. He wants ___ (become) a pilot.
4. Do you mind ___ (wait)? 5. I'm interested in ___ (learn) Chinese.

## الإجابات

1. don't hurry 2. get 3. to become 4. waiting 5. learning
