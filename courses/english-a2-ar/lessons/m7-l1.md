# First conditional

**If + present simple, will + فعل**: شيء ممكن يحدث ونتيجته.

```text
If it rains, we'll stay at home.
If you study, you'll pass.
I'll call you if I have time.
What will you do if you don't get the job?
```

لا تضع will بعد if: *If it will rain* ❌

نفس القاعدة مع **when, before, after, as soon as, until**:

```text
I'll call you when I arrive.     (لا: when I will arrive)
```
