# أطر الـ agents: متى تستخدمها، وLangChain v1 في 20 سطرًا

يمنحك الإطار حلقة الـ agent، والحالة، والبث (streaming)، وإعادة المحاولة، والموافقة البشرية، فلا تكتبها بنفسك. ووجد الدليل LangChain في 18.8% وLangGraph في 8.0% من وظائف مهندسي الذكاء الاصطناعي، فتوقّع أسئلة عنهما، لكن أجب كمهندس لا كمعجب.

## متى تستخدم إطارًا

| استخدم كودًا عاديًا (SDK وحلقة) | استخدم إطارًا |
|---|---|
| أداة أو اثنتان، وسير عمل ثابت | أدوات كثيرة، وتفرعات، وإعادة محاولات |
| تحتاج أن ترى كل تفصيلة | تحتاج إيقافًا واستئنافًا، وموافقة بشرية، وحالة دائمة |
| فريق صغير ومزوّد نماذج واحد | عدة مزوّدين، أو فريق يستخدمه أصلًا |

ما زالت نصيحة Anthropic في *Building effective agents* صحيحة: ابدأ باستدعاءات الواجهة البرمجية مباشرة، وإن استخدمت إطارًا فافهم الكود الذي تحته، لأن الـ prompts المخفية والتجريدات تجعل الأخطاء أصعب في الاكتشاف.

## LangChain v1

أعاد LangChain 1.0 ‏(أكتوبر 2025) بناء المكتبة حول دالة واحدة، `create_agent`، وهي تعمل فوق **LangGraph** (الـ runtime الأدنى مستوى بالحالة والـ checkpoints). وانتقلت كلاسات الـ chains القديمة إلى حزمة منفصلة اسمها `langchain-classic`، فالدروس الأقدم من أواخر 2025 تعرض غالبًا واجهات لا يصح أن تنسخها.

```python
from typing import Literal
from pydantic import BaseModel
from langchain.agents import create_agent
from langchain.agents.structured_output import ToolStrategy
from langchain.tools import tool

@tool
def get_order(order_id: str) -> str:
    """Look up an order's status by its id, for example A-17."""
    orders = {"A-17": "shipped on Monday, arrives Thursday"}
    return orders.get(order_id, "no such order")

class Triage(BaseModel):
    category: Literal["shipping", "refund", "other"]
    reply: str

agent = create_agent(
    "ollama:qwen3",            # any provider: "openai:...", "anthropic:...", a local model...
    tools=[get_order],
    system_prompt="You are a support assistant. Use tools; never guess an order status.",
    response_format=ToolStrategy(Triage),
)
result = agent.invoke({"messages": [{"role": "user", "content": "Where is my order A-17?"}]})
print(result["structured_response"])   # category='shipping' reply='...arrives Thursday.'
```

الـ **middleware** هو طريقة v1 لإضافة التحكم دون إعادة كتابة الحلقة: منها جاهز يحجب البيانات الشخصية (PII)، ويلخّص السجلات الطويلة، ويتوقف قبل أدوات معينة لطلب موافقة بشرية، ويمكنك كتابة middleware خاص بك يعمل قبل أو بعد كل استدعاء للنموذج أو لأداة (ميزانيات، وتسجيل، وفحص سياسات).

الدورة القصيرة *LangChain and LangGraph: build agents with v1* ‏(بالإنجليزية) تمر على الأدوات والـ middleware والذاكرة والـ RAG والـ graphs خطوة بخطوة.
