# أسئلة RAG التي ستُسأل عنها

لقد بنيت DocAnswer، فأجب من تجربتك. وهذه الأسئلة المعتادة وجوهر الإجابة القوية:

| السؤال | جوهر الإجابة القوية |
|---|---|
| بحث نصي أم متجهي؟ | الاثنان: الكلمات للمصطلحات والمعرّفات الدقيقة، والمتجهات للمعنى، والهجين مع RRF، ثم القياس |
| كيف تعالج تقارير PDF ضخمة؟ | الاستخراج مع التخطيط (الجداول!)، وOCR للممسوح، والتقطيع بحسب البنية، وحفظ البيانات الوصفية، وإزالة المكرر |
| النموذج يهلوس حين يخلو السياق من الإجابة؟ | تعليمة الرفض وفحصها، وتقييمات الأمانة، وإظهار المصادر، ودرجة الثقة |
| نقاط فشل RAG المعتادة؟ | محتوى غائب، وأفضل k فاتها الصواب، والضياع في سياق طويل، واستخراج خاطئ، وشكل سيئ |
| ذكر المصادر؟ | رقّم المصادر، واشترط الإشارة إليها، وتحقق من وجود المعرّفات المذكورة، واربط بالصفحة |
| التخزين الدلالي المؤقت (semantic caching)؟ | إعادة استخدام إجابات الأسئلة القريبة جدًا في تضميناتها، وهو خطر حين تعتمد الإجابة على المستخدم أو الوقت |
| التوسع إلى أكثر من 10 ملايين مستند؟ | قاعدة بيانات متجهية ببحث تقريبي (HNSW)، ومرشحات بيانات وصفية، وتقسيم، وفهرسة تدريجية، وتخزين مؤقت |
| أهم الموازنات؟ | حجم القطعة مقابل السياق، وk مقابل الضجيج والتكلفة، وجودة معيد الترتيب مقابل الزمن، والحداثة مقابل تكلفة الفهرسة |

و**الصلاحيات** هي السؤال الذي ينساه الناس: في الشركات يجب ألا يسترجع المستخدمون إلا المستندات المسموح لهم برؤيتها. فصفِّ بحسب حقوق الوصول وقت الاسترجاع، لا بعد التوليد أبدًا.

## أبعد من الـ RAG الأساسي

كثيرًا ما يسأل المحاورون: «كيف ستحسّن الاسترجاع؟». سمِّ التقنية، ثم قل كيف ستقيسها:

| التقنية | الفكرة | تفيد حين |
|---|---|---|
| **إعادة كتابة السؤال (query rewriting)** | يعيد النموذج كتابة سؤال غامض أو حواري إلى استعلام بحث (أو أكثر) | أسئلة المتابعة مثل «وماذا عن ألمانيا؟» |
| **HyDE** | ولّد إجابة افتراضية، وحوّلها إلى embedding، وابحث بها | أسئلة صياغتها مختلفة جدًا عن المستندات |
| **Reranking** | cross-encoder يعيد تقييم أفضل 50 ويحتفظ بأفضل 5 | المقطع الصحيح يُسترجع لكن ترتيبه منخفض |
| **مقاطع بسياقها (contextual chunks)** | قبل الـ embedding، أضِف ملاحظة قصيرة عن موضع كل مقطع في مستنده (سمّتها Anthropic ‏*contextual retrieval* في 2024) | مقاطع لا تعني شيئًا وحدها («الرسوم 2%») |
| **مرشحات البيانات الوصفية (metadata filters)** | رشّح حسب المنتج أو التاريخ أو اللغة أو صلاحيات الوصول قبل الترتيب | مجموعات كبيرة ومختلطة |
| **GraphRAG** | ابنِ graph للكيانات وعلاقاتها وأجب منه | أسئلة عبر مستندات كثيرة («أي الموردين مرتبطون بـ...») |
| **Agentic RAG** | يقرر النموذج متى وماذا يبحث، وربما عدة مرات | أسئلة متعددة الخطوات، وتكلّف خطوات أكثر |

قل دائمًا الموازنة: كل خطوة إضافية تزيد الزمن والتكلفة، فأضِفها فقط حين تُظهر مقاييس الاسترجاع الفجوة.

## فيديوهات اختيارية

الدرس أعلاه كامل وحده. هذه الفيديوهات للتعمق إن كنت تحب التعلم بالمشاهدة. الفيديوهات بالإنجليزية: إن أردت فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.
