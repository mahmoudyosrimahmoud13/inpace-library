# الاستدلال: الاختيار والسياق والسرعة

| المصطلح | ماذا تقول |
|---|---|
| **درجة الحرارة (Temperature)** | تقسم الدرجات قبل softmax: منخفضة = مركّزة وقابلة للتكرار، ومرتفعة = متنوعة. استخدم 0 للاستخراج والتقييمات |
| **Top-p** | الاختيار فقط من أصغر مجموعة رموز يبلغ مجموع احتمالاتها p |
| **نافذة السياق** | أقصى عدد رموز للمدخل والمخرج معًا. وبعدها يجب أن تقطع أو تلخّص أو تسترجع، والسياقات الطويلة تكلّف أكثر وقد يفوّت النموذج حقائق في المنتصف |
| **ذاكرة KV المؤقتة** | تحفظ مفاتيح كل رمز وقيمه كي لا يعيد الرمز التالي حساب البادئة كلها، فتسرّع التوليد لكنها تستهلك ذاكرة GPU كثيرة |
| **TTFT** | زمن أول رمز: وهو ما يشعر به المستخدم. والبث (streaming) يعرض الرموز فور وصولها |
| **التكميم (Quantization)** | تخزين الأوزان بـ 8 أو 4 بتات بدل 16: أصغر وأسرع، مع فقد في الجودة يجب قياسه |
| **مزيج الخبراء (MoE)** | كل رمز يستخدم قليلًا فقط من شبكات خبراء كثيرة: معاملات أكثر بحساب مماثل لكل رمز |

## كيف تجعل الخوادمُ التوليدَ سريعًا

المحاورون في الشركات المهتمة بالبنية التحتية يتعمقون خطوة أخرى. اعرف ماذا تمنحك كل حيلة:

| التقنية | ماذا تفعل | ماذا تمنحك |
|---|---|---|
| **Continuous batching** | يضيف الخادم طلبات جديدة إلى الدفعة الجارية كلما انتهت طلبات أخرى | مستخدمين أكثر بكثير لكل GPU |
| **Paged attention** (vLLM) | يخزّن الـ KV cache في كتل صغيرة، مثل صفحات الذاكرة الافتراضية | هدر أقل في ذاكرة GPU، ودفعات أكبر |
| **Speculative decoding** | نموذج صغير يقترح عدة tokens، والكبير يتحقق منها في مرور واحد | زمن أقل بالمخرجات نفسها |
| **Prefix (prompt) caching** | يعيد استخدام الـ KV cache لبداية prompt مشتركة بين الطلبات | prompts نظام طويلة أرخص وأسرع |
| **Flash attention** | يحسب الـ attention على قطع تتسع لها الذاكرة السريعة داخل الشريحة | أسرع وذاكرة أقل والنتيجة نفسها |

مرحلتان تهمّان الزمن: **prefill** (قراءة الـ prompt كله دفعة واحدة، وتحدد زمن أول token) و**decode** (token واحد في كل خطوة، وتحدد عدد الـ tokens في الثانية). الـ prompts الطويلة تضر الـ prefill، والإجابات الطويلة تضر الـ decode.

## أسئلة للتدريب (من مقابلات حقيقية)

*ما درجة الحرارة وtop-p؟ وماذا يحدث حين تتجاوز نافذة السياق؟ وما ذاكرة KV المؤقتة ولماذا تفيد؟ واشرح التكميم وموازناته. وما الفرق بين BPE وWordPiece والترميز على مستوى الحروف؟* أجب عن كل منها بصوت عالٍ في أقل من دقيقتين.

*وأيضًا: لماذا أول token أبطأ من الباقي؟ ماذا ستغيّر لتخدم ضعف المستخدمين على الـ GPUs نفسها؟*
