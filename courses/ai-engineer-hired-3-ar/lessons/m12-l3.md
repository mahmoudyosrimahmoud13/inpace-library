# الـ fine-tuning عمليًا: LoRA وQLoRA والـ preference tuning

وجد الدليل الـ fine-tuning في 30.8% من وظائف AI-first، لكنه مسؤولية *أساسية* في 4% فقط. فأنت تحتاج غالبًا أن تشرحه جيدًا وتعرف متى لا تفعله، أكثر من حاجتك لتشغيله.

## LoRA في صورة واحدة

الـ fine-tuning الكامل يحدّث كل الأوزان. أما **LoRA** ‏(Low-Rank Adaptation، 2021) فيجمّد مصفوفة الأوزان الأصلية `W` ويتعلم تحديثًا صغيرًا من مصفوفتين نحيفتين: `W' = W + B·A`، حيث `B` بحجم d×r و`A` بحجم r×k، برتبة (rank) صغيرة r (غالبًا من 8 إلى 64).

```python
import numpy as np
d, k, r = 4096, 4096, 16              # one attention matrix of a 7B-size model, rank 16
full = d * k
lora = d * r + r * k
print(full, lora, f"{lora / full:.2%}")  # 16777216 131072 0.78%

W = np.random.randn(d, k).astype(np.float32)
A = np.random.randn(r, k).astype(np.float32) * 0.01
B = np.zeros((d, r), dtype=np.float32)     # B starts at zero, so training starts from the original model
x = np.random.randn(k).astype(np.float32)
assert np.allclose(W @ x, (W + B @ A) @ x)
```

تدريب أقل من 1% من المعاملات يعني ذاكرة GPU أقل بكثير، والنتيجة ملف **adapter** صغير تستطيع تبديله لكل عميل أو مهمة، أو دمجه في الأوزان عند التشغيل.

ويذهب **QLoRA** ‏(2023) أبعد: حمّل النموذج الأساسي المجمّد بدقة 4-bit ودرّب adapters ‏LoRA فوقه. وهكذا يضبط الناس نماذج من 7B إلى 70B على GPU واحد. وفي الكود، يكون هذا عادة مكتبة `peft` من Hugging Face ‏(`LoraConfig` بالمعاملات `r` و`lora_alpha` و`target_modules`)، مع `trl` أو Unsloth لحلقة التدريب.

## أنواع الضبط

| النوع | البيانات | يعلّم |
|---|---|---|
| **SFT** ‏(supervised fine-tuning) | أزواج prompt ← إجابة مثالية | شكلًا، أو أسلوبًا، أو مهمة ضيقة |
| **Preference tuning: ‏DPO** | prompt، وإجابة أفضل، وإجابة أسوأ | أي الإجابتين تفضّل، دون تدريب reward model منفصل |
| **RL بمكافآت قابلة للتحقق** | مسائل لها إجابات يمكن فحصها | التفكير (كما في الـ reasoning models) |
| **Distillation** | مخرجات نموذج كبير على مدخلاتك | جودة النموذج الكبير في نموذج صغير رخيص |

## سير عمل يمنع إهدار مال الـ GPU

1. أثبت المهمة بالـ **prompting ومجموعة تقييم** أولًا، فمجموعة التقييم هذه هي ما ستحكم به على النموذج المضبوط.
2. اجمع **من مئات إلى آلاف الأمثلة النظيفة**، فالجودة أهم من الكمية، وأمثلة سيئة قليلة تعلّم عادات سيئة.
3. احجز جزءًا للاختبار، واضبط نموذجًا صغيرًا بـ LoRA.
4. قارن بالنموذج الكبير مع الـ prompting في **الجودة والتكلفة والزمن**، وتأكد أنه لم ينسَ مهارات عامة تحتاجها.
5. خطط للصيانة: نموذج أساسي جديد يعني ضبطًا جديدًا.
