# pandas: Series, DataFrames and loading data

NumPy arrays are numbers without names. Real data has column names, mixed types (numbers, text, dates) and missing values. **pandas** adds those, on top of NumPy. In ML work, pandas is where data is loaded, cleaned and explored before it becomes arrays or tensors.


## Series and DataFrame

- A **Series** is one labelled column.
- A **DataFrame** is a table of Series sharing one row **index**.

```python
import io
import pandas as pd

csv = io.StringIO("""order_id,date,city,category,price,qty
1,2026-01-03,Cairo,books,120,2
2,2026-01-03,Giza,toys,250,1
3,2026-01-04,Cairo,toys,,3
4,2026-01-05,Alexandria,books,90,1
5,2026-01-05,Cairo,games,400,1
6,2026-01-06,Giza,books,110,
""")
df = pd.read_csv(csv, parse_dates=["date"])   # in real work: pd.read_csv("orders.csv")
print(df.shape)
print(df.head(3))
print(df.dtypes)
```

## First look at any dataset

```python
df.info()                         # columns, types, non-null counts
print(df.describe())              # count, mean, std, min, quartiles, max for numbers
print(df["city"].value_counts())  # how often each value appears
print(df.isna().sum())            # missing values per column
```

Do these four every time before modelling. They find wrong types, impossible values and missing data early.

## Selecting

```python
print(df["price"])                        # one column (a Series)
print(df[["city", "price"]])              # several columns (a DataFrame)
print(df.loc[0, "city"])                  # by label: row label 0, column 'city'
print(df.iloc[0:2, 0:3])                  # by position, like NumPy
print(df[df["city"] == "Cairo"])          # filter rows with a boolean mask
print(df.query("price > 100 and city != 'Giza'"))
```

`loc` uses labels, `iloc` uses positions. Mixing them up is the most common pandas bug.

## Version note

pandas 3.0 (2026) made two changes you'll notice: text columns get a dedicated string type by default, and **copy-on-write** is always on, so changing a selection never silently changes the original table. Old tutorials warn about `SettingWithCopyWarning`; with copy-on-write, assign to the table itself with `df.loc[mask, "col"] = value`.
