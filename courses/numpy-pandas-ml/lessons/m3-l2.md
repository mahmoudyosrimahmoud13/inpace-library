# Cleaning data and making features

Models don't accept missing values, text or dates directly. Cleaning and **feature engineering** turn raw columns into numbers a model can learn from, and they usually matter more than the choice of model.

```python
import io
import numpy as np
import pandas as pd

df = pd.read_csv(io.StringIO("""order_id,date,city,category,price,qty
1,2026-01-03,Cairo,books,120,2
2,2026-01-03,Giza,toys,250,1
3,2026-01-04,Cairo,toys,,3
4,2026-01-05,Alexandria,books,90,1
5,2026-01-05,Cairo,games,400,1
6,2026-01-06,Giza,books,110,
"""), parse_dates=["date"])
```

## Missing values

```python
print(df.isna().sum())
df["qty"] = df["qty"].fillna(1)                                         # a sensible default
df["price"] = df["price"].fillna(df.groupby("category")["price"].transform("median"))   # median of the same category
print(df[["category", "price", "qty"]])
```

Choices: drop the rows (`dropna`), fill with a constant, fill with a statistic (median is robust to outliers), or add a "was missing" flag column so the model can learn from missingness itself. Whatever you choose, compute statistics on the **training data only** and reuse them for test data, or information leaks from the test set into training.

## New columns

```python
df["revenue"] = df["price"] * df["qty"]                  # vectorized, like NumPy
df["weekday"] = df["date"].dt.day_name()                 # date parts
df["is_weekend"] = df["date"].dt.dayofweek >= 4          # Friday and Saturday in Egypt
df["price_band"] = pd.cut(df["price"], bins=[0, 100, 300, np.inf], labels=["low", "mid", "high"])
print(df[["date", "weekday", "is_weekend", "price", "price_band", "revenue"]])
```

## Categories to numbers

```python
encoded = pd.get_dummies(df[["city", "category"]], dtype=int)    # one-hot encoding
print(encoded.columns.tolist())
codes = df["city"].astype("category").cat.codes                  # integer codes, for embeddings
print(codes.tolist())
```

| Encoding | Use when |
|---|---|
| **One-hot** | few categories, linear models and small networks |
| **Integer codes** | tree models, or as input to an embedding layer in a neural network |
| **Target / frequency encoding** | many categories (thousands of products), with care to avoid leakage |

## From DataFrame to model input

```python
X = pd.concat([df[["price", "qty"]], encoded], axis=1).to_numpy(dtype=np.float32)
y = df["revenue"].to_numpy(dtype=np.float32)
print(X.shape, X.dtype, y.shape)
```

`to_numpy(dtype=np.float32)` is the hand-off point: from here, `torch.from_numpy(X)` or `tf.convert_to_tensor(X)` take over.
