# Plotting and exploring data

Looking at data catches problems no summary number shows: a sensor stuck at zero, two populations mixed together, a label that's almost always the same. pandas plots through **matplotlib**.

```python
import matplotlib
matplotlib.use("Agg")                     # draw to files; in Jupyter you can skip this line
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

rng = np.random.default_rng(0)
df = pd.DataFrame({
    "price": np.concatenate([rng.normal(100, 15, 300), rng.normal(300, 40, 100)]),
    "qty": rng.integers(1, 6, 400),
    "city": rng.choice(["Cairo", "Giza", "Alexandria"], 400, p=[0.5, 0.3, 0.2]),
})

fig, axes = plt.subplots(1, 3, figsize=(12, 3.5))
df["price"].plot.hist(bins=30, ax=axes[0], title="price: two groups")
df["city"].value_counts().plot.bar(ax=axes[1], title="orders per city")
df.plot.scatter(x="price", y="qty", ax=axes[2], alpha=0.4, title="price vs qty")
fig.tight_layout()
fig.savefig("explore.png", dpi=100)
print("saved explore.png")
```

The histogram shows two separate price groups (two kinds of product?), something the mean (about 150) completely hides.

## What to plot, and why

| Question | Plot |
|---|---|
| How is one number distributed? Outliers? | histogram, box plot |
| How common is each category? Is the target balanced? | bar chart of value counts |
| How do two numbers relate? | scatter plot |
| How does something change over time? | line plot |
| Which features move together? | correlation heatmap |

```python
print(df[["price", "qty"]].corr().round(2))
print(df.groupby("city")["price"].describe().round(1))
```

## An exploration checklist before any model

1. Shape, types, missing values (`info`, `isna().sum()`).
2. Distribution of the **target**: balanced? skewed? (a log transform helps skewed money targets).
3. Distributions of key features; impossible values (negative ages, prices of 0).
4. Relationship of each key feature with the target.
5. Duplicates (`df.duplicated().sum()`) and leakage suspects (a column that's "too good", like a refund flag when predicting refunds).
