# Keys, and when you need them

Keys tell Flutter which element belongs to which widget when a list changes.

```dart
ListView(children: [for (final c in courses) CourseTile(key: ValueKey(c.id), course: c)]);
```

Without keys, reordering or removing items in a list of **stateful** widgets makes state stick to the wrong item
(element matching is by position and type).

| Key | Use |
|---|---|
| `ValueKey(id)` | items with a stable id |
| `ObjectKey(obj)` | identity of an object |
| `UniqueKey()` | force a fresh element every build (e.g. restart an animation) |
| `GlobalKey` | reach a widget's state or move a widget across the tree keeping its state; expensive, use rarely |
| `PageStorageKey` | remember scroll positions |
