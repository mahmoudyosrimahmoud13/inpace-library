# Records, patterns and sealed classes

## Records: lightweight tuples

```dart
(int, String) pair = (1, 'one');
({double lat, double lng}) where = (lat: 30.0, lng: 31.2);
(String, int) parse(String s) => (s.trim(), s.length);
final (text, n) = parse(' hi ');      // destructuring
```

## Patterns and switch expressions

```dart
String describe(Object o) => switch (o) {
  int n when n < 0 => 'negative',
  int() => 'an int',
  (int x, int y) => 'a point $x,$y',
  {'type': 'trip', 'minutes': int m} => 'a $m-minute trip',
  List(isEmpty: true) => 'empty list',
  _ => 'something else',
};
```

inPace's Android bridge switches on a message type, and Dart 3 cases don't fall through (no `break` needed):

```dart
switch (msg['type']) {
  case 'share':
    await Share.share(msg['text'] as String);
  case 'trip':
    await Reminders.trip(msg['trip'] == null ? null : Map<String, dynamic>.from(msg['trip'] as Map));
}
```

## Sealed classes: exhaustive state

```dart
sealed class LoadState<T> {}
class Loading<T> extends LoadState<T> {}
class Loaded<T> extends LoadState<T> { Loaded(this.data); final T data; }
class Failed<T> extends LoadState<T> { Failed(this.error); final Object error; }

Widget view(LoadState<List<Course>> s) => switch (s) {
  Loading() => const CircularProgressIndicator(),
  Loaded(:final data) => CourseList(data),
  Failed(:final error) => ErrorText('$error'),
};   // no default needed: the compiler knows every case
```

Add a new state and every `switch` that forgot it **fails to compile**. That's the selling point to say in an interview.

Also know: class modifiers `final`, `base`, `interface`, `mixin class`; **extension types** (zero-cost wrappers, e.g.
`extension type UserId(String value) {}`).
