# Live coding: four classic tasks

Do each in 30 to 45 minutes, talking out loud.

1. **Search with debounce:** a text field that searches an API 300 ms after typing stops, shows loading, results,
   empty and error states, and cancels stale requests.
2. **Infinite list:** load 20 items per page when the user nears the bottom, with pull-to-refresh and an error retry.
3. **Countdown timer widget:** start, pause, resume, reset, correct after the app goes to the background
   (compute from the end time, don't trust ticks).
4. **Form:** sign-up with validation, async username check, disabled submit while sending, and accessible labels.

What interviewers watch: you clarify requirements first, handle loading/empty/error, dispose controllers, keep logic
out of widgets, and write at least one test.

```dart
// Debounce, the core of task 1
Timer? _t;
void onChanged(String q) {
  _t?.cancel();
  _t = Timer(const Duration(milliseconds: 300), () => _search(q));
}
@override
void dispose() { _t?.cancel(); super.dispose(); }
```
