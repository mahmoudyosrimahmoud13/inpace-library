# Rendering tricks that matter

- `const` constructors: the same instance, so the element skips rebuilding that subtree.
- `RepaintBoundary`: puts a subtree on its own layer so a ticking clock doesn't repaint the whole screen.
- Animate with `AnimatedBuilder` and a `child` argument so the static part isn't rebuilt every frame.
- **Shader compilation jank** was a big issue with Skia; **Impeller** (default on iOS and modern Android) precompiles
  shaders and largely removes it.
- Startup: defer non-critical work, lazy-load features (deferred imports), keep `main()` light. inPace's Android app
  shows a light Flutter loading screen while Python starts, then swaps in the WebView.
- App size: `flutter build apk --analyze-size`, split per ABI (`--split-per-abi`), remove unused assets and fonts.
