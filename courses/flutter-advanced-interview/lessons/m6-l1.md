# go_router and deep links

```dart
final router = GoRouter(
  initialLocation: '/',
  redirect: (context, state) {
    final signedIn = authState.isSignedIn;
    if (!signedIn && state.matchedLocation != '/setup') return '/setup';
    return null;
  },
  routes: [
    GoRoute(path: '/', builder: (_, __) => const Home()),
    GoRoute(path: '/courses/:id', builder: (_, s) => CoursePage(id: s.pathParameters['id']!)),
    StatefulShellRoute.indexedStack(branches: [...]),   // bottom tabs that keep their state
  ],
);
```

- Navigator 1.0 (`push`/`pop`) is imperative; Router/Navigator 2.0 is **declarative**: the URL is state. go_router
  wraps it.
- **Deep links:** Android App Links (`assetlinks.json` on your domain) and iOS Universal Links
  (`apple-app-site-association`). Custom schemes (`inpace://`) are easier but anyone can claim them.

inPace handles both: `https://mahmoudyosrimahmoud13.github.io/inPace/open#...` web links and `inpace://open/...` arrive
through the `app_links` package and are passed into the WebView. The data after `#` never reaches a server.
