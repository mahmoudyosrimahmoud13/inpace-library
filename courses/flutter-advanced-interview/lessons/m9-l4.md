# Behavioural rounds and the last week

Prepare **5 stories** with STAR (situation, task, action, result), each with a number if you can:

1. A hard bug you found (a navigation bug that looked like many bugs is a great one).
2. A performance win (frame times before and after).
3. A disagreement about architecture and how it ended.
4. Something you shipped end to end.
5. A failure and what you changed afterwards.

**Last-week checklist**

- [ ] Re-answer every question you marked.
- [ ] Two mock interviews (a friend, or record yourself).
- [ ] One system design per day, 30 minutes, drawn.
- [ ] Your GitHub: two projects with READMEs, screenshots, tests and CI badges.
- [ ] Questions to ask them: how they test, release cadence, how decisions are made, what success looks like in 90 days.
