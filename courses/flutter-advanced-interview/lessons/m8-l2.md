# CI/CD

```yaml
name: android
on: { push: { tags: ["v*"] } }
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with: { channel: stable, cache: true }
      - run: flutter pub get
      - run: flutter analyze && flutter test
      - run: echo "$KEYSTORE_B64" | base64 -d > android/app/upload.jks
        env: { KEYSTORE_B64: "${{ secrets.KEYSTORE_B64 }}" }
      - run: flutter build apk --release
      - uses: softprops/action-gh-release@v2
        with: { files: build/app/outputs/flutter-apk/app-release.apk }
```

- Run analyze and tests on every pull request; build and sign on tags.
- **Pin versions** of Flutter and plugins. inPace pins `flutter_local_notifications` to 21.x because 22+ needs newer
  build tools: dependency upgrades break builds more often than code does.
- Ship with crash reporting (Crashlytics or Sentry), staged rollouts, and feature flags for risky features.
