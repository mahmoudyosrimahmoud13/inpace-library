# Unit, widget, golden and integration tests

```dart
// unit
test('trip finishes when time is up', () {
  final t = Trip(goal: const Duration(minutes: 25), clock: FakeClock(start));
  t.clock.advance(const Duration(minutes: 25));
  expect(t.isDone, isTrue);
});

// widget
testWidgets('shows the course title', (tester) async {
  await tester.pumpWidget(ProviderScope(
    overrides: [coursesProvider.overrideWith((ref) async => [Course(id: 'a', title: 'Jinja')])],
    child: const MaterialApp(home: CourseList()),
  ));
  await tester.pumpAndSettle();
  expect(find.text('Jinja'), findsOneWidget);
});

// golden
await expectLater(find.byType(CourseCard), matchesGoldenFile('goldens/course_card.png'));
```

- **Mocks:** `mocktail` (no code generation) or hand-written fakes. Prefer fakes for repositories: simpler and more
  honest.
- **Time:** inject a clock; never `DateTime.now()` deep inside logic (inPace's Python side does the same with its
  `clock` module).
- **Integration tests** (`integration_test` package) run on a device or emulator; **Patrol** helps with native dialogs
  like permissions.
- In CI: `flutter analyze`, `dart format --set-exit-if-changed`, `flutter test --coverage`.
