# Theming, localization and right-to-left

## Theming

```dart
MaterialApp(
  theme: ThemeData(colorScheme: ColorScheme.fromSeed(seedColor: const Color(0xFF2F7D6D))),
  darkTheme: ThemeData(colorScheme: ColorScheme.fromSeed(
      seedColor: const Color(0xFF2F7D6D), brightness: Brightness.dark)),
  themeMode: ThemeMode.system,
);
```

Add your own tokens with `ThemeExtension<T>` (spacing, brand colours) and read them with
`Theme.of(context).extension<AppTokens>()`.

## Localization

`flutter_localizations` + `intl` + ARB files (`app_en.arb`, `app_ar.arb`) with plurals and placeholders;
`flutter gen-l10n` generates `AppLocalizations`.

## Right to left

- Arabic locales set `Directionality` to RTL automatically.
- Use **directional** widgets: `EdgeInsetsDirectional`, `AlignmentDirectional`, `PositionedDirectional`,
  `start`/`end` instead of `left`/`right`.
- Mirror direction icons only (back arrows); `Icon` has `matchTextDirection`.
- Test with the locale forced to Arabic, and mixed text (Arabic with English words and numbers).
