# Immutability and equality

State objects should be **immutable**, with `copyWith`, and compare by **value**:

```dart
@immutable
class TripState {
  const TripState({required this.left, this.paused = false});
  final Duration left;
  final bool paused;
  TripState copyWith({Duration? left, bool? paused}) =>
      TripState(left: left ?? this.left, paused: paused ?? this.paused);
  @override
  bool operator ==(Object o) => o is TripState && o.left == left && o.paused == paused;
  @override
  int get hashCode => Object.hash(left, paused);
}
```

Value equality lets Bloc and Riverpod skip rebuilds when nothing really changed. Code generation (`freezed`) writes
this for you; know what it generates.
