# Background work and notifications

- Dart code doesn't run when the app is killed. Options: **WorkManager** (Android periodic or one-off jobs),
  `BGTaskScheduler` on iOS (the OS decides when), push notifications (FCM/APNs) to wake the app.
- **Local notifications**: `zonedSchedule` with the `timezone` package; **exact alarms** on Android 12+ need the
  `SCHEDULE_EXACT_ALARM` permission (or fall back to inexact). inPace chooses exact when allowed, inexact otherwise.
- Android 13+ needs the `POST_NOTIFICATIONS` runtime permission.
- Foreground services for long user-visible work (navigation, music); Android 14 requires declaring their type.
