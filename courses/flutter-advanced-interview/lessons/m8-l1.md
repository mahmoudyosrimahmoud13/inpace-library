# Flavors, signing and builds

- **Flavors** (dev, staging, prod): different app ids, names, icons and API URLs. Android `productFlavors`, iOS schemes,
  `--dart-define-from-file=env/prod.json` for config.
- **Signing:** Android upload key in a keystore (never in git; CI secrets); Play App Signing holds the app signing key.
  iOS: certificates and provisioning profiles (fastlane match helps).
- `flutter build appbundle --release --obfuscate --split-debug-info=build/symbols` and **keep the symbols** to
  de-obfuscate crash reports.
- Versioning: `version: 1.17.0+11700` in pubspec is `versionName+versionCode`. inPace writes `1.17.0+11700`: the code is the version
  with its parts packed into one number, so every release is higher.
