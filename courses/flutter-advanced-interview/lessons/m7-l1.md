# Method channels, Pigeon and FFI

## Platform channels

```dart
const channel = MethodChannel('app/battery');
final level = await channel.invokeMethod<int>('getLevel');
```

```kotlin
MethodChannel(flutterEngine.dartExecutor.binaryMessenger, "app/battery").setMethodCallHandler { call, result ->
    if (call.method == "getLevel") result.success(batteryLevel()) else result.notImplemented()
}
```

- `MethodChannel` for calls, `EventChannel` for streams from native (sensors), `BasicMessageChannel` for raw messages.
- Messages are serialized; they're **asynchronous**; native handlers run on the platform main thread (move heavy
  work off it).

## Pigeon: type-safe channels

Write an interface in Dart; Pigeon generates Dart, Kotlin and Swift code. No string method names, no casting errors.
Prefer it for anything beyond one or two calls.

## FFI

`dart:ffi` calls C functions directly, synchronously, with no serialization: ideal for C/C++/Rust libraries
(crypto, SQLite, image codecs). `ffigen` generates bindings.
