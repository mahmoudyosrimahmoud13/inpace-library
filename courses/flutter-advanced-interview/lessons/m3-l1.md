# Local state, InheritedWidget and listenables

Start with the simplest thing that works.

- **Ephemeral state** (a tab index, an animation) belongs in a `StatefulWidget`.
- **App state** (the signed-in user, a cart) needs to be shared.

Under every package is `InheritedWidget`: descendants read it with `context.dependOnInheritedWidgetOfExactType`, and
**only those** rebuild when it changes.

```dart
class Counter extends ChangeNotifier {
  int value = 0;
  void inc() { value++; notifyListeners(); }
}
final counter = Counter();
ListenableBuilder(listenable: counter, builder: (_, __) => Text('${counter.value}'));
```

`ValueNotifier<T>` + `ValueListenableBuilder` cover a lot of simple cases with no package at all.
