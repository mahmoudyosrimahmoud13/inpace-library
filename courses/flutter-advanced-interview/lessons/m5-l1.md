# Finding jank with DevTools

**Always profile in profile mode** (`flutter run --profile`) on a real, preferably low-end, device. Debug mode is
much slower and lies.

DevTools:

- **Performance:** frame chart. A red bar means the UI or raster thread missed its budget.
- **Track widget rebuilds** to see what rebuilds too often.
- **CPU profiler** for slow Dart code.
- **Memory:** leaks (growing heap, retained `State` objects).
- **Network** and **Logging**.

The usual causes:

| Cause | Fix |
|---|---|
| Rebuilding big subtrees | split widgets, `const`, select only what you need (`ref.watch(p.select(...))`, `BlocSelector`) |
| Heavy work in `build` | compute once and cache; never sort or parse in build |
| Long lists built eagerly | `ListView.builder`, `itemExtent` or `prototypeItem` |
| Expensive effects | `saveLayer` from `Opacity`, `ClipRRect`, shadows: use `FadeTransition`, pre-clipped images |
| Big images | `cacheWidth`/`cacheHeight` to decode at display size |
| CPU work on the UI isolate | `Isolate.run` / `compute` |
