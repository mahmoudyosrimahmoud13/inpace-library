# Generics, mixins and extensions

```dart
abstract interface class Repository<T, Id> {
  Future<T?> find(Id id);
  Future<void> save(T item);
}

mixin Loggable { void log(String m) => debugPrint('[$runtimeType] $m'); }
class CourseRepo with Loggable implements Repository<Course, String> { ... }

extension DurationText on Duration {
  String get mmss => '${inMinutes.remainder(60).toString().padLeft(2, '0')}:'
                     '${inSeconds.remainder(60).toString().padLeft(2, '0')}';
}
print(const Duration(seconds: 754).mmss);   // 12:34
```

- Generics are **reified** in Dart: `List<int>` knows it's a list of ints at runtime (unlike Java's erasure).
- Mixins add behaviour without inheritance chains; `on` restricts where they apply.
- Extensions add methods to types you don't own; they're resolved statically (no runtime dispatch).
