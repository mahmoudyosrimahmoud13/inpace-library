# Multi-head attention and the transformer

**Multi-head** attention runs several attentions in parallel, each with its own `W_Q, W_K, W_V`, so different heads can
track different relations (who did what, when), then concatenates them.

A transformer **encoder** layer: multi-head self-attention → add & **LayerNorm** → feed-forward network → add &
LayerNorm. The **decoder** adds masked self-attention and attention over the encoder's output. **Positional encoding**
tells the model where each word is, since attention itself ignores order:

![Positional encoding](positional.png)

The notebook proves attention matters: a model that must count how often each token appears scores **30%** without
attention and **99.4%** as a tiny 2-layer transformer.
