# Sentiment classification and debiasing

With embeddings, a tiny model (average the word vectors, then softmax) already works, but it ignores word order:
"completely lacking in good taste, good service and good ambience" has "good" three times. An RNN over the embeddings
reads the order.

**Bias:** embeddings learn society's stereotypes from text ("man is to computer programmer as woman is to homemaker").
The slides' fix: find the bias direction, neutralize words that should be neutral, equalize pairs like
grandmother/grandfather. Bias in models trained on web text is still an active problem: test for it, measure it,
and don't assume it's gone.
