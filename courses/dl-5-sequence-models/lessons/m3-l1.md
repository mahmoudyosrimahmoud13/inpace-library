# Vanishing gradients in RNNs

"The **cat**, which already ate …, **was** full": to get "was" right, the network must remember "cat" over many steps.
But the gradient is multiplied by the same weights at every step, so it shrinks (or explodes) exponentially:

![How far back the gradient reaches](vanishing.png)

A real measurement on untrained networks: in a plain RNN the gradient from the last step is about 10¹⁴ times weaker
60 steps back. An LSTM whose **forget gate starts open** keeps it close to full strength. (Exploding gradients are
easier: **clip** them, `torch.nn.utils.clip_grad_norm_`.)
