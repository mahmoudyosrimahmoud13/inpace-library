# Word representations and using embeddings

One-hot vectors treat every pair of words as equally different: "apple" is as far from "orange" as from "king". An
**embedding** is a dense vector (say 300 numbers) where similar words are close, so what the model learns about
"orange juice" helps with "apple juice".

**Transfer learning with embeddings:** learn them from a huge text corpus (or download them), then use them for a task
with little labelled data, like named-entity recognition. That was the first big wave of transfer learning in NLP;
today, whole pre-trained transformers play that role.
