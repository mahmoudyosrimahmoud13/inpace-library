# Analogies, cosine similarity and the embedding matrix

`e_king − e_man + e_woman ≈ e_queen`: directions in the space carry meaning. Compare vectors with **cosine
similarity**, `u·v / (||u||·||v||)`. The notebook's tiny hand-made example finds "queen" with similarity 1.0.

The **embedding matrix** `E` has one row (or column) per word; multiplying by a one-hot vector picks one row. In
practice you never multiply: you **look up**.

```python
emb = nn.Embedding(num_embeddings=10_000, embedding_dim=300)   # keras.layers.Embedding(10_000, 300)
vectors = emb(token_ids)                                       # (batch, time) -> (batch, time, 300)
```
