# Sequence-to-sequence models

An **encoder** reads the input (a French sentence, or an image's CNN features for captioning); a **decoder** writes the
output. The decoder is a **conditional language model**: `P(English | French)`. We want the most likely whole
sentence, `argmax_y P(y | x)`.

**Greedy** search (best word at every step) often fails: "Jane is going to be visiting" can beat "Jane is visiting" word
by word while being less likely as a whole.
