# Beam search, refinements and error analysis

**Beam search** keeps the `B` most likely partial sentences at every step (B = 3 in the slides; 10 in production was
common). B = 1 is greedy.

- **Length normalization:** multiplying many probabilities favours short outputs; use the average log-probability,
  `(1/T_y^α)·Σ log P` with `α ≈ 0.7`.
- **Error analysis:** compare `P(y*)` (the human translation) with `P(ŷ)` (yours). If `P(y*) > P(ŷ)`, beam search
  missed it: increase B. If `P(y*) ≤ P(ŷ)`, the **model** is at fault: count which is more common before fixing.

The notebook's toy model: greedy finds a sentence with probability 0.041; beam search (B = 3) finds one with 0.400.
