# The recurrent network

A standard network can't share what it learned at one position with another, and needs fixed sizes. An RNN reads
one element at a time and carries a **hidden state**:

```text
a<t> = tanh(W_aa·a<t−1> + W_ax·x<t> + b_a)
ŷ<t> = softmax(W_ya·a<t> + b_y)
```

The **same** weights at every step. **Backpropagation through time** unrolls the loop and sums the gradients over
steps.

Architectures by shape: **many-to-many** with equal lengths (tagging names in a sentence), **many-to-one** (sentiment),
**one-to-many** (music generation), and **many-to-many with different lengths** (translation: an encoder then a decoder).

```python
rnn = nn.RNN(input_size=8, hidden_size=32, batch_first=True)   # keras.layers.SimpleRNN(32)
out, h_last = rnn(x)            # x: (batch, time, features); out: every step's hidden state
```
