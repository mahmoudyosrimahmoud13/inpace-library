# Homes

The running project of the inPace course "Machine Learning refresh 1": California house values (1990 census, the Hands-On Machine Learning version), with linear and logistic regression from scratch.

```bash
pip install numpy pandas scikit-learn
python p1_one_feature.py
```

| File | What it adds |
|---|---|
| `homes.py` | Loading and cleaning the data |
| `p1_one_feature.py` | One feature and the cost function |
| `p2_gradient_descent.py` | Gradient descent and learning rates |
| `p3_many_features.py` | Many features, vectorization, scaling |
| `p4_logistic.py` | Logistic regression: expensive or not |
| `p5_regularization.py` | Overfitting and L2 regularization |
| `p6_check_with_sklearn.py` | Your models against scikit-learn, and trees |
