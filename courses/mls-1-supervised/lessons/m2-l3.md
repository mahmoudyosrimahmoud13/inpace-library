# Practice: compute a cost by hand

Data: `(1, 2), (2, 4), (3, 5)`. Model `f(x) = 2x + 0`.

Predictions: 2, 4, 6. Errors: 0, 0, 1. Squared: 0, 0, 1. Sum = 1. `J = 1 / (2·3) = 0.1667`.

Now compute `J` for `w = 1.5, b = 0.67` and decide which line is better. Then write this in NumPy:

```python
import numpy as np
x = np.array([1., 2., 3.]); y = np.array([2., 4., 5.])
def cost(w, b):
    return ((w * x + b - y) ** 2).sum() / (2 * len(x))
print(cost(2, 0), cost(1.5, 0.67))
```
