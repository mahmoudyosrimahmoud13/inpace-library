# The logistic loss

Squared error with a sigmoid gives a **non-convex** cost with local minima. Use the log loss instead:

```text
loss = −log(f(x))       if y = 1
loss = −log(1 − f(x))   if y = 0

J(w,b) = −(1/m) Σᵢ [ y⁽ⁱ⁾ log f(x⁽ⁱ⁾) + (1 − y⁽ⁱ⁾) log(1 − f(x⁽ⁱ⁾)) ]
```

- Predict 0.99 when the truth is 1: tiny loss. Predict 0.01 when the truth is 1: huge loss.
- This cost is **convex** for logistic regression.
- It comes from **maximum likelihood** for a Bernoulli variable: the same principle that gave squared error for
  Gaussian noise. Saying this links Day 2 and today, which interviewers like.

## Numerical stability

`log(0)` is `−inf`. Real code clips predictions (`np.clip(p, 1e-15, 1 − 1e-15)`) or computes the loss from `z`
directly (`BCEWithLogits` in PyTorch, `from_logits=True` in TensorFlow). Part 2 comes back to this.
