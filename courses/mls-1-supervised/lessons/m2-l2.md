# The squared error cost

```text
J(w, b) = (1 / 2m) · Σᵢ ( f_w,b(x⁽ⁱ⁾) − y⁽ⁱ⁾ )²
```

- Square so positive and negative errors don't cancel, and big errors count more.
- Divide by `m` so the cost doesn't grow with the dataset size.
- The `1/2` only makes the derivative tidier.

**Goal:** `minimize J(w, b)` over `w, b`.

The slides show `J` as a bowl (3D surface) and as **contour plots**: each ring is a set of `(w, b)` with the same cost;
the centre is the minimum.

## Going further

- For linear regression, `J` is **convex**: one global minimum, no local traps. That's a key fact for later, because
  neural networks lose this property.
- **MSE vs MAE:** squared error punishes outliers hard (a single huge error dominates); mean absolute error is more
  robust but not smooth at zero. **Huber loss** is squared near zero and linear far away: a common interview answer
  for "my data has outliers".
- There's also a closed form, the **normal equation** `w = (XᵀX)⁻¹Xᵀy`. It's exact but costs about `O(n³)` in the
  number of features and fails when `XᵀX` is singular; gradient descent scales better and generalizes to other models.
