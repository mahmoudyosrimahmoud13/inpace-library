# The model

Notation you must be fluent in:

| Symbol | Means |
|---|---|
| `x` | input feature, `y` target |
| `m` | number of training examples |
| `(x⁽ⁱ⁾, y⁽ⁱ⁾)` | the i-th example |
| `ŷ` ("y-hat") | the prediction |
| `w, b` | parameters (weight and bias) |

Univariate linear regression:

```text
f_w,b(x) = w·x + b
```

Training means choosing `w` and `b` so `ŷ⁽ⁱ⁾` is close to `y⁽ⁱ⁾` for the training examples, and, what really
matters, close for **new** examples.

## Advanced view

- Linear regression is linear **in the parameters**, not necessarily in `x`: `w₁x + w₂x² + b` is still linear
  regression (Day 5: polynomial features).
- Under the hood it's a statistical model: `y = w·x + b + noise`. If the noise is Gaussian, minimizing squared error is
  the same as **maximum likelihood**. That's why squared error is the natural choice, not just a convenient one.
