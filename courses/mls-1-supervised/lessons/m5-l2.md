# Checking convergence and choosing α

- Plot `J` against iterations. It should **decrease every iteration** and flatten.
- An automatic test ("stop when `J` drops by less than ε = 0.001") is possible, but choosing ε is hard; the plot is
  more reliable.
- Choosing `α`: try 0.001, 0.003, 0.01, 0.03, 0.1, 0.3, 1 (×3 steps). Pick the largest that decreases smoothly.
- Debug trick: with a very small `α`, `J` **must** go down. If it doesn't, you have a bug.
