# Gradient descent for logistic regression

The update looks **identical** to linear regression:

```text
w_j = w_j − α · (1/m) Σᵢ ( f(x⁽ⁱ⁾) − y⁽ⁱ⁾ ) · x_j⁽ⁱ⁾
b   = b   − α · (1/m) Σᵢ ( f(x⁽ⁱ⁾) − y⁽ⁱ⁾ )
```

but `f` is now the sigmoid. That neat result comes from `g'(z) = g(z)(1 − g(z))` cancelling with the log loss.

```python
def sigmoid(z): return 1 / (1 + np.exp(-z))

def step(X, y, w, b, alpha):
    p = sigmoid(X @ w + b)
    err = p - y
    return w - alpha * X.T @ err / len(y), b - alpha * err.mean()
```

Same tools as before: scaling, a learning curve, vectorization.
