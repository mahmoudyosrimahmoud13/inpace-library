# Capstone: a tiny ML library

Build `tinyml.py` with no ML libraries (NumPy only):

```python
class LinearRegression:
    def __init__(self, alpha=0.01, iters=2000, lam=0.0): ...
    def fit(self, X, y): ...           # stores mu, sigma from X; trains w, b; keeps self.history
    def predict(self, X): ...          # applies the SAME mu, sigma

class LogisticRegression(LinearRegression):
    def predict_proba(self, X): ...
    def predict(self, X, threshold=0.5): ...
```

Requirements:

- Vectorized everything; shapes written in comments.
- Z-score scaling fitted in `fit` only.
- L2 regularization (not on `b`).
- Tests: on a dataset you generate with known `w`, `b`, your model recovers them closely; your results match
  scikit-learn within a small tolerance.
- A README with the learning curves.

This is the exact kind of take-home many ML internships and junior roles give.
