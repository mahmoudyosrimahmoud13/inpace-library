# Practice: label the problem

For each, say supervised or unsupervised; regression or classification or which unsupervised kind:

1. Predict a learner's final quiz score from their study minutes. (supervised, regression)
2. Group learners by how they study, with no labels. (unsupervised, clustering)
3. Flag a login that looks nothing like the user's normal ones. (unsupervised, anomaly detection)
4. Decide if a review is positive or negative. (supervised, classification)
5. Squeeze 1,000 features into 50 for a plot. (unsupervised, dimensionality reduction)

Now invent one example of each kind from your own work or studies, and write the input `x` and output `y` clearly.
That habit (always naming `x` and `y`) is the first thing good interviewers listen for.
