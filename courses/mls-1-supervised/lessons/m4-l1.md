# Multiple linear regression

With `n` features, `x` and `w` are vectors:

```text
f_w,b(x) = w·x + b = w₁x₁ + w₂x₂ + … + wₙxₙ + b
```

Notation: `x_j` is feature j; `x⁽ⁱ⁾` is example i (a vector); `x_j⁽ⁱ⁾` is feature j of example i. The data is a
matrix `X` of shape `(m, n)`.

Gradient descent is the same idea, for every `w_j` at once:

```text
w_j = w_j − α · (1/m) Σᵢ ( f(x⁽ⁱ⁾) − y⁽ⁱ⁾ ) · x_j⁽ⁱ⁾
```

## Interpreting weights (careful!)

`w_j` is the change in prediction for a one-unit change in `x_j` **holding the others fixed**. Weights are only
comparable if features are on similar scales, and correlated features (multicollinearity) can make individual
weights unstable even when predictions are fine.
