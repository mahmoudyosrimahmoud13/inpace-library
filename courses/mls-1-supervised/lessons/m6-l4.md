# Project 4: logistic regression, is this district expensive?

You'll turn Homes into a classifier: is a district's median value above $250,000? Logistic regression, from scratch.

The code is above this text. Save it as `p4_logistic.py`.

## Read the code

- **`sigmoid()`** squashes any number into 0..1 (clipped so huge inputs don't overflow).
- **`train()`** is gradient descent again; with the sigmoid, the gradient of the log loss has the same simple shape:
  `X.T @ (p - y) / m`. `lam` adds L2 regularization (used tomorrow).
- **`log_loss()`** is the cost for classifiers: it punishes confident wrong answers hard.
- The script compares with the "always no" baseline, prints the strongest weights, precision and recall, and the
  three districts the model was least sure about.

## Run it

```bash
python p4_logistic.py
```

What it shows:

- **75% is the bar**: a model that always says "not expensive" is right three times in four. 87% is real progress,
  but much less than the number suggests on its own.
- Location and crowding (people per household) separate expensive districts.
- **It finds two in three expensive districts**, and 80% of its "expensive" calls are right. Moving the 0.5
  threshold trades one for the other (part 2 of the refresh goes deeper).
- The least sure districts sit right at the border: values near $250k.
