# Feature engineering and polynomial regression

Good features often matter more than the algorithm. Example: from frontage and depth, create `area = frontage × depth`.

**Polynomial regression** fits curves with linear regression by adding powers: `x, x², x³` or `√x`.

```python
X_poly = np.c_[x, x**2, x**3]
X_poly = (X_poly - X_poly.mean(0)) / X_poly.std(0)   # scaling is essential: x³ explodes
```

## Going further

- More features add flexibility and also the risk of **overfitting** (Day 8).
- scikit-learn's `PolynomialFeatures` + `StandardScaler` + `LinearRegression` in a `Pipeline` keeps the steps in order
  and fitted only on training data.
- Interactions (`x₁·x₂`), logs for skewed values (prices, counts), one-hot encoding for categories (part 2), and date
  parts (day of week) are the everyday feature engineering moves.
