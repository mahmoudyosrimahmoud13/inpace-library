# Vectorization

```python
# loop
f = 0
for j in range(n):
    f += w[j] * x[j]
f += b

# vectorized
f = np.dot(w, x) + b
```

Vectorized code is shorter **and** much faster: NumPy calls optimized C and uses the CPU's SIMD instructions and
parallel hardware; on GPUs the speed-up is huge. For the whole dataset:

```python
def predict(X, w, b):          # X: (m, n), w: (n,)
    return X @ w + b           # (m,)

def gradients(X, y, w, b):
    err = X @ w + b - y        # (m,)
    dw = X.T @ err / len(y)    # (n,)
    db = err.mean()
    return dw, db
```

Get used to writing the **shapes** next to every line. Shape bugs are the most common ML code bug, and NumPy
broadcasting can hide them (a `(m,)` minus `(m, 1)` silently becomes `(m, m)`).
