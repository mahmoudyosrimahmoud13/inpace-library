# Project 1: a line through real house prices

From today to the end of this course you build **Homes**: predicting California house values, first with one
feature, then many, then classifying expensive districts, all from scratch with NumPy, and finally checked against
scikit-learn.

The project folder is above this text. Save it with its `data` folder and install `pip install numpy pandas
scikit-learn`. The data is the 1990 California census by district (20,640 rows), the version used in Aurélien
Géron's *Hands-On Machine Learning*. `homes.py` loads it, fills 207 missing bedroom counts with the median, adds two
ratios, and drops districts whose value was capped at $500,001 (not real prices).

## Read the code

- `cost(w, b)` is the squared error cost from the lesson: the mean of squared errors, divided by 2.
- The script evaluates it on a grid of 28,341 `(w, b)` pairs and finds the lowest, then compares with the exact
  least-squares line from `np.polyfit`, then tests on districts the line never saw.

## Run it

```bash
python p1_one_feature.py
```

The real output:

```text
19,648 districts (15,718 to train, 3,930 to test). Income is in $10,000s.

1. Correlation between median income and house value: 0.64
2. Cost on a grid of 28,341 (w, b) pairs: lowest 2,751 at w = 40.0, b = 45.0
   w =   0.0, b =  192.1  ->  cost     4,682
   w =  20.0, b =   50.0  ->  cost     5,588
   w =  40.0, b =   45.0  ->  cost     2,751
3. The exact least-squares line: value = 39.8 x income + 45.9  (cost 2,751)
4. On the test districts: typical error (RMSE) $74k; predicting the average for everyone: $98k
   A district with median income $50,000 (x = 5): predicted $245k
```

What it shows:

- Income alone explains a lot (correlation 0.64): the best line roughly says "+$40k of house value per +$10k of
  income".
- The grid's lowest point and the exact solution agree. The cost really is a bowl with one bottom.
- On new districts the typical error is $74k, against $98k for "everyone gets the average". Better, and far from
  perfect: one feature isn't enough.

## What to take away

- The cost function scores every possible line; training finds its lowest point.
- Always compare with a baseline on data the model didn't see.
