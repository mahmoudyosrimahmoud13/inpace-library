# Feature scaling

If one feature ranges 300 to 2,000 (square feet) and another 0 to 5 (bedrooms), the cost contours are long thin
ellipses, and gradient descent zig-zags. Scaling makes them rounder and convergence much faster.

| Method | Formula |
|---|---|
| Divide by max | `x / max` |
| Mean normalization | `(x − μ) / (max − min)` |
| **Z-score** | `(x − μ) / σ` |

Aim for roughly `−1 ≤ x ≤ 1` (anything from about −3 to 3 is fine).

## The rule interviewers check

Compute `μ` and `σ` **on the training set only**, then apply those same numbers to validation, test and live data.
Computing them on all data **leaks** information from the test set. Save them with the model.

Trees (part 2) don't need scaling; anything trained by gradient descent, and distance-based methods (k-means, KNN),
do.
