# Gradient descent for linear regression

The derivatives for squared error:

```text
∂J/∂w = (1/m) Σᵢ ( f(x⁽ⁱ⁾) − y⁽ⁱ⁾ ) · x⁽ⁱ⁾
∂J/∂b = (1/m) Σᵢ ( f(x⁽ⁱ⁾) − y⁽ⁱ⁾ )
```

(The `1/2` in `J` cancels the `2` from the square.)

```python
def gradient_descent(x, y, w=0.0, b=0.0, alpha=0.01, iters=1000):
    m = len(x)
    history = []
    for _ in range(iters):
        err = w * x + b - y
        dw = (err * x).sum() / m
        db = err.sum() / m
        w, b = w - alpha * dw, b - alpha * db       # simultaneous
        history.append((err ** 2).sum() / (2 * m))
    return w, b, history
```

Plot `history`: a **learning curve** over iterations. It should go down every step; if it ever goes up, `α` is too
big (or there's a bug).

> **Interview:** derive `∂J/∂w` on a whiteboard. Use the chain rule: the outer square gives `2(f − y)`, the inner
> `f = wx + b` gives `x`. Being able to do this calmly is a strong signal.
