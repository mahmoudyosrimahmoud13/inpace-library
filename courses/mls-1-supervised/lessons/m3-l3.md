# Project 2: gradient descent from scratch

You'll find the same line as yesterday, but the way neural networks learn: start somewhere, step downhill, repeat.

The code is above this text. Save it as `p2_gradient_descent.py`.

## Read the code

- **`descend(alpha)`** starts at `w = b = 0`. Each step computes the error for every district, the two partial
  derivatives (`mean(err * x)` and `mean(err)`), and moves both parameters against them, scaled by the learning rate
  `alpha`. It records a few steps, and stops if `w` explodes.
- It runs with four learning rates.

## Run it

```bash
python p2_gradient_descent.py
```

What it shows:

- **0.001 is too slow**: after 2,000 steps it's still far from `w = 39.8, b = 45.9`.

- **0.13 diverges**: each step overshoots more, and within 100 steps the numbers are astronomical. There's a cliff
  between "fast" and "broken", which is why you watch the cost while training.
- Notice `b` moves much more slowly than `w`: income values are around 4, so `w`'s gradient is bigger. Tomorrow's
  feature scaling fixes exactly that.

## What to take away

- The learning rate decides between slow, fast and divergent.
