# The model and the decision boundary

For a yes/no label `y ∈ {0, 1}`, a straight line's output isn't a probability and one outlier can drag the threshold.
Use the **sigmoid**:

```text
g(z) = 1 / (1 + e^(−z))         z = w·x + b
f_w,b(x) = g(w·x + b) = P(y = 1 | x; w, b)
```

`g(0) = 0.5`, large `z` → 1, very negative `z` → 0.

**Decision boundary:** predict 1 when `f ≥ 0.5`, which means `w·x + b ≥ 0`. With raw features it's a line (a
hyperplane); with polynomial features (`x₁², x₂²`) it can be a circle or any curve.

## Going further

- `z` is the **log-odds**: `log(p / (1 − p)) = w·x + b`. So `wⱼ` changes the log-odds by `wⱼ` per unit of `xⱼ`.
- The threshold 0.5 is a choice. Moving it trades precision for recall (part 2, skewed datasets).
- For many classes: one-vs-rest, or softmax regression (part 2).
