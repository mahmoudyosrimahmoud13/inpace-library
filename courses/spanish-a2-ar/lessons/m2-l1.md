# حكاية رحلة

يوسف ذهب إلى غرناطة. أكثر الأفعال شيوعًا شاذة في الماضي: fui وhice وtuve وestuve...

## استمع أولًا: المحادثة

**العودة من غرناطة**

| الإسبانية | المعنى |
|---|---|
| **Carmen:** ¿Adónde fuiste en vacaciones? | إلى أين ذهبت في الإجازة؟ |
| **Yusuf:** Fui a Granada con mi mujer. Estuvimos cuatro días. | ذهبت إلى غرناطة مع زوجتي. بقينا أربعة أيام. |
| **Carmen:** ¡Qué envidia! ¿Qué tal fue? | يا بختك! كيف كانت؟ |
| **Yusuf:** Fue increíble. El primer día vimos la Alhambra. Tuvimos que reservar las entradas con un mes de antelación. | كانت رائعة. في اليوم الأول رأينا قصر الحمراء. اضطررنا لحجز التذاكر قبلها بشهر. |
| **Carmen:** ¿Y qué más hicisteis? | وماذا فعلتما أيضًا؟ |
| **Yusuf:** Paseamos por el Albaicín, tomamos té en una tetería y una noche fuimos a un espectáculo de flamenco. | تمشّينا في حي البيازين، وشربنا شايًا في مقهى شاي، وفي ليلة ذهبنا لعرض فلامنكو. |
| **Carmen:** ¿Hizo buen tiempo? | هل كان الجو جيدًا؟ |
| **Yusuf:** Sí, hizo sol todos los días. Solo tuvimos un problema: ¡no pude dormir por el calor! | نعم، كان مشمسًا كل يوم. كانت عندنا مشكلة واحدة فقط: لم أستطع النوم من الحر! |

## قلّد الكلام (Shadowing)

اقرأ المحادثة بصوت عالٍ **ثلاث مرات**: أولًا ببطء، ثم بسرعة عادية، ثم دون أن تنظر إلى عمود المعنى. ولو عندك الصوت من الروابط بالأسفل، أوقفه بعد كل جملة وقلّد إيقاع المتكلم ولحن صوته، لا الكلمات فقط. هذا اسمه **التقليد (Shadowing)**، وهو يدرّب أذنك ولسانك معًا.

## كلمات وعبارات احفظها

| العبارة | المعنى |
|---|---|
| ¿Adónde fuiste? | إلى أين ذهبت؟ |
| Fui a... con... | ذهبت إلى... مع... |
| Estuvimos cuatro días. | بقينا أربعة أيام. |
| ¿Qué tal fue? Fue increíble. | كيف كانت؟ كانت رائعة. |
| Tuvimos que... | اضطررنا أن... |
| reservar las entradas / el hotel | يحجز التذاكر / الفندق |
| ¿Hizo buen tiempo? | هل كان الجو جيدًا؟ |
| Hizo sol / frío / calor. | كان مشمسًا / باردًا / حارًا. |
| No pude dormir. | لم أستطع النوم. |
| ¡Qué envidia! | يا بختك! |
| el primer día / el último día | اليوم الأول / اليوم الأخير |

## انطقها صح

**الوصل.** المتحدثون بالإسبانية يصلون الكلمات: عندما تنتهي كلمة بحرف علة وتبدأ التالية بحرف علة، يندمجان في مقطع واحد. *Fue a la Alhambra* تُسمع "فويا لالامبرا" تقريبًا. و*Fui a Granada* ← "فويا غرانادا". لهذا تبدو الإسبانية السريعة كأنها كلمة واحدة طويلة.

تدرّب على قراءة جمل المحادثة بالوصل: *Estuvimos en el hotel* و*tomamos un té* و*la entrada*.
