# الماضي البسيط المنتظم

لحدث **انتهى في وقت محدد في الماضي**: *ayer* (أمس)، *anoche* (البارحة)، *el lunes pasado*، *en 2020*، *hace dos años* (منذ سنتين).

| | -ar (hablar) | -er و -ir (comer، vivir) |
|---|---|---|
| yo | habl**é** | com**í** / viv**í** |
| tú | habl**aste** | com**iste** |
| él / ella | habl**ó** | com**ió** |
| nosotros | habl**amos** | com**imos** |
| vosotros | habl**asteis** | com**isteis** |
| ellos | habl**aron** | com**ieron** |

**العلامة مهمة:** *hablo* (أتكلم) غير *habló* (تكلّم هو).

## تغيير في الكتابة مع yo

*llegar → llegué*، *buscar → busqué*، *empezar → empecé*، *jugar → jugué*. (للحفاظ على نفس النطق.)
و *leer → leyó, leyeron*، *creer → creyó*.

```text
Ayer trabajé hasta las ocho.        أمس اشتغلت حتى الثامنة.
El año pasado viví en Madrid.       العام الماضي عشت في مدريد.
¿Cuándo llegaste?                   متى وصلت؟
```

## تمرين

(yo) comprar، (ellos) salir، (tú) escribir، (yo) llegar، (nosotros) cenar.

**الإجابات:** compré، salieron، escribiste، llegué، cenamos.
