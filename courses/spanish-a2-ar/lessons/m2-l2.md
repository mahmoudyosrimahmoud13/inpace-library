# الماضي الشاذ: fui, tuve, hice

## ser و ir: نفس الماضي!

| fui | fuiste | fue | fuimos | fuisteis | fueron |
|---|---|---|---|---|---|

المعنى من السياق: *Fui al cine* (ذهبت للسينما)، *Fue increíble* (كان رائعًا).

## جذور شاذة بنهايات خاصة (بدون علامات)

| المصدر | الجذر | yo / él |
|---|---|---|
| tener | tuv- | tuve / tuvo |
| estar | estuv- | estuve / estuvo |
| poder | pud- | pude / pudo |
| poner | pus- | puse / puso |
| saber | sup- | supe / supo |
| hacer | hic- | hice / **hizo** |
| querer | quis- | quise / quiso |
| venir | vin- | vine / vino |
| decir | dij- | dije / dijo / ellos **dijeron** |

النهايات: **-e, -iste, -o, -imos, -isteis, -ieron** (و -eron بعد j: *dijeron, trajeron*).

## dar و ver

*di, diste, dio...* و *vi, viste, vio...* (بدون علامات).

## أفعال -ir بتغيير الجذر (مع él و ellos)

*pedir → pidió, pidieron*، *dormir → durmió, durmieron*، *sentir → sintió*.

## تمرين

(yo) hacer، (ella) estar، (nosotros) tener، (ellos) decir، (tú) ir، (él) dormir.

**الإجابات:** hice، estuvo، tuvimos، dijeron، fuiste، durmió.
