# lo, la, le: لا تكرر الاسم

## المفعول المباشر: lo, la, los, las (ماذا؟ من؟)

```text
¿Compras el pan?، Sí, lo compro.          هل تشتري الخبز؟ نعم، أشتريه.
¿Ves a María?، Sí, la veo.               هل ترى ماريا؟ نعم، أراها.
¿Tienes las llaves?، No, no las tengo.    معك المفاتيح؟ لا، ليست معي.
```

## المفعول غير المباشر: le, les (لمن؟)

```text
Le escribo a mi madre.      أكتب لأمي.
Les doy un regalo.          أعطيهم هدية.
```

## مكان الضمير

- **قبل الفعل المصرّف:** *Lo compro.*
- **أو ملتصق بالمصدر وبالـ gerundio:** *Voy a comprarlo* = *Lo voy a comprar*.
- **ملتصق بالأمر الإيجابي:** *¡Cómpralo!*

## ضميران معًا: le + lo = se lo

*Le doy el libro → **Se lo** doy.* (أعطيه إياه.) لا تقل *le lo* ❌.

## تمرين

أعد الصياغة بضمير: Compro **las manzanas**. Llamo **a Pedro**. Doy **el regalo a mi hermana**.

**الإجابات:** Las compro. Lo llamo. Se lo doy.
