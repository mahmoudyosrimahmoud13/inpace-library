# في محل ملابس

يوسف يحتاج جاكيت. استمع للمقارنات (más... que) وللكلمتين الصغيرتين lo وla اللتين تحلان محل الاسم.

## استمع أولًا: المحادثة

**شراء جاكيت**

| الإسبانية | المعنى |
|---|---|
| **Dependienta:** Hola, ¿le puedo ayudar en algo? | مرحبًا، هل أستطيع مساعدتك؟ |
| **Yusuf:** Sí, busco una chaqueta para el invierno. | نعم، أبحث عن جاكيت للشتاء. |
| **Dependienta:** Tenemos esta negra y esta azul. La negra es más larga y más caliente. | عندنا هذا الأسود وهذا الأزرق. الأسود أطول وأدفأ. |
| **Yusuf:** ¿Y cuál es más barata? | وأيهما أرخص؟ |
| **Dependienta:** La azul. Cuesta ochenta euros; la negra cuesta ciento veinte. | الأزرق. سعره ثمانون يورو؛ والأسود مئة وعشرون. |
| **Yusuf:** Me gusta la negra. ¿Me la puedo probar? Uso la talla M. | يعجبني الأسود. هل أستطيع تجربته؟ مقاسي M. |
| **Dependienta:** Claro, los probadores están al fondo. | طبعًا، غرف القياس في الخلف. |
| **Yusuf:** Me queda un poco pequeña. ¿La tiene en una talla más grande? | إنه ضيق قليلًا عليّ. هل عندك مقاس أكبر؟ |
| **Dependienta:** Sí, aquí tiene la L. Es tan bonita como la otra. | نعم، تفضّل مقاس L. إنه جميل مثل الآخر. |
| **Yusuf:** Perfecta. Me la llevo. ¿Puedo pagar con tarjeta? | ممتاز. سآخذه. هل أستطيع الدفع بالبطاقة؟ |

## قلّد الكلام (Shadowing)

اقرأ المحادثة بصوت عالٍ **ثلاث مرات**: أولًا ببطء، ثم بسرعة عادية، ثم دون أن تنظر إلى عمود المعنى. ولو عندك الصوت من الروابط بالأسفل، أوقفه بعد كل جملة وقلّد إيقاع المتكلم ولحن صوته، لا الكلمات فقط. هذا اسمه **التقليد (Shadowing)**، وهو يدرّب أذنك ولسانك معًا.

## كلمات وعبارات احفظها

| العبارة | المعنى |
|---|---|
| ¿Le puedo ayudar? | هل أستطيع مساعدتك؟ |
| Busco... | أبحث عن... |
| ¿Cuánto cuesta / cuestan? | كم سعره / سعرها؟ |
| ¿Me lo/la puedo probar? | هل أستطيع تجربته؟ |
| ¿Qué talla usa? | ما مقاسك؟ |
| Me queda grande / pequeño. | واسع / ضيق عليّ. |
| ¿Lo tiene en otro color? | هل عندك لون آخر؟ |
| Me lo/la llevo. | سآخذه. |
| ¿Puedo pagar con tarjeta / en efectivo? | هل أستطيع الدفع بالبطاقة / نقدًا؟ |
| Está de rebajas. | عليه تخفيض. |
| ciento veinte, doscientos, quinientos | 120، 200، 500 |

## انطقها صح

**الإيقاع.** الإسبانية تعطي كل مقطع تقريبًا نفس الطول، كأنه رشاش: *la-ne-gra-es-más-lar-ga*. أما الإنجليزية (والعربية بدرجة ما) فتمد المقاطع المضغوطة وتضغط الباقي. جرّب أن تنقر على الطاولة نقرة لكل مقطع وأنت تقرأ المحادثة: نقرة لكل مقطع، بسرعة ثابتة. ولا تبتلع أي حرف علة.
