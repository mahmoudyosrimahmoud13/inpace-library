# نظرية الأعداد 2: الأسس السريعة والمعكوس الضربي

## الأس السريع (Fast Power)

حساب aⁿ بضرب a في نفسه n مرة: O(n)، مستحيل لـ n = 10¹⁸. الفكرة: a¹⁰ = (a⁵)²، و a⁵ = a × (a²)². نقسم الأس على 2 كل خطوة: O(log n).

```cpp
long long power(long long a, long long n, long long mod) {
    long long res = 1;
    a %= mod;
    while (n > 0) {
        if (n & 1) res = res * a % mod;   // البت الحالي = 1
        a = a * a % mod;
        n >>= 1;
    }
    return res;
}
```

مثال: a¹³، و 13 بالثنائي = 1101، إذن a¹³ = a⁸ × a⁴ × a¹.

## المعكوس الضربي (Modular Inverse)

لحساب (a / b) mod p، نضرب a في **معكوس** b: الرقم الذي إذا ضربناه في b أعطى 1 (mod p).

**نظرية فيرما الصغرى**: إذا كان p أوليًا (مثل 10⁹+7) و b لا يقبل القسمة على p:

```
b^(p-1) ≡ 1 (mod p)   ⟹   b^(p-2) هو معكوس b
```

```cpp
long long inv(long long b) { return power(b, MOD - 2, MOD); }
long long divide(long long a, long long b) { return a % MOD * inv(b) % MOD; }
```

## التوافيق nCr مع mod

عدد طرق اختيار r من n: n! / (r! (n−r)!). نجهّز المضروب ومعكوسه مرة واحدة:

```cpp
const int N = 1e6;
vector<long long> fact(N + 1), inv_fact(N + 1);
fact[0] = 1;
for (int i = 1; i <= N; i++) fact[i] = fact[i - 1] * i % MOD;
inv_fact[N] = power(fact[N], MOD - 2, MOD);
for (int i = N; i > 0; i--) inv_fact[i - 1] = inv_fact[i] * i % MOD;

long long nCr(int n, int r) {
    if (r < 0 || r > n) return 0;
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD;
}
```

بعد التجهيز (O(N))، كل nCr في O(1).

## مسائل مشهورة

- **عدد مضاعفات k من 1 إلى n**: n / k (قسمة صحيحة)، في O(1).
- **عدد الأرقام من 1 إلى n القابلة للقسمة على a أو b**: n/a + n/b − n/lcm(a, b) (مبدأ الشمول والاستبعاد).
- **آخر رقم من aⁿ**: power(a, n, 10).
- **هل n قوة لـ 2؟**: `n > 0 && (n & (n - 1)) == 0` (ستفهمها في درس البتات).

## نصائح

- استخدم `long long` في كل حسابات mod؛ ضرب رقمين قريبين من 10⁹ يتجاوز `int`.
- اكتب `power` و`inv` مرة في قالب (template) شخصي واستخدمها دائمًا.
- المعكوس بنظرية فيرما يعمل فقط إذا كان mod **أوليًا**.
