# الـ arrays والـ strings

## الـ arrays

الـ array مجموعة عناصر من نفس النوع، متجاورة في الذاكرة، نصل لأي عنصر برقمه (index) في O(1). الترقيم يبدأ من **0**.

```cpp
int n;
cin >> n;
vector<int> a(n);              // array بحجم n (vector أفضل من int a[n])
for (int i = 0; i < n; i++) cin >> a[i];

int mx = a[0];
for (int i = 1; i < n; i++) mx = max(mx, a[i]);
cout << mx << "\n";
```

أخطاء شائعة:
- الوصول إلى `a[n]`: آخر عنصر هو `a[n-1]`. الخروج عن الحدود يعطي Runtime Error أو نتائج عشوائية.
- array كبيرة جدًا داخل `main` (مثل مليون عنصر) قد تُسقط البرنامج؛ استخدم `vector` أو عرّفها خارج `main`.

### عكس array، وعدّ العناصر

```cpp
reverse(a.begin(), a.end());

int cnt = 0;
for (int x : a) if (x > 0) cnt++;      // عدد الموجبين
```

### array ثنائية الأبعاد (Grid)

```cpp
int n, m;
cin >> n >> m;
vector<vector<char>> g(n, vector<char>(m));
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        cin >> g[i][j];
```

مسائل الشبكات (grids) كثيرة جدًا: خريطة، لوحة شطرنج، متاهة.

## الـ strings

```cpp
string s;
cin >> s;                  // كلمة واحدة (يتوقف عند المسافة)
getline(cin, s);           // سطر كامل بالمسافات

cout << s.size() << "\n";  // الطول
cout << s[0] << "\n";      // أول حرف
s += "!";                  // إضافة في الآخر
```

### الحروف أرقام في الحقيقة

كل حرف له كود (ASCII): `'a'` = 97، `'A'` = 65، `'0'` = 48. هذا يسهّل حيلًا كثيرة:

```cpp
char c = 'd';
int pos = c - 'a';          // 3: ترتيب الحرف في الأبجدية
char up = c - 'a' + 'A';    // 'D'
int digit = '7' - '0';      // 7
```

### أمثلة سريعة

```cpp
// هل النص palindrome (يُقرأ من الجهتين بنفس الشكل)؟
string t = s;
reverse(t.begin(), t.end());
cout << (s == t ? "YES" : "NO") << "\n";

// عدد كل حرف من a إلى z
int freq[26] = {};
for (char c : s) freq[c - 'a']++;
```

Frequency Array `freq` هذه ستستخدمها كثيرًا جدًا في درس الـ Ad-hoc.

## عند استخدام `getline` بعد `cin`

`cin >> n` يترك سطرًا جديدًا في الـ input، فيقرأه `getline` كسطر فارغ. الحل:

```cpp
cin >> n;
cin.ignore();          // تخطَّ نهاية السطر
getline(cin, s);
```
