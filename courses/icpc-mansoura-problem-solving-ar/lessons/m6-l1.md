# STL 2: set و map و stack و queue و priority_queue

## set: عناصر فريدة ومرتبة

```cpp
set<int> s;
s.insert(5); s.insert(1); s.insert(5);   // {1, 5}: المكرر يُتجاهل
s.count(5);                               // 1 إن وُجد، 0 إن لم يوجد
s.erase(1);
for (int x : s) cout << x << " ";        // تمرّ بالترتيب
*s.begin();                               // أصغر عنصر
*s.rbegin();                              // أكبر عنصر
s.lower_bound(3);                         // أول عنصر >= 3
```

كل العمليات **O(log n)**. `multiset` مثلها لكن تسمح بالتكرار (احذف نسخة واحدة بـ `ms.erase(ms.find(x))`).

## map: مفتاح ← قيمة

```cpp
map<string, int> cnt;
for (auto &w : words) cnt[w]++;           // عدّ الكلمات
for (auto &[word, c] : cnt) cout << word << " " << c << "\n";  // بالترتيب الأبجدي

if (cnt.count("ali")) { /* موجود */ }
```

مفيدة جدًا عندما تكون القيم كبيرة (حتى 10⁹) فلا تصلح array تكرار. O(log n) لكل عملية. توجد أيضًا `unordered_map` (O(1) في المتوسط، بدون ترتيب).

## stack: آخر من يدخل، أول من يخرج

```cpp
stack<int> st;
st.push(1); st.push(2);
st.top();     // 2
st.pop();
st.empty();
```

مثال كلاسيكي: هل الأقواس متوازنة؟

```cpp
bool balanced(const string &s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[') st.push(c);
        else {
            if (st.empty()) return false;
            char o = st.top(); st.pop();
            if ((c == ')' && o != '(') || (c == ']' && o != '[')) return false;
        }
    }
    return st.empty();
}
```

## queue: أول من يدخل، أول من يخرج

```cpp
queue<int> q;
q.push(1); q.push(2);
q.front();    // 1
q.pop();
```

ستستخدمها في BFS (درس الـ graph). و`deque` تسمح بالإضافة والحذف من الجهتين.

## priority_queue: أكبر عنصر دائمًا في الأعلى

```cpp
priority_queue<int> pq;                       // الأكبر أولًا
pq.push(3); pq.push(10); pq.push(5);
pq.top();     // 10
pq.pop();

priority_queue<int, vector<int>, greater<int>> mn;   // الأصغر أولًا
```

الإضافة والحذف O(log n). مثال: كل مرة خذ أصغر رقمين، اجمعهما، وأرجع الناتج (تكلفة دمج الحبال):

```cpp
long long cost = 0;
while (mn.size() > 1) {
    long long a = mn.top(); mn.pop();
    long long b = mn.top(); mn.pop();
    cost += a + b;
    mn.push(a + b);
}
```

## أي هيكل أختار؟

| أحتاج | استخدم |
|---|---|
| عناصر فريدة، بحث سريع، ترتيب | `set` |
| عدّ أو ربط قيمة بمفتاح | `map` |
| آخر عنصر دخل (Backtracking، أقواس) | `stack` |
| أول عنصر دخل (queue، BFS) | `queue` |
| أكبر أو أصغر عنصر دائمًا | `priority_queue` |
