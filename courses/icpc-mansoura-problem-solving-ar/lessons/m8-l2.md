# Greedy Algorithms (Greedy)

الخوارزمية **الجشعة** تأخذ في كل خطوة **أفضل اختيار الآن**، ولا ترجع فيه أبدًا. عندما تنجح تكون بسيطة وسريعة جدًا، لكنها كثيرًا ما **تفشل**، لذلك يجب أن تقنع نفسك لماذا هي صحيحة قبل الإرسال.

## مثال ناجح: أكبر عدد من الأنشطة

لديك n نشاط، لكل نشاط بداية ونهاية. اختر أكبر عدد من الأنشطة التي لا تتداخل.

القاعدة الجشعة الصحيحة: **رتّب حسب وقت النهاية، وخذ كل نشاط يبدأ بعد نهاية آخر نشاط أخذته.**

```cpp
vector<pair<int,int>> act(n);            // {end, start}
for (auto &[e, s] : act) cin >> s >> e;
sort(act.begin(), act.end());            // حسب النهاية
int cnt = 0, lastEnd = INT_MIN;
for (auto &[e, s] : act)
    if (s >= lastEnd) { cnt++; lastEnd = e; }
cout << cnt << "\n";
```

**لماذا صحيح؟** (حجة التبديل) خذ أي حل أمثل. نشاطه الأول ينتهي في وقت ما؛ النشاط الذي ينتهي **أبكر** من الكل لا ينتهي بعده. استبدله به: الحل يبقى صالحًا وبنفس العدد، ويترك وقتًا أكثر للباقي. كرر الحجة لكل خطوة.

الترتيب حسب **البداية** أو حسب **أقصر مدة** يعطي إجابات خاطئة؛ جرّب أمثلة صغيرة لتقتنع.

## مثال فاشل: الفكة بالعملات

العملات {1, 3, 4} والمبلغ 6. الجشع (أكبر عملة أولًا): 4 + 1 + 1 = 3 عملات. لكن 3 + 3 = عملتان فقط. هنا نحتاج **Dynamic Programming**.

**قاعدة عملية**: إذا وجدت مثالًا مضادًا صغيرًا للقاعدة الجشعة خلال دقيقة، فهي خاطئة. إذا لم تجد، حاول أن تشرح لماذا الاختيار الجشع "آمن" دائمًا.

## أنماط جشعة شائعة

| المسألة | القاعدة |
|---|---|
| أكبر عدد أنشطة غير متداخلة | الأبكر انتهاءً أولًا |
| أقل عدد أشخاص في قوارب سعتها اثنان | رتّب، وأقرن الأثقل مع الأخف إن أمكن (Two Pointers) |
| أكبر مجموع بعد k عملية "اقلب الإشارة" | اقلب أصغر الأرقام السالبة أولًا |
| أقل تكلفة لدمج أكوام | دائمًا ادمج أصغر اثنين (priority_queue) |
| إنهاء مهام قبل مواعيدها | رتّب حسب الموعد النهائي |

### مثال: القوارب

كل قارب يحمل شخصين على الأكثر، ووزن أقصى x. أقل عدد قوارب؟

```cpp
sort(w.begin(), w.end());
int l = 0, r = n - 1, boats = 0;
while (l <= r) {
    if (w[l] + w[r] <= x) l++;     // الأخف يركب مع الأثقل
    r--;                           // الأثقل يركب في كل الأحوال
    boats++;
}
```

الأثقل يحتاج قاربًا على أي حال؛ أفضل ما نفعله أن نضع معه أخف شخص إذا أمكن.

## الجشع مع الترتيب المخصص

أحيانًا السر في **ترتيب** العناصر. مثال: رتّب أرقامًا كنصوص لتكوين أكبر رقم ممكن عند لصقها:

```cpp
sort(s.begin(), s.end(), [](const string &a, const string &b) {
    return a + b > b + a;          // "9" قبل "34" لأن "934" > "349"
});
```

## كيف تتعامل مع مسألة تشك أنها جشعة؟

1. اكتب القاعدة الجشعة بوضوح.
2. جرّبها على 3 أو 4 أمثلة صغيرة **تحاول بها كسرها**.
3. إذا صمدت، فكّر في حجة التبديل.
4. إذا كانت n صغيرة، قارن ناتجها بحل بحث كامل (brute force) على أمثلة عشوائية: أسرع طريقة لاكتشاف الخطأ.
