# ما هو Problem Solving؟ وأول برنامج بـ C++

**Problem Solving** هو أن تقرأ مسألة، وتفهم المطلوب بدقة، وتصل لطريقة صحيحة وسريعة لحلها، ثم تكتبها كودًا يمرّ على كل الاختبارات. هذه المهارة هي أساس مسابقة **ICPC**، وأساس مقابلات العمل في الشركات الكبيرة، وأساس أن تكون مبرمجًا قويًا عمومًا.

## كيف تعمل المسائل؟

كل مسألة على مواقع مثل **Codeforces** فيها:
- **نص المسألة**: القصة والمطلوب.
- **الـ input** والـ output: الشكل الدقيق.
- **الـ constraints**: مثل `1 ≤ n ≤ 10^5`. هذه أهم سطر في المسألة، لأنها تخبرك بالسرعة المطلوبة.
- **حد الوقت والذاكرة**: عادة 1 ثانية و256 ميجابايت.
- **أمثلة**: جرّب كودك عليها أولًا.

يُرسَل حلك إلى **الـ judge** الذي يشغّله على اختبارات مخفية ويرد:

| النتيجة | المعنى |
|---|---|
| Accepted | صحيح ✓ |
| Wrong Answer | ناتج خاطئ في اختبار ما |
| Time Limit Exceeded | بطيء جدًا: تحتاج طريقة أسرع |
| Runtime Error | خروج عن حدود array، قسمة على صفر... |
| Compilation Error | خطأ في كتابة الكود |

## لماذا C++؟

أغلب المتسابقين يستخدمون **C++** لأنها سريعة جدًا ومعها مكتبة **STL** الجاهزة. تدريب ICPC Mansoura كله بـ C++، وكذلك هذا الكورس.

ثبّت محرّرًا: **Code::Blocks** أو **VS Code** مع مترجم g++، أو جرّب أونلاين على **ideone.com** أو داخل Codeforces نفسه.

## أول برنامج

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int a, b;
    cin >> a >> b;          // قراءة رقمين
    cout << a + b << "\n";  // طباعة المجموع
    return 0;
}
```

- `bits/stdc++.h` تضيف كل المكتبات مرة واحدة (مريحة في المسابقات).
- السطران بعد `main` يجعلان القراءة والطباعة أسرع بكثير. اكتبهما دائمًا.
- استخدم `"\n"` بدل `endl`، فهي أسرع.

## أنواع البيانات وحدودها

| النوع | يتسع تقريبًا لـ |
|---|---|
| `int` | ± 2 × 10⁹ |
| `long long` | ± 9 × 10¹⁸ |
| `double` | أرقام عشرية |
| `char` | حرف واحد |
| `string` | نص |
| `bool` | true / false |

**أشهر خطأ للمبتدئين**: ضرب رقمين كل منهما 10⁵ يعطي 10¹⁰، أكبر من `int` فيتجاوز (overflow) ويعطي ناتجًا غريبًا. إذا كان الناتج قد يتعدى 2 × 10⁹ فاستخدم `long long`.

## الشروط والتكرار

```cpp
int n;
cin >> n;
if (n % 2 == 0) cout << "Even\n";
else cout << "Odd\n";

long long sum = 0;
for (int i = 1; i <= n; i++) sum += i;   // مجموع 1..n
cout << sum << "\n";
```

## طريقة العمل على أي مسألة

1. اقرأ المسألة **مرتين**، وافهم الأمثلة يدويًا.
2. انظر للـ constraints: ما حجم n؟
3. فكّر في الحل على الورق قبل الكود.
4. اكتب الكود، وجرّبه على الأمثلة وعلى edge cases (أصغر وأكبر قيمة).
5. أرسل. إذا أخذت Wrong Answer، ابحث عن الحالة التي لم تفكر فيها.

الاستمرارية أهم من الذكاء: مسائل قليلة كل يوم أفضل من عشرين مسألة مرة في الشهر.
