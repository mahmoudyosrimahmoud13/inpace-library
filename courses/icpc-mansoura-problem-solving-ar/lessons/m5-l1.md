# STL 1: vector و pair و sort والنصوص

**STL** (Standard Template Library) مكتبة جاهزة في C++ فيها هياكل بيانات وخوارزميات مكتوبة بإتقان. المتسابق الجيد يعرفها جيدًا لأنها توفر وقتًا وأخطاءً.

## vector: مصفوفة مرنة

```cpp
vector<int> v;            // فارغ
v.push_back(5);           // أضف في الآخر: O(1)
v.push_back(2);
v.pop_back();             // احذف آخر عنصر
cout << v.size() << " " << v.back() << "\n";

vector<int> w(n, 0);      // n أصفار
v.clear();                // أفرغه
```

## pair: قيمتان معًا

```cpp
pair<int, string> p = {90, "Ali"};
cout << p.first << " " << p.second << "\n";

vector<pair<int,int>> pts(n);
for (auto &[x, y] : pts) cin >> x >> y;
```

ترتيب `pair` يكون حسب `first` ثم `second` تلقائيًا.

## sort: الترتيب في O(n log n)

```cpp
sort(v.begin(), v.end());                    // تصاعدي
sort(v.begin(), v.end(), greater<int>());    // تنازلي
sort(v.rbegin(), v.rend());                  // تنازلي أيضًا

// ترتيب مخصص
sort(pts.begin(), pts.end(), [](auto &a, auto &b) {
    if (a.second != b.second) return a.second < b.second;
    return a.first > b.first;
});
```

دالة المقارنة يجب أن تُرجع `true` فقط إذا كان `a` **يأتي قبل** `b`، ولا تُرجع `true` للعنصرين المتساويين (استخدم `<` وليس `<=`)، وإلا قد يسقط البرنامج.

## خوارزميات جاهزة مفيدة

```cpp
int mx = *max_element(v.begin(), v.end());
int mn = *min_element(v.begin(), v.end());
long long s = accumulate(v.begin(), v.end(), 0LL);   // 0LL لتجنب overflow
int c = count(v.begin(), v.end(), 3);                // كم مرة ظهر 3
reverse(v.begin(), v.end());

// إزالة المكرر (بعد الترتيب)
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());

// كل التباديل (permutations)
sort(v.begin(), v.end());
do { /* استخدم v */ } while (next_permutation(v.begin(), v.end()));
```

## البحث في مصفوفة مرتبة

```cpp
// أول موضع قيمته >= x
auto it = lower_bound(v.begin(), v.end(), x);
int idx = it - v.begin();
// أول موضع قيمته > x
auto it2 = upper_bound(v.begin(), v.end(), x);
// عدد مرات ظهور x
int cntx = upper_bound(v.begin(), v.end(), x) - lower_bound(v.begin(), v.end(), x);
```

كلها O(log n)، وستفهم كيف تعمل من الداخل في درس البحث الثنائي.
