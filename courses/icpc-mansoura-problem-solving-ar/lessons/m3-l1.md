# الـ functions، الـ struct، و Time Complexity

## الـ functions

الدالة تجمع كودًا تكرره في مكان واحد باسم واضح:

```cpp
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; 1LL * i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}

int main() {
    int n; cin >> n;
    cout << (isPrime(n) ? "YES" : "NO") << "\n";
}
```

### التمرير بالقيمة أم بالمرجع؟

```cpp
void addOne(int x)  { x++; }   // نسخة: الأصل لا يتغير
void addOne2(int &x) { x++; }  // مرجع (&): يغيّر الأصل

long long total(const vector<int> &a) { // مرجع ثابت: بدون نسخ، وبدون تعديل
    long long s = 0;
    for (int x : a) s += x;
    return s;
}
```

تمرير `vector` كبير **بدون** `&` ينسخه في كل استدعاء، وقد يسبب Time Limit Exceeded.

## الـ struct: تجميع بيانات مرتبطة

```cpp
struct Student {
    string name;
    int score;
};

vector<Student> st(n);
for (auto &s : st) cin >> s.name >> s.score;

sort(st.begin(), st.end(), [](const Student &a, const Student &b) {
    if (a.score != b.score) return a.score > b.score;  // الأعلى درجة أولًا
    return a.name < b.name;                            // ثم أبجديًا
});
```

## Time Complexity

قبل أن تكتب الكود، اسأل: **كم عملية سيقوم بها حلي في أسوأ حالة؟**

القاعدة الذهبية: الحاسوب يقوم بحوالي **10⁸ عملية بسيطة في الثانية**.

| التعقيد | مثال | مناسب لـ n حتى |
|---|---|---|
| O(1) | معادلة مباشرة | أي حجم |
| O(log n) | Binary Search | 10¹⁸ |
| O(n) | لفة واحدة | 10⁸ |
| O(n log n) | الترتيب sort | 10⁶ |
| O(n²) | لفتان متداخلتان | 10⁴ |
| O(n³) | ثلاث لفات | 500 |
| O(2ⁿ) | كل الـ subsets | 20 |

**إذن الـ constraints تخبرك بالحل**: إذا كانت `n ≤ 2 × 10⁵` فحل O(n²) سيأخذ 4 × 10¹⁰ عملية: بطيء جدًا. تحتاج O(n log n) أو O(n).

### كيف تحسب التعقيد؟

```cpp
for (int i = 0; i < n; i++)          // n مرة
    for (int j = 0; j < n; j++)      // × n مرة
        cnt++;                       // = O(n²)

for (int i = 1; i < n; i *= 2)       // i تتضاعف: O(log n)
    cnt++;
```

- لفّات متتالية: **تُجمع** → O(n + m).
- لفّات متداخلة: **تُضرب** → O(n × m).
- نتجاهل الثوابت: O(2n) = O(n).

### مثال: هل الرقم أولي؟

الطريقة البطيئة: جرّب القسمة على كل الأرقام من 2 إلى n−1: O(n). الأسرع: يكفي حتى √n، لأن أي قاسم أكبر من √n له قاسم مقابل أصغر منه: O(√n). لـ n = 10⁹: 31,623 عملية بدل مليار.
