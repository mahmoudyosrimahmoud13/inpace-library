# Variables, outputs, expressions and loops

## Variables

```hcl
variable "env" {
  type        = string
  description = "dev, staging or prod"
  validation {
    condition     = contains(["dev", "staging", "prod"], var.env)
    error_message = "env must be dev, staging or prod."
  }
}
variable "instance_count" {
  type    = number
  default = 2
}
variable "allowed_cidrs" {
  type    = list(string)
  default = []
}
variable "db_password" {
  type      = string
  sensitive = true
}
```

Set them in `terraform.tfvars`, `prod.tfvars` (`-var-file=prod.tfvars`), or `TF_VAR_env=prod`. Never commit secret values: pass them from your CI's secrets or read them from Secrets Manager with a data source.

## Locals and expressions

```hcl
locals {
  name   = "shop-${var.env}"
  is_prod = var.env == "prod"
  common_tags = { env = var.env, owner = "platform" }
}
resource "aws_db_instance" "main" {
  multi_az            = local.is_prod
  deletion_protection = local.is_prod
  instance_class      = local.is_prod ? "db.m7g.large" : "db.t4g.micro"
}
```

## Many copies: count and for_each

```hcl
variable "subnets" {
  default = {
    "public-a"  = { cidr = "10.0.0.0/24",  az = "eu-central-1a" }
    "public-b"  = { cidr = "10.0.1.0/24",  az = "eu-central-1b" }
  }
}
resource "aws_subnet" "this" {
  for_each          = var.subnets
  vpc_id            = aws_vpc.main.id
  cidr_block        = each.value.cidr
  availability_zone = each.value.az
  tags              = { Name = "${local.name}-${each.key}" }
}
output "subnet_ids" { value = { for k, s in aws_subnet.this : k => s.id } }
```

Prefer **for_each with a map** over `count`: with `count`, removing the first item renumbers the rest and Terraform wants to replace them all. With `for_each`, each item has a stable key.

`terraform console` lets you try expressions and functions (`cidrsubnet("10.0.0.0/16", 8, 1)` gives `10.0.1.0/24`).
