# Ansible: variables, templates and roles

## Variables, from many places

```text
group_vars/all.yml        # every host
group_vars/web.yml        # hosts in [web]
host_vars/web01.yml       # one host
```

```yaml
# group_vars/web.yml
app_port: 8000
server_name: shop.example.com
packages: [nginx, git, python3-pip]
```

**Facts** are variables Ansible discovers about each host: `ansible_facts['os_family']`, `ansible_facts['default_ipv4']['address']`, memory, CPUs.

## Templates (Jinja2)

```jinja
# templates/site.conf.j2  (managed by Ansible, don't edit on the server)
server {
    listen 80;
    server_name {{ server_name }};
    location / {
        proxy_pass http://127.0.0.1:{{ app_port }};
    }
{% if enable_health | default(true) %}
    location = /health { return 200 "ok\n"; }
{% endif %}
}
```

## Roles: the unit of reuse

```text
roles/nginx/
  tasks/main.yml
  handlers/main.yml
  templates/site.conf.j2
  defaults/main.yml       # lowest-priority defaults, meant to be overridden
  meta/main.yml           # dependencies
```

```yaml
# site.yml
- hosts: web
  become: true
  roles:
    - common        # users, ssh hardening, packages, time sync
    - nginx
    - app
```

```bash
ansible-galaxy init roles/app                       # scaffold a role
ansible-galaxy collection install community.general # extra modules
```

## Loops and conditions

```yaml
- name: Create admin users
  ansible.builtin.user:
    name: "{{ item.name }}"
    groups: wheel
    append: true
  loop: "{{ admins }}"
  when: ansible_facts['os_family'] == "RedHat"
```

Keep roles small and focused, put defaults in `defaults/`, and test each role on a fresh machine.
