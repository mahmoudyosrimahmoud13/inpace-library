# Troubleshooting IaC

## Terraform

| Problem | What it means | Fix |
|---|---|---|
| `Error acquiring the state lock` | Another run is going, or one crashed | Wait; if truly stale, `terraform force-unlock <id>` |
| Plan wants to **replace** a resource | You changed an attribute that can't be updated in place (marked `forces replacement`) | Revert, or plan a safe migration; `create_before_destroy` for zero downtime |
| Plan shows changes nobody made | Drift (console edits), or provider defaults | Bring code in line, or `ignore_changes` for attributes others manage (e.g. ASG desired count) |
| `Provider produced inconsistent result` | Provider bug or eventual consistency in AWS | Re-run; upgrade the provider |
| `AccessDenied` | The role running Terraform lacks a permission | CloudTrail shows the exact action |
| Cycle error | Two resources reference each other | Split with a separate rule resource (e.g. `aws_vpc_security_group_ingress_rule`) |

```bash
TF_LOG=DEBUG terraform plan 2> debug.log     # see every API call
terraform plan -target=module.web            # focus (for debugging only, not daily use)
terraform providers                          # which providers and versions
```

## Ansible

| Problem | Fix |
|---|---|
| `UNREACHABLE` | SSH problem: test `ssh web01` directly; check inventory host, user, ProxyJump |
| `Missing sudo password` | Use `-K`, or passwordless sudo for the automation user |
| Task always shows `changed` | It's not idempotent: replace `shell`/`command` with a module, or add `creates:` / `changed_when:` |
| Wrong variable value | `ansible -m debug -a "var=app_port" web01`; remember variable precedence (extra vars win) |
| Slow runs | Turn on pipelining and ControlPersist; `gather_facts: false` where not needed; more `forks` |

```bash
ansible-playbook site.yml -vvv --limit web01 --start-at-task "Configure the site"
```
