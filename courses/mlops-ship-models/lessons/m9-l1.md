# Deep learning models in the same pipeline

Everything in this course applies to deep learning: versioned data, tracked runs, a pipeline, a registry, a gate,
a service, CI and monitoring. A few things need extra care.

## A checkpoint is more than weights

A PyTorch `state_dict` holds the weights. To use the model later you also need: the network's shape (layers, sizes),
the **preprocessing** (here, each feature's mean and standard deviation), the feature order, the settings and the
data version. Put them all in one checkpoint, or better, make preprocessing **part of the model** (as buffers in the
module), so nobody can load the weights and forget to normalize. Forgotten normalization is one of the most common
deep learning serving bugs, and it never raises an error.

Load checkpoints with `torch.load(..., weights_only=True)`. Like pickles, full checkpoints can run code when loaded;
`weights_only` refuses anything but tensors and simple types.

## Training habits

- **Early stopping**: keep the weights from the best validation epoch, and stop after several epochs without
  improvement.
- **Seeds and determinism**: fix `torch.manual_seed`. GPUs add some nondeterminism of their own; record it, and
  compare runs on averages of a few seeds when it matters.
- **Track everything**: MLflow's `mlflow.pytorch` flavor logs PyTorch models like the scikit-learn ones.

## Exporting for serving

PyTorch is large and built for training. For serving, export to **ONNX**, a standard model format, and run it with
**ONNX Runtime**: a much smaller install, often faster on CPU, and usable from other languages. Always check the
export: run the same inputs through both and compare. Some operations don't export; you find out at export time,
or worse, from different numbers.

## When deep learning is worth it

On small tabular data like Bikecast, gradient boosted trees usually win. Deep learning earns its place with images,
sound, text, very large data, or when you need to train end to end with other networks. The MLOps around it is the
same either way.
