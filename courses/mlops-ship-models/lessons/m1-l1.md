# Start here: what you'll build

Most machine learning courses end when the model scores well in a notebook. This one starts there. You take one
model, **Bikecast**, all the way to production and keep it working there.

Bikecast predicts how many bikes will be rented in the next hour in Washington D.C., from the time, the weather and
recent demand. The data is real: 17,379 hours of the city's bike sharing system in 2011 and 2012 (UCI Bike Sharing
Dataset, by Hadi Fanaee-T, CC BY 4.0). It's a good MLOps teacher because the world changes under it: rentals grew
about 65% from 2011 to 2012, so a model trained once slowly goes wrong, and you have to notice and fix it.

| Day | You add | Tools |
|---|---|---|
| 1 | A training script you can rerun and trust: time split, baseline, leak check | scikit-learn |
| 2 | Data checks and data versions | pandas, hashing (the idea behind DVC) |
| 3 | Experiment tracking | MLflow |
| 4 | A pipeline that reruns only what changed | your own runner (the idea behind DVC, Airflow) |
| 5 | A model registry with a quality gate and rollback | MLflow Model Registry |
| 6 | A prediction service, tests, a Docker image | FastAPI, pytest, Docker |
| 7 | CI that blocks bad models | GitHub Actions |
| 8 | Monitoring, drift and retraining | your own monitor |
| 9 | The same steps for a deep learning model, and the capstone | PyTorch, ONNX Runtime |

## Where this fits

This course assumes you can train a model: the **Machine Learning refresh** and **Deep learning** courses, or
**PyTorch**, cover that. It goes deeper on the ML-specific parts of shipping. For the general tools, the
**Docker and containers**, **DevOps and CI/CD** and **Observability** courses go further.

## What you need

- Python 3.10 or newer, Git, about 2 hours a day.
- `pip install -r requirements.txt` (pandas, scikit-learn, MLflow, FastAPI, pytest). In a virtual environment:
  `python -m venv .venv` and activate it first.
- Day 6: Docker Desktop (or Docker on Linux) to build the image. Everything else works without it.
- Day 7: a GitHub account, to see the CI run there.
- Day 9: `pip install torch onnx onnxruntime onnxscript` (CPU is fine).

## Get the code

The project folder is above this text. Save all its files in one folder, `bikecast`, keeping `data/`, `tests/` and
`.github/` as they are, and run each project from there: `python p01_train.py`. Start a git repository in that
folder today and commit after every project: CI on day 7 needs it, and it's how MLflow records which code trained
each model.

Every output in the lessons is real. Times will differ on your computer; scores won't.
