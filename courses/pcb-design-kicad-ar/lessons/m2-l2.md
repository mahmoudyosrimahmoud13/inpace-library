# الـ Footprints والأجزاء والـ BOM

الـ schematic يقول ما المتصل. والآن قرر ما هو كل جزء **فعليًا**.

## ‏Through-hole أم surface mount؟

| | Through-hole ‏(THT) | Surface mount ‏(SMD) |
|---|---|---|
| اللحام باليد | سهل | مقبول من مقاس 0805 فأكبر؛ أصعب للأجزاء الصغيرة جدًا |
| المساحة على الـ board | كبيرة | صغيرة |
| السعر بالكميات | أعلى | أقل |
| التجميع في المصنع | أقل شيوعًا | قياسي؛ المصنع يستطيع لحام كل شيء لك |

في أول board، الخلط لا مشكلة فيه: مقاس SMD للـ resistors ما زلت تستطيع التعامل معه (**0805** = ‏2.0 × 1.25 mm، أو **1206**)، وthrough-hole للـ connectors والـ electrolytic capacitor.

أسماء مقاسات الـ SMD الشائعة:

```text
code   size (mm)     hand-soldering
1206   3.2 x 1.6     easy
0805   2.0 x 1.25    comfortable with tweezers
0603   1.6 x 0.8     needs practice
0402   1.0 x 0.5     hard; leave to the factory
```

والـ chips أيضًا تأتي في packages: ‏**DIP-8** ‏(through-hole، مناسب للـ breadboard)، و**SOIC-8** ‏(small outline، مسافة pins ‏1.27 mm، ‏SMD سهل)، وأصغر بكثير مثل QFN.

## تعيين الـ footprints

افتح **Tools → Assign Footprints**. لكل جزء، اختر footprint من القائمة على اليمين (استخدم أزرار الفلترة والبحث):

| الجزء | الـ Footprint ‏(اسم مكتبة KiCad) |
|---|---|
| R1 وR2 وR3 | `Resistor_SMD:R_0805_2012Metric` |
| C2 وC3 | `Capacitor_SMD:C_0805_2012Metric` |
| C1 ‏(electrolytic ‏10 µF) | `Capacitor_THT:CP_Radial_D5.0mm_P2.00mm` |
| LED | `LED_SMD:LED_0805_2012Metric` أو `LED_THT:LED_D5.0mm` |
| 555 | `Package_DIP:DIP-8_W7.62mm` ‏(أو `Package_SO:SOIC-8_3.9x4.9mm_P1.27mm`) |
| connector الكهرباء | `Connector_PinHeader_2.54mm:PinHeader_1x02_P2.54mm_Vertical` |

عارض الـ footprint ‏(الأيقونة في الأعلى) يعرض الـ pads ومعاينة 3D، فتستطيع التأكد أنه يطابق الجزء الحقيقي.

## مطابقة الـ footprint مع الـ datasheet

قبل أن تثق بأي footprint، قارنه بالـ **package drawing** في الـ datasheet الخاص بالجزء:

1. **مكان الـ pin رقم 1 والترقيم** (أشهر خطأ، وهو يُفسد الـ board).
2. **المسافة بين الـ pads ‏(pitch)**: ‏2.54 mm للـ DIP، و1.27 mm للـ SOIC.
3. **قطر الثقب** لأجزاء الـ THT: قطر الرِجل زائد حوالي 0.2 إلى 0.4 mm.
4. للـ transistors والـ regulators: **ترتيب الـ pins** ‏(E-B-C، أو IN-GND-OUT) يختلف بين الموديلات؛ طابق أرقام pins الـ symbol مع الـ footprint.

## الـ BOM ‏(bill of materials)

الـ **BOM** يذكر كل جزء ستشتريه: الـ reference والقيمة والـ footprint والكمية ورقم الجزء من الشركة المصنعة أو المورد. في الـ Schematic Editor: ‏**Tools → Generate Bill of Materials**.

‏BOM بسيط، وتكلفته:

```python
bom = [
    ("R1", "1k 0805", 1, 0.01), ("R2", "68k 0805", 1, 0.01), ("R3", "470 0805", 1, 0.01),
    ("C1", "10uF 16V radial", 1, 0.05), ("C2", "10nF 0805", 1, 0.01), ("C3", "100nF 0805", 1, 0.01),
    ("D1", "red LED 0805", 1, 0.03), ("U1", "NE555 DIP-8", 1, 0.25), ("J1", "2-pin header", 1, 0.05),
]
per_board = sum(qty * price for _, _, qty, price in bom)
print(f"{len(bom)} lines, parts per board about ${per_board:.2f}")
print(f"for 10 boards: ${per_board * 10:.2f} (buy a few spares of the small parts)")
```

```output
9 lines, parts per board about $0.43
for 10 boards: $4.30 (buy a few spares of the small parts)
```

أضف field مثل **LCSC** أو **MPN** ‏(manufacturer part number) لكل symbol ‏(اضغط E، وأضف field). والمصانع التي تجمّع الـ boards تستخدمه لاختيار الجزء بالضبط.

## الخلاصة

- اختر THT أو SMD لكل جزء؛ و0805 مقاس جيد للحام باليد؛ واعرف الفرق بين DIP وSOIC.
- عيّن الـ footprints وتحقق من الـ pin رقم 1 والـ pitch وقطر الثقب وترتيب الـ pins مقابل الـ datasheet.
- اصنع BOM بأرقام الأجزاء؛ فهو قائمة مشترياتك وقائمة تجميع المصنع معًا.
