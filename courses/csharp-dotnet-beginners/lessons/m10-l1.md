# async and await

Reading a web page or a database takes time. `async`/`await` lets your program wait without blocking: a web server can serve other requests meanwhile.

```csharp
using System.Net.Http.Json;

using var http = new HttpClient();
http.DefaultRequestHeaders.UserAgent.ParseAdd("inpace-course");   // GitHub requires one
var repo = await http.GetFromJsonAsync<Repo>("https://api.github.com/repos/dotnet/runtime");
Console.WriteLine($"{repo?.Name}: {repo?.stargazers_count} stars");

record Repo(string Name, int stargazers_count);
```

## The rules

- A method that awaits is marked `async` and returns `Task` (or `Task<T>` for a value).
- `await` every task; don't use `.Result` or `.Wait()`, which block and can freeze apps.
- Async spreads upward: if you call an async method, your method usually becomes async too. That's normal.
- Some APIs (GitHub's included) require a `User-Agent` header: `http.DefaultRequestHeaders.UserAgent.ParseAdd("my-app");`

Read more: [Asynchronous programming](https://learn.microsoft.com/dotnet/csharp/asynchronous-programming/).
