# if, switch and loops

Conditions go in brackets, blocks in braces:

> **Optional video above.** Part of freeCodeCamp's *Learn C#: Full Course with Mini-Projects* (0:46:59 to 1:36:16, about 49 min), coding the same ideas in Visual Studio. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```csharp
int score = 85;
if (score >= 90)
    Console.WriteLine("A");
else if (score >= 80)
    Console.WriteLine("B");
else
    Console.WriteLine("Keep going");

// A switch expression (C# 8 and newer): one value in, one value out
string day = DateTime.Now.DayOfWeek switch
{
    DayOfWeek.Friday or DayOfWeek.Saturday => "Weekend",
    _ => "Workday",
};
```

```csharp
for (int i = 1; i <= 5; i++)      // start; keep going while; step
    Console.WriteLine(i);

int tries = 0;
while (tries < 3) { tries++; }

do { Console.Write("Again? (y/n) "); }     // runs at least once
while (Console.ReadLine() == "y");

foreach (char c in "hello") Console.Write(c);
```

`break` leaves a loop and `continue` skips to the next round. The **conditional operator** picks between two values: `string label = age >= 18 ? "adult" : "minor";`

Read more: [Branches and loops](https://learn.microsoft.com/dotnet/csharp/tour-of-csharp/tutorials/branches-and-loops).
