## Methods you'll use every day

| Code | Result |
|---|---|
| `"  hi ".Trim()` | `"hi"` |
| `"Cairo".ToUpper()` | `"CAIRO"` |
| `"a,b,c".Split(',')` | an array of 3 strings |
| `"hello".Contains("ell")` | `true` |
| `"hello".Replace("l", "L")` | `"heLLo"` |
| `"hello".Substring(1, 3)` | `"ell"` |
| `"hello".Length` | `5` |
| `string.Join(", ", names)` | joins with commas |

## Comparing and checking

To compare ignoring capitals, say so: `string.Equals(a, b, StringComparison.OrdinalIgnoreCase)`. To check input, prefer `string.IsNullOrWhiteSpace(s)`: it's `true` for `null`, `""` and `"   "`.

## Strings never change

A string is **immutable**: `ToUpper()` returns a new string and leaves the old one alone, so write `name = name.ToUpper();`. When you build a long text in a loop, use `StringBuilder`, which doesn't make a new string every time.
