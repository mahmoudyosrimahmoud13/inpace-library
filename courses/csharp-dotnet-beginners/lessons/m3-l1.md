# Reading input safely

`Console.ReadLine()` gives back what the user typed as a `string` (it can be `null` if the input ends). Never trust it to be a number: use `TryParse`, which returns `true` or `false` and puts the number in an `out` variable:

> **Optional video above.** Part of freeCodeCamp's *Learn C#: Full Course with Mini-Projects* (1:36:16 to 2:08:24, about 32 min), coding the same ideas in Visual Studio. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```csharp
int age;
Console.Write("Age: ");
while (!int.TryParse(Console.ReadLine(), out age) || age < 0)
{
    Console.Write("Please type a whole number: ");
}
Console.WriteLine($"Next year you'll be {age + 1}.");
```

## Formatting numbers

| Format | `1234.5` shows as |
|---|---|
| `{x:N2}` | `1,234.50` |
| `{x:F1}` | `1234.5` |
| `{x:C}` | money in the computer's currency |
| `{x:P0}` (for `0.25`) | `25%` |
