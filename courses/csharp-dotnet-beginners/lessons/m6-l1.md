# Methods and parameters

A **method** is a named block of code. Its signature says what it returns and what it takes. In a top-level program you can write methods under your code:

> **Optional video above.** Part of freeCodeCamp's *Learn C#: Full Course with Mini-Projects* (4:30:00 to 6:01:09, about 91 min), coding the same ideas in Visual Studio. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```csharp
Console.WriteLine(Area(3, 4));          // 6
Greet("Mona");
Greet("Omar", greeting: "Welcome");

double Area(double width, double height) => width * height / 2;   // returns a value

void Greet(string name, string greeting = "Hello")                 // returns nothing
{
    Console.WriteLine($"{greeting}, {name}!");
}
```

## Getting more than one value back

- `out`: the method **must** set it; the caller gets it back (that's how `TryParse` works).
- `ref`: the method can read and change the caller's variable.
- A **tuple** is usually clearer than either:

```csharp
(int min, int max) Range(int[] numbers) => (numbers.Min(), numbers.Max());

var (low, high) = Range([4, 9, 1]);
Console.WriteLine($"{low} to {high}");    // 1 to 9

void DoubleIt(ref int x) => x *= 2;
int n = 5;
DoubleIt(ref n);                             // n is now 10
```

## Overloading

Two methods can share a name if their parameters differ: `Print(int x)` and `Print(string s)`. C# picks the right one from the arguments, which is why `Console.WriteLine` accepts almost anything.
