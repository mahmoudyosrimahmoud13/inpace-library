# Types, variables and conversions

In C# every variable has a **type**, fixed when you declare it. The compiler refuses to put text into a number variable, which catches mistakes early.

> **Optional video above.** Part of freeCodeCamp's *Learn C#: Full Course with Mini-Projects* (0:10:56 to 0:25:36, about 15 min), coding the same ideas in Visual Studio. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```csharp
int age = 25;
double height = 1.75;
decimal price = 199.99m;     // m: a decimal literal
bool isStudent = true;
char grade = 'A';            // one character, single quotes
string name = "Mona";        // text, double quotes

var city = "Cairo";          // var: the compiler sees it's a string
const int MaxTries = 3;      // can never change
```

## Which number type?

| Type | Use it for |
|---|---|
| `int` | counts and whole numbers (up to about 2 billion) |
| `long` | bigger whole numbers |
| `double` | measurements and science, where tiny rounding is fine |
| `decimal` | **money**: exact in base 10 |

## Converting

Text from the user is a `string`. Convert it with `int.Parse` (fails with an exception on bad text) or, better, `int.TryParse` (module 3). Between number types, a smaller type converts to a bigger one by itself; the other way needs a **cast** and may lose data:

```csharp
int n = int.Parse("42");
double d = n;                // int to double: automatic
int back = (int)3.99;        // cast: 3, the fraction is dropped
string s = n.ToString();
```
