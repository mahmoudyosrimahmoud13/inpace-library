# Classes, properties and constructors

A **class** is your own type. Its **properties** hold data, its **constructor** sets an object up, and its **methods** do things:

> **Optional video above.** Part of freeCodeCamp's *Learn C#: Full Course with Mini-Projects* (7:15:56 to 8:17:11, about 61 min), coding the same ideas in Visual Studio. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```csharp
var account = new BankAccount("Mona", 500);
account.Deposit(250);
Console.WriteLine(account);        // Mona: 750.00 EGP

public class BankAccount
{
    public string Owner { get; }               // read-only after construction
    public decimal Balance { get; private set; } // only the class can change it

    public BankAccount(string owner, decimal opening = 0)
    {
        ArgumentException.ThrowIfNullOrWhiteSpace(owner);
        Owner = owner;
        Balance = opening;
    }

    public void Deposit(decimal amount)
    {
        ArgumentOutOfRangeException.ThrowIfNegativeOrZero(amount);
        Balance += amount;
    }

    public override string ToString() => $"{Owner}: {Balance:N2} EGP";
}
```

## The pieces

- `public` can be used from anywhere; `private` only inside the class. Keep data private and let methods guard it.
- `{ get; private set; }` is an **auto-property**: C# writes the hidden field for you.
- `static` members belong to the class itself, not to one object (like `Math.Round`).
- Putting a class in its own file (`BankAccount.cs`) keeps projects tidy.
