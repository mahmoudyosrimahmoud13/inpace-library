# How a C# program is built

New projects use **top-level statements**: `Program.cs` holds the code that runs, with no class around it. Older code (and the video) may show the full form; both are the same program:

> **Optional video above.** Part of freeCodeCamp's *Learn C#: Full Course with Mini-Projects* (0:00:00 to 0:10:56, about 11 min), coding the same ideas in Visual Studio. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```csharp
// Program.cs, top-level statements (.NET 6 and newer)
Console.WriteLine("Hello, World!");
```

```csharp
// The same program, written the classic way
namespace Hello;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("Hello, World!");
    }
}
```

## The rules that trip beginners

- Every statement ends with `;`.
- Blocks go between `{ }`; indentation is only for people.
- C# is **case-sensitive**: `Console` works, `console` doesn't.
- `//` starts a comment; `/* ... */` spans lines.

## What's in the folder

| File | What it is |
|---|---|
| `Program.cs` | your code |
| `Hello.csproj` | the project: target .NET version, packages |
| `bin/`, `obj/` | build output; never edit, never commit |

C# is **compiled**: `dotnet build` turns your code into a program, and the compiler finds many mistakes before the program even runs. `dotnet run` builds and runs in one step.
