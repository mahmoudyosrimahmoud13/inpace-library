# NuGet packages

[NuGet](https://www.nuget.org) is .NET's package store. Adding a package writes it into the `.csproj`; `dotnet build` downloads it:

```bash
dotnet add package Humanizer
```

```csharp
using Humanizer;

Console.WriteLine(TimeSpan.FromMinutes(90).Humanize());   // 1 hour
Console.WriteLine("some_variable_name".Humanize());       // Some variable name
```

Before you add a package, check it on nuget.org: downloads, last update, who publishes it, and its license. Every package is code you now depend on. Much of what you need is already built into .NET: JSON (`System.Text.Json`), HTTP (`HttpClient`), files, dates and LINQ.
