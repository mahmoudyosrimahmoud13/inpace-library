# Operators and math

| Operator | Meaning |
|---|---|
| `+ - * /` | the four operations |
| `%` | remainder: `7 % 2` is `1` |
| `++`, `--` | add or subtract 1 |
| `+=`, `-=`, `*=` | change a variable in place |
| `== != < > <= >=` | compare (gives a `bool`) |
| `&& \|\| !` | and, or, not |

## The trap: integer division

When both sides are `int`, `/` gives an `int` and drops the fraction:

```csharp
Console.WriteLine(7 / 2);        // 3
Console.WriteLine(7 / 2.0);      // 3.5
Console.WriteLine(7.0 / 2);      // 3.5
int total = 7, people = 2;
double share = (double)total / people;   // 3.5
```

## The Math class

`Math.Round(2.567, 2)` is `2.57`, `Math.Pow(2, 10)` is `1024`, `Math.Max(a, b)` and `Math.Min(a, b)` pick one, and `Math.Sqrt(16)` is `4`. Brackets work as in school: `(a + b) * c`.
