# Arrays and List<T>

An **array** has a fixed size. A **`List<T>`** grows and shrinks; `T` is the type of its items. Both count from 0:

> **Optional video above.** Part of freeCodeCamp's *Learn C#: Full Course with Mini-Projects* (3:11:02 to 3:55:00, about 44 min), coding the same ideas in Visual Studio. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```csharp
int[] scores = { 90, 75, 88 };
Console.WriteLine(scores[0]);          // 90
Console.WriteLine(scores.Length);      // 3
Array.Sort(scores);                    // 75, 88, 90

List<string> names = ["Mona", "Omar"]; // a collection expression (C# 12)
names.Add("Laila");
names.Remove("Omar");
Console.WriteLine(names.Count);        // 2
Console.WriteLine(names.Contains("Mona"));

foreach (string n in names)
    Console.WriteLine(n);
```

Reading past the end (`scores[3]` above) throws an `IndexOutOfRangeException` (for a list, an `ArgumentOutOfRangeException`). In loops, use `.Length` for arrays and `.Count` for lists.

Read more: [List collection](https://learn.microsoft.com/dotnet/csharp/tour-of-csharp/tutorials/list-collection).
