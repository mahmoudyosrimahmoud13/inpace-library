# Final project and where to go next

Build a small API of your own, with the logic in a class library and tests for it. Ideas: a habit tracker, a recipe box, a reading list, a shop's price list with discounts.

## Where .NET goes from here

| Path | Learn next |
|---|---|
| Web back end | ASP.NET Core, Entity Framework Core, authentication |
| Web front end | Blazor |
| Mobile and desktop | .NET MAUI |
| Games | Unity |
| Cloud | Azure, Docker (the library's Docker and Kubernetes course) |

Free and official: Microsoft Learn's [C# learning paths](https://learn.microsoft.com/training/browse/?terms=c%23), and the [Foundational C# with Microsoft](https://www.freecodecamp.org/learn/foundational-c-sharp-with-microsoft/) certification on freeCodeCamp.
