# Dictionaries and LINQ

A **`Dictionary<TKey, TValue>`** connects keys to values. Use `TryGetValue` to read a key that might be missing:

> **Optional video above.** Part of freeCodeCamp's *Learn C#: Full Course with Mini-Projects* (3:55:00 to 4:30:00, about 35 min), coding the same ideas in Visual Studio. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```csharp
var stock = new Dictionary<string, int>
{
    ["apples"] = 12,
    ["bread"] = 3,
};
stock["milk"] = 6;                         // add or change

if (stock.TryGetValue("bread", out int count))
    Console.WriteLine($"bread: {count}");

foreach (var (item, qty) in stock)
    Console.WriteLine($"{item}: {qty}");
```

## LINQ: questions about collections

**LINQ** lets you filter, sort and add up any collection in one readable line. Each step takes a small function written with `=>` (a **lambda**):

```csharp
int[] scores = [90, 45, 75, 88, 60];

var passed = scores.Where(s => s >= 60).OrderByDescending(s => s).ToList();
Console.WriteLine(string.Join(", ", passed));    // 90, 88, 75, 60
Console.WriteLine(scores.Average());             // 71.6
Console.WriteLine(scores.Count(s => s < 60));    // 1
var labels = scores.Select(s => s >= 60 ? "pass" : "fail");
```

Read more: [LINQ overview](https://learn.microsoft.com/dotnet/csharp/linq/).
