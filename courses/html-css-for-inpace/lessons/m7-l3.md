# A take-home task, the way companies set it

**Task (2 hours):** Build a responsive "course card" list page from this description, without frameworks.

- A header with a title and a theme switch.
- A grid of cards: cover image, title, progress bar, "Continue" button.
- Works from 360 px to 1400 px, in English and Arabic.
- Keyboard and screen reader friendly.
- Light and night themes.

**How it's judged:** semantic HTML, CSS that's easy to change (custom properties, logical properties), no layout
shift, accessible names and focus, and a short README explaining your choices. Write the README: interviewers
read it first.
