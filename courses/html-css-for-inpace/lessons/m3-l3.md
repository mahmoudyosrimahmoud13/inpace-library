# Positioning and stacking

| `position` | Behaviour |
|---|---|
| `static` | Normal flow (default) |
| `relative` | Normal flow, can nudge; becomes the anchor for absolute children |
| `absolute` | Out of flow, placed against the nearest positioned ancestor |
| `fixed` | Placed against the viewport |
| `sticky` | Normal until it reaches an edge, then sticks (needs `top` or similar) |

`z-index` only works inside a **stacking context**. New contexts come from `position` + `z-index`, `opacity < 1`,
`transform`, `filter` and more. "My z-index: 9999 doesn't work" almost always means the element is trapped in a
lower stacking context.

inPace's island scene stacks the sky, the sea, the island and Tempo as layers inside one positioned container.
