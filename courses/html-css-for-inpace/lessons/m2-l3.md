# Images, media and icons

- Always give `<img>` an `alt`: describe it, or `alt=""` if it's decoration.
- Set `width` and `height` (or `aspect-ratio` in CSS) so the page doesn't jump when the image loads (that jump is
  measured as **CLS**, Cumulative Layout Shift).
- `loading="lazy"` delays images below the fold.
- Inline SVG (like Tempo and the island) can be styled with CSS and needs no extra request. Give a meaningful one
  `role="img"` and `aria-label`, or `aria-hidden="true"` if it's decoration.
