# Fast pages

## Core Web Vitals

| Metric | Measures | Good |
|---|---|---|
| **LCP** Largest Contentful Paint | when the main content appears | under 2.5 s |
| **INP** Interaction to Next Paint | how fast the page answers clicks | under 200 ms |
| **CLS** Cumulative Layout Shift | how much things jump | under 0.1 |

## What helps

- Less CSS and JS; no framework when you don't need one (inPace has one CSS and one JS file).
- `font-display: swap` and only the font weights you use; preload the main font.
- Compressed images in modern formats (WebP, AVIF), sized for their slot, with `srcset`.
- Animate `transform` and `opacity`, not `top` or `width`.
- `content-visibility: auto` lets the browser skip rendering off-screen sections.
- Cache static files for a long time with versioned names; don't cache HTML that changes (inPace sends
  `no-store` for pages).
