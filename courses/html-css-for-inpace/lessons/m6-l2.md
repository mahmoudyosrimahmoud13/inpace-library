# Accessibility basics that interviewers ask about

| Topic | What to do |
|---|---|
| Contrast | Body text at least 4.5:1 against its background (WCAG AA); large text 3:1 |
| Focus | Never remove focus outlines without a visible replacement. Use `:focus-visible` |
| Keyboard | Everything reachable with Tab, in a sensible order. No positive `tabindex` |
| Names | Every control has a name: a `<label>`, visible text, or `aria-label` |
| ARIA | First rule of ARIA: don't use ARIA if a native element does the job |
| Live updates | `aria-live="polite"` for messages that appear without a page load |
| Motion | Respect `prefers-reduced-motion` |
| Language | `lang` on `<html>`, and on any passage in another language |

```css
:focus-visible { outline: 3px solid var(--accent); outline-offset: 2px; }
.visually-hidden { position: absolute; width: 1px; height: 1px; overflow: hidden; clip-path: inset(50%); }
```

Test with: keyboard only, a screen reader (NVDA, VoiceOver or TalkBack), DevTools' Lighthouse and its
accessibility tree.
