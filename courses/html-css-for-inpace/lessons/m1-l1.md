## Your plan for this week

| Day | Module | Time |
|---|---|---|
| 1 | How a page gets to the screen | about 1 h |
| 2 | Semantic HTML and forms | about 1.5 h |
| 3 | The cascade, specificity and the box model | about 1.5 h |
| 4 | Flexbox and Grid | about 1.5 h |
| 5 | Responsive design, logical properties and RTL | about 1.5 h |
| 6 | Theming with custom properties, accessibility | about 1.5 h |
| 7 | Performance and interview drill | about 1.5 h |

Every day ends with a small build. Use one folder, one `index.html` and one `style.css`, and open it in a browser
with the developer tools on. inPace's own pages (`inpace/templates` and `inpace/static/style.css`) are your real
world example all week.

## What you need

- A browser with developer tools (Chrome, Edge or Firefox).
- A text editor (VS Code is fine).
- inPace's code, to compare with real pages.
