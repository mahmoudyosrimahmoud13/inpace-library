# Logical properties

Physical properties (`left`, `right`, `margin-left`) don't flip for right-to-left languages. **Logical** ones follow
the writing direction:

| Physical | Logical |
|---|---|
| `margin-left` | `margin-inline-start` |
| `padding-left` + `padding-right` | `padding-inline` |
| `left: 0` | `inset-inline-start: 0` |
| `border-right` | `border-inline-end` |
| `text-align: left` | `text-align: start` |
| `width` / `height` | `inline-size` / `block-size` |

With logical properties, one stylesheet serves English and Arabic. Search inPace's `style.css` for `inline-start`:
it's used everywhere.
