# Right to left done properly

- Set `dir="rtl"` on `<html>`; don't just right-align text.
- Use `dir="auto"` for user text that could be either language.
- Mixed text needs care: "درس عن Python" has an Arabic base direction with an English word inside. Each paragraph
  should get its own direction. inPace's Markdown renderer counts **words** in each block to decide (it used to count
  letters, which got this exact example wrong).
- Mirror icons that point somewhere (back/forward arrows), but **not** things like a play button, a clock or a
  checkmark.
- Numbers and code stay left to right inside RTL text; `<bdi>` and `unicode-bidi: isolate` keep them from jumping.
- Arabic needs a good font and often a slightly larger `line-height`.
