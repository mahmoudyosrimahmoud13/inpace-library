# Mobile first

Write the phone layout first, then add rules for bigger screens:

```css
.lesson { padding: 1rem; }
@media (min-width: 48rem) { .lesson { padding: 2rem 3rem; } }
```

Newer tools:

- **Container queries**: style a component by the size of **its container**, not the screen.
  ```css
  .card-list { container-type: inline-size; }
  @container (min-width: 30rem) { .card { display: grid; grid-template-columns: 6rem 1fr; } }
  ```
- `@media (prefers-reduced-motion: reduce)`: turn off big animations.
- `@media (hover: hover)`: hover effects only where there is a mouse.
- Touch targets at least about 44 by 44 px.

inPace's pages work from a 360 px phone to a wide desktop window, from the same CSS.
