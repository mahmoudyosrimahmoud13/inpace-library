# The box model and units

Every element is a box: **content**, **padding**, **border**, **margin**.

```css
*, *::before, *::after { box-sizing: border-box; }
```

With `border-box`, `width` includes padding and border, which is what people expect. Almost every modern
stylesheet (inPace's too) starts with this.

## Margin collapse

Vertical margins between blocks collapse: `margin-bottom: 20px` followed by `margin-top: 30px` gives 30 px, not 50.
It doesn't happen in flex or grid containers. A common interview "why" question.

## Units

| Unit | Relative to | Use for |
|---|---|---|
| `px` | the screen (CSS pixels) | borders, small fixed details |
| `rem` | the root font size | type and spacing that should follow the user's text size |
| `em` | this element's font size | padding inside buttons that scales with their text |
| `%` | the parent | widths |
| `vw`, `vh`, `dvh` | the viewport | full-screen panels (`dvh` handles mobile toolbars) |
| `ch` | the width of "0" | comfortable line length: `max-width: 65ch` |

`clamp(1rem, 2.5vw, 1.5rem)` gives fluid type with a minimum and maximum.
