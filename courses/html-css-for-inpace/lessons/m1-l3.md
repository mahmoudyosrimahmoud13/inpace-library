# The skeleton of a document

```html
<!doctype html>
<html lang="en" dir="ltr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Lessons · inPace</title>
  <link rel="stylesheet" href="/static/style.css">
  <script src="/static/app.js" defer></script>
</head>
<body>
  <header>...</header>
  <main id="main">...</main>
</body>
</html>
```

| Line | Why it matters |
|---|---|
| `<!doctype html>` | Standards mode. Without it, browsers use "quirks mode" with old, odd layout rules |
| `lang` and `dir` | Screen readers pick the right voice; `dir="rtl"` flips the page for Arabic |
| `charset` | Must come early so text is read correctly |
| `viewport` | Without it, phones pretend to be 980 px wide and shrink the page |

Open `inpace/templates/base.html`. Find each of these lines, and notice `lang` and `dir` come from Jinja variables.
