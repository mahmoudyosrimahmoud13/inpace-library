# Custom properties and themes

```css
:root {
  --bg: #fbf8f2; --ink: #1f2a2e; --accent: #2f7d6d;
  --radius: .75rem;
}
:root[data-theme="dark"] { --bg: #12191c; --ink: #e8eeea; }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { --bg: #12191c; --ink: #e8eeea; }
}
body { background: var(--bg); color: var(--ink); }
.button { background: var(--accent); border-radius: var(--radius); }
```

- Custom properties **inherit** and can change at runtime (unlike Sass variables, which are gone after compiling).
- A theme is just a set of values on a root selector. inPace's `base.html` writes `data-theme` and `data-accent` on `<html>`,
  and `style.css` follows the system's dark mode unless you picked `light`. Change one attribute and the whole page follows.
- `color-mix(in srgb, var(--accent) 20%, transparent)` makes tints from one colour.
- Tell the browser too: `color-scheme: light dark` styles form controls and scrollbars.
