# Interview drill: 15 questions

Answer each out loud in under a minute before reading the short answer.

1. **Block vs inline vs inline-block?** Block takes the full width and starts a new line; inline flows in text and
   ignores width/height; inline-block flows in text but respects width and height.
2. **`display: none` vs `visibility: hidden`?** None removes it from layout and the accessibility tree; hidden keeps
   its space.
3. **How does specificity work?** Ids, then classes/attributes/pseudo-classes, then elements; later wins on ties.
4. **What's a BFC?** A block formatting context: an area whose layout is self-contained; `display: flow-root`
   creates one and contains floats.
5. **Why `box-sizing: border-box`?** Width includes padding and border, so sizes add up.
6. **Flex vs Grid?** One-dimensional content-driven vs two-dimensional layout-driven.
7. **What causes a reflow?** Changing geometry (size, position, fonts, content) or reading layout values after
   writing styles (forced synchronous layout).
8. **Semantic HTML: why?** Accessibility, SEO, built-in behaviour, readable code.
9. **How do you make a site work in Arabic?** `dir="rtl"`, logical properties, mirrored direction icons, `dir="auto"`
   for user text, fonts.
10. **`em` vs `rem`?** `em` follows this element's font size, `rem` the root's.
11. **What is a stacking context?** A group whose z-index is resolved together; created by transform, opacity < 1,
    positioned + z-index...
12. **How do you theme a site?** Custom properties on `:root`, swapped by a data attribute and `prefers-color-scheme`.
13. **What's CLS and how do you prevent it?** Layout jumps; reserve space for images, ads and fonts.
14. **Progressive enhancement?** Start with HTML that works, then add CSS and JS layers.
15. **What's the critical rendering path?** DOM + CSSOM → render tree → layout → paint → composite.
