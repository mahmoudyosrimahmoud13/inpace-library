# Flexbox: one direction

```css
.toolbar { display: flex; gap: .5rem; align-items: center; }
.toolbar .grow { flex: 1; }          /* takes the free space */
.chips { display: flex; flex-wrap: wrap; gap: .4rem; }
```

- The **main axis** follows `flex-direction` (row by default); `justify-content` aligns along it.
- The **cross axis** is the other one; `align-items` aligns along it.
- `flex: 1` is shorthand for `flex-grow: 1; flex-shrink: 1; flex-basis: 0%`.
- `gap` replaces margin tricks between items.
- `min-width: 0` on a flex item lets long text shrink and wrap instead of overflowing. A very common fix.

In RTL, `row` starts from the right automatically: flexbox follows the writing direction.
