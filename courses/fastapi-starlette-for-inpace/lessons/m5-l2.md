# Deploying a Python web service

inPace doesn't deploy to a server; it ships as a desktop app. For a normal service:

- **Process**: `uvicorn app:app --host 0.0.0.0 --port 8000 --workers 4`, or Gunicorn with Uvicorn workers.
- **In front**: a reverse proxy (Nginx, Caddy, a cloud load balancer) for TLS, compression and static files.
- **Container**: a slim Python image, dependencies installed in a cached layer, a non-root user.
- **Config**: environment variables (pydantic-settings).
- **Health**: `/health` for the load balancer; inPace has `/ping` for a similar reason (a second launch finds the
  first).
- **Observability**: structured logs, metrics (request count, latency), tracing.
- **Scaling**: stateless app servers behind a load balancer; state in the database and cache.
