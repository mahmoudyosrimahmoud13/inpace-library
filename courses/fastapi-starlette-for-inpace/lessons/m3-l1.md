# Your first FastAPI app

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI(title="Courses API")

class LessonIn(BaseModel):
    title: str = Field(min_length=1, max_length=120)
    minutes: int = Field(ge=1, le=600)
    media: str | None = None

class Lesson(LessonIn):
    id: str

DB: dict[str, Lesson] = {}

@app.post("/lessons", response_model=Lesson, status_code=201)
def create(lesson: LessonIn) -> Lesson:
    item = Lesson(id=f"l{len(DB) + 1}", **lesson.model_dump())
    DB[item.id] = item
    return item

@app.get("/lessons/{lesson_id}")
def read(lesson_id: str) -> Lesson:
    if lesson_id not in DB:
        raise HTTPException(404, "Lesson not found")
    return DB[lesson_id]
```

Run `uvicorn main:app --reload` and open `/docs`: interactive docs generated from your types.

- The body is **parsed and validated** by Pydantic. Bad data gets a 422 with exact field errors, before your code runs.
- `response_model` filters the output, so you never leak fields by accident (like a password hash).
- Path, query, body and header parameters come from the function signature.
