## A request and a response

```http
POST /learn/42/lesson/m1-l2/done HTTP/1.1
Host: 127.0.0.1:8765
Content-Type: application/x-www-form-urlencoded
X-InPace-Nav: 1

next=m1-l3
```

```http
HTTP/1.1 303 See Other
Location: /learn/42/lesson/m1-l3?yay=lesson
```

| Methods | Meaning |
|---|---|
| GET | Read; safe and idempotent; can be cached |
| POST | Create or act; not idempotent |
| PUT / PATCH | Replace / partly change |
| DELETE | Remove; idempotent |

| Status | Means |
|---|---|
| 200, 201, 204 | OK, created, no content |
| 301, 302, **303**, 307, 308 | Redirects. **303** means "now GET this", the right answer after a form POST |
| 400, 401, 403, 404, 409, 422 | Bad request, not signed in, not allowed, not found, conflict, invalid data |
| 500, 502, 503 | Server bug, bad gateway, unavailable |

**Idempotent** means doing it twice has the same effect as once. Interviewers ask about it all the time, usually
with "how do you stop a payment from being charged twice?" (an idempotency key).
