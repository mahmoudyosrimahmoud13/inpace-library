# Databases from an async server

- **SQLite** (inPace): a file, no server, one writer at a time. Perfect for one user. Turn on WAL mode for better
  concurrency, keep transactions short.
- **PostgreSQL**: the default for multi-user services. Use a pool (asyncpg or SQLAlchemy async).
- Use **parameters**, never string formatting, in SQL:

```python
db.execute("SELECT * FROM events WHERE journey = ? AND type = ?", (jid, "lesson_done"))   # safe
db.execute(f"SELECT * FROM events WHERE journey = '{jid}'")                                 # SQL injection
```

## Transactions and idempotency

`lesson_done` first checks whether the event already exists, so pressing Done twice doesn't add two events. On a
real API you'd use a unique constraint or an idempotency key header.
