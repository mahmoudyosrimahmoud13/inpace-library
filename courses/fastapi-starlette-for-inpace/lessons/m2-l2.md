# Forms, uploads and responses

```python
form = await request.form()              # needs python-multipart for file uploads
name = form.get("name", "").strip()
up = form.get("file")                    # an UploadFile
if not up or not getattr(up, "filename", ""):
    return go(back, err="Choose a file first.")
data = await up.read()
if len(data) > 100 * 1024 * 1024:
    return go(back, err="That file is over 100 MB.")
```

- **Validate everything** on the server: presence, size, type, and that ids exist. Error messages in plain words.
- Reading an upload fully into memory is fine for small local files; for big ones, stream to disk in chunks.

Responses you'll use:

```python
HTMLResponse(html)
JSONResponse({"ok": True})
RedirectResponse(url, status_code=303)
FileResponse(path, filename="course.lpack")          # streams from disk
Response(svg, media_type="image/svg+xml")
StreamingResponse(generator(), media_type="text/csv")
```

`FileResponse` plus a `BackgroundTask` that deletes a temporary file after sending is a pattern inPace uses for
exports:

```python
return FileResponse(tmp, filename=name, background=BackgroundTask(lambda: Path(tmp).unlink(missing_ok=True)))
```
