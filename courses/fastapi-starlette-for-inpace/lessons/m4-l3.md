# Security checklist for Python web apps

| Threat | Defence |
|---|---|
| SQL injection | Parameters, an ORM |
| XSS | Autoescaping templates; CSP |
| CSRF (forms with cookies) | SameSite cookies, CSRF tokens, checking Origin |
| Broken auth | Hash passwords with Argon2 or bcrypt; short-lived tokens; rate limits |
| Path traversal | Resolve paths and check they stay inside the allowed folder |
| Big uploads | Size limits before reading everything |
| Secrets | Environment variables or a secret manager, never in git |
| CORS | Allow only the origins you need |

inPace examples:

- `127.0.0.1` only, so other machines can't reach the server at all.
- `course.safe_media_path` refuses `..`, absolute paths and drive letters in course file names, so a course can't
  point at `../../vault.db`.
- Web pages inside lessons get a sandbox CSP with `connect-src 'none'`.
- Files from other people are checked (signatures, sizes, shapes) before anything is stored.

```python
def safe_join(root: Path, rel: str) -> Path | None:
    p = (root / rel).resolve()
    return p if p.is_relative_to(root.resolve()) else None
```
