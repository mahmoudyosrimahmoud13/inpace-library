# Background work and real-time

| Need | Tool |
|---|---|
| Tiny job after the response (send an email, delete a temp file) | `BackgroundTasks` |
| Jobs that must survive restarts, retries, schedules | A queue: Celery, RQ, Arq, Dramatiq |
| Something at a time of day | A scheduler (cron, APScheduler) |
| Push updates to the browser | WebSockets or Server-Sent Events |

inPace has an interesting case: reminders must fire **while the app is closed**, so it hands them to the operating
system's scheduler (Task Scheduler, launchd, systemd timers, cron) which runs `inpace --remind <id>`. No
always-on process is needed. And the island trip timer, while the app is open, uses a `threading.Timer` that shows
a notification when time is up.

```python
from fastapi import WebSocket

@app.websocket("/ws/race/{rid}")
async def race_ws(ws: WebSocket, rid: str):
    await ws.accept()
    while True:
        msg = await ws.receive_json()
        await ws.send_json({"echo": msg})
```
