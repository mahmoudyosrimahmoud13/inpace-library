# Blocking work in an async app

An `async def` route runs on the event loop. If it calls something slow and **blocking** (a network download with
`urllib`, heavy file work), every other request waits.

```python
from starlette.concurrency import run_in_threadpool

async def library_page(request):
    index = await run_in_threadpool(library.load_index, V.home)    # urllib download in a worker thread
    return page("library.html", request, index=index)
```

| Work | Do |
|---|---|
| Async library (httpx.AsyncClient, asyncpg) | `await` it directly |
| Blocking library (requests, urllib, sqlite3, PIL) | `run_in_threadpool` (or a plain `def` route in FastAPI, which runs in the pool automatically) |
| CPU-heavy (big image work, ML) | a process pool or a job queue |

SQLite calls in inPace are quick and local, so they run inline; network calls go to the thread pool.
