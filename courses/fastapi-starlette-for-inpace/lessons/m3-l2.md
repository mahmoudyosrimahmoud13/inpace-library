# Dependency injection

```python
from typing import Annotated
from fastapi import Depends, Header

def get_vault() -> Vault:
    return app.state.vault

def current_user(token: Annotated[str, Header()], vault: Annotated[Vault, Depends(get_vault)]):
    user = vault.user_for(token)
    if not user:
        raise HTTPException(401, "Sign in first")
    return user

@app.get("/me")
def me(user: Annotated[User, Depends(current_user)]):
    return {"name": user.name}
```

- Dependencies are functions; FastAPI calls them, caches each one **per request**, and passes results in.
- Dependencies can depend on dependencies (a tree).
- `yield` dependencies run cleanup after the response (open a DB session, yield it, close it).
- In tests: `app.dependency_overrides[get_vault] = lambda: test_vault`.

## Compare with inPace

inPace's `needs_setup(handler)` is a decorator doing what a FastAPI dependency would do; `V` from the closure is
what `Depends(get_vault)` would give. Same idea, less machinery.
