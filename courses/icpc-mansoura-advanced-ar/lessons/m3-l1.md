# Bitmask DP

عندما تكون الـ state **subset** من n عنصر صغير (n حتى 20 تقريبًا)، نمثلها برقم (mask) كما تعلمت في المستوى 1، ونجعلها جزءًا من الـ state في الـ DP.

## مثال: مسألة البائع المتجول (TSP)

n مدينة ومسافة بين كل اثنتين. ابدأ من المدينة 0، زر كل المدن مرة واحدة، وارجع إليها. أقل مسافة؟

تجربة كل الترتيبات: n! (مستحيل لـ n = 16). مع DP:

- الـ state: `dp[mask][v]` = أقل مسافة لزيارة المدن في mask بالضبط، بدءًا من 0، والوقوف الآن عند v.
- الـ transition: من (mask, v) نذهب لمدينة u ليست في mask: `dp[mask | (1<<u)][u] = min(..., dp[mask][v] + d[v][u])`.
- الأساس: `dp[1][0] = 0` (زرنا المدينة 0 فقط ونحن فيها).
- الإجابة: `min over v of dp[full][v] + d[v][0]`.

```cpp
int n; cin >> n;
vector<vector<long long>> d(n, vector<long long>(n));
for (auto &row : d) for (auto &x : row) cin >> x;

const long long INF = LLONG_MAX / 4;
vector<vector<long long>> dp(1 << n, vector<long long>(n, INF));
dp[1][0] = 0;
for (int mask = 1; mask < (1 << n); mask++)
    for (int v = 0; v < n; v++) {
        if (dp[mask][v] == INF || !((mask >> v) & 1)) continue;
        for (int u = 0; u < n; u++)
            if (!((mask >> u) & 1))
                dp[mask | (1 << u)][u] = min(dp[mask | (1 << u)][u], dp[mask][v] + d[v][u]);
    }
long long best = INF;
int full = (1 << n) - 1;
for (int v = 1; v < n; v++) best = min(best, dp[full][v] + d[v][0]);
if (n == 1) best = 0;
cout << best << "\n";
```

التعقيد O(2ⁿ × n²): لـ n = 16 حوالي 1.6 × 10⁷. ممتاز.

لماذا الترتيب `mask` تصاعديًا صحيح؟ لأن `mask | (1<<u)` دائمًا **أكبر** من mask، فكل حالة نقرأها حُسبت بالفعل.

## مثال: التوزيع (Assignment / Matching)

n شخص و n مهمة (n حتى 21). `ok[i][j]` = هل الشخص i يقبل المهمة j. كم طريقة لتوزيع مهمة لكل شخص؟

الحيلة: الشخص التالي هو **عدد Bitmasks** في mask (عدد المهام الموزعة حتى الآن)، فلا نحتاج بعدًا إضافيًا:

```cpp
vector<long long> ways(1 << n, 0);
ways[0] = 1;
for (int mask = 0; mask < (1 << n); mask++) {
    if (!ways[mask]) continue;
    int i = __builtin_popcount(mask);              // الشخص الذي عليه الدور
    if (i >= n) continue;
    for (int j = 0; j < n; j++)
        if (ok[i][j] && !((mask >> j) & 1))
            ways[mask | (1 << j)] = (ways[mask | (1 << j)] + ways[mask]) % MOD;
}
cout << ways[(1 << n) - 1] << "\n";
```

O(2ⁿ × n).

## المرور على الـ subsets لـ mask

حيلة مشهورة للمرور على كل sub ⊆ mask:

```cpp
for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
    // استخدم sub
}
// (المجموعة الفارغة sub = 0 تُعالج منفصلة إن احتجتها)
```

المرور على كل mask وكل sub لها معًا: O(3ⁿ) وليس O(4ⁿ). مفيد لمسائل "قسّم n عنصر إلى مجموعات".

## علامات Bitmask DP

- n صغير جدًا (≤ 20 إلى 22) في مسألة تبدو صعبة.
- "زر الكل"، "وزّع الكل"، "كل عنصر مرة واحدة"، والترتيب يهم.
