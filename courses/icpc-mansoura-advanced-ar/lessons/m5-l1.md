# Counting and Combinatorics (Counting)

مسائل "كم طريقة...؟" تحتاج أدوات رياضية، ومعها كل ما تعلمته من mod و Modular Inverse.

## القاعدتان الأساسيتان

- **الجمع**: إذا كان الشيء إما من نوع A (a طريقة) **أو** من نوع B (b طريقة) ولا تداخل: a + b.
- **الضرب**: إذا اخترنا خطوة أولى (a طريقة) **ثم** خطوة ثانية (b طريقة): a × b.

## الـ permutations والـ combinations

| السؤال | العدد |
|---|---|
| ترتيب n عنصر مختلف | n! |
| اختيار r من n، الترتيب لا يهم | C(n, r) = n! / (r! (n−r)!) |
| ترتيب r من n | n! / (n−r)! |
| ترتيب كلمة فيها تكرار (مثل AABBB) | n! / (a! b! ...) |

جهّز المضروب ومعكوسه مرة واحدة (من المستوى 1) لتحسب C(n, r) في O(1):

```cpp
const int MAXN = 2000000;
long long fact[MAXN + 1], inv_fact[MAXN + 1];

long long power(long long a, long long e) {
    long long r = 1; a %= MOD;
    while (e) { if (e & 1) r = r * a % MOD; a = a * a % MOD; e >>= 1; }
    return r;
}
void prepare() {
    fact[0] = 1;
    for (int i = 1; i <= MAXN; i++) fact[i] = fact[i - 1] * i % MOD;
    inv_fact[MAXN] = power(fact[MAXN], MOD - 2);
    for (int i = MAXN; i > 0; i--) inv_fact[i - 1] = inv_fact[i] * i % MOD;
}
long long C(int n, int r) {
    if (r < 0 || r > n) return 0;
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD;
}
```

## Stars and Bars

عدد طرق توزيع n كرة **متطابقة** على k صندوق (مسموح الصندوق الفارغ) = C(n + k − 1, k − 1).

تخيل n نجمة و k − 1 قضيبًا يقسمونها: نختار أماكن القضبان من n + k − 1 مكانًا.

إذا كان كل صندوق يأخذ **واحدًا على الأقل**: وزّع واحدًا لكل صندوق أولًا، فيبقى n − k: الإجابة C(n − 1, k − 1).

## المسارات في الشبكة

عدد المسارات من (0, 0) إلى (n, m) بخطوات يمين وأعلى فقط = C(n + m, n): نختار أي الخطوات من n + m تكون "يمين".

## مبدأ Inclusion–Exclusion

|A ∪ B| = |A| + |B| − |A ∩ B|، وبشكل عام: نجمع المجموعات الفردية، نطرح تقاطعات كل اثنين، نجمع تقاطعات كل ثلاثة...

مثال: كم رقمًا من 1 إلى N يقبل القسمة على **واحد على الأقل** من الأوليات p₁..pₖ (k صغير)؟

```cpp
long long countDivisible(long long N, const vector<long long> &p) {
    int k = p.size();
    long long total = 0;
    for (int mask = 1; mask < (1 << k); mask++) {
        long long prod = 1; bool over = false;
        for (int i = 0; i < k; i++)
            if ((mask >> i) & 1) {
                if (prod > N / p[i]) { over = true; break; }   // تجاوز N: لا مضاعفات
                prod *= p[i];
            }
        if (over) continue;
        int bits = __builtin_popcount(mask);
        total += (bits % 2 == 1 ? 1 : -1) * (N / prod);
    }
    return total;
}
```

## العدّ بالـ DP

## مبدأ "المكمّل"

أحيانًا عدّ **العكس** أسهل: (كل الطرق) − (الطرق السيئة). مثال: عدد كلمات طولها n من 26 حرفًا فيها حرف 'a' **مرة على الأقل** = 26ⁿ − 25ⁿ.
