# البرمجة الديناميكية التكرارية، بعمق

في المستوى 1 تعلمت فكرة DP: حالة، وانتقال، وحالات أساس. في المستوى 2 المسائل أكبر، فنحتاج **الشكل التكراري (Tabulation)** لأنه أسرع وبلا خطر Stack Overflow، ونحتاج التفكير في **ترتيب ملء الجدول** و**توفير الذاكرة**.

## ترتيب الملء

القاعدة: عند حساب حالة، يجب أن تكون كل الحالات التي تعتمد عليها **محسوبة بالفعل**. إذا كان `dp[i][j]` يعتمد على `dp[i-1][...]`، املأ الصفوف بالترتيب من i = 0.

## توفير الذاكرة: صفّان بدل الجدول كله

إذا كان الصف i يعتمد على الصف i−1 فقط، احتفظ بصفين:

```cpp
// عدد الطرق في شبكة n × m (يمين أو أسفل فقط)، مع خانات مغلقة '#'
vector<long long> prv(m, 0), cur(m, 0);
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        if (g[i][j] == '#') { cur[j] = 0; continue; }
        if (i == 0 && j == 0) { cur[j] = 1; continue; }
        long long up = (i > 0) ? prv[j] : 0;
        long long left = (j > 0) ? cur[j - 1] : 0;
        cur[j] = (up + left) % MOD;
    }
    swap(prv, cur);
}
// الإجابة في prv[m-1] بعد آخر swap
```

## أطول تتابع متزايد (LIS) في O(n log n)

الحل المعروف O(n²) بطيء لـ n = 2 × 10⁵. الفكرة الأسرع: `tails[k]` = **أصغر نهاية ممكنة** لتتابع متزايد طوله k+1. هذه المصفوفة مرتبة دائمًا، فنستخدم البحث الثنائي:

```cpp
vector<int> tails;
for (int x : a) {
    auto it = lower_bound(tails.begin(), tails.end(), x);  // أول نهاية >= x
    if (it == tails.end()) tails.push_back(x);              // يطيل أطول تتابع
    else *it = x;                                           // نهاية أصغر لنفس الطول
}
cout << tails.size() << "\n";
```

(لتتابع **غير متناقص** استخدم `upper_bound` بدل `lower_bound`.)

## الحقيبة غير المحدودة وعدد الطرق

عدد طرق تكوين المبلغ x من عملات (كل عملة بلا حد)، حيث **الترتيب لا يهم**:

```cpp
vector<long long> ways(x + 1, 0);
ways[0] = 1;
for (int c : coins)                 // العملات في اللفة الخارجية: كل تركيبة مرة واحدة
    for (int s = c; s <= x; s++)
        ways[s] = (ways[s] + ways[s - c]) % MOD;
```

لو قلبنا اللفتين (المبلغ خارجًا والعملات داخلًا) لحسبنا **الترتيبات** المختلفة (2+1 و 1+2 مرتين). انتبه لهذا الفرق في نص المسألة.

## DP على شكل "بادئة + اختيار"

كثير من مسائل المستوى 2: `dp[i][state]` = أفضل نتيجة لأول i عنصر وحالة صغيرة (آخر اختيار، عدد ما استخدمناه...). مثال: أكبر مجموع بحيث لا نأخذ عنصرين متجاورين، مع حد أقصى k عنصر:

```cpp
// dp[i][j][t]: أول i عنصر، أخذنا j عنصرًا، t = هل أخذنا العنصر i-1
const long long NEG = LLONG_MIN / 4;
vector<vector<array<long long,2>>> dp(n + 1, vector<array<long long,2>>(k + 1, {NEG, NEG}));
dp[0][0][0] = 0;
for (int i = 0; i < n; i++)
    for (int j = 0; j <= k; j++)
        for (int t = 0; t < 2; t++) {
            if (dp[i][j][t] == NEG) continue;
            dp[i + 1][j][0] = max(dp[i + 1][j][0], dp[i][j][t]);                   // لا نأخذ a[i]
            if (!t && j < k) dp[i + 1][j + 1][1] = max(dp[i + 1][j + 1][1], dp[i][j][t] + a[i]); // نأخذه
        }
```

استخدام `NEG` كقيمة "مستحيل" بدل 0 مهم عندما تكون الأرقام سالبة.
