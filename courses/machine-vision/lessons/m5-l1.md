# Edges with subpixel accuracy, and fast filtering

In inspection, "the edge is at pixel 112" isn't good enough: parts are measured to hundredths of a pixel. Horn's lectures (based on work with the machine vision company Cognex) show how.

## Finding an edge to a fraction of a pixel

1. Compute the brightness gradient along the direction across the edge.
2. Find the pixel where its magnitude peaks.
3. Fit a parabola through the peak and its two neighbours; the parabola's top is the subpixel edge position.

```python
import numpy as np

def subpixel_peak(g, i):
    """Peak of the parabola through g[i-1], g[i], g[i+1], as an offset from i."""
    a, b, c = g[i - 1], g[i], g[i + 1]
    return i + 0.5 * (a - c) / (a - 2 * b + c)

true_edge = 41.37
x = np.arange(100)
profile = 50 + 150 / (1 + np.exp(-(x - true_edge) / 1.2))      # a blurred step, as cameras see edges
profile += np.random.default_rng(0).normal(scale=0.5, size=x.size)
g = np.abs(np.gradient(profile))                                # gradient magnitude across the edge
i = int(g.argmax())
print("pixel:", i, " subpixel:", round(subpixel_peak(g, i), 2), " true:", true_edge)
```

Accuracy around a tenth of a pixel is routine this way, and better with careful modelling of the blur and averaging along the edge. Choose the gradient operator and the amount of smoothing together: more smoothing fights noise but shifts and blurs closely spaced edges.

## Fast filtering: integral images

Large box filters are needed for smoothing and in many detectors, and a naive k×k box sum costs k² additions per pixel. An **integral image** stores at each pixel the sum of everything above and to the left; then *any* rectangle's sum costs four lookups, whatever its size.

```python
img = np.random.default_rng(1).integers(0, 256, (480, 640)).astype(np.int64)
ii = np.pad(img.cumsum(0).cumsum(1), ((1, 0), (1, 0)))          # integral image with a zero border

def box_sum(y0, x0, y1, x1):                                    # sum of img[y0:y1, x0:x1]
    return ii[y1, x1] - ii[y0, x1] - ii[y1, x0] + ii[y0, x0]

print(box_sum(100, 200, 151, 251) == img[100:151, 200:251].sum())   # True, with 4 lookups instead of 2,601 additions
```

The same trick made the Viola-Jones face detector (2001) run in real time, and repeated box filters approximate a Gaussian blur at constant cost per pixel. In the lectures, Horn generalises this: filters built from piecewise polynomials can be computed quickly by repeated summing after differentiating the kernel.
