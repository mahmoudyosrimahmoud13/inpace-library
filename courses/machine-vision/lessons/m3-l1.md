# Vanishing points and camera calibration

To measure the world in metres from pixels, you need the camera's parameters:

- **Intrinsic:** focal length in pixels (fx, fy), principal point (cx, cy), lens distortion.
- **Extrinsic:** where the camera is and how it's turned (rotation R, translation t).

The full projection of a world point P to pixel coordinates is p ∼ K [R | t] P, with the intrinsic matrix

K = [[fx, 0, cx], [0, fy, cy], [0, 0, 1]]

## Vanishing points give calibration

Each set of parallel world lines meets at a vanishing point, which depends only on the lines' **direction** and on K, not on where the lines are. The vanishing points of three perpendicular directions (say the edges of a box or a building) are enough to find the principal point and the focal length: the principal point is the **orthocentre** of the triangle they form, and the focal length follows from the geometry.

```python
import numpy as np

def line(p, q):                   # homogeneous line through two image points
    return np.cross([*p, 1.0], [*q, 1.0])

def meet(l1, l2):                 # intersection of two homogeneous lines
    v = np.cross(l1, l2)
    return v[:2] / v[2]

f, c = 700.0, np.array([320.0, 240.0])
K = np.array([[f, 0, c[0]], [0, f, c[1]], [0, 0, 1]])
R = np.array([[0.9, 0.0, -0.436], [0.0, 1.0, 0.0], [0.436, 0.0, 0.9]])   # camera turned about 26 degrees

def img(P):                       # project world points with K and R, camera 0 at origin, scene 10 m ahead
    q = (K @ (R @ np.asarray(P, float).T + np.array([[0], [0], [10]]))).T
    return q[:, :2] / q[:, 2:]

# two parallel edges of a box along the world X direction
a = img([[0, 0, 0], [4, 0, 0]]); b = img([[0, 1, 0], [4, 1, 0]])
vp = meet(line(*a), line(*b))
d = K @ R @ np.array([1.0, 0, 0])                   # the theory: vanishing point = K R (direction)
print(np.round(vp, 1), np.round(d[:2] / d[2], 1))   # the same point
```

## Calibration in practice

The standard method (Zhang, 2000) photographs a **flat checkerboard** in 10 to 20 different positions. Its corners are at known positions on the board; the software solves for K, the lens distortion and each view's pose, minimising the **reprojection error** (pixels between where corners were detected and where the model puts them). In OpenCV: `cv2.findChessboardCorners`, then `cv2.calibrateCamera`.

Good practice:

- fill the image with the board in some views, tilt it in others, and cover the corners of the image (where distortion is largest);
- keep focus and zoom fixed afterwards: changing them changes K;
- check the reprojection error (well under a pixel is typical for a good setup) and test on a held-out view.
