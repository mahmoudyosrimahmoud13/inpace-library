# Build a container by hand

Put Days 5 to 7 together: a "container" with no Docker at all.

## 1. A root file system

```bash
mkdir -p ~/box && cd ~/box
# A tiny Alpine Linux root file system (about 3 MB):
curl -LO https://dl-cdn.alpinelinux.org/alpine/v3.20/releases/x86_64/alpine-minirootfs-3.20.3-x86_64.tar.gz
mkdir rootfs && sudo tar xzf alpine-minirootfs-*.tar.gz -C rootfs
```

(If that exact version is gone, pick the current `alpine-minirootfs` file from the same folder.)

## 2. New namespaces, a new root

```bash
sudo unshare --mount --uts --ipc --net --pid --fork --mount-proc=$PWD/rootfs/proc \
  chroot rootfs /bin/sh
```

Inside:

```sh
hostname box; hostname
ps                  # you are PID 1
ls /                # Alpine's files, not the host's
ip a                # only lo: no network
cat /etc/os-release # Alpine
```

## 3. Limit it with a cgroup

In a second terminal on the host:

```bash
sudo mkdir /sys/fs/cgroup/box
echo 100M | sudo tee /sys/fs/cgroup/box/memory.max
echo "50000 100000" | sudo tee /sys/fs/cgroup/box/cpu.max
echo 50 | sudo tee /sys/fs/cgroup/box/pids.max
# move the container's shell into it (find its PID on the host):
pid=$(pgrep -f "chroot rootfs" | tail -1)
echo $pid | sudo tee /sys/fs/cgroup/box/cgroup.procs
```

Now inside, try a fork bomb safely: it stops at 50 processes instead of freezing the host.

## 4. What Docker adds on top

| You did by hand | Docker / containerd / runc also does |
|---|---|
| Untar a root file system | Layered images (overlayfs), registries |
| `unshare` + `chroot` | `pivot_root` (more secure than chroot), user namespaces |
| Write cgroup files | Same files, from `--memory`, `--cpus` |
| No network | veth pairs, a bridge, NAT and port publishing |
| Nothing | Drop capabilities, a seccomp profile, AppArmor/SELinux |

That's the whole trick: **a container is a process**, wrapped in namespaces, limited by cgroups, and filtered by seccomp and MAC. When the Docker course talks about isolation, you'll know which kernel feature does each part.

## Clean up

```bash
exit                               # leave the container shell
sudo rmdir /sys/fs/cgroup/box      # only works once it has no processes
```
