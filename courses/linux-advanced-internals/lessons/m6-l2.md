# systemd internals: dependencies, sockets and sandboxing

## Two separate ideas: requirement and order

| Directive | Means |
|---|---|
| `Wants=b` | Start b too, but don't fail if it fails |
| `Requires=b` | Start b too; if b fails or stops, stop me |
| `After=b` | If both are starting, start me after b |
| `Before=b` | The reverse |
| `PartOf=b` | Restart/stop me when b restarts/stops |

`Requires=` without `After=` starts both **at the same time**. You almost always want both: `Wants=network-online.target` **and** `After=network-online.target`.

```bash
systemctl list-dependencies nginx
systemctl show nginx -p Requires -p Wants -p After
systemd-analyze critical-chain nginx.service
systemd-analyze verify /etc/systemd/system/myapp.service
```

## Socket activation

systemd can hold a listening socket and start the service only when the first connection arrives (and hand it the socket). Used by `sshd` on some systems, by CUPS, and by many small services. Benefits: faster boot, services started on demand, restarts without dropping connections waiting in the socket queue.

```bash
systemctl list-sockets
```

## Sandboxing: the cheapest security you'll ever get

```ini
[Service]
User=myapp
NoNewPrivileges=yes
ProtectSystem=strict          # /usr, /etc and others read-only
ReadWritePaths=/var/lib/myapp
ProtectHome=yes               # no access to /home
PrivateTmp=yes                # its own /tmp
PrivateDevices=yes
ProtectKernelTunables=yes
ProtectKernelModules=yes
RestrictAddressFamilies=AF_INET AF_INET6 AF_UNIX
SystemCallFilter=@system-service
CapabilityBoundingSet=
```

Each line uses the namespaces, capabilities and seccomp filters from this course, with no code changes to the app.

```bash
systemd-analyze security myapp.service   # an exposure score per service, with what to fix
```

Add options one at a time and restart: if the app breaks, the journal shows what it was denied.

## Transient units

`systemd-run` starts a one-off command as a real unit, with limits and logging:

```bash
sudo systemd-run --unit=reindex --property=MemoryMax=1G /opt/app/reindex.sh
journalctl -u reindex -f
```
