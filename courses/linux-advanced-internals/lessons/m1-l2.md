# /sys and sysctl: tuning the kernel

## /proc/sys and sysctl

Kernel settings you're allowed to change live under `/proc/sys`. `sysctl` reads and writes them with dots instead of slashes.

```bash
sysctl vm.swappiness                    # same as cat /proc/sys/vm/swappiness
sudo sysctl -w vm.swappiness=10         # change now (lost at reboot)
sysctl -a 2>/dev/null | wc -l           # how many there are
```

Make changes permanent in a file under `/etc/sysctl.d/`:

```text
# /etc/sysctl.d/90-server.conf
vm.swappiness = 10
net.core.somaxconn = 4096
fs.inotify.max_user_watches = 524288
```

```bash
sudo sysctl --system      # load all files now
```

## Settings worth knowing

| Setting | Controls | When you touch it |
|---|---|---|
| `vm.swappiness` | How eagerly to swap | Databases often lower it |
| `vm.dirty_ratio`, `vm.dirty_background_ratio` | How much unwritten data may sit in the page cache | Heavy writers, big RAM |
| `vm.overcommit_memory` | Whether the kernel promises more memory than exists | Redis asks for `1` |
| `net.core.somaxconn` | Max queue of not-yet-accepted connections | Busy web servers |
| `net.ipv4.ip_forward` | Act as a router | Routers, VPNs, container hosts |
| `net.ipv4.tcp_syncookies` | Survive SYN floods | Leave on |
| `fs.file-max` | System-wide open files | Huge servers |
| `kernel.pid_max` | Highest PID | Many short-lived processes |
| `fs.inotify.max_user_watches` | File watchers per user | IDEs, sync tools: "too many open files" style errors |

Change one thing at a time, measure, and write down why. Defaults are good for most machines.

## /sys: devices and drivers

`/sys` (sysfs) shows the kernel's model of hardware as a tree:

```bash
ls /sys/class/net/                       # network interfaces
cat /sys/class/net/*/speed 2>/dev/null   # link speed (Mb/s)
cat /sys/block/sda/queue/scheduler       # I/O scheduler of a disk
cat /sys/block/sda/queue/rotational      # 1 = spinning disk, 0 = SSD
ls /sys/fs/cgroup                        # cgroups (Day 6)
cat /sys/class/thermal/thermal_zone*/temp 2>/dev/null
```

Some sysfs files are writable (change the I/O scheduler, turn a CPU off), but changes are lost at reboot. Make them permanent with a udev rule or a systemd unit.

## Per-process limits: ulimit

```bash
ulimit -n               # open files allowed for this shell
ulimit -a               # all limits
```

For services, set limits in the unit file (`LimitNOFILE=65536`), not in `/etc/security/limits.conf` (which applies only to login sessions).
