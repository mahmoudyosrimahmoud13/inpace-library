# Start here: /proc, the kernel's window

This course is about **why** Linux behaves the way it does, and how to look inside when something goes wrong. It builds on Operating Systems Fundamentals and Linux System Administration. Use a VM you don't mind breaking; several labs need root.

## /proc/PID: everything about one process

```bash
pid=$(pgrep -o sshd)          # any process will do
sudo ls /proc/$pid
```

| File | Tells you |
|---|---|
| `status` | State, memory (VmRSS), threads, UIDs, context switches, capabilities |
| `cmdline` | The exact command line (NUL-separated: `tr '\0' ' ' < cmdline`) |
| `environ` | Its environment variables (root or owner only) |
| `cwd`, `exe`, `root` | Links to its working directory, program file, and root directory |
| `fd/` | Every open file descriptor, as links to files, sockets, pipes |
| `maps` | Its memory map: every region, permissions, which file backs it |
| `limits` | Resource limits (open files, processes, core size) |
| `io` | Bytes read and written |
| `stack` | Its kernel stack (root): where it's stuck inside the kernel |
| `ns/` | Which namespaces it lives in (Day 5) |
| `cgroup` | Which cgroup it belongs to (Day 6) |

## Questions you can now answer in seconds

```bash
sudo ls -l /proc/$pid/fd | wc -l             # how many files does it have open?
grep -E 'State|Threads|VmRSS' /proc/$pid/status
sudo readlink /proc/$pid/cwd                 # where was it started?
cat /proc/$pid/limits | grep 'open files'    # will it run out of file descriptors?
sudo cat /proc/$pid/stack                    # why is a 'D' state process stuck?
```

Tools like `ps`, `top`, `lsof` and `free` are just friendly readers of these files.

## Whole-system files

```bash
cat /proc/loadavg /proc/uptime
head /proc/meminfo
cat /proc/cpuinfo | grep 'model name' | uniq -c
cat /proc/mounts | head
cat /proc/sys/fs/file-nr       # file handles in use / max
```

## /proc is generated, not stored

Nothing in `/proc` is on disk. Each `read()` runs kernel code that formats the current state. That's why sizes show as 0 and why the contents change every time you look.
