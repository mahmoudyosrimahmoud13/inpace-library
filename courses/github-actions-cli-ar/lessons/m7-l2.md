# action خاصة بك، وإعادة استخدام الـ workflows

عندما تكرر عدة مستودعات الخطوات نفسها، اكتبها مرة واحدة.

## الـ composite action

خطوات في ملف `action.yml` تُستخدم كأي action:

```yaml
# .github/actions/node-test/action.yml
name: Node tests
description: Set up Node and run the tests
inputs:
  node-version:
    default: "22"
runs:
  using: composite
  steps:
    - uses: actions/setup-node@v7
      with:
        node-version: ${{ inputs.node-version }}
    - run: npm test
      shell: bash
```

```yaml
- uses: actions/checkout@v7
- uses: ./.github/actions/node-test     # from this repository
  with:
    node-version: "24"
```

## الـ reusable workflow

‏workflow كامل تستدعيه workflows أخرى، مع `on: workflow_call`. وتحفظ الفرق واحدًا في مستودع مشترك (`uses: my-org/ci/.github/workflows/node.yml@v1`) كي يختبر كل مشروع بالطريقة نفسها.

```yaml
# .github/workflows/node.yml in the shared repository
on:
  workflow_call:
    inputs:
      node-version:
        type: string
        default: "22"
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-node@v7
        with:
          node-version: ${{ inputs.node-version }}
      - run: npm test
```
