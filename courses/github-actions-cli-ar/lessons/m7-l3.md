# إلى أين بعد ذلك

درس اختياري.

- **التوثيق الرسمي:** [GitHub Docs: Actions](https://docs.github.com/actions) و [دليل gh](https://cli.github.com/manual) واضحان وكاملان.
- **الشهادة:** يقدّم GitHub شهادة *GitHub Actions*، ولدى freeCodeCamp دورة تحضير كاملة مجانية على YouTube.
- **الحاويات:** خذ دورة *Docker و Kubernetes* في هذه المكتبة، ثم ابنِ الصور وارفعها من Actions.
- **ساهم:** اختر مشروعًا تستخدمه، واقرأ الـ workflows في `.github/workflows/`، وأصلح issue صغيرة. قراءة خطوط إنتاج الآخرين تعلّم الكثير.
