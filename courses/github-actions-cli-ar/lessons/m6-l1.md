# الأسرار والمتغيرات والرمز

## الأسرار

كلمات المرور ومفاتيح API تُوضع في **Settings ← Secrets and variables ← Actions**، وليس في YAML أبدًا. وفي الـ workflow تكون `${{ secrets.NAME }}`، ويخفيها GitHub في السجلات.

```bash
gh secret set DEPLOY_KEY < key.txt        # from the terminal
gh variable set SITE_URL --body "https://mona.github.io/study-tasks"
```

```yaml
- run: ./deploy.sh
  env:
    API_KEY: ${{ secrets.DEPLOY_KEY }}   # pass secrets as environment variables
    SITE: ${{ vars.SITE_URL }}           # variables are for settings that aren't secret
```

طلبات الدمج القادمة من **forks** لا تحصل على أسرارك، فلا يستطيع غريب سرقتها بطلب دمج يطبعها.

## الـ GITHUB_TOKEN

كل تشغيل يحصل على رمز مؤقت، `secrets.GITHUB_TOKEN`، يستطيع العمل على هذا المستودع وينتهي عند انتهاء الـ job. أعطه **الصلاحيات التي يحتاجها فقط**، في أعلى الـ workflow:

```yaml
permissions:
  contents: write        # e.g. to create a release
  pull-requests: write   # e.g. to comment on a pull request
```

عند ضبط `permissions:` يُغلق كل ما لم يُذكر. وهذا يحدّ من الضرر إن اختُرقت خطوة يومًا.
