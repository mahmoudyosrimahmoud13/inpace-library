# اكتب workflow وشغّله واقرأه

أنشئ هذا الملف، واحفظه، وارفعه:

> **فيديو اختياري في الأعلى.** جزء من فيديو TechWorld with Nana *GitHub Actions Tutorial*، من 9:50 إلى 20:40. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```yaml
# .github/workflows/hello.yml
name: Hello

on:
  push:
  workflow_dispatch:        # adds a "Run workflow" button in the Actions tab

jobs:
  say-hello:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7          # get the repository's files
      - name: Say hello
        run: echo "Hello from ${{ github.actor }} on ${{ github.ref_name }}"
      - name: List the files
        run: ls -la
```

افتح تبويب **Actions**: يظهر التشغيل خلال ثوانٍ. اضغطه، ثم الـ job، ثم خطوة لترى نتيجتها. الأخضر يعني أن كل خطوة انتهت بالرمز 0، والأحمر يعني أن واحدة فشلت وتم تخطي ما بعدها.

## YAML في دقيقتين

- المسافات البادئة لها معنى: استخدم **مسافات، لا Tab أبدًا**، وحافظ على محاذاة المستويات.
- `key: value`، والقوائم تبدأ بـ `- `.
- ‏`${{ ... }}` **تعبير** يملؤه GitHub قبل تشغيل الخطوة. `github.actor` هو من رفع، و `github.ref_name` الفرع أو الوسم، و `secrets.NAME` سرّ.
- ‏`run: |` يسمح للخطوة بعدة أسطر من الأوامر.

## عندما يفشل

1. اقرأ سجل الخطوة الحمراء من الأسفل للأعلى: الخطأ الحقيقي غالبًا قرب النهاية.
2. **أعد التشغيل** (أعلى اليمين) إن بدا كعطل مؤقت في الشبكة.
3. اجعل الخطوة تطبع أكثر (`echo` و `ls`)، وارفع، وانظر مرة أخرى. و `gh run view --log-failed` يوفّر الضغطات.
4. الخطأ الإملائي في YAML يظهر على التشغيل نفسه ("Invalid workflow file"). ومحرر GitHub والأداة المجانية [actionlint](https://github.com/rhysd/actionlint) يجدانه قبل أن ترفع.
