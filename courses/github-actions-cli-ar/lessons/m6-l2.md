# انشر موقعًا وإصدارًا

## GitHub Pages من workflow

في **Settings ← Pages** اضبط *Source* على **GitHub Actions**. ثم يختبر هذا الـ workflow، ولا ينشر الموقع إلا إن نجحت الاختبارات:

```yaml
# .github/workflows/pages.yml
name: Publish the site

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write          # to publish to GitHub Pages
  id-token: write       # to prove to Pages that this run is really from this repository

concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-node@v7
        with:
          node-version: 22
      - run: npm test

  deploy:
    needs: test                  # only publish if the tests passed
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v7
      - uses: actions/configure-pages@v6
      - uses: actions/upload-pages-artifact@v5
        with:
          path: .                # the folder to publish
      - id: deployment
        uses: actions/deploy-pages@v5
```

‏`needs: test` يجعل النشر ينتظر الاختبارات. وتعرض **البيئة (environment)** `github-pages` الرابط الحي على التشغيل، ويمكنك إضافة حماية للبيئة (موافقة إلزامية، أو من main فقط).

## إصدار عندما ترفع وسمًا

```yaml
# .github/workflows/release.yml
name: Release

on:
  push:
    tags: ["v*"]                 # runs when you push a tag like v1.2.0

permissions:
  contents: write                # to create the release

jobs:
  release:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-node@v7
        with:
          node-version: 22
      - run: npm test
      - name: Make the zip
        run: zip -r "study-tasks-${GITHUB_REF_NAME}.zip" index.html style.css tasks.js storage.js app.js
      - name: Create the release
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: gh release create "$GITHUB_REF_NAME" "study-tasks-${GITHUB_REF_NAME}.zip" --generate-notes --verify-tag
```

والآن النشر هو: `git tag -a v1.1.0 -m "..."` ثم `git push origin v1.1.0`. فتعمل الاختبارات، وإن نجحت يظهر الإصدار بملاحظاته والملف المضغوط. وأداة `gh` مثبَّتة مسبقًا على أجهزة GitHub وتقرأ الرمز من `GH_TOKEN`.
