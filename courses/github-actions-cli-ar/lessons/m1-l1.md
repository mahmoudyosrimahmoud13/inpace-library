# ابدأ من هنا: جولة في مستودع

هذه الدورة هي النصف الثاني من Git: العمل **على GitHub** مع الآخرين، ومن الطرفية، وترك الآلات تختبر عملك وتنشره. وتفترض أنك تعرف الـ commits والفروع و push (دورة *احترف Git من الصفر*، الوحدات 1 إلى 5).

| الوحدة | ماذا تتعلم |
|---|---|
| 1 | صفحات المستودع و README و issues و projects |
| 2 | طلبات الدمج والمراجعات وطرق الدمج والفروع المحمية |
| 3 | أداة GitHub لسطر الأوامر (`gh`) |
| 4 | GitHub Actions: أول workflow لك |
| 5 | التكامل المستمر: اختبارات مع كل push |
| 6 | النشر والأمان: Pages والإصدارات والأسرار والصلاحيات |
| 7 | مشروع: خط إنتاج كامل لتطبيق حقيقي |

نحو 4 أسابيع بمعدل 3 إلى 4 ساعات أسبوعيًا.

## تبويبات المستودع

- **Code:** الملفات، والفروع (قائمة الفروع)، والتاريخ (أيقونة الساعة)، وملف README المعروض أسفل الملفات.
- **Issues:** قائمة المهام: أخطاء، وأفكار، وأسئلة.
- **Pull requests:** تغييرات مقترحة تنتظر المراجعة.
- **Actions:** الآلات: الاختبارات والبناء والنشر.
- **Projects:** لوحات لتخطيط العمل.
- **Settings:** الظهور، والمتعاونون، وقواعد الفروع، و Pages، والأسرار.

اضغط مفتاح **.** (النقطة) في أي مستودع فيُفتح VS Code كامل في المتصفح (github.dev). واضغط **t** للبحث عن ملف باسمه، و **y** على ملف لتحصل على رابط لا يتغير أبدًا، مثبَّت على الـ commit الحالي.

## README جيد

ملف README هو الواجهة. ويجيب بهذا الترتيب: **ما هذا** (جملة وصورة)، و**كيف تستخدمه** (التثبيت والتشغيل)، و**كيف تساعد** (رابط CONTRIBUTING.md)، و**الرخصة**. ويكتبه GitHub بلغة Markdown:

````markdown
# Study Tasks

Plan what you study, tick it off, see the minutes left.

![Screenshot](docs/screenshot.png)

## Run it

```bash
npm test
```

> [!TIP]
> Works offline: tasks stay in your browser.

| Feature | Status |
|---|---|
| Tasks | done |
| Sync | planned |
````
