# ثبّت gh وسجّل الدخول

يجلب `gh` موقع GitHub إلى طرفيتك: طلبات الدمج، والـ issues، والإصدارات، و Actions، دون أن تترك لوحة المفاتيح. ويعمل بجانب Git: يهتم Git بالـ commits، ويهتم `gh` بكل ما حولها على GitHub.

- **ويندوز:** `winget install --id GitHub.cli`
- **ماك:** `brew install gh`
- **لينكس:** اتبع [الخطوات الرسمية](https://github.com/cli/cli/blob/trunk/docs/install_linux.md) (حزمة أوبونتو نفسها قديمة غالبًا).

```bash
gh --version
gh auth login --git-protocol ssh   # choose GitHub.com, then log in with a browser; ssh fits the keys you made
gh auth status                      # who you are, and the token's scopes
gh repo view --web                  # open this folder's repository in the browser
```

يحفظ `gh` رمزه الخاص (في مخزن مفاتيح نظامك). وإن قال يومًا إن صلاحية ناقصة، مثلًا لإدارة الـ workflows، فشغّل `gh auth refresh -s workflow`.
