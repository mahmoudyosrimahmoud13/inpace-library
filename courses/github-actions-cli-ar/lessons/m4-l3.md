# الأحداث والـ runners والجدولة

> **فيديو اختياري في الأعلى.** جزء من فيديو TechWorld with Nana *GitHub Actions Tutorial*، من 20:40 إلى 24:35. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```yaml
on:
  push:
    branches: [main]
    paths-ignore: ["docs/**", "*.md"]   # don't run for README changes
  pull_request:
  schedule:
    - cron: "30 5 * * 1"                  # every Monday at 05:30 UTC
  workflow_dispatch:
    inputs:
      level:
        type: choice
        options: [quick, full]
```

- أوقات **cron** بتوقيت UTC، و [crontab.guru](https://crontab.guru) يشرح أي سطر cron. وقد تتأخر التشغيلات المجدولة دقائق، وتتوقف بعد 60 يومًا دون نشاط في المستودع العام.
- **الـ runners:** ‏`ubuntu-latest` الأسرع والأرخص، و `windows-latest` و `macos-latest` تستهلك دقائق أكثر في المستودعات الخاصة. ويمكنك أيضًا تشغيل runner خاص بك (**self-hosted runner**) على جهازك.
- **if:** يشغّل خطوة أو job أحيانًا فقط: `if: github.ref == 'refs/heads/main'`، أو `if: failure()` لإرسال رسالة عندما ينكسر شيء.
