# الدمج، وحماية main

لزر الدمج ثلاثة اختيارات:

| الطريقة | التاريخ على main | يناسب |
|---|---|---|
| **Create a merge commit** | كل commits الفرع مع merge commit | الاحتفاظ بكل خطوة |
| **Squash and merge** | commit واحد لطلب الدمج كله | أغلب الفرق: طلب واحد، commit نظيف واحد |
| **Rebase and merge** | commits الفرع معادًا تطبيقها، بلا merge commit | الفروع المرتبة ذات الـ commits المفيدة |

ويمكنك إيقاف ما لا يستخدمه فريقك في **Settings ← General**، وتفعيل *Automatically delete head branches*.

## قواعد لـ main

في **Settings ← Rules ← Rulesets** (أو *Branch protection rules* الأقدم) احمِ main كي لا يكسره أحد، ولا بالخطأ:

- **اشترط طلب دمج** قبل الدمج، بموافقة واحدة أو أكثر.
- **اشترط نجاح الفحوص (status checks)**: يجب أن تكون اختبارات الوحدة 5 خضراء.
- **امنع الرفع بالقوة** والحذف.
- اختياري: اشترط **commits موقَّعة**، أو **تاريخًا خطيًا**، أو حلّ المحادثات.

## CODEOWNERS

ملف `.github/CODEOWNERS` يحدد من يجب أن يراجع أي ملفات. ومع قاعدة *Require review from Code Owners* يجب أن يوافق هؤلاء:

```text
# .github/CODEOWNERS
# These people are asked to review changes to these files.
*               @mona
.github/        @mona @ali
```
