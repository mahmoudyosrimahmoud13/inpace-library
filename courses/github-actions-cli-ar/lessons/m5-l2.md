# تشغيل أسرع وأذكى: cache و artifacts والفلاتر

## الـ cache

تنزيل الحزم نفسها في كل تشغيل بطيء. ويستطيع `setup-node` و `setup-python` حفظها مؤقتًا (ويحتاجان ملف قفل مثل `package-lock.json`):

```yaml
- uses: actions/setup-node@v7
  with:
    node-version: 22
    cache: npm
- run: npm ci        # install exactly what package-lock.json says
```

ولأي شيء آخر، يحفظ `actions/cache@v6` مجلدًا تحت مفتاح، وعادة يكون hash لملف القفل: `key: deps-${{ hashFiles('**/requirements.txt') }}`.

## الـ artifacts: احتفظ بملفات من التشغيل

يُحذف الـ runner عندما تنتهي الـ job. ولتحتفظ بتقرير اختبارات، أو ناتج بناء، أو صورة، ارفعه كـ **artifact** (يمكن تنزيله من صفحة التشغيل لمدة 90 يومًا افتراضيًا):

```yaml
- if: failure()                 # only when something broke
  uses: actions/upload-artifact@v7
  with:
    name: screenshots
    path: test-results/
```

ولتمرير ملفات من job إلى التالية في نفس التشغيل، ارفعها في الأولى واستخدم `actions/download-artifact` في الثانية.

## شغّل ما يلزم فقط

- ‏`paths:` و `paths-ignore:` تحت `push` و `pull_request` تتخطى التشغيل للتغييرات التي لا تهم (التوثيق والصور).
- ‏`if:` على job أو خطوة: `if: github.event_name == 'push'`.
- ‏`timeout-minutes: 15` على الـ job يوقف التي تعلق (الافتراضي 6 ساعات).
