# شرح عملية

ياسين يزور مركز إعادة تدوير مع فصل ابنه. المرشدة تشرح ماذا يحدث للقمامة، مستخدمة المبني للمجهول: wird gesammelt وwird sortiert.

## استمع أولًا: المحادثة

**في مركز إعادة التدوير**

| الألمانية | المعنى |
|---|---|
| **Führerin:** Herzlich willkommen! Hier seht ihr, was mit eurem Müll passiert. | أهلًا وسهلًا! هنا سترون ماذا يحدث لقمامتكم. |
| **Kind:** Was passiert mit den Plastikflaschen? | ماذا يحدث للزجاجات البلاستيكية؟ |
| **Führerin:** Zuerst werden sie in der gelben Tonne gesammelt. Dann werden sie mit Lastwagen hierher gebracht. | أولًا تُجمع في الصندوق الأصفر. ثم تُنقل إلى هنا بالشاحنات. |
| **Yasin:** Und wie wird der Müll sortiert? Von Hand? | وكيف تُفرز القمامة؟ باليد؟ |
| **Führerin:** Nur zum Teil. Das meiste wird von Maschinen sortiert. Danach wird das Plastik gewaschen und klein gemacht. | جزئيًا فقط. أغلبها تفرزه الآلات. بعدها يُغسل البلاستيك ويُقطّع. |
| **Kind:** Und was wird daraus gemacht? | وماذا يُصنع منه؟ |
| **Führerin:** Neue Flaschen, Kleidung, sogar Möbel. In Deutschland werden fast alle Flaschen recycelt. | زجاجات جديدة، وملابس، وحتى أثاث. في ألمانيا يُعاد تدوير كل الزجاجات تقريبًا. |
| **Yasin:** Interessant! Und das Glas wurde früher auch hier sortiert, oder? | مثير! والزجاج كان يُفرز هنا أيضًا سابقًا، صحيح؟ |
| **Führerin:** Ja, aber seit 2020 wird es in einer anderen Anlage bearbeitet. | نعم، لكن منذ 2020 يُعالج في مصنع آخر. |

## قلّد الكلام (Shadowing)

اقرأ المحادثة بصوت عالٍ **ثلاث مرات**: أولًا ببطء، ثم بسرعة عادية، ثم دون أن تنظر إلى عمود المعنى. ولو عندك الصوت من الروابط بالأسفل، أوقفه بعد كل جملة وقلّد إيقاع المتكلم ولحن صوته، لا الكلمات فقط. هذا اسمه **التقليد (Shadowing)**، وهو يدرّب أذنك ولسانك معًا.

## كلمات وعبارات احفظها

| العبارة | المعنى |
|---|---|
| Was passiert mit...? | ماذا يحدث لـ...؟ |
| Zuerst... dann... danach... zum Schluss... | أولًا... ثم... بعد ذلك... وأخيرًا... |
| Es wird gesammelt / sortiert. | يُجمع / يُفرز. |
| von Hand / von Maschinen | باليد / بالآلات |
| Was wird daraus gemacht? | ماذا يُصنع منه؟ |
| der Müll / die Mülltrennung | القمامة / فرز القمامة |
| die gelbe Tonne / der Biomüll | الصندوق الأصفر (للتغليف) / النفايات العضوية |
| das Pfand | رهن الزجاجات |
| zum Teil | جزئيًا |
| fast alle | كلها تقريبًا |
| Wie funktioniert das? | كيف يعمل هذا؟ |

## انطقها صح

**اسم المفعول واضحًا.** في المبني للمجهول، اسم المفعول في الآخر يحمل المعنى، فانطقه كاملًا: *wird geSAMmelt* و*wird sorTIERT* و*wird reCYcelt* (من الإنجليزية: "ري-سايكلت"). كثير من الكلمات التقنية مستعارة من الإنجليزية أو الفرنسية، والألمانية تنطقها بطريقتها: *recyceln* و*Container* و*Maschine* (ما-شي-نه).
