# Read: the introduction (chapter 1)

Chapter 1 is short and has no formulas. It sets up the whole book, so it's worth reading slowly.

**What to take from it**

- Machine learning is about **data**, a **model** and **learning**. Data are turned into **vectors** of numbers; a model
  is a function (or a probability distribution) with **parameters**; learning means finding parameters that work well on
  data the model has **not** seen.
- The book has two parts. **Part I** is the mathematics (linear algebra, geometry, decompositions, calculus,
  probability, optimization). **Part II** uses all of it on four problems: **regression**, **dimensionality
  reduction** (PCA), **density estimation** (Gaussian mixtures) and **classification** (SVMs).
- The figure with the four "pillars" of machine learning standing on the mathematical foundations is the map for
  the four courses here. Courses 1 to 3 are the foundations, course 4 is the pillars.

**Three ways to think of a vector**, all used in the book:

1. an arrow in space (geometry; 3Blue1Brown's view),
2. a list of numbers (computer science; how data are stored),
3. any object you can add and scale (the abstract view in section 2.4: polynomials and functions are vectors too).

Don't worry if the exercises in later chapters feel slow at first. This book rewards working examples on paper.
