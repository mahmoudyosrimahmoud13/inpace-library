# Read: groups, vector spaces and subspaces (2.4)

Section 2.4 makes "vector" abstract: anything you can **add** and **scale** with the usual rules is a vector.

**What matters**

- A **group** is the minimal structure: an operation with closure, associativity, a neutral element and inverses.
  The book uses it to define a vector space carefully. You can read this quickly; the definition of a **vector
  space** that follows is what you need.
- Examples of vector spaces: ℝⁿ, m × n matrices, polynomials, functions. The same theorems apply to all of them.
- A **subspace** is a subset that is itself a vector space. Test it with three questions: does it contain **0**? Is it
  closed under **addition**? Under **scaling**? Lines and planes through the origin pass; anything that misses the
  origin fails.
- The solutions of **Ax = 0** always form a subspace (the kernel). The solutions of Ax = b with b ≠ 0 never do.
