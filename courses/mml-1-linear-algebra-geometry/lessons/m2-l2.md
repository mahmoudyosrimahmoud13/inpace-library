# Read: solving systems, Gaussian elimination (2.3)

Section 2.3 is the most hands-on part of the chapter. Have paper ready.

**The plan of the section**

1. A **particular solution** plus everything in the **kernel** (solutions of Ax = 0) gives **all** solutions:
   x = x_p + λ₁x₁ + λ₂x₂ + …
2. **Elementary row operations** (swap rows, scale a row, add a multiple of one row to another) don't change the
   solutions. Use them to reach **row-echelon form** (a staircase), then **reduced row-echelon form**.
3. **Pivot** columns ↔ basic variables; non-pivot columns ↔ **free variables**. The "Minus-1 trick" reads the kernel
   straight off the reduced form.
4. **Inverse by elimination**: reduce [A | I] to [I | A⁻¹].
5. In practice nobody inverts matrices to solve Ax = b: the closing part mentions iterative methods (Jacobi,
   Gauss-Seidel, conjugate gradients) for big systems. In code, use `np.linalg.solve`, not `inv`.

**Do on paper:** the long worked example with the 4 × 5 system (follow every row operation), then the
inverse-by-elimination example.
