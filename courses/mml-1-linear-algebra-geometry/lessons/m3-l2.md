# Read: linear independence (2.5) and basis and rank (2.6)

These two sections are the heart of chapter 2.

![Two vectors that span the plane, and two that only span a line](span.png)

**Linear independence (2.5)**: vectors are independent if the only way to combine them to 0 is with all weights 0.
Practical test: put them as **columns** of a matrix and do Gaussian elimination. **Every column is a pivot column**
↔ independent. A non-pivot column is a combination of the pivot columns to its left.

**Basis (2.6.1)**: a set of vectors that is independent **and** spans the space. Every vector then has **unique**
coordinates in that basis. All bases of a space have the same size: its **dimension**.

**Rank (2.6.2)**: the number of independent columns = the number of independent rows. Facts to remember:

- rank(A) = rank(Aᵀ)
- an n × n matrix is invertible ↔ rank n
- Ax = b has a solution ↔ rank(A) = rank([A | b])
- **rank-nullity**: dim(kernel) + rank = number of columns

**Do on paper:** the example that finds a basis of a span by elimination; then check the rank of a 3 × 3 matrix with
one row equal to the sum of the other two (it's 2).
