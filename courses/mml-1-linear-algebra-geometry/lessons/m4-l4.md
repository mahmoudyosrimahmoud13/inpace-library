# Read: affine spaces (2.8) and further reading (2.9)

**Affine subspaces** are subspaces shifted away from the origin: L = x₀ + U. The solution set of Ax = b (b ≠ 0) is
one: a particular solution plus the kernel. Lines and planes that don't pass through 0 are affine.

**Affine mappings** are a linear map followed by a shift: x ↦ Ax + b. A neural network layer before its activation
(Wx + b) is affine, not linear; people say "linear layer" loosely.
