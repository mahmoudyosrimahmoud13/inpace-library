# One base, fifty pages

`base.html` holds what every page shares: the `<head>`, the top bar, the side menu, messages, the script.
Child templates fill **blocks**:

```jinja
{# base.html #}
<html lang="{{ lang or 'en' }}" dir="{{ 'rtl' if lang == 'ar' else 'ltr' }}"
      {% if theme %} data-theme="{{ theme }}"{% endif %}>
<title>{% block title %}inPace{% endblock %} · inPace</title>
...
<div class="page {% block width %}{% endblock %}">
  {% if msg %}<p class="ok" role="status">{{ msg }}</p>{% endif %}
  {% block main %}{% endblock %}
</div>
```

```jinja
{# island.html #}
{% extends "base.html" %}
{% block title %}Tempo's island{% endblock %}
{% block width %}wide{% endblock %}
{% block main %}
  <h1>Tempo's island.</h1>
  ...
{% endblock %}
```

- `{% extends %}` must be the first tag.
- Anything outside blocks in a child is ignored.
- `{{ super() }}` prints the parent's block content, to add to it instead of replacing it.
- Blocks can be nested and can be used as tiny "settings" (like `width` here).

Every message (`?ok=...`, `?err=...`) shows in one place, the base, because `page()` puts `msg` and `err` in the
context for every page.
