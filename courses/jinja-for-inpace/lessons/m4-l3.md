# Interview drill

1. **What's server-side rendering, and why choose it?** HTML built on the server: fast first paint, works without JS,
   simple. Trade-off: every change needs a request (or some JS on top).
2. **Jinja vs Django templates?** Jinja allows Python-like expressions and function calls, has macros, and is faster;
   Django's language is deliberately more limited.
3. **How does template inheritance work?** A child extends a base and overrides named blocks; `super()` adds to them.
4. **How do you avoid XSS in templates?** Autoescape, `Markup` only for trusted HTML, `tojson` in scripts, quoted
   attributes, checked URLs.
5. **What's SSTI?** Server-side template injection: rendering user input as a template, which can run code. Never do
   it; if users need templates, use the sandbox.
6. **Macro vs include?** A macro takes arguments like a function; an include renders a file with the current context.
7. **How does inPace pass shared data to every page?** `page()` builds a base context and merges the route's values.
8. **How would you translate templates?** The i18n extension with gettext or a dictionary, `trimmed`, plural forms,
   and a per-request language.
