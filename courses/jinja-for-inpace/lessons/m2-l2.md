# Includes with context

A share box (copy a link, send on WhatsApp, show a QR) appears on several pages. It lives in `_share.html` (the
underscore says "partial, not a page"):

```jinja
{% with share=c.send, sid='send-' ~ c.journey.id, label=_('Your progress link') %}
  {% include '_share.html' %}
{% endwith %}
```

- `include` renders another template **with the current context**.
- `with` sets variables only for that block, so the partial gets the names it expects (`share`, `sid`, `label`).
- `~` joins strings (it converts numbers too).
- `{% include "x.html" ignore missing %}` doesn't fail if the file isn't there.
