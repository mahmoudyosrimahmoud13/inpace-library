# Custom filters and tests you write

```python
def filesize(n: int) -> str:
    for unit in ("bytes", "KB", "MB", "GB"):
        if n < 1024 or unit == "GB":
            return f"{n:.0f} {unit}" if unit == "bytes" else f"{n:.1f} {unit}"
        n /= 1024

env.filters["filesize"] = filesize
env.tests["overdue"] = lambda d: d < date.today()
```

```jinja
{{ 2_400_000 | filesize }}          {# 2.3 MB #}
{% if task.due is overdue %}late{% endif %}
```

Filters can be `@pass_context` (get the template context) or `@pass_environment`. Keep filters pure and tiny; put
logic that touches the database in the route, not the template.
