# Testing templates

inPace tests pages through the whole app with Starlette's `TestClient`:

```python
def test_island_shows_trophy(client, vault):
    r = client.get("/island")
    assert r.status_code == 200
    assert "isle-trophy" in r.text
```

Test templates directly too:

```python
from jinja2 import Environment, DictLoader, StrictUndefined
env = Environment(loader=DictLoader({"t.html": "Hi {{ name }}"}), undefined=StrictUndefined, autoescape=True)
assert env.get_template("t.html").render(name="<b>") == "Hi &lt;b&gt;"
```

`StrictUndefined` turns a typo like `{{ coures.title }}` into an error instead of an empty string: use it in tests
(and in development) to catch them.
