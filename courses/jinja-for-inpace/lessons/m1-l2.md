# Filters and tests

Filters change a value with a pipe:

```jinja
{{ name | default("friend") }}
{{ title | truncate(40) }}
{{ items | length }}
{{ people | map(attribute="name") | join(", ") }}
{{ modules | selectattr("done") | list | length }} of {{ modules | length }} done
{{ price | round(1) }}
{{ text | e }}            {# escape #}
{{ data | tojson }}       {# safe JSON for a <script> #}
```

inPace adds its own filters: `short` (shortens long text), `date` (a friendly date) and `filesize`:

```jinja
<small>{{ f.size | filesize }} · {{ f.when | date }}</small>
```

**Tests** check a value with `is`:

```jinja
{% if value is defined %} ... {% endif %}
{% if n is divisibleby 2 %} ... {% endif %}
{% if x is none %} ... {% endif %}
```
