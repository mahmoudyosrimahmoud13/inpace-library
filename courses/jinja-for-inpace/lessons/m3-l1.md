# Setting up the Environment

inPace builds one Environment when the module loads:

```python
env = Environment(loader=FileSystemLoader(HERE / "templates"),
                  autoescape=select_autoescape(["html"]),
                  extensions=["jinja2.ext.i18n"])
env.globals["icon"] = icon              # {{ icon('island', 22) }}
env.globals["avatar"] = avatar          # a person's turtle as SVG
env.globals["cover"] = cover            # a course's cover or a drawn one
env.globals["mascot"] = mascot          # Tempo
env.globals["say"] = say                # translate with %s values
env.globals["T"] = t                    # translate with {name} values
env.filters["short"] = short
env.filters["date"] = nice_date
env.filters["filesize"] = filesize
```

- **Globals** are available in every template without passing them.
- **Filters** are functions whose first argument is the value before the pipe.
- Create the Environment **once**: it caches compiled templates. Making one per request throws that away.
- `FileSystemLoader` finds files relative to the package (`HERE`), so it works inside a frozen PyInstaller app too.

## Shared context: page()

```python
def page(name, request, **ctx):
    base = {"request": request, "msg": ..., "err": ..., "lang": ..., "theme": ..., "accent": ...}
    if V.is_set_up:
        base["me"] = V.me
        base["island_on"] = garden.is_on(V)
        ...
    base.update(ctx)                     # the route's own values win
    return HTMLResponse(env.get_template(name).render(**base))
```

This is the same idea as a Django "context processor": everything every page needs, in one place.
