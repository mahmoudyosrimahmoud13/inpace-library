# Project part 3: generate new digits

Put the course together into your first generative model of images:

1. **Compress** each 8 × 8 digit to 20 numbers with PCA (day 6).
2. **Model** those 20-number codes with a **mixture of Gaussians**, fitted by **your own EM** (day 5).
3. **Sample** new codes from the mixture (ancestral sampling, day 1: first the component, then the Gaussian), and map
   them back to images.
4. **Judge** the results with a classifier trained on real digits: if a generated image is a convincing digit, the judge
   should recognize it, and be confident.

This is the same recipe, in miniature, as many real generative models: a compressed latent space, a probability model
in that space, and a decoder back to images. In part 5, deep networks replace the linear PCA decoder and the Gaussian
mixture, and the images get sharper.

## 1. Set up: data, PCA codes, the judge, and your EM

```python
import numpy as np
from sklearn.datasets import load_digits
from sklearn.linear_model import LogisticRegression

digits = load_digits()
X, y = digits.data / 16.0, digits.target
rng = np.random.default_rng(0)
idx = rng.permutation(len(y))
tr, te = idx[:1400], idx[1400:]

mean = X[tr].mean(axis=0)
eigvals, eigvecs = np.linalg.eigh(np.cov((X[tr] - mean).T, bias=True))
U = eigvecs[:, np.argsort(eigvals)[::-1]][:, :20]       # top 20 principal directions
codes = (X[tr] - mean) @ U                              # 20 numbers per training image

def decode(Z):
    return np.clip(Z @ U.T + mean, 0, 1)                # back to pixels, kept in the valid range

judge = LogisticRegression(max_iter=2000).fit(X[tr], y[tr])
print(f"the judge recognizes {judge.score(X[te], y[te]):.1%} of real test digits")
print(f"its average confidence on real test digits: {judge.predict_proba(X[te]).max(axis=1).mean():.2f}")

# your EM from day 5
def log_gauss(X, mu, S):
    D = X.shape[1]
    L = np.linalg.cholesky(S)
    sol = np.linalg.solve(L, (X - mu).T)
    return -0.5 * (D * np.log(2 * np.pi) + 2 * np.log(np.diag(L)).sum() + (sol ** 2).sum(0))

def e_step(X, pi, mu, S):
    logp = np.stack([np.log(pi[k]) + log_gauss(X, mu[k], S[k]) for k in range(len(pi))], axis=1)
    top = logp.max(axis=1, keepdims=True)
    log_px = top[:, 0] + np.log(np.exp(logp - top).sum(axis=1))
    return np.exp(logp - log_px[:, None]), log_px.sum()

def m_step(X, gamma, floor=1e-4):
    Nk = gamma.sum(axis=0)
    mu = (gamma.T @ X) / Nk[:, None]
    S = [((gamma[:, k, None] * (X - mu[k])).T @ (X - mu[k])) / Nk[k] + floor * np.eye(X.shape[1])
         for k in range(gamma.shape[1])]
    return Nk / len(X), mu, np.array(S)

def em(X, K, rng, iters=300, tol=1e-6):
    mu = X[rng.choice(len(X), K, replace=False)]
    S = np.array([np.cov(X.T) for _ in range(K)])
    pi = np.full(K, 1 / K)
    last = -np.inf
    for _ in range(iters):
        gamma, ll = e_step(X, pi, mu, S)
        if ll - last < tol:
            break
        last = ll
        pi, mu, S = m_step(X, gamma)
    return pi, mu, S
```

```output
the judge recognizes 98.0% of real test digits
its average confidence on real test digits: 0.91
```

## 2. One Gaussian for everything

The baseline from day 6: a single Gaussian over all the codes (that's probabilistic PCA).

```python
def sample_mixture(pi, mu, S, n, rng):
    comp = rng.choice(len(pi), size=n, p=pi)                    # ancestral sampling: component first,
    return np.array([rng.multivariate_normal(mu[k], S[k]) for k in comp])   # then the Gaussian

pi1, mu1, S1 = em(codes, 1, np.random.default_rng(0))
fake1 = decode(sample_mixture(pi1, mu1, S1, 500, rng))
print(f"one Gaussian: judge's average confidence {judge.predict_proba(fake1).max(axis=1).mean():.2f}")
```

```output
one Gaussian: judge's average confidence 0.60
```

The judge is unsure about these samples: they're blends of several digits.

## 3. A mixture of Gaussians, fitted by your EM

Now 10 components, with no labels at all: EM has to discover the groups by itself.

```python
pi10, mu10, S10 = em(codes, 10, np.random.default_rng(0))
fake10 = decode(sample_mixture(pi10, mu10, S10, 500, rng))
probs = judge.predict_proba(fake10)
print(f"10-component mixture: judge's average confidence {probs.max(axis=1).mean():.2f}")
print("which digits the judge sees in the samples:", np.bincount(probs.argmax(axis=1), minlength=10))
```

```output
10-component mixture: judge's average confidence 0.84
which digits the judge sees in the samples: [52 38 62 58 49 47 44 53 52 45]
```

More convincing, and the judge sees every digit among them, though nobody told the model what a digit is.

## 4. Ask for a specific digit

Fit one Gaussian **per digit class** (a class-conditional model, the generative classifier of part 1, section 5.3,
now used to generate). Then ask for 100 images of each digit and see whether the judge agrees.

```python
recognized = 0
for k in range(10):
    pik, muk, Sk = em(codes[y[tr] == k], 1, np.random.default_rng(0))
    imgs = decode(sample_mixture(pik, muk, Sk, 100, rng))
    recognized += np.sum(judge.predict(imgs) == k)
print(f"asked for a digit, got one the judge recognizes as that digit: {recognized / 1000:.1%}")
print("an imagined 3 (×10, rounded):")
pik, muk, Sk = em(codes[y[tr] == 3], 1, np.random.default_rng(0))
print(np.round(decode(sample_mixture(pik, muk, Sk, 1, rng))[0].reshape(8, 8) * 10).astype(int))
```
