## Conditional independence (11.2)

a and b are **conditionally independent given c** when `p(a, b | c) = p(a | c) p(b | c)`: once you know c, learning b
tells you nothing more about a. Graphs let you read these independences off without any algebra.

**The three example graphs** (11.2.1) are the heart of the section. Learn all three, with a story for each:

| Graph | Without observing c | After observing c |
|---|---|---|
| tail-to-tail: a ← c → b | a and b are dependent (a common cause) | independent |
| head-to-tail: a → c → b | dependent (a chain) | independent |
| head-to-head: a → c ← b | **independent** | **dependent** |

The third one is the surprise, and it's **explaining away** (11.2.2): the battery and the fuel tank are independent, but
once you see an empty gauge, finding a flat battery makes an empty tank *less* likely. You computed exactly that
yesterday.

**D-separation** (11.2.3) turns the table into a rule for any graph: a path between two nodes is blocked if it passes
through an observed tail-to-tail or head-to-tail node, or through an unobserved head-to-head node with no observed
descendants. If every path is blocked, the nodes are conditionally independent.

Then four applications:

- **Naive Bayes** (11.2.4): assume all features are independent given the class. Wrong, but often useful, and
  extremely cheap. You'll build one on digits today.
- **Generative models** (11.2.5): a graph tells you how to sample the data, cause first.
- **Markov blanket** (11.2.6): a node's parents, children and its children's other parents. Given its blanket, a node is
  independent of everything else. Gibbs sampling (chapter 14) uses exactly this.
- **Graphs as filters** (11.2.7): a graph defines a family of distributions by the independences it allows.

## Sequence models (11.3)

For data in order (text, speech, sensor readings), the product rule gives a chain, and assuming each step depends only on
the previous one gives a **first-order Markov chain**. Higher orders remember more but need many more parameters. The
elegant fix is **hidden variables** (11.3.1): a hidden chain of states, each generating an observation. With discrete
hidden states this is a **hidden Markov model**; with linear-Gaussian ones, it's a Kalman filter (day 6). Hidden state
can carry information across arbitrarily long stretches, using few parameters: the idea behind recurrent networks too.
