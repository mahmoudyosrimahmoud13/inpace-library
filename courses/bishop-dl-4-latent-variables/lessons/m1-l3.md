# Build: a graphical model you can sample and query

Section 11.2.2 uses a small car model with three binary variables: the battery B (1 = charged), the fuel tank F
(1 = full) and the electric fuel gauge G (1 = reads full). Its graph is B → G ← F. Today you build it, sample from it,
and answer questions by counting and by exact sums.

## 1. The model

The numbers are the book's: a charged battery and a full tank are both 90% likely, and the gauge is unreliable.

```python
import numpy as np

p_B1 = 0.9
p_F1 = 0.9
p_G1 = {(1, 1): 0.8, (1, 0): 0.2, (0, 1): 0.2, (0, 0): 0.1}     # p(G = 1 | B, F)

def joint(b, f, g):
    """The factorization from the graph: p(B) p(F) p(G | B, F)."""
    pb = p_B1 if b else 1 - p_B1
    pf = p_F1 if f else 1 - p_F1
    pg = p_G1[(b, f)] if g else 1 - p_G1[(b, f)]
    return pb * pf * pg

total = sum(joint(b, f, g) for b in (0, 1) for f in (0, 1) for g in (0, 1))
print("the joint adds up to", round(total, 10))
print("numbers needed: general joint", 2 ** 3 - 1, " graph", 1 + 1 + 4)
```

```output
the joint adds up to 1.0
numbers needed: general joint 7  graph 6
```

With three yes/no variables the saving is tiny (6 numbers instead of 7). With 30 variables it would be the difference
between about a billion numbers and a few hundred.

## 2. Ancestral sampling

Sample the parents first (B and F, which have no parents), then G given them.

```python
rng = np.random.default_rng(0)
n = 1_000_000
B = rng.random(n) < p_B1
F = rng.random(n) < p_F1
p_g = np.select([B & F, B & ~F, ~B & F], [0.8, 0.2, 0.2], 0.1)
G = rng.random(n) < p_g
print("share of samples with the gauge reading empty:", round(np.mean(~G), 4))
```

```output
share of samples with the gauge reading empty: 0.3146
```

## 3. Inference: is the tank empty?

The gauge reads empty. How likely is an empty tank now? Answer it twice: exactly, by summing the joint, and by counting
samples.

```python
def prob(query, given):
    """p(query | given) by summing the joint over all 8 states. Both are dicts like {'F': 0}."""
    num = den = 0.0
    for b in (0, 1):
        for f in (0, 1):
            for g in (0, 1):
                s = {"B": b, "F": f, "G": g}
                if all(s[k] == v for k, v in given.items()):
                    p = joint(b, f, g)
                    den += p
                    if all(s[k] == v for k, v in query.items()):
                        num += p
    return num / den

print(f"p(F=0)              = {prob({'F': 0}, {}):.3f}")
print(f"p(F=0 | G=0)        = {prob({'F': 0}, {'G': 0}):.3f}   samples: {np.mean(~F[~G]):.3f}")
print(f"p(F=0 | G=0, B=0)   = {prob({'F': 0}, {'G': 0, 'B': 0}):.3f}   samples: {np.mean(~F[~G & ~B]):.3f}")
```

```output
p(F=0)              = 0.100
p(F=0 | G=0)        = 0.257   samples: 0.258
p(F=0 | G=0, B=0)   = 0.111   samples: 0.110
```

These are the book's numbers (11.34 and the result that follows it). An empty gauge raises the chance of an empty tank
from 0.1 to about 0.26. But once we also find the battery flat, the chance drops back to about 0.11: the flat battery
**explains away** the empty reading. You'll study why tomorrow.
