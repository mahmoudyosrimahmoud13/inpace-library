# Project part 2: PCA and probabilistic PCA on digits

## 1. PCA by eigendecomposition

```python
import numpy as np
from sklearn.datasets import load_digits

digits = load_digits()
X, y = digits.data / 16.0, digits.target
rng = np.random.default_rng(0)
idx = rng.permutation(len(y))
tr, te = idx[:1400], idx[1400:]

mean = X[tr].mean(axis=0)
C = np.cov((X[tr] - mean).T, bias=True)               # 64 × 64 covariance
eigvals, eigvecs = np.linalg.eigh(C)
order = np.argsort(eigvals)[::-1]                       # largest first
eigvals, U = eigvals[order], eigvecs[:, order]

explained = np.cumsum(eigvals) / eigvals.sum()
for M in [2, 5, 10, 20, 40]:
    print(f"M = {M:2d} components keep {explained[M - 1]:.1%} of the variance")
```

```output
M =  2 components keep 28.5% of the variance
M =  5 components keep 54.6% of the variance
M = 10 components keep 73.9% of the variance
M = 20 components keep 89.6% of the variance
M = 40 components keep 98.8% of the variance
```

## 2. Compress and reconstruct

Keep M numbers per image: project onto the top M eigenvectors, then map back.

```python
def reconstruct(Xq, M):
    Z = (Xq - mean) @ U[:, :M]           # M numbers per image
    return Z @ U[:, :M].T + mean

for M in [5, 10, 20, 40]:
    err = np.mean((reconstruct(X[te], M) - X[te]) ** 2)
    print(f"M = {M:2d}: mean squared reconstruction error on test images {err:.4f}")
print("theory for M = 20 (dropped eigenvalues / 64, on the training data):",
      round(eigvals[20:].sum() / 64, 4))
```

```output
M =  5: mean squared reconstruction error on test images 0.0343
M = 10: mean squared reconstruction error on test images 0.0199
M = 20: mean squared reconstruction error on test images 0.0084
M = 40: mean squared reconstruction error on test images 0.0010
theory for M = 20 (dropped eigenvalues / 64, on the training data): 0.0076
```

The last line is section 16.1.2's result: the error per pixel is the sum of the discarded eigenvalues, divided by the
64 pixels (on the training data; the test error is close).

## 3. Denoising with PCA

Add heavy noise to test images, then project onto the top components and back. The noise spreads over all 64 directions,
but the digits live mostly in the first few, so projecting removes most of the noise.

```python
noisy = X[te] + rng.normal(0, 0.3, X[te].shape)
print(f"error of the noisy images:        {np.mean((noisy - X[te]) ** 2):.4f}")
for M in [5, 10, 20]:
    print(f"error after PCA cleanup (M = {M:2d}): {np.mean((reconstruct(noisy, M) - X[te]) ** 2):.4f}")
```

```output
error of the noisy images:        0.0895
error after PCA cleanup (M =  5): 0.0412
error after PCA cleanup (M = 10): 0.0341
error after PCA cleanup (M = 20): 0.0366
```

The cleanup removes more than half the error. M = 10 works best here: with too few components the digits themselves lose
detail, and with too many, more of the noise is kept.

## 4. Probabilistic PCA (section 16.2.3)

The closed-form maximum likelihood solution: σ² is the average of the discarded eigenvalues, and
`W = U_M (Λ_M − σ²I)^½`.

```python
def ppca_fit(M):
    sigma2 = eigvals[M:].mean()
    W = U[:, :M] * np.sqrt(eigvals[:M] - sigma2)
    return W, sigma2

def gauss_loglik(Xq, cov):
    D = Xq.shape[1]
    sign, logdet = np.linalg.slogdet(cov)
    d = Xq - mean
    return -0.5 * (D * np.log(2 * np.pi) + logdet + np.sum(d @ np.linalg.inv(cov) * d, axis=1))

for M in [5, 10, 20, 40]:
    W, s2 = ppca_fit(M)
    C_model = W @ W.T + s2 * np.eye(64)
    print(f"PPCA with M = {M:2d}: average test log-likelihood {gauss_loglik(X[te], C_model).mean():8.2f}"
          f"   (parameters: {64 * M + 1 + 64})")
C_full = C + 1e-3 * np.eye(64)
print(f"full-covariance Gaussian:  average test log-likelihood {gauss_loglik(X[te], C_full).mean():8.2f}"
      f"   (parameters: {64 * 65 // 2 + 64})")
```

```output
PPCA with M =  5: average test log-likelihood     8.13   (parameters: 385)
PPCA with M = 10: average test log-likelihood    16.38   (parameters: 705)
PPCA with M = 20: average test log-likelihood    25.30   (parameters: 1345)
PPCA with M = 40: average test log-likelihood    38.50   (parameters: 2625)
full-covariance Gaussian:  average test log-likelihood    46.67   (parameters: 2144)
```

Probabilistic PCA turns PCA into a proper density model, so models can be compared by their likelihood on new data. The
likelihood keeps rising with M, and here the full covariance is best of all: with 1,400 training images, there's enough
data to estimate all 2,144 numbers. Probabilistic PCA earns its place when dimensions are many and data is scarce: for
28 × 28 images, a full covariance would need about 300,000 numbers.

## 5. Sample new images from the model

Draw z from N(0, I), map it through W, and add the mean. These are images the model "imagines".

```python
W, s2 = ppca_fit(20)
z = rng.normal(size=(5, 20))
fake = z @ W.T + mean                                    # the noise ε is left out to keep the images clean
print("pixel range of the samples:", round(fake.min(), 2), "to", round(fake.max(), 2))
print("one sample as an 8 × 8 image (×10, rounded):\n", np.round(fake[0].reshape(8, 8) * 10).astype(int))
```
