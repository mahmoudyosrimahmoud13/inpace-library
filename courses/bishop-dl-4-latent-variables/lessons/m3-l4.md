# Build: four samplers for one awkward distribution

The target: a two-peaked density on the line, known only **up to a constant**, as in real problems.

```text
p̃(z) = exp(−(z − 2)²) + 0.5·exp(−(z + 2)² / 0.5)
```

Its true normalized mean and variance can be computed on a fine grid, so you can check every sampler.

## 1. The target, and the truth

```python
import numpy as np

rng = np.random.default_rng(0)

def p_tilde(z):
    return np.exp(-(z - 2) ** 2) + 0.5 * np.exp(-(z + 2) ** 2 / 0.5)

grid = np.linspace(-8, 8, 200001)
w = p_tilde(grid) / p_tilde(grid).sum()
true_mean = np.sum(w * grid)
true_var = np.sum(w * (grid - true_mean) ** 2)
print(f"true mean {true_mean:.3f}, true variance {true_var:.3f}")
```

```output
true mean 0.955, true variance 3.522
```

## 2. Rejection sampling (14.1.3)

Proposal: a wide Gaussian q with standard deviation 3. Find a k with `k·q(z) ≥ p̃(z)` everywhere (here by checking the grid,
with a little margin).

```python
def q_pdf(z):
    return np.exp(-z ** 2 / 18) / np.sqrt(2 * np.pi * 9)

k = 1.05 * np.max(p_tilde(grid) / q_pdf(grid))
z = rng.normal(0, 3, 200_000)
keep = rng.random(z.size) < p_tilde(z) / (k * q_pdf(z))
samples = z[keep]
print(f"acceptance rate {keep.mean():.3f}   mean {samples.mean():.3f}   variance {samples.var():.3f}")
```

```output
acceptance rate 0.241   mean 0.965   variance 3.501
```

Exact samples, but most proposals are thrown away. In many dimensions this rate would collapse.

## 3. Importance sampling (14.1.5)

Keep every proposal and weight it instead. The weights need only p̃: normalize them by their sum.

```python
z = rng.normal(0, 3, 200_000)
w_is = p_tilde(z) / q_pdf(z)
w_is /= w_is.sum()
mean_is = np.sum(w_is * z)
print(f"importance sampling: mean {mean_is:.3f}   variance {np.sum(w_is * (z - mean_is) ** 2):.3f}")
print(f"effective sample size: {1 / np.sum(w_is ** 2):,.0f} of {z.size:,}")
```

```output
importance sampling: mean 0.955   variance 3.527
effective sample size: 81,625 of 200,000
```

The **effective sample size** says how many equally weighted samples those weighted ones are worth: a quick health
check. If it's tiny, a few samples dominate and the estimate can't be trusted.

## 4. The Metropolis algorithm (14.2.1)

Random-walk proposals, accepted with probability `min(1, p̃(z*)/p̃(z))`. Try a small and a large step size.

```python
def metropolis(step, n=200_000, burn_in=2_000):
    z, chain, accepted = 0.0, np.empty(n), 0
    for i in range(n):
        proposal = z + step * rng.normal()
        if rng.random() < p_tilde(proposal) / p_tilde(z):
            z, accepted = proposal, accepted + 1
        chain[i] = z
    return chain[burn_in:], accepted / n

for step in [0.1, 2.5]:
    chain, rate = metropolis(step)
    print(f"step {step}: acceptance {rate:.2f}   mean {chain.mean():.3f}   variance {chain.var():.3f}")
```

```output
step 0.1: acceptance 0.95   mean 1.735   variance 1.580
step 2.5: acceptance 0.38   mean 0.951   variance 3.529
```

With tiny steps, almost everything is accepted, but the chain crawls and rarely crosses the gap between the peaks, so its
estimates are off. With bigger steps, fewer proposals are accepted but the chain explores both peaks, and the estimates
come out right. Tuning the step size is the everyday craft of MCMC.

## 5. Langevin dynamics (14.3.3)

Only the **score** is needed: `d/dz log p̃(z)`. Compute it by hand here (in part 5 a network will learn it).

```python
def score(z):
    a = np.exp(-(z - 2) ** 2)
    b = 0.5 * np.exp(-(z + 2) ** 2 / 0.5)
    return (a * (-2 * (z - 2)) + b * (-4 * (z + 2))) / (a + b)

eta = 0.01
z = rng.normal(0, 3, 20_000)                 # 20,000 independent particles, started anywhere
for t in range(2000):
    z = z + eta * score(z) + np.sqrt(2 * eta) * rng.normal(size=z.size)
print(f"Langevin: mean {z.mean():.3f}   variance {z.var():.3f}")
print(f"share of particles on the left peak: {np.mean(z < 0):.3f}   (truth: {np.sum(w[grid < 0]):.3f})")
```

```output
Langevin: mean 0.440   variance 4.200
share of particles on the left peak: 0.391   (truth: 0.263)
```

The mean is off, and far too many particles sit on the left peak. What went wrong? Each particle follows the local
gradient, and the valley between the peaks is a barrier: a particle that started near one peak rarely gets pushed over to
the other. In 2,000 steps, the proportions are still mostly those of the starting positions. Run it 10 times longer and
it does settle, but in many dimensions with many peaks that wait becomes hopeless.

## 6. Annealed Langevin: start blurry, sharpen step by step

The fix used by score-based diffusion models: first sample from a **blurred** version of p (p convolved with Gaussian
noise of size σ), where the peaks merge and particles move freely. Then reduce σ step by step, running a little Langevin
at each level, until σ is tiny. For our target, the blurred score is easy to write, because p̃ is a mixture of two
Gaussians: blurring just adds σ² to each component's variance.

```python
means = np.array([2.0, -2.0])
variances = np.array([0.5, 0.25])
weights = np.array([np.sqrt(np.pi), 0.5 * np.sqrt(0.5 * np.pi)])   # the area under each bump of p̃
weights /= weights.sum()

def blurred_score(z, sigma):
    V = variances + sigma ** 2
    comp = weights * np.exp(-(z[:, None] - means) ** 2 / (2 * V)) / np.sqrt(2 * np.pi * V)
    resp = comp / comp.sum(axis=1, keepdims=True)
    return np.sum(resp * (-(z[:, None] - means) / V), axis=1)

z = rng.normal(0, 3, 20_000)
for sigma in np.geomspace(4, 0.01, 12):                 # from very blurry to almost exact
    eta = 0.1 * (0.25 + sigma ** 2)                      # bigger steps while things are blurry
    for t in range(300):
        z = z + eta * blurred_score(z, sigma) + np.sqrt(2 * eta) * rng.normal(size=z.size)
print(f"annealed Langevin: mean {z.mean():.3f}   variance {z.var():.3f}")
print(f"share of particles on the left peak: {np.mean(z < 0):.3f}   (truth: {np.sum(w[grid < 0]):.3f})")
```

```output
annealed Langevin: mean 0.988   variance 3.483
share of particles on the left peak: 0.257   (truth: 0.263)
```

Now the particles are split between the peaks in the right proportions, with 3,600 steps in total. Hold on to this
picture. A diffusion model (part 5) is exactly this: a network that learns the blurred score at every noise level, and a
generator that walks pure noise down through the levels until an image appears.
