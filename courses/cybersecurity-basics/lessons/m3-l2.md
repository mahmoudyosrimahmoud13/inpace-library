# Securing your own devices

Most security starts at home. These habits protect you, and they're exactly what companies ask employees to do.

## 1. Updates

Updates fix known vulnerabilities, and attackers scan for unpatched systems within days of a fix being published.

- Turn on **automatic updates** for the operating system, the browser and apps.
- On Linux: `sudo apt update && sudo apt upgrade` regularly, or enable unattended upgrades.
- Replace devices that no longer get security updates (old phones, old routers).

## 2. Accounts and privileges

- Use a **normal user account** day to day; use administrator rights (sudo, "Run as administrator") only when needed.
- **Lock screen** with a PIN or password, locking after a few minutes.
- Remove accounts and apps you don't use.

## 3. Install software safely

- Only from official stores or the developer's own website.
- **Never cracked software**: it's the number-one source of password-stealing malware.
- Check permissions on phone apps: a flashlight doesn't need your contacts.
- For downloads, check the published **SHA-256** when it's offered.

## 4. Browser hygiene

- Keep the browser updated; it's the program attackers target most.
- Few extensions, from trusted publishers. Extensions can read everything you do.
- Let the password manager fill passwords: it refuses on fake sites, which protects you from phishing.

## 5. Backups: the 3-2-1 rule

Ransomware, theft, a dead disk or a spilled tea: backups make all of them survivable.

- **3** copies of important data
- on **2** different kinds of storage (laptop + external disk)
- with **1** copy offsite or offline (cloud, or a disk at a relative's house)

And: **test a restore**. A backup you've never restored is a hope, not a backup. Keep at least one copy **disconnected**, so ransomware can't encrypt it too.

## 6. Encryption

Turn on full-disk encryption (BitLocker, FileVault, LUKS) and a phone screen lock. Then a lost device is a cost, not a data leak.

## 7. Phones

- Screen lock and biometrics, automatic updates, Find My Device turned on.
- Apps only from the official store; be careful with APKs from unknown sites.
- Don't root or jailbreak your main phone: it removes important protections.

## 8. Privacy settings

Review what your social media shows publicly. Attackers use your job, birthday, family names and travel posts for convincing phishing and for guessing security questions.

## A personal security checklist

- [ ] Password manager set up, important passwords unique
- [ ] MFA on email, bank, social media, GitHub
- [ ] Automatic updates on every device
- [ ] Full-disk encryption on laptop, lock screen on phone
- [ ] 3-2-1 backups, one restore tested
- [ ] Router admin password changed, firmware updated
- [ ] No cracked software
