# Project part 2: a graph network on the karate club

In the 1970s, the sociologist Wayne Zachary recorded the friendships among 34 members of a university karate club. During
his study the club split in two, after a dispute between the instructor ("Mr. Hi") and the president. The graph ships with
the `networkx` library, labelled with which side each member joined.

The challenge: tell the network the side of only **two** people, the instructor and the president, and let it predict
everyone else's from the friendship graph alone.

## 1. The graph

```python
import numpy as np
import networkx as nx
from minigrad import Tensor, Adam, cross_entropy

G = nx.karate_club_graph()
n = G.number_of_nodes()
A = nx.to_numpy_array(G, weight=None)                 # adjacency matrix, 1 where two members are friends
side = np.array([0 if G.nodes[i]["club"] == "Mr. Hi" else 1 for i in range(n)])
print("members:", n, "  friendships:", int(A.sum() / 2), "  members per side:", np.bincount(side))
```

```output
members: 34   friendships: 78   members per side: [17 17]
```

## 2. The normalized adjacency matrix (section 13.2.2)

Add self-loops (each node keeps some of its own features) and normalize by the degrees, so popular members don't
dominate: `Â = D^(−½)(A + I)D^(−½)`.

```python
A_self = A + np.eye(n)
deg = A_self.sum(axis=1)
A_hat = A_self / np.sqrt(deg[:, None] * deg[None, :])
print("row of member 0 (the instructor) touches", int((A_hat[0] > 0).sum()), "members, including himself")
```

```output
row of member 0 (the instructor) touches 17 members, including himself
```

## 3. A two-layer GCN

The members have no other features, so each one's input is just a one-hot vector (the identity matrix). Two layers let
information travel two hops through the friendship graph.

```python
X = np.eye(n)
rng = np.random.default_rng(0)
W1 = Tensor(rng.normal(0, np.sqrt(2 / n), (n, 16)), requires_grad=True)
W2 = Tensor(rng.normal(0, np.sqrt(2 / 16), (16, 2)), requires_grad=True)
Ah = Tensor(A_hat)

def gcn(X):
    hidden = (Ah @ (Tensor(X) @ W1)).relu()          # layer 1: mix with neighbours, transform, ReLU
    return Ah @ (hidden @ W2)                        # layer 2: mix again, one score per side

labelled = np.array([0, 33])                          # the instructor and the president
opt = Adam([W1, W2], lr=0.01)
for step in range(201):
    loss = cross_entropy(gcn(X)[labelled], side[labelled])
    opt.zero_grad()
    loss.backward()
    opt.step()

pred = gcn(X).data.argmax(axis=1)
others = np.setdiff1d(np.arange(n), labelled)
print(f"accuracy on the 32 members it was never told about: {np.mean(pred[others] == side[others]):.3f}")
print("members it got wrong:", np.where(pred != side)[0])
```

```output
accuracy on the 32 members it was never told about: 0.969
members it got wrong: [8]
```

From two labels and the friendship graph, it gets all but one member right. The training loss only ever saw two nodes;
the graph carried the rest. (The member it misses, number 9 when counting from 1 as Zachary did, is the famous
borderline case of this data set: Zachary's own analysis of the network placed this member on the wrong side too.)

## 4. Permutation equivariance (section 13.1.3)

Renumber the members at random. The predictions should be renumbered in exactly the same way.

```python
perm = np.random.default_rng(1).permutation(n)
P = np.eye(n)[perm]
Ah_saved = Ah
Ah = Tensor(P @ A_hat @ P.T)                          # the same graph, new numbering
out_perm = gcn(P @ X).data                            # each member keeps their own features, in the new order
Ah = Ah_saved
print("predictions renumbered the same way:", np.allclose(out_perm, gcn(X).data[perm]))
```

```output
predictions renumbered the same way: True
```

The renumbering doesn't change a single prediction, only their order: the adjacency matrix becomes `P Â Pᵀ` and the
feature matrix becomes `P X`, exactly as in section 13.1.3.

## 5. Over-smoothing (section 13.3.4)

Apply the averaging step many times, with no learning at all, and watch every member's vector become the same.

```python
H = np.random.default_rng(2).normal(size=(n, 8))
for layers in [1, 2, 5, 20, 100]:
    Hk = np.linalg.matrix_power(A_hat, layers) @ H
    Hk = Hk / np.linalg.norm(Hk, axis=1, keepdims=True)
    spread = np.mean(np.linalg.norm(Hk - Hk.mean(axis=0), axis=1))
    print(f"{layers:3d} rounds of averaging: average distance between members' (normalized) vectors {spread:.3f}")
```

```output
  1 rounds of averaging: average distance between members' (normalized) vectors 0.866
  2 rounds of averaging: average distance between members' (normalized) vectors 0.729
  5 rounds of averaging: average distance between members' (normalized) vectors 0.450
 20 rounds of averaging: average distance between members' (normalized) vectors 0.081
100 rounds of averaging: average distance between members' (normalized) vectors 0.000
```

After a hundred rounds, all members look almost identical: the representation has forgotten who is who. That's why deep
GNNs need residual connections, or simply few layers.
