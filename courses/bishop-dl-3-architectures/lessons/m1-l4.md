# Build: convolution, equivariance and pooling in NumPy

## 1. A convolution, written out

Slide a 3 × 3 filter over an image and take a weighted sum at each position (no flip, as in neural networks).

```python
import numpy as np
from sklearn.datasets import load_digits

def conv2d_simple(img, kernel):
    k = kernel.shape[0]
    H, W = img.shape
    out = np.zeros((H - k + 1, W - k + 1))
    for i in range(out.shape[0]):
        for j in range(out.shape[1]):
            out[i, j] = np.sum(img[i:i + k, j:j + k] * kernel)
    return out

digit = load_digits().images[0] / 16.0         # an 8 × 8 picture of a zero
vertical_edges = np.array([[1, 0, -1],
                           [1, 0, -1],
                           [1, 0, -1]], dtype=float)
fmap = conv2d_simple(digit, vertical_edges)
print("image (×10, rounded):\n", np.round(digit * 10).astype(int))
print("feature map, shape", fmap.shape, ":\n", np.round(fmap, 1))
```

```output
image (×10, rounded):
 [[0 0 3 8 6 1 0 0]
 [0 0 8 9 6 9 3 0]
 [0 2 9 1 0 7 5 0]
 [0 2 8 0 0 5 5 0]
 [0 3 5 0 0 6 5 0]
 [0 2 7 0 1 8 4 0]
 [0 1 9 3 6 8 0 0]
 [0 0 4 8 6 0 0 0]]
feature map, shape (6, 6) :
 [[-2.1 -1.7  0.9  0.2  0.4  1.7]
 [-2.5 -0.6  1.9 -1.1 -0.7  2.1]
 [-2.2  0.6  2.2 -1.6 -1.5  1.8]
 [-1.9  0.8  1.9 -1.8 -1.4  1.8]
 [-2.1  0.4  1.4 -1.8 -0.2  2.1]
 [-1.9 -0.8  0.6 -0.4  0.9  1.5]]
```

The output is 6 × 6: 8 − 3 + 1 (section 10.2.3). It's large and positive where brightness drops from left to right
(the right side of the ring) and large and negative where it rises (the left side): a vertical-edge detector.

## 2. Same padding

Pad one row and column of zeros on every side to keep the size: 8 + 2·1 − 3 + 1 = 8.

```python
padded = np.pad(digit, 1)
print("padded size:", padded.shape, " feature map size:", conv2d_simple(padded, vertical_edges).shape)
```

```output
padded size: (10, 10)  feature map size: (8, 8)
```

## 3. Translation equivariance

Shift the image one pixel to the right. The feature map shifts one pixel to the right too, and is otherwise unchanged.

```python
shifted = np.roll(np.pad(digit, 1), 1, axis=1)        # pad first, so nothing wraps around the edge
a = conv2d_simple(np.pad(digit, 1), vertical_edges)
b = conv2d_simple(shifted, vertical_edges)
print("shifted map equals the original map moved one pixel right:",
      np.allclose(b[:, 1:], a[:, :-1]))
```

```output
shifted map equals the original map moved one pixel right: True
```

## 4. Pooling gives a little invariance

2 × 2 max pooling keeps the largest value in each block. Compare how much the feature map and the pooled map change when
the input moves by one pixel.

```python
def max_pool(fm):
    H, W = fm.shape
    return fm[:H // 2 * 2, :W // 2 * 2].reshape(H // 2, 2, W // 2, 2).max(axis=(1, 3))

def change(u, v):
    return np.abs(u - v).sum() / np.abs(u).sum()

print(f"feature map changed by {change(a, b):.0%} after the shift")
print(f"pooled map changed by  {change(max_pool(a), max_pool(b)):.0%}")
```

```output
feature map changed by 117% after the shift
pooled map changed by  75%
```

A one-pixel shift changes the raw feature map completely (more than 100%, because the values land in different places).
The pooled map changes less, because a value that moves within its 2 × 2 block still wins the same block. Pooling
helps, but it's far from full invariance. Tomorrow you'll measure the effect on a whole trained network.

## 5. Count the parameters

A convolutional layer's parameter count doesn't depend on the image size. Compare with a fully connected layer producing
an output of the same size.

```python
C_in, C_out, k, H = 3, 64, 3, 200
conv_params = C_out * (C_in * k * k + 1)
dense_params = (C_in * H * H) * (C_out * H * H)
print(f"3×3 convolution, 3 → 64 channels: {conv_params:,} parameters")
print(f"fully connected layer, same input and output sizes: {dense_params:,} parameters")
```

```output
3×3 convolution, 3 → 64 channels: 1,792 parameters
fully connected layer, same input and output sizes: 307,200,000,000 parameters
```

That's parameter sharing at work: about 1,800 numbers instead of about 300 billion.
