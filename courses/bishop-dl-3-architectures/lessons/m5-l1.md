# Big project: a transformer that sorts

Today you build a GPT-style decoder transformer (section 12.3.1) on your own library, and train it on a task where every
output depends on the **whole** input: sorting a list of digits.

## The task, as a language

Each training example is a sequence of 13 tokens: six random digits, a separator token `|`, then the same digits sorted.

```text
9 5 7 5 1 5 | 1 5 5 5 7 9
```

The model reads the sequence left to right and is trained to predict each next token, exactly like a language model.
We only score its predictions on the sorted half: predicting the random digits is impossible, and pointless.

To sort, the model must, at each output position, look back at the input digits and find the next smallest one it
hasn't written yet. That needs **attention** over the whole input; a bigram model could never do it.
