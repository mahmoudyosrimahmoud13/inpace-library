# Read: inside trained CNNs, detection, segmentation and style transfer (10.3–10.6)

Read sections 10.3 to 10.6 to the end of the chapter (pages 302 to 324). This half of the chapter is lighter: it's a
tour of what CNNs can do. Read for ideas, not derivations.

## Looking inside (10.3)

- **Visual cortex** (10.3.1): the original inspiration. Simple and complex cells in the brain respond to oriented edges,
  much like the first layer of a CNN.
- **Trained filters** (10.3.2): first-layer filters learn edge and colour detectors; deeper layers respond to textures,
  parts, then whole objects.
- **Saliency maps** (10.3.3): the gradient of a class score with respect to the input pixels shows which pixels mattered.
  Your autodiff can compute it: it's just backpropagation all the way to the image.
- **Adversarial attacks** (10.3.4): a change to the pixels too small for a person to see can flip the network's answer,
  if it's chosen along the gradient. A sobering reminder that CNNs don't see the way we do.
- **Synthetic images** (10.3.5): run gradient *ascent* on the input to make an image a unit loves.

## Object detection (10.4)

Not just "what" but "where". Learn the vocabulary: **bounding boxes**, **intersection-over-union** (overlap ÷ union, used
to score a predicted box), **sliding windows** (cheap with convolutions, because neighbouring windows share computation),
**detection across scales**, **non-max suppression** (keep the best of several overlapping boxes), and the idea behind
fast region-based CNNs.

## Image segmentation (10.5)

Label **every pixel**. The network must shrink the image to understand it, then grow it back: **up-sampling** and
transpose convolutions, **fully convolutional** networks, and the **U-net**, whose skip connections carry fine detail from
the shrinking half to the growing half. Remember the U-net: it's the standard network inside diffusion models (part 5).

## Style transfer (10.6)

Optimize an image so that its deep features match one picture's **content** and another's **style** (texture
statistics). A playful idea with a serious point: different layers of a CNN capture different kinds of information.
