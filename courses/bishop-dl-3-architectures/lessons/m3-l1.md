## The problem attention solves

Take the word "bank" in "I swam to the bank" and "I paid at the bank". The right representation of a word depends on
the **other words around it**. A transformer layer takes a set of N token vectors (the rows of a matrix X) and produces
N new vectors in which each token has gathered information from the others (12.1.1).

## Building it up (12.1.2 to 12.1.5)

The book builds attention in careful steps. Follow them in order:

1. **Attention coefficients** (12.1.2): each output yₙ is a weighted average of all the inputs, `yₙ = Σₘ aₙₘ xₘ`, with
   weights that are positive and add up to 1.
2. **Self-attention** (12.1.3): choose the weights from how similar tokens are: a softmax of the dot products
   `xₙᵀxₘ`. In the language of information retrieval, each token sends out a **query**, compares it with every token's
   **key**, and collects their **values**.
3. **Learnable parameters** (12.1.4): with no parameters, there's nothing to learn. So compute queries, keys and values
   with three learned matrices: `Q = XW⁽q⁾`, `K = XW⁽k⁾`, `V = XW⁽v⁾`. Then

```text
Y = Softmax[ Q Kᵀ ] V
```

4. **Scaling** (12.1.5): with D-dimensional vectors, dot products grow like √D, which pushes the softmax into a region
   where it's almost one-hot and its gradients vanish. Divide by √D:

```text
Y = Softmax[ Q Kᵀ / √D ] V
```

## Multi-head attention and the transformer layer (12.1.6–12.1.7)

One attention pattern can only capture one kind of relationship. Use H **heads** in parallel, each with its own smaller
Q, K, V matrices, then concatenate the results and mix them with one more matrix. A **transformer layer** adds:

- a **residual connection** around the attention (section 9.5),
- **layer normalization** (section 7.4.3),
- a small two-layer **MLP** applied to each token separately, with its own residual connection.

## Cost and position (12.1.8–12.1.9)

- **Complexity**: attention compares every pair of tokens, so it costs N² in the sequence length. That's why long contexts
  are expensive.
- **Positional encoding**: attention by itself ignores order. Permute the input tokens and the outputs are permuted the same
  way (it's **permutation equivariant**): "dog bites man" and "man bites dog" would look the same. So add a vector to
  each token that depends on its position. The book discusses the sinusoidal encoding; learned position vectors also work.
