# Read: graph neural networks (chapter 13)

Read all of chapter 13 (pages 407 to 428). It's short, and it ties together everything you've seen: convolution,

## Data on graphs (13.1)

Molecules (atoms and bonds), social networks (people and friendships), road maps, citation networks. A graph has
**nodes** with feature vectors and **edges** between them, written as an **adjacency matrix** A (13.1.2): `A[n, m] = 1`
when n and m are connected.

The key constraint (13.1.3): the order in which we number the nodes is arbitrary. Renumbering them (a permutation matrix
P) changes A into `PAPᵀ` and the feature matrix X into `PX`, but it's the same graph. So:

- a network that predicts something **per node** must be **permutation equivariant**: renumber the nodes and the
  predictions are renumbered the same way;
- a network that predicts something about the **whole graph** must be **permutation invariant**.

## Neural message passing (13.2)

The book starts from convolutions on images (13.2.1): a pixel's new value depends on itself and its neighbours, with
shared weights. On a graph, neighbours have no fixed order or count, so use an operation that doesn't care: **aggregate**
the neighbours' messages with a sum, mean or maximum (13.2.3), then **update** the node (13.2.4). One layer:

```text
zₙ_new = Update( zₙ , Aggregate({ zₘ : m is a neighbour of n }) )
```

**Graph convolutional networks** (13.2.2) are a simple, popular case: average the features of a node and its neighbours,
with degree normalization, then a shared linear layer and a non-linearity. In matrix form:

Each layer spreads information one more hop. Read how the same layers serve **node** classification (13.2.5), **edge**
classification (13.2.6) and **graph** classification (13.2.7, add a final invariant pooling over all nodes).

## Going further (13.3)

- **Graph attention networks** (13.3.1): weight neighbours by learned attention instead of fixed degree normalization.
  A transformer is just a graph network on a **fully connected** graph!
- **Edge and graph embeddings** (13.3.2–13.3.3): give edges and the whole graph their own learned vectors too.
- **Over-smoothing** (13.3.4): stack too many layers and every node's representation becomes the same average of the
  whole graph. Residual connections help.
- **Geometric deep learning** (13.3.6): the unifying view. CNNs, transformers and GNNs are all built by asking which
  symmetries of the data (translations, permutations) the network should respect.
