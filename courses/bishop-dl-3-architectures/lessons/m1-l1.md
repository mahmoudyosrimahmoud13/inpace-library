# Start here

This is part 3 of 5 of the course series on **Deep Learning: Foundations and Concepts** by Christopher M. Bishop and
Hugh Bishop (Springer, 2024). Part 3 covers the three great architectures: **convolutional networks** for images
(chapter 10), **transformers** for sequences and language (chapter 12) and **graph neural networks** (chapter 13).
Chapter 11 comes in part 4, with the other probabilistic models.

## Get the book

As before: each **Read** lesson opens the right pages of *your own copy* (the Springer PDF; or read free online at
[bishopbook.com](https://www.bishopbook.com) using the section numbers in each title). On this course's page, press
**Find it for me** in the box **"This course reads a book you get yourself"**.

## Before you start

You need **part 2**, and especially your **minigrad** library. This course adds three things to it: a convolution
operation, layer normalization, and attention. The updated library is in this course's files as `minigrad.py`; your
day-7 version from part 2 is the starting point.

## The big projects

You'll build all three architectures on your own library, in NumPy:

1. **A convolutional network** that reads handwritten digits, compared with part 2's fully connected network when the
   digits move by one pixel, and trained with data augmentation (section 9.1.3) to be robust to shifts.
2. **A small decoder transformer** that learns to **sort** lists of digits, written token by token like a language model,
   with causal attention you can look inside.
3. **A graph convolutional network** that predicts which side each member of a club took in a famous split, from just two
   labelled people.

## Module projects for your CV

On top of the big projects, **every module ends with a real project in PyTorch** that you build and publish on GitHub:

- a CIFAR-10 image classifier, then a look inside it (filters, saliency maps) and an adversarial attack that fools it;
- a transformer written from scratch that reads movie reviews, honestly compared with a simple baseline;
- a character-level GPT trained on Shakespeare, measured in bits per character against the compressors of part 1;
- a graph convolutional network that classifies research papers from their words and citations.

Each project lesson comes with a notebook (attached to the lesson; on the website it opens in Google Colab) and the
finished code under `projects/` in the course files. Every dataset the projects use is also in one separate download, [bishop-datasets.zip](https://github.com/mahmoudyosrimahmoud13/inpace-library/releases/download/bishop-datasets-v1/bishop-datasets.zip) (239 MB, with a README saying which files go with which project), for working offline. For the projects: `pip install torch pandas pyarrow pillow
matplotlib numpy`. A GPU is not needed: every project trains on a laptop CPU in 2 to 15 minutes (much faster in Colab).
