# Build: self-attention step by step

Build attention in NumPy exactly in the book's order, then check its properties.

## 1. Attention with no parameters (12.1.3)

Four tokens, each a 4-dimensional vector. The first two are similar to each other, and so are the last two.

```python
import numpy as np

def softmax(a, axis=-1):
    a = a - a.max(axis=axis, keepdims=True)
    e = np.exp(a)
    return e / e.sum(axis=axis, keepdims=True)

X = np.array([[1.0, 0.9, 0.0, 0.0],
              [0.9, 1.0, 0.1, 0.0],
              [0.0, 0.1, 1.0, 0.8],
              [0.0, 0.0, 0.8, 1.0]])
A = softmax(X @ X.T)                       # attention coefficients: each row adds up to 1
print("attention matrix:\n", np.round(A, 2))
print("row sums:", A.sum(axis=1))
Y = A @ X
```

```output
attention matrix:
 [[0.43 0.42 0.08 0.07]
 [0.42 0.42 0.08 0.07]
 [0.09 0.1  0.42 0.4 ]
 [0.08 0.09 0.41 0.42]]
row sums: [1. 1. 1. 1.]
```

Each token attends mostly to itself and its similar partner: tokens 1 and 2 form one group, 3 and 4 another.

## 2. Queries, keys and values (12.1.4–12.1.5)

Now with learned matrices (random here), and the 1/√D scaling.

```python
rng = np.random.default_rng(0)
D = 4
Wq, Wk, Wv = (rng.normal(0, 1, (D, D)) for _ in range(3))

def attention(X, Wq, Wk, Wv, mask=None):
    Q, K, V = X @ Wq, X @ Wk, X @ Wv
    scores = Q @ K.T / np.sqrt(K.shape[1])
    if mask is not None:
        scores = scores + mask
    A = softmax(scores)
    return A @ V, A

Y, A = attention(X, Wq, Wk, Wv)
print("output shape:", Y.shape)
print("attention matrix:\n", np.round(A, 2))
```

```output
output shape: (4, 4)
attention matrix:
 [[0.52 0.41 0.03 0.04]
 [0.53 0.4  0.03 0.03]
 [0.18 0.16 0.27 0.4 ]
 [0.15 0.13 0.29 0.43]]
```

## 3. Why divide by √D?

Dot products of random vectors grow with their length. Without scaling, the softmax becomes almost one-hot.

```python
for D in [4, 64, 1024]:
    q, k = rng.normal(size=(D,)), rng.normal(size=(8, D))
    raw = softmax(k @ q)
    scaled = softmax(k @ q / np.sqrt(D))
    print(f"D = {D:4d}: largest weight without scaling {raw.max():.3f}, with scaling {scaled.max():.3f}")
```

```output
D =    4: largest weight without scaling 0.685, with scaling 0.419
D =   64: largest weight without scaling 1.000, with scaling 0.623
D = 1024: largest weight without scaling 1.000, with scaling 0.608
```

At D = 1024, the unscaled softmax puts almost all the weight on one token. Its gradient is then nearly zero, and learning
stalls (section 12.1.5).

## 4. Attention ignores order

Shuffle the tokens: the outputs come out shuffled the same way. Attention is **permutation equivariant** (section
12.1.9).

```python
perm = [2, 0, 3, 1]
Y_perm, _ = attention(X[perm], Wq, Wk, Wv)
print("shuffled inputs give shuffled outputs:", np.allclose(Y_perm, Y[perm]))
```

```output
shuffled inputs give shuffled outputs: True
```

## 5. Positional encoding

Add a different vector to each position so order matters. The sinusoidal encoding uses sines and cosines of different
frequencies.

```python
def positional_encoding(N, D):
    pos = np.arange(N)[:, None]
    i = np.arange(D // 2)[None, :]
    angle = pos / 10000 ** (2 * i / D)
    pe = np.zeros((N, D))
    pe[:, 0::2], pe[:, 1::2] = np.sin(angle), np.cos(angle)
    return pe

P = positional_encoding(4, 4)
Y1, _ = attention(X + P, Wq, Wk, Wv)
Y2, _ = attention(X[perm] + P, Wq, Wk, Wv)
print("still just a shuffle once positions are added?", np.allclose(Y2, Y1[perm]))
```

```output
still just a shuffle once positions are added? False
```

With positions added, shuffling the words really changes the result: now "dog bites man" and "man bites dog" differ.

## 6. A causal mask

A language model must not look at future tokens. Add −∞ (in practice a very large negative number) above the diagonal
before the softmax.

```python
N = 4
mask = np.triu(np.full((N, N), -1e9), k=1)
_, A = attention(X, Wq, Wk, Wv, mask=mask)
print(np.round(A, 2))
```

```output
[[1.   0.   0.   0.  ]
 [0.57 0.43 0.   0.  ]
 [0.29 0.26 0.45 0.  ]
 [0.15 0.13 0.29 0.43]]
```

Row n only has weights on tokens 1 to n: token 1 can only see itself, token 4 sees everything before it.

## 7. Multiple heads

Split D into H heads of size D / H, attend in each, and concatenate. The trick is a reshape and a transpose, which is how
you'll write it in minigrad.

```python
def multi_head(X, Wq, Wk, Wv, H):
    N, D = X.shape
    def split(M):                                  # (N, D) -> (H, N, D/H)
        return M.reshape(N, H, D // H).transpose(1, 0, 2)
    Q, K, V = split(X @ Wq), split(X @ Wk), split(X @ Wv)
    A = softmax(Q @ K.transpose(0, 2, 1) / np.sqrt(D // H))     # (H, N, N): one attention matrix per head
    out = (A @ V).transpose(1, 0, 2).reshape(N, D)              # back to (N, D)
    return out, A

out, A = multi_head(X, Wq, Wk, Wv, H=2)
print("output:", out.shape, "  attention matrices:", A.shape)
```

```output
output: (4, 4)   attention matrices: (2, 4, 4)
```

Two heads, two different 4 × 4 attention patterns over the same tokens.
