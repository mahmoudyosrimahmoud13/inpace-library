# جهّز المستودع باحتراف

يفتح المراجعون مستودعك قبل أن يقرؤوا كودك. فاجعل أول 30 ثانية جيدة:

```text
docanswer/
  docanswer/          the package: ingest.py, search.py, answer.py, api.py
  evals/              golden sets and evaluation scripts
  tests/              pytest tests
  data/raw/           your documents (or a script that downloads them)
  .env.example        the settings, with fake values
  requirements.txt
  Dockerfile
  README.md
```

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install pypdf rank_bm25 sentence-transformers openai fastapi uvicorn httpx pytest
pip freeze > requirements.txt
git init && git add . && git commit -m "Project skeleton"
```

## اختر نموذجك بتكلفة قليلة

يتحدث الكود في هذه الدورة مع أي واجهة **متوافقة مع OpenAI**، تختارها بثلاثة إعدادات في `.env`، فتغيّرها دون تغيير الكود:

```bash
# .env.example: copy to .env and never commit .env
# Free and local, with Ollama (ollama.com): ollama pull llama3.1
LLM_BASE_URL=http://localhost:11434/v1
LLM_API_KEY=ollama
LLM_MODEL=llama3.1
# Or a hosted API: leave LLM_BASE_URL empty for OpenAI and set your key and model
```

أضف `.env` و`.venv/` و`data/*.npy` إلى `.gitignore` الآن. فمفتاح API المسرّب في مستودع عام تكتشفه البرامج الآلية خلال دقائق، وهو نوع الأخطاء الذي يتذكره المراجعون.
