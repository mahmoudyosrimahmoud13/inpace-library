# قيّم الإجابات

أنشئ مجموعة ذهبية ثانية `evals/answers.jsonl`: 40 سؤالًا مع إجابة مرجعية قصيرة، و10 أسئلة **لا** تستطيع المستندات الإجابة عنها، ومرجعها جملة الرفض. ثم قيّم كل إجابة بـ **نموذج حَكَم** (LLM judge) في أمرين: *صحيحة* (توافق المرجع) و*أمينة* (كل ادعاء فيها تدعمه المصادر).

```python
# evals/eval_answers.py
"""LLM-as-judge on the golden set: is each answer correct, and is every claim supported by its sources?"""
import json

from docanswer.answer import MODEL, REFUSAL, answer, client
from docanswer.search import Searcher

JUDGE = """You grade an answer from a document assistant.
Question: {question}
Reference answer: {reference}
Sources the assistant saw:
{sources}
Assistant answer: {answer}
Reply with JSON only: {{"correct": true or false, "faithful": true or false, "reason": "one sentence"}}
correct: it agrees with the reference answer. faithful: every claim is supported by the sources."""


def judge(row, result):
    if row["reference"] == REFUSAL:                       # unanswerable questions: the right answer is a refusal
        ok = result["answer"].startswith("I don't have")
        return {"correct": ok, "faithful": ok, "reason": "should refuse"}
    reply = client.chat.completions.create(
        model=MODEL, temperature=0, response_format={"type": "json_object"},
        messages=[{"role": "user", "content": JUDGE.format(question=row["question"], reference=row["reference"],
                                                          sources=result["sources"], answer=result["answer"])}])
    return json.loads(reply.choices[0].message.content)


def run(golden, searcher):
    grades = [judge(row, answer(row["question"], searcher)) for row in golden]
    n = len(grades)
    return {"correct": sum(g["correct"] for g in grades) / n, "faithful": sum(g["faithful"] for g in grades) / n,
            "failures": [(row["question"], g["reason"]) for row, g in zip(golden, grades) if not g["correct"]]}


if __name__ == "__main__":
    golden = [json.loads(line) for line in open("evals/answers.jsonl", encoding="utf-8")]
    print(json.dumps(run(golden, Searcher()), indent=2, ensure_ascii=False))
```

## لا تثق بالحَكَم ثقة عمياء

الحَكَم نموذج أيضًا ويخطئ. وقبل أن تثق بأرقامه، قيّم 30 إجابة بنفسك وقارن، واذكر **نسبة الاتفاق**. وإن كانت منخفضة فاجعل أمر الحَكَم أكثر صرامة أو أعطه أمثلة. ويؤكد ممارسون مثل هامل حسين ([Your AI Product Needs Evals](https://hamel.dev/blog/posts/evals/)) هذا بالضبط: انظر إلى بياناتك، واجعل الحكام الآليين متوافقين مع حكم البشر.
