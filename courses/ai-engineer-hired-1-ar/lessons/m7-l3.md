# LinkedIn وGitHub يعملان لصالحك

## LinkedIn

- **العنوان:** الوظيفة التي تريدها مع دليلك، مثل «AI Engineer · RAG and evaluation · Python, FastAPI, Docker». لا «طالب» ولا «أبحث عن فرص».
- **النبذة:** 3 فقرات قصيرة: ماذا تبني، وأفضل مشروع لك برقم واحد، وما الذي تبحث عنه.
- **المميز (Featured):** العرض الحي لـ DocAnswer ومستودعه.
- **Open to work** مرئي للمسؤولين عن التوظيف فقط إن كنت موظفًا.
- **انشر ما بنيته:** ملخصًا قصيرًا لما تعلمته مع جدول التقييم. وينقل الدليل عن مهندسين حصلوا على مقابلات بالبناء العلني.

## GitHub

- ملف README للحساب: سطر عنك وروابط لأفضل 2 إلى 3 مشاريع.
- **ثبّت** أفضل مستودعاتك، وأرشف الدروس غير المكتملة أو أخفها.
- كل مستودع مثبّت: README واضح، وCI ناجح، ولا أسرار، وترخيص.
- الالتزامات المنتظمة الحقيقية أفضل من نمط المربعات الخضراء. فالمراجعون يفتحون الكود.
