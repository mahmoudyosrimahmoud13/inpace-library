# قِس الاسترجاع قبل التوليد

إن لم تُسترجع القطعة الصحيحة فلن ينقذ أي أمر الإجابة. ابنِ **مجموعة ذهبية**: أسئلة، لكل منها معرّف القطعة التي فيها الإجابة.

1. اكتب 30 سؤالًا بنفسك من احتياجات مستخدمين حقيقيين، وابحث عن قطعة إجابة كل منها.
2. أضف 30 أخرى باختيار قطع عشوائية وكتابة سؤال تجيب عنه كل قطعة (يمكنك صياغة مسودتها بنموذج لغوي ثم تصحيحها بيدك، فأسئلة النموذج تنسخ كلمات القطعة وتجعل البحث يبدو أفضل مما هو).
3. احفظها في `evals/retrieval.jsonl`: `{"question": "...", "chunk_id": "handbook.pdf:12:0"}`.

```python
# evals/eval_retrieval.py
"""Hit rate@k and MRR on the golden set: each question names the chunk that holds its answer."""
import json

from docanswer.search import Searcher


def evaluate(searcher, golden, k=5):
    hits, reciprocal = 0, 0.0
    for row in golden:
        ids = [c["id"] for c in searcher.search(row["question"], k=k)]
        if row["chunk_id"] in ids:
            hits += 1
            reciprocal += 1 / (ids.index(row["chunk_id"]) + 1)
    return {"hit_rate": round(hits / len(golden), 3), "mrr": round(reciprocal / len(golden), 3)}


if __name__ == "__main__":
    golden = [json.loads(line) for line in open("evals/retrieval.jsonl", encoding="utf-8")]
    print(evaluate(Searcher(), golden))
```
