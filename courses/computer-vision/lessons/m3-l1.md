# Convolutional neural networks

Hand-made filters find edges. But which filters find a cat's ear, a tumour or a scratch? A **convolutional neural network (CNN)** learns its own filters from labelled examples.

```mermaid
flowchart LR
    I[image 224×224×3] --> C1[conv + ReLU<br/>edges, colours]
    C1 --> P1[pool: halve size]
    P1 --> C2[conv + ReLU<br/>textures, corners]
    C2 --> P2[pool]
    P2 --> C3[conv + ReLU<br/>parts: eyes, wheels]
    C3 --> G[global average]
    G --> F[fully connected]
    F --> O[class probabilities]
```

## The layers

- **Convolution layer:** many learned kernels (say 64 of 3×3×channels) slide over the input; each produces a **feature map** showing where its pattern appears. Weights are shared across positions, so a pattern is found anywhere in the image with few parameters.
- **ReLU:** sets negatives to zero, adding the non-linearity that lets stacked layers learn complex shapes.
- **Pooling** (or stride 2): halves width and height, so later layers see larger areas (a bigger **receptive field**).
- **Classifier head:** turns the final features into class scores; softmax gives probabilities.

Early layers learn edges and colours; middle layers textures and parts; late layers whole objects.

## Counting shapes and parameters

```python
def conv_out(size, kernel, stride=1, pad=0):
    return (size + 2 * pad - kernel) // stride + 1

size, channels, params = 224, 3, 0
for out_ch in [32, 64, 128]:
    params += 3 * 3 * channels * out_ch + out_ch        # weights + biases of a 3×3 conv
    size = conv_out(size, 3, pad=1)                     # 'same' padding keeps the size
    size = conv_out(size, 2, stride=2)                  # 2×2 pooling halves it
    channels = out_ch
    print(f"after block: {size}×{size}×{channels}")
print("conv parameters:", params)                       # about 93 thousand
print("one dense layer on the raw image would need:", 224 * 224 * 3 * 128)
```

Three conv blocks need about 93 thousand weights; one fully connected layer from the raw image to 128 units would need 19 million. Weight sharing is why CNNs made vision practical.

## Training

Like any network: show labelled images, measure the loss, update weights by gradient descent. Two habits matter most in practice:

- **Data augmentation:** random crops, flips, colour changes and small rotations, so the model learns the object, not the photo.
- **Transfer learning:** start from a network pretrained on a big dataset (ImageNet's 1.2 million images, or larger) and fine-tune it on your few thousand images. This is almost always better than training from scratch.
