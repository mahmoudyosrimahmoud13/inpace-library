# Project 3: a CNN that tells coin from background

You'll train a small convolutional network on patches of the photo, labelled automatically by day 2's pipeline, and
compare it with a simple brightness rule.

The code is above this text. Save it as `p3_cnn.py`. It needs PyTorch.

## Read the code

- **`patches()`** cuts 24 × 24 patches every 4 pixels. A patch whose centre is deep inside a coin is labelled 1; far
  from any coin, 0. Patches near an edge are skipped, because their label would be a guess. This is how you get
  training data without labelling by hand: from a pipeline you trust, on the easy cases.
- **Train on the left half, test on the right half.** Neighbouring patches overlap, so a random split would test on
  pixels the model trained on. The same leak as a random split on time data.
- **The baseline**: call a patch "coin" if its average brightness is above a threshold chosen on the training
  patches.
- **`CoinNet`**: three small convolution layers with ReLU and pooling, then global average pooling and a linear layer:
  5,954 parameters.
- **`augment()`** flips, turns by 90 degrees and changes brightness (40% to 130%), so the network can't rely on one
  orientation or exposure.

## Run it

```bash
python p3_cnn.py
```

What it shows:

- **The brightness rule is already 96% right**: a strong baseline. Always compute one.
- **CoinNet reaches about 99.9%** on the half it never saw, and gets right all 76 patches the brightness rule got
  wrong: it uses shape and texture, not only brightness.
- Test accuracy wobbles from epoch to epoch (98.2% at epoch 3). With small data, look at the trend, not one epoch.

## Make it yours

1. Train on a random 50% of patches instead of the left half. Is test accuracy higher? Why is that number less
   trustworthy?
2. Remove the augmentation. Then test on patches made 50% darker. What happens?
3. **Transfer learning**: replace CoinNet with a pretrained ResNet-18 from torchvision (resize patches to 64 × 64 and
   repeat the gray channel three times), freeze it and train only the last layer. Is it worth it here?

## What to take away

- Labels can come from a simpler method you trust, on the clear cases.
- Split by space (or time), not at random, when samples overlap.
- Beat a baseline you computed, not 50%.
