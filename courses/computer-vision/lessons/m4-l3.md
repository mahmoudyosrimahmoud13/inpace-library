# Project 4: split touching coins, and build a detector

You'll split touching coins with watershed segmentation, then turn CoinNet into a detector and grade it with IoU,
with and without non-maximum suppression.

The code is above this text. Save it as `p4_detect.py`. It needs `coinnet.pt` from project 3.

## Read the code

- **`split_touching()`**: the **distance transform** gives each coin pixel its distance to the background; each
  coin's centre is a peak. **Watershed** floods outward from each peak until the floods meet, so two touching coins
  become two regions. Their boxes are the "truth" for the detector.
- **`detect()`** runs CoinNet on every position (every 4 pixels), giving a **score map**. Every position confidently
  inside a coin proposes a box sized by its distance to the edge of the high-score area, so each coin gets many
  overlapping boxes, like a real detector's raw output.
- **`iou()`** is intersection over union: 1 for the same box, 0 for no overlap.
- **`nms()`** keeps the best-scoring box, drops every box overlapping it above a threshold, and repeats.
- **`grade()`** matches predicted boxes to true ones at IoU 0.5 or more: right, extra (false positives) and missed.

## Run it

```bash
python p4_detect.py
```

The real output:

```text

2. CoinNet as a detector: 1590 candidate boxes from the score map
   (right = IoU of 0.5 or more with a watershed box)
   no NMS                       1590 boxes: 24 right, 1566 extra, 0 missed
   NMS at IoU 0.5                358 boxes: 24 right, 334 extra, 0 missed
   NMS at IoU 0.3                166 boxes: 24 right, 142 extra, 0 missed
   score >= 10, then NMS 0.3      39 boxes: 24 right, 15 extra, 0 missed
   saved p4_detections.png: the boxes after NMS, and the score map
```

What it shows:

- **Watershed counts all 24 coins**: the two merged pairs from day 2 are split.
- **Without NMS, 1,590 boxes** for 24 coins. NMS cuts them, but small boxes inside a coin overlap a big box too little
  to be removed.
- **A score threshold before NMS** leaves 39 boxes: all 24 coins found, 15 extra. Real detectors work the same way: a
  confidence threshold, then NMS, both tuned on validation data. Precision (24 of 39 right) and recall (24 of 24
  found) are the two numbers to trade.

## Make it yours

1. Tune the score threshold and the NMS threshold to get 0 extra boxes without missing any. Then check the same
   settings on the photo turned 90 degrees.
2. Compute **average precision**: sort boxes by score, compute precision and recall at each, and take the area under
   the curve.
3. Compare with a real detector: run a pretrained YOLO or Faster R-CNN (torchvision) on the photo. What does it call
   the coins, and why?

## What to take away

- Watershed splits touching objects using the distance transform.
- A detector is scores, boxes, a threshold and NMS, graded with IoU, precision and recall.
