# من اليومية إلى ميزان المراجعة في شيت

لنبنِ قلب نظام محاسبي في ملف واحد: يومية وأستاذ وميزان مراجعة يحدّثون أنفسهم.

## الشيت 1: COA (دليل الحسابات)

جدول `COA`: Code | Name | Type (أصل، التزام، حقوق ملكية، إيراد، مصروف) | Normal (مدين أو دائن) | Statement (BS أو IS)

## الشيت 2: Journal (اليومية)

جدول `Journal`، صف لكل سطر من كل قيد:

| Date | Entry | Code | Account | Debit | Credit | Memo |
|---|---|---|---|---|---|---|
| 01/06/2026 | 1 | 1010 | *(معادلة)* | 20,000 | | إيداع المالكة |
| 01/06/2026 | 1 | 3010 | *(معادلة)* | | 20,000 | |

- الحساب: `=XLOOKUP([@Code], COA[Code], COA[Name], "Bad code")`
- فحص لكل قيد في ملخص: `=SUMIFS(Journal[Debit], Journal[Entry], A2)-SUMIFS(Journal[Credit], Journal[Entry], A2)` يجب أن يساوي 0 لكل قيد. والتنسيق الشرطي يجعل غير الصفر أحمر.

التحقّق من البيانات يحافظ على النظافة: Data ← Data Validation ← List ← `=INDIRECT("COA[Code]")` (أو نطاق مسمّى) فلا يُختار إلا كود حقيقي.

## الشيت 3: ميزان المراجعة

اسرد كل الأكواد (`=COA[Code]` أو `=SORT(COA[Code])`)، ثم:

| العمود | المعادلة |
|---|---|
| الاسم | `=XLOOKUP(A2, COA[Code], COA[Name])` |
| إجمالي المدين | `=SUMIFS(Journal[Debit], Journal[Code], A2)` |
| إجمالي الدائن | `=SUMIFS(Journal[Credit], Journal[Code], A2)` |
| رصيد مدين | `=MAX(C2-D2, 0)` |
| رصيد دائن | `=MAX(D2-C2, 0)` |

إجماليات في الأسفل، وفحص: `=SUM(E:E)-SUM(F:F)` يجب أن يساوي 0.

لفترة معيّنة: أضف شرط تاريخ لكل SUMIFS، مع تاريخي البداية والنهاية في خلايا مدخلات:
`=SUMIFS(Journal[Debit], Journal[Code], A2, Journal[Date], ">="&Start, Journal[Date], "<="&End)`

## الشيت 4: أستاذ لأي حساب

اختر حسابًا في خلية (`B1`)، ثم:

`=FILTER(Journal[[Date]:[Memo]], Journal[Code]=B1)`

ورصيد جارٍ بجانبه: المدين ناقص الدائن، تراكميًا. هذه صفحة أستاذ كاملة لأي حساب، بمعادلة واحدة.

## لماذا نبني هذا والبرامج موجودة؟

لأنك ستصدّر باستمرار من برامج المحاسبة (Odoo وQuickBooks وSAP والبرامج المحلية) وتعيد بناء هذه العروض بالضبط لتراجع الأرقام وتعدّلها وتشرحها. فهم البنية يجعل كل تصدير سهل التعامل.

## جرّب بنفسك

ابنِ الشيتات الأربعة وأدخل عمليات نور الإحدى عشرة لشهر يونيو من كورس "المحاسبة من الصفر". ميزان المراجعة يجب أن يكون إجماليه 24,100، وكل فحص قيد صفرًا، وشيت الأستاذ يُظهر النقدية تنتهي عند 9,400.
