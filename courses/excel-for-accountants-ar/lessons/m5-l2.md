# الموازنات وتحليل "ماذا لو"

الشيتات تتألّق في "ماذا لو؟": ماذا لو ارتفعت الأسعار 10%، ماذا لو بعنا أقل بـ 20%؟

## موازنة مبنية على المحرّكات

ضع **المحرّكات** في المدخلات، وليس النتائج أبدًا:

| المدخل | القيمة |
|---|---|
| الكيكات شهريًا (يناير) | 450 |
| النمو الشهري | 5% |
| السعر | 120 |
| التكلفة المتغيّرة للكيكة | 50 |
| التكاليف الثابتة شهريًا | 21,000 |

ثم الأشهر في الأعمدة:

| | يناير | فبراير | مارس |
|---|---|---|---|
| الكيكات | `=Jan_cakes` | `=B2*(1+Growth)` | `=C2*(1+Growth)` |
| المبيعات | `=B2*Price` | ... | |
| التكاليف المتغيّرة | `=B2*VarCost` | ... | |
| المساهمة | `=B3-B4` | ... | |
| التكاليف الثابتة | `=Fixed` | ... | |
| الربح | `=B5-B6` | ... | |

غيّر مدخلًا واحدًا فتتحدّث السنة كلها.

## Goal Seek (البحث عن الهدف): اعمل للخلف

"كم كيكة لربح 7,000؟" Data ← What-If Analysis ← Goal Seek:
- Set cell: خلية الربح
- To value: 7000
- By changing: مدخل الكيكات

الإجابة: 400. (نفس منطق التعادل في كورس "محاسبة التكاليف"، يعمله الشيت.)

## جداول البيانات: إجابات كثيرة مرة واحدة

**جدول بمتغيّر واحد**: الربح لأسعار من 100 إلى 140.

1. اكتب الأسعار في عمود (100، 105، ...، 140).
2. في الخلية فوق القائمة وعلى يمينها، ضع `=Profit`.
3. حدّد النطاق ← Data ← What-If Analysis ← Data Table ← Column input cell: مدخل السعر.

جدول **بمتغيّرين** يُظهر الربح لكل تركيبة من السعر (رأسيًا) والحجم (أفقيًا): خريطة سريعة لأين يربح المشروع.

## السيناريوهات

اعمل ثلاثة أعمدة مدخلات: **متشائم** و**أساسي** و**متفائل** (الحجم، السعر، التكاليف)، وخلية اختيار بقائمة منسدلة. المدخلات النشطة تستخدم:

`=CHOOSE(Scenario, Pess_volume, Base_volume, Opt_volume)`

أو `=XLOOKUP(Scenario_name, ScenarioNames, VolumeRow)`. مفتاح واحد يقلب النموذج كله. اعرض الثلاثة للإدارة، وليس المتفائل وحده أبدًا.

## الحساسية: أي مدخل يهم أكثر؟

غيّر كل مدخل 10% واحدًا تلو الآخر وسجّل التغيّر في الربح. أكبر أثر هو حيث تركّز جهد التوقّع (لنور: السعر، بسبب الرافعة التشغيلية).

## جرّب بنفسك

ابنِ موازنة محرّكات لـ 12 شهرًا لمشروع صغير فيها نمو، ورفع سعر في يوليو، وتعيين جديد في سبتمبر. استخدم Goal Seek لحجم التعادل، وجدول بيانات بمتغيّرين للسعر × الحجم، وثلاثة سيناريوهات بخلية اختيار.
