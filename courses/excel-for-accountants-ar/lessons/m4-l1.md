# التسوية البنكية في إكسل

كل شهر، يجب أن يتفق حساب النقدية عندك مع كشف البنك، بعد مراعاة التوقيت. **التسوية البنكية** تثبت ذلك، وتكشف الأخطاء والاحتيال.

## لماذا يختلفان

| البند | في دفاترك وليس في البنك بعد | في البنك وليس في دفاترك بعد |
|---|---|---|
| إيداعات في الطريق | ✓ (سُجِّلت، والبنك لم يضفها بعد) | |
| شيكات لم تُصرف | ✓ (حُرِّرت ولم تُصرف بعد) | |
| مصاريف بنكية، فوائد | | ✓ |
| تحويلات مباشرة من العملاء | | ✓ |
| أخطاء | في أي طرف | في أي طرف |

## الإعداد

شيت `Books`: أسطر حساب النقدية عندك (Date، Ref، Description، Amount: + داخل، − خارج).
شيت `Bank`: تصدير كشف البنك (Date، Ref، Description، Amount).

نظّف الاثنين أولًا: `TRIM` للأوصاف، وتأكّد أن المبالغ أرقام، وبنفس اتجاه الإشارة.

## المطابقة بـ COUNTIFS

في `Books`، عمود **In bank?**:

`=IF(COUNTIFS(Bank[Amount], [@Amount], Bank[Ref], [@Ref])>0, "Matched", "Open")`

لو المراجع غير موثوقة، طابق بالمبلغ ونطاق تاريخ:

`=IF(COUNTIFS(Bank[Amount], [@Amount], Bank[Date], ">="&[@Date]-3, Bank[Date], "<="&[@Date]+5)>0, "Matched", "Open")`

واعمل نفس الشيء في `Bank` مقابل `Books`. صفِّ "Open" في الطرفين: هذه بنود التسوية. المبالغ المكرّرة (دفعتان بـ 500) تحتاج نظرة بشرية: COUNTIFS تُظهر 2.

## مذكرة التسوية

| | |
|---|---|
| **الرصيد حسب كشف البنك** | 48,300 |
| يُضاف: إيداعات في الطريق | 6,200 |
| يُطرح: شيكات لم تُصرف | (9,100) |
| **رصيد البنك المعدّل** | **45,400** |
| **الرصيد حسب الدفاتر** | 45,520 |
| يُضاف: تحويل عميل لم يُسجَّل | 300 |
| يُطرح: مصاريف بنكية | (120) |
| يُطرح: خطأ (شيك 1,580 سُجِّل 1,280) | (300) |
| **رصيد الدفاتر المعدّل** | **45,400** |

خلية فحص: رصيد البنك المعدّل − رصيد الدفاتر المعدّل = 0.

البنود في **جانب الدفاتر** تحتاج قيود يومية (سجّل التحويل والمصاريف وصحّح الخطأ). أما بنود جانب البنك فتنتظر أن تُسوّى الشهر القادم؛ ولو بقي "إيداع في الطريق" مفتوحًا أسابيع، ابحث.

## اجعلها قالبًا شهريًا

المدخلات: رصيد الكشف ورصيد الدفاتر؛ وقائمة البنود المفتوحة تمتلئ من الشيتين بـ `FILTER`:

`=FILTER(Books, Books[In bank?]="Open")`

الشهر القادم، الصق التصديرات الجديدة وتُعاد التسوية تلقائيًا.

## جرّب بنفسك

اعمل 15 سطر دفاتر و14 سطر بنك لشهر، فيها إيداعان في الطريق، وشيكان لم يُصرفا، ومصاريف بنكية، وتحويل عميل، وخطأ تبديل أرقام. طابقها بـ COUNTIFS وابنِ مذكرة التسوية حتى يصبح الفحص صفرًا. اكتب القيود المطلوبة.
