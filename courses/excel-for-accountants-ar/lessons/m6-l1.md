# البيانات النظيفة والضوابط وPower Query

تصديرات الأنظمة والبنوك فوضوية: مسافات زائدة، أرقام كنصوص، تواريخ بأشكال غريبة، إجماليات مختلطة بالبيانات. التنظيف باليد كل شهر بطيء ومعرّض للأخطاء.

## إصلاحات سريعة بالمعادلات

| المشكلة | الحل |
|---|---|
| مسافات زائدة | `=TRIM(A2)` (و`CLEAN` للحروف الخفية) |
| أرقام مخزّنة كنص | `=VALUE(A2)` أو `=A2*1`، أو Data ← Text to Columns ← Finish |
| أرقام أوروبية "1.234,50" | `=NUMBERVALUE(A2, ",", ".")` |
| تواريخ كنص "31/03/2026" | `=DATE(RIGHT(A2,4), MID(A2,4,2), LEFT(A2,2))` |
| الكود والاسم في خلية "1010 - Cash" | `=TEXTBEFORE(A2, " - ")`، `=TEXTAFTER(A2, " - ")` |
| تكرارات | Data ← Remove Duplicates (على نسخة)، أو `=UNIQUE()` |
| صفوف فارغة | صفِّ الفارغ واحذفه، أو `=FILTER(range, colA<>"")` |

## Power Query: نظّف مرة، وحدّث للأبد

Data ← Get Data ← From File (CSV، Excel، مجلد). محرّر Power Query يسجّل كل خطوة تنظيف:

1. حذف الصفوف العليا (شعار البنك والعناوين)
2. استخدام الصف الأول كعناوين
3. تغيير الأنواع (تاريخ، رقم عشري)
4. Trim للنصوص، استبدال قيم، تقسيم أعمدة
5. استبعاد صفوف الإجماليات
6. Close & Load إلى جدول

الشهر القادم: ضع الملف الجديد في نفس المكان ← Data ← Refresh All. كل الخطوات تعمل من جديد. و**From Folder** تجمع كل الملفات الشهرية في جدول واحد.

Google Sheets ليس فيه Power Query، لكن `IMPORTDATA` و`QUERY` ونفس المعادلات تغطي الحالات البسيطة.

## الضوابط: اجعل الأخطاء ظاهرة

- **خلايا فحص** في كل مكان (المدين = الدائن، الميزانية متوازنة، إجمالي الجدول المحوري = المصدر)، مجمّعة في شيت `Checks` بخلية واحدة "ALL OK": `=IF(AND(check1=0, check2=0), "ALL OK", "CHECK")`.
- **التحقّق من البيانات**: قوائم منسدلة للأكواد والفئات، حدود للتواريخ، أعداد صحيحة فقط.
- **حماية** خلايا المعادلات (Format Cells ← Protection، ثم Review ← Protect Sheet)، مع ترك المدخلات غير مقفلة.
- **الإصدار والملاحظات**: شيت `Readme` يقول ماذا يفعل الملف، ومصادره، ومن حدّثه ومتى.
- **تجنّب الأرقام المكتوبة** داخل المعادلات. ابحث عنها: Ctrl + ` يُظهر المعادلات، وGo To Special ← Constants يجد الأرقام المكتوبة بين المعادلات.

## أخطاء شيتات شائعة للبحث عنها

- نطاق معادلة لا يشمل الصفوف الأخيرة (استخدم الجداول)
- إجمالي يشمل إجماليًا فرعيًا (عدّ مرتين)
- خطأ إشارة (الدائن مضاف كموجب)
- معادلة منسوخة تشير إلى صف خطأ
- ملف مربوط نُقل (Data ← Edit Links)

## جرّب بنفسك

نزّل كشف حساب CSV من بنكك (أو اعمل واحدًا فوضويًا بمسافات وأرقام كنصوص وصف إجمالي). نظّفه بـ Power Query، وحمّله كجدول، وحدّثه بعد إضافة صفوف للـ CSV. أضف شيت Checks بثلاثة فحوص على الأقل.
