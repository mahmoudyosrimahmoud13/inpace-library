# Read: directed graphical models (8.5)

A **directed graphical model** (Bayesian network) draws a joint distribution as a graph: one node per variable, arrows
from "parents" to "children".

- **Factorization**: p(x₁, …, x_K) = ∏ p(x_k | parents(x_k)). Read it straight off the graph.
- **Plate notation**: a box with "N" around a node means "repeat N times" (one per data point).
- **d-separation (8.5.3)**: rules for reading conditional independence off the graph. Learn the three patterns
  (chain a → b → c, fork a ← b → c, collider a → b ← c); the collider is the surprising one: observing b makes a and c
  dependent.
