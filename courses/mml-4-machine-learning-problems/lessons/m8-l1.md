# Read: GMMs and parameter learning by maximum likelihood (11.1–11.2)

**Density estimation**: model where data are likely to be. One Gaussian is too simple for data with several clusters,
so use a **mixture**: p(x) = Σₖ πₖ N(x | μₖ, Σₖ), with weights πₖ ≥ 0 summing to 1.

**Maximum likelihood (11.2)** has no closed form: the log of a **sum** doesn't split. But setting the gradient to zero
gives three update rules that depend on **responsibilities**:

- **Responsibility** r_nk = πₖN(xₙ | μₖ, Σₖ) / Σⱼ πⱼN(xₙ | μⱼ, Σⱼ): how much component k "explains" point n (soft
  assignment, a posterior probability).
- **Means** (11.2.2): μₖ = Σₙ r_nk xₙ / N_k, with N_k = Σₙ r_nk. A weighted average.
- **Covariances** (11.2.3): weighted covariance of the points around μₖ.
- **Weights** (11.2.4): πₖ = N_k / N.

The responsibilities depend on the parameters and the parameters on the responsibilities. That circularity is solved
by iterating (tomorrow's EM view, but you can already try it below).
