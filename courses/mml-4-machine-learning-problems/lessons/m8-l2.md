# Read: the EM algorithm and the latent variable view (11.3–11.5)

**EM (11.3)** alternates two steps until the log-likelihood stops improving:

- **E-step**: compute the responsibilities with the current parameters.
- **M-step**: update means, covariances and weights with the formulas above.

![EM on three clusters, and the log-likelihood rising every round](gmm_em.png)

- The log-likelihood **never decreases** from one round to the next. EM can still stop at a **local** optimum, so run it
  from several starts.
- A component can collapse onto a single point (variance → 0, likelihood → ∞); in practice add a small value to the
  covariance diagonal.

**Latent variable view (11.4)**: introduce a hidden one-hot z saying which component generated each point. Then
p(x) = Σ_z p(x | z)p(z), the responsibilities are the posterior p(z | x), and EM maximizes a lower bound on the
log-likelihood. k-means is the limit of EM with tiny, equal, spherical covariances and hard assignments.
