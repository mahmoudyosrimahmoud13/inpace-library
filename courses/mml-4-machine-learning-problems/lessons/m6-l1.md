# Read: PCA problem setting and maximum variance (10.1–10.2)

**Principal component analysis** finds a low-dimensional linear subspace that captures data well. It's both a
compression method and a way to see high-dimensional data.

![PCA on 2D data: the top eigenvector is the direction of largest variance](pca.png)

**Setting (10.1)**: centered data xₙ ∈ ℝᴰ, a code zₙ = Bᵀxₙ ∈ ℝᴹ with M < D, and a reconstruction x̃ₙ = Bzₙ. B has
orthonormal columns.

**Maximum variance (10.2)**: choose the direction b (‖b‖ = 1) that maximizes the variance of the projected data,
bᵀSb, where S is the data covariance.

- It's a **constrained optimization** problem (course 3, day 8): the Lagrangian gives **Sb = λb**.
- So b is an **eigenvector** of S, and the variance it captures is its eigenvalue λ. Take the largest.
- For M directions, take the eigenvectors of the M largest eigenvalues (the book proves it by induction).
