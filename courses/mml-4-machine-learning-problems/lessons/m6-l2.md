# Read: the projection perspective (10.3)

A second route to the same answer: find the subspace that minimizes the **average squared reconstruction error**
(1/N) Σ ‖xₙ − x̃ₙ‖².

- The optimal reconstruction is the **orthogonal projection** of each point onto the subspace (course 1).
- The error equals the sum of the eigenvalues you **don't** keep: J = Σ_{j>M} λⱼ.
- So **maximizing variance kept** and **minimizing reconstruction error** are the same problem:
  kept + error = total variance = trace(S).

The MNIST figures (digits rebuilt from more and more components) show what this looks like on real data.
