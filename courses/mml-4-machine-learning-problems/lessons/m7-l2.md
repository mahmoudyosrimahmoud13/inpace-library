# Read: key steps in practice, and probabilistic PCA (10.6–10.8)

**The recipe (10.6)**: subtract the mean; standardize each feature if they have different units; compute the
eigendecomposition (or SVD); project; to reconstruct, multiply back and undo the standardization and centering. The
book walks through it with pictures; it's exactly what `sklearn.decomposition.PCA` does.

**Probabilistic PCA (10.7)**: the same subspace, seen as a **latent variable model**: z ~ N(0, I) of dimension M,
x = Bz + μ + ε with Gaussian noise. Then:

- p(x) is Gaussian with covariance BBᵀ + σ²I (low-rank plus noise).
- The maximum likelihood B spans the principal subspace: PCA falls out of a probabilistic model.
- You get a generative model (you can sample new data) and a principled way to handle missing values.

10.8 links PCA to autoencoders (a neural network version) and to factor analysis and ICA.
