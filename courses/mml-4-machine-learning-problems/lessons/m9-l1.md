# Read: separating hyperplanes and the primal SVM (12.1–12.2)

**Binary classification** with labels y ∈ {−1, +1} and a linear decision rule sign(⟨w, x⟩ + b).

**Hyperplanes (12.1)**: {x : ⟨w, x⟩ + b = 0}; w is the normal vector (course 1's orthogonal complement), and the
distance from a point to it is |⟨w, x⟩ + b| / ‖w‖.

**Maximum margin (12.2.1–12.2.3)**: among all separating hyperplanes, choose the one farthest from the closest points.
Scale w so the closest points have ⟨w, x⟩ + b = ±1; then the margin is 1/‖w‖ on each side and maximizing it means
**minimizing ½‖w‖²** subject to yₙ(⟨w, xₙ⟩ + b) ≥ 1. A convex quadratic program (course 3).

**Soft margin (12.2.4)**: real data overlap. Add slack variables ξₙ ≥ 0 and pay C·Σξₙ. Large C → few violations,
narrow margin; small C → wider margin, more violations.

**Hinge loss (12.2.5)**: the same thing as empirical risk minimization: minimize
½‖w‖² + C Σ max(0, 1 − yₙ(⟨w, xₙ⟩ + b)). Points beyond the margin cost nothing; that's why only a few points (the
support vectors) matter.
