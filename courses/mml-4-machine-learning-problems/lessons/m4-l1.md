# Read: problem formulation and parameter estimation (9.1–9.2)

Chapter 9 works out linear regression completely. It's a model you can understand fully, so it's the best place to see
every idea of the book in action.

**Setting (9.1)**: y = f(x) + ε with Gaussian noise ε ~ N(0, σ²), and f linear **in the parameters**:
f(x) = φ(x)ᵀθ. The features φ(x) can be non-linear (polynomials, sines), so "linear regression" fits curves too.

**Maximum likelihood (9.2.1)**: the negative log-likelihood is the sum of squared errors, and setting its gradient to
zero gives the **normal equations** ΦᵀΦθ = Φᵀy, so θ_ML = (ΦᵀΦ)⁻¹Φᵀy. Course 2's gradient, course 1's projection.

**Overfitting (9.2.2)**: with polynomial features, high degrees fit the training points perfectly and swing wildly in
between. The book's RMSE figure matches the chart on day 1.

**MAP (9.2.3)**: a Gaussian prior gives θ_MAP = (ΦᵀΦ + (σ²/b²)I)⁻¹Φᵀy. The added λI also fixes numerical problems
when ΦᵀΦ is close to singular.

**Regularized least squares (9.2.4)**: the same thing seen as a penalty. Every result here should feel familiar now.
