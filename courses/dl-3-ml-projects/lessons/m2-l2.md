# When to change the dev set or the metric

If your metric says A is better but users prefer B, the **metric** is wrong. The slides' example: a cat classifier with
fewer errors that also lets through pornographic images. Fix it by weighting the errors that matter more:
`error = Σ w(i)·[wrong] / Σ w(i)`, with a big weight for the unacceptable ones.

Two separate steps (orthogonalization again): first **define** the target (metric and dev set), then **work out how
to hit it**. If the dev set doesn't match real users (blurry phone photos vs crisp web images), change it.
