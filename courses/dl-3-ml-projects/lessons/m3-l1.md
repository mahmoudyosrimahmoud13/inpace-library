# Human level, Bayes error and avoidable bias

**Bayes error** is the best any function could do (some images are just too blurry). For tasks humans do well,
human-level error is a good stand-in for it.

![Progress slows after human level](human_level.png)

Measure the gaps, then work on the biggest:

| | Example A | Example B |
|---|---|---|
| human (≈ Bayes) | 1% | 7.5% |
| train | 8% | 8% |
| dev | 10% | 10% |
| **focus on** | avoidable bias (7%) | variance (2%) |

Same train and dev errors, opposite advice, because of the human-level number.

**Which human?** For an estimate of Bayes error, use the **best** (a team of experts: 0.5% in the slides' X-ray
example), not a typical person.
