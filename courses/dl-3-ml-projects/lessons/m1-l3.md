# One number to optimize, and satisficing metrics

Precision and recall are both useful, but choosing between two classifiers is hard with two numbers. Combine them into
one: **F1** (`2PR / (P + R)`), or an average across countries, users or classes.

When some things only need to be **good enough**, make them constraints: *maximize accuracy subject to running time
under 100 ms* or *at most one false wake-up per 24 hours*. One **optimizing** metric, the rest **satisficing**.

Today's version: for a product built on a large language model you still need this. Pick one main quality score
on your own evaluation set, and set limits on cost, latency and safety.
