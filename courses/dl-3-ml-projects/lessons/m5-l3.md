# End-to-end deep learning

Replace a pipeline of hand-made stages (audio → features → phonemes → words → transcript) with one network
(audio → transcript). It needs **lots of data**. Often a **two-step** system wins: the slides' face recognition first
finds and crops the face, then identifies it, because each step has plenty of data.

Pros: lets the data speak, less hand design. Cons: needs much data, throws away useful hand-designed knowledge.
The key question: **do you have enough data to learn the whole mapping?** Speech recognition and translation went
fully end-to-end; self-driving still mixes learned parts with explicit planning and safety rules.
