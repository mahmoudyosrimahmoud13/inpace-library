# Multi-task learning

One network, several outputs at once: a self-driving image labelled for pedestrians, cars, stop signs and traffic
lights, with a sigmoid per label (not softmax: several can be true). Missing labels? Leave them out of the loss.

It helps when tasks share low-level features, each task has similar amounts of data, and the network is big enough.
Transfer learning is used far more often, but today's large models are deeply multi-task: one model, many tasks.
