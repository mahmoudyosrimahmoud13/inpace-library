# في محل ملابس

طارق يحتاج جاكيت. استمع للمقارنات (wärmer als) ونهايات الصفات (eine warme Jacke).

## استمع أولًا: المحادثة

**جاكيت شتوي**

| الألمانية | المعنى |
|---|---|
| **Verkäuferin:** Guten Tag. Kann ich Ihnen helfen? | نهارك سعيد. هل أستطيع مساعدتك؟ |
| **Tarek:** Ja, ich suche eine warme Jacke für den Winter. | نعم، أبحث عن جاكيت دافئ للشتاء. |
| **Verkäuferin:** Wir haben diese schwarze Jacke und diese blaue. Die schwarze ist länger und wärmer. | عندنا هذا الجاكيت الأسود وهذا الأزرق. الأسود أطول وأدفأ. |
| **Tarek:** Und welche ist billiger? | وأيهما أرخص؟ |
| **Verkäuferin:** Die blaue. Sie kostet neunzig Euro, die schwarze hundertvierzig. | الأزرق. سعره تسعون يورو، والأسود مئة وأربعون. |
| **Tarek:** Die schwarze gefällt mir besser. Kann ich sie anprobieren? Ich habe Größe M. | الأسود يعجبني أكثر. هل أستطيع تجربته؟ مقاسي M. |
| **Verkäuferin:** Natürlich. Die Umkleidekabinen sind dort hinten. | طبعًا. غرف القياس هناك في الخلف. |
| **Tarek:** Sie ist ein bisschen zu eng. Haben Sie sie eine Nummer größer? | إنه ضيق قليلًا. هل عندك مقاس أكبر؟ |
| **Verkäuferin:** Ja, hier ist L. Die steht Ihnen sehr gut! | نعم، تفضّل L. إنه يليق بك جدًا! |
| **Tarek:** Gut, ich nehme sie. Kann ich mit Karte zahlen? | حسنًا، سآخذه. هل أستطيع الدفع بالبطاقة؟ |

## قلّد الكلام (Shadowing)

اقرأ المحادثة بصوت عالٍ **ثلاث مرات**: أولًا ببطء، ثم بسرعة عادية، ثم دون أن تنظر إلى عمود المعنى. ولو عندك الصوت من الروابط بالأسفل، أوقفه بعد كل جملة وقلّد إيقاع المتكلم ولحن صوته، لا الكلمات فقط. هذا اسمه **التقليد (Shadowing)**، وهو يدرّب أذنك ولسانك معًا.

## كلمات وعبارات احفظها

| العبارة | المعنى |
|---|---|
| Kann ich Ihnen helfen? | هل أستطيع مساعدتك؟ |
| Ich suche... | أبحث عن... |
| Was kostet die Jacke? | كم سعر الجاكيت؟ |
| Kann ich das anprobieren? | هل أستطيع تجربة هذا؟ |
| Welche Größe haben Sie? | ما مقاسك؟ |
| Das ist zu eng / zu weit. | ضيق / واسع جدًا. |
| eine Nummer größer / kleiner | مقاس أكبر / أصغر |
| Das steht dir / Ihnen gut. | هذا يليق بك. |
| Ich nehme es / sie / ihn. | سآخذه. |
| Das ist im Angebot. | عليه عرض. |
| Kann ich das umtauschen? | هل أستطيع استبداله؟ |

## انطقها صح

**-er و-en و-el في الآخر.** في *wärmer* و*billiger* و*länger*، الـ *-er* صوت قصير يشبه "آ" ("فيرما"). وفي *kaufen* و*Jacken*، الـ *-en* غالبًا مجرد نون ساكنة ("كاوفن"). وفي *Mantel*، *-el* لام ساكنة. المتحدثون الأصليون يختصرون هذه النهايات كثيرًا؛ قلّدهم عندما تتدرب على التقليد.
