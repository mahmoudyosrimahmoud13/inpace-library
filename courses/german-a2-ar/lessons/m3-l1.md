# هدية عيد ميلاد

لينا وطارق يختاران هدية لزميلة. استمع لـ dem وder وmir وdir: حالة الجر Dativ.

## استمع أولًا: المحادثة

**ماذا نهديها؟**

| الألمانية | المعنى |
|---|---|
| **Lena:** Nächste Woche hat Julia Geburtstag. Was schenken wir ihr? | الأسبوع القادم عيد ميلاد يوليا. ماذا نهديها؟ |
| **Tarek:** Vielleicht ein Buch? Sie liest gern. | ربما كتاب؟ هي تحب القراءة. |
| **Lena:** Gute Idee. Ich kann ihr auch einen Gutschein von dem Café neben dem Büro geben. Sie geht dort oft hin. | فكرة جيدة. أستطيع أيضًا أن أعطيها قسيمة من المقهى بجانب المكتب. هي تذهب إلى هناك كثيرًا. |
| **Tarek:** Perfekt. Kannst du mir helfen? Ich weiß nicht, welches Buch ihr gefällt. | ممتاز. هل تستطيعين مساعدتي؟ لا أعرف أي كتاب سيعجبها. |
| **Lena:** Klar. Sie mag Krimis. Gehen wir nach der Arbeit mit dem Fahrrad zur Buchhandlung? | طبعًا. هي تحب الروايات البوليسية. هل نذهب بالدراجة إلى المكتبة بعد العمل؟ |
| **Tarek:** Gern. Und wem geben wir die Karte zum Unterschreiben? | بكل سرور. ولمن نعطي البطاقة ليوقّع عليها؟ |
| **Lena:** Dem Chef zuerst, dann den Kollegen. | للمدير أولًا، ثم للزملاء. |
| **Tarek:** Alles klar. Das gefällt mir: ein Geschenk von uns allen! | تمام. هذا يعجبني: هدية منا جميعًا! |

## قلّد الكلام (Shadowing)

اقرأ المحادثة بصوت عالٍ **ثلاث مرات**: أولًا ببطء، ثم بسرعة عادية، ثم دون أن تنظر إلى عمود المعنى. ولو عندك الصوت من الروابط بالأسفل، أوقفه بعد كل جملة وقلّد إيقاع المتكلم ولحن صوته، لا الكلمات فقط. هذا اسمه **التقليد (Shadowing)**، وهو يدرّب أذنك ولسانك معًا.

## كلمات وعبارات احفظها

| العبارة | المعنى |
|---|---|
| Was schenken wir ihr? | ماذا نهديها؟ |
| Sie hat Geburtstag. | عيد ميلادها. |
| Kannst du mir helfen? | هل تستطيع مساعدتي؟ |
| Das gefällt mir. | هذا يعجبني. |
| Wie geht es dir / Ihnen? | كيف حالك؟ (غير رسمي / رسمي) |
| Es geht mir gut. | أنا بخير. |
| mit dem Fahrrad / mit der Bahn | بالدراجة / بالقطار |
| nach der Arbeit | بعد العمل |
| Herzlichen Glückwunsch zum Geburtstag! | عيد ميلاد سعيد! |
| Das steht dir gut. | هذا يليق بك. |
| Wem gehört das? | لمن هذا؟ |
| Danke dir! / Danke Ihnen! | شكرًا لك! |

## انطقها صح

**سماع الحالات الإعرابية.** النهايات *-m* و*-n* و*-r* تحمل القواعد، فلا تبتلعها: *dem* (ديم)، و*den* (دين)، و*der* (دير). مثل الفرق في العربية بين "الرجلُ" و"الرجلَ" و"الرجلِ". تدرّب على المجموعة ببطء: *der Mann, den Mann, dem Mann*. ثم في جمل: *Ich helfe dem Mann* (أساعد الرجل). *Ich sehe den Mann* (أرى الرجل).
