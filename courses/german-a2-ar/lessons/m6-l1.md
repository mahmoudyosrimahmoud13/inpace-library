# الانتقال إلى شقة

طارق ينتقل إلى شقة جديدة ولينا تساعده. استمع إلى أين تذهب الأشياء (in den Schrank) وأين توجد (im Schrank).

## استمع أولًا: المحادثة

**أين أضعه؟**

| الألمانية | المعنى |
|---|---|
| **Lena:** Wohin soll ich die Bücher stellen? | أين أضع الكتب؟ |
| **Tarek:** Stell sie bitte ins Regal im Wohnzimmer. | ضعيها من فضلك على الرف في غرفة المعيشة. |
| **Lena:** Und die Lampe? Auf den Tisch oder neben das Sofa? | والمصباح؟ على الطاولة أم بجانب الكنبة؟ |
| **Tarek:** Neben das Sofa, bitte. Da kann ich abends lesen. | بجانب الكنبة من فضلك. هناك أستطيع القراءة في المساء. |
| **Lena:** Die Wohnung ist wirklich schön. Wie viel Miete zahlst du? | الشقة جميلة حقًا. كم الإيجار؟ |
| **Tarek:** Achthundert Euro warm. Sie hat zwei Zimmer, eine Küche und einen Balkon. | ثمانمئة يورو شاملة التدفئة. فيها غرفتان ومطبخ وشرفة. |
| **Lena:** Wo ist eigentlich der Kaffee? Ich habe Durst. | بالمناسبة أين القهوة؟ أنا عطشانة. |
| **Tarek:** Der Kaffee ist im Karton auf dem Boden, unter den Tassen. | القهوة في الكرتونة على الأرض، تحت الفناجين. |
| **Lena:** Gefunden! Ich hoffe, dass du dich hier wohlfühlst. | وجدتها! أتمنى أن تشعر بالراحة هنا. |

## قلّد الكلام (Shadowing)

اقرأ المحادثة بصوت عالٍ **ثلاث مرات**: أولًا ببطء، ثم بسرعة عادية، ثم دون أن تنظر إلى عمود المعنى. ولو عندك الصوت من الروابط بالأسفل، أوقفه بعد كل جملة وقلّد إيقاع المتكلم ولحن صوته، لا الكلمات فقط. هذا اسمه **التقليد (Shadowing)**، وهو يدرّب أذنك ولسانك معًا.

## كلمات وعبارات احفظها

| العبارة | المعنى |
|---|---|
| Wohin soll ich das stellen? | أين أضع هذا؟ |
| Stell es auf den Tisch. | ضعه على الطاولة. |
| Das Buch liegt auf dem Tisch. | الكتاب على الطاولة. |
| das Wohnzimmer / das Schlafzimmer | غرفة المعيشة / غرفة النوم |
| die Küche / das Bad / der Balkon | المطبخ / الحمام / الشرفة |
| Wie viel Miete zahlst du? | كم الإيجار الذي تدفعه؟ |
| die Warmmiete / die Kaltmiete | الإيجار شامل / غير شامل التدفئة |
| eine Zweizimmerwohnung | شقة من غرفتين |
| Ich habe Durst / Hunger. | أنا عطشان / جوعان. |
| Ich fühle mich hier wohl. | أشعر بالراحة هنا. |
| der Vermieter / die Nachbarn | صاحب البيت / الجيران |

## انطقها صح

**الضغط في العبارات القصيرة.** الألمانية تضغط على المعلومة الجديدة المهمة: *Stell sie ins REgal* و*neben das SOfa* و*im KARton*. وحروف الجر والأدوات ضعيفة وسريعة. قلّد المحادثة واجعل حروف الجر صغيرة والأسماء قوية.
