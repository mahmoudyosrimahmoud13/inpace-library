# أول برنامج لك بلغة C

لغة C من أهم لغات البرمجة على الإطلاق. Linux وويندوز وبايثون نفسها ومحركات الألعاب والبرامج داخل سيارتك وغسالتك: جزء كبير منها مكتوب بلغة C. تعلّم C يعلّمك **كيف يعمل الكمبيوتر فعلًا**: الذاكرة والبايتات وما يتحول إليه كودك.

## ماذا تحتاج

تحتاج **compiler**، وهو برنامج يحوّل كود C إلى برنامج يستطيع الكمبيوتر تشغيله.

- **Linux:** غالبًا موجود عندك. افتح الطرفية (terminal) واكتب `gcc --version`. لو ظهرت رسالة "command not found"، ثبّته بالأمر `sudo apt install build-essential` (في أوبونتو وديبيان).
- **ويندوز:** ثبّت **MSYS2** من موقع msys2.org، ثم شغّل في طرفيته `pacman -S mingw-w64-ucrt-x86_64-gcc`. أو استخدم **WSL** (Linux داخل ويندوز) واتبع خطوات Linux.
- **ماك:** شغّل `xcode-select --install` في الطرفية.
- **بدون تثبيت أصلًا:** استخدم compiler على الإنترنت مثل onlinegdb.com أو godbolt.org لتبدأ اليوم.

اكتب الكود في أي محرر نصوص. **VS Code** مع إضافة C/C++ اختيار مجاني جيد.

## مرحبًا يا عالم

أنشئ ملفًا اسمه `hello.c`:

<!-- diagram -->
```mermaid
flowchart LR
  A["hello.c<br/>النص الذي تكتبه"] --> B["gcc<br/>الـ compiler"] --> C["hello<br/>machine code"] --> D["./hello<br/>يعمل على المعالج"]
```

```c
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
```

```output
Hello, world!
```

الآن ترجم البرنامج وشغّله من الطرفية، في المجلد الذي فيه الملف:

```
gcc hello.c -o hello
./hello
```

- `gcc hello.c -o hello` معناه: ترجم الملف `hello.c` وسمِّ الناتج `hello`.
- `./hello` يشغّله. (في ويندوز اسمه `hello.exe`.)

## معنى كل سطر

- `#include <stdio.h>` يضيف مكتبة **الإدخال والإخراج القياسية**، وفيها الـ function `printf`.
- `int main(void)` هي النقطة التي **يبدأ** منها كل برنامج C. و`int` معناها أنها ترجع عددًا صحيحًا عندما تنتهي.
- `{` و`}` تحددان بداية جسم الـ function ونهايته.
- `printf("Hello, world!\n");` تطبع نصًا. و`\n` معناها **سطر جديد**. وكل جملة تنتهي **بفاصلة منقوطة** `;`.
- `return 0;` تخبر نظام التشغيل: "انتهيت بدون أخطاء".

## compile errors طبيعية

احذف الفاصلة المنقوطة بعد `printf(...)` وترجم مرة أخرى. سيتوقف الـ compiler ويخبرك **بالملف والسطر والمشكلة**، مثلًا `hello.c:4:30: error: expected ';' before 'return'`. اقرأ أول خطأ أولًا، فالأخطاء التالية تكون غالبًا بسببه. إصلاح compile errors نصف البرمجة، فلا تحبط.

وترجم دائمًا مع تشغيل التحذيرات؛ فهي تكشف أخطاء حقيقية:

```
gcc -Wall -Wextra hello.c -o hello
```

## التعليقات

```c
// A comment on one line
/* A comment
   over several lines */
```

الـ compiler يتجاهل التعليقات. استخدمها لتشرح **لماذا** فعلت شيئًا، لا ماذا فعلت.

## جرّب بنفسك

عدّل البرنامج ليطبع اسمك في سطر ومدينتك في السطر التالي، باستخدام `printf` واحدة لكل سطر.

**الإجابة:**

```c
#include <stdio.h>

int main(void) {
    printf("My name is Omar\n");
    printf("I live in Cairo\n");
    return 0;
}
```

```output
My name is Omar
I live in Cairo
```
