# Project 4: conversations that continue, and answers from the policies

You'll give the desk memory (one conversation per customer) and a `search_policies` tool over the shop's rules.

The code is above this text. Save it as `p4_memory_rag.py`.

## Read the code

- **`search_policies`** is retrieval at its simplest: score each policy by the words it shares with the question,
  return the best two, each labelled with its name. It's a tool, so the agent decides when to search. (The
  course's RAG lesson does the same with embeddings; the RAG course builds it all from scratch.)
- **`InMemorySaver`** with a `thread_id` keeps each conversation's messages. Same thread: the agent remembers.
  A new thread: a new customer.
- **`ask()`** prints only the new steps of each turn.

## Run it

```bash
python p4_memory_rag.py
```

The real output, with `qwen2.5:1.5b`:

```text
Model: ollama:qwen2.5:1.5b

search_policies('can I return a helmet') ->
   [returns] Returns: unused items can be returned within 30 days of delivery for a full refund. Bikes that have been ridden can be returned within 14 da...

Customer: Hi, my order is A1001. What did I buy?
   agent asks: get_order({'order_id': 'A1001'})
   agent: Your order A1001 includes a City bike with 7 gears. It cost $549. The order was placed on November 2nd, 2026 and you received your item on November 6th, 2026.
Customer: Can I still return it? I've ridden it twice.
   agent: I'm sorry, but I don't have information on whether this specific order can be returned. You should contact our customer service for that.
Customer: What was my order number again?
   agent: Sure! Your order number was A1001. If you need to confirm anything else, feel free to ask.

   messages kept in this conversation: 8
A different customer (a new thread): What was my order number?
   agent: I need your order ID to look it up. Could you please provide me with that information?
```

What it shows:

- **The search works**: for "can I return a helmet", the returns policy comes first.
- **Memory works**: the third question ("my order number again?") is answered from the conversation, and a new
  thread doesn't know it.
- **The agent didn't search the policies** for "Can I still return it?", and told the customer to contact customer
  service, which is the shop itself. The tool was there and described; the small model didn't use it. Tomorrow you
  build a workflow where the policy lookup always happens.

## Make it yours

1. Ask the return question first, in a fresh thread. Does the agent search then?
2. Replace the word-overlap search with embeddings (`init_embeddings` and `InMemoryVectorStore`, as in the RAG
  lesson) and compare which policy comes first for five questions.
3. Add `SummarizationMiddleware` and hold a 20-message conversation. What does the agent still remember?

## What to take away

- Memory is a checkpointer plus a thread id per conversation.
- Retrieval as a tool lets the agent choose; sometimes it chooses wrong.
