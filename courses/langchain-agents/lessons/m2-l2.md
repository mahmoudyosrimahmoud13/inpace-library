# Structured output: answers your code can use

Often the final answer isn't for a person but for your program: a category to route on, fields to save. Pass a Pydantic model as `response_format`, and the agent returns a validated object.

```python
from typing import Literal
from pydantic import BaseModel, Field
from langchain.agents.structured_output import ToolStrategy

class Triage(BaseModel):
    """How to handle a support ticket."""
    category: Literal["shipping", "refund", "other"]
    urgent: bool = Field(description="True if the customer is blocked or very upset")
    reply: str = Field(description="A short, friendly reply to send")

triage_agent = create_agent(
    model,
    tools=[get_order],
    system_prompt="Triage support tickets. Check order status with tools when an order id is given.",
    response_format=ToolStrategy(Triage),
)
result = triage_agent.invoke({"messages": [{"role": "user", "content": "Order A-17 hasn't arrived!!"}]})
ticket = result["structured_response"]
print(ticket.category, ticket.urgent)
print(ticket.reply)
```

`result["structured_response"]` is a real `Triage` object, so `ticket.category` can only be one of the three allowed values.

## Two strategies

| Strategy | How it works | Use it when |
|---|---|---|
| `ToolStrategy(Schema)` | the schema is offered to the model as a special tool; the agent validates the call and, if it's invalid, sends the error back so the model can fix it | works with any model that supports tool calling |
| `ProviderStrategy(Schema)` | the provider's own structured-output feature enforces the schema while generating | the provider supports it and you want the strictest guarantee |

Passing the schema directly (`response_format=Triage`) lets LangChain pick for you.

## Schema tips

- **Enums (`Literal`) for anything you route on.** Free text can't be routed reliably.
- **Descriptions on fields** are instructions to the model; write them like a prompt.
- **Small and flat** beats deeply nested.
- Still check business rules in code: a valid shape can hold a wrong value (an `urgent=False` on an angry message), which is what evaluation in module 5 measures.
