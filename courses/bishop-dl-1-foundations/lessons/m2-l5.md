# Build: the screening test and the biased variance

Two short experiments that check this module's results with code: Bayes' theorem on the cancer test, and the bias of
the maximum likelihood variance.

## 1. Bayes' theorem, two ways

First by formula, with the book's numbers.

```python
import numpy as np

p_cancer = 0.01
p_pos_given_cancer = 0.90      # 10% false negatives
p_pos_given_healthy = 0.03     # 3% false positives

p_pos = p_pos_given_cancer * p_cancer + p_pos_given_healthy * (1 - p_cancer)     # sum rule
p_cancer_given_pos = p_pos_given_cancer * p_cancer / p_pos                       # Bayes
print(f"p(positive) = {p_pos:.4f}")
print(f"p(cancer | positive) = {p_cancer_given_pos:.3f}")
```

```output
p(positive) = 0.0387
p(cancer | positive) = 0.233
```

Then by simulation: screen a million imaginary people and count.

```python
rng = np.random.default_rng(1)
n = 1_000_000
has_cancer = rng.random(n) < p_cancer
positive = np.where(has_cancer, rng.random(n) < p_pos_given_cancer, rng.random(n) < p_pos_given_healthy)
print(f"share of positives who have cancer: {has_cancer[positive].mean():.3f}")
```

```output
share of positives who have cancer: 0.233
```

The simulation agrees with the formula. When a probability result feels wrong, simulating it is the fastest way to
convince yourself.

## 2. Maximum likelihood for a Gaussian

Draw 5 points from a Gaussian with mean 0 and variance 1, and estimate the mean and variance by maximum likelihood.

```python
x = rng.normal(0.0, 1.0, size=5)
mu_ml = x.mean()
var_ml = np.mean((x - mu_ml) ** 2)
print(f"mu_ML = {mu_ml:.3f}, var_ML = {var_ml:.3f}")
```

```output
mu_ML = -0.554, var_ML = 0.890
```

One sample proves nothing. Repeat it 100,000 times and average the estimates, to see the **bias** from section 2.3.3.

```python
N = 5
samples = rng.normal(0.0, 1.0, size=(100_000, N))
means = samples.mean(axis=1, keepdims=True)
var_ml = np.mean((samples - means) ** 2, axis=1)
print(f"average var_ML           = {var_ml.mean():.3f}   (theory: (N-1)/N = {(N - 1) / N:.3f})")
print(f"average N/(N-1) * var_ML = {(N / (N - 1) * var_ml).mean():.3f}   (unbiased)")
```

```output
average var_ML           = 0.798   (theory: (N-1)/N = 0.800)
average N/(N-1) * var_ML = 0.998   (unbiased)
```

On average, the maximum likelihood variance is 20% too small with 5 points, exactly the factor (N − 1)/N. Multiplying
by N/(N − 1) removes the bias. Try N = 100 and watch the gap almost disappear.

## 3. Squared error is Gaussian likelihood

Section 2.3.4 says that, with Gaussian noise, maximizing the likelihood and minimizing the sum of squares give the same
weights. Check it on a straight-line fit: compute the negative log-likelihood for many slopes and see where its
minimum is.

```python
x = np.linspace(0, 1, 20)
t = 2.0 * x + rng.normal(0, 0.2, x.size)

slopes = np.linspace(1.0, 3.0, 2001)
sse = [np.sum((t - w * x) ** 2) for w in slopes]
sigma2 = 0.2 ** 2
nll = [np.sum((t - w * x) ** 2) / (2 * sigma2) + x.size / 2 * np.log(2 * np.pi * sigma2) for w in slopes]
print("slope with the smallest squared error:", round(slopes[np.argmin(sse)], 3))
print("slope with the largest likelihood:   ", round(slopes[np.argmin(nll)], 3))
```

```output
slope with the smallest squared error: 1.937
slope with the largest likelihood:    1.937
```

Same slope. The negative log-likelihood is just the squared error, scaled and shifted, so they have the same minimum.
