# Build: logistic regression by gradient descent

You'll write logistic regression from nothing but NumPy, check the gradient formula from section 5.4.3, and see the
linearly separable trap for yourself.

## 1. Data: two Gaussian classes with a shared covariance

This is exactly the setup of section 5.3.1, so the best boundary is a straight line.

```python
import numpy as np

rng = np.random.default_rng(0)
cov = np.array([[1.0, 0.6], [0.6, 1.0]])
X0 = rng.multivariate_normal([0, 0], cov, 200)
X1 = rng.multivariate_normal([2, 1], cov, 200)
X = np.vstack([X0, X1])
t = np.array([0] * 200 + [1] * 200)
Phi = np.hstack([np.ones((400, 1)), X])        # bias column, then the two inputs
print(Phi.shape, t.mean())
```

```output
(400, 3) 0.5
```

## 2. The cross-entropy error and its gradient

```python
def sigmoid(a):
    return 1 / (1 + np.exp(-a))

def error(w):
    y = sigmoid(Phi @ w)
    return -np.mean(t * np.log(y) + (1 - t) * np.log(1 - y))

def gradient(w):
    y = sigmoid(Phi @ w)
    return Phi.T @ (y - t) / len(t)               # (prediction − target) × input, averaged

# check the formula against a numerical derivative
w = rng.normal(size=3)
eps = 1e-6
numeric = np.array([(error(w + eps * e) - error(w - eps * e)) / (2 * eps) for e in np.eye(3)])
print("formula:", np.round(gradient(w), 6))
print("numeric:", np.round(numeric, 6))
```

```output
formula: [-0.018955 -0.246194 -0.108802]
numeric: [-0.018955 -0.246194 -0.108802]
```

Always check a hand-written gradient like this. In part 2 you'll check a whole automatic-differentiation library the same
way.

## 3. Train it

```python
w = np.zeros(3)
for step in range(5001):
    w -= 0.5 * gradient(w)
    if step % 1000 == 0:
        acc = np.mean((sigmoid(Phi @ w) > 0.5) == t)
        print(f"step {step:4d}: error {error(w):.4f}, accuracy {acc:.3f}")
print("weights:", np.round(w, 3))
```

## 4. Compare with the generative answer

For Gaussian classes with a shared covariance, section 5.3 gives the weights in closed form:
`w = Σ⁻¹(μ₁ − μ₀)` and `w₀ = −½μ₁ᵀΣ⁻¹μ₁ + ½μ₀ᵀΣ⁻¹μ₀ + ln(p(C₁)/p(C₀))`. Fit the means and the shared covariance by maximum
likelihood, and compare.

```python
mu0, mu1 = X0.mean(0), X1.mean(0)
S = 0.5 * np.cov(X0.T, bias=True) + 0.5 * np.cov(X1.T, bias=True)    # shared covariance, weighted by class size
Si = np.linalg.inv(S)
w_gen = Si @ (mu1 - mu0)
w0_gen = -0.5 * mu1 @ Si @ mu1 + 0.5 * mu0 @ Si @ mu0               # equal priors, so the log term is 0
print("generative:     ", np.round([w0_gen, *w_gen], 3))
print("discriminative: ", np.round(w, 3))
```

```output
generative:      [-2.072  2.159 -0.361]
discriminative:  [-2.219  2.329 -0.409]
```

Close, because here the generative model's assumptions are exactly true. When they're not (real data rarely is
Gaussian), logistic regression usually wins, because it never assumed anything about how x is distributed.

## 5. The linearly separable trap

Move the classes far apart so a straight line separates them perfectly, and train without regularization.

```python
Xs = np.vstack([X0, X1 + [6, 6]])
Phis = np.hstack([np.ones((400, 1)), Xs])
for lam in [0.0, 0.01]:
    w = np.zeros(3)
    for step in range(20000):
        y = sigmoid(Phis @ w)
        w -= 0.5 * (Phis.T @ (y - t) / 400 + lam * w)
    print(f"lambda = {lam}: |w| = {np.linalg.norm(w):.1f}")
```

```output
lambda = 0.0: |w| = 11.3
lambda = 0.01: |w| = 3.1
```

Without regularization, the weights keep growing for as long as you train: the error can always get a little smaller by
making the sigmoid steeper. A small penalty stops it, exactly as section 5.4.3 warns.
