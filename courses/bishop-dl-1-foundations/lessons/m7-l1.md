# Big project: a tumour classifier, two ways

You've read five chapters. Now use them together on real medical data, the way a careful machine learning engineer
would. No new reading today: everything you need is in chapters 4 and 5.

## The data

The **Breast Cancer Wisconsin** data set, which ships with scikit-learn (no download needed). Each of its 569 rows is a
breast tumour, described by 30 measurements of cell nuclei taken from a scan of a fine-needle biopsy (radius, texture,
smoothness and so on). Each tumour is labelled **malignant** (cancer) or **benign**.

It's a real, published data set, but it's small and old. Treat this project as practice in method, not as a medical
tool.

## What you'll build

1. **A generative classifier** (section 5.3): one Gaussian per class with a shared covariance, fitted by maximum
   likelihood with the closed-form formulas.
2. **A discriminative classifier** (section 5.4): logistic regression trained by gradient descent with weight decay,
   with the weight-decay strength chosen on a validation set.
3. **An honest comparison**: accuracy, cross-entropy and the ROC curve with its AUC, all written by you, all measured on
   a test set you never touch while building.
4. **A doctor's decision rule** (section 5.2): a loss matrix that makes missing a cancer 20 times worse than a false
   alarm, and a reject option that sends unsure cases to a human.

## How it's organized

- **Part 1** builds and compares the two classifiers.
- **Part 2** turns probabilities into decisions.
- **Wrap-up** asks you to write a one-page report.

Every block has been run; the outputs you see are real. Run them yourself in order, then try the changes suggested at
the end of each part.

## Ground rules (the same as a real project)

- Split the data **once**, at the start: training (60%), validation (20%), test (20%).
- Choose everything (λ, thresholds) using **training and validation only**.
- Look at the test set **once**, at the end of each part, to report results.
