# Project part 2: from probabilities to decisions

A model's job isn't to output 0.83. It's to help someone decide. Section 5.2 tells you how. This part continues the
same notebook. Starting a fresh one? Run this block first: it repeats what part 1 built.

```python
import numpy as np
from sklearn.datasets import load_breast_cancer

data = load_breast_cancer()
X, t = data.data, 1 - data.target
rng = np.random.default_rng(42)
idx = rng.permutation(len(t))
tr, va, te = idx[:341], idx[341:455], idx[455:]
Z = (X - X[tr].mean(0)) / X[tr].std(0)

def sigmoid(a):
    return 1 / (1 + np.exp(-a))

def fit_logistic(Z, t, lam, steps=3000, lr=0.5):
    Phi = np.hstack([np.ones((len(Z), 1)), Z])
    w = np.zeros(Phi.shape[1])
    for _ in range(steps):
        w -= lr * (Phi.T @ (sigmoid(Phi @ w) - t) / len(t) + lam * np.r_[0, w[1:]])
    return w

def predict_logistic(w, rows):
    return sigmoid(w[0] + Z[rows] @ w[1:])

best_lam = 0.001
w_log = fit_logistic(np.vstack([Z[tr], Z[va]]), np.r_[t[tr], t[va]], best_lam)
```

## 1. Put a price on mistakes

A **loss matrix** says what each kind of mistake costs. Missing a cancer (a false negative) is far worse than a false
alarm, which only means another test. Say a miss costs 20 and a false alarm costs 1:

| | predict benign | predict malignant |
|---|---|---|
| **truly benign** | 0 | 1 |
| **truly malignant** | 20 | 0 |

Section 5.2.2 says: choose the decision with the smaller **expected** loss. Predicting malignant costs `1 · p(benign)`,
predicting benign costs `20 · p(malignant)`. So predict malignant whenever `20p > 1 − p`, that is when **p > 1/21 ≈
0.048**, not 0.5.

```python
L_miss, L_false_alarm = 20, 1
theory = L_false_alarm / (L_false_alarm + L_miss)
print(f"threshold from decision theory: {theory:.3f}")

def total_loss(p, t, threshold):
    pred = p > threshold
    misses = np.sum((pred == 0) & (t == 1))
    alarms = np.sum((pred == 1) & (t == 0))
    return L_miss * misses + L_false_alarm * alarms, misses, alarms
```

```output
threshold from decision theory: 0.048
```

## 2. Check it on the validation set

The formula assumes the probabilities are **calibrated** (a predicted 0.1 really means 1 in 10). Check by sweeping the
threshold on validation data, using a model trained on the training set only.

```python
w_tr = fit_logistic(Z[tr], t[tr], best_lam)
p_va = predict_logistic(w_tr, va)

print("threshold   loss   misses   false alarms")
for th in [0.5, 0.2, 0.1, theory, 0.02, 0.005]:
    loss, m, a = total_loss(p_va, t[va], th)
    print(f"{th:9.3f}   {loss:4d}   {m:6d}   {a:12d}")
```

```output
threshold   loss   misses   false alarms
    0.500     21        1              1
    0.200     24        1              4
    0.100     26        1              6
    0.048     30        1             10
    0.020     38        1             18
    0.005     47        1             27
```

Look at the misses column: it never reaches zero. One malignant case gets a very low probability, so even a threshold
of 0.005 misses it. **No threshold can fix a confident mistake.** Lowering the threshold here only adds false alarms,
which is why 0.5 has the lowest loss on these 114 cases.

Should we pick 0.5 then? No. One case decides that table, and a validation set this small can't tell thresholds apart
reliably. We keep the threshold from decision theory: it comes from the loss matrix, which is a fact about the costs,
not a guess fitted to a few examples. The confident miss is a job for the next step.

## 3. The reject option

Some cases are genuinely unsure. Section 5.2.3: if the model's confidence is below θ, don't decide; refer the case to
a pathologist. Confidence here means the probability of whichever class the model leans towards, `max(p, 1 − p)`.

```python
p_te = predict_logistic(w_log, te)
conf = np.maximum(p_te, 1 - p_te)
print("  theta   referred   errors among the rest")
for theta in [0.5, 0.9, 0.99, 0.999]:
    keep = conf >= theta
    errors = np.sum((p_te[keep] > 0.5) != t[te][keep])
    print(f"{theta:7}   {np.mean(~keep):8.1%}   {errors:5d} of {keep.sum()}")
```

```output
  theta   referred   errors among the rest
    0.5       0.0%       1 of 114
    0.9       7.9%       1 of 105
   0.99      29.8%       0 of 80
  0.999      47.4%       0 of 60
```

At θ = 0.9 the model refers 8% of cases but still makes its one mistake. At θ = 0.99 it is right on everything it
decides, but it refers almost a third of the cases. That's the real trade-off of the reject option: fewer automatic
mistakes, more work for people. Where to set θ is a decision for the hospital, not for the model. Automating the easy
cases and flagging the hard ones is still the honest way to deploy a classifier in medicine.

## 4. The final report on the test set

Put it together: refer the unsure cases, and decide the rest with the loss-based threshold.

```python
theta = 0.99
keep = conf >= theta
decide = p_te[keep] > theory
truth = t[te][keep]
tp = np.sum(decide & (truth == 1)); fp = np.sum(decide & (truth == 0))
fn = np.sum(~decide & (truth == 1)); tn = np.sum(~decide & (truth == 0))
print(f"referred to a pathologist: {np.sum(~keep)} of {len(te)}")
print(f"decided automatically:     TP {tp}  FP {fp}  FN {fn}  TN {tn}")
print(f"recall (cancers caught):   {tp / (tp + fn):.3f}")
print(f"precision:                 {tp / (tp + fp):.3f}")
```

```output
referred to a pathologist: 34 of 114
decided automatically:     TP 32  FP 0  FN 0  TN 48
recall (cancers caught):   1.000
precision:                 1.000
```

Read it out loud as you would to a doctor: "Out of 114 biopsies, the system referred 34 to you. On the other 80 it
caught all 32 cancers and raised no false alarms." Then add the honest footnote: on 80 cases, "no mistakes" is
encouraging, not proof.
