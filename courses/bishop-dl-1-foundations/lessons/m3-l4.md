# Build: entropy, KL divergence and a Bayesian coin

## 1. Entropy in bits

The book's two examples: eight equally likely states, then eight states with probabilities
(1/2, 1/4, 1/8, 1/16, 1/64, 1/64, 1/64, 1/64).

```python
import numpy as np

def entropy_bits(p):
    p = np.asarray(p, dtype=float)
    p = p[p > 0]                      # 0 · log 0 counts as 0
    return -np.sum(p * np.log2(p))

uniform = np.full(8, 1 / 8)
skewed = np.array([1/2, 1/4, 1/8, 1/16, 1/64, 1/64, 1/64, 1/64])
print("uniform:", entropy_bits(uniform), "bits")
print("skewed: ", entropy_bits(skewed), "bits")
```

```output
uniform: 3.0 bits
skewed:  2.0 bits
```

## 2. KL divergence is not symmetric

Compare a two-peaked distribution p with a single wide bump q, on a grid.

```python
x = np.linspace(-6, 6, 2001)
dx = x[1] - x[0]

def gauss(x, mu, s):
    return np.exp(-(x - mu) ** 2 / (2 * s ** 2)) / np.sqrt(2 * np.pi * s ** 2)

p = 0.5 * gauss(x, -2, 0.6) + 0.5 * gauss(x, 2, 0.6)
q = gauss(x, 0, 2.2)

def kl(a, b):
    return np.sum(a * np.log(a / b)) * dx

print(f"KL(p||q) = {kl(p, q):.3f} nats")
print(f"KL(q||p) = {kl(q, p):.3f} nats")
```

```output
KL(p||q) = 0.558 nats
KL(q||p) = 1.230 nats
```

`KL(q‖p)` is much bigger: q puts probability in the gap between p's two peaks, where p is almost zero, and KL punishes
that heavily. Remember this asymmetry: it decides how variational methods behave in parts 4 and 5.

## 3. Cross-entropy is maximum likelihood

Fit the mean of a Gaussian model q to samples from p by two routes: maximize the average log-likelihood, and minimize
the cross-entropy between the empirical data and the model. They're the same number with the sign flipped, so they
pick the same mean.

```python
rng = np.random.default_rng(0)
data = rng.normal(1.5, 1.0, size=500)

mus = np.linspace(0, 3, 301)
avg_loglik = [np.mean(np.log(gauss(data, m, 1.0))) for m in mus]
print("best mu by likelihood:", round(mus[np.argmax(avg_loglik)], 2), "  sample mean:", round(data.mean(), 2))
```

```output
best mu by likelihood: 1.47   sample mean: 1.47
```

## 4. A Bayesian coin

The book's warning: three tosses, three heads, and maximum likelihood says tails is impossible. A Bayesian puts a prior
on μ, the probability of heads. The standard choice for a coin is a **Beta(a, b)** prior, because the posterior stays
a Beta: after h heads and t tails it is Beta(a + h, b + t). The book doesn't need its details; this one fact is
enough here.

```python
h, t = 3, 0
mu_ml = h / (h + t)
a, b = 2, 2                                   # a mild prior: "probably fair-ish"
post_mean = (a + h) / (a + b + h + t)
print(f"maximum likelihood p(heads) = {mu_ml:.2f}")
print(f"Bayesian posterior mean     = {post_mean:.2f}")
```

```output
maximum likelihood p(heads) = 1.00
Bayesian posterior mean     = 0.71
```

Now watch the posterior settle as more flips arrive from a coin that really lands heads 70% of the time. The posterior
after each batch is the prior for the next.

```python
flips = rng.random(1000) < 0.7
a, b = 2, 2
for n in [0, 10, 100, 1000]:
    heads = flips[:n].sum()
    A, B = a + heads, b + n - heads
    mean = A / (A + B)
    sd = np.sqrt(A * B / ((A + B) ** 2 * (A + B + 1)))
    print(f"after {n:4d} flips: p(heads) ≈ {mean:.3f} ± {sd:.3f}")
```

```output
after    0 flips: p(heads) ≈ 0.500 ± 0.224
after   10 flips: p(heads) ≈ 0.643 ± 0.124
after  100 flips: p(heads) ≈ 0.740 ± 0.043
after 1000 flips: p(heads) ≈ 0.698 ± 0.014
```

The ± column is the posterior's standard deviation: the model's own uncertainty. It shrinks as the data grows, which is
exactly the **epistemic** uncertainty from the start of chapter 2. The coin itself stays random, which no amount of data
removes.
