# Read: discriminant functions and decision theory (5.1–5.2)

Read the opening of chapter 5 and sections 5.1 and 5.2 (pages 131 to 150).

## Discriminant functions (5.1)

A classifier divides the input space into regions, one per class, separated by **decision boundaries**. With a linear
function `y(x) = wᵀx + w₀`, the boundary is a straight line (a hyperplane in more dimensions). Two pictures to
understand:

- **w points across the boundary**: it sets the boundary's orientation, and w₀ shifts it away from the origin.
- **More than two classes** (5.1.2) is trickier than it looks: combining several yes/no classifiers leaves ambiguous
  regions (Figure 5.2). The clean fix is K linear functions, one per class, and you pick the largest. Its regions are
  always convex.

**Least squares for classification** (5.1.4) is tempting because it has a closed-form solution, and it fails badly:
a few correctly classified points far from the boundary drag it off course (Figure 5.4). The book's explanation is the
real lesson: least squares assumes Gaussian noise, and class labels are nothing like Gaussian. **Pick the error function
that matches the kind of target you have.**

## Decision theory (5.2)

This is one of the most practical sections in the book. Read every subsection.

- **Misclassification rate** (5.2.1): to make as few mistakes as possible, assign x to the class with the largest
  posterior `p(Cₖ | x)`.
- **Expected loss** (5.2.2): not all mistakes cost the same. Telling a cancer patient they're healthy is far worse than
  the reverse. A **loss matrix** (Figure 5.6) puts a price on each kind of mistake, and the best decision minimizes the
  expected loss, which changes the boundary.
- **The reject option** (5.2.3): when the largest posterior is below a threshold θ, don't decide: hand the case to a
  human. You get fewer mistakes on the cases you do decide.
- **Inference and decision** (5.2.4): three ways to build a classifier, from most to least work: model how the data
  is generated for each class (**generative**), model the posterior directly (**discriminative**), or learn a function
  that outputs the class with no probabilities at all (**discriminant function**). The book lists why posteriors are
  worth having: you can change the loss matrix, add a reject option, correct for class imbalance, and combine models,
  all without retraining.
- **Classifier accuracy** (5.2.5): learn the four counts (true/false positives and negatives), and **precision**,
  **recall** and the F-score. The book warns that accuracy misleads when classes are imbalanced: with 1 sick person in
  1,000, "everyone is healthy" is 99.9% accurate and useless.
- **ROC curve** (5.2.6): sweep the decision threshold from one extreme to the other and plot the true positive rate
  against the false positive rate. The **area under the curve** (AUC) summarizes the whole curve in one number:
  1 is perfect, 0.5 is guessing.

You'll use the loss matrix, the reject option and the ROC curve in this course's big project.
