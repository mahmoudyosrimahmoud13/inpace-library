## 1. Make the data

Ten points from `sin(2πx)` with a little Gaussian noise, and a test set of 100 more made the same way.

```python
import numpy as np

rng = np.random.default_rng(30)

def make_data(n):
    x = np.linspace(0, 1, n)
    t = np.sin(2 * np.pi * x) + rng.normal(0, 0.3, n)
    return x, t

x_train, t_train = make_data(10)
x_test, t_test = make_data(100)
print(np.round(x_train, 2))
print(np.round(t_train, 2))
```

```output
[0.   0.11 0.22 0.33 0.44 0.56 0.67 0.78 0.89 1.  ]
[ 0.47  0.87  0.69  0.8   0.26  0.37 -1.15 -0.57 -0.61  0.31]
```

## 2. Fit a polynomial

A polynomial of order M is a **linear** function of its weights. Put the powers of x in the columns of a matrix
(the **design matrix**), and the weights that minimize the sum-of-squares error solve a least-squares problem.

```python
def design(x, M):
    return np.vstack([x ** j for j in range(M + 1)]).T     # columns: 1, x, x², ..., x^M

def fit(x, t, M, lam=0.0):
    Phi = design(x, M)
    # minimize sum of squares + (lam/2)·||w||²  ->  (ΦᵀΦ + lam·I) w = Φᵀt
    return np.linalg.solve(Phi.T @ Phi + lam * np.eye(M + 1), Phi.T @ t)

def rms(x, t, w):
    y = design(x, len(w) - 1) @ w
    return np.sqrt(np.mean((y - t) ** 2))

w3 = fit(x_train, t_train, 3)
print("weights for M = 3:", np.round(w3, 2))
```

```output
weights for M = 3: [  0.39   7.03 -23.76  16.58]
```

## 3. Watch over-fitting happen

Compare the training and test error as M grows. This is the book's Figure 1.7.

```python
print(" M   train RMS   test RMS   largest |w|")
for M in [0, 1, 3, 6, 9]:
    w = fit(x_train, t_train, M)
    print(f"{M:2d}   {rms(x_train, t_train, w):9.3f}   {rms(x_test, t_test, w):8.3f}   {np.abs(w).max():11.1f}")
```

```output
 M   train RMS   test RMS   largest |w|
 0       0.648      0.753           0.1
 1       0.497      0.562           1.3
 3       0.279      0.340          23.8
 6       0.248      0.351         730.1
 9       0.000      1.635     1294850.7
```

Read the table the way the book reads its figure:

- The training error keeps falling, and at M = 9 it's essentially **zero**: 10 weights can pass through 10 points.
- The test error is lowest somewhere in the middle and gets much worse at M = 9.
- The weights explode. Huge weights with opposite signs are what make the curve swing between the points.

## 4. Two cures

First, more data: the same M = 9 model with 100 training points.

```python
x_big, t_big = make_data(100)
w9_big = fit(x_big, t_big, 9)
print("M = 9 with 100 points: test RMS", round(rms(x_test, t_test, w9_big), 3))
```

```output
M = 9 with 100 points: test RMS 0.284
```

Second, regularization: keep the 10 points but penalize large weights. Try the two values from the book.

```python
for ln_lam in [-18, 0]:
    w = fit(x_train, t_train, 9, lam=np.exp(ln_lam))
    print(f"ln λ = {ln_lam:3d}: train {rms(x_train, t_train, w):.3f}, test {rms(x_test, t_test, w):.3f}, "
          f"largest |w| {np.abs(w).max():.1f}")
```

```output
ln λ = -18: train 0.235, test 0.347, largest |w| 774.5
ln λ =   0: train 0.491, test 0.584, largest |w| 0.4
```

With ln λ = −18 the weights shrink and the test error drops. With ln λ = 0 the penalty is so strong that the curve is
too flat: under-fitting again. Choosing λ is exactly the **model selection** problem from section 1.2.6.

## 5. Choose λ properly

Never use the test set to choose a hyperparameter: it would stop being a fair test. Split off a **validation set**.

```python
x_val, t_val = make_data(50)
best = min(range(-30, 1), key=lambda k: rms(x_val, t_val, fit(x_train, t_train, 9, lam=np.exp(k))))
w = fit(x_train, t_train, 9, lam=np.exp(best))
print("best ln λ on validation:", best, "  test RMS:", round(rms(x_test, t_test, w), 3))
```

```output
best ln λ on validation: -11   test RMS: 0.327
```
