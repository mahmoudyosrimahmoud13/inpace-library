# Start here

This is part 1 of 5 of a course series built on **Deep Learning: Foundations and Concepts** by Christopher M. Bishop
and Hugh Bishop (Springer, 2024). Part 1 covers chapters 1 to 5: what deep learning is, probability, the standard
distributions, and networks with a single layer for regression and classification.

This isn't a course of exercises. **Every module ends with a real project that you build yourself**, on real data,
in PyTorch: a fuel-use predictor, a spam filter, a text compressor, a machine-failure detector, a house-price model and
a clothes classifier in this part alone. Each one becomes a GitHub repository with a README and results you can put on
your CV. Each part also ends with a **big project**.

| Part | Chapters | Big project |
|---|---|---|
| **1. Probability and single-layer networks** (this one) | 1–5 | A tumour classifier, two ways, with a doctor's decision rule |
| 2. Deep networks and how they learn | 6–9 | Your own automatic-differentiation library, training a digit recognizer |
| 3. Convolutions, transformers and graphs | 10, 12, 13 | A CNN, a small character-level transformer and a graph network, on your library |
| 4. Structured models, sampling and latent variables | 11, 14–16 | EM for Gaussian mixtures, MCMC and Langevin samplers, probabilistic PCA |
| 5. Generative models | 17–20 | A variational autoencoder and a diffusion model that make new digits |

## First, get the book

The book is **not inside this course**. Each **Read** lesson opens the right pages of *your own copy*.

- **The PDF eBook** from [Springer](https://link.springer.com/book/10.1007/978-3-031-45468-4) (many university
  libraries give it to students for free), or
- the **free online version** on [bishopbook.com](https://www.bishopbook.com). It reads in the browser, so the lessons
  can't open its pages for you, but every lesson title says which sections to read.

If you have the PDF: on this course's page, in the box **"This course reads a book you get yourself"**, press **Find it
for me**. inPace looks in your Downloads, Documents and Desktop folders (on a phone: Download, Documents, Books) and
recognizes the book by its title and number of pages, whatever the file is called. If it's somewhere else, choose the
folder or the file yourself.

The course expects a 656-page PDF. If inPace warns that the page count is different, you have another copy: the
lessons may open a few pages off, so trust the section numbers in each lesson's title.

The authors also give away free extras on [bishopbook.com](https://www.bishopbook.com): all the figures, worked
**solutions to the exercises of chapters 2 to 10**, and a list of corrections.

## Before you start

The book assumes you're comfortable with:

- **Linear algebra**: vectors, matrices, matrix products, inverses, eigenvectors.
- **Calculus**: derivatives, partial derivatives, the chain rule, gradients.
- **Python with NumPy**: the Build lessons are NumPy code; the module projects use PyTorch, explained as you go.

Not there yet? Take these first. They're all in the library:

- *Maths for ML 1 to 4* (the free book Mathematics for Machine Learning) for the maths. Part 3 overlaps a lot with this
  course's chapters 2 and 3, which is fine: Bishop's version will feel like a second, deeper look.
- *NumPy and pandas for machine learning* for the code.
- *Deep Learning 1* if you'd like to see neural networks working in practice before the theory.

You don't need a GPU for any part of this series: everything runs on an ordinary laptop, or free in
[Google Colab](https://colab.research.google.com). For the projects, install Python 3.10 or newer, then once:

```bash
pip install torch pandas matplotlib scikit-learn jupyter
```

You'll also want a free [GitHub](https://github.com) account and `git`, to publish your projects.

## How each module works

- **Read** lessons open the book at the right pages, with notes under them: what matters most, what you can skim, and
  the idea behind the formulas. Read with a pencil and redo the short derivations yourself.
- **Watch** lessons play a video that shows the same idea from another angle. They're optional extras.
- **Build** lessons are NumPy code you run yourself. Every example was run before publishing, and the printed output
  under each one is the real output.
- Each module ends with a **module project**: a step-by-step guide to building a real project in PyTorch, with the
  real output of every command, ideas to make it your own, and a line for your CV. Each one comes with a **notebook**
  (attached to the lesson; on the website you can open it in Google Colab) that builds and runs the whole project, and
  the finished code is in the course files under `projects/`. Every dataset the projects use is also in one separate download, [bishop-datasets.zip](https://github.com/mahmoudyosrimahmoud13/inpace-library/releases/download/bishop-datasets-v1/bishop-datasets.zip) (239 MB, with a README saying which files go with which project), for working offline. Build it yourself first, and use them to check your work.
- Each module also has a **quiz** (pass with 70% to open the next module). Each question can have **more than one
  right answer**, so read every option. There's also a **task** (publishing your project) and a short **explanation in your own words**. They're
  optional, but they're the best way to make it stick.
