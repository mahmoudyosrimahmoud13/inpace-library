## Generative classifiers (5.3)

Model each class separately: a prior `p(Cₖ)` (how common it is) and a class-conditional density `p(x | Cₖ)` (what its
examples look like), then use Bayes' theorem to get the posterior. For two classes, the posterior turns out to be the
**logistic sigmoid** of a quantity a:

```text
p(C₁ | x) = σ(a),    σ(a) = 1 / (1 + e⁻ᵃ),    a = ln [ p(x | C₁) p(C₁) / ( p(x | C₂) p(C₂) ) ]
```

a is just the **log-odds**. For K classes, the sigmoid becomes the **softmax**.

**Gaussian classes with a shared covariance** (5.3.1). If both classes are Gaussian with the *same* covariance Σ, the
quadratic terms cancel and a becomes **linear** in x: `a = wᵀx + w₀`. So the boundary is a straight line. If each class
has its own covariance, the boundary becomes curved (quadratic).

**Fitting it** (5.3.2): by maximum likelihood, everything has a simple formula. The prior is the fraction of each class,
the means are the class averages, and the shared covariance is a weighted average of the two class covariances.

**Discrete features** (5.3.3): with many yes/no features, assuming they're independent within each class gives the
**naive Bayes** model. Read it to know the name.

## Discriminative classifiers (5.4)

Why model x at all, if we only need the posterior? Take the form we just derived, `σ(wᵀφ(x))`, and fit w directly. That's
**logistic regression** (5.4.3). Two advantages: far fewer parameters (with M features, about M instead of the M²/2 a
covariance needs), and no Gaussian assumption that might be wrong.

The error function is the negative log-likelihood of Bernoulli labels, the **cross-entropy error**. Its gradient has a
beautiful form, which the book points out:

```text
∇E(w) = Σₙ ( yₙ − tₙ ) φₙ          (prediction minus target, times the input)
```

It's the same form as the gradient for linear regression. There's **no closed-form solution**, so we use gradient
descent: the same tool that will train every network in the rest of the book.

Two warnings to remember:

- **Linearly separable data breaks maximum likelihood**: the weights grow forever, making the sigmoid infinitely
  steep. Regularization fixes it.
- **Multi-class** (5.4.4): the softmax with cross-entropy has the same "prediction minus target" gradient.

Skim **probit regression** (5.4.5). Read **canonical link functions** (5.4.6) for the big idea: whenever the output
activation matches the target's distribution (identity for Gaussian, sigmoid for Bernoulli, softmax for categorical),
the gradient takes that simple "prediction minus target" form. This tells you which output layer and error function
to pair in every network you'll build.
