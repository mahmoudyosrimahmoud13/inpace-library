# Build: Gaussian ellipses, conditionals, and a kernel density

## 1. The ellipse comes from the eigenvectors

```python
import numpy as np

rng = np.random.default_rng(0)
mu = np.array([1.0, 2.0])
Sigma = np.array([[2.0, 1.2],
                  [1.2, 1.0]])

vals, vecs = np.linalg.eigh(Sigma)
print("eigenvalues:", np.round(vals, 3))
print("eigenvectors (columns):\n", np.round(vecs, 3))
```

```output
eigenvalues: [0.2 2.8]
eigenvectors (columns):
 [[ 0.555 -0.832]
 [-0.832 -0.555]]
```

Sample from this Gaussian and check that, in the eigenvector coordinates, the two directions are uncorrelated with
variances equal to the eigenvalues. That's section 3.2.1 in code.

```python
X = rng.multivariate_normal(mu, Sigma, size=200_000)
Y = (X - mu) @ vecs                       # rotate into the eigenvector coordinates
print("covariance after rotation:\n", np.round(np.cov(Y.T), 3))
```

```output
covariance after rotation:
 [[0.2   0.003]
 [0.003 2.809]]
```

## 2. A conditional Gaussian

For a 2-D Gaussian, the conditional of x₁ given x₂ is Gaussian with

```text
mean     = μ₁ + Σ₁₂ / Σ₂₂ · (x₂ − μ₂)
variance = Σ₁₁ − Σ₁₂² / Σ₂₂
```

Check the formula against the samples: keep only the samples whose x₂ is close to 3, and look at their x₁.

```python
x2 = 3.0
cond_mean = mu[0] + Sigma[0, 1] / Sigma[1, 1] * (x2 - mu[1])
cond_var = Sigma[0, 0] - Sigma[0, 1] ** 2 / Sigma[1, 1]

near = X[np.abs(X[:, 1] - x2) < 0.02, 0]
print(f"formula: mean {cond_mean:.3f}, variance {cond_var:.3f}")
print(f"samples: mean {near.mean():.3f}, variance {near.var():.3f}   ({near.size} samples)")
```

```output
formula: mean 2.200, variance 0.560
samples: mean 2.206, variance 0.540   (2019 samples)
```

Notice the conditional variance (0.56) is smaller than the marginal variance of x₁ (2.0): knowing x₂ tells you a lot
about x₁, because they're strongly correlated.

## 3. Kernel density estimation

Estimate a two-peaked density from 50 samples with Gaussian kernels of three widths, and score each on fresh data.

```python
def sample(n):
    which = rng.random(n) < 0.3
    return np.where(which, rng.normal(-2, 0.5, n), rng.normal(1, 1.0, n))

train, test = sample(50), sample(5000)

def kde(points, data, h):
    d = points[:, None] - data[None, :]
    return np.mean(np.exp(-d ** 2 / (2 * h ** 2)) / np.sqrt(2 * np.pi * h ** 2), axis=1)

for h in [0.05, 0.4, 3.0]:
    print(f"h = {h:4}: average log-density on new data = {np.mean(np.log(kde(test, train, h))):.3f}")
```

```output
h = 0.05: average log-density on new data = -3.483
h =  0.4: average log-density on new data = -1.795
h =  3.0: average log-density on new data = -2.266
```

The tiny width over-fits (spikes on each training point, so new points get low density), the huge width
under-fits (one big blur), and the middle wins. Same story as the polynomial order M.

## 4. K nearest neighbours as a classifier

Section 3.5.3 ends with the nearest-neighbour classifier. Here it is on two Gaussian clouds.

```python
A = rng.normal([0, 0], 1.0, size=(100, 2))
B = rng.normal([2, 2], 1.0, size=(100, 2))
Xtr = np.vstack([A, B]); ytr = np.array([0] * 100 + [1] * 100)
Xte = np.vstack([rng.normal([0, 0], 1.0, (500, 2)), rng.normal([2, 2], 1.0, (500, 2))])
yte = np.array([0] * 500 + [1] * 500)

def knn_predict(Xq, K):
    d = ((Xq[:, None, :] - Xtr[None, :, :]) ** 2).sum(-1)
    nearest = np.argsort(d, axis=1)[:, :K]
    return (ytr[nearest].mean(axis=1) > 0.5).astype(int)

for K in [1, 15, 151]:
    print(f"K = {K:3d}: test accuracy {np.mean(knn_predict(Xte, K) == yte):.3f}")
```

```output
K =   1: test accuracy 0.893
K =  15: test accuracy 0.925
K = 151: test accuracy 0.924
```

K = 1 follows every noisy training point and does worst. Larger K smooths the boundary, and these two clouds are
simple enough that even K = 151 does well. On data with a twisty boundary between the classes, a very large K would
blur the twists away: the same under-fitting you saw with a too-wide kernel.
