# Build: basis functions, LMS and the bias–variance experiment

## 1. Gaussian basis functions

Build a design matrix of 24 Gaussian bumps plus a bias column, the same setup as the book's Figure 4.7.

```python
import numpy as np

rng = np.random.default_rng(0)
centres = np.linspace(0, 1, 24)
s = 0.1                                            # width of each bump

def design(x):
    bumps = np.exp(-(x[:, None] - centres[None, :]) ** 2 / (2 * s ** 2))
    return np.hstack([np.ones((len(x), 1)), bumps])   # φ₀ = 1, then 24 Gaussians

def make_data(n, noise=0.3):
    x = rng.random(n)
    return x, np.sin(2 * np.pi * x) + rng.normal(0, noise, n)

def fit(x, t, lam):
    Phi = design(x)
    return np.linalg.solve(lam * np.eye(Phi.shape[1]) + Phi.T @ Phi, Phi.T @ t)

x, t = make_data(25)
print("design matrix shape:", design(x).shape)
```

```output
design matrix shape: (25, 25)
```

## 2. Sequential learning (LMS)

Instead of solving the normal equations, visit the points one at a time and nudge the weights (section 4.1.5). After
enough passes it approaches the regularized solution.

```python
lam = np.exp(-2.4)
w_exact = fit(x, t, lam)

w = np.zeros(25)
eta = 0.05
Phi = design(x)
for epoch in range(3000):
    for n in rng.permutation(len(x)):
        err = t[n] - w @ Phi[n]
        w += eta * (err * Phi[n] - lam / len(x) * w)     # squared error step, plus a little weight decay
print("largest gap to the exact solution:", round(np.abs(w - w_exact).max(), 4))
```

```output
largest gap to the exact solution: 0.0292
```

The penalty is split evenly across the 25 points (`lam / len(x)`), so one pass over the data applies it once in total.
Stochastic updates land close to, not exactly on, the exact answer, because each step only sees one point. A smaller
step size η closes the gap further, at the cost of more passes.

## 3. The bias–variance experiment

Now the real thing: L = 100 data sets of N = 25 points, fitted with three values of λ. For each λ, measure on a fine grid
of x:

- **bias²**: the squared gap between the *average* fit and the true sine,
- **variance**: how much the individual fits spread around their average,
- **test error**: the error on fresh noisy points, which should be about bias² + variance + noise.

```python
grid = np.linspace(0, 1, 1000)
truth = np.sin(2 * np.pi * grid)
G = design(grid)
datasets = [make_data(25) for _ in range(100)]
x_test, t_test = make_data(1000)

print(" ln λ    bias²   variance   sum    test error")
for ln_lam in [2.6, -0.31, -2.4]:
    fits = np.array([G @ fit(xd, td, np.exp(ln_lam)) for xd, td in datasets])
    avg = fits.mean(axis=0)
    bias2 = np.mean((avg - truth) ** 2)
    var = np.mean(fits.var(axis=0))
    test = np.mean([np.mean((design(x_test) @ fit(xd, td, np.exp(ln_lam)) - t_test) ** 2) for xd, td in datasets])
    print(f"{ln_lam:5.2f}   {bias2:6.3f}   {var:7.3f}   {bias2 + var:5.3f}   {test:6.3f}")
```

```output
 ln λ    bias²   variance   sum    test error
 2.60    0.066     0.011   0.077    0.156
-0.31    0.001     0.023   0.025    0.108
-2.40    0.001     0.036   0.037    0.119
```

Read the table from top to bottom:

- **ln λ = 2.6**: heavy regularization. Tiny variance, big bias: every fit is too flat in the same way.
- **ln λ = −2.4**: light regularization. Small bias, bigger variance: each fit chases its own noise.
- **ln λ = −0.31** sits in between, and has the smallest sum and the smallest test error.

The test error is roughly bias² + variance + 0.09, where 0.09 is the noise variance (0.3²). That's the decomposition from
section 4.3, measured instead of derived.
