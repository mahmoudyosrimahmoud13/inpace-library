# Capstone: backup.sh, done properly

The script from the course outline: it **checks** prerequisites, **creates** a backup, **verifies** it, **logs**, **handles failures**, **alerts**, and **cleans up** old backups.

```bash
#!/usr/bin/env bash
# backup.sh: back up directories to a dated archive, verify, alert, and prune.
# Usage: backup.sh [-n] [-k DAYS] DIR...
set -euo pipefail

readonly DEST=${BACKUP_DEST:-/var/backups/files}
readonly LOG=${BACKUP_LOG:-/var/log/backup.log}
keep=7; dry=0

log()    { printf '%s %s\n' "$(date '+%F %T')" "$*" | tee -a "$LOG" >&2; }
die()    { log "ERROR: $*"; notify "backup FAILED on $(hostname): $*"; exit 1; }
notify() { [[ -n ${WEBHOOK_URL:-} ]] || return 0
           curl -fsS -m 10 -H 'Content-Type: application/json' \
             -d "$(jq -n --arg t "$1" '{text:$t}')" "$WEBHOOK_URL" >/dev/null || true; }
usage()  { echo "Usage: $0 [-n] [-k DAYS] DIR..." >&2; exit 2; }

while getopts ":nk:" o; do
  case $o in n) dry=1 ;; k) keep=$OPTARG ;; *) usage ;; esac
done
shift $((OPTIND - 1))
(( $# > 0 )) || usage

# 1. Check prerequisites
for cmd in tar gzip jq curl flock; do command -v "$cmd" >/dev/null || die "missing $cmd"; done
[[ $keep =~ ^[0-9]+$ ]] || die "-k needs a number of days"
for d in "$@"; do [[ -d $d ]] || die "not a directory: $d"; done
mkdir -p "$DEST"
exec 9>"$DEST/.lock"; flock -n 9 || { log "another backup is running"; exit 0; }

need=$(du -sk "$@" | awk '{s+=$1} END {print s}')
free=$(df -k --output=avail "$DEST" | tail -1)
(( free > need )) || die "not enough space in $DEST (need ${need}K, have ${free}K)"

# 2. Create
archive="$DEST/backup-$(hostname)-$(date +%F_%H%M).tar.gz"
tmp=$(mktemp "$DEST/.partial.XXXXXX")
trap 'rm -f "$tmp"' EXIT
if (( dry )); then log "DRY RUN: would write $archive from $*"; exit 0; fi
log "starting backup of $* to $archive"
tar czf "$tmp" --absolute-names "$@" 2>>"$LOG" || die "tar failed"

# 3. Verify (readable archive, non-empty, checksum saved)
gzip -t "$tmp" || die "archive is corrupt"
tar tzf "$tmp" >/dev/null || die "archive listing failed"
mv "$tmp" "$archive"
sha256sum "$archive" > "$archive.sha256"
log "verified $(du -h "$archive" | cut -f1) $(basename "$archive")"

# 4. Clean up old backups
find "$DEST" -name 'backup-*.tar.gz*' -type f -mtime +"$keep" -print -delete | while read -r f; do log "pruned $f"; done

notify "backup OK on $(hostname): $(basename "$archive")"
log "done"
```

## Map it to the course

| Part | Day |
|---|---|
| Strict mode, `die`, exit codes | 2 |
| `getopts`, usage | 2 |
| Tests, loops over `"$@"` | 3 |
| Functions | 4 |
| `trap`, `mktemp`, `flock`, logging | 5 |
| Dry run, checks first, idempotent prune | 5 |
| `jq`, `awk` | 6 |
| Alerts | 7 |

Writing to a `.partial` file and renaming only after verification means a crash mid-backup never leaves a half-written archive that looks complete.
