# Project: a daily server report

Build `report.sh`, which prints a short health report and exits with a code that says whether anything needs attention.

```bash
#!/usr/bin/env bash
set -euo pipefail

warn=0
line() { printf '%-22s %s\n' "$1" "$2"; }
flag() { line "$1" "$2  <-- CHECK"; warn=1; }

echo "Report for $(hostname) at $(date '+%F %T')"
echo "----------------------------------------"

load=$(cut -d' ' -f1 /proc/loadavg)
cpus=$(nproc)
if awk -v l="$load" -v c="$cpus" 'BEGIN {exit !(l > c)}'; then
  flag "Load (${cpus} CPUs)" "$load"
else
  line "Load (${cpus} CPUs)" "$load"
fi

avail=$(awk '/MemAvailable/ {printf "%d", $2/1024}' /proc/meminfo)
(( avail < 500 )) && flag "Memory available" "${avail} MB" || line "Memory available" "${avail} MB"

while read -r use mount; do
  use=${use%\%}
  (( use > 85 )) && flag "Disk $mount" "${use}%" || line "Disk $mount" "${use}%"
done < <(df -x tmpfs -x devtmpfs --output=pcent,target | tail -n +2)

failed=$(systemctl --failed --no-legend | wc -l)
(( failed > 0 )) && flag "Failed services" "$failed" || line "Failed services" "0"

errors=$(journalctl -p err --since "24 hours ago" -q | wc -l)
(( errors > 50 )) && flag "Errors (24h)" "$errors" || line "Errors (24h)" "$errors"

exit "$warn"
```

## What to notice

- `< <(...)` (process substitution) feeds a command's output into a `while` loop **without** a pipe, so variables set inside the loop (like `warn`) survive.
- awk does the decimal comparison bash can't (`load` is `1.42`, and `(( ))` only knows whole numbers).
- The exit code (0 fine, 1 needs attention) is what makes it useful to cron, monitoring and CI.

## Make it yours

Add checks for: pending updates (`apt list --upgradable 2>/dev/null | wc -l`), certificate expiry (`openssl x509 -enddate -noout -in cert.pem`), or whether a URL answers (`curl -sf`).
