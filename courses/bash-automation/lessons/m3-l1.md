# Tests, if and case

## `[[ ]]`: the bash test

```bash
if [[ -f $file ]]; then
  echo "exists"
elif [[ -d $file ]]; then
  echo "is a directory"
else
  echo "missing"
fi
```

Prefer `[[ ]]` over the old `[ ]`: no word-splitting surprises inside, and it supports `&&`, `||`, patterns and regex.

| Test | True when |
|---|---|
| `-e f` / `-f f` / `-d f` | Exists / is a regular file / is a directory |
| `-r f` / `-w f` / `-x f` | Readable / writable / executable |
| `-s f` | Exists and isn't empty |
| `-z $s` / `-n $s` | String is empty / not empty |
| `$a == $b` / `$a != $b` | Strings equal / differ |
| `$s == *.log` | Glob pattern match |
| `$s =~ ^[0-9]+$` | Regex match (`BASH_REMATCH` holds groups) |
| `f1 -nt f2` | f1 is newer than f2 |

Numbers: use arithmetic, which reads like normal maths:

```bash
if (( used > 90 )); then echo "critical"; fi
(( retries < 3 )) && echo "try again"
```

## case: many choices

```bash
case "$1" in
  start)          systemctl start myapp ;;
  stop)           systemctl stop myapp ;;
  restart|reload) systemctl restart myapp ;;
  *.tar.gz|*.tgz) tar xzf "$1" ;;
  "")             echo "Usage: $0 start|stop|restart" >&2; exit 2 ;;
  *)              echo "Unknown: $1" >&2; exit 2 ;;
esac
```

`case` matches **glob patterns**, which makes it perfect for subcommands and file types.
