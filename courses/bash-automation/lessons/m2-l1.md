# Arguments, input and options

## Positional parameters

```bash
#!/usr/bin/env bash
# greet.sh NAME [GREETING]
echo "Script: $0"
echo "First: $1, second: ${2:-Hello}"
echo "Count: $#"
echo "All: $@"
```

| Variable | Holds |
|---|---|
| `$0` | The script's name |
| `$1` ... `$9`, `${10}` | Arguments |
| `$#` | How many arguments |
| `"$@"` | All arguments, each one kept separate (use this) |
| `$*` | All arguments as one string (rarely what you want) |

Loop over every argument safely:

```bash
for f in "$@"; do
  echo "Processing $f"
done
```

`shift` drops `$1` and moves the rest down; handy in loops.

## Usage messages

```bash
usage() { echo "Usage: $0 SOURCE_DIR DEST_DIR" >&2; exit 2; }
[[ $# -eq 2 ]] || usage
```

Errors go to **stderr** (`>&2`), so they don't end up in someone's output file.

## Asking the user

```bash
read -rp "Delete $dir? [y/N] " answer
[[ $answer == [yY] ]] || exit 0
read -rsp "Password: " pw; echo     # -s: don't echo what is typed
```

Scripts that run from cron have nobody to answer. Prefer options to questions.

## Options with getopts

```bash
#!/usr/bin/env bash
verbose=0; keep=7
while getopts ":vk:h" opt; do
  case $opt in
    v) verbose=1 ;;
    k) keep=$OPTARG ;;
    h) echo "Usage: $0 [-v] [-k DAYS] DIR"; exit 0 ;;
    :) echo "Option -$OPTARG needs a value" >&2; exit 2 ;;
    \?) echo "Unknown option -$OPTARG" >&2; exit 2 ;;
  esac
done
shift $((OPTIND - 1))       # now $1 is the first non-option argument
dir=${1:?Usage: $0 [-v] [-k DAYS] DIR}
```

`getopts` handles short options (`-v -k 14`, or `-vk14`). For long options (`--keep`) you parse by hand with a `while` and `case`, or reach for Python.
