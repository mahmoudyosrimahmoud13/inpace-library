# Arrays and string tricks

## Indexed arrays

```bash
servers=(web01 web02 "db 01")
echo "${servers[0]}"            # web01
echo "${#servers[@]}"           # 3 items
servers+=(cache01)              # append
for s in "${servers[@]}"; do    # quoted [@]: each item stays whole, even "db 01"
  echo "$s"
done
```

Arrays are the safe way to build a command with options:

```bash
args=(-a --delete)
[[ $dry_run == 1 ]] && args+=(--dry-run)
rsync "${args[@]}" "$src/" "$dest/"
```

Lines of a command into an array:

```bash
mapfile -t users < <(cut -d: -f1 /etc/passwd)
echo "${#users[@]} accounts"
```

## Associative arrays (bash 4+)

```bash
declare -A port=([web]=80 [db]=5432 [cache]=6379)
port[ssh]=22
for name in "${!port[@]}"; do
  echo "$name -> ${port[$name]}"
done
```

## String operations without external tools

| Expression | With `f=/var/log/app.log.gz` |
|---|---|
| `${f##*/}` | `app.log.gz` (like `basename`) |
| `${f%/*}` | `/var/log` (like `dirname`) |
| `${f%.gz}` | `/var/log/app.log` (remove a suffix) |
| `${f%%.*}` | `/var/log/app` (remove the longest suffix) |
| `${f#/var/}` | `log/app.log.gz` (remove a prefix) |
| `${f/log/LOG}` | `/var/LOG/app.log.gz` (replace first) |
| `${f//log/LOG}` | replace all |
| `${#f}` | length |
| `${f^^}` / `${f,,}` | upper / lower case |
| `${f:0:4}` | first 4 characters |

Memory trick: `#` is on the left of `$` on a keyboard, so it cuts from the **left**; `%` is on the right.

```bash
for f in *.jpeg; do mv -- "$f" "${f%.jpeg}.jpg"; done   # rename all .jpeg to .jpg
```
