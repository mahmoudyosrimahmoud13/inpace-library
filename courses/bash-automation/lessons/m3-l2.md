# Loops, and reading files line by line

## for

```bash
for host in web01 web02 db01; do
  ssh "$host" uptime
done

for f in /var/log/*.log; do           # a glob: safe with spaces, no ls needed
  [[ -e $f ]] || continue             # nothing matched: skip
  echo "$(wc -l < "$f") $f"
done

for (( i = 1; i <= 5; i++ )); do echo "try $i"; done
for i in {1..10}; do echo "$i"; done
```

**Never** loop over `$(ls)`: it breaks on spaces and odd names. Use globs, or `find ... -print0` with `while read`.

## while and until

```bash
until curl -sf http://localhost:8080/health > /dev/null; do
  echo "waiting for the app..."; sleep 2
done

retries=0
while ! ping -c1 -W1 db01 &>/dev/null; do
  (( ++retries >= 10 )) && { echo "db01 never came up" >&2; exit 1; }
  sleep 3
done
```

## Reading a file line by line (the right way)

```bash
while IFS= read -r line; do
  echo "got: $line"
done < servers.txt
```

- `IFS=` keeps leading and trailing spaces.
- `-r` keeps backslashes as they are.

Split lines into fields:

```bash
while IFS=: read -r user _ uid _ _ home shell; do
  (( uid >= 1000 )) && echo "$user uses $shell"
done < /etc/passwd
```

Files from `find`, safely, even with spaces and newlines in names:

```bash
find /srv/uploads -type f -mtime +30 -print0 |
while IFS= read -r -d '' f; do
  echo "old: $f"
done
```

## break and continue

`break` leaves the loop; `continue` jumps to the next round. Both take a number for nested loops (`break 2`).
