# Read: autoencoders and variational autoencoders (chapter 19)

Read chapter 19 (pages 563 to 580).

## Deterministic autoencoders (19.1)

An **autoencoder** is trained to reproduce its input through a bottleneck: an encoder squeezes `x` into a small code `z`,
a decoder rebuilds `x` from it.

- **Linear autoencoders** (19.1.1): with linear layers and squared error, the best code is exactly the PCA subspace of
  part 4. The Build lesson checks this numerically.
- **Deep autoencoders** (19.1.2): non-linear layers can learn curved surfaces in data space, which PCA can't.
- **Sparse** (19.1.3), **denoising** (19.1.4) and **masked** (19.1.5) autoencoders change the task rather than the
  shape: force most code units to zero, rebuild a clean image from a corrupted one, or fill in hidden patches. Masked
  autoencoders are a powerful way to pre-train vision transformers.

But a plain autoencoder is a poor **generator**: decode a random code and you usually get garbage, because nothing makes
the codes fill a known region of space.

## Variational autoencoders (19.2)

The VAE fixes that by making the model probabilistic: `p(z) = N(0, I)`, and the decoder defines `p(x | z, w)`. The
likelihood `p(x)` needs an integral over `z` that can't be computed, so the VAE maximizes the **evidence lower bound**
(ELBO) from part 4's chapter 16 instead (19.6 to 19.12). Three ideas make it work, and the chapter lists them clearly:

1. **The ELBO**, as in the EM algorithm, but with a network instead of an exact posterior.
2. **Amortized inference** (19.2.1): instead of fitting a separate distribution `q(z)` for every data point, one
   **encoder** network outputs a Gaussian `q(z | x)` (a mean and a variance per latent dimension, 19.13) for any `x`.
3. **The reparameterization trick** (19.2.2): sampling isn't differentiable, but `z = μ + σ ε` with `ε ~ N(0, I)` is
   (19.17, 19.18), so gradients flow back into the encoder.

The ELBO splits into two terms (19.14): a **reconstruction** term (decode `z`, how likely is `x`?) and a **KL** term that
keeps each `q(z | x)` close to the prior. The KL term is what fills the latent space smoothly, so that random codes decode
to plausible images. Read the discussion of what can go wrong too: blurry samples, and a KL term so strong that the code
is ignored.

## What to take from the chapter

- Autoencoders learn compressed codes; linear ones are PCA.
- A VAE is an autoencoder trained as a probabilistic model: an encoder, a decoder, and a bound on the likelihood.
- Reconstruction and KL pull against each other, and that tension shapes the latent space you'll map in the project.
