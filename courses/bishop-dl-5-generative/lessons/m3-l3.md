# Build: an autoencoder that turns out to be PCA, and the VAE's KL term

Section 19.1.1 makes a surprising claim: an autoencoder with linear layers and a squared-error loss learns nothing more
than PCA, which you met in part 4. Today you check it: train a linear autoencoder on the digits by gradient descent and
compare it with PCA. Then you check the closed-form KL divergence that every VAE uses, against a brute-force estimate.

## 1. A linear autoencoder, trained by gradient descent

The 1,797 small digits from scikit-learn, 64 pixels each, centred. The encoder is a 64 × 5 matrix, the decoder a 5 × 64
matrix: squeeze each image into 5 numbers and rebuild it.

```python
import numpy as np
from sklearn.datasets import load_digits

X = load_digits().data / 16.0
X = X - X.mean(0)                               # centred, as PCA assumes
N, D, M = len(X), 64, 5

rng = np.random.default_rng(0)
W_enc = rng.normal(0, 0.1, (D, M))
W_dec = rng.normal(0, 0.1, (M, D))
for step in range(1, 30001):
    Z = X @ W_enc                               # encode: 5 numbers per image
    R = Z @ W_dec - X                           # reconstruction error
    g_dec = Z.T @ R / N                         # gradients of half the mean squared error
    g_enc = X.T @ (R @ W_dec.T) / N
    W_dec -= 0.05 * g_dec
    W_enc -= 0.05 * g_enc
    if step in (1, 1000, 10000, 30000):
        print(f"step {step:5d}: mean squared error per pixel {np.mean(R ** 2):.5f}")
```

```output
step     1: mean squared error per pixel 0.07597
step  1000: mean squared error per pixel 0.03365
step 10000: mean squared error per pixel 0.03337
step 30000: mean squared error per pixel 0.03337
```

## 2. The same thing as PCA?

PCA's best 5-dimensional reconstruction projects onto the 5 leading eigenvectors of the covariance matrix. Compare the
errors, and compare the **subspaces**: the autoencoder's 5 directions don't have to be PCA's eigenvectors one by one, but
they should span the same 5-dimensional space. The cosines of the angles between two subspaces (the singular values of
`U_pcaᵀ U_ae`) are all 1 when the spaces are identical.

```python
cov = X.T @ X / N
eigval, eigvec = np.linalg.eigh(cov)
U_pca = eigvec[:, ::-1][:, :M]                  # the 5 leading principal directions
pca_error = np.mean((X @ U_pca @ U_pca.T - X) ** 2)
print(f"PCA error per pixel:         {pca_error:.5f}")
print(f"autoencoder error per pixel: {np.mean((X @ W_enc @ W_dec - X) ** 2):.5f}")

U_ae, _ = np.linalg.qr(W_dec.T)                 # an orthonormal basis of the decoder's 5 directions
cosines = np.linalg.svd(U_pca.T @ U_ae, compute_uv=False)
print("cosines of the angles between the two subspaces:", np.round(cosines, 4))
```

```output
PCA error per pixel:         0.03337
autoencoder error per pixel: 0.03337
cosines of the angles between the two subspaces: [1. 1. 1. 1. 1.]
```

The autoencoder has found PCA's subspace, by gradient descent, without ever computing an eigenvector. That's why
autoencoders only become interesting with **non-linear** layers: then they can learn curved surfaces that PCA can't
(section 19.1.2).

## 3. The KL term of a VAE

A VAE's loss contains `KL(q(z | x) ‖ p(z))`, where `q` is a Gaussian with mean `μ` and variance `σ²` from the encoder, and
`p(z) = N(0, 1)`. For one dimension it has a closed form:

```text
KL = ½ (μ² + σ² − 1 − ln σ²)
```

Check it against the definition, `E_q[ln q(z) − ln p(z)]`, estimated with a million samples from `q`.

```python
log_normal = lambda z, m, v: -0.5 * (np.log(2 * np.pi * v) + (z - m) ** 2 / v)
rng = np.random.default_rng(1)
for mu, var in [(0.0, 1.0), (1.5, 0.5), (-2.0, 0.1)]:
    z = rng.normal(mu, np.sqrt(var), 1_000_000)
    sampled = np.mean(log_normal(z, mu, var) - log_normal(z, 0.0, 1.0))
    closed = 0.5 * (mu ** 2 + var - 1 - np.log(var))
    print(f"mu {mu:+.1f}, variance {var}: closed form {closed:.4f}, by sampling {sampled:.4f}")
```

```output
mu +0.0, variance 1.0: closed form 0.0000, by sampling 0.0000
mu +1.5, variance 0.5: closed form 1.2216, by sampling 1.2236
mu -2.0, variance 0.1: closed form 2.7013, by sampling 2.7001
```

When `q` is exactly the prior (`μ = 0`, `σ² = 1`) the KL is zero: that code costs nothing. Moving the mean away or
shrinking the variance costs more, so the KL term pulls every image's code towards the prior. That's what makes a VAE's
latent space smooth enough to sample from, as you'll see in the module project.

## What to take away

- A linear autoencoder with squared error learns the PCA subspace: depth and non-linearity are what make autoencoders
  more powerful.
- The VAE's KL term has a simple closed form for Gaussians, and it keeps the codes close to `N(0, I)`.
