# Project 3: pretrain TinyGPT

You'll train the model to predict the next token over Shakespeare, watch both losses, and read samples as they
improve.

The code is above this text. Save it as `p3_train.py`. It takes **10 to 20 minutes** on a laptop CPU (14 minutes on
the 2-core machine that made the output below), and much less with a GPU.

## Read the code

- The text is tokenized once. The first 90% is for training; the last 10% (**validation**) is never trained on.
- **`batches()`** picks 32 random windows of 128 tokens. The targets are the same windows shifted by one: every
  position predicts the next token.
- The training loop is the one from every deep learning course: forward, loss, backward, clip gradients, step.
  **AdamW** with weight decay, and a learning rate that warms up for 100 steps then follows a **cosine** curve down.
- Every 500 steps, **`estimate()`** averages the loss on 40 batches from each part, and **`sample()`** writes 40
  tokens after `ROMEO:` so you can read progress.
- The weights and settings are saved to `tinygpt.pt` for days 4 and 5.

## Run it

```bash
python p3_train.py
```

What it shows:

- **At step 0, noise.** By step 500 it has learned the shape of a play: names in capitals, a colon, a line break, a
  speech, a blank line. Then the words get better: by the end, real words, often in a plausible order.
- **Training loss keeps falling; validation loss falls more slowly**, and the gap grows (2.74 against 3.18). The gap
  is the model memorizing its training text a little. Watch the validation number: it's the only one that tells you
  about new text.
- A loss of 3.18 means the right next token gets, on average, a probability of about 1 in 24.

This is **pretraining**: the same objective as the base models in the lessons, at a tiny scale.

## Make it yours

1. Train for 500 steps with `LR = 1e-2`, then with `1e-4`. What happens to the loss each time?
2. Set `dropout` to 0 in `CONFIG` and train again. Does the gap between the two losses grow?
3. **Fine-tune**: load `tinygpt.pt`, then train 300 more steps only on the lines of one character (filter the text
   for speeches after `ROMEO:`), with a 10 times smaller learning rate. Do samples start to sound like Romeo?

## What to take away

- Pretraining is next-token prediction on lots of text, with a held-out part to stay honest.
- Structure is learned first, then words, then (with far more data and size) meaning.
