# Pretraining: learning from the internet

**Pretraining** is where nearly all the knowledge and most of the cost goes. The recipe is simple to state:

1. Collect a huge amount of text: filtered web pages, books, code, scientific papers. Modern models train on trillions of tokens.
2. Show the model a piece of text, ask it to predict each next token, and measure how wrong it was (the **loss**: low when it gave the right token a high probability).
3. Adjust every parameter slightly to reduce the loss (**gradient descent**, with gradients from **backpropagation**).
4. Repeat for months on thousands of GPUs.

```python
import numpy as np

def cross_entropy(probs, target):
    return -np.log(probs[target])

probs = np.array([0.92, 0.03, 0.02, 0.03])   # model's guess for the next token; index 0 is ' Cairo'
print(round(cross_entropy(probs, 0), 3))      # 0.083: confident and right, low loss
print(round(cross_entropy(probs, 2), 3))      # 3.912: the true token got 2%, high loss
```

Training pushes the loss down averaged over trillions of such predictions. To predict text well, the model has to pick up grammar, facts, styles, and patterns of reasoning, because all of them help guess the next token.

## Data is the product

- **Quality filters** remove spam, duplicates and low-quality pages; deduplication matters a lot.
- **Mixture:** the share of code, maths, languages and domains shapes what the model is good at.
- **Cutoff:** the data stops at a date, so the model's knowledge does too.
- **Contamination:** if benchmark questions leak into training data, scores look better than real ability.

## Scaling laws

Researchers found that loss falls smoothly and predictably as you increase three things together: **parameters**, **data** and **compute**. DeepMind's Chinchilla paper (2022) showed many models were too big for their data, and suggested roughly 20 training tokens per parameter for compute-optimal training. Today's models are often trained on far more tokens than that, because a smaller model trained longer is cheaper to run for millions of users.

## The result: a base model

A pretrained **base model** continues documents. Ask it "What is the capital of Egypt?" and it may continue with more quiz questions, because that's what such text on the web looks like. Turning it into an assistant is the next lesson.
