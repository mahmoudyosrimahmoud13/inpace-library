# Project 5: evaluate TinyGPT

You'll measure the model against simple baselines on text it never saw, check what it learned, and check how much
it copies.

The code is above this text. Save it as `p5_evaluate.py`.

## Read the code

- **`model_loss()`** runs the model over the whole validation part in windows of 128 tokens and averages the loss.
- **Baselines**, with the same tokenizer and data: a uniform guess; a **unigram** model (each token's frequency); a
  **bigram** model (the next token given only the previous one). Both add 1 to every count so nothing has zero
  probability.
- **Perplexity** is `exp(loss)`: how many tokens the model is, in effect, choosing between at each step.
- **The format check** generates 5 samples and counts lines that are a name and a colon, and how many of those
  names are real characters.
- **The copy check** cuts the samples into pieces of 10, 20 and 40 characters and looks for each piece word for word
  in the training text.

## Run it

```bash
python p5_evaluate.py
```

The real output:

```text
1. Loss and perplexity on the last 10% of the text, never trained on (lower is better):
   uniform guess                  loss 6.24   perplexity  512.0
   token frequencies (unigram)    loss 5.55   perplexity  258.0
   previous token only (bigram)   loss 4.04   perplexity   56.7
   TinyGPT                        loss 3.19   perplexity   24.3
   Perplexity is how many tokens the model is, in effect, choosing between at each step.

2. Did it learn the format of a play? In 5 samples, 25 lines are a speaker's name and a colon:
   ['ANGELO:', 'BRUTUS:', 'BUCKINGHAM:', 'CLARENCE:', 'CLIFFFORD:', 'CORIOLANUS:', 'DUKE VINCENTIO:', 'First Gentleman:']
   23 of 25 are real characters from the plays

3. Pieces of 10 characters in the samples found word for word in the training text: 30%
3. Pieces of 20 characters in the samples found word for word in the training text: 2%
3. Pieces of 40 characters in the samples found word for word in the training text: 0%
   Short pieces are often common phrases; longer ones are almost never copied: it writes new text in the style of the plays.
```

What it shows:

- **TinyGPT beats every baseline**: perplexity 24 against 57 for the bigram. Looking at the whole window, not only
  the last token, is what the transformer adds.
- **It learned the format**: 25 speaker lines in 5 samples, 23 of them real characters (and one, `CLIFFFORD`, nearly).
- **It doesn't copy**: about a third of 10-character pieces appear in the plays (common phrases), almost none of 20,
  none of 40. It writes new text in the style. Large models do sometimes reproduce long passages; this check is how
  you'd find out.
