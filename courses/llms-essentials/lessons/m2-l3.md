# Project 2: build the transformer

You'll write TinyGPT's model, a small GPT, look inside one attention layer, and check it's wired right before
training.

The code is above this text: `gpt.py` (the model) and `p2_model.py`.

## Read the code

**`gpt.py`**, in the order data flows:

- **Embeddings**: `tok` turns each token id into 128 numbers; `pos` adds 128 numbers for its position.
- **`SelfAttention`**: one linear layer makes queries, keys and values for 4 heads at once. Scores are `q @ k`,
  divided by the square root of the head size, then the **causal mask** (`torch.tril`) blocks every later position
  before the softmax. The weights are kept in `last_weights` so you can look at them. (The `cache` part is for
  day 4.)
- **`Block`**: layer norm, attention, add it back (a **residual connection**); layer norm, a small MLP, add it back.
- **`GPT`**: 4 blocks, a final layer norm, and a head that scores all 512 tokens. The head shares its weights with
  the token embeddings, as in GPT-2. `_init` starts all weights small, as GPT-2 does.
- **`forward()`** returns the scores (logits) and, given targets, the cross-entropy loss.

**`p2_model.py`** counts parameters, runs a line through the model, prints head 1's attention weights, changes the
last token to check nothing earlier changes, and measures the starting loss.

## Run it

```bash
python p2_model.py
```

What it shows:

- **875,264 parameters.** GPT-2 small has 124 million; today's large models have hundreds of billions. Same parts.
- Each block has about 198,000 parameters, most in the MLP (4 × 128 wide).
- **The untrained attention spreads evenly** over the past: each row is roughly 1 divided by the number of tokens it
  can see. Training will make it pick.
- **The causal mask works**: changing the last token changes nothing before it. That's what lets the model learn
  from every position of a sequence at once.
- **The starting loss is 6.25**, almost exactly ln(512): the model starts by guessing evenly. A much higher number
  would mean a wiring or initialization bug.

## What to take away

- A GPT is embeddings, a stack of attention and MLP blocks with residuals, and a head.
- Check the shapes, the mask and the starting loss before spending time on training.
