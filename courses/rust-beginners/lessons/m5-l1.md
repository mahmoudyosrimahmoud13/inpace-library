# Vec, String and HashMap

The three collections you'll use most.

## Vec: a list that grows

```rust
fn main() {
    let mut scores: Vec<i32> = Vec::new();
    scores.push(70);
    scores.push(85);
    let mut more = vec![92, 64];        // vec! makes a Vec from values
    scores.append(&mut more);

    println!("{:?} has {} items", scores, scores.len());
    println!("first {}, last {:?}", scores[0], scores.last());

    for s in &scores {                  // borrow to read
        print!("{s} ");
    }
    println!();

    for s in &mut scores {              // borrow to change
        *s += 5;
    }
    println!("{:?}", scores);

    scores.sort();
    scores.retain(|&s| s >= 75);        // keep only some
    println!("{:?}", scores);
}
```

```output
[70, 85, 92, 64] has 4 items
first 70, last Some(64)
70 85 92 64 
[75, 90, 97, 69]
[75, 90, 97]
```

- `for s in &scores` borrows; `for s in scores` would **move** the vector into the loop, using it up.
- `*s += 5` changes the item through the mutable reference (`*` follows the reference).
- `scores[10]` stops the program; `scores.get(10)` returns `None` instead.

## Iterators: the Rust way to process lists

Instead of index loops, chain **iterator** methods:

```rust
fn main() {
    let prices = vec![12.5, 40.0, 7.25, 99.0, 18.0];

    let total: f64 = prices.iter().sum();
    let cheap: Vec<f64> = prices.iter().copied().filter(|&p| p < 20.0).collect();
    let with_tax: Vec<String> = prices.iter().map(|p| format!("{:.2}", p * 1.14)).collect();
    let most = prices.iter().copied().fold(f64::MIN, f64::max);

    println!("total {total}");
    println!("cheap {:?}", cheap);
    println!("with tax {:?}", with_tax);
    println!("most {most}");
    println!("any over 50? {}", prices.iter().any(|&p| p > 50.0));
}
```

```output
total 176.75
cheap [12.5, 7.25, 18.0]
with tax ["14.25", "45.60", "8.26", "112.86", "20.52"]
most 99
any over 50? true
```

- `.iter()` borrows each item; `.copied()` turns `&f64` into `f64`.
- `filter`, `map` and friends are **lazy**: nothing happens until `collect`, `sum`, `count` or a `for` loop pulls the values.
- `|p| p * 1.14` is a **closure** (Rust's lambda).
- `.collect()` builds a collection; you say which kind with the variable's type.

## String

```rust
fn main() {
    let mut s = String::from("Cairo");
    s.push_str(" is");
    s.push(' ');
    s += "huge";
    println!("{s} ({} bytes)", s.len());

    let upper = s.to_uppercase();
    let words: Vec<&str> = s.split(' ').collect();
    println!("{upper} / {:?}", words);
    println!("contains 'is'? {}", s.contains("is"));
    println!("{}", s.replace("huge", "busy"));

    let arabic = "مرحبا";
    println!("{} bytes, {} letters", arabic.len(), arabic.chars().count());
}
```

```output
Cairo is huge (13 bytes)
CAIRO IS HUGE / ["Cairo", "is", "huge"]
contains 'is'? true
Cairo is busy
10 bytes, 5 letters
```

`len()` counts **bytes**. Arabic letters take 2 bytes in UTF-8, so count letters with `.chars().count()`. For the same reason you can't write `s[0]`: a byte might be half a letter.

## HashMap: key to value

```rust
use std::collections::HashMap;

fn main() {
    let text = "the cat saw the dog and the cat ran";
    let mut count: HashMap<&str, u32> = HashMap::new();
    for w in text.split_whitespace() {
        *count.entry(w).or_insert(0) += 1;
    }

    println!("'the' appears {} times", count["the"]);
    println!("'cow': {:?}", count.get("cow"));

    let mut pairs: Vec<(&str, u32)> = count.into_iter().collect();
    pairs.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(b.0)));   // most common first, then A to Z
    for (word, n) in pairs.iter().take(3) {
        println!("{word}: {n}");
    }
}
```

```output
'the' appears 3 times
'cow': None
the: 3
cat: 2
and: 1
```

- `entry(key).or_insert(0)` gets the value for a key, inserting 0 first if it's missing. Then `+= 1`.
- `get` returns an `Option`; `count["the"]` stops the program if the key is missing.
- A HashMap has **no order**: printing it directly gives a different order each run. Collect into a Vec and sort when order matters, or use `BTreeMap`, which keeps keys sorted.

## Summary

- `Vec<T>`: push, len, get, sort, retain; borrow with `&v` / `&mut v` in loops.
- Iterators (`iter`, `map`, `filter`, `sum`, `collect`) replace most index loops.
- `String` is UTF-8 (count letters with `chars()`); `HashMap` with `entry().or_insert()` counts things.
