# Your first Rust program

Rust is a systems language like C and C++: fast, no garbage collector, close to the machine. What makes it different is that the compiler **checks your memory and thread safety** before the program ever runs. Whole families of bugs (dangling pointers, double frees, data races) simply don't compile.

It's used in Firefox, the Linux kernel, Windows, Android, Cloudflare, Discord and many command-line tools. It's also been voted the most admired language by developers for years running.

## Install Rust

Go to **rustup.rs** and follow the one-line install. On Linux and macOS:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

On Windows, download `rustup-init.exe` from the same site. Then check:

```bash
rustc --version
cargo --version
```

To try Rust without installing anything, use the **Rust Playground** at play.rust-lang.org.

For an editor, VS Code with the **rust-analyzer** extension is excellent: it shows types, errors and suggestions as you type.

## Cargo: Rust's project tool

You'll rarely call the compiler directly. **Cargo** creates projects, builds them, runs them, runs tests and downloads libraries ("crates").

<!-- diagram -->
```mermaid
flowchart LR
  N["cargo new hello"] --> P["hello/<br/>Cargo.toml<br/>src/main.rs"]
  P -- "cargo run" --> B["compiles to target/debug/hello"]
  B --> R["runs it: Hello, world!"]
```

```bash
cargo new hello
cd hello
cargo run
```

Cargo made this layout:

```text
hello/
  Cargo.toml      project name, version, dependencies
  src/
    main.rs       your code
```

and `src/main.rs` already contains:

```rust
fn main() {
    println!("Hello, world!");
}
```

```output
Hello, world!
```

`cargo run` compiles and runs it. The first build is slower; later builds only recompile what changed.

## Line by line

- `fn main()` declares the function where the program starts.
- `println!` prints a line. The `!` means it's a **macro**, not a normal function. Macros can do things functions can't, like take a varying number of arguments and check the format text while compiling.
- Statements end with `;`.

## Printing values

`{}` in the text is replaced by the next value:

```rust
fn main() {
    let cups = 42;
    let price = 3.5;
    println!("Cups sold: {}", cups);
    println!("{} cups at {} each = {}", cups, price, cups as f64 * price);
    println!("Total: {total:.2}", total = cups as f64 * price);
    let name = "Rust";
    println!("Hello, {name}!");
}
```

```output
Cups sold: 42
42 cups at 3.5 each = 147
Total: 147.00
Hello, Rust!
```

- `{:.2}` prints 2 decimal places.
- `{name}` uses a variable directly.
- `cups as f64` converts the whole number to a decimal. Rust never mixes number types silently, so you must convert on purpose.

## Useful Cargo commands

| Command | Does |
|---|---|
| `cargo run` | build and run |
| `cargo build` | build only (into `target/debug/`) |
| `cargo build --release` | optimized build (into `target/release/`), much faster programs |
| `cargo check` | check for errors without building, very fast |
| `cargo test` | run the tests |
| `cargo fmt` | format your code the standard way |
| `cargo clippy` | extra advice about your code |

## Reading compiler errors

Rust's error messages are famously helpful. They point to the exact spot, explain the problem and often suggest the fix:

```text
error[E0425]: cannot find value `cupz` in this scope
 --> src/main.rs:3:20
  |
3 |     println!("{}", cupz);
  |                    ^^^^ help: a local variable with a similar name exists: `cups`
```

Read them fully. In Rust, fighting the compiler at first is normal; it's catching bugs that other languages let you ship.

## Summary

- Install with rustup; create and run projects with `cargo new` and `cargo run`.
- `println!("{}", x)` prints; `{name}` and `{:.2}` format values.
- Rust converts numbers only when you say so (`as f64`); read error messages fully.
