# Tags and versions

A **tag** is a name that stays on one commit forever, usually a version.

```bash
git tag v1.2.0                          # lightweight tag: just a name
git tag -a v1.2.0 -m "Notes and Add all"   # annotated: with a message, author and date (use this for releases)
git tag                                 # list
git show v1.2.0
git push origin v1.2.0                  # tags are NOT pushed by a normal git push
git push --follow-tags                  # push commits and their annotated tags
git describe                            # e.g. v1.2.0-3-g9c8b7a6: 3 commits after v1.2.0
git tag -d v1.2.0 && git push origin :refs/tags/v1.2.0   # delete a tag here and on GitHub
```

## Semantic versioning

`MAJOR.MINOR.PATCH`, like `1.25.1`:

- **PATCH** (1.25.0 → 1.25.1): bug fixes only.
- **MINOR** (1.24 → 1.25): new features, nothing breaks.
- **MAJOR** (1.x → 2.0): something that worked before may break.

In the GitHub course, a pushed tag will build and publish a release by itself.
