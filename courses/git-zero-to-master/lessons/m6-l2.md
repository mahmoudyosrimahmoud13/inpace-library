# Interactive rebase: edit your history

Before you open a pull request, tidy your commits: join small fixes, fix messages, change the order, drop experiments.

> **Optional video above.** Part of freeCodeCamp's *Advanced Git Tutorial* (with Tower), from 1:23 to 8:54. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```bash
git rebase -i HEAD~4      # the last 4 commits open in your editor, OLDEST FIRST
```

```text
pick 1a2b3c4 Add login form
pick 5d6e7f8 Fix typo
pick 9a8b7c6 Add validation
pick 3c4d5e6 wip
```

Change the word at the start of each line, save and close:

| Word | Does |
|---|---|
| `pick` | keep the commit |
| `reword` | keep it, edit the message |
| `squash` | join into the commit above, edit the joined message |
| `fixup` | join into the commit above, keep the above message |
| `drop` | delete the commit |
| `edit` | stop there, so you can change the commit (then `git commit --amend` and `git rebase --continue`) |

Moving lines changes the order. Here, `fixup` on *Fix typo* and `drop` on *wip* leave two clean commits.

## Fixups made easy

Made a fix for an older commit? Mark it when you commit, and let Git place it:

```bash
git commit --fixup=1a2b3c4          # message: "fixup! Add login form"
git rebase -i --autosquash main     # the fixup moves under its commit by itself
git config --global rebase.autoSquash true   # always do that
```
