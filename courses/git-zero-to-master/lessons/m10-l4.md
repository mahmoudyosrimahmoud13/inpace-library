# Where to go next

An optional lesson.

- **Next course:** *GitHub: pull requests, the CLI and Actions*: reviews, the `gh` command, and automatic tests and releases.
- **The book:** [Pro Git](https://git-scm.com/book) is free and complete (in English). Chapter 10 (Git Internals) goes deeper than module 9.
- **Practice:** [Learn Git Branching](https://learngitbranching.js.org) is a game with levels for rebase, cherry-pick and more, in your browser.
- **Real life:** contribute to an open-source project you use. Nothing teaches Git like a real review.
