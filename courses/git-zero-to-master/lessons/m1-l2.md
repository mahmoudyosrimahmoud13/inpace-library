# Install and set up Git

- **Windows:** install [Git for Windows](https://git-scm.com/download/win). Keep the default choices. It also gives you **Git Bash**, a terminal where every command in this course works.
- **Mac:** open Terminal and type `git --version`. If Git isn't there, the Mac offers to install it.
- **Linux:** `sudo apt install git` (Ubuntu, Debian) or `sudo dnf install git` (Fedora).

## Tell Git who you are

Every commit records a name and an email. Set them once for your computer (`--global`):

```bash
git config --global user.name "Mona Hassan"
git config --global user.email "mona@example.com"
git config --global init.defaultBranch main     # new projects start on a branch called main
git config --global core.editor "code --wait"   # VS Code opens for long messages (optional)
git config --global pull.rebase true            # module 5 explains this one

git config --list --show-origin                  # see every setting and which file it comes from
```

Use the same email as your GitHub account, so GitHub links your commits to you. If you want to keep your email private, GitHub gives you a `...@users.noreply.github.com` address in **Settings → Emails**.

## Getting help

`git help commit` opens the full manual for a command, and `git commit -h` prints a short summary. The manuals are long but exact: experts read them all the time.
