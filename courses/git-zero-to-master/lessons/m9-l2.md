# Refs, HEAD and detached HEAD

A **ref** is a name for a commit hash, stored as a tiny file:

```bash
cat .git/HEAD                    # ref: refs/heads/main  (HEAD points to a branch)
cat .git/refs/heads/main         # 9c8b7a6...  (the branch points to a commit)
git rev-parse main               # the same, the proper way (refs can also live in .git/packed-refs)
git show-ref                      # every branch, remote branch and tag
```

So a branch really is a 41-byte file, and a commit moves it by rewriting that file.

## Detached HEAD

If you switch to a commit (or tag) instead of a branch, HEAD points straight at a commit:

```bash
git switch --detach v1.2.0       # look around an old version
# You are in 'detached HEAD' state...
```

Looking is fine. But commits you make here belong to no branch: switch away and they're only in the reflog. To keep them, make a branch **before** you leave: `git switch -c try-old-idea`.
