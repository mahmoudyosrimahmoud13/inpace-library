# cherry-pick: copy one commit

`git cherry-pick` copies a commit from another branch onto yours, as a new commit. Typical use: a bug fix made on main that you also need on a release branch.

> **Optional video above.** Part of freeCodeCamp's *Advanced Git Tutorial* (with Tower), from 8:54 to 12:10. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```bash
git switch release-1.2
git cherry-pick 9c8b7a6          # copy that commit here
git cherry-pick -x 9c8b7a6       # also write "cherry picked from ..." in the message
git cherry-pick a1b2c3d..9c8b7a6 # a range (everything after a1b2c3d, up to 9c8b7a6)
git cherry-pick --continue / --abort   # after a conflict, like a rebase
```

Committed on the wrong branch? Cherry-pick the commit to the right branch, then remove it from the wrong one with `git reset --hard HEAD~1` (if it isn't pushed).
