# The reflog: Git's safety net

You ran `git reset --hard` and lost commits? They aren't gone. Git records every place HEAD has been, for about 90 days, in the **reflog**:

```bash
git reflog
# 3f2e1d0 HEAD@{0}: reset: moving to HEAD~2
# 9c8b7a6 HEAD@{1}: commit: Add tests
# 5d4c3b2 HEAD@{2}: commit: Add login form

git reset --hard 9c8b7a6        # go back to where you were
# or keep both: put a branch on the lost commit
git branch rescue 9c8b7a6
```

The reflog is local: it's only on your computer, and it only knows commits that were committed. Uncommitted work thrown away by `git restore` or `reset --hard` isn't in it. **Commit often**: a commit can almost always be saved.
