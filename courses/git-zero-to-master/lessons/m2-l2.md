# Reading history

```bash
git log                         # full: hash, author, date, message
git log --oneline --graph --all # the whole tree, one line per commit (use this a lot)
git log -p README.md            # every change to one file, with its diff
git log --stat                  # which files each commit touched
git log --author="Mona" --since="2 weeks ago"
git log --grep="login"          # commits whose message mentions login
git show a1b2c3d                # one commit: message and diff
git show HEAD~2:README.md       # a file as it was 2 commits ago
```

## Naming commits

- **The hash:** `a1b2c3d` (the first 7 characters are enough).
- **HEAD:** the commit you're on now.
- **HEAD~1**, **HEAD~2**: one and two commits back. `HEAD^` is the same as `HEAD~1`.
- **A branch name**, like `main`: the newest commit on that branch.

Make a short alias for the log you'll use most:

```bash
git config --global alias.lg "log --oneline --graph --all --decorate"
git lg
```
