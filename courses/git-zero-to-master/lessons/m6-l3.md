# Conflicts during a rebase

A rebase replays commits one at a time, so it can stop at a commit with a conflict. Resolve it like a merge conflict, then:

```bash
git add page.html
git rebase --continue     # go on to the next commit (NOT git commit)
git rebase --skip         # leave this commit out
git rebase --abort        # stop, everything back as before the rebase
```

**Careful:** during a rebase, "ours" is the branch you're rebasing **onto** (main), and "theirs" is **your** commit. It's the opposite of a merge. If a rebase went wrong after it finished, `git reset --hard ORIG_HEAD` goes back to before it, and the reflog always has it too.
