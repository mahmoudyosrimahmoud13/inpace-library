# Connect to GitHub with an SSH key

GitHub doesn't accept your password for Git. Use an **SSH key**: a pair of files on your computer, one private (never share it) and one public (you give it to GitHub). Set it up once:

> **Optional video above.** Part of freeCodeCamp's *Git and GitHub for Beginners, Crash Course*, from 20:30 to 30:21. Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```bash
ssh-keygen -t ed25519 -C "mona@example.com"   # press Enter to accept the place; a passphrase is a good idea
cat ~/.ssh/id_ed25519.pub                      # the PUBLIC key: copy all of it
# GitHub: Settings -> SSH and GPG keys -> New SSH key -> paste
ssh -T git@github.com                          # "Hi mona! You've successfully authenticated"
```

Then use **SSH addresses** for your repositories, the ones that start with `git@github.com:`, not `https://`:

```bash
git clone git@github.com:mona/notes.git
git remote set-url origin git@github.com:mona/notes.git   # switch an existing repo from https
```
