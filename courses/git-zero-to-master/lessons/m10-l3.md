# Signed commits

Anyone can set `user.name` to your name. A **signature** proves a commit really came from you, and GitHub shows it as **Verified**. The simplest way uses the SSH key you already have:

```bash
git config --global gpg.format ssh
git config --global user.signingkey ~/.ssh/id_ed25519.pub
git config --global commit.gpgsign true
git config --global tag.gpgsign true
# GitHub: Settings -> SSH and GPG keys -> New SSH key -> Key type: Signing Key -> paste the same .pub
git log --show-signature -1
```

Many companies and open-source projects require signed commits on main (a branch protection rule you'll set in the GitHub course).
