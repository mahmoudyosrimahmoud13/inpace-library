# Shipping it: library alerts, Markdown, a real installer, and deleting everything

## 1. New courses: a badge and one notification

The library is a static `library.json` on GitHub Pages. Twice a day, in a background thread, the app downloads
it and compares course ids with the ones it has already seen (`library_known` in the `meta` table).

- **The first look only remembers.** Otherwise every course would be "new" on day one.
- New ids go to `library_new`: a number on **Course library** in the menu, a note and **New** tags in the library
  (new courses first), and one system notification.
- Opening the library clears the badge.

**Interview point:** "what's new" needs a baseline. Decide what happens on the very first run.

## 2. Markdown the way people write it

Lessons use `markdown-it-py` with the CommonMark preset plus tables. People (and AI tools) also write GitHub-style
extras, which rendered wrong: `~~strike~~`, bare links, `- [ ]` task lists, `> [!NOTE]` boxes, and footnotes
(`[^1]` became a broken link and the note vanished, because `[^1]: text` parses as a *link reference definition*).

`inpace/mdfix.py` adds them **without new packages**: core rules that walk the token stream (bare links, task
boxes, note boxes) and a small pre/post step for footnotes that leaves code blocks alone.

## 3. A real Windows installer

Windows Defender flagged inPace. The cause: a PyInstaller **one-file** `.exe`, which unpacks itself to a temp
folder on every start, the pattern scanners distrust most.

What changed:
- PyInstaller **one-folder** build, no UPX, and a **version resource** (company, product, version).
- **Inno Setup** wraps it into `inPace-setup.exe`: per-user install (no admin), Start menu, an uninstaller in
  *Installed apps*, `inpace://` links registered under `HKCU\Software\Classes`.
- Updates download `inPace-setup.exe`, check it against `SHA256SUMS`, and run it with
  `/VERYSILENT /RELAUNCH=1`; a `[Run]` entry with `Check: Relaunch` opens inPace again.
- CI installs it silently, checks the files and their version info, uninstalls, and checks nothing is left.
- Old one-file copies still get a legacy zip once, so they can reach the version that knows about the installer.

**Honest limit:** the blue SmartScreen "unknown publisher" box only goes away with **code signing**.

## 4. Delete all my data

Settings has a red card. You type **DELETE** (or the translated word), optionally tick "also the downloaded
videos", and inPace closes the database, empties its folder, reopens an empty vault, and clears the system
reminders. The next page is the welcome page.

**Interview point:** local-first apps must give a clean exit too: the user's data, the user's decision.

## The pattern behind this week

Most bugs here weren't in the logic. They were in what surrounds it: a version label, a cache header, a working
directory, a packaging format. When something "doesn't show up", check **what reached the user**, not just the code.
