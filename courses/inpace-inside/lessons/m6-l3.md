# Reminders on every platform

inPace isn't running most of the time, so reminders are **handed to the operating system**:

| System | How |
|---|---|
| Windows | Task Scheduler tasks; toasts via PowerShell, with Tempo's face (`appLogoOverride`) |
| Mac | launchd agents; `osascript` notifications |
| Linux | systemd user timers (or cron); `notify-send -i tempo.png` |
| Android | the page sends `reminders.plan()` to Flutter, which schedules with flutter_local_notifications |

On a computer, the scheduler runs `inpace --remind <id>` or `inpace --check-reminders` (hourly), which shows what's
due and exits. It never opens the window.

## The focus trip in a notification (Android)

Every page tells the app the trip state (`#inpace-trip`). Flutter shows an **ongoing** notification with
`usesChronometer: true, chronometerCountDown: true, when: endTime`: **Android draws the countdown itself**, so it
keeps going when inPace is closed. `timeoutAfter` removes it at the end, and an **exact** alarm says
"your plant is ready".
