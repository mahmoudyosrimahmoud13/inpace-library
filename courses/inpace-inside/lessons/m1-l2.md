# The stack and the code map

## The stack

| Layer | Choice | Why |
|---|---|---|
| Language | Python 3.10+ | One language for logic, files, crypto and builds |
| Web server | Uvicorn + **Starlette** | Small, fast, ASGI; no extra framework layers |
| Pages | **Jinja2** templates, plain CSS and one `app.js` | Works without a build step; fast on old phones |
| Database | **SQLite** (`vault.db`) | One file, no server, transactions, triggers |
| Crypto | **PyNaCl** (Ed25519 signatures, Argon2id, SecretBox) | Well-reviewed, simple API |
| Desktop window | **pywebview** (falls back to the browser) | A real app window around the local server |
| Desktop builds | **PyInstaller** | One installable file per system |
| Android | A **Flutter** shell + **serious_python** | Flutter draws the WebView and notifications; Python runs the same app |
| Lesson extras | markdown-it, Pygments, pdf.js, Mermaid | All bundled, all offline |

## The code map

```text
inpace/
  __main__.py     starts the server on a free port, opens the window
  app.py          every route and page (about 3,100 lines, 112 routes)
  vault.py        the database: tables, events, milestones, people
  identity.py     your signing key; canon.py makes canonical JSON and fingerprints
  course.py       reads and checks courses; editor.py, organize.py and ai.py make them
  exchange.py     contact cards, progress files, approvals, links
  checks.py       what the checker sees, verified exams, file requests
  exam.py         exams built from a seed, the same on every device
  pace.py         weekly goals, pauses, spaced review, encrypted backups
  races.py        friendly races between learners
  garden.py       Tempo's island; garden_art.py and mascot.py draw it as SVG
  reminders.py    reminders and Tempo's notifications; notifier.py talks to each OS
  library.py      the online course library
  updater.py      checks, downloads and installs updates safely
  templates/      Jinja pages; static/ CSS, JS, fonts, pdf.js, Mermaid
mobile/           Flutter shell (lib/main.dart) and the Android build
packaging/        PyInstaller builds and release helpers
tests/            pytest, run on Windows, Mac and Linux on every push
```

About 12,000 lines of Python, with `app.py` the largest. A good first reading order: `__main__.py`, the top
of `app.py` (`create_app`, `page`, `go`), then `vault.py`.
