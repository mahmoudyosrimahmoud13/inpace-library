# Two languages, and right to left

## Translation without gettext files

`locales/ar.json` maps **English text to Arabic text**. Templates use `{% trans %}` and `_()`; Python uses
`say()` and `t("... {name} ...", name=...)`. Missing strings fall back to English. Pros: no .po/.mo build
step, the English text is the key, easy to review. Cons: changing English text means re-keying the Arabic.

## Direction

- The page gets `<html lang="ar" dir="rtl">`.
- CSS uses **logical properties** (`margin-inline-start`, `padding-inline`, `inset-inline-start`), so most
  layout flips by itself.
- User content gets `dir="auto"`; lessons get per-block direction (Day 3).
- Icons that mean a direction (back/forward arrows) are mirrored in RTL.

## Fonts

Hanken Grotesk and Newsreader for Latin, IBM Plex Sans Arabic for Arabic, all bundled. An offline app can't count
on Google Fonts.
