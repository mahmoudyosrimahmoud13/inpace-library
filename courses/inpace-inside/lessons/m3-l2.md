# How a lesson is drawn

`app.py` renders lesson Markdown with **markdown-it** (CommonMark plus tables, raw HTML off), then
`media.lesson_html` turns special links into players.

## The Markdown pipeline

1. `_highlight` colours code blocks with **Pygments** on the device. A block marked `mermaid` becomes
   `<pre class="mermaid">`, drawn later in the page by the bundled Mermaid library (with zoom and full screen).
2. A core rule `_bidi` gives every paragraph, heading, list item, quote and table cell its own `dir`, by
   counting Arabic words against Latin words (code and links don't count). Mixed Arabic/English lessons read right.
3. Media: `![](video.mp4)`, a lone YouTube link, `book.pdf#pages=12-19`, `.docx/.pptx/.xlsx`, `.html`.

## Where files are found

In order: a full path, the course's own files (`<home>/media/<course>/`), then the folder the learner pointed
inPace to, trying shorter and shorter endings of the path, so a moved folder still works.

## Safety

- Web pages in lessons run with `Content-Security-Policy: sandbox allow-scripts ...; connect-src 'none'`:
  they work, but can't reach inPace, your data or the internet.
- Office files are previewed by reading their XML with Python's own tools, with size caps, and files that try
  XML tricks are refused.
- YouTube loads only when you press play, through youtube-nocookie.
