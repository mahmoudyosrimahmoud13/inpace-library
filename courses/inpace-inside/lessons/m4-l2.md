# Navigation done right

Most "the screen didn't update" bugs in web apps come from navigation. inPace's rules:

| Rule | How |
|---|---|
| Never show a stale page | `Cache-Control: no-store` on every HTML response (NavMiddleware) |
| Never resend a form with Back | Post/Redirect/Get: every POST answers with a redirect |
| Sent forms don't pile up in history | `data-nav-form`: send with `fetch`, then `location.replace(go)` |
| One-off pages vanish from Back | `<meta name="inpace-dispose" content="/where-it-belongs">`: if Back lands there, replace it |
| Bfcache doesn't show old colours | `pageshow` with `persisted` reloads the page |
| Same page, new state | `goFresh`: if only the `#hash` differs, reload |

```js
function goFresh(url) {
  const next = new URL(url, location.href);
  const samePage = next.pathname === location.pathname && next.search === location.search;
  if (samePage && next.hash) { history.replaceState(history.state, "", next.href); location.reload(); }
  else location.replace(next.href);
}
```

The quiz is a good example: `POST /quiz` saves the attempt and redirects to `/quiz/result`. The result page is
**disposable**: Back skips it and goes to the course, so you never see or resend old answers.
