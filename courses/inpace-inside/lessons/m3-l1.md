# The course format

A course is a folder (or a `.lpack` zip):

```text
course.yaml      id, title, version, language, description, modules (lessons + requires)
lessons/*.md     the lesson text in Markdown
questions.yaml   quiz questions and their options (neutral ids)
answers.yaml     which options are right, and why
files/           small files: the cover, PDFs, pictures
```

## Two shapes, one model

AI chats produce an **all-in-one** `course.yaml` with `content:` inside each lesson and questions as
`right: [...]` and `wrong: [...]` lists. `course.py` converts it to the split shape, giving each option a
**neutral id**: `"o" + sha256(qid + "\x1f" + text)[:6]`. Neutral ids matter: if right answers were always `a`,
anyone could cheat.

## The fingerprint and the answers

A course's `hash` is the fingerprint of `{id, title, version, description, language, modules, questions}` with
lesson text inlined. **Answers are not included**, so a copy with or without answers is "the same course", and
a checker can hold the answers privately.

## Tasks

Each module can require: a **practical** (upload proof), an **explain** (written answer with `min_words`),
and a **quiz** (`questions`, `pass` percent). The next module opens when the tasks are done.
