# Pace: goals, pauses, review and races

## Weekly commitments

A learner commits to N milestones a week. `pace.weeks()` builds weekly buckets from events and milestones:
this week's count, the goal, streaks, and a finish-date forecast. A **pause** (holiday, exams) is an event, so
it's part of the honest record too.

## Spaced review

Quiz questions go into **Leitner boxes**: right moves a card up a box, wrong sends it back to box 1. The days until
the next review: box 1 → 1 day, 2 → 3, 3 → 7, 4 → 14, 5 → 30 (`LEITNER_DAYS`). The daily review shows only cards
that are due.

## Races

Friends race on a course for N days. Each racer's score comes from their **own signed records**, and they
exchange `race_update` files. No server keeps the scoreboard: each device computes it from the updates it has.
