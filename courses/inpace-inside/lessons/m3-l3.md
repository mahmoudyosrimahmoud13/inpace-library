# Making and sharing courses

## Four ways in

- **By hand**, in the editor (forms) or as one YAML file.
- **From a folder** of class material: `organize.py` sorts files by lecture or week, and you can move things
  before adding.
- **From a PDF book**: chapters come from the bookmarks; each section becomes a lesson that opens only its pages.
- **With AI**: `ai.py` writes a prompt for the source you have (topic, book, playlist, exam...). You paste it into
  any AI chat and paste the YAML back. inPace never calls an AI on its own.

## The library

A public GitHub repository (`inpace-library`). The author makes a **signed** course file in the app and opens an
issue form. GitHub Actions (`library_tools.py`):

1. checks the course loads, the signature matches, and it's under 20 MB,
2. opens a pull request; a maintainer merges,
3. publishes `library.json`, `packs/<id>.zip` (each with a SHA-256) and the covers to GitHub Pages.

The app downloads a pack only when you press **Add**, and checks its SHA-256 against `library.json`. Updates to a
course are accepted only when signed by the **same key**, so nobody can take over someone else's course.
