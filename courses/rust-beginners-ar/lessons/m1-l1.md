# أول برنامج لك بلغة Rust

‏Rust لغة أنظمة مثل C وC++: سريعة، وبدون جامع قمامة، وقريبة من الآلة. وما يميزها أن الـ compiler **يتحقق من أمان الذاكرة والـ threads** قبل أن يعمل البرنامج أصلًا. عائلات كاملة من الأخطاء (الـ pointers المعلّقة، والـ double free، وdata races) ببساطة لا تُترجم.

تُستخدم في Firefox ونواة Linux وويندوز وأندرويد وCloudflare وDiscord وأدوات كثيرة لسطر الأوامر. واختارها المبرمجون اللغة الأكثر إعجابًا لسنوات متتالية.

## تثبيت Rust

ادخل على **rustup.rs** واتبع أمر التثبيت المكوّن من سطر واحد. على Linux وماك:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

على ويندوز، نزّل `rustup-init.exe` من نفس الموقع. ثم تحقق:

```bash
rustc --version
cargo --version
```

ولتجربة Rust بدون تثبيت أي شيء، استخدم **Rust Playground** على play.rust-lang.org.

وكمحرر، VS Code مع إضافة **rust-analyzer** ممتاز: يعرض الأنواع والأخطاء والاقتراحات وأنت تكتب.

## ‏Cargo: أداة مشاريع Rust

نادرًا ما ستستدعي الـ compiler مباشرة. **Cargo** يُنشئ المشاريع ويبنيها ويشغّلها ويشغّل الاختبارات وينزّل المكتبات ("crates").

<!-- diagram -->
```mermaid
flowchart LR
  N["cargo new hello"] --> P["hello/<br/>Cargo.toml<br/>src/main.rs"]
  P -- "cargo run" --> B["يترجم إلى target/debug/hello"]
  B --> R["يشغّله: Hello, world!"]
```

```bash
cargo new hello
cd hello
cargo run
```

صنع Cargo هذا التنظيم:

```text
hello/
  Cargo.toml      project name, version, dependencies
  src/
    main.rs       your code
```

والملف `src/main.rs` يحتوي بالفعل على:

```rust
fn main() {
    println!("Hello, world!");
}
```

```output
Hello, world!
```

‏`cargo run` يترجم ويشغّل. البناء الأول أبطأ؛ والبناءات اللاحقة لا تعيد ترجمة إلا ما تغيّر.

## سطرًا بسطر

- `fn main()` تعلن عن الـ function التي يبدأ منها البرنامج.
- `println!` تطبع سطرًا. وعلامة `!` معناها أنها **ماكرو (macro)** وليست function عادية. والماكرو تستطيع أشياء لا تستطيعها الـ functions، مثل أخذ عدد variable من المعاملات والتحقق من نص التنسيق أثناء الترجمة.
- الجمل تنتهي بـ `;`.

## طباعة القيم

‏`{}` داخل النص تُستبدل بالقيمة التالية:

```rust
fn main() {
    let cups = 42;
    let price = 3.5;
    println!("Cups sold: {}", cups);
    println!("{} cups at {} each = {}", cups, price, cups as f64 * price);
    println!("Total: {total:.2}", total = cups as f64 * price);
    let name = "Rust";
    println!("Hello, {name}!");
}
```

```output
Cups sold: 42
42 cups at 3.5 each = 147
Total: 147.00
Hello, Rust!
```

- `{:.2}` تطبع منزلتين عشريتين.
- `{name}` تستخدم variable مباشرة.
- `cups as f64` تحوّل العدد الصحيح إلى عشري. ‏Rust لا تخلط أنواع الأرقام بصمت أبدًا، فيجب أن تحوّل عن قصد.

## أوامر Cargo مفيدة

| الأمر | ماذا يفعل |
|---|---|
| `cargo run` | يبني ويشغّل |
| `cargo build` | يبني فقط (في `target/debug/`) |
| `cargo build --release` | بناء محسّن (في `target/release/`)، برامج أسرع بكثير |
| `cargo check` | يتحقق من الأخطاء بدون بناء، سريع جدًا |
| `cargo test` | يشغّل الاختبارات |
| `cargo fmt` | ينسّق الكود بالطريقة القياسية |
| `cargo clippy` | نصائح إضافية عن كودك |

## قراءة أخطاء الـ compiler

رسائل أخطاء Rust مشهورة بأنها مفيدة. تشير إلى المكان بالضبط، وتشرح المشكلة، وغالبًا تقترح الحل:

```text
error[E0425]: cannot find value `cupz` in this scope
 --> src/main.rs:3:20
  |
3 |     println!("{}", cupz);
  |                    ^^^^ help: a local variable with a similar name exists: `cups`
```

اقرأها كاملة. في Rust، من الطبيعي في البداية أن تشعر أنك تتصارع مع الـ compiler؛ إنه يكتشف أخطاء تسمح لك لغات أخرى بتسليمها للمستخدمين.

## الخلاصة

- ثبّت بـ rustup؛ وأنشئ المشاريع وشغّلها بـ `cargo new` و`cargo run`.
- `println!("{}", x)` تطبع؛ و`{name}` و`{:.2}` تنسّقان القيم.
- ‏Rust لا تحوّل الأرقام إلا عندما تطلب ذلك (`as f64`)؛ واقرأ رسائل الأخطاء كاملة.
