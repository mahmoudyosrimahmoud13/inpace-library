# ‏Vec وString وHashMap

المجموعات الثلاث التي ستستخدمها أكثر من غيرها.

## ‏Vec: قائمة تكبر

```rust
fn main() {
    let mut scores: Vec<i32> = Vec::new();
    scores.push(70);
    scores.push(85);
    let mut more = vec![92, 64];        // vec! makes a Vec from values
    scores.append(&mut more);

    println!("{:?} has {} items", scores, scores.len());
    println!("first {}, last {:?}", scores[0], scores.last());

    for s in &scores {                  // borrow to read
        print!("{s} ");
    }
    println!();

    for s in &mut scores {              // borrow to change
        *s += 5;
    }
    println!("{:?}", scores);

    scores.sort();
    scores.retain(|&s| s >= 75);        // keep only some
    println!("{:?}", scores);
}
```

```output
[70, 85, 92, 64] has 4 items
first 70, last Some(64)
70 85 92 64 
[75, 90, 97, 69]
[75, 90, 97]
```

- `for s in &scores` تستعير؛ أما `for s in scores` فست**نقل** الـ vector إلى الـ loop وتستهلكه.
- `*s += 5` تغيّر العنصر عبر الـ reference القابل للتغيير (`*` تتبع الـ reference).
- `scores[10]` توقف البرنامج؛ و`scores.get(10)` ترجع `None` بدلًا من ذلك.

## الـ iterators: طريقة Rust في معالجة القوائم

بدل loops الفهرس، اربط functions **الـ iterator**:

```rust
fn main() {
    let prices = vec![12.5, 40.0, 7.25, 99.0, 18.0];

    let total: f64 = prices.iter().sum();
    let cheap: Vec<f64> = prices.iter().copied().filter(|&p| p < 20.0).collect();
    let with_tax: Vec<String> = prices.iter().map(|p| format!("{:.2}", p * 1.14)).collect();
    let most = prices.iter().copied().fold(f64::MIN, f64::max);

    println!("total {total}");
    println!("cheap {:?}", cheap);
    println!("with tax {:?}", with_tax);
    println!("most {most}");
    println!("any over 50? {}", prices.iter().any(|&p| p > 50.0));
}
```

```output
total 176.75
cheap [12.5, 7.25, 18.0]
with tax ["14.25", "45.60", "8.26", "112.86", "20.52"]
most 99
any over 50? true
```

- `.iter()` تستعير كل عنصر؛ و`.copied()` تحوّل `&f64` إلى `f64`.
- `filter` و`map` وأخواتهما **كسولة**: لا يحدث شيء حتى تسحب `collect` أو `sum` أو `count` أو loop `for` القيم.
- `|p| p * 1.14` هي **closure** (lambda في Rust).
- `.collect()` تبني مجموعة؛ وتحدد نوعها بنوع الـ variable.

## ‏String

```rust
fn main() {
    let mut s = String::from("Cairo");
    s.push_str(" is");
    s.push(' ');
    s += "huge";
    println!("{s} ({} bytes)", s.len());

    let upper = s.to_uppercase();
    let words: Vec<&str> = s.split(' ').collect();
    println!("{upper} / {:?}", words);
    println!("contains 'is'? {}", s.contains("is"));
    println!("{}", s.replace("huge", "busy"));

    let arabic = "مرحبا";
    println!("{} bytes, {} letters", arabic.len(), arabic.chars().count());
}
```

```output
Cairo is huge (13 bytes)
CAIRO IS HUGE / ["Cairo", "is", "huge"]
contains 'is'? true
Cairo is busy
10 bytes, 5 letters
```

‏`len()` تعدّ **البايتات**. والحروف العربية تأخذ بايتين في UTF-8، فعدّ الحروف بـ `.chars().count()`. وللسبب نفسه لا تستطيع كتابة `s[0]`: فالبايت قد يكون نصف حرف.

## ‏HashMap: من مفتاح إلى قيمة

```rust
use std::collections::HashMap;

fn main() {
    let text = "the cat saw the dog and the cat ran";
    let mut count: HashMap<&str, u32> = HashMap::new();
    for w in text.split_whitespace() {
        *count.entry(w).or_insert(0) += 1;
    }

    println!("'the' appears {} times", count["the"]);
    println!("'cow': {:?}", count.get("cow"));

    let mut pairs: Vec<(&str, u32)> = count.into_iter().collect();
    pairs.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(b.0)));   // most common first, then A to Z
    for (word, n) in pairs.iter().take(3) {
        println!("{word}: {n}");
    }
}
```

```output
'the' appears 3 times
'cow': None
the: 3
cat: 2
and: 1
```

- `entry(key).or_insert(0)` تأخذ قيمة المفتاح، وتُدخل 0 أولًا لو كان غير موجود. ثم `+= 1`.
- `get` ترجع `Option`؛ و`count["the"]` توقف البرنامج لو كان المفتاح غير موجود.
- الـ HashMap **ليس لها ترتيب**: طباعتها مباشرة تعطي ترتيبًا مختلفًا في كل تشغيل. اجمعها في Vec ورتّبها عندما يهم الترتيب، أو استخدم `BTreeMap` التي تحافظ على ترتيب المفاتيح.

## الخلاصة

- `Vec<T>`: ‏push وlen وget وsort وretain؛ واستعر بـ `&v` / `&mut v` في الـ loops.
- الـ iterators (`iter` و`map` و`filter` و`sum` و`collect`) تحل محل أغلب loops الفهرس.
- `String` بترميز UTF-8 (عدّ الحروف بـ `chars()`)؛ و`HashMap` مع `entry().or_insert()` تعدّ الأشياء.
