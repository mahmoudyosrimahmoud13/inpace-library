# الـ Enums وmatch وOption

الـ enums في Rust أقوى بكثير منها في C. كل بديل (variant) يمكن أن يحمل بياناته الخاصة، و`match` تتأكد من أنك تتعامل مع كل واحد.

## ‏enum بسيط

```rust
#[derive(Debug)]
enum Direction {
    North,
    East,
    South,
    West,
}

fn turn_right(d: Direction) -> Direction {
    match d {
        Direction::North => Direction::East,
        Direction::East => Direction::South,
        Direction::South => Direction::West,
        Direction::West => Direction::North,
    }
}

fn main() {
    let d = turn_right(Direction::West);
    println!("{:?}", d);
}
```

```output
North
```

أضف اتجاهًا خامسًا وانسه في `match`، ولن يُترجم البرنامج حتى تتعامل معه.

## بدائل تحمل بيانات

```rust
enum Payment {
    Cash(f64),
    Card { amount: f64, last4: String },
    Voucher(String),
}

impl Payment {
    fn describe(&self) -> String {
        match self {
            Payment::Cash(a) => format!("cash {a}"),
            Payment::Card { amount, last4 } => format!("card ending {last4}: {amount}"),
            Payment::Voucher(code) => format!("voucher {code}"),
        }
    }
}

fn main() {
    let payments = [
        Payment::Cash(50.0),
        Payment::Card { amount: 120.0, last4: "4421".to_string() },
        Payment::Voucher("EID25".to_string()),
    ];
    for p in &payments {
        println!("{}", p.describe());
    }
}
```

```output
cash 50
card ending 4421: 120
voucher EID25
```

كل بديل يحمل بيانات مختلفة، و`match` تفكها إلى variables (`a` و`amount` و`last4` و`code`). وهذا هو نمط `std::variant` مع `visit` في C++، لكنه مبني داخل اللغة.

## ‏Option: لا مزيد من null

‏Rust **ليس فيها null**. القيمة التي قد تكون غير موجودة نوعها `Option<T>`، وهو مجرد enum:

```rust
enum Option<T> {
    Some(T),
    None,
}
```

لا تستطيع استخدام `Option<i32>` كـ `i32` بالصدفة. يجب أن تتحقق أولًا أيهما هو:

```rust
fn find_price(item: &str) -> Option<f64> {
    match item {
        "tea" => Some(15.0),
        "coffee" => Some(30.0),
        _ => None,
    }
}

fn main() {
    for item in ["coffee", "cake"] {
        match find_price(item) {
            Some(p) => println!("{item}: {p}"),
            None => println!("{item}: not on the menu"),
        }
    }

    // shorter forms
    if let Some(p) = find_price("tea") {
        println!("tea is {p}");
    }
    let cake = find_price("cake").unwrap_or(0.0);
    println!("cake or zero: {cake}");
}
```

```output
coffee: 30
cake: not on the menu
tea is 15
cake or zero: 0
```

- `if let Some(p) = ...` تشغّل الكتلة فقط عندما توجد قيمة.
- `.unwrap_or(default)` تعطي القيمة أو قيمة افتراضية.
- `.unwrap()` تعطي القيمة أو **توقف البرنامج** لو كانت None. مقبولة في التجارب السريعة؛ وتجنبها في الكود الحقيقي.

functions قياسية كثيرة ترجع Option: ‏`vec.first()` و`vec.get(i)` و`text.find(' ')` و`map.get(key)` و`iterator.max()`.

## functions Option مفيدة

```rust
fn main() {
    let nums = vec![4, 9, 2];
    let doubled = nums.first().map(|n| n * 2);       // Some(8)
    let empty: Vec<i32> = Vec::new();
    println!("{:?} {:?}", doubled, empty.first().map(|n| n * 2));
    println!("{}", nums.get(10).is_none());
    let biggest = nums.iter().max().copied().unwrap_or(0);
    println!("{biggest}");
}
```

```output
Some(8) None
true
9
```

‏`.map(f)` تغيّر القيمة الموجودة بالداخل لو وُجدت، وتترك None كما هي. وتسمح لك بالعمل مع القيم "المحتملة" بدون كتابة `match` كل مرة.

## ‏let else

عندما لا تستطيع الـ function الاستمرار بدون قيمة، تأخذها `let ... else` أو تخرج مبكرًا:

```rust
fn shout_first_word(s: &str) -> String {
    let Some(word) = s.split_whitespace().next() else {
        return String::from("(empty)");
    };
    word.to_uppercase()
}

fn main() {
    println!("{}", shout_first_word("hello there"));
    println!("{}", shout_first_word("   "));
}
```

```output
HELLO
(empty)
```

## الخلاصة

- بدائل الـ enum يمكن أن تحمل بيانات؛ و`match` تفكها ويجب أن تغطي كل بديل.
- `Option<T>` ‏(`Some(x)` أو `None`) تحل محل null؛ والـ compiler يجبرك على التحقق.
- استخدم `if let` و`let else` و`unwrap_or` و`map`؛ واترك `unwrap()` للتجارب.
