# Read: backpropagation and automatic differentiation (5.6)

**Backpropagation (5.6.1)**: a deep network is a long composition f_K ∘ … ∘ f_1. The chain rule turns its gradient into
a product of Jacobians. Computing that product **from the loss backwards** reuses intermediate results, so the
gradient with respect to *all* parameters costs about as much as one forward pass.

**Automatic differentiation (5.6.2)**: write any function as a **computation graph** of simple operations (+, ×, exp,
sin…). Each node knows its local derivative. **Reverse mode** sweeps from the output back to the inputs and gives the
whole gradient in one pass; that's what PyTorch's `loss.backward()` and `tf.GradientTape` do. Forward mode is cheaper
when there are few inputs and many outputs.

**Do on paper:** the book's example f(x) = √(x² + exp(x²)) + cos(x² + exp(x²)). Draw the graph, write the intermediate
variables, then do the backward pass by hand.
