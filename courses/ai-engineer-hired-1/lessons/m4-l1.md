# Ingest and chunk the documents

The model can only answer from what retrieval finds, and retrieval can only find what chunking kept intact. Keep the **source and page** on every chunk: that's what makes citations possible.

```python
# docanswer/ingest.py
"""Read the documents in data/raw and cut them into overlapping chunks that remember their source."""
import json
import re
from pathlib import Path

from pypdf import PdfReader


def read_documents(folder):
    for path in sorted(Path(folder).rglob("*")):
        if path.suffix.lower() == ".pdf":
            for page_no, page in enumerate(PdfReader(path).pages, 1):
                yield {"source": path.name, "page": page_no, "text": page.extract_text() or ""}
        elif path.suffix.lower() in (".md", ".txt"):
            yield {"source": path.name, "page": None, "text": path.read_text(encoding="utf-8")}


def chunk(text, size=800, overlap=150):
    """Pack paragraphs into chunks of about `size` characters; carry `overlap` characters into the next one."""
    paragraphs = [p.strip() for p in re.split(r"\n\s*\n", text) if p.strip()]
    chunks, current = [], ""
    for p in paragraphs:
        if current and len(current) + len(p) > size:
            chunks.append(current)
            current = current[-overlap:]           # a fact cut in two still appears whole once
        current = (current + "\n\n" + p).strip()
    if current:
        chunks.append(current)
    return chunks


def build_chunks(raw="data/raw", out="data/chunks.jsonl"):
    count = 0
    with open(out, "w", encoding="utf-8") as f:
        for doc in read_documents(raw):
            for i, text in enumerate(chunk(doc["text"])):
                row = {"id": f"{doc['source']}:{doc['page']}:{i}", "source": doc["source"], "page": doc["page"], "text": text}
                f.write(json.dumps(row, ensure_ascii=False) + "\n")
                count += 1
    return count


if __name__ == "__main__":
    print(build_chunks(), "chunks")
```

## Choices you'll be asked to justify

- **Size:** small chunks (300 to 500 characters) retrieve precisely but lose context; big ones (1,500+) keep context but dilute the match. 800 with overlap is a sensible start; then measure.
- **Overlap:** so a sentence cut at a boundary still appears whole somewhere.
- **Structure:** split on paragraphs and headings, not every N characters. Tables and lists need special care.
- **Scanned PDFs** have no text layer: `extract_text()` returns nothing, and you need OCR.

Run `python -m docanswer.ingest`, then open `data/chunks.jsonl` and read 20 random chunks. You'll find broken headers, page numbers and repeated footers. Cleaning them is part of the job.
