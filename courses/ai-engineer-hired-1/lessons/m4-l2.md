# Search: keywords, vectors and hybrid

**Keyword search (BM25)** is great at exact terms: article numbers, product codes, names. **Vector search** (embeddings) finds meaning: "time off" matches "annual leave". Each misses what the other catches, so production systems often combine them. **Reciprocal rank fusion** merges the two ranked lists without tuning weights: an item ranked well in both lists wins.

```python
# docanswer/search.py
"""Hybrid search: BM25 keywords plus embeddings, merged with reciprocal rank fusion (RRF)."""
import json
import re
from pathlib import Path

import numpy as np
from rank_bm25 import BM25Okapi


def tokenize(text):
    return re.findall(r"\w+", text.lower())


def rrf(rankings, k=5, c=60):
    """Merge several ranked lists of ids: each list gives 1 / (c + rank) to its items."""
    scores = {}
    for ranking in rankings:
        for rank, item in enumerate(ranking, 1):
            scores[item] = scores.get(item, 0.0) + 1.0 / (c + rank)
    return sorted(scores, key=scores.get, reverse=True)[:k]


class Searcher:
    def __init__(self, chunks_path="data/chunks.jsonl", model_name="sentence-transformers/all-MiniLM-L6-v2", model=None):
        self.chunks = [json.loads(line) for line in open(chunks_path, encoding="utf-8")]
        self.bm25 = BM25Okapi([tokenize(c["text"]) for c in self.chunks])
        if model is None:
            from sentence_transformers import SentenceTransformer
            model = SentenceTransformer(model_name)
        self.model = model
        cache = Path(chunks_path).with_suffix(".npy")     # delete it after you re-ingest
        if cache.exists():
            self.vectors = np.load(cache)
        else:
            self.vectors = self.model.encode([c["text"] for c in self.chunks], normalize_embeddings=True)
            np.save(cache, self.vectors)

    def keyword(self, query, n):
        return list(np.argsort(-self.bm25.get_scores(tokenize(query)))[:n])

    def semantic(self, query, n):
        q = self.model.encode([query], normalize_embeddings=True)[0]
        return list(np.argsort(-(self.vectors @ q))[:n])

    def search(self, query, k=5, pool=20):
        best = rrf([self.keyword(query, pool), self.semantic(query, pool)], k=k)
        return [self.chunks[i] for i in best]
```

## Where a vector database fits

For a few thousand chunks, NumPy in memory is enough and fast. Past a few hundred thousand, or when many servers share the index, use a vector database (pgvector, Qdrant, Weaviate, Pinecone). Say this trade-off in interviews: it shows you choose tools by need, not by fashion.
