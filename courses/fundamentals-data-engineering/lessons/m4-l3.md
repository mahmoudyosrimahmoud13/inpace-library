# Project 4: total cost of ownership for Inkwell's analytics

The owner has three offers for where Inkwell's analytics should run: a server in the office, a database on a cloud
virtual machine, or a serverless cloud warehouse. She asks which is cheapest. Your answer: "cheapest over three
years, counting our time".

The code is above this text. Save it as `p04_tco.py`.

## Read the code

- **`OPTIONS`** describes each choice: money up front (capex), the monthly bill (opex), **engineer hours per month**
  to keep it running, and data egress (the dashboard in the office downloads results from the cloud).
- The serverless option has `growth_per_month`: its bill grows with data and queries, 4% a month in this example.
- **`tco()`** adds it up month by month: direct costs (bills, egress) and people costs (hours times
  `ENGINEER_HOUR`).

**The prices are examples, not quotes.** Part of this project is replacing them with real ones.

## Run it

```bash
python p04_tco.py
```

The real output:

```text
Total cost of ownership over 36 months (example prices)

Option                             Direct     People      Total
Serverless cloud warehouse         14,616      4,320     18,936
Database on a cloud VM             10,008     14,400     24,408
Own server (on premises)           10,320     28,800     39,120

Cheapest over 36 months: Serverless cloud warehouse
People are 74% of the cost of 'Own server (on premises)': the part a price list never shows.

TOCO question for your write-up: what can't the team build while it looks after its own servers?
```

Look at the **Direct** column alone: the own server and the cloud VM look cheapest. Add the people, and the order
flips. This is the book's TCO argument in numbers.

## Make it yours

1. Look up today's prices: a cloud VM with 4 CPUs and 16 GB of memory, 500 GB of disk, and one serverless warehouse
   (BigQuery, Snowflake, Redshift Serverless, or MotherDuck). Put them into `OPTIONS`. Write down where each number
   came from.
2. Change `ENGINEER_HOUR` to a real hourly cost in your country. Does the winner change?
3. Make the serverless bill grow 10% a month instead of 4%. In which month does it overtake the cloud VM? (Hint: print
   the running totals inside `tco()`.)
4. Add an **ADR 3** to `ARCHITECTURE.md`: your choice, the TCO table, and one TOCO sentence: what the team won't build
   because of it.

## What to take away

- Direct costs are only part of TCO; people's time often dominates.
- Growth rates matter: the cheapest today isn't always the cheapest in year three.
- A cost decision is only as good as its sources. Write them down.
