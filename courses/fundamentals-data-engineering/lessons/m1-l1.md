# Start here

This course follows **Fundamentals of Data Engineering** by Joe Reis and Matt Housley (O'Reilly, 2022), chapter by
chapter. The book doesn't teach one tool. It teaches the **ideas that stay true whatever tools you use**: the data
engineering lifecycle (generation, storage, ingestion, transformation, serving), the "undercurrents" under every
stage (security, data management, DataOps, architecture, orchestration, software engineering), and how to choose
between options without following the hype.

Reading about pipelines isn't the same as building one. So **every day ends with a project you run yourself**. Over
thirteen days you build the whole data platform of a small, made-up online bookshop, **Inkwell Books**: its source
database, a data lake, incremental ingestion with change data capture, a star schema with history, a tested
transformation pipeline, a dashboard, a feature table for machine learning, privacy controls, tested backups, and an
orchestrator that runs it all every night.

## First, get the book

The book is **not inside this course**. Each **Read** lesson opens the right pages of *your own copy*: buy the eBook
or print edition from [O'Reilly](https://www.oreilly.com/library/view/fundamentals-of-data/9781098108298/) or any
bookshop. Many companies and universities give free access through the O'Reilly learning platform.

If you have the PDF: on this course's page, in the box **"This course reads a book you get yourself"**, press **Find it
for me**. inPace looks in your Downloads, Documents and Desktop folders and recognizes the book by its title and number
of pages, whatever the file is called. If it's somewhere else, choose the folder or the file yourself.

The course expects the 446-page PDF of the first edition. If inPace warns that the page count is different, you have
another copy: the lessons may open a few pages off, so trust the chapter and section names in each lesson's title.

## Before you start

You need to be comfortable with:

- **SQL**: `SELECT`, `WHERE`, `GROUP BY`, `JOIN`. Window functions help, and the projects explain them as they go.
- **Python**: functions, loops, reading and writing files, running a script from a terminal.

Not there yet? The library has *PostgreSQL for Beginners* and *Python: the full course*. Take them first.

For the projects, install Python 3.9 or newer, then one library, once:

```bash
pip install duckdb
```

[DuckDB](https://duckdb.org) is a fast analytics database that runs inside your Python script: no server, no account,
no cloud bill. It reads CSV, JSON and Parquet files directly, so one laptop can play the part of a data lake and a
data warehouse.

## How each module works

- **Read** lessons open the book at the right pages, with notes: what to look for, and what you can skim.
- **Concept** lessons explain the chapter's big ideas in plain words, with a diagram or a table.
- **Project** lessons show the code with the Copy button, explain each part, and show the real output. Every script
  was run before publishing. Your numbers can differ slightly (timings always do), but the pattern will be the same.
- Each module has a **quiz** (pass with 70% to open the next one). Questions can have **more than one right answer**,
  so read every option. There's also a **task** to hand in and a short **explanation in your own words**.
