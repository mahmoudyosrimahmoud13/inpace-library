# Introduction to low-level design

Low-level design zooms into **one component** and asks: which classes, which methods, which data, and how do they
work together? Good LLD follows a few principles:

- **Single responsibility:** each class does one job.
- **Program to interfaces:** depend on what something does, not on how it does it.
- **Open for extension, closed for modification:** add new behaviour by adding classes, not by editing old ones.
