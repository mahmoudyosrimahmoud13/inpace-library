# Choosing a datastore

Pick storage by **the shape of the data and how it is read**:

| Need | Typical choice |
|---|---|
| Related records, transactions, joins | relational database (PostgreSQL, MySQL) |
| Huge scale, simple lookups by key | key-value or wide-column NoSQL (DynamoDB, Cassandra) |
| Big files (images, video) | object storage (S3, Google Cloud Storage) |
| Very fast repeated reads | an in-memory cache (Redis) |
| Searching text | a search engine (Elasticsearch) |

Real systems use several at once. Say *why* for each choice: the reason is what an interviewer listens for.
