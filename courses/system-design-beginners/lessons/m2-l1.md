# The core requirement: streaming video

The core of the system is getting video from **one broadcaster** to **many viewers** quickly. Notice the shape:

- **Write path:** one stream comes in (the broadcaster's camera).
- **Read path:** millions of viewers pull it out.

This is a **read-heavy** system, and that single fact explains most later choices: copies of the video close to the
viewers, caching, and pre-processing the video once so millions don't each need it processed.
