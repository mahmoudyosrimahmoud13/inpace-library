# Database design

Separate the two kinds of data the system holds:

| Data | Example | Where it usually lives |
|---|---|---|
| Metadata | stream title, owner, status, start time | a database (SQL or NoSQL) |
| Large files | video segments | object storage (like Amazon S3) and CDNs |

Never put large video files inside a database row: store them as files and keep only their **location** in the database.

A first table might be:

```text
streams(stream_id PK, owner_id, title, status, started_at, ended_at)
users(user_id PK, name, created_at)
```
