# WebRTC vs MPEG-DASH vs HLS

| | WebRTC | MPEG-DASH / HLS |
|---|---|---|
| Built on | mostly UDP, peer-to-peer style | HTTP (TCP), video cut into segments |
| Delay | under a second | a few seconds to tens of seconds |
| Scale | hard to reach millions | easy, works with any CDN |
| Use | video calls, auctions, very interactive streams | sports, concerts, YouTube, Netflix |

**Adaptive bitrate:** with DASH or HLS the player reads a **manifest** (a playlist of segments in each quality) and
switches quality automatically as the viewer's network speed changes.
