# MapReduce for video transformation

Each chunk must be **transcoded**: turned into several qualities (240p, 480p, 720p, 1080p) and formats, so every
device and network speed has something it can play.

This is a perfect job for the **MapReduce** idea:

- **Map:** split the work into independent pieces (each chunk × each quality) and run them on many machines in parallel.
- **Reduce:** collect the results and put them back together in order, ready to serve.

Because chunks are independent, adding more machines makes processing faster. That's **horizontal scaling**.
