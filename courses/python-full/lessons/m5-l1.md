## Arguments from the terminal

`sys.argv` is a list of what was typed in the terminal: the program's name, then each word after it. Check its length before you use it, and leave with `sys.exit()` if something's missing:

```python
import sys

if len(sys.argv) < 2:
    sys.exit("Usage: python greet.py NAME ...")
for arg in sys.argv[1:]:          # [1:] skips the program's own name
    print("Welcome,", arg)
```

Try it: `python greet.py Mona Ali` prints two lines. Slicing with `[1:]` means "from position 1 to the end".

Read more: [Modules](https://docs.python.org/3/tutorial/modules.html) and [a brief tour of the standard library](https://docs.python.org/3/tutorial/stdlib.html).
