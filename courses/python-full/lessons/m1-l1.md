# Start here

This is a complete Python course for beginners: from your first line of code to functions, loops, errors, libraries, tests, files, regular expressions and classes. It follows the syllabus of **Harvard's CS50P** (CS50's Introduction to Programming with Python), one of the best free programming courses there is.

## How each module works

1. **The written lessons** are the course: they explain every idea with the code that matters, so you can learn everything from them alone.
2. **Harvard's lecture is optional.** It sits on top of each module's first lesson for anyone who likes learning by video. Skip it, or watch it in parts: inPace remembers where you stopped.
3. **Practice:** a small program to write, a question to answer in your own words, and a quiz.

## Set up your computer

1. Install Python 3 from [python.org/downloads](https://www.python.org/downloads/). On Windows, tick **Add python.exe to PATH** on the first screen.
2. Install [VS Code](https://code.visualstudio.com/) and its **Python** extension.
3. Make a folder for this course, open it in VS Code, and create a file named `hello.py`:

```python
print("hello, world")
```

4. Open the terminal (**Terminal → New Terminal**) and run it: `python hello.py` (on Mac and Linux, `python3 hello.py`).

Can't install anything? Use [cs50.dev](https://cs50.dev), Harvard's free editor in the browser (sign in with GitHub).
