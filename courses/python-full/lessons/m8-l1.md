# Patterns with re.search

A **regular expression** (regex) is a pattern that text can match. It answers questions like "is this a valid email?" or "find every date in this text".

```python
import re

code = input("Student code: ").strip()     # like CS-2026-0042
if re.fullmatch(r"[A-Z]{2}-\d{4}-\d{4}", code, re.IGNORECASE):
    print("Valid")
else:
    print("Invalid")
```

## The pieces

| Pattern | Matches |
|---|---|
| `.` | any character except a new line |
| `*` | 0 or more of the last thing |
| `+` | 1 or more |
| `?` | 0 or 1 (optional) |
| `{3}`, `{2,4}` | exactly 3, from 2 to 4 |
| `\d`, `\w`, `\s` | a digit, a word character, a space |
| `[abc]`, `[^abc]` | one of these, none of these |
| `^`, `$` | the start, the end |
| `(a\|b)` | a or b |
| `\.` | a real dot |

`re.search` finds the pattern anywhere in the text; `re.fullmatch` (or `^...$`) needs the whole text to match. Always write patterns as raw strings, `r"..."`.

Read more: [the re module](https://docs.python.org/3/library/re.html) and the [Regular expression HOWTO](https://docs.python.org/3/howto/regex.html).
