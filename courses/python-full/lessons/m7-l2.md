# CSV files

CSV (comma-separated values) is the simplest table format: one row per line, the columns split by commas. Excel and Google Sheets open it. Use the `csv` module, not `split(",")`, because a value can contain a comma inside quotes:

```python
import csv

# shops.csv:
# name,address
# Nile Books,"12 Tahrir St, Cairo"
# Sea Cafe,Corniche

shops = []
with open("shops.csv", encoding="utf-8") as file:
    for row in csv.DictReader(file):        # each row is a dict, keyed by the header
        shops.append(row)

for shop in sorted(shops, key=lambda s: s["name"]):
    print(f"{shop['name']}: {shop['address']}")
```

```python
with open("shops.csv", "a", encoding="utf-8", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "address"])
    writer.writerow({"name": "Green Grocer", "address": "5 Nasr Rd, Giza"})
```

`key=` tells `sorted` what to sort by. `lambda s: s["name"]` is a tiny function written in one line; you'll meet `lambda` again in module 10.
