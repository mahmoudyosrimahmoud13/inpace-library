# Asking until the input is right

Put `try` inside a `while True` loop and you get a function that keeps asking until it gets a good answer:

```python
def ask_number(prompt):
    while True:
        try:
            return float(input(prompt))
        except ValueError:
            print("That's not a number, try again.")


price = ask_number("Price: ")
```

## Raising your own errors

Your functions can refuse bad input too, with `raise`. The caller decides what to do about it:

```python
def percent(part, whole):
    if whole == 0:
        raise ValueError("whole can't be 0")
    return round(part / whole * 100)

try:
    print(percent(3, 0))
except ValueError as e:
    print("Problem:", e)
```

## finally

`finally:` runs whether there was an error or not, which is where cleanup goes (closing something, saying goodbye). You'll see a neater way to close files with `with` in module 7.

Read more: [Errors and exceptions](https://docs.python.org/3/tutorial/errors.html) in the official tutorial.
