# Sets, type hints and docstrings

A **set** keeps each value once, with no order. It's the quickest way to remove duplicates or check if something is in a big collection:

> **Optional video above.** Harvard's whole lecture for this week (2 h 29 min), by David J. Malan, covering this module. Harvard's own written notes: [CS50P notes, week 9](https://cs50.harvard.edu/python/notes/9/). Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```python
cities = set()
for f in [{"city": "Cairo"}, {"city": "Aswan"}, {"city": "Cairo"}]:
    cities.add(f["city"])
print(sorted(cities))          # ['Aswan', 'Cairo']
```

## Type hints

Hints say what type a variable or function expects. Python doesn't enforce them, but tools like `mypy` and VS Code use them to catch mistakes before you run the code:

```python
def repeat(word: str, n: int) -> str:
    """
    Repeat a word n times, one per line.

    :param word: the word to repeat
    :param n: how many times
    :return: the word n times, one per line
    """
    return (word + "\n") * n
```

## Constants and global

Names in CAPITALS (`MAX_TRIES = 3`) are constants by convention: values you don't change. Avoid `global`: a function that changes outside variables is hard to follow. Pass values in and return them instead, or use a class.
