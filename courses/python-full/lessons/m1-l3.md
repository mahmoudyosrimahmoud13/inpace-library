# Numbers: int, float and rounding

Python has whole numbers (`int`) and numbers with a decimal point (`float`). Since `input()` always gives text, convert it first:

```python
x = int(input("x: "))
y = int(input("y: "))
print(x + y)        # without int(), "1" + "2" would be "12"
```

## The operators

| Operator | Meaning | Example |
|---|---|---|
| `+ - *` | add, subtract, multiply | `7 * 6` is `42` |
| `/` | divide (always gives a float) | `7 / 2` is `3.5` |
| `//` | divide and drop the fraction | `7 // 2` is `3` |
| `%` | the remainder | `7 % 2` is `1` (so 7 is odd) |
| `**` | power | `2 ** 10` is `1024` |

## Rounding and formatting

`round(x, 2)` rounds to 2 places. Inside an f-string, a format after a colon controls how a number looks, without changing it:

```python
z = 1000 / 3
print(round(z, 2))      # 333.33
print(f"{z:.2f}")       # 333.33
print(f"{1234567:,}")   # 1,234,567
```

## Floats aren't exact

`0.1 + 0.2` gives `0.30000000000000004`, because computers store decimals in binary. That's normal. Round when you show a result, and for money use whole units (piasters, cents) or the `decimal` module.
