# Writing conditions well

A condition is just a value that is `True` or `False` (a `bool`). So a function can return the answer directly:

```python
def is_even(n):
    return n % 2 == 0      # instead of: if ...: return True / else: return False

if is_even(10):
    print("even")
```

## match: one value, many cases

When you compare one variable against many fixed values, `match` (Python 3.10 and newer) reads better than a long `elif` chain. `_` catches everything else, and `|` means or:

```python
match command:
    case "start" | "go":
        print("Starting")
    case "stop":
        print("Stopping")
    case _:
        print("Unknown command")
```

## Truthy and falsy

Empty things count as `False`: `""`, `0`, `[]`, `{}` and `None`. So `if name:` means "if the user typed something". It's short, but only use it when that's really what you mean.

Read more: [if statements](https://docs.python.org/3/tutorial/controlflow.html#if-statements) and [match statements](https://docs.python.org/3/tutorial/controlflow.html#match-statements).
