# *args, **kwargs and argparse

`*` unpacks a list into separate arguments, and `**` unpacks a dict into named arguments. In a function's definition they collect any number of arguments:

```python
def total(price, delivery, tip):
    return price + delivery + tip


order = [120, 25, 10]
print(total(*order))
print(total(**{"price": 120, "delivery": 25, "tip": 10}))


def f(*args, **kwargs):
    print("Positional:", args)      # a tuple
    print("Named:", kwargs)         # a dict
```

## argparse

For programs with options (`python hello.py -n 3`), `argparse` reads `sys.argv` for you, checks types, and writes the `--help` text:

```python
import argparse

parser = argparse.ArgumentParser(description="Say hello")
parser.add_argument("-n", default=1, type=int, help="number of times to say hello")
args = parser.parse_args()
for _ in range(args.n):
    print("hello")
```
