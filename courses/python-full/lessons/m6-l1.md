# assert and pytest

A **test** is code that checks your code. `assert` stops with an error when its condition is false. [pytest](https://docs.pytest.org/) runs every function whose name starts with `test_` and tells you which ones failed:

> **Optional video above.** Harvard's whole lecture for this week (51 min), by David J. Malan, covering this module. Harvard's own written notes: [CS50P notes, week 5](https://cs50.harvard.edu/python/notes/5/). Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```python
# shop.py
def discount(price, percent):
    return round(price * (1 - percent / 100), 2)
```

```python
# test_shop.py
from shop import discount


def test_normal():
    assert discount(200, 10) == 180
    assert discount(80, 25) == 60


def test_no_discount():
    assert discount(200, 0) == 200


def test_free():
    assert discount(200, 100) == 0
```

```bash
pip install pytest
pytest test_shop.py
```

Separate test functions for separate cases: when one fails, its name already tells you which kind of input is broken.
