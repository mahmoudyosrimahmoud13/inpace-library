# Your own modules

Any `.py` file is a module. Put functions in `money.py` and import them from another file in the same folder:

```python
# money.py
def egp(amount):
    return f"{amount:,.2f} EGP"


def main():
    print(egp(1500))


if __name__ == "__main__":     # only when you run money.py itself
    main()
```

```python
# receipt.py
from money import egp
print("Total:", egp(249.5))
```

Without the `if __name__ == "__main__":` line, importing `money` would also run its `main()` and print `1,500.00 EGP`. With it, the file works both as a program and as a module. You'll use this in every project that has tests.
