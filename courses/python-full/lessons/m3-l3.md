# Nested loops and small functions

A loop inside a loop goes through rows and columns. Splitting the work into small functions keeps each piece easy to read:

```python
def main():
    print_table(3)


def print_table(n):
    for row in range(1, n + 1):          # each row
        print_row(row, n)


def print_row(row, n):
    for col in range(1, n + 1):          # each column
        print(row * col, end="\t")
    print()


main()        # a small times table
```

Each function does one thing and has a name that says what. When something breaks, you know where to look. That habit matters more than any single trick in this course.
