# What to test

Good tests try the **normal** cases, the **edges** (0, empty text, the biggest allowed value), and the **wrong** inputs. Check that wrong inputs raise the right error:

```python
import pytest
from grade import grade


def test_edges():
    assert grade(90) == "A"
    assert grade(89) == "B"
    assert grade(0) == "F"


def test_invalid():
    with pytest.raises(ValueError):
        grade(101)
```

## Make your code testable

Tests can only check what a function **returns**. So keep `input()` and `print()` in `main()`, and put the logic in small functions that take values and return values. That's why every practical task in this course asks for a function.

## Tests in a folder

Many test files can live in a `tests/` folder; `pytest` with no file name finds them all.
