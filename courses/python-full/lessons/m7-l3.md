# JSON and paths

CSV is for tables. For nested data (lists inside dicts), save **JSON** with the `json` module. It's the format web APIs use too:

```python
import json
from pathlib import Path

settings = {"name": "Mona", "goals": ["python", "sql"], "minutes": 60}
path = Path("settings.json")
path.write_text(json.dumps(settings, indent=2, ensure_ascii=False), encoding="utf-8")

loaded = json.loads(path.read_text(encoding="utf-8"))
print(loaded["goals"][0])     # python
print(path.exists(), path.suffix, Path.home())
```

`pathlib.Path` is the modern way to work with file paths: it joins folders with `/`, works on Windows, Mac and Linux, and can read or write a whole small file in one line.

Read more: [Saving structured data with json](https://docs.python.org/3/tutorial/inputoutput.html#saving-structured-data-with-json).
