# Text: print, input and strings

`input()` asks the user a question and gives back what they typed, always as **text** (a `str`). `print()` shows values on the screen.

```python
name = input("What's your name? ")
print("hello,", name)        # print puts a space between arguments
print("hello, " + name)       # + joins two strings
print(f"hello, {name}")       # an f-string: the cleanest way
```

## Cleaning what people type

People type extra spaces and odd capitals. String **methods** fix that. A method is a function that belongs to a value, called with a dot:

```python
name = input("Name: ").strip().title()   # "  mona ali " -> "Mona Ali"
first, last = name.split(" ")            # split at the space into two variables
print(f"Hi {first}! Your name has {len(name)} characters.")
```

## Useful string methods

| Method | What it does |
|---|---|
| `.strip()` | removes spaces at both ends |
| `.lower()`, `.upper()` | all small or all capital letters |
| `.title()` | Capital At The Start Of Each Word |
| `.replace(a, b)` | swaps every `a` for `b` |
| `.split(sep)` | cuts the text into a list |
| `.startswith(x)` | `True` if the text starts with `x` |

## print's own options

`print` adds a new line at the end and a space between arguments. Change them with `end` and `sep`:

```python
print("a", "b", "c", sep="-")    # a-b-c
print("no new line", end="")
print(" ...same line")
```

## Comments

Anything after `#` is a **comment**: Python ignores it, people read it. Write comments that say *why*, not what. Quotes inside quotes: use the other kind (`'He said "hi"'`) or a backslash (`"He said \"hi\""`).
