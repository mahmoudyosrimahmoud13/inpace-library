# Properties and class methods

An attribute can be changed by anyone: `course.level = "expert"`. A **property** runs your code whenever the attribute is read or set, so you can check the value:

```python
class Course:
    LEVELS = ["beginner", "intermediate", "advanced"]

    def __init__(self, title, level):
        self.title = title
        self.level = level          # goes through the setter below

    @property
    def level(self):
        return self._level

    @level.setter
    def level(self, level):
        if level not in self.LEVELS:
            raise ValueError("Invalid level")
        self._level = level

    @classmethod
    def ask(cls):
        return cls(input("Title: "), input("Level: "))


course = Course.ask()
```

- `self._level` with an underscore is the real storage. The underscore says "don't touch this directly".
- A `@classmethod` belongs to the class, not to one object: `Course.ask()`. It's handy for other ways to create objects.
- `LEVELS` is a **class variable**, shared by every course.
