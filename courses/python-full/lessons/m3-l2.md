# Lists and dictionaries

A **list** keeps values in order. A **dictionary** (`dict`) connects **keys** to **values**, like words to their meanings.

```python
friends = ["Mona", "Omar", "Laila"]
print(friends[0], len(friends))
friends.append("Karim")
for friend in friends:
    print(friend)

for i, friend in enumerate(friends, 1):   # with a number
    print(i, friend)
```

```python
cities = {"Mona": "Cairo", "Omar": "Alexandria"}
print(cities["Omar"])            # Alexandria
cities["Laila"] = "Aswan"          # add or change

for name, city in cities.items():
    print(name, "lives in", city)

print(cities.get("Karim", "unknown"))   # no KeyError if it's missing
```

## A list of dictionaries

Real data is often a list of records. Each record is a dict with the same keys:

```python
friends = [
    {"name": "Mona", "city": "Cairo"},
    {"name": "Omar", "city": "Alexandria"},
]
for f in friends:
    print(f["name"], f["city"], sep=", ")
```

## Counting with a dict

A dict is the easiest way to count things: `counts[word] = counts.get(word, 0) + 1`.
