# Your own functions

A **function** is a named piece of code you can run again and again. It can take **parameters** (its inputs) and `return` a value (its output).

```python
def main():
    x = int(input("What's x? "))
    print("x squared is", square(x))


def square(n):
    return n * n


main()
```

## Why `main()` at the bottom?

Python reads a file from top to bottom. Putting the program in `main()` and calling it on the last line means every function is already defined when the program starts, so the order of the functions doesn't matter.

## print or return?

`print` shows something to a person. `return` hands a value back to the code that called the function, so it can be used again: stored, compared, printed later. A function that only prints can't be used inside a bigger calculation, and it's hard to test.

## Default values and scope

A parameter can have a default. Variables made inside a function exist only inside it (its **scope**):

```python
def hello(to="world"):
    message = f"hello, {to}"
    return message

print(hello())        # hello, world
print(hello("Mona"))  # hello, Mona
# print(message)      # NameError: message only lives inside hello()
```
