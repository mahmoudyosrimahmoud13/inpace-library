# Classes and objects

A **class** is your own type: a blueprint. An **object** is one thing made from it. The class bundles the data (attributes) with the functions that work on it (methods):

```python
class Course:
    def __init__(self, title, hours):
        if not title:
            raise ValueError("Missing title")
        self.title = title
        self.hours = hours

    def __str__(self):
        return f"{self.title} ({self.hours} h)"


python = Course("Python", 40)
print(python)            # Python (40 h)
print(python.hours)
```

## What each part is

- `__init__` runs when you create an object. It sets up the attributes.
- `self` is the object itself; every method gets it first.
- `__str__` says how the object looks when printed.
- Raising an error in `__init__` means an invalid object can never exist.

You've used objects all along: `"hi".upper()` calls a method of a `str` object, and `[].append()` a method of a `list` object.
