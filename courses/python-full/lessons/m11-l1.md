# Plan and build your project

Now build something of your own, about the size of everything you did in this course put together. Pick a problem from your own life: that's what keeps you going when it gets hard.

## Ideas

- A budget tracker that reads your expenses from a CSV and shows totals per category.
- A quiz game that loads questions from a JSON file and keeps high scores.
- A tool that renames or sorts the files in a folder by date or type.
- A small command-line app that calls a public API (weather, prayer times, exchange rates) and saves results.

## The shape (Harvard asks for the same)

- `project.py` with a `main()` and at least **3 other functions** at the top level.
- `test_project.py` with a `test_` function for each of those 3 functions, run with pytest.
- `requirements.txt` for any package you installed.
- `README.md`: what it does, how to run it, and why you designed it the way you did.

## Work in small steps

Get the smallest version working first, commit it with git, then add one feature at a time. Every time something works, write a test for it.
