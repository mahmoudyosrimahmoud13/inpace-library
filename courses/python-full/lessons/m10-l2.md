# Comprehensions, lambda and generators

A **comprehension** builds a list (or dict) from a loop, in one line:

```python
words = ["learn", "at", "your", "pace"]
upper = [w.upper() for w in words]                 # ['LEARN', 'AT', 'YOUR', 'PACE']
long = [w for w in words if len(w) > 2]            # with a condition
lengths = {w: len(w) for w in words}               # a dict comprehension

friends = [{"name": "Mona", "city": "Cairo"}, {"name": "Omar", "city": "Alexandria"}]
in_cairo = sorted(f["name"] for f in friends if f["city"] == "Cairo")
```

## lambda, map and filter

`lambda` is a small nameless function, mostly used as `key=` for sorting. `map` and `filter` do what comprehensions do; prefer the comprehension when it reads better:

```python
by_city = sorted(friends, key=lambda f: f["city"])
numbers = list(map(int, "1 2 3".split()))         # [1, 2, 3]
```

## Generators

A function with `yield` gives values one at a time instead of building a huge list in memory. That matters when there are millions of items:

![Measured peak memory: a list grows with n, a generator stays flat](list_vs_generator.png)

Measured with `tracemalloc` while writing this lesson: summing a million squares through a list peaked at about 40 MB; through a generator, under 1 KB.

```python
def squares(n):
    for i in range(n):
        yield i * i


for s in squares(1_000_000):
    print(s)          # starts printing at once, uses almost no memory
```
