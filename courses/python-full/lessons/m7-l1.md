# Reading and writing files

Variables disappear when the program ends. Files stay. `open()` gives you a file; `with` closes it for you, even if an error happens:

> **Optional video above.** Harvard's whole lecture for this week (1 h 32 min), by David J. Malan, covering this module. Harvard's own written notes: [CS50P notes, week 6](https://cs50.harvard.edu/python/notes/6/). Everything you need is in the text below, so watch it only if it helps you: inPace remembers where you stopped.

```python
guest = input("Guest: ")
with open("guests.txt", "a", encoding="utf-8") as file:   # "a" adds to the end
    file.write(f"{guest}\n")

with open("guests.txt", encoding="utf-8") as file:
    for line in sorted(file):
        print("Invited:", line.rstrip())  # rstrip removes the \n at the end
```

## The modes

| Mode | Means |
|---|---|
| `"r"` | read (the default) |
| `"w"` | write: **empties the file first** |
| `"a"` | append: add to the end |

Always pass `encoding="utf-8"`, so Arabic and other languages work the same on every computer.

Read more: [Reading and writing files](https://docs.python.org/3/tutorial/inputoutput.html#reading-and-writing-files).
