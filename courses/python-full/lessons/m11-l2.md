# Where to go next

You can now write real Python. Where it leads depends on what you want to build:

| Goal | Next in the library |
|---|---|
| Websites and APIs | FastAPI, then Docker and Kubernetes (the **Python backend developer** roadmap) |
| Data analysis | Data analytics for beginners (the **Become a data analyst** roadmap) |
| Machine learning | Maths for ML, then the ML and DL courses (the **Machine learning, from the maths up** roadmap) |

Harvard's certificate: if you solve CS50P's own problem sets and final project at [cs50.harvard.edu/python](https://cs50.harvard.edu/python/), you can get a free certificate from Harvard.
