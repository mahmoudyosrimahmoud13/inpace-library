# Promises and async/await

```js
async function save(form) {
  try {
    const r = await fetch(form.action, { method: "POST", body: new FormData(form) });
    if (!r.ok) throw new Error(`HTTP ${r.status}`);
    return await r.json();
  } catch (err) {
    console.warn(err);          // network down, or our own error
    return null;
  }
}
```

- `fetch` only **rejects** on network failure. A 404 or 500 still resolves: check `r.ok`.
- `await` pauses this function, not the page.
- Run things in parallel: `await Promise.all([a(), b()])` (fails fast), `Promise.allSettled` (waits for all),
  `Promise.race`, `Promise.any`.
- Cancel with `AbortController`:

```js
const ctl = new AbortController();
setTimeout(() => ctl.abort(), 5000);
await fetch(url, { signal: ctl.signal });
```
