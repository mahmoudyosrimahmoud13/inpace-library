# this, arrow functions and bind

`this` depends on **how a function is called**, not where it's written:

| Call | `this` |
|---|---|
| `obj.method()` | `obj` |
| `fn()` | `undefined` in strict mode (the global object otherwise) |
| `new Fn()` | the new object |
| `fn.call(x)`, `fn.apply(x)`, `fn.bind(x)` | `x` |
| an arrow function | the `this` of the code around it (arrows have no own `this`) |
| a DOM handler `el.addEventListener("click", function () {})` | `el` |

```js
class Timer {
  constructor() { this.s = 0; }
  start() { setInterval(() => this.s++, 1000); }      // arrow keeps this
  // setInterval(function () { this.s++ }, 1000)     // wrong: this is not the Timer
}
```
