# Visibility, beacons and wake lock

The focus trip in "phone down" mode pauses when you leave the screen:

```js
document.addEventListener("visibilitychange", () => {
  if (document.hidden) {
    if (mode === "phone" && state === "running") {
      if (navigator.sendBeacon) navigator.sendBeacon("/island/pause");
      else fetch("/island/pause", { method: "POST", keepalive: true });
    }
  } else { sync(); keepAwake(); }
});
```

- `visibilitychange` is the reliable "user left" signal (more than `unload`, which mobile browsers often skip).
- `sendBeacon` and `fetch(..., { keepalive: true })` let a small request finish even while the page goes away.
- `navigator.wakeLock.request("screen")` keeps the screen on during the trip.
- The timer on screen is just a display: the **server** owns the real elapsed time (`sync()` asks it), so closing the
  page loses nothing. Never trust a client-side timer for anything that matters.
