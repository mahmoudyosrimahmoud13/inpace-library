# Canvas and images

The island's "share a picture" turns the SVG into a PNG in the page:

```js
const svg = await (await fetch("/island/share.svg")).text();
const url = URL.createObjectURL(new Blob([svg], { type: "image/svg+xml" }));
const img = new Image();
await new Promise((ok, bad) => { img.onload = ok; img.onerror = bad; img.src = url; });
const canvas = document.createElement("canvas");
canvas.width = canvas.height = 1080;
canvas.getContext("2d").drawImage(img, 0, 0, 1080, 1080);
form.png.value = canvas.toDataURL("image/png");   // the form then sends the PNG to the server
```

Notice the pattern of wrapping an old callback API (`onload`/`onerror`) in a Promise so it can be awaited.

Canvas basics: `getContext("2d")`, `fillRect`, `drawImage`, `toBlob`/`toDataURL`. For sharp output on high-density
screens, scale by `devicePixelRatio`. A canvas becomes "tainted" if you draw a cross-origin image without CORS, and
then you can't export it.
