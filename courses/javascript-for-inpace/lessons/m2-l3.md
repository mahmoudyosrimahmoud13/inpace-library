# Prototypes and classes

Every object has a hidden link to a **prototype**. Looking up a property walks the chain:
`obj → Constructor.prototype → Object.prototype → null`.

`class` is cleaner syntax for the same thing:

```js
class Shape { area() { return 0; } }
class Square extends Shape {
  #side;                                  // truly private field
  constructor(s) { super(); this.#side = s; }
  area() { return this.#side ** 2; }
}
Object.getPrototypeOf(new Square(2)) === Square.prototype   // true
```

Interview angle: "prototypal inheritance" means objects inherit directly from objects; classes don't copy methods,
they share them through the prototype.
