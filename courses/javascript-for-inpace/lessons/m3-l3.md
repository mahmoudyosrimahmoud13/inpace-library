# Forms from JavaScript

```js
form.addEventListener("submit", (e) => {
  e.preventDefault();
  const data = new FormData(form);          // every named field, files included
  if (e.submitter?.name) data.append(e.submitter.name, e.submitter.value);
  console.log(Object.fromEntries(data));
});
```

`e.submitter` is the button that was pressed. inPace forms often have two buttons with different values (for
example "Approve" and "Ask for changes"), and the background sender adds the submitter's value so the server knows
which one.

Also useful: `form.requestSubmit()` (runs validation, unlike `form.submit()`), `form.reportValidity()`,
`input.setCustomValidity("message")`.
