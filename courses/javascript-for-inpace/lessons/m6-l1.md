# Pointer events: mouse, pen and touch together

Pointer events give one API for every input. The diagram viewer supports drag to pan and two-finger pinch to zoom:

```js
const pts = new Map();                                 // pointerId -> {x, y}
const gap = () => { const [a, b] = [...pts.values()]; return Math.hypot(a.x - b.x, a.y - b.y) || 1; };

view.addEventListener("pointerdown", (e) => {
  pts.set(e.pointerId, { x: e.clientX, y: e.clientY });
  if (pts.size === 2) { pinch = { d: gap(), z }; drag = null; return; }
  drag = { x: e.clientX, y: e.clientY, l: view.scrollLeft, t: view.scrollTop };
  view.setPointerCapture(e.pointerId);                 // keep getting moves even outside the element
});
view.addEventListener("pointermove", (e) => {
  if (pts.has(e.pointerId)) pts.set(e.pointerId, { x: e.clientX, y: e.clientY });
  if (pinch && pts.size === 2) { apply(pinch.z * gap() / pinch.d); return; }
  if (drag) { view.scrollLeft = drag.l - (e.clientX - drag.x); view.scrollTop = drag.t - (e.clientY - drag.y); }
});
```

- `setPointerCapture` keeps the drag going when the finger leaves the box.
- The new zoom is the start zoom times the ratio of the finger distances.
- CSS `touch-action: pan-x pan-y` normally, and `touch-action: none` once zoomed, so the browser doesn't fight the
  gesture but plain swipes still scroll.
- The wheel zooms only with Ctrl (or in full screen), so normal scrolling still scrolls the lesson. A good UX detail.
