# location and history

| Call | Effect |
|---|---|
| `location.href = url` | Navigate, adding a history entry |
| `location.replace(url)` | Navigate, replacing the current entry (Back skips it) |
| `location.reload()` | Load the same page again |
| `history.pushState(state, "", url)` | Change the URL **without** loading; adds an entry |
| `history.replaceState(state, "", url)` | Change the URL without loading or adding an entry |
| `popstate` event | Back/Forward between entries made by pushState |
| `pageshow` with `e.persisted` | The page came from the back-forward cache |

## goFresh: a real fix

```js
function goFresh(url) {
  const next = new URL(url, location.href);
  const samePage = next.pathname === location.pathname && next.search === location.search;
  if (samePage && next.hash) { history.replaceState(history.state, "", next.href); location.reload(); }
  else location.replace(next.href);
}
```

Assigning a URL that differs only in its `#hash` doesn't load anything; the browser just scrolls. So after buying
an island item, the shop looked unchanged. goFresh notices "same page plus hash", writes the new URL, and reloads.

## The back-forward cache

This small script sits in the `<head>` of inPace's `base.html`:

```js
var m = document.querySelector('meta[name="inpace-dispose"]');
var nav = performance.getEntriesByType("navigation")[0];
if (m && nav && nav.type === "back_forward") location.replace(m.content);   // one-off page: leave it
window.addEventListener("pageshow", function (e) {
  if (!e.persisted) return;                                               // a normal load
  if (m) location.replace(m.content); else location.reload();            // restored from memory: refresh
});
```

Browsers may restore a page from memory on Back, frozen as it was. inPace reloads it so colours, language and data
are current, and "one-off" pages (a sent quiz, a finished trip) send you to the page they belong to.
