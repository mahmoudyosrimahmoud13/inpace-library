# Finding and changing elements

```js
const box = document.querySelector("#inpace-trip");
const cards = document.querySelectorAll(".card");     // a static NodeList; use forEach
box.textContent = "Done";                                // safe: never parsed as HTML
box.classList.toggle("open", isOpen);
box.dataset.state = "running";                           // reads/writes data-state
box.hidden = true;
const el = document.createElement("button");
el.append("Share"); box.append(el);
```

## textContent vs innerHTML

`innerHTML` parses HTML: if any part came from a user, that's an **XSS** hole. Use `textContent` for text. When
app.js builds markup with a template string, the content is either fixed or already escaped by the server.

## Batch your reads and writes

Reading layout (`offsetWidth`, `getBoundingClientRect`) right after writing styles forces the browser to do layout
immediately ("layout thrashing"). Read everything first, then write.
