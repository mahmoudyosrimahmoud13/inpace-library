# let, const, scope and hoisting

- `const` can't be reassigned (but a const object can still be changed inside).
- `let` and `const` are **block-scoped**; `var` is function-scoped and leaks out of blocks.
- Declarations are **hoisted**: `var` reads as `undefined` before its line; `let`/`const` throw a
  ReferenceError (the "temporal dead zone"); function declarations are fully hoisted.

```js
for (var i = 0; i < 3; i++) setTimeout(() => console.log(i));   // 3 3 3
for (let j = 0; j < 3; j++) setTimeout(() => console.log(j));   // 0 1 2
```

With `let`, each loop round gets its own `j`. This is the most common closure question in interviews.

## Strict mode and modules

ES modules (`<script type="module">`) are strict automatically: no accidental globals, `this` is `undefined` in
plain functions. inPace's `app.js` is a classic script whose parts are wrapped in blocks and arrow functions to keep
names private.
