# 20 questions, short answers

Answer out loud first.

1. **Closure?** A function plus the variables it remembers from where it was made.
2. **`==` vs `===`?** Loose with conversion vs strict.
3. **Event loop?** Stack, then all microtasks, then render, then the next task.
4. **Microtask vs task?** Promise callbacks vs timers/events; microtasks first.
5. **`this` rules?** Set by the call: method, plain call, new, bind/call/apply; arrows inherit.
6. **Hoisting?** Declarations move to the top; let/const are in the TDZ.
7. **Event delegation?** One listener on an ancestor using bubbling and `closest()`.
8. **`preventDefault` vs `stopPropagation`?** Stop the default action vs stop bubbling.
9. **Debounce vs throttle?** Run after a quiet period vs at most once per interval.
10. **Shallow vs deep copy?** `{...o}` copies one level; `structuredClone(o)` copies deep.
11. **Why `fetch` 404 doesn't throw?** It only rejects on network errors; check `r.ok`.
12. **What is CORS?** The browser blocks reading cross-origin responses unless the server allows it with headers.
13. **XSS and how to prevent?** Injected scripts; escape output, use `textContent`, a Content-Security-Policy.
14. **CSRF?** Another site making your browser send a request; same-site cookies, tokens, checking the origin.
15. **`map`/`filter`/`reduce`?** Transform, select, fold to one value.
16. **Promise.all vs allSettled?** Fail fast vs wait for all.
17. **What's a memory leak in the browser?** Listeners, timers or caches keeping detached nodes alive.
18. **localStorage vs cookies?** Client-only strings vs sent to the server.
19. **Modules: ESM vs CommonJS?** `import`/`export`, static and async-loaded vs `require`, dynamic and sync.
20. **How would you make a page work offline?** A service worker caching assets, plus data in IndexedDB.
