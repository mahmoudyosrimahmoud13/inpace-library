# Full screen, keyboard and focus

```js
if (box.requestFullscreen && !document.fullscreenElement) box.requestFullscreen().catch(() => {});
document.addEventListener("fullscreenchange", () => setTimeout(fit, 250));
view.addEventListener("keydown", (e) => {
  if (e.key === "+" || e.key === "=") apply(z * 1.25);
  else if (e.key === "-") apply(z / 1.25);
  else if (e.key === "0") fit();
});
```

- Full screen must start from a user action, and returns a promise.
- After leaving full screen the box size changes, so the diagram refits after a short delay (a real bug fixed in
  v1.17).
- `tabindex="0"` makes the diagram view focusable so keyboard users can zoom too.
