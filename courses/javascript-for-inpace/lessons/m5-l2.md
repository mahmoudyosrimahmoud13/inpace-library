# Storage, cookies, clipboard and share

| API | Good for | Notes |
|---|---|---|
| `localStorage` | Small per-device preferences | Synchronous, strings only, about 5 MB, can throw (private mode): wrap in try/catch |
| `sessionStorage` | One tab's session | Cleared when the tab closes |
| `IndexedDB` | Large or structured data | Async; use a helper library |
| Cookies | Data the **server** must see on every request | inPace's `tz` cookie tells the server the device's time-zone offset |
| `navigator.clipboard.writeText` | Copy buttons | Needs a secure context and a user action |
| `navigator.share` | The phone's share sheet | Feature-detect: `if (navigator.share)` |

app.js wraps every storage call:

```js
try { last = +localStorage.getItem("inpace-plan-at") || 0; } catch (e) {}
```

The real data lives on the server (vault.db); the browser only stores small conveniences. That's the right split.
