# Closures

A **closure** is a function that remembers the variables from where it was created.

```js
function counter() {
  let n = 0;
  return () => ++n;
}
const next = counter();
next(); next();   // 2
```

app.js uses closures everywhere to keep state per component. The diagram viewer keeps its zoom level `z` and
`fitted` flag inside the function that sets up each diagram, so two diagrams on one page never mix their zoom:

```js
document.querySelectorAll(".diagram").forEach((box) => {
  let z = 1, fitted = true;              // private to this diagram
  const apply = (nz) => { z = Math.min(8, Math.max(0.2, nz)); /* ... */ };
  // listeners below all share z through the closure
});
```

## Common uses

Private state, factories, event handlers that remember their element, `debounce`/`throttle`, memoization.

```js
function debounce(fn, ms) {
  let t;
  return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), ms); };
}
```

Writing `debounce` from memory is a very common interview task.
