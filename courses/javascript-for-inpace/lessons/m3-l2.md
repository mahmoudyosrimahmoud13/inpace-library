# Events and delegation

Events go **down** (capture) then **up** (bubble) through the tree. Delegation uses bubbling: one listener on
`document` handles every matching element, **including ones added later**.

This is app.js's navigation code:

```js
document.addEventListener("click", (e) => {
  const a = e.target.closest("a[data-replace], a[data-up]");
  if (!a || a.target) return;
  e.preventDefault();
  if (a.hasAttribute("data-up")) goUp(a.href); else location.replace(a.href);
});
```

- `e.target` is what was clicked (maybe an icon inside the link); `closest()` walks up to the link.
- `preventDefault()` stops the normal navigation; `stopPropagation()` (rarely needed) stops bubbling.
- One listener instead of hundreds: less memory, and new content works without re-binding.

## Listener options

```js
view.addEventListener("wheel", onWheel, { passive: false });   // we will call preventDefault
window.addEventListener("scroll", onScroll, { passive: true }); // promise not to block scrolling
btn.addEventListener("click", once, { once: true });
```
