# Back-of-the-envelope numbers

Interviewers want you to estimate out loud. Write the formula, then the numbers (state that prices are assumptions and change often):

- **Tokens per request:** system prompt 500 + 8 chunks × 200 + question 50 + history 0 = about 2,150 input; answer about 300 output.
- **Daily cost:** requests per day × (input tokens × input price + output tokens × output price).
- **Index size:** 10M documents × 5 chunks × 1,024 dimensions × 4 bytes ≈ 205 GB of float32 vectors, before index overhead; halve it with float16, or much more with quantization.
- **Throughput:** peak requests per second × average generation seconds = concurrent generations to provision.
