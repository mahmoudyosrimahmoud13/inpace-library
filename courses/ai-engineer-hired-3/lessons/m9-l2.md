# A 4-hour take-home simulation

Pick one prompt (they're modelled on real assignments the field guide collected), set a 4-hour timer, and work as if a company were waiting:

1. **Policy assistant:** answers questions about 10 policy PDFs with mandatory citations, an "I don't have that information" fallback, and a 7-question eval set.
2. **Inbox triage:** classify 30 sample emails, draft replies, and require human approval before anything is sent.
3. **LLM router:** an API that sends each request to a small or large model, with caching and failover, and reports cost and latency.

## What wins (from the guide's analysis)

- **Clarify first:** write your assumptions at the top of the README.
- **Start with the eval harness**, then build until it passes.
- Document decisions and trade-offs; test edge cases.
- Show production awareness: error handling, cost estimate, monitoring ideas.
- A short **video walkthrough**.

One published rubric weighted functionality 30%, challenge completion 30%, context engineering 25% and code quality 15%. What fails: no evals, no documented decisions, over-engineering, and an unprepared defence round.
