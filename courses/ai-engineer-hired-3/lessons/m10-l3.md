# Going further: resources worth your time

An optional lesson: a short, opinionated list. Pick one at a time.

**Books**
- Chip Huyen, *AI Engineering* (O'Reilly, 2025): the field's reference book.
- Chip Huyen, *Designing Machine Learning Systems* (O'Reilly, 2022).
- Chip Huyen, [*Introduction to Machine Learning Interviews*](https://huyenchip.com/ml-interviews-book/) (free online).

**Courses (free)**
- [LLM Zoomcamp](https://github.com/DataTalksClub/llm-zoomcamp) (DataTalks.Club): RAG, vector search, evaluation, monitoring, with a capstone.
- [Hugging Face LLM Course](https://huggingface.co/learn/llm-course).
- [Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) (Andrej Karpathy, a YouTube series): build neural nets and GPT from scratch.
- 3Blue1Brown's neural network series on YouTube, for intuition.

**Writing by practitioners**
- [Building effective agents](https://www.anthropic.com/engineering/building-effective-agents) (Anthropic)
- [Your AI Product Needs Evals](https://hamel.dev/blog/posts/evals/) (Hamel Husain)
- [Patterns for building LLM-based systems](https://eugeneyan.com/writing/llm-patterns/) (Eugene Yan)
- [OWASP Top 10 for LLM Applications](https://genai.owasp.org/llm-top-10/)
- [AI Engineering Field Guide](https://github.com/alexeygrigorev/ai-engineering-field-guide) (Alexey Grigorev): job data, interview questions, take-home examples.

**Interview practice**
- [Hello Interview](https://www.hellointerview.com/learn/system-design/in-a-hurry/introduction) for system design.
- [Machine-Learning-Interviews](https://github.com/alirezadir/Machine-Learning-Interviews) on GitHub (an ML interview guide by a former FAANG engineer).
