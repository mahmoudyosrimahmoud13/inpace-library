# Inference: sampling, context and speed

| Term | What to say |
|---|---|
| **Temperature** | divides the scores before softmax: low = focused and repeatable, high = varied. Use 0 for extraction and evals |
| **Top-p** | sample only from the smallest set of tokens whose probability adds up to p |
| **Context window** | the maximum tokens of input plus output. Past it, you must cut, summarize or retrieve; long contexts also cost more and the model can miss facts in the middle |
| **KV cache** | keeps each token's keys and values so the next token doesn't recompute the whole prefix; it makes generation fast but uses a lot of GPU memory |
| **TTFT** | time to first token: what users feel. Streaming shows tokens as they come |
| **Quantization** | storing weights in 8 or 4 bits instead of 16: smaller and faster, with some quality loss to measure |
| **Mixture of Experts (MoE)** | each token uses only a few of many expert sub-networks: more parameters, similar compute per token |

## How serving makes it fast

Interviewers at infrastructure-minded companies go one level deeper. Know what each trick buys:

| Technique | What it does | What it buys |
|---|---|---|
| **Continuous batching** | the server adds new requests to the running batch as others finish | far more users per GPU |
| **Paged attention** (vLLM) | stores the KV cache in small blocks, like virtual memory pages | less wasted GPU memory, bigger batches |
| **Speculative decoding** | a small model drafts several tokens, the big one checks them in one pass | lower latency with the same output |
| **Prefix (prompt) caching** | reuses the KV cache of a shared prompt start across requests | cheaper and faster long system prompts |
| **Flash attention** | computes attention in tiles that fit in fast on-chip memory | faster, less memory, same result |

Two phases matter for latency: **prefill** (reading the whole prompt at once, which sets time to first token) and **decode** (one token at a time, which sets tokens per second). Long prompts hurt prefill; long answers hurt decode.
