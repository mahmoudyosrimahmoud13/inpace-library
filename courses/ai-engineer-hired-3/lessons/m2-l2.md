# Inference: sampling, context and speed

| Term | What to say |
|---|---|
| **Temperature** | divides the scores before softmax: low = focused and repeatable, high = varied. Use 0 for extraction and evals |
| **Top-p** | sample only from the smallest set of tokens whose probability adds up to p |
| **Context window** | the maximum tokens of input plus output. Past it, you must cut, summarize or retrieve; long contexts also cost more and the model can miss facts in the middle |
| **KV cache** | keeps each token's keys and values so the next token doesn't recompute the whole prefix; it makes generation fast but uses a lot of GPU memory |
| **TTFT** | time to first token: what users feel. Streaming shows tokens as they come |
| **Quantization** | storing weights in 8 or 4 bits instead of 16: smaller and faster, with some quality loss to measure |
| **Mixture of Experts (MoE)** | each token uses only a few of many expert sub-networks: more parameters, similar compute per token |
