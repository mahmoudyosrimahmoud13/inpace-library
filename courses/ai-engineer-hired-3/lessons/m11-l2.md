# Agent frameworks: when, and LangChain v1 in 20 lines

A framework gives you the agent loop, state, streaming, retries and human approval, so you don't write them yourself. The field guide found LangChain in 18.8% and LangGraph in 8.0% of AI engineer postings, so expect questions about them, but answer as an engineer, not a fan.

## When to use one

| Use plain code (an SDK and a loop) | Use a framework |
|---|---|
| one or two tools, a fixed workflow | many tools, branching, retries |
| you need every detail visible | you need pause and resume, human approval, durable state |
| a small team, one model provider | several providers, or a team that already uses it |

Anthropic's advice in *Building effective agents* still holds: start with direct API calls; if you use a framework, understand the code underneath, because hidden prompts and abstractions make bugs harder to find.

## LangChain v1

LangChain 1.0 (October 2025) rebuilt the library around one function, `create_agent`, which runs on **LangGraph** (the lower-level graph runtime with state and checkpoints). Older chain classes moved to the separate `langchain-classic` package, so tutorials from before late 2025 often show APIs you shouldn't copy.

```python
from typing import Literal
from pydantic import BaseModel
from langchain.agents import create_agent
from langchain.agents.structured_output import ToolStrategy
from langchain.tools import tool

@tool
def get_order(order_id: str) -> str:
    """Look up an order's status by its id, for example A-17."""
    orders = {"A-17": "shipped on Monday, arrives Thursday"}
    return orders.get(order_id, "no such order")

class Triage(BaseModel):
    category: Literal["shipping", "refund", "other"]
    reply: str

agent = create_agent(
    "ollama:qwen3",            # any provider: "openai:...", "anthropic:...", a local model...
    tools=[get_order],
    system_prompt="You are a support assistant. Use tools; never guess an order status.",
    response_format=ToolStrategy(Triage),
)
result = agent.invoke({"messages": [{"role": "user", "content": "Where is my order A-17?"}]})
print(result["structured_response"])   # category='shipping' reply='...arrives Thursday.'
```

**Middleware** is how v1 adds control without rewriting the loop: built-in ones redact PII, summarise long histories, and pause before chosen tools for human approval; your own can run code before or after every model or tool call (budgets, logging, policy checks).
