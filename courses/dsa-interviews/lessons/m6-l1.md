# Binary search trees and heaps

## Binary search tree (BST)

In a BST, for every node: everything in the **left** subtree is smaller, everything in the **right** is bigger. So searching, inserting and deleting take O(h): **O(log n) when balanced**, O(n) if it degenerates into a line.

```python
def search(root, x):
    while root and root.val != x:
        root = root.left if x < root.val else root.right
    return root
```

Key facts:
- An **inorder** traversal of a BST gives values **sorted**. Many BST questions are "do an inorder traversal and use the order".
- To **validate** a BST, pass down the allowed range, not just compare with the children:

```python
def is_bst(n, lo=float("-inf"), hi=float("inf")) -> bool:
    if not n:
        return True
    if not (lo < n.val < hi):
        return False
    return is_bst(n.left, lo, n.val) and is_bst(n.right, n.val, hi)
```

Real databases use balanced trees (B-trees) for indexes. In Python interviews, a sorted list with `bisect` often stands in for a BST.

## Heap (priority queue)

A **heap** always gives you the **smallest** item quickly:

| Operation | Cost |
|---|---|
| Look at the smallest | O(1) |
| Push | O(log n) |
| Pop the smallest | O(log n) |
| Build from a list | O(n) |

Python's `heapq` is a **min-heap** on a plain list:

```python
import heapq
h = []
heapq.heappush(h, 5); heapq.heappush(h, 1); heapq.heappush(h, 3)
heapq.heappop(h)    # 1
```

For a **max-heap**, push negative numbers. For records, push tuples: `(priority, item)`.

## Pattern: top k

The k largest numbers in O(n log k): keep a min-heap of size k; its top is the smallest of your current top k.

```python
def k_largest(nums: list[int], k: int) -> list[int]:
    h = []
    for x in nums:
        heapq.heappush(h, x)
        if len(h) > k:
            heapq.heappop(h)          # drop the smallest
    return sorted(h, reverse=True)
```

(`heapq.nlargest(k, nums)` does the same.)

## Pattern: merge k sorted lists

Put the first item of each list in a heap; repeatedly pop the smallest and push the next item from its list. O(N log k) for N items in total.

## Pattern: running median

Two heaps: a max-heap for the smaller half and a min-heap for the bigger half, kept balanced. The median is at their tops.
