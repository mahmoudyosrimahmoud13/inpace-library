# Dynamic programming, part 2: grids and two strings

Many DP problems need **two numbers** to describe a state: a position in a grid, or positions in two strings.

## Unique paths in a grid

A robot moves only right or down from the top-left to the bottom-right of an m × n grid. How many paths?

- State: `dp[r][c]` = paths to reach cell (r, c).
- Transition: you came from above or from the left: `dp[r][c] = dp[r-1][c] + dp[r][c-1]`.
- Base: the first row and column have exactly 1 path each.

```python
def unique_paths(m: int, n: int) -> int:
    dp = [[1] * n for _ in range(m)]
    for r in range(1, m):
        for c in range(1, n):
            dp[r][c] = dp[r - 1][c] + dp[r][c - 1]
    return dp[-1][-1]
```

Space can drop to one row, since each row needs only the row above.

Careful in Python: `[[1] * n] * m` makes **m references to the same row**. Use the list comprehension above.

## Longest common subsequence (two strings)

How long is the longest sequence of letters that appears, in order, in both strings? ("abcde" and "ace" → 3)

- State: `dp[i][j]` = LCS of `a[:i]` and `b[:j]`.
- Transition:
  - If `a[i-1] == b[j-1]`: `dp[i][j] = dp[i-1][j-1] + 1`
  - Otherwise: `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

```python
def lcs(a: str, b: str) -> int:
    dp = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]
    for i in range(1, len(a) + 1):
        for j in range(1, len(b) + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[-1][-1]
```

The extra row and column of zeros are the base case "one string is empty". O(len(a) × len(b)).

## Edit distance

The fewest inserts, deletes and replacements to turn one word into another: the same table idea, with three choices:

```python
if a[i-1] == b[j-1]:
    dp[i][j] = dp[i-1][j-1]
else:
    dp[i][j] = 1 + min(dp[i-1][j],      # delete
                       dp[i][j-1],      # insert
                       dp[i-1][j-1])    # replace
```

Spell checkers and DNA comparison use exactly this.

## 0/1 knapsack

Items with weights and values; a bag that holds W. Best total value, each item used at most once?

```python
def knapsack(weights, values, W):
    dp = [0] * (W + 1)                    # dp[w] = best value with capacity w
    for wt, val in zip(weights, values):
        for w in range(W, wt - 1, -1):    # go DOWN so each item is used once
            dp[w] = max(dp[w], dp[w - wt] + val)
    return dp[W]
```

Many problems are knapsack in disguise: "can this array be split into two equal sums?" is "can I fill a bag of size total/2?"

## How to recognize DP

- "**How many ways**...", "**minimum / maximum**...", "**is it possible**..."
- Choices at each step whose effects add up.
- A brute-force recursion that repeats the same calls.
