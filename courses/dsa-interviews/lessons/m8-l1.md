# Greedy algorithms and intervals

A **greedy** algorithm makes the choice that looks best **right now** and never goes back. When it works it's simple and fast, but it often **doesn't** work, so you must be able to argue why it's correct.

## When greedy works: maximum non-overlapping meetings

Pick as many non-overlapping meetings as possible. Greedy rule: **always take the meeting that ends first**.

```python
def max_meetings(meetings: list[tuple[int, int]]) -> int:
    meetings.sort(key=lambda m: m[1])     # by end time
    count, free_at = 0, float("-inf")
    for start, end in meetings:
        if start >= free_at:
            count += 1
            free_at = end
    return count
```

Why it's right (an "exchange argument"): any best schedule can swap its first meeting for the one that ends earliest without losing anything, because that leaves at least as much time for the rest.

Sorting by **start time** or by **shortest length** gives wrong answers. Try small counter-examples to convince yourself.

## When greedy fails

Coins [1, 3, 4], amount 6: greedy takes 4 + 1 + 1 (3 coins), but 3 + 3 is 2 coins. That's why coin change needed DP.

**Rule of thumb**: if you can find a small counter-example to the greedy rule in a minute, use DP. If you can't, try to explain why the greedy choice is always safe.

## Classic greedy problems

**Jump game**: can you reach the end, if `nums[i]` is the furthest jump from i?

```python
def can_jump(nums: list[int]) -> bool:
    reach = 0
    for i, n in enumerate(nums):
        if i > reach:
            return False
        reach = max(reach, i + n)
    return True
```

**Gas station**: if the total gas is at least the total cost, a solution exists; start just after the point where your running tank went most negative.

## Interval patterns

Intervals show up constantly (calendars, bookings, time ranges). Almost every interval problem starts with **sorting**:

| Problem | Sort by | Then |
|---|---|---|
| Merge overlapping | start | extend the last one or start a new one |
| Insert a new interval | (already sorted) | add the ones before, merge the overlap, add the rest |
| Most non-overlapping / fewest to remove | end | greedy as above |
| Meeting rooms needed | start (plus a heap of end times) | the heap's size at its biggest |

Minimum meeting rooms with a heap:

```python
import heapq

def rooms(meetings: list[list[int]]) -> int:
    meetings.sort()
    ends = []                         # end times of meetings in progress
    for start, end in meetings:
        if ends and ends[0] <= start:
            heapq.heappop(ends)       # a room freed up
        heapq.heappush(ends, end)
    return len(ends)
```
