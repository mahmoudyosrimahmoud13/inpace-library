# Hash maps and sets

A **hash map** (Python `dict`) stores key → value with **O(1) average** lookup. A **set** stores unique keys. They're the single most useful tool in interviews: whenever you're searching a list again and again, a dict or set probably removes that loop.

## Two Sum (the classic)

Find two indexes whose values add to `target` (unsorted input):

```python
def two_sum(nums: list[int], target: int) -> list[int]:
    seen = {}                      # value -> index
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
    return []
```

Brute force is O(n²) (check every pair). This is O(n) time, O(n) space. The trick: for each number, ask "have I already seen the number that completes it?"

## Counting things

```python
from collections import Counter, defaultdict

counts = Counter(words)            # {"the": 12, "cat": 3, ...}
counts.most_common(3)

groups = defaultdict(list)         # missing keys start as []
for w in words:
    groups[len(w)].append(w)
```

### Group anagrams

```python
def group_anagrams(words: list[str]) -> list[list[str]]:
    groups = defaultdict(list)
    for w in words:
        groups["".join(sorted(w))].append(w)   # "eat", "tea", "ate" -> "aet"
    return list(groups.values())
```

The key idea: **choose a key** that is the same for everything that belongs together. Here it's the sorted letters; it could also be a tuple of 26 letter counts (faster for long words).

## Sets for "have I seen it?"

Longest run of consecutive numbers (unsorted), in O(n):

```python
def longest_consecutive(nums: list[int]) -> int:
    s = set(nums)
    best = 0
    for x in s:
        if x - 1 not in s:             # x starts a run
            length = 1
            while x + length in s:
                length += 1
            best = max(best, length)
    return best
```

Each number is visited a constant number of times, because runs are only counted from their start.

## What can be a key?

Keys must be **hashable** (unchangeable): numbers, strings, tuples. Not lists or dicts. To use a list as a key, convert it: `tuple(my_list)`.

## Hash maps, honestly

"O(1)" is the **average**. Lookups hash the key to find a slot; when two keys land in the same slot (a collision), it takes a little longer. Python keeps this rare, so in interviews you can say O(1) average and mention the worst case if asked.
