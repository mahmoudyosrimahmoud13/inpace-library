# Arrays, strings and two pointers

Arrays (Python lists) and strings are in most interview questions. Strings in Python are **immutable**: every change makes a new string.

## Pattern: two pointers

Use two indexes moving through the data instead of a nested loop. It turns many O(n²) problems into O(n).

### Opposite ends

Is a string a palindrome, ignoring non-letters and case?

```python
def is_palindrome(s: str) -> bool:
    i, j = 0, len(s) - 1
    while i < j:
        if not s[i].isalnum():
            i += 1
        elif not s[j].isalnum():
            j -= 1
        else:
            if s[i].lower() != s[j].lower():
                return False
            i += 1
            j -= 1
    return True
```

O(n) time, O(1) space.

### Pair with a target sum in a **sorted** array

```python
def two_sum_sorted(a: list[int], target: int) -> tuple[int, int] | None:
    i, j = 0, len(a) - 1
    while i < j:
        s = a[i] + a[j]
        if s == target:
            return i, j
        if s < target:
            i += 1      # need a bigger sum
        else:
            j -= 1      # need a smaller sum
    return None
```

Why it works: because the array is sorted, moving the left pointer can only increase the sum, and moving the right one can only decrease it. Each step safely throws away one candidate.

### Same direction: slow and fast pointers

Remove duplicates from a sorted list **in place** and return the new length:

```python
def dedupe(a: list[int]) -> int:
    write = 0
    for read in range(len(a)):
        if read == 0 or a[read] != a[read - 1]:
            a[write] = a[read]
            write += 1
    return write
```

`read` looks at every item, `write` marks where the next kept item goes.

## Prefix sums

Many "sum of a range" questions become O(1) per query after an O(n) setup:

```python
nums = [3, 1, 4, 1, 5]
prefix = [0]
for x in nums:
    prefix.append(prefix[-1] + x)      # prefix[i] = sum of nums[:i]

def range_sum(i, j):                    # sum of nums[i..j] inclusive
    return prefix[j + 1] - prefix[i]
```

## Strings: useful tools

```python
from collections import Counter

Counter("listen") == Counter("silent")   # anagram check, O(n)
"".join(reversed(s))                     # reverse
s.split(), " ".join(words)               # words
ord("a"), chr(97)                        # characters and their codes
```

Build strings with a list and `"".join(parts)` at the end, not `+=` in a loop.
