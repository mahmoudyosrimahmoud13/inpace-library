# Sliding window

For questions about a **contiguous** part of an array or string (a subarray or substring), a **window** that slides from left to right often replaces checking every start and end (O(n²)) with one pass (O(n)).

## Fixed-size window

Largest sum of any 3 consecutive numbers:

```python
def max_sum_k(nums: list[int], k: int) -> int:
    window = sum(nums[:k])
    best = window
    for i in range(k, len(nums)):
        window += nums[i] - nums[i - k]   # add the new one, drop the oldest
        best = max(best, window)
    return best
```

Instead of re-adding k numbers each time, update the total by what entered and what left.

## Variable-size window

The pattern: grow the window on the right; when it breaks a rule, shrink it from the left until it's valid again.

```python
left = 0
for right in range(len(s)):
    # 1. add s[right] to the window
    while window_is_invalid():
        # 2. remove s[left] from the window
        left += 1
    # 3. the window s[left:right+1] is valid: record the answer
```

### Longest substring without repeating characters

```python
def longest_unique(s: str) -> int:
    last = {}                  # char -> last index seen
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1           # jump past the earlier copy
        last[ch] = right
        best = max(best, right - left + 1)
    return best
```

`"abcabcbb"` → 3 (`"abc"`). Each character enters and leaves the window at most once: O(n).

### Shortest subarray with sum ≥ target (positive numbers)

```python
def min_len(target: int, nums: list[int]) -> int:
    left = total = 0
    best = float("inf")
    for right, x in enumerate(nums):
        total += x
        while total >= target:
            best = min(best, right - left + 1)
            total -= nums[left]
            left += 1
    return 0 if best == float("inf") else best
```

This works because all numbers are **positive**: shrinking the window always lowers the sum. With negative numbers, a sliding window fails; use prefix sums with a hash map instead (the "subarray sum equals k" problem).

## Window with counts

When the rule is about character counts (anagram in a string, at most k changes), keep a `Counter` of the window and update it as characters enter and leave.

## Spotting it

Sliding window is likely when you see: **contiguous** subarray or substring, **longest / shortest / count**, and a condition you can update as the edges move.
