# Stacks and queues

## Stack: last in, first out

In Python, a list is a stack: `append` to push, `pop()` to pop, `a[-1]` to peek. All O(1).

Stacks fit anything **nested** or anything you must **undo in reverse**: brackets, undo history, the browser's Back button, function calls.

### Valid parentheses

```python
def valid(s: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif not stack or stack.pop() != pairs[ch]:
            return False
    return not stack
```

## Monotonic stack

A stack kept in increasing or decreasing order answers "the **next greater** (or smaller) element" for every item in O(n).

Days until a warmer temperature:

```python
def daily_temperatures(t: list[int]) -> list[int]:
    ans = [0] * len(t)
    stack = []                      # indexes of days still waiting, temperatures decreasing
    for i, temp in enumerate(t):
        while stack and t[stack[-1]] < temp:
            j = stack.pop()
            ans[j] = i - j          # day i is the first warmer day for day j
        stack.append(i)
    return ans
```

Each index is pushed and popped once: O(n), even though there's a `while` inside a `for`.

## Queue: first in, first out

Use `collections.deque`, **not** a list (`list.pop(0)` is O(n)):

```python
from collections import deque
q = deque()
q.append("a"); q.append("b")
q.popleft()      # "a", O(1)
```

Queues power **breadth-first search** (Day 6) and anything processed in arrival order.

### Sliding window maximum (deque)

Keep a deque of indexes whose values are decreasing; the front is always the window's max:

```python
def max_window(nums: list[int], k: int) -> list[int]:
    dq, out = deque(), []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()            # left the window
        if i >= k - 1:
            out.append(nums[dq[0]])
    return out
```
