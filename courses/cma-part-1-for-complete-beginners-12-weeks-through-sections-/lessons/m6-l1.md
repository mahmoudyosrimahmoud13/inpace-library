## 1. The cost function

> **y = a + b x** — total cost = fixed cost + (variable cost per unit × activity)

| 📈 Pattern | 🧠 In total | 🧠 Per unit | 💡 Example |
|---|---|---|---|
| Variable | Moves with volume | Constant | Fabric |
| Fixed | Constant | Falls as volume rises | Rent |
| Mixed | Fixed base plus variable layer | Falls then flattens | Electricity |
| Step | Jumps at thresholds | Staircase | Extra supervisor per shift |

Costs behave like this only inside the **relevant range**.

## 2. High-low: two points, one line

> b = (cost at high activity − cost at low activity) ÷ (high activity − low activity)
>
> a = cost at high − b × activity at high

| Month | Units | Cost $ |
|---|---|---|
| January | 1,000 | 12,000 |
| February | 1,500 | 15,500 |
| March | 800 | 10,600 |
| April | 1,800 | 17,600 |

b = (17,600 − 10,600) ÷ (1,800 − 800) = 7,000 ÷ 1,000 = **$7 per unit**.
a = 17,600 − 12,600 = **$5,000**. Forecast at 1,600 units = 5,000 + 11,200 = **$16,200**.

⚠️ High-low uses the highest and lowest **activity**, not the highest and lowest cost, and it ignores
every other observation — fast but crude.

## 3. Regression

Least squares uses every point and reports:

| 📊 Output | 🧠 Meaning |
|---|---|
| Intercept | Estimated fixed cost |
| Slope | Estimated variable cost per unit |
| R² | Share of cost variation explained (0.90 = strong fit) |
| Standard error | Typical size of the prediction error |
| Multiple regression | Two or more drivers at once |

Reading example: R² = 0.92, standard error = 400 → the model explains 92% of the variation and a
single prediction is likely to be out by roughly $400. Regression is more reliable than high-low
because it uses all the data, but it needs good data and a true linear relationship.
