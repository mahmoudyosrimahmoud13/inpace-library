## 1. General versus application controls

| 🏷️ Type | 🧠 Covers | 💡 Examples |
|---|---|---|
| General | The environment all applications run in | Access, backups, change control, network and physical security |
| Application | Controls inside one process or system | Input checks, batch totals, output distribution |

**Application controls can never be stronger than the general controls around them.** Perfect edit
checks are worthless if someone else can log in as the accountant.

## 2. Application controls

| 🔎 Control | 🧠 Catches | 💡 Example |
|---|---|---|
| Field check | Wrong character type | Letters in a numeric field |
| Format check | Wrong pattern | Date not DD/MM/YY |
| Limit (range) check | Out-of-range values | Hours worked above 12 |
| Validity check | Non-existent codes | Employee number not in the master file |
| Check digit | Mistyped long numbers | Last digit validates an account number |
| Duplicate check | Double entry | Invoice number already used |
| Batch totals | Missing records | Hash total, record count, financial total |

Processing and output controls follow: run-to-run totals, audit trails, exception reports, restricted
report distribution and logged error correction.

## 3. Backup, continuity and recovery

| 🧩 Plan | 🧠 Protects | 💡 Content |
|---|---|---|
| Backup | Data | Regular, encrypted, off-site, **tested** copies |
| DRP | IT systems | Recovery priorities, sites, teams |
| BCP | The whole business | People, premises, suppliers, communications |

| 📏 Metric | 🧠 Meaning |
|---|---|
| RTO | How long we can be down |
| RPO | How much data we can lose, in time |

**Worked example:** RTO 4 hours, RPO 30 minutes → replicate data every 30 minutes and keep a warm
standby site ready for a 4-hour switchover.

| 🏢 Site | 💡 Cost and speed |
|---|---|
| Hot | Most expensive, instant |
| Warm | Moderate |
| Cold | Cheapest, slowest |

A backup becomes a control only when it has been **restored and tested**.

## 4. Documentation and flowcharts

| 📄 Document | 🧠 Shows |
|---|---|
| Document flowchart | Movement of documents between people and departments |
| System flowchart | Program or system logic |
| Data flow diagram | Data moving between processes and stores |
| Process map | Steps, delays and waste |

| 🔷 Symbol | 🧠 Meaning |
|---|---|
| Oval | Start or end |
| Rectangle | Process |
| Diamond | Decision |
| Parallelogram | Input or output |
| Cylinder | Database |

**Worked example:** requisition → manager approval → purchase order → goods received and matched to
order and invoice → payment authorised by a second person → posted to the ledger. Every arrow is a
place where a control can be placed.
