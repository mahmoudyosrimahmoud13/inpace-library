## 1. Choosing a system

| 🏭 Production type | 🧮 System | 💡 Example |
|---|---|---|
| Unique jobs | Job order costing | Print shop, construction |
| Continuous output | Process costing | Cement, soft drinks |
| Many products, heavy overhead | Activity-based costing | A factory with 40 variants |
| Mixed batches | Hybrid / operations | Cars built to order |

**Job order costing** collects cost on a job sheet: materials + labour + applied overhead. Under- or
over-applied overhead is corrected at period end.

## 2. Process costing and equivalent units

> Weighted average: completed units + (ending WIP × % complete)
>
> FIFO: (beginning WIP × % to finish) + started and completed + (ending WIP × % complete)

| Data | Units |
|---|---|
| Beginning WIP (40% complete) | 200 |
| Started | 1,000 |
| Completed and transferred | 1,100 |
| Ending WIP (60% complete) | 100 |

Weighted average: 1,100 + 60 = **1,160 EUP**. FIFO: 120 + 900 + 60 = **1,080 EUP**.

Costs: beginning $2,400 + added $20,800 = $23,200.

| Measure | Weighted average | FIFO |
|---|---|---|
| EUP | 1,160 | 1,080 |
| Cost per EUP | $20.00 | $19.26 |
| Transferred out | 1,100 × $20 = $22,000 | Depends on the layers |

Weighted average blends old and new costs; FIFO separates them and is more accurate when costs move
sharply.

## 3. Activity-based costing

ABC spreads overhead on the activities that cause it.

| Activity | Cost pool | Driver | Quantity | Rate |
|---|---|---|---|---|
| Set-ups | 120,000 | Set-ups | 400 | $300 each |
| Inspections | 80,000 | Inspections | 1,000 | $80 each |
| Material handling | 100,000 | Moves | 2,500 | $40 each |

Product X: 40 set-ups + 100 inspections + 300 moves = 12,000 + 8,000 + 12,000 = **$32,000**. A single
volume-based rate usually gives small-batch products far too little of this cost.

| 👍 ABC | 👎 ABC |
|---|---|
| More accurate product cost | Costly to build and keep |
| Reveals the cost of complexity | Needs reliable driver data |
| Better pricing and product mix | Drivers still involve judgement |

## 4. Other approaches

| 🧾 Approach | 🧠 Idea |
|---|---|
| Kaizen costing | Continuous reduction on existing products |
| Target costing | Price − required profit = allowed cost; design to it |
| Life-cycle costing | Design, production, service and disposal costs |
| Throughput costing | Only direct material is inventoried |
| Standard costing | Compare actual with standard |

**Target costing example:** price $300, required margin 20% = $60, so cost must be **$240**. If the
current design costs $265, the team must remove $25 *in design*, not by squeezing suppliers later.
