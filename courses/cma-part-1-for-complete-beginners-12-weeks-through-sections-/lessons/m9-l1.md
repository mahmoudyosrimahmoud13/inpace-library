## 1. The vocabulary

| 🏷️ Pairing | 🧠 Meaning | 💡 Example |
|---|---|---|
| Direct vs indirect | Traceable to the product or not | Leather vs factory security |
| Product vs period | Inventoried or expensed with time | Direct labour vs marketing salary |
| Prime cost | Direct material + direct labour | The clearly traceable costs |
| Conversion cost | Direct labour + overhead | Turning material into product |
| Sunk | Already spent | A machine already bought |
| Opportunity | Benefit given up | Rent lost by using your own building |
| Relevant | Future and different between options | Only these matter in decisions |

**Rule:** sunk costs are never relevant.

| 🧾 System | 🧮 Overhead applied as | 🧠 Note |
|---|---|---|
| Actual | Actual overhead ÷ actual activity | Accurate but lumpy and late |
| Normal | Predetermined rate × actual activity | Smooth; leaves under/over-applied |
| Standard | Standard rate × standard activity allowed | Best for control and variances |

## 2. Absorption versus variable costing

| 🔍 Feature | Absorption | Variable |
|---|---|---|
| Product cost | Variable + fixed manufacturing | Variable manufacturing only |
| Fixed manufacturing overhead | In inventory and COGS | Period cost |
| External reporting | Required by GAAP and IFRS | Not allowed externally |
| Profit driver | Production **and** sales | Sales only |

**Worked example:** produced 10,000 chairs, sold 8,000 at $50; variable manufacturing $20; variable
selling $2; fixed manufacturing $90,000; fixed selling and admin $40,000.

| Line | Variable costing | Absorption costing |
|---|---|---|
| Sales | 400,000 | 400,000 |
| COGS | 160,000 (8,000 × $20) | 232,000 (8,000 × $29) |
| Gross profit | — | 168,000 |
| Variable selling | 16,000 | 16,000 |
| Fixed manufacturing | 90,000 | — |
| Fixed selling and admin | 40,000 | 40,000 |
| **Operating profit** | **94,000** | **112,000** |

The gap is **2,000 units in inventory × $9 fixed overhead per unit = $18,000**.

| 📦 Inventory movement | Which profit is higher |
|---|---|
| Increases | Absorption |
| Decreases | Variable |
| Unchanged | Equal |

## 3. Joint products and by-products

| 🔧 Method | 🧮 Base | 👍 / 👎 |
|---|---|---|
| Physical units | Volume | Simple, ignores value |
| Sales value at split-off | Relative sales value | Reflects value |
| Net realisable value | Final value − further cost | Used with no split-off market |
| Constant gross margin | Equal % margin for all | Complex but consistent |
| By-product | NRV deducted from joint cost | Keeps main products clean |

**Worked example:** joint cost $600,000; A 40,000 units at $8 = 320,000; B 20,000 units at $6 =
120,000; total sales value 440,000.

| Method | Product A | Product B |
|---|---|---|
| Physical units | 400,000 | 200,000 |
| Sales value at split-off | 436,364 | 163,636 |

**Sell or process further?** Compare incremental revenue with incremental cost; the joint cost is
sunk. A sells at $8 now or $12 after $2.50 more cost → process further, gaining **$1.50 per unit**.
