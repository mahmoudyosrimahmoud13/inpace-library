## 1. The accounting information system

An AIS collects, records, stores and reports accounting data. Its six parts:

| 🧩 Part | 💡 Example |
|---|---|
| People | The AP clerk, the CFO |
| Procedures | Month-end close checklist |
| Data | Journal entries, master files |
| Software | ERP finance module |
| Infrastructure | Servers, cloud, scanners |
| Controls and security | Access rules, reconciliations |

## 2. Transaction cycles

| 🔁 Cycle | 🔎 Steps | 🛡️ Key control |
|---|---|---|
| Revenue (order to cash) | Order → credit check → ship → invoice → collect | Credit approval; shipping matched to invoice |
| Expenditure (purchase to pay) | Requisition → order → receive → invoice → pay | Three-way match |
| Production | Plan → issue material → convert → finish | Material requisitions |
| HR and payroll | Hire → time record → pay | Separate preparation from payment |
| Financing | Borrow, issue shares, repay | Board authorisation |

## 3. Databases

| 🧩 Term | 🧠 Meaning |
|---|---|
| Field / record / table | One item → related items → related records |
| Primary key | Uniquely identifies a record (Customer ID) |
| Foreign key | Links to another table (Customer ID in the invoice) |
| Relational database | Tables joined by keys, little duplication |
| Data dictionary | Definitions of every field |

Two benefits: **less duplication** (the address is stored once, so it cannot contradict itself) and
**easier reporting** (query instead of re-keying).

## 4. ERP and the data stores

An ERP is one integrated database with modules for finance, sales, purchasing, production and HR.

| 👍 ERP | 👎 ERP |
|---|---|
| One source of truth | Expensive and slow to implement |
| Real-time cross-business information | Processes must change |
| Easier reporting and audit trail | Concentrated risk if access is weak |

| 🏗️ Store | 🧠 Holds | ⚠️ Note |
|---|---|---|
| Data warehouse | Cleaned, structured history for reporting | Built for analysis, not transactions |
| Data mart | A subset for one department | Cheaper, narrower |
| Data lake | Raw data of any type | Flexible but needs governance |

**ETL** — extract, transform, load — is the pipeline that fills the warehouse; analytics is only as
good as this step.

## 5. Enterprise performance management

EPM connects strategy to execution on top of the ERP: driver-based planning and rolling forecasts,
consolidation across entities, management reporting and scorecards, profitability analysis, and
dashboards.
