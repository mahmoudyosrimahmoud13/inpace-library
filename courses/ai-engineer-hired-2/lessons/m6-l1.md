# Heaps, intervals and greedy

## Heaps: the best few, fast

`heapq` is a min-heap. For the k largest, keep a min-heap of size k: the smallest of your k is on top, ready to be replaced. O(n log k). For a max-heap, push negative numbers.

```python
import heapq

def kth_largest(nums, k):
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)            # drop the smallest; the k largest stay
    return heap[0]


class MedianFinder:                        # two heaps: the low half and the high half
    def __init__(self):
        self.low, self.high = [], []       # low is a max-heap (stored negative)

    def add(self, x):
        heapq.heappush(self.low, -x)
        heapq.heappush(self.high, -heapq.heappop(self.low))
        if len(self.high) > len(self.low):
            heapq.heappush(self.low, -heapq.heappop(self.high))

    def median(self):
        if len(self.low) > len(self.high):
            return -self.low[0]
        return (-self.low[0] + self.high[0]) / 2
```

## Intervals: sort by start, then sweep

Almost every interval problem starts with `intervals.sort()`. Then one pass merges overlaps (`start <= last_end`), counts removals (keep the one that ends first) or tracks rooms in use (a heap of end times).

```python
def merge(intervals):
    intervals.sort(key=lambda iv: iv[0])
    out = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= out[-1][1]:
            out[-1][1] = max(out[-1][1], end)
        else:
            out.append([start, end])
    return out
```

## Greedy: the local best is the global best

Greedy works when you can argue that taking the best choice now never hurts later (an "exchange argument"). Kadane's algorithm: extend the current subarray, or start fresh if the sum so far only hurts. If you can't justify a greedy choice in one sentence, suspect dynamic programming instead.

```python
def max_subarray(nums):
    best = cur = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)              # extend, or start fresh here
        best = max(best, cur)
    return best
```
