# More layered builds to practice

Do at least one more, with a friend playing the interviewer who reveals the next level only when you finish the current one.

| Build | Level 1 | Level 2 | Level 3 |
|---|---|---|---|
| Rate limiter | fixed window per user | sliding window | token bucket, configurable per plan |
| Web crawler | crawl one site to depth N (BFS, visited set) | respect robots.txt and a delay per host | concurrent with `asyncio`, a cap per host |
| Bank / credits ledger | deposit, withdraw, balance | credits that expire, used oldest first | a monthly statement and an undo |
| File system `cd` | absolute and relative paths, `..` | symbolic links | detect link loops |
