# NumPy you must be fluent in

ML coding rounds ask you to write a model's core in NumPy, without loops where a vector operation exists. Know these by heart:

| Idea | Example |
|---|---|
| shapes first | write `# X: (n, d), w: (d,)` above every function |
| matrix product | `X @ w` is `(n,)`; `A @ B` needs `A.shape[1] == B.shape[0]` |
| broadcasting | `X - X.mean(axis=0)` subtracts each column's mean from every row |
| `axis` and `keepdims` | `x.sum(axis=1, keepdims=True)` keeps `(n, 1)` so it divides `(n, d)` |
| masks | `X[y == 1]` picks the rows of class 1 |
| top k | `np.argpartition(-s, k - 1)[:k]` in O(n), then sort those k |
| stability | subtract the max before `exp`; clip probabilities before `log` |

Practice: rewrite three of your loop-based Python functions as one NumPy line each, and check with `np.allclose` that the answers match.
