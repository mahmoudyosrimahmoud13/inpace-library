# 2-D dynamic programming, bits and math

When the state needs two numbers (positions in two strings, a cell in a grid, an item and a remaining capacity), the table is 2-D. Longest Common Subsequence is the template for most two-string problems (Edit Distance, Interleaving String):

```python
def lcs(a, b):
    dp = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]   # dp[i][j]: LCS of a[i:], b[j:]
    for i in range(len(a) - 1, -1, -1):
        for j in range(len(b) - 1, -1, -1):
            if a[i] == b[j]:
                dp[i][j] = 1 + dp[i + 1][j + 1]
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j + 1])
    return dp[0][0]
```

**Knapsack shapes:** 0/1 (each item once: loop capacity downwards, e.g. Partition Equal Subset Sum, Target Sum) and unbounded (items reusable: loop capacity upwards, e.g. Coin Change II).

## Bits

| Trick | Means |
|---|---|
| `x & 1` | is x odd? |
| `x & (x - 1)` | x without its lowest set bit |
| `a ^ a == 0`, `a ^ 0 == a` | XOR cancels pairs: the single number = XOR of all |
| `x >> 1`, `x << 1` | divide or multiply by 2 |
| `bits[i] = bits[i >> 1] + (i & 1)` | count set bits for 0..n in O(n) |

## Matrix and math

Rotate a matrix in place = transpose, then reverse each row. Spiral order = four boundaries that shrink. Fast power = square and halve the exponent (O(log n)).
