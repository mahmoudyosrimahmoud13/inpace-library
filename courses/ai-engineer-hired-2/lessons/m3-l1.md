# Sliding window and stack

## Sliding window

For "the longest/shortest **contiguous** part that satisfies X", keep a window `[start, i]`. Grow it one step at a time with `i`; when it breaks the rule, shrink it from `start`. Each index enters and leaves once: O(n).

```python
def longest_unique(s):
    last = {}                          # char -> last index
    start = best = 0
    for i, ch in enumerate(s):
        if ch in last and last[ch] >= start:
            start = last[ch] + 1           # jump past the repeat
        last[ch] = i
        best = max(best, i - start + 1)
    return best
```

For fixed-size windows (permutation in a string), keep counts of the window and compare them to the target counts as the window slides.

## Stack and monotonic stack

A stack matches pairs (brackets) and evaluates expressions. A **monotonic stack** answers "the next greater/smaller element" in O(n): keep indexes whose answer isn't known yet; a new value pops everything it beats.

```python
def daily_temperatures(temps):
    answer = [0] * len(temps)
    stack = []                         # days still waiting for a warmer day
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            j = stack.pop()
            answer[j] = i - j
        stack.append(i)
    return answer
```
