# AI-assisted coding rounds

Some companies now let you use an AI assistant in a coding round, because that's how engineers work. In mid-2025 Meta announced it was trialling AI-enabled coding interviews, and the field guide reports Microsoft running an AI-assisted round followed by a separate no-AI round. Others move the other way: Google said in 2025 it was bringing back in-person interviews, partly because of AI cheating in remote ones.

## How you're judged when AI is allowed

The interviewer watches **how you direct and check** the tool, not whether it can solve the problem:

- Plan first, out loud; ask the AI for small, specific pieces.
- Read every line it gives you and say what it does. Pasting code you can't explain is the fastest way to fail.
- Write or ask for tests, run them, and catch its mistakes yourself.
- Know the complexity of what it wrote.

**The rule that never changes:** if a round says no AI, using one is cheating, and companies are getting better at spotting it. Train without AI, so you can do both.
