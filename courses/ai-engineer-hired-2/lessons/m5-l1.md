# Trees and tries

## Depth-first: ask your children, then decide

Most tree problems are one recursive function: handle the empty node, get answers from the left and right subtrees, combine. Decide **what the function returns** before writing it.

```python
def max_depth(root):
    if not root:
        return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))


def is_valid_bst(node, lo=float("-inf"), hi=float("inf")):
    if not node:
        return True
    if not lo < node.val < hi:
        return False
    return is_valid_bst(node.left, lo, node.val) and is_valid_bst(node.right, node.val, hi)
```

When the answer isn't what you return (Diameter, Max Path Sum), return one thing (the best single path down) and update another in an outer variable (the best path through this node).

## Breadth-first: level by level

A queue and a `for` loop over the current level size:

```python
from collections import deque

def level_order(root):
    if not root:
        return []
    out, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        out.append(level)
    return out
```

## Tries

A trie stores words letter by letter, so prefix questions cost O(length of word). It's also the heart of autocomplete, and of Word Search II (search many words in a grid at once).

```python
class Trie:
    def __init__(self):
        self.root = {}

    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node["$"] = True                  # the end of a word

    def search(self, word, prefix=False):
        node = self.root
        for ch in word:
            if ch not in node:
                return False
            node = node[ch]
        return prefix or "$" in node
```
