# Problem set: heaps, intervals, greedy

Solve them in order: each one adds one idea to the last. Rules for every problem:

1. **Timebox:** 20 minutes for Easy, 35 for Medium, 50 for Hard. Start a timer.
2. **Say it out loud** (or write it): clarify, examples, brute force, then better.
3. **Stuck at the timebox?** Read the hint below, then try 10 more minutes. Still stuck: watch the solution on [NeetCode](https://neetcode.io/roadmap), close it, and write the code yourself from memory.
4. **Log it** in your tracker: date, time taken, solved alone or not, the key idea in one line.
5. **Redo** every problem you needed help with after 3 days, and again after 10.
