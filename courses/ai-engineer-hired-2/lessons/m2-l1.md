# Arrays, hashing and two pointers

## Hash map: remember what you've seen

When a brute force checks every pair (O(n²)), ask: *could I look the partner up instead of searching for it?* A dict or set turns the inner loop into an O(1) lookup.

```python
def two_sum(nums, target):
    seen = {}                          # value -> index
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
```

## Counting and grouping

`Counter` counts; a dict of lists groups things by a key you compute (for anagrams, the sorted letters). When counts are bounded by n, **bucket sort** gets the top k in O(n):

```python
from collections import Counter

def top_k_frequent(nums, k):
    buckets = [[] for _ in range(len(nums) + 1)]   # buckets[c] = values seen c times
    for x, c in Counter(nums).items():
        buckets[c].append(x)
    out = []
    for c in range(len(nums), 0, -1):
        out.extend(buckets[c])
        if len(out) >= k:
            return out[:k]
```

## Two pointers on a sorted array

After sorting, one pointer at each end moves inward: if the sum is too small, move left up; too big, move right down. Skip equal neighbours to avoid duplicate answers.

```python
def three_sum(nums):
    nums.sort()
    res = []
    for i, a in enumerate(nums):
        if i and a == nums[i - 1]:
            continue                       # same first number: same triples
        lo, hi = i + 1, len(nums) - 1
        while lo < hi:
            s = a + nums[lo] + nums[hi]
            if s < 0:
                lo += 1
            elif s > 0:
                hi -= 1
            else:
                res.append([a, nums[lo], nums[hi]])
                lo += 1
                while lo < hi and nums[lo] == nums[lo - 1]:
                    lo += 1
    return res
```

**Prefix and suffix:** "product of everything except me" is the product of everything to my left times everything to my right, computed in two passes, no division.
