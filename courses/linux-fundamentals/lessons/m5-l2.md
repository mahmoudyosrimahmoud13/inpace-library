# Practice: answer questions from a log file

Make a sample web log to practise on:

```bash
mkdir -p ~/lab && cd ~/lab
for i in $(seq 1 500); do
  ip="10.0.0.$(( RANDOM % 20 ))"
  code=$(( RANDOM % 10 == 0 ? 500 : (RANDOM % 6 == 0 ? 404 : 200) ))
  page=$(shuf -n1 -e / /login /cart /api/items /about)
  echo "$ip - - [17/Nov/2026:10:$(( RANDOM % 60 )):00] \"GET $page HTTP/1.1\" $code $(( RANDOM % 5000 ))"
done > access.log
head -3 access.log
```

Each line: IP, date, request, status code, bytes.

## Questions and one way to answer each

```bash
# 1. How many requests?
wc -l < access.log

# 2. How many errors (status 500)?
awk '$9 == 500' access.log | wc -l

# 3. Top 5 IPs
awk '{print $1}' access.log | sort | uniq -c | sort -nr | head -5

# 4. Requests per page
awk '{print $7}' access.log | sort | uniq -c | sort -nr

# 5. Total bytes sent
awk '{s += $10} END {print s}' access.log

# 6. Which pages give 404s?
awk '$9 == 404 {print $7}' access.log | sort | uniq -c

# 7. Save the 500 errors to their own file
grep '" 500 ' access.log > errors.log
```

Field numbers come from splitting on spaces: `$1` is the IP, `$7` the path, `$9` the status, `$10` the bytes. When you're not sure, check with `awk '{print $9}' access.log | head`.

## The real skill

It isn't memorising flags. It's **breaking a question into steps**: which lines, which column, group, count, sort, limit. The same steps work in SQL and in pandas.
