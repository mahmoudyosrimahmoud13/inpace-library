# Working with files and directories

```bash
mkdir projects                 # make a directory
mkdir -p projects/site/css     # make the whole path, no error if it exists
touch notes.txt                # create an empty file (or update its time)
cp notes.txt notes.bak         # copy a file
cp -r projects projects-copy   # copy a directory (recursive)
mv notes.bak old/              # move into a directory
mv draft.txt final.txt         # rename = move to a new name
rm final.txt                   # delete a file
rm -r projects-copy            # delete a directory and everything in it
rmdir empty-dir                # delete only if empty
```

## rm has no undo

There's no recycle bin on the command line. Two habits:

- Use `rm -i` (asks first) when you're unsure, and `ls` the exact same pattern first.
- **Never** run `rm -rf` with a variable or `*` you haven't checked. `rm -rf $DIR/*` with an empty `$DIR` becomes `rm -rf /*`.

## Wildcards (globs)

The **shell** expands these before the command runs:

| Pattern | Matches |
|---|---|
| `*` | Anything (except a leading dot) |
| `?` | Exactly one character |
| `[abc]` / `[0-9]` | One of these characters |
| `{jpg,png}` | Each choice in turn (brace expansion) |

```bash
ls *.txt
ls report-202?.pdf
cp photo-[0-9].jpg backup/
mkdir -p 2026/{jan,feb,mar}      # makes three directories
echo *.log                        # see exactly what a glob expands to before using it
```

## Quotes

- `"double quotes"`: spaces kept, but `$VAR` and `$(command)` are still expanded.
- `'single quotes'`: everything is literal.
- `\` escapes one character: `cd My\ Documents`.

```bash
echo "Home is $HOME"     # Home is /home/sara
echo 'Home is $HOME'     # Home is $HOME
```

## Find out what a file is

```bash
file photo.jpg          # JPEG image data...
du -sh projects         # how much space a directory uses
stat notes.txt          # every detail
```
