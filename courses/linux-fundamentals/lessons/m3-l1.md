# Reading files: cat, less, head, tail

| Command | Use it for |
|---|---|
| `cat file` | Print a short file |
| `less file` | Read a long file page by page |
| `head -n 20 file` | The first 20 lines |
| `tail -n 20 file` | The last 20 lines |
| `tail -f file` | Keep showing new lines as they're added (logs!) |
| `wc -l file` | Count lines (`-w` words, `-c` bytes) |

## less, the pager

Inside `less`:

- Space / b: page down / up
- `/error`: search forward, `n` next match, `N` previous
- `G` end, `g` start
- `q` quit
- `F` follow new lines like `tail -f` (Ctrl+C to stop following)

`man` uses `less`, so these keys work in manual pages too.

## Watching a log live

```bash
sudo tail -f /var/log/syslog          # Debian/Ubuntu
sudo journalctl -f                    # any systemd system
tail -f app.log | grep --line-buffered ERROR
```

## Comparing files

```bash
diff old.conf new.conf           # line differences
diff -u old.conf new.conf        # the "unified" format you see in code reviews
cmp a.bin b.bin                  # byte differences for binary files
```

## Try it

```bash
cat /etc/os-release
less /etc/services        # search for "ssh" with /ssh
head -n 5 /etc/passwd
wc -l /etc/passwd         # roughly how many accounts
```
