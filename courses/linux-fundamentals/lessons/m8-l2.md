# Capstone: find your way around an unfamiliar machine

This is the real goal of the course: someone gives you a login to a Linux box you've never seen, and within ten minutes you know what it is and what's going on.

## The ten-minute tour

```bash
# What is this machine?
hostnamectl                 # name, OS, kernel, virtualization
cat /etc/os-release
uptime                      # how long it's been up, load average

# Who am I, and what may I do?
id
sudo -l                     # what sudo allows me (if anything)

# Resources
nproc; free -h; df -h       # CPUs, memory, disk space
lsblk                       # disks and partitions

# What's running?
systemctl --type=service --state=running | head -30
ps aux --sort=-%mem | head
ss -tlnp                    # what's listening on the network

# What happened recently?
last -n 10                  # recent logins
journalctl -p err -b | tail -20   # errors since this boot
ls -lt /var/log | head

# Who else is here?
who
```

## Reading the load average

`uptime` shows three numbers, the average number of processes wanting CPU (or stuck on disk) over 1, 5 and 15 minutes. Compare with `nproc`: on a 4-CPU machine, a load of 4 means fully busy; 12 means work is queuing.
