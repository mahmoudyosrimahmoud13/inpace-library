## The grammar of this unit: ir a + infinitive, and stem-changing verbs

**Ir** (to go) is irregular:

| ir | |
|---|---|
| yo | **voy** |
| tú | **vas** |
| él / ella / usted | **va** |
| nosotros | **vamos** |
| vosotros | **vais** |
| ellos / ustedes | **van** |

**ir a + infinitive** = "going to", for plans: *Voy a visitar a mis abuelos. ¿Qué vas a hacer? Vamos a comer fuera.* It's the easiest way to talk about the future, and Spanish speakers use it all the time.

Going **to a place** also uses *a*: *Voy a Madrid. Voy al cine* (a + el = al).

**Stem-changing verbs.** Some verbs change the vowel in their stem, in every form **except nosotros and vosotros**:

| e → ie: querer (want) | o → ue: poder (can) | e → i: pedir (ask for) |
|---|---|---|
| qu**ie**ro | p**ue**do | p**i**do |
| qu**ie**res | p**ue**des | p**i**des |
| qu**ie**re | p**ue**de | p**i**de |
| queremos | podemos | pedimos |
| queréis | podéis | pedís |
| qu**ie**ren | p**ue**den | p**i**den |

Others like these: *empezar (empieza)*, *preferir (prefiero)*, *volver (vuelvo)*, *dormir (duermo)*, *jugar (juego)*.

*Querer* and *poder* + infinitive are very useful: *¿Quieres venir? No puedo ir.*
