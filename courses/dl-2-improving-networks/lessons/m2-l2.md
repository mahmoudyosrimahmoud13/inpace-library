# Dropout

During training, drop each unit with probability `1 − keep_prob`, and scale the survivors by `1 / keep_prob`
("inverted dropout") so the expected value stays the same. At test time, use every unit and no scaling.

Why it works: a unit can't rely on any one input, so it spreads its weights out: an effect like L2. Use more dropout
in big layers that overfit, less (or none) in small ones.

```python
nn.Dropout(p=0.5)               # PyTorch: p is the DROP probability (the slides' keep_prob = 0.5)
keras.layers.Dropout(rate=0.5)  # Keras: rate is the drop probability too
model.train(); model.eval()     # PyTorch: dropout is on in train(), off in eval(). Forgetting eval() is a classic bug.
```
