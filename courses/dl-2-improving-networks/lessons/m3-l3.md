# Gradient checking

Reshape all parameters into one vector `θ`, and compare `dθ_approx[i] = (J(θ + ε·e_i) − J(θ − ε·e_i)) / 2ε` with your
`dθ`. Relative difference `≈ 10⁻⁷` is great, `10⁻⁵` worth a look, `10⁻³` a bug.

Notes from the slides that still apply: don't use it in training (slow), include regularization, turn dropout off,
and check again after some training. Today: `torch.autograd.gradcheck` does this for you (use float64). You need it
mostly when you write your own backward function (a custom layer or a custom CUDA kernel).
