# Mini-batch gradient descent

Split the training set into mini-batches (`X{t}`, `Y{t}`) and take a step after **each** one. One pass over all the
data is an **epoch**.

| Batch size | Name | Behaviour |
|---|---|---|
| m | batch | smooth but slow steps |
| 1 | stochastic | noisy, loses vectorization |
| 32 to 512 (often a power of 2) | mini-batch | the usual choice |

The cost goes down with noise (each batch is different), not smoothly. Make sure a batch fits in GPU memory.

```python
loader = torch.utils.data.DataLoader(dataset, batch_size=64, shuffle=True)   # reshuffled every epoch
ds = tf.data.Dataset.from_tensor_slices((x, y)).shuffle(10_000).batch(64).prefetch(tf.data.AUTOTUNE)
```
