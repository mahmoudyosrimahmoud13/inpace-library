# Bias, variance, and the basic recipe

Compare training error with dev error (and with what's possible, roughly human-level error):

| Train error | Dev error | Diagnosis |
|---|---|---|
| 1% | 11% | high **variance** (overfitting) |
| 15% | 16% | high **bias** (underfitting) |
| 15% | 30% | both |
| 0.5% | 1% | good |

**The recipe:** high bias? Bigger network, train longer, better architecture. Then high variance? More data,
regularization, better architecture. In deep learning you can often reduce one **without** making the other worse
(a bigger network plus regularization), so the old "trade-off" matters less.
