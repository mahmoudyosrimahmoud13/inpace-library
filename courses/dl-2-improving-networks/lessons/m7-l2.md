# Softmax for many classes

For `C` classes, the last layer has `C` units and softmax turns scores into probabilities that sum to 1:
`softmax(z)_i = e^(z_i) / Σ_j e^(z_j)`. The loss is categorical cross-entropy: `−log(ŷ of the true class)`.

```python
loss = nn.functional.cross_entropy(logits, labels)         # PyTorch: logits + class indices; softmax is inside
loss = keras.losses.SparseCategoricalCrossentropy(from_logits=True)
```

A common bug: adding your own softmax before `cross_entropy`, so it's applied twice. Training still "works", badly.
