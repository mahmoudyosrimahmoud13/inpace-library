# L2 regularization and weight decay

Add a penalty for large weights: `J = (1/m)·ΣL + (λ / 2m)·Σ_l ||W[l]||²`. The gradient gains `(λ/m)·W`, so every step
also shrinks the weights a little: hence the name **weight decay**.

**Why it helps:** small weights keep `z` near 0, where tanh is almost linear, so each layer is "simpler" and the network
can't fit every wiggle of the training noise.

## The 2026 way: AdamW

With Adam, adding L2 to the loss is **not** the same as weight decay (Adam rescales the gradient, including the
penalty). **AdamW** applies the decay directly to the weights, which works better and is the default for most modern
networks:

```python
torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)
keras.optimizers.AdamW(learning_rate=1e-3, weight_decay=0.01)
```
