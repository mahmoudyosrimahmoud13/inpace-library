# What to tune, and how to search

Roughly by importance: **learning rate** first; then momentum β, mini-batch size, number of hidden units; then number of
layers and learning-rate decay. Adam's β₁, β₂, ε: almost never.

- **Random search, not a grid:** with a grid you try only a few values of the hyperparameter that matters most.
- **Coarse to fine:** find the good region, then sample more densely inside it.
- **Use the right scale:** sample the learning rate on a **log** scale (`10 ** np.random.uniform(-4, -1)`), and β as
  `1 − 10^r`, because results are very sensitive near β = 1.

## Today's tools

Libraries do the bookkeeping: **Optuna** (PyTorch-friendly), **KerasTuner**, and Ray Tune for many machines. They use
smarter methods than pure random search (Bayesian optimization, early stopping of bad trials like Hyperband).
