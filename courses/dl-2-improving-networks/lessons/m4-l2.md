# Exponentially weighted averages and bias correction

`v_t = β·v_(t−1) + (1 − β)·θ_t` averages over roughly the last `1 / (1 − β)` values. It's the engine inside momentum,
RMSprop, Adam and batch norm's running statistics.

![Exponentially weighted averages](ewma.png)

Because `v_0 = 0`, the first values are too low. **Bias correction** divides by `1 − β^t`, which fixes the start and
fades away as `t` grows.
