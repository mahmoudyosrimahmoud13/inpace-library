# Interview drill

1. **Train error 1%, dev 10%. What next?** Variance: more data, augmentation, regularization (weight decay, dropout),
   or a better architecture.
2. **Why does dropout need `model.eval()`?** Dropout and batch norm behave differently in training and inference.
3. **Adam vs AdamW?** AdamW decouples weight decay from the adaptive gradient scaling; it generalizes better.
4. **Why warmup?** Early Adam statistics are unreliable; small steps first avoid divergence.
5. **How do you pick a learning rate?** Log-scale search; or a learning-rate range test (increase it every step, pick a
   value a bit below where the loss blows up).
6. **BatchNorm vs LayerNorm?** BatchNorm normalizes over the batch (great for CNNs with big batches); LayerNorm over
   features of each example (transformers, any batch size).
7. **Your loss is NaN. What do you check?** Learning rate too high, `log(0)` (use logits), bad inputs (NaN/inf in data),
   exploding gradients (clip them: `torch.nn.utils.clip_grad_norm_`).
