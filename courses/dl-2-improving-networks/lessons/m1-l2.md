# Train, dev and test sets

Applied deep learning is a loop: **idea → code → experiment**. Good data splits make the loop fast and honest.

| Set | Used for |
|---|---|
| train | fitting the parameters |
| dev (validation) | choosing between models and hyperparameters |
| test | one unbiased final estimate (optional if you don't need it) |

With a million examples, 98 / 1 / 1 is fine: 10,000 dev examples are plenty to compare models. The old 60/20/20 rule
was for small datasets.

**Rule that matters most:** dev and test must come from the **same distribution**, the one you care about. Training
data can be different (part 3 covers that case in depth).
