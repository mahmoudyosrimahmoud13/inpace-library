# Normalizing inputs

Subtract the mean and divide by the standard deviation of each feature, computed **on the training set**, then apply
the same numbers to dev and test. Features on similar scales make the cost round instead of a long thin valley, so
gradient descent can take bigger steps.

```python
from sklearn.preprocessing import StandardScaler   # or keras.layers.Normalization().adapt(x_train)
scaler = StandardScaler().fit(X_train); X_dev = scaler.transform(X_dev)
```
