# الأصناف (classes)

الصنف قالب لكائنات تتشارك نفس البنية والسلوك.

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 3:12:56 إلى 3:20:25. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
class Timer {
  #seconds = 0;                 // private field: only the class can see it

  constructor(label) {
    this.label = label;
  }

  tick(n = 1) {
    this.#seconds += n;
    return this;                // lets you chain: t.tick().tick()
  }

  get minutes() {               // a getter: used like a property
    return Math.floor(this.#seconds / 60);
  }

  toString() {
    return `${this.label}: ${this.minutes} min`;
  }
}

class PomodoroTimer extends Timer {   // inheritance
  constructor() {
    super("Pomodoro");
  }
  get finished() {
    return this.minutes >= 25;
  }
}

const p = new PomodoroTimer();
p.tick(1500);
console.log(String(p), p.finished);   // Pomodoro: 25 min true
```

استخدم الأصناف عندما تكون لديك كائنات كثيرة بنفس السلوك. وللبيانات البسيطة تكفي الكائنات العادية والدوال (وهذا ما يفعله المشروع).
