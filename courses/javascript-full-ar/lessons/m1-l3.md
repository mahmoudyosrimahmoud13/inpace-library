# المتغيرات والأنواع

المتغير صندوق له اسم يحفظ قيمة. استخدم **`const`** افتراضيًا، و **`let`** عندما ستتغير القيمة. (الكود القديم يستخدم `var`، وتشرح الوحدة 7 لماذا نتجنبها.)

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 0:05:56 إلى 0:14:05. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
const name = "Mona";       // string (text)
let age = 24;               // number
const isStudent = true;     // boolean: true or false
let city;                   // undefined: no value yet
const nothing = null;       // null: "empty on purpose"

age = age + 1;              // let can change
console.log(name, age);     // Mona 25
console.log(typeof age);    // "number"
```

| النوع | مثال |
|---|---|
| string (نص) | `"hello"`، `'hi'` |
| number (رقم) | `42`، `3.14` (نوع واحد للاثنين) |
| boolean | `true`، `false` |
| undefined | متغير بلا قيمة |
| null | لا قيمة، عن قصد |
| object و array | الوحدتان 4 و 6 |

**الأسماء:** تبدأ بحرف، وتستخدم camelCase (`totalMinutes`)، وتذكّر أن JavaScript **تفرّق بين الحروف الكبيرة والصغيرة**: `age` غير `Age`. وإعادة الإسناد إلى `const` خطأ: `TypeError: Assignment to constant variable.`
