# var و let و const

| | var | let | const |
|---|---|---|---|
| النطاق | الدالة كلها | الكتلة `{ }` | الكتلة `{ }` |
| إعادة الإسناد | نعم | نعم | لا |
| هل تستخدمها؟ | لا، في الكود القديم فقط | عندما تتغير القيمة | افتراضيًا |

`var` تتسرب خارج الكتل ويمكن استخدامها قبل سطرها (كـ `undefined`)، وهذا يخفي الأخطاء. والكود الحديث يستخدم `const` و `let`.

>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
for (var i = 0; i < 3; i++) {}
console.log(i);   // 3: var leaked out of the loop
for (let j = 0; j < 3; j++) {}
// console.log(j); // ReferenceError: j stays inside the loop
```
