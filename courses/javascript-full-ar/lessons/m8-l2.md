# الأحداث

تخبرك الصفحة عندما يحدث شيء: نقرة، أو مفتاح، أو إرسال نموذج.

```javascript
const button = document.querySelector("button");
button.addEventListener("click", (event) => {
  console.log("Clicked!", event.target);
});

const form = document.querySelector("form");
form.addEventListener("submit", (event) => {
  event.preventDefault();        // stop the page from reloading
  const text = form.querySelector("input").value;
  console.log("New task:", text);
});
```

**تفويض الأحداث:** بدل مستمع لكل عنصر، ضع مستمعًا واحدًا على القائمة وافحص `event.target`. ويعمل أيضًا مع العناصر المضافة لاحقًا. ستستخدمه في المشروع.
