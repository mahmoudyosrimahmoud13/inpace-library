# النصوص القالبية (template literals)

استخدم العلامة `` ` `` و `${...}` لوضع القيم داخل النص. أوضح من `+`، ويمكن أن تمتد لعدة أسطر.

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 3:06:39 إلى 3:10:43. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
const task = "Read chapter 3";
const minutes = 30;
console.log(`${task}: ${minutes} min, ${minutes / 60} h`);
// Read chapter 3: 30 min, 0.5 h

const card = `
  Name: ${task}
  Done: ${minutes > 20 ? "later" : "now"}
`;
```
