# الكائنات

الكائن يجمع قيمًا مترابطة تحت أسماء (مفاتيح).

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 1:49:11 إلى 2:10:15. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
const task = {
  title: "Read chapter 3",
  minutes: 30,
  done: false,
  tags: ["reading", "math"],
};

console.log(task.title);           // dot notation
console.log(task["minutes"]);      // bracket notation (when the key is in a variable)
task.done = true;                  // update
task.priority = "high";            // add a new key
delete task.tags;                  // remove a key
console.log("priority" in task);   // true
console.log(Object.keys(task));    // ["title", "minutes", "done", "priority"]

for (const [key, value] of Object.entries(task)) {
  console.log(`${key}: ${value}`);
}
```

**الكائنات كجداول بحث** تغني عن سلاسل if/else الطويلة:

```javascript
const dayNames = { 0: "Sunday", 1: "Monday", 5: "Friday" };
console.log(dayNames[5] ?? "Another day");   // "Friday"
```

**الكائنات تُمرَّر بالمرجع:** `const b = a` لا تنسخ، بل يشير الاسمان إلى نفس الكائن. انسخ بـ `{ ...a }` (نسخة سطحية) أو `structuredClone(a)` (نسخة عميقة).
