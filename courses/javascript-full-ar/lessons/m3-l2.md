# switch و ternary و ?? و ?.

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 1:32:15 إلى 1:43:38. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
const day = "Fri";
switch (day) {
  case "Fri":
  case "Sat":
    console.log("Weekend");
    break;               // without break, it falls into the next case
  default:
    console.log("Work day");
}

const age = 20;
const label = age >= 18 ? "adult" : "minor";   // condition ? if true : if false

const nickname = null;
console.log(nickname ?? "no nickname");        // ?? : a default only for null/undefined

const user = { profile: null };
console.log(user.profile?.city);               // ?. : undefined instead of a crash
```

`||` تعطي الطرف الأيمن لأي قيمة **كاذبة** (فـ `0 || 10` تساوي 10)، أما `??` فتعطيه فقط مع `null` و `undefined` (فـ `0 ?? 10` تساوي 0). استخدم `??` للقيم الافتراضية.
