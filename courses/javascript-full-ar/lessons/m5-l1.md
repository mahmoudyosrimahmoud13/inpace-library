# الدوال والمعاملات و return

الدالة كتلة كود لها اسم ويمكن إعادة استخدامها.

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 0:51:41 إلى 1:08:41. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
function minutesToHours(minutes) {   // minutes is a parameter
  return minutes / 60;               // return sends a value back and stops the function
}
const h = minutesToHours(90);         // 90 is the argument
console.log(h);                       // 1.5

function greet(name = "friend") {     // a default value
  console.log(`Hi, ${name}!`);        // no return: the result is undefined
}
greet();          // Hi, friend!
greet("Mona");    // Hi, Mona!
```

## النطاق (scope)

المتغير المعلن بـ `let` أو `const` داخل `{ }` يوجد فقط داخل هذين القوسين. ويمكن قراءة المتغيرات الخارجية داخل الدالة، لكن تجنّب تغييرها من الداخل: أدخل القيم كمعاملات وأخرج النتائج بـ return.

```javascript
const tax = 0.14;
function withTax(price) {
  const result = price * (1 + tax);   // result lives only here
  return Math.round(result);
}
console.log(withTax(100));   // 114
// console.log(result);      // ReferenceError: result is not defined
```
