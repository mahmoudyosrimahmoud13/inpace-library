# الدوال السهمية و rest و spread

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 2:47:17 إلى 2:57:18. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
const double = (n) => n * 2;           // one expression: the value is returned
const add = (a, b) => {                 // with braces you need return
  const sum = a + b;
  return sum;
};

const total = (...nums) => nums.reduce((s, n) => s + n, 0);   // rest: any number of arguments
console.log(total(1, 2, 3, 4));         // 10

const a = [1, 2];
const b = [...a, 3];                    // spread: copy and extend -> [1, 2, 3]
console.log(Math.max(...b));            // 3
console.log(double(5), add(2, 3));      // 10 5
```

الدوال قيم: يمكنك حفظها في متغيرات وتمريرها لدوال أخرى. وهذا ما فعلته في `map((t) => t.title)`: دالة **callback**.
