# الحلقات: for و while و for...of

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 2:10:15 إلى 2:24:12. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
for (let i = 1; i <= 5; i++) {   // start; condition; step
  console.log(i);                  // 1 2 3 4 5
}

const minutes = [25, 40, 15];
let total = 0;
for (const m of minutes) {       // each value: the easiest loop for arrays
  total += m;
}
console.log(total);              // 80

let n = 3;
while (n > 0) {                  // repeat while the condition is true
  console.log(n);
  n--;
}
```

استخدم `break` للخروج من الحلقة مبكرًا، و `continue` للانتقال للدورة التالية. والحلقة التي لا يصبح شرطها false أبدًا تعمل للأبد: تأكد أن شيئًا يتغير في كل دورة.
