- **مهمة واحدة لكل دالة**، واسم يقولها: `totalMinutes`، `isValidEmail`.
- **نقية متى أمكن:** نفس المدخلات تعطي نفس المخرجات، بلا تغيير في الخارج. والدوال النقية سهلة الاختبار.
- **اخرج مبكرًا** عند المدخلات الخاطئة بدل التداخل العميق.

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 1:41:11 إلى 1:43:38. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
function discount(price, percent) {
  if (price < 0 || percent < 0 || percent > 100) return null;   // return early
  return price - (price * percent) / 100;
}
console.log(discount(200, 25));   // 150
console.log(discount(200, 120));  // null
```
