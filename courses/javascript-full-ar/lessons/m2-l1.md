# الحساب بالأرقام

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 0:14:05 إلى 0:21:19. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
console.log(7 + 2, 7 - 2, 7 * 2, 7 / 2);  // 9 5 14 3.5
console.log(7 % 2);       // 1: the remainder (is 7 odd? yes)
console.log(2 ** 10);     // 1024: power

let count = 0;
count += 5;               // count = count + 5
count++;                  // add 1
console.log(count);       // 6

console.log(0.1 + 0.2);                 // 0.30000000000000004
console.log((0.1 + 0.2).toFixed(2));    // "0.30"
console.log(Math.round(2.6), Math.floor(2.6), Math.max(3, 9, 4));  // 3 2 9
console.log(Math.floor(Math.random() * 6) + 1);  // a dice: 1 to 6
```

**الكسور ليست دقيقة** (0.1 + 0.2): للمال احسب بالقروش (أرقام صحيحة) أو قرّب عند العرض.

**من نص إلى رقم:** `Number("42")` تعطي 42، و `parseInt("42px")` تعطي 42، و `Number("abc")` تعطي `NaN` (ليس رقمًا). افحص بـ `Number.isNaN(x)`.
