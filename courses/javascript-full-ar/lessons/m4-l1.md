# المصفوفات

المصفوفة قائمة مرتبة. والمواضع تبدأ من **0**.

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 0:40:44 إلى 0:51:41. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
const tasks = ["Read", "Code", "Review"];
console.log(tasks[0], tasks.length);   // "Read" 3
tasks[1] = "Code more";                 // change an item
tasks.push("Rest");                     // add at the end
const last = tasks.pop();               // remove from the end: "Rest"
tasks.unshift("Plan");                  // add at the start
tasks.shift();                          // remove from the start
console.log(tasks.includes("Read"));    // true
console.log(tasks.indexOf("Review"));   // 2
const grid = [[1, 2], [3, 4]];          // an array of arrays
console.log(grid[1][0]);                // 3
```

المصفوفة المعلنة بـ `const` يمكن تعديل محتواها (`push` تعمل)، و `const` تمنعك فقط من ربط الاسم بمصفوفة أخرى.
