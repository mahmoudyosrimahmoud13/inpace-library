# الأخطاء وتتبعها

```javascript
function parseTasks(text) {
  try {
    return JSON.parse(text);
  } catch (error) {
    console.error("Bad data:", error.message);
    return [];
  } finally {
    console.log("parseTasks finished");   // runs either way
  }
}

function createTask(title) {
  if (!title.trim()) throw new Error("A task needs a title.");   // your own error
  return { title };
}
```

**اقرأ رسالة الخطأ:** نوعه (`TypeError`، `ReferenceError`)، ورسالته، والملف والسطر. ثم استخدم لوحة **Sources** في المتصفح: انقر رقم السطر لوضع **breakpoint**، وأعد التحميل، وتقدّم في الكود خطوة بخطوة مراقبًا المتغيرات. وكلمة `debugger;` في كودك تفعل الشيء نفسه.
