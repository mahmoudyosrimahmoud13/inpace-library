# إلى أين بعد ذلك

درس اختياري. اختر طريقًا:

- **الواجهة الأمامية:** تعلّم React أو Vue ثم TypeScript. وفي [react.dev](https://react.dev) دليل مجاني ممتاز.
- **الخلفية:** Node.js مع Express أو Fastify، وقاعدة بيانات، وواجهات REST.
- **التمرين:** [javascript.info](https://javascript.info) (أفضل مرجع مجاني بالتفصيل)، و [MDN Web Docs](https://developer.mozilla.org) (المرجع الرسمي)، ومشاريع شهادة JavaScript على freeCodeCamp.

استمر في بناء أشياء صغيرة: صفحة طقس بواجهة برمجية، ولعبة أسئلة، ومتتبع ميزانية. كل منها سطر في سيرتك.
