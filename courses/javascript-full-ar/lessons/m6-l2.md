> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
const task = { title: "Code", minutes: 40, done: false };
const { title, minutes } = task;          // take keys into variables
const { done: isDone = false } = task;    // rename, with a default
const [first, second] = ["a", "b", "c"];  // from an array

const updated = { ...task, done: true };  // a copy with one change (task is unchanged)

function show({ title, minutes }) {        // destructure parameters
  return `${title} (${minutes} min)`;
}
console.log(title, minutes, isDone, first, show(updated), task.done);
```
