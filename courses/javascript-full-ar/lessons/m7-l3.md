# الوحدات: import و export

قسّم الكود إلى ملفات. كل ملف يصدّر ما يُسمح للآخرين باستخدامه.

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 3:20:25 إلى 3:26:00. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
// math.js
export function add(a, b) { return a + b; }
export const PI = 3.14159;
export default function square(n) { return n * n; }

// main.js
import square, { add, PI } from "./math.js";
console.log(add(2, 3), PI, square(4));
```

- **في المتصفح:** `<script type="module" src="main.js">`، وافتح الصفحة عبر خادم صغير (إضافة Live Server في VS Code)، وليس بالنقر المزدوج على الملف.
- **في Node:** أضف `"type": "module"` إلى `package.json`.
- **حزم npm:** `npm install date-fns` ثم `import { format } from "date-fns";`.
