# JSON

JSON نص يشبه كائنات JavaScript، وهو الطريقة التي ترسل بها التطبيقات البيانات عبر الإنترنت وتحفظها.

```javascript
const tasks = [{ title: "Read", minutes: 25 }];
const text = JSON.stringify(tasks);        // object -> text
console.log(text);                          // [{"title":"Read","minutes":25}]
const back = JSON.parse(text);              // text -> object
console.log(back[0].minutes);               // 25
```

في JSON تُكتب المفاتيح والنصوص بـ **علامات تنصيص مزدوجة**، ولا توجد دوال ولا `undefined` ولا تعليقات. و `JSON.parse` ترمي خطأ مع النص التالف: الوحدة 10 تشرح كيف تلتقطه.
