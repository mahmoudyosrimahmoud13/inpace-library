# ثلاث طرق لتشغيل JavaScript

1. **وحدة التحكم في المتصفح:** اضغط **F12** (أو زر الفأرة الأيمن ← Inspect)، وافتح **Console**، واكتب `2 + 3`. مناسبة للتجارب السريعة.
2. **Node.js في الطرفية:** احفظ ملفًا `hello.js` وشغّله بـ `node hello.js`.
3. **صفحة ويب:** وسم `<script>` داخل ملف HTML.

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Learn JavaScript, Full Course for Beginners* (بو كارنز)، من 0:01:24 إلى 0:05:56. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```javascript
// hello.js
console.log("Hello, world!");   // prints a line
console.log(2 + 3);              // 5
// a comment: JavaScript ignores it
/* a comment
   on several lines */
```

```html
<!-- index.html -->
<!doctype html>
<html>
  <body>
    <h1>My page</h1>
    <script src="hello.js"></script>
  </body>
</html>
```

`console.log` أفضل صديق لك: اطبع القيم لترى ماذا يفعل كودك.
