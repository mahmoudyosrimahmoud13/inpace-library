# Project 5: from search results to a cited answer

You'll put the pieces together: hybrid retrieval, a numbered prompt with a budget, a local model through Ollama, and
citations read back from the answer.

The code is above this text. Save it as `p05_answer.py`, with `llm.py` next to it. Start Ollama and run
`ollama pull qwen2.5:1.5b` first.

## Read the code

- **`llm.py`**: `chat(messages)` posts to Ollama's `/api/chat` with temperature 0 and returns the reply and the token
  counts in and out. `available()` checks Ollama is running. Change the model with the `OLLAMA_MODEL` environment
  variable.
- **`SYSTEM`** holds the four rules from the concept lesson.
- **`Assistant.__init__`** builds everything from projects 2 to 4 once: chunks, BM25, the chunk vectors and the
  summary vectors.
- **`retrieve()`** is project 4's three-way hybrid.
- **`build_prompt()`** numbers the sources, up to 900 characters each, and stops when 3,000 characters are used.
- **`answer()`** retrieves, builds the prompt, calls the model, and reads every `[n]` in the reply back to a document
  id (`cited`).

What it shows:

- **The right document leads to a right answer**: `random.sample` and `shutil.rmtree` were retrieved, and the answers
  use them.
- **No citations, in any answer.** The rule is in the prompt; the small model ignores it. `cited` is empty.
- **The POST question is answered from memory.** None of the five sources is about sending requests (they're all
  about the HTTP *server*), but the model knows `http.client` and writes a full example. It's even right, and it's
  not grounded: nothing in the sources supports it.
- **The out-of-scope question is refused** with the exact sentence. Good.
- A 500 to 800-token prompt takes 15 to 50 seconds on a CPU. The prompt, not the answer, is most of the tokens.

## Make it yours

1. Run with a bigger model (`OLLAMA_MODEL=qwen2.5:7b` or `llama3.1:8b`) if your computer has 16 GB. Count citations
   again.
2. Put the sources **after** the question instead of before. Does the answer change?
3. Change the budget to 1,200 characters. Which questions lose their right source, and does the answer get worse?
4. Add a **relevance threshold**: if the best summary cosine is below a value you choose, skip the model and return
   the refusal directly. Which value refuses the neural network question without refusing real ones?

## What to take away

- RAG's answer step is a prompt: numbered sources, rules, a budget, a fixed refusal.
- Models don't always follow the rules; read what comes back.
- A right answer isn't proof of a grounded one.
