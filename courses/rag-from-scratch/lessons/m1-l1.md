# Start here: what you'll build

In this course you build one app from start to finish: **Ask Python**, an assistant that answers questions about
Python's standard library from its own documentation, and says which documents it used.

You build every part yourself, one project a day:

| Day | You add | You'll know |
|---|---|---|
| 1 | A search engine (BM25) and a test set of 45 questions | How to score a search, and why word matching falls short |
| 2 | Chunking | How cutting documents changes what search finds |
| 3 | Embeddings and a vector index | Search by meaning, and where it fails too |
| 4 | Hybrid search with rank fusion | Why the best systems combine searches |
| 5 | The answer: prompt, local model, citations | How the model uses (and ignores) your sources |
| 6 | Answer evaluation | How to measure answers, not only search |
| 7 | Updates, filters, injection checks, cache, an HTTP API | What changes when real people use it |

The documents are 1,517 real docstrings from Python's standard library (`pydocs.json`, under the PSF License). The
test set (`evalset.json`) has 45 questions written the way people ask, like "Delete a folder together with
everything inside it", each with the document that answers it.

## What you need

- Python 3.10 or newer, and about 2 hours a day.
- Two packages: `pip install numpy model2vec`. The first project only needs Python itself.
- From day 5: **Ollama** (free, runs on your computer, no account). Install it from ollama.com, then run
  `ollama pull qwen2.5:1.5b` once (about 1 GB). Any laptop from the last ten years can run this model; an answer
  takes a few seconds to half a minute without a graphics card. A bigger model, like `qwen2.5:7b`, answers better if
  your computer has 16 GB of memory: set `OLLAMA_MODEL=qwen2.5:7b`.

## Get the code

The project folder is above this text. Save all its files in one folder, `ask-python`, and run each project from
there, like `python p01_bm25.py`. Every output shown in the lessons is real, from running the code. Times will differ
on your computer, and answers from the model will be worded differently.

Start a git repository in that folder today. You'll change the code every day, and the last task asks for a link.
