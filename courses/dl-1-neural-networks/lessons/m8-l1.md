## Which framework in 2026?

- **PyTorch** is the default for research and most new projects, and what most open models are released in.
- **Keras 3** is a high-level API that runs on **TensorFlow, JAX or PyTorch**: change one line (`KERAS_BACKEND`).
- **TensorFlow** 2.21 is stable and mostly receives fixes now; Google recommends Keras 3, JAX or PyTorch for new
  generative-AI work. TF Lite is now called **LiteRT** (running models on phones).
- One practical note: load **one** framework per Python process. PyTorch and TensorFlow can clash in the same one,
  which is why each notebook uses only one.
