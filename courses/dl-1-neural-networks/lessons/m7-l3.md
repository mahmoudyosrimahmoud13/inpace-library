# Building blocks, parameters and hyperparameters

Each layer has a **forward** function (cache `Z`, `A`) and a **backward** function (use the cache, return `dA[l−1]`,
`dW[l]`, `db[l]`). Autograd builds these for you, but knowing them is what lets you debug.

**Parameters** are learned: `W`, `b`. **Hyperparameters** are what you choose: learning rate, number of layers and
units, activations, batch size, epochs, and (part 2) regularization and optimizer settings. Finding good
hyperparameters is empirical: try, measure on the dev set, repeat.

**And the brain?** A neuron in a network is a loose cartoon of a biological neuron. The analogy helped early on; today
it says little about how either really works.
