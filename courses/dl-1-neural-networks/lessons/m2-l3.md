# Gradient descent

Repeat: `w := w − α·∂J/∂w`, `b := b − α·∂J/∂b`. `α` is the learning rate. Because `J` is convex here, gradient
descent reaches the global minimum from any starting point.

> **Interview:** "What happens if α is too big? Too small?" Too big: the cost bounces or blows up. Too small: training
> crawls. Plot the cost every few steps; it should go down smoothly.
