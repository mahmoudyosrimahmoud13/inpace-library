# Gradient descent for logistic regression, on m examples

For one example: forward (`z`, `a`, `L`), backward (`dz`, `dw`, `db`). For `m` examples, average the gradients, then
take one step. The slides first do it with **for-loops** over examples and features. That works, but it's slow;
tomorrow we remove the loops.

```python
# one step, PyTorch doing the backward pass for you
logits = X @ w + b                  # X: (m, n_x), w: (n_x,)
loss = torch.nn.functional.binary_cross_entropy_with_logits(logits, y)
loss.backward()                     # fills w.grad and b.grad: the averaged dw and db
with torch.no_grad():
    w -= lr * w.grad; b -= lr * b.grad
    w.grad = None; b.grad = None
```
