# Neurons, layers and supervised learning

A neural network is a stack of simple functions. Each **neuron** computes a weighted sum of its inputs plus a bias,
then applies a non-linear **activation**: `a = g(w·x + b)`. Stack many of them in **layers** and the network can
represent very complicated mappings from `x` to `y`.

The slides' housing example is the key idea: you don't tell the network that "family size" or "walkability" matter.
You give it inputs and correct answers, and the hidden layer **discovers** useful intermediate features by itself.

## Which kind of network for which data

| Data | Network | Examples |
|---|---|---|
| Tables of numbers | standard (fully connected) | prices, ad clicks, credit risk |
| Images | convolutional (CNN) | photo tagging, medical scans |
| Sequences | recurrent (RNN), and today mostly **transformers** | speech, translation, text |
| Several at once | custom / multimodal | self-driving (camera + radar), image + text models |

**Structured data** (columns with meaning) vs **unstructured data** (pixels, audio, words): deep learning's biggest
jumps came on unstructured data, where hand-made features were weakest.
