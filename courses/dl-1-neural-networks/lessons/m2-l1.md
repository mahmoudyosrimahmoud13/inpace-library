# Binary classification and notation

A 64×64 colour image becomes one long column of `n_x = 64·64·3 = 12,288` numbers. With `m` examples, stack them as
**columns**: `X` has shape `(n_x, m)` and `Y` has shape `(1, m)`.

| Symbol | Means |
|---|---|
| `x(i)`, `y(i)` | the i-th example and its label |
| `m` | number of examples |
| `n_x` | number of input features |
| `W[l]`, `b[l]` | weights and bias of layer `l` |
| `a[l]` | activations (outputs) of layer `l`; `a[0] = x` |

**Heads-up for code:** PyTorch and Keras put one example per **row**: `X` is `(m, n_x)`. The maths is the same, the
matrices are transposed. When shapes don't match, this is usually why.
