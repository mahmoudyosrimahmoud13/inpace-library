# Deep L-layer networks and their dimensions

The same two steps, repeated for `l = 1 … L`:

```text
Z[l] = W[l]·A[l−1] + b[l]
A[l] = g[l](Z[l])
```

Shapes to check, every time: `W[l]` is `(n[l], n[l−1])`, `b[l]` is `(n[l], 1)`, `Z[l]` and `A[l]` are `(n[l], m)`.
In PyTorch a deep network is a list of layers:

```python
model = nn.Sequential(nn.Linear(64, 128), nn.ReLU(), nn.Linear(128, 64), nn.ReLU(), nn.Linear(64, 10))
```
