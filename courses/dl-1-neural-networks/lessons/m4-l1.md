# Vectorization

"Whenever possible, avoid explicit for-loops." One matrix product replaces a loop over all examples:
`Z = wᵀX + b` gives every example's `z` at once. Libraries run it with SIMD instructions on a CPU and thousands of
cores on a GPU. The slide's demo: about **300 times faster** than the loop, for the same result.

The vectorized logistic regression step:

```text
Z  = wᵀX + b        (1, m)
A  = σ(Z)           (1, m)
dZ = A − Y          (1, m)
dw = X·dZᵀ / m      (n_x, 1)
db = mean(dZ)
w := w − α·dw ;  b := b − α·db
```

Only the loop over **training steps** remains.
