# Broadcasting, and the shape bugs it causes

When shapes don't match, NumPy, PyTorch and TensorFlow **stretch** the smaller array where its size is 1:

![Broadcasting](broadcasting.png)

`b` in `wᵀX + b` is broadcast the same way across all `m` columns.

## The rank-1 trap

```python
a = np.random.randn(5)      # shape (5,): neither a row nor a column
a.T @ a                     # a number, not the 5×5 matrix you expected
a = np.random.randn(5, 1)   # say what you mean: a column
assert a.shape == (5, 1)    # cheap insurance
```

Shape bugs don't crash; they silently compute the wrong thing. Write shapes in comments and use `assert`.
