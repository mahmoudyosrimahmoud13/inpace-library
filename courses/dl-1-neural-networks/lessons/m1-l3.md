# Why deep learning took off (and what changed since)

The slide's curve: as you add data, old algorithms flatten out, while bigger networks keep improving. Three drivers:
**data**, **computation** (GPUs), and **algorithms** (for example ReLU instead of sigmoid made training much faster).

## Going further: the 2020s version of that curve

- **Scaling laws:** for language models, loss falls smoothly and predictably as you grow model size, data and compute
  together. That's why models went from millions to hundreds of billions of parameters.
- **Pre-training then adapting:** most real projects now start from a model someone else trained on huge data
  (a foundation model) and adapt it, instead of training from zero. You'll do this in parts 3, 4 and 5.
- The fast iteration loop on the slide (idea → code → experiment) is still the core skill: the faster your loop,
  the faster you learn what works.

> **Interview:** "Why does a bigger network help more when you have more data?" A small model's error is dominated by
> bias (it can't represent the function); more data doesn't fix that. A big model can use the extra data.
