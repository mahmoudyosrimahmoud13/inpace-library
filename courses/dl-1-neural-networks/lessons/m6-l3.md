# Random initialization

If all weights start at zero, every hidden unit computes the same thing and gets the same gradient, forever: the
layer behaves like **one** unit (symmetry). Start with small random weights.

Modern practice: frameworks already initialize sensibly (`nn.Linear` uses Kaiming-uniform; Keras `Dense` uses
Glorot-uniform). For deep ReLU networks, He initialization (`std = √(2/n)`) keeps the signal steady; part 2 shows
why with a chart.
