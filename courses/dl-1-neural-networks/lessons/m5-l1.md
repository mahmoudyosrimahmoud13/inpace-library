# Representation: what each layer computes

A 2-layer network (we don't count the input): the hidden layer has `n_h` units, the output layer one unit.

```text
Z[1] = W[1]·X + b[1]     W[1]: (n_h, n_x)   b[1]: (n_h, 1)
A[1] = tanh(Z[1])
Z[2] = W[2]·A[1] + b[2]  W[2]: (1, n_h)     b[2]: (1, 1)
A[2] = σ(Z[2]) = ŷ
```

Each hidden unit is a logistic-regression-like unit; the output combines them.
