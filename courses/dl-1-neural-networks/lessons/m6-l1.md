# Activation functions

![Activations and their slopes](activations.png)

| Activation | Use it for | Watch out for |
|---|---|---|
| sigmoid | the output of a yes/no classifier | slope ≈ 0 far from 0: slow learning |
| tanh | hidden layers, when you want outputs centred on 0 | same flat tails |
| **ReLU** `max(0, z)` | the default for hidden layers | units that always output 0 ("dead") |
| Leaky ReLU, **GELU**, SiLU | modern alternatives | GELU is the standard in transformers |

**Why non-linear at all?** Without it, layers collapse: `W2·(W1·x)` is just one matrix times `x`. A deep linear
network is a linear model.
