# Derivatives without fear

A derivative is a **slope**: nudge the input a tiny bit, see how much the output moves. For `f(a) = 3a`, the slope is 3
everywhere; for `f(a) = a²`, it's `2a`, different at every point. That's all deep learning needs: how much does the
cost change if I nudge this weight?
