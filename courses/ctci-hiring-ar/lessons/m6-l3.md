# الترتيب والبحث (الفصل 10)

اقرأ مقدمة **الفصل 10، Sorting and searching**. نادرًا ما يُطلب منك كتابة خوارزمية ترتيب من الصفر، لكن يجب أن تعرف كيف
تعمل الخوارزميات الشائعة وكم تكلف، وكثيرًا ما ستعدّل الـ binary search.

## خوارزميات الترتيب التي تعرفها

| الخوارزمية | الوقت (عادةً) | الأسوأ | ذاكرة إضافية | ملاحظة |
|---|---|---|---|---|
| Bubble وselection | O(n²) | O(n²) | O(1) | للشرح فقط |
| Merge sort | O(n log n) | O(n log n) | O(n) | تقسم نصفين، ترتب، تدمج؛ stable |
| Quick sort | O(n log n) | O(n²) | O(log n) | تقسم حول pivot؛ سريعة عمليًا |
| Radix sort | O(k · n) | O(k · n) | O(n) | لأعداد صحيحة من k خانة |
| `sorted` في Python | O(n log n) | O(n log n) | O(n) | Timsort، stable |

**Stable** تعني أن العناصر المتساوية تحتفظ بترتيبها الأصلي. ويهم ذلك حين ترتب بمفتاح ثم بآخر.

الـ merge sort تستحق أن تكتبها من الذاكرة، لأن خطوة الدمج فيها وحدها تحل أسئلة مقابلات كثيرة:

```python
def merge_sort(a):
    if len(a) <= 1:
        return a
    mid = len(a) // 2
    left, right = merge_sort(a[:mid]), merge_sort(a[mid:])
    merged, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:              # <= keeps equal items in order: stable
            merged.append(left[i]); i += 1
        else:
            merged.append(right[j]); j += 1
    return merged + left[i:] + right[j:]

print(merge_sort([38, 27, 43, 3, 9, 82, 10]))
```

```output
[3, 9, 10, 27, 38, 43, 82]
```

## الدمج من الخلف

سؤال شائع: في الـ array المسماة A مساحة فارغة في نهايتها تكفي لـ array مرتبة B؛ ادمج B في A في المكان. الملء من **الأمام**
سيكتب فوق قيم من A ما زلت تحتاجها. والملء من **الخلف** لا يفعل ذلك أبدًا.

```python
def merge_into(a, m, b):
    """a holds m sorted values followed by len(b) empty places."""
    i, j, k = m - 1, len(b) - 1, m + len(b) - 1
    while j >= 0:
        if i >= 0 and a[i] > b[j]:
            a[k] = a[i]; i -= 1
        else:
            a[k] = b[j]; j -= 1
        k -= 1
    return a

print(merge_into([1, 4, 7, 0, 0, 0], 3, [2, 3, 9]))
```

```output
[1, 2, 3, 4, 7, 9]
```

## binary search معدَّل

يعمل الـ binary search حين تستطيع أن تستبعد نصف الخيارات الباقية بفحص واحد. في array مرتبة ثم **مُدوَّرة**
(`[15, 16, 19, 20, 25, 1, 3, 4, 5, 7, 10, 14]`)، يكون أحد النصفين حول المنتصف مرتبًا دائمًا. افحص هل الهدف في ذلك النصف؛
وإن لم يكن، فابحث في الآخر.

```python
def search_rotated(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        if a[lo] <= a[mid]:                       # the left half is in order
            if a[lo] <= target < a[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:                                     # the right half is in order
            if a[mid] < target <= a[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1

a = [15, 16, 19, 20, 25, 1, 3, 4, 5, 7, 10, 14]
print([search_rotated(a, t) for t in [5, 15, 14, 8]])
```

```output
[8, 0, 11, -1]
```

## الترتيب كأداة

الترتيب أولًا كثيرًا ما يجعل المسألة سهلة: تصبح القيم المكررة متجاورة، ويمكن إيجاد الأزواج بمؤشرين، وتشترك الـ anagrams
في شكل مرتب واحد. يكلف O(n log n)، وهذا مقبول غالبًا.

```python
from collections import defaultdict

def group_anagrams(words):
    groups = defaultdict(list)
    for w in words:
        groups["".join(sorted(w))].append(w)      # anagrams have the same sorted letters
    return list(groups.values())

print(group_anagrams(["eat", "tea", "tan", "ate", "nat", "bat"]))
```

```output
[['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]
```
