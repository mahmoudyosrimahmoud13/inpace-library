# قراءة: Big O (الجزء VI)

اقرأ اليوم **الجزء VI**، وحلّ أمثلته وتمارينه بالقلم. Big O هي لغة كل مقابلة تقنية: بعد أن تكتب حلًا، سيسألك المقابِل
تقريبًا دائمًا: "ما الـ time complexity وما الـ space complexity؟".

## ماذا تأخذ من كل قسم

| القسم | الفكرة في سطر |
|---|---|
| *An analogy* و*Time complexity* | Big O تصف كيف **ينمو** العمل مع نمو المدخلات، لا كم ثانية يأخذ. |
| *Space complexity* | الذاكرة تُحسب أيضًا، ومنها الـ call stack للدوال الـ recursive. |
| *Drop the constants* | O(2n) هي O(n): ما يهمنا شكل النمو. |
| *Drop the non-dominant terms* | O(n² + n) هي O(n²): مع n الكبيرة، الحد الأكبر يغلب. |
| *Multi-part algorithms: add vs. multiply* | حلقة بعد حلقة: نجمع (O(a + b)). حلقة داخل حلقة: نضرب (O(a · b)). |
| *Amortized time* | عملية رخيصة عادةً ومكلفة نادرًا (مثل قائمة تكبر) قد تبقى O(1) في المتوسط. |
| *Log N runtimes* | حين تقسم كل خطوة المسألة نصفين (binary search)، يكون العمل O(log n). |
| *Recursive runtimes* | دالة تستدعي نفسها مرتين في كل مستوى، بعمق n، تعمل نحو 2ⁿ. |

## جدول تحتفظ به بجوارك

| Big O | الاسم | كود نموذجي | n = 1,000,000 |
|---|---|---|---|
| O(1) | ثابت | قراءة `a[i]`، البحث عن مفتاح في dictionary | خطوة واحدة |
| O(log n) | لوغاريتمي | binary search | نحو 20 خطوة |
| O(n) | خطي | حلقة واحدة على المدخلات | مليون |
| O(n log n) | linearithmic | ترتيب جيد | نحو 20 مليونًا |
| O(n²) | تربيعي | حلقة داخل حلقة | تريليون: بطيء جدًا |
| O(2ⁿ) | أُسّي | تجربة كل مجموعة جزئية | مستحيل |

قاعدة تقريبية للمقابلات: الكمبيوتر ينفذ نحو 10⁸ خطوة بسيطة في الثانية. فإذا كانت المدخلات قد تصل إلى 100,000 عنصر، فحل
O(n²) (أي 10¹⁰ خطوة) بطيء جدًا، وتحتاج O(n log n) أو أفضل.

## أخطاء شائعة

- **مدخلان مختلفان يحتاجان حرفين.** حلقة على القائمة `a` وبداخلها حلقة على القائمة `b` هي O(a · b)، لا O(n²).
- **حلقات مخفية.** في Python، `x in my_list` و`my_list.index(x)` والتقطيع `s[1:]` و`sorted()` كلها تأخذ وقتًا. و"حلقة
  واحدة" بداخلها `x in my_list` هي O(n²).
- **الـ strings ليست مجانية.** بناء string بـ `s = s + c` داخل حلقة قد ينسخ الـ string كلها في كل مرة.

## الخلاصة

- Big O تقيس النمو: احذف الثوابت والحدود الأصغر.
- اجمع تكاليف الخطوات المتتالية، واضرب تكاليف الخطوات المتداخلة.
- انتبه للحلقات المخفية داخل العمليات الجاهزة.
