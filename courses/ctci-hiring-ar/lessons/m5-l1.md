## الـ hash tables: أنفع أداة عندك

الـ hash table تربط مفاتيح بقيم، والبحث فيها O(1) في المتوسط. في Python هي `dict` (و`set` للمفاتيح وحدها). تعمل بتحويل
كل مفتاح إلى رقم (الـ hash) يحدد أين يُخزَّن.

النمط في المقابلات: **حين تبحث في القائمة نفسها مرارًا، خزّنها في hash table مرة واحدة.**

```python
from collections import Counter

def is_permutation(a, b):
    """Are the two strings rearrangements of each other? O(len(a) + len(b))."""
    return len(a) == len(b) and Counter(a) == Counter(b)

def first_unique_char(s):
    """Index of the first character that appears once, or -1. Two passes, O(n)."""
    counts = Counter(s)
    for i, ch in enumerate(s):
        if counts[ch] == 1:
            return i
    return -1

print(is_permutation("listen", "silent"), is_permutation("apple", "paple"), is_permutation("abc", "abd"))
print(first_unique_char("swiss"), first_unique_char("aabb"))
```

```output
True True False
1 -1
```

## الـ arrays التي يتغير حجمها: لماذا `append` هي O(1)

تحتفظ قائمة Python بمساحة إضافية في نهايتها. حين تمتلئ، تنتقل إلى قطعة ذاكرة أكبر. الانتقال مكلف، لكنه نادر، فتكون تكلفة
`append` بالـ **amortized** هي O(1) (الجزء VI). يمكنك أن تشاهد Python وهي تكبّر القائمة:

```python
import sys

items, last_size, growths = [], sys.getsizeof([]), []
for i in range(64):
    items.append(i)
    size = sys.getsizeof(items)
    if size != last_size:
        growths.append(len(items))
        last_size = size
print("the list grew its memory when it reached these lengths:", growths)
```

```output
the list grew its memory when it reached these lengths: [1, 5, 9, 17, 25, 33, 41, 53]
```

احتاجت 8 فقط من 64 عملية append إلى ذاكرة أكثر، والفجوات بين مرات التكبير تتسع كلما طالت القائمة (تضيف Python نحو ثُمن
الحجم الحالي، مع بضعة أماكن احتياطية، في كل مرة)، فأغلب عمليات الـ append لا تكلف شيئًا إضافيًا. (الأطوال الدقيقة
تعتمد على إصدار Python عندك.)

## بناء الـ strings

الـ strings في Python لا تتغير. `s = s + c` تصنع string جديدة، وقد تنسخ كل ما بُني حتى الآن. اجمع الأجزاء في list ثم
اربطها مرة واحدة بدلًا من ذلك.

```python
def compress(s):
    """'aabcccccaaa' -> 'a2b1c5a3'; return s itself if that isn't shorter."""
    parts, i = [], 0
    while i < len(s):
        j = i
        while j < len(s) and s[j] == s[i]:
            j += 1
        parts.append(s[i] + str(j - i))      # one character and how many times it repeats
        i = j
    out = "".join(parts)                     # one join at the end: O(n)
    return out if len(out) < len(s) else s

print(compress("aabcccccaaa"), compress("abc"))
```

```output
a2b1c5a3 abc
```

## مؤشران والتعديل في المكان

أسئلة كثيرة عن الـ arrays تطلب العمل **في المكان**، بلا array ثانية. ومؤشران (indexes) يتحركان في الـ array هما الحل
غالبًا. مثلًا، تدوير مصفوفة مربعة 90 درجة مع عقارب الساعة: اقلبها حول القطر، ثم اعكس كل صف.

```python
def rotate(matrix):
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]   # transpose
    for row in matrix:
        row.reverse()                                                 # mirror left to right

m = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
rotate(m)
for row in m:
    print(row)
```

```output
[7, 4, 1]
[8, 5, 2]
[9, 6, 3]
```
