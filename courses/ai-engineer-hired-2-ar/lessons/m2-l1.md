# المصفوفات والتجزئة والمؤشران

## القاموس: تذكّر ما رأيته

حين يفحص الحل البدائي كل زوج (O(n²))، اسأل: *هل يمكنني البحث عن الشريك مباشرة بدل التفتيش عنه؟* القاموس أو المجموعة يحوّلان الحلقة الداخلية إلى بحث بتكلفة O(1).

```python
def two_sum(nums, target):
    seen = {}                          # value -> index
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
```

## العدّ والتجميع

يعدّ `Counter`، ويجمّع قاموسٌ من القوائم الأشياءَ بمفتاح تحسبه (للكلمات المتجانسة: الحروف مرتبة). وحين تكون التكرارات محدودة بـ n، يعطيك **الترتيب بالدلاء** (bucket sort) أكبر k في O(n):

```python
from collections import Counter

def top_k_frequent(nums, k):
    buckets = [[] for _ in range(len(nums) + 1)]   # buckets[c] = values seen c times
    for x, c in Counter(nums).items():
        buckets[c].append(x)
    out = []
    for c in range(len(nums), 0, -1):
        out.extend(buckets[c])
        if len(out) >= k:
            return out[:k]
```

## مؤشران على مصفوفة مرتبة

بعد الترتيب يتحرك مؤشر من كل طرف إلى الداخل: إن كان المجموع صغيرًا حرّك الأيسر، وإن كان كبيرًا حرّك الأيمن. وتخطَّ الجيران المتساوين لتتجنب الإجابات المكررة.

```python
def three_sum(nums):
    nums.sort()
    res = []
    for i, a in enumerate(nums):
        if i and a == nums[i - 1]:
            continue                       # same first number: same triples
        lo, hi = i + 1, len(nums) - 1
        while lo < hi:
            s = a + nums[lo] + nums[hi]
            if s < 0:
                lo += 1
            elif s > 0:
                hi -= 1
            else:
                res.append([a, nums[lo], nums[hi]])
                lo += 1
                while lo < hi and nums[lo] == nums[lo - 1]:
                    lo += 1
    return res
```

**البادئة واللاحقة:** «حاصل ضرب الكل عداي» هو حاصل ضرب كل ما على يساري في كل ما على يميني، ويُحسب في مرورين دون قسمة.
