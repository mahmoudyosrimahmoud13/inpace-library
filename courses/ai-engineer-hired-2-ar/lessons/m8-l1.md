# المخططات (Graphs)

قرّر أولًا ما العقد وما الحواف (خلايا الشبكة، أو المقررات، أو الكلمات)، ثم اختر الأداة:

| السؤال | الأداة |
|---|---|
| عدّ المناطق، أو الملء | DFS أو BFS مع مجموعة المزار |
| أقل عدد خطوات بلا أوزان | BFS |
| ترتيب مع متطلبات سابقة، أو اكتشاف دورة في مخطط موجّه | الترتيب الطوبولوجي |
| المكونات المتصلة، أو حافة زائدة تصنع دورة | اتحاد المجموعات (union-find) |
| أرخص مسار بأوزان موجبة | Dijkstra (كومة) |
| ربط الكل بأقل تكلفة | الشجرة الممتدة الصغرى (Prim أو Kruskal) |

```python
from collections import defaultdict, deque
import heapq

def num_islands(grid):
    rows, cols = len(grid), len(grid[0])
    count = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] != "1":
                continue
            count += 1
            q = deque([(r, c)])
            grid[r][c] = "0"                  # mark visited when you enqueue
            while q:
                i, j = q.popleft()
                for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    a, b = i + di, j + dj
                    if 0 <= a < rows and 0 <= b < cols and grid[a][b] == "1":
                        grid[a][b] = "0"
                        q.append((a, b))
    return count


def can_finish(n, prerequisites):          # Kahn's topological sort
    graph, indegree = defaultdict(list), [0] * n
    for course, pre in prerequisites:
        graph[pre].append(course)
        indegree[course] += 1
    q = deque(i for i in range(n) if indegree[i] == 0)
    taken = 0
    while q:
        node = q.popleft()
        taken += 1
        for nxt in graph[node]:
            indegree[nxt] -= 1
            if indegree[nxt] == 0:
                q.append(nxt)
    return taken == n                        # False means there's a cycle
```

```python
def find_redundant(edges):                # union-find
    parent = list(range(len(edges) + 1))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]    # path halving
            x = parent[x]
        return x

    for a, b in edges:
        ra, rb = find(a), find(b)
        if ra == rb:
            return [a, b]                    # already connected: this edge makes a cycle
        parent[ra] = rb


def network_delay(times, n, k):             # Dijkstra
    graph = defaultdict(list)
    for u, v, w in times:
        graph[u].append((v, w))
    dist, heap = {}, [(0, k)]
    while heap:
        d, node = heapq.heappop(heap)
        if node in dist:
            continue                         # already settled with a shorter distance
        dist[node] = d
        for nxt, w in graph[node]:
            if nxt not in dist:
                heapq.heappush(heap, (d + w, nxt))
    return max(dist.values()) if len(dist) == n else -1
```

استخدم BFS بطابور صريح في الشبكات الكبيرة: فقد يتجاوز DFS العودي حد العودية في بايثون. وتكلّف خوارزميات المخططات O(V + E) لـ BFS وDFS، وO(E log V) لـ Dijkstra.
