# الأكوام والفترات والخوارزميات الجشعة

## الأكوام: الأفضل القليل بسرعة

`heapq` كومة صغرى. ولأكبر k عناصر احتفظ بكومة صغرى حجمها k: أصغر الـ k في القمة، جاهز للاستبدال. التكلفة O(n log k). وللكومة الكبرى أدخل الأرقام سالبة.

```python
import heapq

def kth_largest(nums, k):
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)            # drop the smallest; the k largest stay
    return heap[0]


class MedianFinder:                        # two heaps: the low half and the high half
    def __init__(self):
        self.low, self.high = [], []       # low is a max-heap (stored negative)

    def add(self, x):
        heapq.heappush(self.low, -x)
        heapq.heappush(self.high, -heapq.heappop(self.low))
        if len(self.high) > len(self.low):
            heapq.heappush(self.low, -heapq.heappop(self.high))

    def median(self):
        if len(self.low) > len(self.high):
            return -self.low[0]
        return (-self.low[0] + self.high[0]) / 2
```

## الفترات: رتّب بالبداية ثم امسح

تبدأ أغلب مسائل الفترات بـ `intervals.sort()`. ثم يدمج مرورٌ واحد المتداخل (`start <= last_end`)، أو يعدّ ما يجب حذفه (أبقِ التي تنتهي أولًا)، أو يتتبع الغرف المستخدمة (كومة من أوقات الانتهاء).

```python
def merge(intervals):
    intervals.sort(key=lambda iv: iv[0])
    out = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= out[-1][1]:
            out[-1][1] = max(out[-1][1], end)
        else:
            out.append([start, end])
    return out
```

## الجشع: الأفضل محليًا هو الأفضل كليًا

ينجح الجشع حين تستطيع أن تبرهن أن أخذ الخيار الأفضل الآن لا يضر لاحقًا أبدًا («حجة التبديل»). خوارزمية Kadane: مدّد المصفوفة الفرعية الحالية، أو ابدأ من جديد إن كان المجموع حتى الآن يضر فقط. وإن لم تستطع تبرير الاختيار الجشع في جملة واحدة، فاشتبه في البرمجة الديناميكية بدلًا منه.

```python
def max_subarray(nums):
    best = cur = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)              # extend, or start fresh here
        best = max(best, cur)
    return best
```
