# الأشجار وأشجار البادئات

## العمق أولًا: اسأل أبناءك ثم قرّر

أغلب مسائل الأشجار دالة عودية واحدة: عالج العقدة الفارغة، وخذ الإجابات من الشجرتين اليسرى واليمنى، وادمجها. وقرّر **ماذا تُرجع الدالة** قبل كتابتها.

```python
def max_depth(root):
    if not root:
        return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))


def is_valid_bst(node, lo=float("-inf"), hi=float("inf")):
    if not node:
        return True
    if not lo < node.val < hi:
        return False
    return is_valid_bst(node.left, lo, node.val) and is_valid_bst(node.right, node.val, hi)
```

وحين لا تكون الإجابة هي ما تُرجعه (القطر، وأكبر مجموع مسار)، أرجع شيئًا (أفضل مسار نازل واحد) وحدّث شيئًا آخر في متغير خارجي (أفضل مسار يمر بهذه العقدة).

## العرض أولًا: مستوى بعد مستوى

طابور وحلقة `for` على حجم المستوى الحالي:

```python
from collections import deque

def level_order(root):
    if not root:
        return []
    out, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        out.append(level)
    return out
```

## أشجار البادئات (Tries)

تخزّن شجرة البادئات الكلمات حرفًا حرفًا، فتكلف أسئلة البادئة O(طول الكلمة). وهي قلب الإكمال التلقائي، ومسألة Word Search II (البحث عن كلمات كثيرة في شبكة دفعة واحدة).

```python
class Trie:
    def __init__(self):
        self.root = {}

    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node["$"] = True                  # the end of a word

    def search(self, word, prefix=False):
        node = self.root
        for ch in word:
            if ch not in node:
                return False
            node = node[ch]
        return prefix or "$" in node
```
