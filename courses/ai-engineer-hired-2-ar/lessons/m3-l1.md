# النافذة المنزلقة والمكدّس

## النافذة المنزلقة

لأسئلة «أطول أو أقصر جزء **متصل** يحقق X»، احتفظ بنافذة `[start, i]`. كبّرها خطوة خطوة بـ `i`، وحين تخالف القاعدة صغّرها من `start`. يدخل كل موضع ويخرج مرة واحدة: O(n).

```python
def longest_unique(s):
    last = {}                          # char -> last index
    start = best = 0
    for i, ch in enumerate(s):
        if ch in last and last[ch] >= start:
            start = last[ch] + 1           # jump past the repeat
        last[ch] = i
        best = max(best, i - start + 1)
    return best
```

وللنوافذ ثابتة الحجم (مثل التبديلة داخل نص) احتفظ بعدّ حروف النافذة وقارنه بعدّ الهدف وهي تنزلق.

## المكدّس والمكدّس الرتيب

يطابق المكدّسُ الأزواجَ (الأقواس) ويحسب التعابير. و**المكدّس الرتيب** يجيب عن «العنصر الأكبر أو الأصغر التالي» في O(n): احتفظ بالمواضع التي لم تُعرف إجابتها بعد، وكل قيمة جديدة تُخرج كل ما تتفوق عليه.

```python
def daily_temperatures(temps):
    answer = [0] * len(temps)
    stack = []                         # days still waiting for a warmer day
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            j = stack.pop()
            answer[j] = i - j
        stack.append(i)
    return answer
```
