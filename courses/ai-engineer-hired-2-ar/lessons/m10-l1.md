# البرمجة الديناميكية ثنائية البعد والبتات والرياضيات

حين تحتاج الحالة إلى رقمين (موضعين في نصين، أو خلية في شبكة، أو عنصر وسعة متبقية) يصبح الجدول ثنائي البعد. وأطول تتابع مشترك (LCS) قالب أغلب مسائل النصين (Edit Distance وInterleaving String):

```python
def lcs(a, b):
    dp = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]   # dp[i][j]: LCS of a[i:], b[j:]
    for i in range(len(a) - 1, -1, -1):
        for j in range(len(b) - 1, -1, -1):
            if a[i] == b[j]:
                dp[i][j] = 1 + dp[i + 1][j + 1]
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j + 1])
    return dp[0][0]
```

**أشكال حقيبة الظهر (knapsack):** 0/1 (كل عنصر مرة: مرّ على السعة تنازليًا، مثل Partition Equal Subset Sum وTarget Sum)، وغير المحدودة (العناصر قابلة لإعادة الاستخدام: مرّ على السعة تصاعديًا، مثل Coin Change II).

## البتات

| الحيلة | معناها |
|---|---|
| `x & 1` | هل x فردي؟ |
| `x & (x - 1)` | x دون أدنى بت مضبوط |
| `a ^ a == 0` و`a ^ 0 == a` | XOR يلغي الأزواج: الرقم الوحيد = XOR الكل |
| `x >> 1` و`x << 1` | القسمة أو الضرب في 2 |
| `bits[i] = bits[i >> 1] + (i & 1)` | عدّ البتات المضبوطة من 0 إلى n في O(n) |

## المصفوفات والرياضيات

تدوير مصفوفة في مكانها = تبديل الصفوف بالأعمدة ثم عكس كل صف. والترتيب الحلزوني = أربعة حدود تنكمش. والأس السريع = ربّع الأساس ونصّف الأس (O(log n)).
