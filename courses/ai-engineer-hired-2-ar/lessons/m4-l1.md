# البحث الثنائي والقوائم المترابطة

## البحث الثنائي، والبحث الثنائي على الإجابة

يعمل البحث الثنائي على أي شيء **رتيب**: مصفوفة مرتبة، أو سؤال نعم/لا يتغير مرة واحدة («هل تأكل كل الموز بسرعة k؟» لا، لا، ...، نعم، نعم). ابحث عن أول *نعم*:

```python
import math

def min_eating_speed(piles, h):
    lo, hi = 1, max(piles)
    while lo < hi:                     # the answer is in [lo, hi]
        mid = (lo + hi) // 2
        if sum(math.ceil(p / mid) for p in piles) <= h:
            hi = mid                       # mid works: maybe smaller works too
        else:
            lo = mid + 1                   # too slow
    return lo
```

حافظ على شرط ثابت واحد («الإجابة في [lo, hi]») فتنتهي الحلقة عليها بالضبط. وأغلب أخطاء البحث الثنائي حلقة لا تنتهي سببها `lo = mid` مع تقريب `mid` إلى الأسفل: ومع `while lo < hi` استخدم `hi = mid` و`lo = mid + 1`.

## القوائم المترابطة

ثلاث حيل تغطي أغلب المسائل: **رأس وهمي** (dummy head) فلا حالة خاصة للعقدة الأولى، و**العكس** في المكان، و**المؤشر السريع والبطيء** (المنتصف، والدورات، والعنصر رقم k من النهاية).

```python
def reverse(head):
    prev = None
    while head:
        nxt = head.next
        head.next = prev
        prev, head = head, nxt
    return prev


def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:
            return True
    return False
```

**LRU Cache** مسألة محبوبة لأنها تجمع بنيتين: قاموسًا للبحث في O(1)، وقائمة مترابطة مزدوجة (أو `collections.OrderedDict` مع `move_to_end`) لتحديث الأحدث استخدامًا في O(1). وكن مستعدًا لبناء القائمة المترابطة بنفسك إن طُلب منك عدم استخدام OrderedDict.
