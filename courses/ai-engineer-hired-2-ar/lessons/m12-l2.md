# مشروع TinyKV خطوة بخطوة

ابنِ مخزن مفتاح وقيمة صغيرًا على أربعة مستويات، تمامًا كنسخة المقابلة. وضعه على GitHub باسم `tinykv` مع الاختبارات أدناه. المستوى 1 معطى، واكتب المستويات من 2 إلى 4 بنفسك واحدًا تلو الآخر، ولا تنتقل حتى تنجح كل الاختبارات. وقِس وقتك: استهدف 20 دقيقة لكل مستوى.

```python
# tinykv.py: level 1
import time


class TinyKV:
    def __init__(self, clock=time.time, path=None):
        self.clock = clock
        self.path = path
        self.data = {}

    def set(self, key, value, ttl=None):
        self.data[key] = value

    def get(self, key):
        return self.data.get(key)

    def delete(self, key):
        return self.data.pop(key, None) is not None
```

## المستويات

1. **الأساسيات:** `set` و`get` (None إن لم يوجد) و`delete` (True إن كان موجودًا).
2. **الانتهاء والمسح:** `set(key, value, ttl=seconds)`، والمفتاح المنتهي يتصرف كأنه غير موجود. وتُرجع `scan(prefix)` المفاتيح الحية التي تبدأ بتلك البادئة مرتبة. وخذ الوقت من `self.clock` لتتحكم فيه الاختبارات.
3. **المعاملات:** `begin()` و`commit()` و`rollback()`، وهي متداخلة. تلغي `rollback` المعاملة المفتوحة الداخلية فقط، وإن لم توجد معاملة مفتوحة تطلق `RuntimeError`.
4. **الحفظ الدائم:** مع `path` يُضاف كل تغيير نهائي (خارج المعاملات، أو عند الـ commit الخارجي) إلى ملف سجل، و`TinyKV(path=...)` جديد يعيد تشغيله. ولا تُكتب أبدًا التغييرات الملغاة.

```python
# test_tinykv.py
import pytest
from tinykv import TinyKV


class FakeClock:
    def __init__(self):
        self.now = 1000.0

    def __call__(self):
        return self.now


def test_level1_basics():
    kv = TinyKV()
    kv.set("a", 1)
    assert kv.get("a") == 1
    assert kv.get("missing") is None
    assert kv.delete("a") is True
    assert kv.delete("a") is False


def test_level2_ttl_and_scan():
    clock = FakeClock()
    kv = TinyKV(clock=clock)
    kv.set("user:1", "Mona", ttl=10)
    kv.set("user:2", "Omar")
    kv.set("order:9", "tea")
    assert kv.scan("user:") == ["user:1", "user:2"]
    clock.now += 10                       # expires exactly at 10 seconds
    assert kv.get("user:1") is None
    assert kv.scan("user:") == ["user:2"]


def test_level3_nested_transactions():
    kv = TinyKV()
    kv.set("a", 1)
    kv.begin()
    kv.set("a", 2)
    kv.begin()
    kv.delete("a")
    assert kv.get("a") is None
    kv.rollback()                         # undo the inner transaction only
    assert kv.get("a") == 2
    kv.commit()
    assert kv.get("a") == 2
    with pytest.raises(RuntimeError):
        kv.rollback()                     # nothing open


def test_level4_persistence(tmp_path):
    path = tmp_path / "data.log"
    kv = TinyKV(path=path)
    kv.set("a", 1)
    kv.set("b", 2)
    kv.delete("a")
    kv.begin()
    kv.set("c", 3)
    kv.rollback()                         # never written
    again = TinyKV(path=path)
    assert again.get("a") is None
    assert again.get("b") == 2
    assert again.get("c") is None
```

## أسئلة تصميم أجب عنها في ملف README

- المفاتيح المنتهية: هل تحذفها عند القراءة (بكسل) أم في الخلفية؟ وما تكلفة كل منهما؟
- المعاملات: هل تحتفظ بسجل تراجع أم بنسخة من البيانات؟ وأيهما أرخص للمخازن الكبيرة؟
- السجل يكبر إلى الأبد: كيف ستضغطه؟
