# Inspect before you analyze

```python
df.shape        # (rows, columns)
df.info()       # column types and missing values
df.describe()   # min, max, mean... of the number columns
```

![df.info() showing 20,838 rows, column types and no missing values](py_03_info.jpg)

![df.describe() with the summary numbers of every numeric column](py_04_describe.jpg)

Read them like a detective: 20,838 rows, no missing values, dates from 1 January to 31 December, quantity between 1
and 4, average order about 94 EGP. If something looks odd here (a negative price, a date in 1900), stop and find out
why before going further.

Other everyday checks: `df["branch"].value_counts()`, `df["branch"].unique()`, `df.isna().sum()`,
`df.duplicated().sum()`.
