# Make it a table: header, freeze, filter

Three habits for every dataset:

1. **Bold the header** so it's clearly not data.
2. **Freeze the top row** so it stays visible: **View → Freeze Cells → Freeze First Row**
   (**Excel:** View → Freeze Panes → Freeze Top Row).
3. **Turn on filters**: **Data → AutoFilter** (**Excel:** Home → Sort & Filter → Filter, or better, **Ctrl + T** to
   make an Excel *Table*, which also grows automatically and gives you named columns).

![Header in yellow, top row frozen, filter arrows on every column](calc_02_table.jpg)

Now the little arrows in the header let you show only some rows: try showing only `Zamalek`, then only `Pastry`.
The status bar at the bottom shows the **Sum** and **Average** of selected cells: a quick way to check a number.
