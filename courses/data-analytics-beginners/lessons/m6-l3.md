# DAX measures

A **measure** is a calculation that respects whatever filters are on (a branch slicer, a month on the axis). Write
them instead of summing columns by dragging. **Home → New measure**:

```text
Total Sales = SUM ( coffee_sales_2025[sales] )
Orders = COUNTROWS ( coffee_sales_2025 )
Average Order = DIVIDE ( [Total Sales], [Orders] )
Coffee Sales = CALCULATE ( [Total Sales], coffee_sales_2025[category] = "Coffee" )
Coffee Share = DIVIDE ( [Coffee Sales], [Total Sales] )
Months = DISTINCTCOUNT ( 'Date'[Month] )
Monthly Target = SUM ( branch_targets[monthly_target_egp] ) * [Months]
vs Target % = DIVIDE ( [Total Sales] - [Monthly Target], [Monthly Target] )
Sales MTD = TOTALMTD ( [Total Sales], 'Date'[Date] )
```

## The one idea that makes DAX click: filter context

A measure is calculated **for each cell of a visual**, with that cell's filters. In a table with branches on rows,
`[Total Sales]` in the Maadi row only sees Maadi orders. `CALCULATE` changes the filters: `Coffee Sales` adds
"category = Coffee" on top of whatever is already there.

- Use `DIVIDE` instead of `/` (it handles dividing by zero).
- Format each measure (currency, %, decimals) in the measure tools.
- Keep measures in one place (a display folder or an empty "Measures" table).
