# groupby: the pivot table of pandas

```python
by_branch = (df.groupby("branch")
               .agg(sales=("sales", "sum"), orders=("order_id", "count"), avg_order=("sales", "mean"))
               .sort_values("sales", ascending=False))
by_branch.round(1)
```

![Sales, orders and average order per branch with groupby and agg](py_07_groupby.jpg)

Read it as: **split** the rows by branch, **apply** sum/count/mean to each group, **combine** the results into one
table. Same numbers as your SUMIFS sheet: check they match. That's how you test your own work.

More you'll use all the time:

```python
df.groupby(["branch", "category"])["sales"].sum().unstack()      # like a pivot table
df.pivot_table(index="branch", columns="category", values="sales", aggfunc="sum")
df[df["branch"] == "Maadi"]                                      # filter rows
df[(df["category"] == "Coffee") & (df["date"].dt.month == 7)]    # two conditions
```
