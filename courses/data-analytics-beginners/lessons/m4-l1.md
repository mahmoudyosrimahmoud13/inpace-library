# Spot the mess

> **About the screenshots:** the spreadsheet pictures show **LibreOffice Calc**, a free program that works like Excel
> (same formulas, same ideas). Where a button or menu has a different name in Excel, it's written next to the step
> as **Excel:**. Everything here works in Excel, Google Sheets and Calc.

Open `coffee_sales_messy.csv`. It's the first 1,500 orders, but typed by tired people:

![A messy branch name with extra spaces and lower case](calc_11_messy.jpg)

| Problem | Example | Why it hurts |
|---|---|---|
| Extra spaces | `  maadi ` | `Maadi` and `  maadi ` count as two branches |
| Mixed case | `MAADI`, `maadi` | same |
| Two date styles | `2025-01-03` and `03/01/2025` | sorting and grouping by month break |
| Blanks | empty `payment` | counts and percentages are off |
| Duplicates | the same order twice | sales are counted twice |

Before you clean: **keep the original** (save a copy), and **count** each problem so you can say what you fixed.
A filter on the branch column shows all the spellings at once.
