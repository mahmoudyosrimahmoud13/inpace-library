# Open the data and look around

> **About the screenshots:** the spreadsheet pictures show **LibreOffice Calc**, a free program that works like Excel
> (same formulas, same ideas). Where a button or menu has a different name in Excel, it's written next to the step
> as **Excel:**. Everything here works in Excel, Google Sheets and Calc.

## Open the CSV

- **Excel:** File → Open → pick `coffee_sales_2025.csv`. (Or Data → From Text/CSV for more control.)
- **Calc:** File → Open; a window asks how to split the columns: choose **Comma** and press OK.

![The coffee sales file opened in LibreOffice Calc](calc_01_open.jpg)

## Moving fast

| Do this | Keys |
|---|---|
| Jump to the last row of data | Ctrl + ↓ |
| Jump to the first cell | Ctrl + Home |
| Select the whole column | Ctrl + Space |
| Select to the end of the data | Ctrl + Shift + ↓ |
| Undo | Ctrl + Z |

Check the size: Ctrl + ↓ in column A takes you to row 20,839 (20,838 orders plus the header row).
