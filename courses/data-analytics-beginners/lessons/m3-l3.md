# Looking things up: VLOOKUP and XLOOKUP

The targets are in another table. Bring each branch's target next to its sales:

```text
E10  =VLOOKUP(A10, Targets!$A$2:$B$5, 2, FALSE)
```

`VLOOKUP(what to find, where, which column to return, FALSE = exact match)`.

![VLOOKUP bringing each branch's monthly target from the Targets sheet](calc_06_vlookup.jpg)

In newer Excel, use **XLOOKUP**, which is easier and safer:

```text
=XLOOKUP(A10, Targets!A2:A5, Targets!B2:B5, "not found")
```

It can look left, doesn't break when you insert columns, and lets you say what to show when nothing matches.
`INDEX` + `MATCH` does the same in older versions (and in Calc before 24.8).

**Always use exact match** (`FALSE` or XLOOKUP's default). Approximate match on unsorted data returns wrong answers
without any error.
