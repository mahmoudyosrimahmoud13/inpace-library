# Set up Jupyter and load the data

**Jupyter** runs Python in a notebook: code, results and charts together. Install **Anaconda** (it includes Jupyter,
pandas and matplotlib), open **JupyterLab**, and create a notebook in the folder with the CSV files. (Or VS Code with
the Python and Jupyter extensions.)

![JupyterLab with the coffee analysis notebook open](py_01_jupyterlab.jpg)

Run a cell with **Shift + Enter**.

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("coffee_sales_2025.csv", parse_dates=["date"])
df.head()
```

![pandas read_csv and the first five rows](py_02_read_head.jpg)

`parse_dates` makes `date` a real date, so you can group by month later. A pandas **DataFrame** is a table: like a
sheet, but you work on whole columns at once.
