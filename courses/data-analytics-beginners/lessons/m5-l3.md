# Highlighting with conditional formatting

Make the important cells jump out: select the Status column, then **Format → Conditional → Condition**
(**Excel:** Home → Conditional Formatting → Highlight Cells Rules → Text that Contains).

![Below target in red, On target in green, and a bar chart of sales by branch](calc_08_cond_chart.jpg)

Other useful rules: **color scales** on numbers (green to red), **data bars** inside cells, and "top 10 items". Use
colour for meaning only, and keep it consistent: red is always bad, green always good.

## A one-page dashboard in a spreadsheet

Put the four headline numbers at the top (total sales, orders, average order, branches on target), then the monthly
line and the branch bars, then the pivot table. That's a real dashboard many small companies run on.
