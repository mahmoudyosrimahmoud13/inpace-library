## Joining the targets (like VLOOKUP)

```python
targets = pd.read_csv("branch_targets.csv")
report = by_branch.reset_index().merge(targets, on="branch")
report["monthly_avg"] = report["sales"] / 12
report["status"] = report.apply(lambda r: "On target" if r.monthly_avg >= r.monthly_target_egp else "Below target", axis=1)
report.to_excel("branch_report.xlsx", index=False)
```

![merge bringing in targets and a status column per branch](py_10_targets_merge.jpg)

`merge` is VLOOKUP for whole tables (and SQL's JOIN). `to_excel` hands the result to people who live in Excel. The
finished notebook is in the course files: `coffee_analysis.ipynb`.
