# Power BI in one picture, and getting the data in

Power BI Desktop is Microsoft's free tool for building interactive reports. (This week has no screenshots: Power BI
runs only on Windows. Follow along in Power BI Desktop, or in Power BI on the web with a work or school account.)

```mermaid
flowchart LR
    A[CSV / Excel / database] --> B[Power Query: clean]
    B --> C[Model: tables + relationships]
    C --> D[DAX measures]
    D --> E[Report: visuals and slicers]
    E --> F[Publish and share]
```

## Get the data

1. **Home → Get data → Text/CSV** → `coffee_sales_2025.csv` → **Transform Data** (not Load: always look first).
2. Do the same for `branch_targets.csv`.

## In Power Query

- Check every column's **type** (the icon left of the name): `date` must be Date, `sales` Whole number.
- **Home → Remove rows / Keep rows**, **Transform → Format → Trim / Capitalize Each Word**, **Remove duplicates**:
  the same cleaning as last week, but **recorded** in *Applied steps* on the right, replayed every refresh.
- **Close & Apply**.

For the messy file, the steps are: Trim and Capitalize Each Word on branch; Replace empty payment with `Unknown`;
change the date type **Using Locale** (English (United Kingdom) for dd/mm/yyyy); Remove duplicates on all columns.
