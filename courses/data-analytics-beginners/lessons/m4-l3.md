# Duplicates, blanks and dates

## Find duplicates first, then remove them

Mark them so you can see what you're deleting:

```text
K2  =IF(COUNTIF($A$2:$A$1531, A2)>1, "duplicate", "")
```

![COUNTIF marking order ids that appear more than once](calc_13_duplicates.jpg)

Then remove them:

- **Excel:** Data → **Remove Duplicates** (choose the columns that define a duplicate).
- **Calc:** Data → More Filters → Standard Filter → Options → **No duplications**, copy the result elsewhere.

## Blanks

Decide, don't delete by habit: fill with `Unknown` when the row is still useful (payment is unknown but the sale is
real), delete only rows that are useless.

## Dates written two ways

Filter the date column for cells that aren't real dates (they're aligned left, as text). Fix them with
`=DATE(RIGHT(B2,4), MID(B2,4,2), LEFT(B2,2))` for `dd/mm/yyyy` text, or with Text to Columns.

## When cleaning repeats every month

Use **Power Query** (in Excel: Data → Get & Transform; it's the same engine as in Power BI, week 3). It records your
cleaning steps and replays them on next month's file with one click.
