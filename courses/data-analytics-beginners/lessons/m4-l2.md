# TRIM, PROPER and friends

Add a helper column next to the data:

```text
J2  =PROPER(TRIM(C2))
```

`TRIM` removes extra spaces, `PROPER` makes "Each Word Capitalized" (`UPPER` and `LOWER` also exist). Fill it down.

![PROPER(TRIM()) turning '  maadi ' into 'Maadi'](calc_12_trim_proper.jpg)

Then copy the clean column and **Paste Special → Values only** over the original (**Excel:** Ctrl+Alt+V → Values),
and delete the helper. Other useful cleaners:

| Formula | Does |
|---|---|
| `SUBSTITUTE(A2, "-", "")` | replace text inside a cell |
| `VALUE(A2)` | turn "123" text into a number |
| `DATEVALUE(A2)` | turn a date written as text into a real date |
| `LEFT`, `RIGHT`, `MID`, `LEN` | cut text apart |

Excel also has **Data → Text to Columns** and **Flash Fill** (Ctrl+E), which copies a pattern you type once.
