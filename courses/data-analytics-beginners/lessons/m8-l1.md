# Your portfolio project

Employers hire analysts who can **show** work. Turn this course into a project:

1. **A question**: "Which branch should get the next marketing budget, and what should it promote?"
2. **The analysis** in one tool you like (Excel, Power BI or Python), with the cleaning steps.
3. **Three findings**, each with a number and a chart. Example structure:
   - *Summer drives the year:* July and August sales are about 65% above January; part of that is the 10% price rise in July, the rest is more orders.
   - *Zamalek sells the most but misses its target:* it averages 48,720 EGP a month against 50,000.
   - *Members spend more per order?* (check it yourself: the answer may surprise you).
4. **A recommendation** and its **risk** ("if we're wrong, we lose...").
5. **One page**: a dashboard screenshot plus five sentences. Put it on GitHub or LinkedIn with the files.

Being honest about limits (made-up data, one year, no costs so no profit) makes you look *more* senior, not less.
