# ثبّت Git وجهّزه

- **ويندوز:** ثبّت [Git for Windows](https://git-scm.com/download/win) واترك الاختيارات الافتراضية. ويعطيك أيضًا **Git Bash**، وهي طرفية تعمل فيها كل أوامر هذه الدورة.
- **ماك:** افتح Terminal واكتب `git --version`. إن لم يكن Git موجودًا، يعرض عليك الماك تثبيته.
- **لينكس:** `sudo apt install git` (أوبونتو وديبيان) أو `sudo dnf install git` (فيدورا).

تأكّد أنه يعمل:

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Git and GitHub for Beginners, Crash Course*، من 11:32 إلى 13:30. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```bash
git --version          # git version 2.4x.x
```

## عرّف Git بنفسك

كل commit يسجّل اسمًا وبريدًا. اضبطهما مرة واحدة لجهازك (`--global`):

```bash
git config --global user.name "Mona Hassan"
git config --global user.email "mona@example.com"
git config --global init.defaultBranch main     # new projects start on a branch called main
git config --global core.editor "code --wait"   # VS Code opens for long messages (optional)
git config --global pull.rebase true            # module 5 explains this one

git config --list --show-origin                  # see every setting and which file it comes from
```

استخدم نفس البريد الذي في حسابك على GitHub، كي يربط GitHub الـ commits بك. وإن أردت إخفاء بريدك، يعطيك GitHub عنوانًا مثل `...@users.noreply.github.com` في **Settings ← Emails**.

## الحصول على المساعدة

`git help commit` يفتح الدليل الكامل لأمر ما، و `git commit -h` يطبع ملخصًا قصيرًا. الأدلة طويلة لكنها دقيقة، والخبراء يقرؤونها طوال الوقت.
