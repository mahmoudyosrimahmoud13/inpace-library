# أول مستودع لك

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Git and GitHub for Beginners, Crash Course*، من 17:30 إلى 20:20. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```bash
mkdir notes && cd notes      # a new folder, and go into it
git init                     # make it a Git repository
echo "# My notes" > README.md  # a first file
git status                   # README.md is "untracked": Git sees it but does not track it yet
git add README.md            # put it in the staging area
git commit -m "Add README"   # save a snapshot with a message
git log --oneline            # the history: one line per commit
```

`git init` أنشأ مجلدًا مخفيًا اسمه `.git`. **هذا المجلد هو المستودع**: فيه كل التاريخ. احذفه فيعود المجلد مجلدًا عاديًا (بالملفات كما هي الآن، وبلا تاريخ). ولا تعدّل شيئًا داخله بيدك أبدًا.

## الدورة اليومية

1. عدّل الملفات.
2. `git status` لترى ما تغيّر.
3. `git add <files>` لتختار ما يدخل.
4. `git commit -m "لماذا"` لتحفظ.

كرّر هذا مرات كثيرة في اليوم. والـ commits الصغيرة أفضل من الكبيرة، وستعرف لماذا في الوحدة 2.

## ماذا يخبرك `git status`

| يقول | المعنى | الخطوة التالية |
|---|---|---|
| Untracked files | ملفات جديدة لا يتتبعها Git بعد | أضفها بـ `git add` |
| Changes not staged for commit | ملفات متتبَّعة غيّرتها | أضفها بـ `git add` |
| Changes to be committed | مجهَّزة وجاهزة | `git commit` |
| nothing to commit, working tree clean | كل شيء محفوظ | تابع العمل |

`git status -s` يعطي نسخة قصيرة: `??` غير متتبَّع، و `M` معدَّل، و `A` مضاف. والعمود الأيسر لمنطقة التجهيز، والأيمن لمجلد العمل.
