# التجهيز ورؤية التغييرات

```bash
git diff                  # changes in your files that are NOT staged yet
git diff --staged         # changes that ARE staged (what the next commit will save)
git add -p                # go through each change and choose: y (yes), n (no), s (split), q (quit)
git add .                 # stage everything in this folder (check git status first!)
git restore --staged a.txt   # take a.txt out of the staging area (your edits stay)
git rm old.txt            # delete a file and stage the deletion
git mv a.txt b.txt        # rename, staged
```

**`git add -p` قدرة خارقة.** غيّرت شيئين لا علاقة بينهما في ملف واحد؟ جهّز أحدهما واحفظ، ثم جهّز الآخر واحفظ مرة أخرى. فيبقى كل commit عن شيء واحد.

## قراءة الـ diff

الأسطر التي تبدأ بـ `-` حُذفت، والتي تبدأ بـ `+` أُضيفت. وسطر مثل `@@ -3,4 +3,5 @@` يقول أين: من السطر 3، و4 أسطر قبل التغيير، و5 بعده. و `git diff --word-diff` يعرض الكلمات المتغيرة بدل الأسطر كاملة، وهذا يفيد مع النصوص.
