# الـ reflog: شبكة الأمان في Git

شغّلت `git reset --hard` وضاعت commits؟ إنها لم تختفِ. يسجّل Git كل مكان كان فيه HEAD، لنحو 90 يومًا، في الـ **reflog**:

```bash
git reflog
# 3f2e1d0 HEAD@{0}: reset: moving to HEAD~2
# 9c8b7a6 HEAD@{1}: commit: Add tests
# 5d4c3b2 HEAD@{2}: commit: Add login form

git reset --hard 9c8b7a6        # go back to where you were
# or keep both: put a branch on the lost commit
git branch rescue 9c8b7a6
```

الـ reflog محلي: موجود على جهازك فقط، ولا يعرف إلا ما حُفظ في commits. أما العمل غير المحفوظ الذي رميته بـ `git restore` أو `reset --hard` فليس فيه. **احفظ كثيرًا**: الـ commit يمكن إنقاذه في كل الحالات تقريبًا.
