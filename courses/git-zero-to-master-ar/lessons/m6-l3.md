# التعارضات أثناء rebase

يعيد rebase تطبيق الـ commits واحدًا تلو الآخر، فقد يتوقف عند commit فيه تعارض. حلّه كتعارض الدمج، ثم:

```bash
git add page.html
git rebase --continue     # go on to the next commit (NOT git commit)
git rebase --skip         # leave this commit out
git rebase --abort        # stop, everything back as before the rebase
```

**انتبه:** أثناء rebase، يكون "ours" هو الفرع الذي تعيد الترتيب **فوقه** (main)، و "theirs" هو الـ commit **الخاص بك**. وهذا عكس الدمج. وإن ساء rebase بعد انتهائه، فإن `git reset --hard ORIG_HEAD` يعيدك إلى ما قبله، والـ reflog يحفظه أيضًا.
