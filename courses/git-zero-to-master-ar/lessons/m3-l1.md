# تراجَع قبل الحفظ

```bash
git restore page.html            # throw away your edits to page.html (back to the last commit). No way back!
git restore --staged page.html   # unstage it, keep your edits
git restore --source=HEAD~3 page.html   # the file as it was 3 commits ago
git clean -n                     # list untracked files that would be deleted (dry run)
git clean -fd                    # really delete untracked files and folders
```

`git restore` و `git clean -f` يرميان العمل نهائيًا، لأنه لم يُحفظ أبدًا. اقرأ `git status` أولًا، واستخدم `git clean -n` قبل `-f`.

الشروحات القديمة تستخدم `git checkout -- file` للشيء نفسه. لكن `git restore` و `git switch` (الوحدة 4) حلّا محل وظائف `checkout` الكثيرة منذ 2019، وهما أوضح.
