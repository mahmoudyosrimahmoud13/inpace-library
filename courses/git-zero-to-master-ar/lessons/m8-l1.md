# stash: ضع العمل جانبًا

في منتصف عمل وتحتاج أن تنتقل لفرع آخر لإصلاح عاجل؟ ضعه في الـ stash:

```bash
git stash push -m "half of the dark mode"   # put your changes aside; your folder is clean again
git stash push -u -m "with new files"        # -u also takes untracked files
git stash list                               # stash@{0}: On main: half of the dark mode
git stash pop                                # bring the newest back and remove it from the list
git stash apply stash@{1}                    # bring one back, keep it in the list
git stash show -p stash@{0}                  # what is inside
git stash branch dark-mode stash@{0}          # a new branch with that work
git stash drop stash@{0}
```

من السهل نسيان الـ stash. لأي شيء أطول من انتقال سريع، فإن commit على فرع (`git commit -m "wip"` ثم تصلحه لاحقًا بـ rebase) أكثر أمانًا. و `git worktree` (أدناه) يغنيك عن الانتقال أصلًا.
