# worktrees و submodules والملفات الكبيرة

## الـ worktrees: فرعان مفتوحان معًا

الـ **worktree** مجلد ثانٍ مرتبط بنفس المستودع، وعليه فرع آخر. راجع طلب دمج أو أصلح خطأ دون أن تلمس عملك غير المكتمل.

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Advanced Git Tutorial* (مع Tower)، من 18:42 إلى 29:30. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```bash
git worktree add ../hotfix main        # a folder ../hotfix with main in it
cd ../hotfix   # ... fix, commit, push ...
git worktree list
git worktree remove ../hotfix
```

الفرع يُفتح في مجلد واحد فقط في كل مرة: إن كنت على main هنا، يرفض Git فتح main في worktree. ولهذا تفعلها من فرع ميزتك.

## الـ submodules: مستودع داخل مستودع

الـ submodule يثبّت مستودعًا آخر عند commit محدد داخل مستودعك (مكتبة مشتركة، أو قالب).

```bash
git submodule add git@github.com:mona/theme.git themes/mine
git clone --recurse-submodules git@github.com:mona/site.git   # clone with them
git submodule update --init --recursive                       # after a normal clone
git submodule update --remote                                 # move to their newest commit
```

الـ submodules تربك الناس (فهي مثبَّتة، فلا تتحدث وحدها). استخدمها فقط عند الضرورة، فمدير الحزم (npm و pip) أبسط غالبًا.

## الملفات الكبيرة: Git LFS

يحتفظ Git بكل نسخة من كل ملف، فـ 500 ميجابايت من الفيديو تغيّرت 10 مرات تصبح 5 جيجابايت للأبد. و **Git LFS** يحفظ الملفات الكبيرة خارج التاريخ ويضع مؤشرًا صغيرًا بدلًا منها:

```bash
git lfs install
git lfs track "*.mp4"      # writes a line in .gitattributes
git add .gitattributes video.mp4
git commit -m "Add intro video"
```
