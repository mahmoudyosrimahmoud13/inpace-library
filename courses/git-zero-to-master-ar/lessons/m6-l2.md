# rebase التفاعلي: عدّل تاريخك

قبل أن تفتح طلب دمج، رتّب commits الخاصة بك: اجمع الإصلاحات الصغيرة، وأصلح الرسائل، وغيّر الترتيب، واحذف التجارب.

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Advanced Git Tutorial* (مع Tower)، من 1:23 إلى 8:54. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```bash
git rebase -i HEAD~4      # the last 4 commits open in your editor, OLDEST FIRST
```

```text
pick 1a2b3c4 Add login form
pick 5d6e7f8 Fix typo
pick 9a8b7c6 Add validation
pick 3c4d5e6 wip
```

غيّر الكلمة في بداية كل سطر، ثم احفظ وأغلق:

| الكلمة | تفعل |
|---|---|
| `pick` | تحتفظ بالـ commit |
| `reword` | تحتفظ به وتعدّل الرسالة |
| `squash` | تدمجه في الذي فوقه وتعدّل الرسالة المدموجة |
| `fixup` | تدمجه في الذي فوقه وتحتفظ برسالة الذي فوقه |
| `drop` | تحذف الـ commit |
| `edit` | تتوقف عنده كي تغيّره (ثم `git commit --amend` و `git rebase --continue`) |

ونقل الأسطر يغيّر الترتيب. هنا يترك `fixup` على *Fix typo* و `drop` على *wip* commit-ين نظيفين.

## إصلاحات بسهولة

عملت إصلاحًا لـ commit أقدم؟ علّمه عند الحفظ، ودع Git يضعه في مكانه:

```bash
git commit --fixup=1a2b3c4          # message: "fixup! Add login form"
git rebase -i --autosquash main     # the fixup moves under its commit by itself
git config --global rebase.autoSquash true   # always do that
```
