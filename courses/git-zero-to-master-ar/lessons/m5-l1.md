# اتصل بـ GitHub بمفتاح SSH

لا يقبل GitHub كلمة مرورك مع Git. استخدم **مفتاح SSH**: زوج من الملفات على جهازك، واحد خاص (لا تشاركه أبدًا) وواحد عام (تعطيه لـ GitHub). جهّزه مرة واحدة:

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Git and GitHub for Beginners, Crash Course*، من 20:30 إلى 30:21. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```bash
ssh-keygen -t ed25519 -C "mona@example.com"   # press Enter to accept the place; a passphrase is a good idea
cat ~/.ssh/id_ed25519.pub                      # the PUBLIC key: copy all of it
# GitHub: Settings -> SSH and GPG keys -> New SSH key -> paste
ssh -T git@github.com                          # "Hi mona! You've successfully authenticated"
```

ثم استخدم **عناوين SSH** لمستودعاتك، وهي التي تبدأ بـ `git@github.com:` وليس `https://`:

```bash
git clone git@github.com:mona/notes.git
git remote set-url origin git@github.com:mona/notes.git   # switch an existing repo from https
```
