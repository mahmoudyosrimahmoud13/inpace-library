# المراجع و HEAD و detached HEAD

الـ **ref** (المرجع) اسم لـ hash commit، ويُحفظ كملف صغير:

```bash
cat .git/HEAD                    # ref: refs/heads/main  (HEAD points to a branch)
cat .git/refs/heads/main         # 9c8b7a6...  (the branch points to a commit)
git rev-parse main               # the same, the proper way (refs can also live in .git/packed-refs)
git show-ref                      # every branch, remote branch and tag
```

إذن الفرع حقًا ملف حجمه 41 بايت، والـ commit يحرّكه بإعادة كتابة هذا الملف.

## Detached HEAD

إن انتقلت إلى commit (أو وسم) بدلًا من فرع، يشير HEAD مباشرة إلى commit:

```bash
git switch --detach v1.2.0       # look around an old version
# You are in 'detached HEAD' state...
```

النظر لا بأس به. لكن الـ commits التي تعملها هنا لا تنتمي لأي فرع: إن انتقلت بعيدًا تبقى في الـ reflog فقط. ولتحتفظ بها، أنشئ فرعًا **قبل** أن تغادر: `git switch -c try-old-idea`.
