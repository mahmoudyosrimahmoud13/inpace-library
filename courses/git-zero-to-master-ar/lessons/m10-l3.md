# الـ commits الموقَّعة

أي شخص يستطيع ضبط `user.name` على اسمك. أما **التوقيع** فيثبت أن الـ commit جاء منك حقًا، ويعرضه GitHub بعلامة **Verified**. وأبسط طريقة تستخدم مفتاح SSH الذي لديك:

```bash
git config --global gpg.format ssh
git config --global user.signingkey ~/.ssh/id_ed25519.pub
git config --global commit.gpgsign true
git config --global tag.gpgsign true
# GitHub: Settings -> SSH and GPG keys -> New SSH key -> Key type: Signing Key -> paste the same .pub
git log --show-signature -1
```

كثير من الشركات والمشاريع مفتوحة المصدر تشترط commits موقَّعة على main (قاعدة حماية فرع ستضبطها في دورة GitHub).
