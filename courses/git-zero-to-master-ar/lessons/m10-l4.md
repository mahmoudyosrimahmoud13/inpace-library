# إلى أين بعد ذلك

درس اختياري.

- **الدورة التالية:** *دورة GitHub: طلبات الدمج وسطر الأوامر و Actions*: المراجعات، والأمر `gh`، والاختبارات والإصدارات الآلية.
- **الكتاب:** [Pro Git](https://git-scm.com/book) مجاني وكامل (بالإنجليزية). والفصل 10 (Git Internals) أعمق من الوحدة 9.
- **التمرين:** [Learn Git Branching](https://learngitbranching.js.org) لعبة بمستويات للـ rebase و cherry-pick وغيرها، في المتصفح مباشرة.
- **الحياة الحقيقية:** ساهم في مشروع مفتوح المصدر تستخدمه. لا شيء يعلّم Git مثل مراجعة حقيقية.
