# عندما يُرفض الـ push

أشهر خطأ في Git:

```text
! [rejected]        main -> main (fetch first)
error: failed to push some refs to 'github.com:mona/notes.git'
hint: Updates were rejected because the remote contains work that you do not have locally.
```

شخص ما (أو أنت من جهاز آخر، أو بوت) رفع commits ليست عندك. فيرفض GitHub كي لا يضيع شيء. احصل على عملهم أولًا، ثم ارفع:

```bash
git pull --rebase            # put your new commits on top of theirs (a straight line, no merge commit)
git push

git pull --rebase --autostash   # same, when you also have changes that aren't committed yet: Git puts them
                                # aside, pulls, then puts them back
```

ومع `git config --global pull.rebase true` (الوحدة 1) يعمل `git pull` العادي rebase تلقائيًا.

## الرفع بالقوة

بعد أن تعيد كتابة commits كنت رفعتها (على فرعك أنت)، يُرفض الـ push العادي. استخدم `git push --force-with-lease`: يكتب فوق فرع GitHub **فقط إن لم يرفع أحد غيرك شيئًا منذ آخر fetch**. لا تستخدم `--force` وحده أبدًا، ولا ترفع بالقوة إلى `main` في مستودع مشترك.
