# cherry-pick: انسخ commit واحدًا

`git cherry-pick` ينسخ commit من فرع آخر إلى فرعك، كـ commit جديد. والاستخدام المعتاد: إصلاح خطأ تم على main وتحتاجه أيضًا على فرع إصدار.

> **فيديو اختياري في الأعلى.** جزء من كورس freeCodeCamp *Advanced Git Tutorial* (مع Tower)، من 8:54 إلى 12:10. كل ما تحتاجه موجود في النص أدناه، فشاهده فقط إن كان يفيدك: يحفظ inPace المكان الذي توقفت عنده.
>
> الفيديو بالإنجليزية: إن أردت مشاهدته فشغّل الترجمة (**CC**)، ثم **الإعدادات ← الترجمة ← ترجمة تلقائية ← العربية**.

```bash
git switch release-1.2
git cherry-pick 9c8b7a6          # copy that commit here
git cherry-pick -x 9c8b7a6       # also write "cherry picked from ..." in the message
git cherry-pick a1b2c3d..9c8b7a6 # a range (everything after a1b2c3d, up to 9c8b7a6)
git cherry-pick --continue / --abort   # after a conflict, like a rebase
```

حفظت على الفرع الخطأ؟ انسخ الـ commit بـ cherry-pick إلى الفرع الصحيح، ثم أزله من الخطأ بـ `git reset --hard HEAD~1` (إن لم يكن مرفوعًا).
