# جهّز Git كالمحترفين

```bash
git config --global alias.st "status -sb"
git config --global alias.lg "log --oneline --graph --all --decorate"
git config --global alias.undo "reset --soft HEAD~1"
git config --global push.autoSetupRemote true   # first push of a branch needs no -u
git config --global fetch.prune true             # forget remote branches deleted on GitHub
git config --global rerere.enabled true
git config --global merge.conflictStyle zdiff3
git config --global diff.algorithm histogram     # clearer diffs
git config --global core.autocrlf input          # Mac/Linux; on Windows: true
```

## نهايات الأسطر و .gitattributes

ينهي ويندوز الأسطر بـ CRLF، وماك ولينكس بـ LF. وملف `.gitattributes` في المشروع يجعل commits الجميع متطابقة:

```text
* text=auto eol=lf
*.bat text eol=crlf
*.png binary
```

## الـ hooks: شغّل الفحوص تلقائيًا

الـ **hook** سكربت يشغّله Git في لحظة ما، مثل قبل كل commit. ضع هذا في `.git/hooks/pre-commit` واجعله قابلًا للتشغيل (`chmod +x`): يُرفض الـ commit إن فشلت الاختبارات.

```bash
#!/bin/sh
npm test --silent || { echo "Tests failed, commit stopped."; exit 1; }
```

مجلد `.git/hooks` لا يُشارك مع الفريق. ولمشاركة الـ hooks ضعها في مجلد مثل `.githooks/` داخل المشروع وشغّل `git config core.hooksPath .githooks`، أو استخدم أداة مثل [pre-commit](https://pre-commit.com) أو Husky. و `git commit --no-verify` يتخطى الـ hooks (للطوارئ).
